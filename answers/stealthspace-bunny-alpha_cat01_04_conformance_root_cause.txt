Three mechanisms explain most of the measured collapse. First, `Risk Screen` replaced a label the model did not recognize; a UI audit supports semantic equivalence. Second, gateway-generated `Queue Routed` activity adds nonbusiness steps, and its emission is incomplete. Third, the ETL change can manufacture reversed `Notify`/`Decision` sequences. Sequential improvements from 32% to 58%, 81%, and 89% fitting provide strong discrimination: the first two repairs recover 49 of the 57 percentage points regained. These aggregates cannot estimate each mechanism’s exact causal share, but they make a broad employee-behavior explanation unnecessary.

Residual evidence must remain separate. `Manual Override` is reportedly a real user action, but it might correct routing or bypass controls. The 55 enhanced traces without a recorded compliance check remain ambiguous between execution and extraction failure; source ordering does not restore a missing event. In August, 210 sign-offs, including 60 after standard review, constitute evidence of a changed control environment. The August policy explains why a control-flow-only tree is stale for a value-dependent obligation. The 66% to 86% improvement with optional sign-off shows syntactic accommodation, not that every sign-off is permissible; high-value status is missing from the aggregate.

Stable approval and appeal rates neither validate the logged semantics nor exclude a narrow serious breach. A prohibited action can remain undetected, while logging repairs can improve fitness without changing operations. Cycle time, event counts, and metadata quality therefore need provenance-aware, behavior-specific investigation rather than inference from noncompliance labels.

def expand_variant_table(variant_counts):
    """Expand counts into one STPT line per event, then parse and construct a log."""
    rows = []
    case_number = 0
    base = datetime(2026, 1, 1)

    for activities, count in variant_counts.items():
        for _ in range(count):
            case_id = f"AGG_{case_number:06d}"
            case_number += 1
            case_start = base + timedelta(seconds=case_number)

            for position, activity in enumerate(activities):
                # Synthetic times preserve only supplied within-trace order.
                timestamp = case_start + timedelta(seconds=position)
                rows.append(
                    f"{case_id},{activity},{timestamp.strftime('%Y-%m-%d %H:%M:%S')}"
                )

    parsed = pm4py.parse_event_log_string(
        "\n".join(rows),
        sep=",",
        activity_key="concept:name",
        timestamp_key="time:timestamp",
        case_id_glue=",",
        return_variant="list_of_dicts",
    )

    records = [
        {
            "case:concept:name": str(row["case:concept:name"]),
            "concept:name": str(row["concept:name"]),
            "time:timestamp": pd.Timestamp(row["time:timestamp"]),
        }
        for row in parsed
    ]

    return pm4py.event_log_from_records(
        records,
        activity_key="concept:name",
        timestamp_key="time:timestamp",
        case_id_key="case:concept:name",
    )


def activities(trace):
    return tuple(event["concept:name"] for event in trace)


def variant_weights(log):
    return Counter(activities(trace) for trace in log)


def normalize_log(log, map_labels=True, remove_queue=True):
    normalized = EventLog()

    for trace in log:
        mapped = []
        for event in trace:
            activity = event["concept:name"]

            if map_labels:
                activity = LABEL_MAP.get(activity, activity)

            # A business user action; deliberately NOT removed.
            if remove_queue and activity == "Queue Routed":
                continue

            mapped.append(Event([{
                "concept:name": activity,
                "time:timestamp": event["time:timestamp"],
                # Preserve the XES attribute object rather than a single string.
                "resource:attributes": dict(event.get("resource:attributes", {})),
            }]))

        if mapped:
            normalized.append(mapped)

    return normalized


def move_kind(move):
    """Portable diagnostics across common PM4Py move-class representations."""
    name = type(move).__name__.lower()

    if "insert" in name:
        return "model_insertion"
    if "delet" in name:
        return "log_deletion"
    if "skip_faulty" in name:
        return "model_skip_prefix"
    if "skip_skippable" in name:
        return "model_skip_suffix"
    if "skip" in name:
        return "model_skip_other"
    return "synchronization"


def alignment_report(log, net, initial_marking, final_marking):
    """
    Replay-based extensive fitness, preserving supplied case multiplicities.

    The denominator is the sum of observed and model steps over weighted cases.
    Silent model steps are included through the returned model_steps sequence.
    """
    weights = variant_weights(log)
    total_cost = 0.0
    total_steps = 0.0
    diagnostics = Counter()
    move_labels = {}

    for trace in log:
        weight = weights[activities(trace)]
        result, _, model_steps = trace_le_alignment(
            trace, net, initial_marking, final_marking
        )

        cost = float(result["cost"])
        total_cost += weight * cost
        total_steps += weight * (len(trace) + len(model_steps))

        for move in result["sync"]:
            kind = move_kind(move)
            diagnostics[kind] += weight

            log_activity = getattr(move, "log_move", None)
            model_activity = getattr(move, "model_move", None)
            labels = move_labels.setdefault(kind, set())

            if log_activity is not None:
                labels.add(str(getattr(log_activity, "name", log_activity)))
            if model_activity is not None:
                labels.add(str(getattr(model_activity, "name", model_activity)))

    fitness = 1.0 - total_cost / total_steps if total_steps else float("nan")

    return {
        "cases": sum(weights.values()),
        "variants": len(weights),
        "fitness": float(fitness),
        "weighted_cost": float(total_cost),
        "weighted_denominator": float(total_steps),
        "diagnostics": dict(diagnostics),
        "move_labels": {
            key: sorted(value) for key, value in move_labels.items()
        },
    }


def dfg_edges(log):
    # Classic PM4Py 2.7 return: DFG, start activities, end activities.
    dfg, starts, ends = pm4py.discover_dfg(log)
    edges = {
        (edge[0], edge[1]): int(weight)
        for edge, weight in dfg.get_graph_dfg().items()
    }
    return edges, set(starts), set(ends)


def source_ordered_case_log(
    dataframe,
    map_labels=True,
    remove_queue=True,
):
    """
    Use authoritative per-case source sequence, not warehouse-ingestion order.

    This function does not create source evidence. Validate sequence semantics
    and completeness before relying on it.
    """
    required = {"case_id", "activity", "source_sequence"}
    missing = required - set(dataframe.columns)
    if missing:
        raise ValueError(f"Missing source columns: {sorted(missing)}")

    data = dataframe.copy()
    if data["source_sequence"].isna().any():
        raise ValueError("Missing source_sequence; do not silently invent an order.")

    data["concept:name"] = data["activity"].replace(LABEL_MAP)
    if map_labels:
        data["concept:name"] = data["concept:name"].map(
            lambda value: LABEL_MAP.get(value, value)
        )

    if remove_queue:
        data = data[data["concept:name"] != "Queue Routed"]

    # Stable sorting preserves supplied order for exact sequence ties.
    data = data.sort_values(
        ["case_id", "source_sequence"], kind="mergesort"
    )

## 7. Provisional conclusion

The best explanation for the measured conformance collapse is a layered representation and governance problem. The June–July recovery from 32% to 58% after label mapping, to 81% after removing technical events, and to 89% after source ordering strongly discriminates among explanations: most of the apparent deterioration came from changed event vocabulary, gateway artifacts, and ingestion-time ordering, not demonstrated workforce misconduct. Confidence in this primary explanation is high, approximately **90–95%**, although the aggregates cannot assign exact causal shares.

A real compliance concern may nevertheless remain. In August, 210 sign-offs show genuine process evolution and explain why the old model is insufficient for the new EUR 50,000 policy. That is not automatically a violation. More importantly, 55 enhanced cases lack a recorded compliance check across June–September. They remain a genuine operational priority because execution and extraction have not been distinguished. `Manual Override` also warrants review as a real user action, without presuming that correction equals misconduct. Confidence that some real control problem remains is **moderate, approximately 55%**; confidence in any particular reviewer’s wrongdoing is much lower.

**Immediate actions:** IT should preserve source events and sequence numbers, document the gateway and logging contracts, and reconcile the 55 missing-check cases without inserting synthetic events. Process owners should version the August policy and add a value-aware conformance rule, not a blanket optional sign-off. Compliance should commission an evidence-complete audit of the missing checks, high-value sign-offs, and overrides, with matched controls and defensible case attribution.

It must not yet be claimed that all reversed notifications were unauthorized, all sign-offs are optional, all overrides are misconduct, or all missing checks are bypasses. Nor may improved aggregate fitness be presented as proof of compliant operations. The stable approval and appeal rates reduce concern about broad customer harm, but incomplete detection means they cannot close the residual compliance question.

## 8. Model-governance recommendation

1. **Version models with policies and executable checks.** Assign every normative model an owner, version, effective date, source-policy identifier, and change history. Require dual approval from process owners and compliance, and preserve the exact model and preprocessing configuration used for every reported conformance result.

2. **Establish event-semantic contracts.** Maintain a controlled dictionary defining each activity’s business meaning, start/end conditions, applicability, producer, and authorization semantics. UI aliases such as `Risk Screen  Classify` must be validated semantic mappings, not informal string replacements; real user actions such as `Manual Override` must remain distinguishable from technical activity.

3. **Adopt an explicit technical-event policy.** Classify events as business activities, technical routing, duplicate delivery, or operational telemetry. Exclude technical events only in documented derived views, while retaining their provenance and case linkage in the audit log. Removal rules must be tested against gateway schemas and cannot be inferred solely from poor model fit.

4. **Preserve timestamp and ordering provenance.** Record business occurrence time separately from creation, ingestion, and receipt time, together with source event IDs, sequence domains, clock/time-zone metadata, gaps, and ties. Never substitute ingestion time for business order without disclosure; validate source sequence and preserve unresolved ordering rather than forcing a total order.

5. **Make material constraints data-aware.** High-value thresholds, resource roles, and authorization rules require governed case attributes and contextual conformance checks. A control-flow tree alone cannot enforce the EUR 50,000 condition. A temporary optional-sign-off model may diagnose change, but production compliance must evaluate the actual predicate and authorized signer.

6. **Gate releases on end-to-end validation.** Before deployment, test schemas, event completeness, semantic mappings, source ordering, case attributes, representative variants, fitness, precision, and workflow outcomes across release cohorts. After deployment, monitor deviations by activity producer, policy cohort, case value, and evidence completeness, with independent manual audits and rollback criteria; distinguish model repair from operational remediation in every change record.
