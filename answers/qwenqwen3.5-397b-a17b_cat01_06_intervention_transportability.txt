Process mining measures actual overlap versus system-recorded overlap. If system overlap is high but cycle time does not drop, the mechanism (parallel work reduces wait) is flawed, perhaps due to downstream bottlenecks. If system overlap is low despite assignment, the implementation (IT locks) is flawed. Stop rules protect against quality degradation. This design isolates whether the lack of effect is due to the intervention logic or the environment's inability to support it.

## 9. Recommendation

**Conditional Go**

We should transfer the concept of parallel verification but not the blanket implementation. Site A's success was confounded by marketing mix shifts and API upgrades; copying the process tree without these supports will fail. Specifically, we must not copy the "all cases" eligibility. Site B's legal requirement for originals on 62% of cases makes immediate parallel document checking impossible for the majority. Attempting to start Document Check before Originals Receipt violates statutory rules and creates false timestamps.

The digital-only subgroup (38% of volume) should enter first. This mirrors Site A's 90% digital context where the intervention worked. For these cases, Identity and Document checks can genuinely overlap. High-value cases requiring Legal Review must remain sequential until Legal capacity is proven sufficient to handle increased inflow from faster verification. We must also address the IT case locking constraint; without system changes, parallel tasks will sit idle waiting for ownership transfer.

Expected benefits include reduced waiting time before Assessment for digital claims, potentially lowering median cycle time by 5-10 hours. Risks include bottleneck shifting to Assessment or Legal Review, worsening p90 performance if downstream capacity is not expanded. Rework may increase if parallel checks reduce communication between specialized roles, evidenced by Site A's slight rework increase.

Expansion to physical document cases should only occur if Originals Receipt delay is reduced externally. Modification is needed if Assessment queue times spike. Abandonment is triggered if appeal rates rise above 5.5% or if IT case locks prevent true parallel task ownership despite system changes. We must pilot with strict controls to separate process logic failure from resource constraints. The goal is structural alignment with legal constraints, not blind replication of Site A's tree. Management must acknowledge that Site B's complexity requires a segmented approach, prioritizing low-risk digital claims to validate the causal mechanism before scaling.
