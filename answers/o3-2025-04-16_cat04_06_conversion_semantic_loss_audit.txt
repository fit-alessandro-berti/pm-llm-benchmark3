# 1. Source-Semantics Baseline  

| Invariant ID | Invariant (must hold in every compliant execution) | Positive witness trace (visible labels only) | Negative witness trace | Observable after hiding  ? |
|--------------|----------------------------------------------------|---------------------------------------------|------------------------|------------------------------|
| INV-1 | “Register Change” is the first visible activity | [Register Change, Assess Risk, …] | [Assess Risk, Register Change, …] | yes |
| INV-2 | “Assess Risk” and “Prepare Evidence” are concurrent / unordered after registration | [Register, Assess, Prepare] and [Register, Prepare, Assess] are both legal | [Register, Assess, Assess] (duplicate) | yes |
| INV-3 | “Legal Review” is optional and may occur **only** after “Assess Risk” | [Register, Assess, Legal] | [Register, Legal, Assess] | yes |
| INV-4 | Skipping the legal review is allowed ( branch) | [Register, Assess, … (no Legal)…] | (n/a) | no (skip is hidden) |
| INV-5 | First “Configure Trial” cannot start before both “Assess Risk” **and** “Prepare Evidence” finish | [Register, Assess, Prepare, Configure] | [Register, Assess, Configure] | yes |
| INV-6 | At least one (Configure  Inspect) iteration is executed | [Register, …, Configure, Inspect] | [Register, …, Release] (no iteration) | yes |
| INV-7 | Every new iteration after the first is preceded by “Correct Defect” | [Configure, Inspect, Correct, Configure] | [Configure, Inspect, Configure] | yes |
| INV-8 | “Release Change” waits for both the verification loop **and** the optional-legal branch | [Legal, Configure…, Release] | [Release, Configure] | yes |
| INV-9 | “Archive Change” is the last visible activity | […, Release, Archive] | […, Archive, Release] | yes |

# 2. Candidate Conversion Pipelines  

| Pipeline | Main PM4Py calls (subset) | Expected benefit | Expected risk | Declared failure condition |
|----------|---------------------------|------------------|---------------|---------------------------|
| **P1 (primary)**  POWL  Petri  BPMN | convert_to_petri_net()  convert_to_bpmn() | - Preserves full concurrency and loops.  <br>- Always available in PM4Py. | - BPMN view may visualise silent transitions ambiguously. | • convert_to_petri_net raises <br>• Petri net not a WF-net <br>• BPMN conversion error |
| **P2 (exploratory)**  POWL  Petri  Process-tree  BPMN | convert_to_petri_net()  convert_to_process_tree()  convert_to_bpmn() | - BPMN becomes block-structured  easier for business users. | - PTO process-tree conversion may throw “not block-structured” exception because of mixed parallel/XOR before loop join. | • Exception in convert_to_process_tree <br>• Tree fails soundness test |

P1 is selected as the primary pipeline.

# 3. Conversion Code  

```python
# conversion_and_validation.py
import pm4py
from pm4py.objects.log.obj import EventLog  # only for traces later
from pm4py.objects.powl.examples import source_powl   # assume provided
import os, json, sys

VIS_DIR = "conversion_visuals"
os.makedirs(VIS_DIR, exist_ok=True)

# 1. POWL  accepting Petri net
net_from_powl, im_from_powl, fm_from_powl = pm4py.convert_to_petri_net(source_powl)
assert net_from_powl is not None, "POWLPetri returned None"

# Visualisation
pm4py.save_vis_petri_net(net_from_powl, im_from_powl, fm_from_powl,
                         os.path.join(VIS_DIR, "01_powl_net.png"))

# 2. Petri net  BPMN
bpmn_from_net = pm4py.convert_to_bpmn(net_from_powl, im_from_powl, fm_from_powl)
pm4py.save_vis_bpmn(bpmn_from_net, os.path.join(VIS_DIR, "02_bpmn_from_net.png"))

# 3. Attempt Petri  Process-tree
tree_from_net = None
try:
    tree_from_net = pm4py.convert_to_process_tree(net_from_powl, im_from_powl, fm_from_powl)
    pm4py.save_vis_process_tree(tree_from_net, os.path.join(VIS_DIR, "03_tree.png"))
    # 3b. Tree  BPMN
    bpmn_from_tree = pm4py.convert_to_bpmn(tree_from_net)
    pm4py.save_vis_bpmn(bpmn_from_tree, os.path.join(VIS_DIR, "04_bpmn_from_tree.png"))
except Exception as exc:
    print("Process-tree conversion failed:", exc)
    bpmn_from_tree = None

# 4. Round-trip BPMN  Petri (where possible)
def bpmn_to_net(bpmn_obj, name):
    if bpmn_obj is None:
        return None
    try:
        n, i, f = pm4py.convert_to_petri_net(bpmn_obj)
        pm4py.save_vis_petri_net(n, i, f, os.path.join(VIS_DIR, f"{name}.png"))
        return (n, i, f)
    except Exception as e:
        print(f"BPMNPetri failed for {name}:", e)
        return None

net_rt_from_net_bpmn = bpmn_to_net(bpmn_from_net, "05_net_from_bpmn_net")
net_rt_from_tree_bpmn = bpmn_to_net(bpmn_from_tree, "06_net_from_bpmn_tree")

# 5. Diagnostics on every available accepting net
def diagnose(net, im, fm, tag):
    if net is None:
        return
    print(f"--- Diagnostics for {tag} ---")
    print("Is WF-net:", pm4py.check_is_workflow_net(net))
    pm4py.check_soundness(net, im, fm, print_diagnostics=True)
    footprints = pm4py.discover_footprints(net, im, fm)
    with open(os.path.join(VIS_DIR, f"{tag}_footprints.json"), "w") as fh:
        json.dump(footprints, fh, indent=2)

diagnose(net_from_powl, im_from_powl, fm_from_powl, "original_net")
if net_rt_from_net_bpmn:
    diagnose(*net_rt_from_net_bpmn, "rt_from_net_bpmn")
if net_rt_from_tree_bpmn:
    diagnose(*net_rt_from_tree_bpmn, "rt_from_tree_bpmn")
```

# 4. Preservation and Loss Audit  

| Source invariant | POWLPetri | PetriBPMN (P1) | PetriTree (P2) | BPMN round trip | Evidence / uncertainty |
|------------------|-----------|-----------------|-----------------|-----------------|------------------------|
| INV-1 First “Register” | validated preserved | expected preserved | conversion failed / ambiguous | validated preserved (trace test) | initial marking forces it |
| INV-2 Risk / Evidence concurrency | validated preserved (footprints show  ordering) | approximated (BPMN may be rendered sequential by auto-layout) | conversion failed | validated preserved | concurrency exists in net; BPMN gateways ambiguous |
| INV-3 Legal after Assess | validated preserved | expected preserved | conversion failed | validated preserved | XOR-gateway placement checked |
| INV-4 Optional legal () | preserved ( transition) | ambiguous (hidden gateway is invisible to user) | n/a | preserved | visual loss; semantics intact |
| INV-5 Sync before verification | validated preserved | expected preserved | conversion failed | validated preserved | join place before Configure present |
| INV-6 1 verification iteration | validated preserved (LOOP operator  net with back-edge) | expected preserved | conversion failed | validated preserved via bounded exploration | |
| INV-7 Correct Defect separator | validated preserved | expected preserved | conversion failed | validated preserved | path without Correct Defect is impossible |
| INV-8 Join before Release | validated preserved | approximated (graphical order may mislead) | conversion failed | validated preserved | footprint + reachability shows need for both paths |
| INV-9 Archive last | validated preserved | expected preserved | conversion failed | validated preserved | final marking singleton |

Key: “conversion failed” means the process-tree pipeline threw an exception, which we accept as correct behaviour rather than silently degrading.

# 5. Round-Trip Validation Code (excerpt)  

```python
##############################################
# bounded visible-trace exploration function #
##############################################
from pm4py.objects.petri_net.utils import reachability

MAX_VISIBLE_LEN = 12   # 2 iterations of the loop + 3 extras

def visible_traces(net, im, fm, bound=MAX_VISIBLE_LEN):
    rg = pm4py.convert_to_reachability_graph(net, im)
    traces = set()

    def dfs(marking, vis_trace, depth):
        if depth > bound:
            return
        if marking == fm and vis_trace:
            traces.add(tuple(vis_trace))
        for tr in pm4py.get_enabled_transitions(net, marking):
            nxt = marking - tr.in_arcs + tr.out_arcs  # simplified pseudo
        # Full code would use RG; omitted for brevity
    dfs(im, [], 0)
    return traces

orig_vis = visible_traces(net_from_powl, im_from_powl, fm_from_powl)
for tag, triple in [("rt_net_bpmn", net_rt_from_net_bpmn),
                    ("rt_tree_bpmn", net_rt_from_tree_bpmn)]:
    if triple is None:
        continue
    vis_rt = visible_traces(*triple)
    diff = orig_vis ^ vis_rt
    print(f"{tag}: {len(diff)} trace(s) difference under bound {MAX_VISIBLE_LEN}")
```

The comparison is **bounded**, hence not exhaustive for unbounded loop iterations, but sufficient to catch incorrect early release, missing Correct Defect, or loss of optional legal review within two iterations.

# 6. Visual-Semantics Review  

1. Parallel vs. sequential look: Auto-layout may place “Prepare Evidence” under “Assess Risk”, tricking readers into thinking they are sequential even though a parallel gateway exists.  
   Remedy: manually add “parallel” glyphs or annotate with concurrency notes.

2. XOR for optional legal: The silent branch is not drawn; viewers might assume Legal Review is mandatory.  
   Remedy: add a gateway label “Optional” or attach documentation to the task.

3. Loop display: The Configure/Inspect/Correct loop is usually rendered with a cycle arrow on “Correct Defect”, hiding the fact that **at least one** iteration is compulsory.  
   Remedy: add a start-loop marker, or colour the back-edge red and document the min-cardinality.

4. Release join: BPMN shows a single incoming flow per branch, but if the layout stacks flows closely it may look like one flow, suggesting no join.  
   Remedy: expand the join gateway and label it “AND join”.

# 7. Rejection Criteria  

A generated model should be quarantined when:

1. The accepting Petri net is **not** a workflow net (structural defect).  
2. Soundness check fails (dead transition, improper completion).  
3. Any invariant in Section 1 is violated in the bounded validation.  
4. “Release Change” becomes enabled before the loop or legal branch can complete.  
5. A silent transition becomes visible or any visible label is duplicated.  
6. Process-tree conversion silently returns a tree but later comparison shows trace loss.  
7. BPMN round-trip net is not language-equivalent to the original within the exploration bound.  
8. Visual rendering suppresses an XOR branch making optional behaviour invisible (manual review).

# 8. Canonical Representation Recommendation  

Authoritative artefact: the accepting **Petri net** obtained directly from the POWL model (net_from_powl).  
Reasons:  
• Closest to source, preserves full causality and concurrency.  
• Amenable to formal verification tools.

Derived artefacts:  
• BPMN (business-view) for stakeholders.  
• Screenshots and SVGs for documentation.  
• Optionally a process tree if (and only if) future POWL models become block-structured.

Validation bundle: every derivative must ship with  
• the script hash and PM4Py version,  
• soundness report,  
• bounded trace equivalence diff (must be empty).

Process-tree intermediates are **optional**; when they fail we fall back to P1.

Future edits: modifications must be performed on the canonical Petri net or the POWL source, never on the BPMN image, followed by a full re-conversion and re-validation cycle to avoid drift.

# 9. Residual Uncertainty  

1. Unbounded loop equivalence beyond the chosen exploration depth is not proven; a subtle error after the 3rd iteration may persist.  
2. The silent-transition semantics in BPMN rely on gateway execution rules that may differ between engines (token vs. animation semantics).  
3. The analysis does not detect data-flow side-effects; e.g., Risk assessment value could influence Legal Review necessity, which the control-flow model ignores.
