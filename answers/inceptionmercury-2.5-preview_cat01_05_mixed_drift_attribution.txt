## 2. Raw-versus-normalized interpretation

The raw/mapped fitness gap implies semantic shifts rather than structural violations. Mapping `Eligibility Screen` to `Validate Eligibility` recovers conformance metrics without proving business logic stayed static; a rule change could still alter downstream flows or validation depth. Duplicated `Open Case` events inflate frequency counts, biasing DFGs toward start-node anomalies and inflating variant complexity. Missing resources obscure responsibility allocation, hindering variance analysis and workload balancing. Crucially, post-May patterns cannot be dismissed as logging drift. `Request Info` rates and rework variants climb steadily alongside cycle times, even when fitness stabilizes after mapping. This suggests substantive behavioral changes driven by incomplete document bundles from Supplier Z. Additionally, median service time remains stable while queues lengthen, indicating capacity constraints rather than activity inefficiency. The persistent gap between mapped fitness and cycle time degradation confirms that schema fixes did not restore original process health. Thus, the log reflects both provenance artifacts and genuine operational deterioration requiring distinct remedies. Furthermore, resource missingness concentrates in migrated activities, suggesting systemic integration issues rather than random noise, which impacts downstream process mining reliability significantly.

## 8. Reproducible Python and PM4Py plan

```python
# Part A: Monthly Data Analysis
import pandas as pd
import numpy as np

data = {
    'month': ['2026-01', '2026-03', '2026-05', '2026-06', '2026-07', '2026-10'],
    'raw_fitness': [0.92, 0.55, 0.49, 0.48, 0.50, 0.55],
    'mapped_fitness': [0.92, 0.90, 0.88, 0.87, 0.86, 0.88],
    'cycle_h': [31.5, 31.2, 36.5, 40.8, 44.2, 47.8],
    'rework_pct': [12, 12, 24, 27, 29, 26]
}
df = pd.DataFrame(data)
df['month'] = pd.to_datetime(df['month'])
df = df.sort_values('month')

# Baseline relative change
baseline = df.loc[df['month'] == '2026-01'].iloc[0]
df['cycle_delta'] = df['cycle_h'] - baseline['cycle_h']
df['fitness_recovery'] = df['mapped_fitness'] - df['raw_fitness']

# DFG distance (Jaccard on edges >0)
edges_map = {
    '2026-01': {'Reg-Val': 100, 'Val-Collect': 98, 'Assess-Info': 12},
    '2026-05': {'Reg-Val': 100, 'Val-Collect': 96, 'Assess-Info': 24}
}
def jaccard(e1, e2):
    s1, s2 = set(e1.keys()), set(e2.keys())
    return len(s1 & s2) / len(s1 | s2) if (s1 | s2) else 1

dist = jaccard(edges_map['2026-01'], edges_map['2026-05'])
print(f"Change Point: {df['month'].iloc[0]} -> {df['month'].iloc[-1]}, Distance: {dist:.2f}")
print(f"Cycle Delta: {df['cycle_delta'].iloc[-1]:.1f}h")
print("Caveats: Omitted edges may affect distance; aggregates hide sub-group variance.")

# Part B: PM4Py Event Log Functions
import pm4py

def prepare_log(event_list):
    """Formats raw event list for PM4Py."""
    return pm4py.format_dataframe(event_list, case_id='case_id', event_id='event_id', timestamp='time')

def slice_window(log, start, end):
    """Slices event log by time range."""
    return pm4py.filter_time_range(log, start_time=start, end_time=end)

def get_monthly_dfg(log, year=2026, month=1):
    """Discovers DFG for a specific month."""
    start = f"{year}-{month:02d}-01"
    end = f"{year}-{month+1:02d}-01"
    return pm4py.discover_dfg(slice_window(log, start, end))

def get_variants(log):
    """Computes variants."""
    return pm4py.get_variants(log)

def get_temporal_profile(log):
    """Computes temporal profile."""
    return pm4py.discover_temporal_profile(log)

def get_skeleton(log):
    """Optional log skeleton."""
    return pm4py.discover_skeleton(log)

def compare_mappings(log, mapping_dict):
    """Compares raw vs mapped without overwriting original log."""
    mapped_log = log.copy()
    mapped_log['event_type'] = mapped_log['event_type'].map(mapping_dict).fillna(mapped_log['event_type'])
    return log, mapped_log
```
