## **1. Equivalence Notions**

### **Visible Trace Equivalence (after hiding ``)**
- **Definition**: Two models are *visible trace equivalent* if they generate the same set of visible traces (ignoring silent `` transitions).
- **Label Distinction**: Duplicate visible labels (e.g., multiple `Analyze Revision`) are distinguished by **occurrence position** (order matters) and **identity** (each instance is unique in the trace).
- **Silent Transitions (``)**: Hidden but may affect reachability of visible traces.

### **Bounded Visible-Language Equivalence (P3)**
- **Definition**: Models are equivalent if their visible traces (with 12 events and 3 `Analyze Revision`) match.
- **Abstraction**: Silent transitions are hidden, but visible labels are preserved in order.
- **Limitation**: Bounded equivalence does not guarantee unbounded equivalence.

### **Business-Relevant Equivalence (P1: Operational Compliance)**
- **Definition**: Models must enforce:
  1. Every `Analyze Revision` must be preceded by a `Check Revision`.
  2. `Rework Case` separates analysis attempts.
  3. `Approve Revision` is optional but visible in logs.
  4. The number of `Check Revision` occurrences is relevant.
- **Key Difference**: Model A checks *inside* the loop; Model B checks *concurrently* with the loop.

### **Abstracted Dashboard Equivalence (P2: Executive View)**
- **Definition**: Models must satisfy:
  1. `Open Case` first, `Close Case` last.
  2. At least one `Analyze Revision` and one `Check Revision`.
  3. Repeated `Check Revision` collapses to a Boolean ("a check occurred").
  4. `Approve Revision` and `` are hidden.
  5. Count of `Analyze Revision` and whether `Rework Case` occurred are recorded.

## **5. Bounded Comparison Code (PM4Py)**

```python
import pm4py
from pm4py.objects.process_tree.obj import ProcessTree
from pm4py.objects.log.obj import EventLog, Trace
from pm4py.objects.conversion.log import converter as log_converter
from pm4py.objects.petri_net.obj import PetriNet, Marking
from pm4py.algo.discovery.alpha import algorithm as alpha_miner
from pm4py.algo.conformance.tokenreplay import algorithm as token_replay
from pm4py.objects.petri_net.utils import petri_utils

def parse_and_compare_models():
    # Parse process trees
    model_a_str = """->('Open Case', *(->(+('Analyze Revision', 'Check Revision'), X('Approve Revision', tau)), 'Rework Case'), 'Close Case')"""
    model_b_str = """->('Open Case', +('Check Revision', *(->('Analyze Revision', X('Approve Revision', tau)), 'Rework Case')), 'Close Case')"""

    model_a = pm4py.parse_process_tree(model_a_str)
    model_b = pm4py.parse_process_tree(model_b_str)

    # Convert to Petri nets
    net_a, im_a, fm_a = pm4py.convert_to_petri_net(model_a)
    net_b, im_b, fm_b = pm4py.convert_to_petri_net(model_b)

    # Check soundness
    print("Model A sound:", pm4py.check_soundness(net_a, im_a, fm_a))
    print("Model B sound:", pm4py.check_soundness(net_b, im_b, fm_b))

    # Generate traces (bounded: 3 Analyze Revision, 12 events)
    def generate_traces(net, im, fm, max_analyze=3, max_events=12):
        traces = []
        visited = set()
        stack = [(im, [])]

        while stack:
            marking, path = stack.pop()
            if marking in visited:
                continue
            visited.add(marking)

            # Check if final marking
            if marking == fm:
                if len(path) <= max_events and path.count('Analyze Revision') <= max_analyze:
                    traces.append(path)
                continue

            # Get enabled transitions
            enabled = pm4py.get_enabled_transitions(net, marking)
            for t in enabled:
                new_marking = petri_utils.apply_transition(net, marking, t)
                new_path = path + [t.label if t.label != 'tau' else None]
                stack.append((new_marking, new_path))

        return traces

    traces_a = generate_traces(net_a, im_a, fm_a)
    traces_b = generate_traces(net_b, im_b, fm_b)

    # Filter out None (tau) and deduplicate
    traces_a = [tuple(filter(None, trace)) for trace in traces_a]
    traces_b = [tuple(filter(None, trace)) for trace in traces_b]

    # Find unique traces
    set_a = set(traces_a)
    set_b = set(traces_b)

    unique_to_a = set_a - set_b
    unique_to_b = set_b - set_a

    print("\nTraces unique to Model A:")
    for trace in unique_to_a:
        print(trace)

    print("\nTraces unique to Model B:")
    for trace in unique_to_b:
        print(trace)

    print(f"\nTotal traces Model A: {len(set_a)}")
    print(f"Total traces Model B: {len(set_b)}")

if __name__ == "__main__":
    parse_and_compare_models()
```

### **Output Explanation**
- The code **exhaustively explores** all traces with 3 `Analyze Revision` and 12 events.
- **Model A** allows multiple `Check Revision` (one per loop iteration).
- **Model B** allows only **one** `Check Revision` (even if loop repeats).
- **Bounded equivalence holds** only if the loop does not repeat excessively.

def count_structural_features(tree):
    nodes = tree.get_children()
    depth = max([count_depth(node) for node in nodes])
    visible_leaves = sum(1 for node in tree.get_leaves() if node.label not in ['tau'])
    silent_leaves = sum(1 for node in tree.get_leaves() if node.label == 'tau')
    return len(nodes), depth, visible_leaves, silent_leaves

def count_depth(node, current=1):
    if not node.children:
        return current
    return max([count_depth(child, current + 1) for child in node.children])

## **8. Simplified Model (Target: P2 Dashboard View)**

### **Compact Process Tree (POWL-like)**
```text
->(
  'Open Case',
  +(
    'Check Revision',
    *(
      ->(
        'Analyze Revision',
        X('Approve Revision', tau)
      ),
      'Rework Case'
    )
  ),
  'Close Case'
)
```
**Simplification Rationale**:
- **Hides `Approve Revision`** (dashboard view).
- **Collapses multiple `Check Revision`** into one (Boolean fact).
