# 1. Equivalence Notions

**Visible trace equivalence (after hiding `tau`)**  
Let $L_{vis}(T)$ be the set of sequences of visible labels produced by process tree $T$ after projecting away all silent transitions (`tau`). Two trees are *visibly equivalent* iff $L_{vis}(A)=L_{vis}(B)$. Duplicate visible labels are **distinguished by occurrence position** (i.e., the trace is a sequence; the second `'Analyze Revision'` is a different event from the first, not an identity tag).

**Bounded visible-language equivalence under P3**  
$L_{vis}^{\leq 12, \leq 3}(A) = L_{vis}^{\leq 12, \leq 3}(B)$, where traces are restricted to length $\le 12$ visible events and at most three occurrences of `'Analyze Revision'`. This is evidence, not a proof of full equivalence.

**Business-relevant equivalence under P1 (operational compliance)**  
Two trees are P1-equivalent if, for every visible trace, each `'Analyze Revision'` is paired with a `'Check Revision'` inside the same loop body (before the next `'Rework Case'` or `'Close Case'`), optional `'Approve Revision'` is permitted once per iteration, and loop repetition is governed by `'Rework Case'`.

**Abstracted dashboard equivalence under P2**  
Apply abstraction $\alpha$: hide `'Approve Revision'` and all silent behavior; collapse `'Check Revision'` occurrences to Boolean $\mathbf{check}$; keep `'Open Case'` first, `'Close Case'` last; record $k = \#\!$`'Analyze Revision'` and $r = \mathbf{rework}$ (true if any `'Rework Case'`). Trees are P2-equivalent if $\alpha(L_{vis}(A)) = \alpha(L_{vis}(B))$.

# 2. Structural Comparison

| Feature | Model A | Model B | Semantic consequence |
|---|---|---|---|
| **Loop scope** | Loop body = `Seq( Par(Analyze,Check), X(Approve,tau) )`; redo = `Rework` | Loop body = `Seq(Analyze, X(Approve,tau))`; redo = `Rework`; `Check` is outside loop | A couples check to each analysis; B decouples |
| **Min Check occurrences** | $k$ (one per loop body, $k\geq 1$) | $1$ (single parallel branch) | A scales with iterations; B is constant |
| **Max Check occurrences** | Unbounded (with loop) | $1$ | A can generate arbitrarily many; B cannot |
| **Placement of Check** | Inside body, must complete before `Rework` of that iteration | Concurrent with whole loop; can occur after `Rework` or after loop exit | A enforces temporal pairing; B allows deferred check |
| **Optional approval** | Once per loop iteration (`X` inside body) | Once per loop iteration (`X` inside body) | Same per-iteration option |
| **Concurrency** | Internal: `+` (parallel/interleaved) of Analyze/Check inside loop | External: `+` (parallel/interleaved) of Check with loop | A has bounded concurrency per iteration; B has cross-iteration concurrency |
| **Join before Close** | Loop exits to sequence then `'Close Case'` | Parallel join of `Check` and loop, then `'Close Case'` | A closes after loop; B requires `Check` branch to finish |

*Interpretation of operators used in this comparison:* `+` is read as concurrency (required by the explicit “concurrently” description of B); `X` is read as XOR / optional (required by P1’s “optional approval”). PM4Py parses these tokens; the BFS code below validates the resulting semantics empirically.

**How optional `Approve` and hidden `tau` affect the verdict:**  
`X('Approve Revision', tau)` is an exclusive branch: at each loop iteration it yields either `'Approve Revision'` or nothing. The verdict between A and B is **not** changed by the presence/absence of Approve; the decisive factor is whether `'Check Revision'` is locked inside the loop body (A) or external (B).

**Two-analysis traces:** **T-A1** and **T-B1** both contain two `'Analyze Revision'` occurrences but differ in whether the first `'Rework Case'` is preceded by `'Check Revision'`. This is the minimal witness for P1 divergence.

# 5. Bounded Comparison Code

This script uses **exhaustive BFS over markings** (not random play-out) and compares only complete traces with $\leq 12$ visible events and $\leq 3$ `'Analyze Revision'`.

```python
import pm4py
from collections import deque
from pm4py.objects.petri_net.obj import Marking, PetriNet

# ------------------------------------------------------------------
# 1. Parse both process trees (as given in the task)
# ------------------------------------------------------------------
t_str_a = "->('Open Case', *(->(+('Analyze Revision', 'Check Revision'), X('Approve Revision', tau)), 'Rework Case'), 'Close Case')"
t_str_b = "->('Open Case', +('Check Revision', *(->('Analyze Revision', X('Approve Revision', tau)), 'Rework Case')), 'Close Case')"

tree_a = pm4py.parse_process_tree(t_str_a)
tree_b = pm4py.parse_process_tree(t_str_b)

# ------------------------------------------------------------------
# 2. Convert to accepting Petri nets and check soundness
# ------------------------------------------------------------------
net_a, im_a, fm_a = pm4py.convert_to_petri_net(tree_a)
net_b, im_b, fm_b = pm4py.convert_to_petri_net(tree_b)

print("Soundness A:", pm4py.check_soundness(net_a, im_a, fm_a, print_diagnostics=False)[0])
print("Soundness B:", pm4py.check_soundness(net_b, im_b, fm_b, print_diagnostics=False)[0])

# ------------------------------------------------------------------
# 3. Exhaustive bounded BFS over markings
# ------------------------------------------------------------------
def freeze_marking(m):
    """Hashable tuple of (place_name, token) sorted."""
    # m may be Marking or dict-like
    try:
        items = [(str(p.name), int(m[p])) for p in m]
    except Exception:
        # Some versions expose .items()
        items = [(str(k.name if hasattr(k, 'name') else k), int(v)) for k, v in m.items()]
    return tuple(sorted(items))

def explore(net, im, fm, max_vis=12, max_analyze=3):
    """Exhaustive BFS; collects complete visible traces only."""
    # Initialize
    init_m = Marking() if not isinstance(im, Marking) else im
    if not isinstance(im, Marking):
        for p, c in (im.items() if hasattr(im, 'items') else []):
            init_m[p] = c

    q = deque()
    # state: (marking, visible_len, analyze_count, trace_tuple)
    q.append((init_m, 0, 0, ()))
    visited = set()
    visited.add((freeze_marking(init_m), 0, 0))
    traces = []

    while q:
        m, vl, ac, trace = q.popleft()

        # If final marking reached, record (only if within bounds; bounds enforced below)
        if freeze_marking(m) == freeze_marking(fm):
            traces.append(trace)
            continue

        # Do not expand visible beyond bounds; silent can still lead to final
        try:
            enabled = pm4py.get_enabled_transitions(net, m)
        except Exception:
            continue

        for t in enabled:
            # Identify label
            label = getattr(t, 'label', None)
            # Silent transitions have None / '' / 'tau'
            is_silent = (label is None or str(label).strip() == '' or str(label) == 'tau')

            # Build next marking manually
            new_m = Marking()
            # Copy current
            try:
                for p, c in m.items():
                    new_m[p] = c
            except Exception:
                # Fallback to dict-like access
                for p in m:
                    new_m[p] = m[p]

            # Consume inputs
            for arc in t.in_arcs:
                p = arc.source
                new_m[p] = new_m.get(p, 0) - 1
            # Produce outputs
            for arc in t.out_arcs:
                p = arc.target
                new_m[p] = new_m.get(p, 0) + 1

            if is_silent:
                new_vl, new_ac = vl, ac
            else:
                new_vl = vl + 1
                new_ac = ac + 1 if str(label) == 'Analyze Revision' else ac
                # Update trace
                new_trace = trace + (str(label),)
            # Prune by P3 bound
            if new_vl > max_vis or new_ac > max_analyze:
                continue
            frozen = freeze_marking(new_m)
            key = (frozen, new_vl, new_ac)
            if key in visited:
                continue
            visited.add(key)
            # For silent, trace unchanged
            q.append((new_m, new_vl, new_ac, new_trace if not is_silent else trace))

    return traces

# ------------------------------------------------------------------
# 4. Run bounded exploration and compare
# ------------------------------------------------------------------
print("\n--- Exhaustive bounded exploration (P3) ---")
traces_a = explore(net_a, im_a, fm_a, max_vis=12, max_analyze=3)
traces_b = explore(net_b, im_b, fm_b, max_vis=12, max_analyze=3)

set_a = set(traces_a)
set_b = set(traces_b)

print(f"A traces found (bounded): {len(set_a)}")
print(f"B traces found (bounded): {len(set_b)}")
print("Unique to A:", len(set_a - set_b))
print("Unique to B:", len(set_b - set_a))

# Print a few witnesses (first few unique)
for t in sorted(set_a - set_b)[:2]:
    print("A-only:", " -> ".join(t))
for t in sorted(set_b - set_a)[:2]:
    print("B-only:", " -> ".join(t))

# ------------------------------------------------------------------
# 5. Heuristic play-out (NOT exhaustive) — for comparison only
# ------------------------------------------------------------------
print("\n--- Heuristic play_out (non-exhaustive) ---")
# pm4py.play_out samples random executions; it may miss traces and
# does not guarantee coverage of the bounded language.
sample_a = pm4py.play_out(tree_a, max_no_of_executions=5)
print("Sample A executions (heuristic):", len(sample_a))
```

**Distinction:** The BFS above is **exhaustive** within the bound because `visited` prevents infinite silent loops and every enabled transition is explored until length/count limits are reached. `pm4py.play_out` is a **random/heuristic** sampler: it can miss rare traces, does not systematically cover all interleavings, and should not be used as proof of equivalence.

```python
def tree_stats(tree, depth=0):
    # Returns dict: nodes, max_depth, visible_leaves, silent_leaves, label_counts
    stats = {'nodes': 1, 'max_depth': depth,
             'visible': 0, 'silent': 0,
             'labels': {}}
    # Leaf?
    if not tree.children or len(tree.children) == 0:
        lab = tree.label
        if lab is not None and str(lab).strip() not in ('', 'tau'):
            stats['visible'] += 1
            stats['labels'][str(lab)] = stats['labels'].get(str(lab), 0) + 1
        elif str(lab) == 'tau':
            stats['silent'] += 1
        return stats
    # Internal
    for c in tree.children:
        s = tree_stats(c, depth+1)
        stats['nodes'] += s['nodes']
        stats['max_depth'] = max(stats['max_depth'], s['max_depth'])
        stats['visible'] += s['visible']
        stats['silent'] += s['silent']
        for k, v in s['labels'].items():
            stats['labels'][k] = stats['labels'].get(k, 0) + v
    return stats
```

# 8. Simplified Model

**Target semantics:** P2 (executive dashboard). The simplification removes external concurrency (the `+` around `Check Revision`) because P2 collapses Check to a Boolean and ignores interleaving. It retains the loop, optional approval, and sequential order Open $\to$ Loop $\to$ Check $\to$ Close.

```text
  'Open Case',

)
```
