```python
import pandas as pd
import pm4py
import networkx as nx

# 1. Load and format
df = pd.read_csv("order_to_resolution.csv")
df = pm4py.format_dataframe(
    df,
    case_id="case:concept:name",
    activity_key="concept:name",
    timestamp_key="time:timestamp"
)
log = pm4py.convert_to_event_log(df)

# 2. Role discovery
roles = pm4py.discover_organizational_roles(log)

def roles_to_df(roles):
    rows = []
    if isinstance(roles, dict):
        for res, role in roles.items():
            rows.append({"org:resource": res, "mined_role": str(role)})
    else:
        for i, group in enumerate(roles):
            for res in group:
                rows.append({"org:resource": res, "mined_role": f"mined_role_{i}"})
    return pd.DataFrame(rows)

role_df = roles_to_df(roles)

# 3. Similarity
sim = pm4py.discover_activity_based_resource_similarity(log)
sim_df = pd.DataFrame(sim) if not isinstance(sim, pd.DataFrame) else sim

# 4. Networks
handover = pm4py.discover_handover_of_work_network(log)
working = pm4py.discover_working_together_network(log)
subcontracting = pm4py.discover_subcontracting_network(log)

def network_edges(net):
    if isinstance(net, (nx.Graph, nx.DiGraph)):
        return pd.DataFrame([
            {"source": u, "target": v, **data}
            for u, v, data in net.edges(data=True)
        ])
    # PM4Py may return a dict-like network; adapt as needed
    try:
        return pd.DataFrame(net)
    except Exception:
        return pd.DataFrame()

handover_df = network_edges(handover)
working_df = network_edges(working)
subcontracting_df = network_edges(subcontracting)

# 5. Resource-level attributes and complexity/substitution join
resource_attrs = df.groupby("org:resource").agg(
    total_events=("concept:name", "size"),
    median_complexity=("case_complexity", "median"),
    high_critical_events=("case_complexity", lambda s: (s >= 0.7).sum()),
    temporary_substitution_events=(
        "temporary_substitution",
        lambda s: s.astype(str).str.lower().isin(["true", "1", "yes"]).sum()
    )
).reset_index()

activity_counts = pd.crosstab(df["org:resource"], df["concept:name"]).reset_index()

# Activity profile normalized per resource, useful for similarity sanity checks
activity_matrix = pd.crosstab(df["org:resource"], df["concept:name"])
activity_profile = activity_matrix.div(activity_matrix.sum(axis=1), axis=0)

# Complexity-weighted activity evidence
activity_complexity = df.groupby(["org:resource", "concept:name"]).agg(
    events=("concept:name", "size"),
    median_case_complexity=("case_complexity", "median"),
    high_critical_events=("case_complexity", lambda s: (s >= 0.7).sum())
).reset_index()

authority_activities = ["A6 Security Review", "A7 Pricing Exception Review", "A9 Supervisor Approval"]
authority_profile = activity_complexity[
    activity_complexity["concept:name"].isin(authority_activities)
]

role_enriched = (
    role_df
    .merge(resource_attrs, on="org:resource", how="left")
    .merge(activity_counts, on="org:resource", how="left")
    .merge(activity_profile.reset_index(), on="org:resource", how="left")
)

# 6. Inspect temporary substitution episodes separately
sub_events = df[df["temporary_substitution"].astype(str).str.lower().isin(["true", "1", "yes"])]
substitution_profile = pd.crosstab(sub_events["org:resource"], sub_events["concept:name"])

# 7. Print/inspect, do not treat mined_role as authority
print("Mined roles:\n", role_df)
print("Similarity:\n", sim_df)
print("Top handover edges:\n", handover_df.sort_values("weight", ascending=False).head(20) if "weight" in handover_df else handover_df.head())
print("Top working-together edges:\n", working_df.sort_values("weight", ascending=False).head(20) if "weight" in working_df else working_df.head())
print("Enriched role view:\n", role_enriched)
print("Authority-sensitive activities:\n", authority_profile)
print("Temporary substitution profile:\n", substitution_profile)
```

    rows = []
    if isinstance(roles, dict):
        for res, role in roles.items():
            rows.append({"org:resource": res, "mined_role": str(role)})
    else:
        for i, group in enumerate(roles):
            for res in group:
                rows.append({"org:resource": res, "mined_role": f"mined_role_{i}"})

def network_edges(net):

            {"source": u, "target": v, **data}
            for u, v, data in net.edges(data=True)
        ])

        return pd.DataFrame(net)

# 6. Operational interpretation

Management should use this structure as a candidate role map, not as a final org chart. The core staffing model is: automation for A1/A2 precheck, routine front-office for standard responses and closure, temporary surge capacity only for low-complexity work, technical analysts for A3/A5/A10, security for A6, commercial for A7/A8, quality for A11/A14, supervisor for final A9, and coordination for cross-functional A13 and escalation routing.

For training, formalize the useful bridges instead of leaving them implicit. R07_Giorgio can be trained and audited as a commercial backup, but his A7/A8 delegation limits and escalation rules should be documented. R13_Mateo can be trained as an escalation broker with mandatory direct-to-specialist paths for critical security, pricing, and approval cases. R01_Amira and R02_Ben can mentor temps, but temps should not receive broad closure authority until entitlement-note quality improves.

For risk control, separate authority from activity volume. A6 security review, A7 pricing exception, and A9 supervisor approval are authority-sensitive. R13’s preliminary A9 approvals must not be treated as final, especially because 13 of 21 were rechecked. R05’s low event count should not cause under-staffing because his cases are high/critical. R11/R12’s high A1/A2/A4/A12 counts should not make them equivalent to permanent front-office agents.

For resilience, cross-train selectively: front-office to technical triage, technical to quality backfill, and commercial shadowing for Giorgio. But preserve independent quality gates and final approval authority. Monitor reopens, pricing duration, security waiting times, and recheck rates as operational controls.

Cautions: first, do not change staffing based only on mined activity-frequency clusters; frequency ignores authority, complexity, and risk. Second, temporary substitution is not proof of permanent competence; Giorgio’s commercial coverage and Mateo’s preliminary approvals show useful but bounded substitution. Third, similar activity profiles do not imply similar authority or risk exposure—R05 and R13 both touch escalations, but one is a rare critical specialist and the other is a broker. Fourth, shadow roles can be beneficial for continuity, but they become risky when delegation limits, audit trails, and final accountability are unclear.
