from collections import Counter

CSV = """case_id,trace,complexity,group,shift,arrival_load,compliance_required,wait_before_review_h,review_service_h,rework_count,cycle_time_h,outcome_30d
C01,Register>Classify>Review>Close,Low,Orion,Night,High,No,3.3,3.1,0,7.2,No appeal
...
"""

# PM4Py import (DFG discovery only; no event timestamps are fabricated)
try:
    from pm4py.objects.log.obj import EventLog, Trace, Event
    from pm4py.discovery import discover_dfg
    PM4PY_AVAILABLE = True
except Exception:
    PM4PY_AVAILABLE = False

def make_log(subdf):
    log = EventLog()
    for _, row in subdf.iterrows():
        tr = Trace()
        tr.attributes["concept:name"] = row["case_id"]
        for act in str(row["trace"]).split(">"):
            tr.append(Event({"concept:name": act}))
        log.append(tr)
    return log

def manual_dfg(subdf):
    dfg = Counter()
    start = Counter()
    end = Counter()
    for _, row in subdf.iterrows():
        acts = str(row["trace"]).split(">")
        start[acts[0]] += 1
        end[acts[-1]] += 1
        for i in range(len(acts)-1):
            dfg[(acts[i], acts[i+1])] += 1
    return dfg, start, end

def print_dfg(subdf, label):
    if PM4PY_AVAILABLE:
        dfg, start, end = discover_dfg(make_log(subdf))
    else:
        dfg, start, end = manual_dfg(subdf)
    print(f"\nDirectly-follows edges for {label}:")
    for edge, freq in sorted(dfg.items(), key=lambda x: -x[1]):
        print(f"  {edge[0]} -> {edge[1]}: {freq}")

## 1. Executive causal assessment

Provisional verdict: `not identifiable from the supplied evidence`; the crude Orion-vs-Nova difference is mainly confounded by case mix and operating conditions. Confidence: 85.

The total effect of changing the resource-group label is not identifiable from these data because assignment is generated by a routing rule after `Classify` and is strongly tied to complexity, shift, compliance requirement, and unmeasured difficulty. A direct effect holding queue wait, service time, or rework fixed is even less identified because those are post-assignment mediators. Mediated interpretations are plausible—Orion has more certified reviewers, and within complexity strata its mean wait and review service are lower—but they remain associations, not causal proof.

Strongest evidence for the verdict is the Simpson reversal. The crude Orion mean is 21.96 h versus Nova 15.24 h, but within low, medium, and high complexity Orion means are 7.50, 17.17, and 31.57 versus Nova 9.64, 19.38, and 35.00. Orion is also far more likely to be high-complexity, night, compliance-required, and rework-heavy. Strongest evidence against the verdict is the consistency of the within-stratum Orion advantage and the plausible staffing mechanism; this could be a real, masked beneficial effect. Small N, sparse overlap, and selection on completed cases prevent a causal conclusion.

The proposed 50% reassignment may fail or backfire because it acts on a label rather than on the mechanisms—reviewer certification, capacity, queueing, compliance waiting, and night staffing. Moving difficult cases to Nova without capacity could increase cycle time and destroy the routing signal needed for learning.

## 6. Intervention and learning plan

Instead, first run an observational baseline, then a capped randomized margin pilot in overlapping strata, and simultaneously test a queue/compliance-capacity intervention. Scale any routing change only on estimated subgroup effects and capacity constraints. If Orion is faster for complex cases, invest in Nova certification/capacity; if no difference, balance workload; if Nova is faster for some low/medium strata, expand only there. # PM4Py-based DFG discovery. No event timestamps are fabricated; event logs are built from trace order.
try:
    from pm4py.objects.log.obj import EventLog, Trace, Event
    from pm4py.discovery import discover_dfg
    PM4PY_AVAILABLE = True
except Exception:
    PM4PY_AVAILABLE = False

def make_log(subdf):
    log = EventLog()
    for _, row in subdf.iterrows():
        tr = Trace()
        tr.attributes["concept:name"] = row["case_id"]
        for act in str(row["trace"]).split(">"):
            tr.append(Event({"concept:name": act}))
        log.append(tr)
    return log

def manual_dfg(subdf):
    dfg = Counter()
    start = Counter()
    end = Counter()
    for _, row in subdf.iterrows():
        acts = str(row["trace"]).split(">")
        start[acts[0]] += 1
        end[acts[-1]] += 1
        for i in range(len(acts) - 1):
            dfg[(acts[i], acts[i + 1])] += 1
    return dfg, start, end

def print_dfg(subdf, label):
    if PM4PY_AVAILABLE:
        dfg, start, end = discover_dfg(make_log(subdf))
    else:
        dfg, start, end = manual_dfg(subdf)
    print(f"\nDirectly-follows edges for {label}:")
    for edge, freq in sorted(dfg.items(), key=lambda x: -x[1]):
        print(f"  {edge[0]} -> {edge[1]}: {freq}")

def check_support(df, grouping, min_n=3):
    counts = df.groupby(list(grouping)).size()
    for idx, n in counts.items():
        if n < min_n:
            idx_txt = ", ".join(str(x) for x in idx) if isinstance(idx, tuple) else str(idx)
            print(f"WARNING: support < {min_n} for {grouping}: {idx_txt} n={n}")

print("Crude group comparison")
crude = df.groupby("resource_group")["cycle_time_h"].agg(["count", "mean", "median"])
print(crude)
crude_diff = crude.loc["Orion", "mean"] - crude.loc["Nova", "mean"]
print(f"Crude Orion-Nova difference: {crude_diff:.2f} h")

print("\nStratified by complexity")
strata = df.groupby(["complexity", "resource_group"])["cycle_time_h"].agg(["count", "mean", "median"])
print(strata)

print("\nMean wait and service by complexity/group")
print(df.groupby(["complexity", "resource_group"])[["wait_before_review_h", "review_service_h"]].mean())

# Standardize to the pooled complexity distribution: Low 12/30, Medium 10/30, High 8/30.
weights = df["complexity"].value_counts(normalize=True).sort_index()
print("\nCommon standardization weights (pooled complexity distribution):")
print(weights.round(3))

def std_mean(subdf, weights):
    means = subdf.groupby("complexity")["cycle_time_h"].mean()
    return sum(means[c] * w for c, w in weights.items())

orion_std = std_mean(df[df["resource_group"] == "Orion"], weights)
nova_std = std_mean(df[df["resource_group"] == "Nova"], weights)
print(f"Complexity-standardized Orion-Nova difference: {orion_std - nova_std:.2f} h")

print("\nOverlap counts for every observed complexity/shift/resource_group combination")
overlap = pd.crosstab([df["complexity"], df["shift"]], df["resource_group"])
print(overlap)

for (comp, shift), row in overlap.iterrows():
    for grp in ["Orion", "Nova"]:
        n = row.get(grp, 0)
        if n < 3:
            print(f"WARNING: sparse cell {comp}, {shift}, {grp}: n={n}")

print("\nTrace variant counts by group")
variants = df.groupby(["resource_group", "trace"]).size().reset_index(name="n")
print(variants.sort_values(["resource_group", "n"], ascending=[True, False]))

print_dfg(df[df["resource_group"] == "Orion"], "Orion")
print_dfg(df[df["resource_group"] == "Nova"], "Nova")

print("\nSupport checks")
check_support(df, ["resource_group"])
check_support(df, ["complexity", "resource_group"])
check_support(df, ["shift", "resource_group"])
check_support(df, ["complexity", "shift", "resource_group"])

## 8. Residual uncertainty

1. Unobserved case risk beyond coarse complexity is central. The single most valuable addition would be a validated pre-assignment risk/difficulty score or blinded audit rating for each case.

2. `wait_before_review_h` mixes queueing with waiting around compliance. The single most valuable addition would be event-level timestamps for `Classify`, `Compliance Check` start/end, `Review` start/end, and `Request Info`/second `Review`.

3. The sample contains only completed cases. The single most valuable design change would be to track open and abandoned cases with current durations, enabling survival or censoring-adjusted analysis.

4. Resource group is a bundle of reviewer skill, staffing, and shift coverage. The single most valuable addition would be reviewer IDs and per-shift staffing/certification counts.

5. Positivity and overlap are poor in several cells. The single most valuable design change would be a small randomized or quasi-random routing pilot with explicit eligibility and assignment probabilities, rather than a blanket 50% reassignment.
