## 2. Raw-versus-normalized interpretation

January–February raw and mapped fitness agree at 0.92–0.93. March raw fitness falls to 0.55 and mapped fitness is 0.90. The 0.35-point recovery accounts for most of the 0.375-point raw drop from the January–February mean on this scoring scale. March splits Register’s successor between Eligibility Screen (500) and Validate Eligibility (140). Together they account for 640 transitions, and their 625 transitions to Collect Documents give about 98 occurrences per 100 cases, close to January.

The gap measures sensitivity to the combined label mapping and duplicate removal under the old normative model. Its size cannot identify how much each correction contributed or estimate the share of cases whose work changed. The same mapped sequence can score well even if the checks, decision criteria, or staff performing them changed. Verify semantic equivalence from stage inputs, outputs, and decision rules.

Duplicated Open Case events can add technical edges, split otherwise identical trace variants, and produce extra alignment moves. They can also bias throughput if the duration clock starts at the first recorded event. Missing resources primarily weaken handover, workload, and team comparisons, with selection bias if complete records are concentrated in particular teams. Activity-only DFGs can retain events with missing resources.

From May onward, both mapped rework edges rise, supported by the raw counts, while the mapped entrance remains stable. Worsening cycle-time tails and reconstructed assessment waits, alongside a modest change in recorded service time, favor a real rework and congestion component. Timestamp provenance and the operational definitions of variants still need validation.

### Distance on the normalized DFG fragment

Use Manhattan distance, (D(t,s)=sum_{e}|r_{t,e}-r_{s,e}|), over the seven supplied relation rates. Give each column equal weight and count the combined decision column once. Rates are occurrences per 100 cases, so repeat visits can contribute multiple times and the columns need not sum to 100. Keep omitted edges outside the calculation and compare only observed snapshots. Neighboring reported snapshots can be more than a month apart.

| month | distance from January | distance from previous supplied snapshot |
|---|---:|---:|
| January | 0 | — |
| March | 3 | 3 |
| May | 40 | 37 |
| July | 59 | 19 |
| September | 28 | 31 |
| October | 64 | 36 |
| December | 36 | 28 |

In May the two rework edges contribute 24 of the 40 distance units from January. Both edges can describe the same loop, so that total measures graph change and does not count affected cases. The immediate assessment-to-decision rate falls from 83 in January to 72 in July. That is consistent with more intervening work and does not give the eventual decision or rejection rate. September moves toward January. In October the senior edge alone contributes 15 of the 36 distance units from September. Under a two-group mix-only model with fixed nonnegative senior-edge rates within high and standard complexity, the rise from 26% to 41% high complexity could increase September’s rate of 7 to at most (7(41/26)approx 11) per 100, even if all senior transitions were in the high group. The observed rate of 22 calls for a within-band change in routing, recording, or detailed composition, assuming comparable cohorts and measurement.

For a case-level rate, quantify the composition term with \(\sum_g (w_{t,g}-w_{0,g})r_{0,g}\) and the within-group term with \(\sum_g w_{t,g}(r_{t,g}-r_{0,g})\), where \(w\) is each intake stratum’s share and \(r\) is its rate. As a sensitivity calculation, supplier mix alone could explain the April–May rework rise of 11 percentage points only if Z and non-Z rework rates were fixed and Z’s rate were about 44 points higher, given Z’s 25-point share increase. The April aggregate permits that difference but does not measure it. Joint supplier, region, and intake complexity strata would make this test more informative.

def read_month_table(csv_text):
    table = pd.read_csv(StringIO(csv_text), index_col="month")
    table.index = pd.PeriodIndex(table.index, freq="M", name="month")
    if table.empty or table.index.hasnans or not table.index.is_unique:
        raise ValueError("Require nonempty, uniquely dated monthly data.")
    if not table.index.is_monotonic_increasing:
        raise ValueError("Months must be sorted.")
    if not np.isfinite(table.to_numpy(dtype=float)).all():
        raise ValueError("Every supplied value must be finite.")
    return table


def validate_aggregates(monthly, rates):
    expected = pd.period_range("2026-01", "2026-12", freq="M")
    if not monthly.index.equals(expected):
        raise ValueError("Require every month of 2026 in the summary.")
    if not rates.index.isin(monthly.index).all() or len(rates.columns) != 7:
        raise ValueError("Require the seven reported DFG columns on summary months.")

    counts = monthly[["cases", "distinct_activity_labels"]]
    if ((counts <= 0) | (counts % 1 != 0)).any().any():
        raise ValueError("Case and label counts must be positive integers.")
    percentages = monthly.filter(regex=r"_pct$")
    if ((percentages < 0) | (percentages > 100)).any().any():
        raise ValueError("Percentages must lie in [0, 100].")
    fitness = monthly[["raw_model_fitness", "mapped_model_fitness"]]
    if ((fitness < 0) | (fitness > 1)).any().any():
        raise ValueError("Fitness must lie in [0, 1].")
    if ((monthly["median_cycle_h"] < 0) |
            (monthly["p90_cycle_h"] < monthly["median_cycle_h"])).any():
        raise ValueError("Cycle times must be nonnegative and p90 >= median.")
    if (rates < 0).any().any():
        raise ValueError("DFG rates must be nonnegative.")


def print_candidate_breaks(monthly, rates, fitness_gap, dfg_step):
    # Exploratory effect-size screens, in each statistic's native units.
    rules = {
        "logging": {
            "fitness_gap": 0.05,
            "distinct_activity_labels": 2,
            "duplicate_open_case_pct": 2,
            "missing_resource_pct": 0.7,
        },
        "behavior or mix": {"rework_variant_pct": 5},
        "performance": {"median_cycle_h": 4, "p90_cycle_h": 10},
    }
    steps = monthly.assign(fitness_gap=fitness_gap).diff().round(8)
    for dimension, thresholds in rules.items():
        for month, row in steps.iloc[1:].iterrows():
            hits = [
                f"{metric} {row[metric]:+g}"
                for metric, threshold in thresholds.items()
                if abs(row[metric]) >= threshold
            ]
            if hits:
                print(f"{dimension}, {month}: {', '.join(hits)}")

    senior_step = rates["Assess->SeniorAssessment"].diff()
    for previous, current in zip(rates.index[:-1], rates.index[1:]):
        distance = dfg_step.loc[current]
        senior_delta = senior_step.loc[current]
        if distance >= 18 or abs(senior_delta) >= 10:
            print(
                f"DFG candidate interval {previous} to {current}: "
                f"L1={distance:g}, senior-edge change={senior_delta:+g}"
            )


def run_aggregates():
    monthly = read_month_table(MONTHLY_CSV)
    rates = read_month_table(DFG_CSV)
    validate_aggregates(monthly, rates)

    baseline = monthly.loc["2026-01":"2026-02"].mean()
    changes = monthly.subtract(baseline, axis="columns")
    fitness_gap = monthly["mapped_model_fitness"] - monthly["raw_model_fitness"]
    from_january = rates.subtract(rates.loc["2026-01"], axis="columns").abs().sum(axis=1)
    dfg_step = rates.diff().abs().sum(axis=1, min_count=1)

    print("January–February reference, equal month weights")
    print(baseline.round(3).to_string())
    print("\nChanges from reference (percentage columns are in percentage points)")
    print(changes.round(3).to_string())
    print("\nFitness recovery and DFG fragment distances")
    print(pd.concat(
        [
            fitness_gap.rename("mapped_minus_raw"),
            from_january.rename("L1_from_Jan"),
            dfg_step.rename("L1_from_previous_snapshot"),
        ],
        axis=1,
    ).round(3).to_string(na_rep="—"))
    print("\nCandidate breaks from adjacent months or supplied snapshots")
    print_candidate_breaks(monthly, rates, fitness_gap, dfg_step)
    print("\nDFG distances use the seven supplied rates only. Omitted edges are unknown.")
    print("Rates count occurrences per 100 cases, including repeated edges.")
    print("DFG snapshots are irregular. Candidate dates are screening flags.")
    print("Monthly aggregates do not identify within-stratum effects, pooled "
          "quantiles, or a causal split of cycle time.")

TIME = "time:timestamp"


def format_event_log(events):
    """Expect case_id, activity, and timestamp. event_order is optional."""
    import pm4py

    required = ["case_id", "activity", "timestamp"]
    missing = set(required).difference(events.columns)
    if missing:
        raise ValueError(f"Missing required columns: {sorted(missing)}")

    source = events.copy(deep=True)
    # Supply UTC or explicitly offset source timestamps. Localize other inputs
    # to their true source timezone before calling this function.
    source["timestamp"] = pd.to_datetime(source["timestamp"], utc=True, errors="raise")
    if source[required].isna().any().any():
        raise ValueError("Null case, activity, or timestamp. Audit upstream.")

    order_columns = ["timestamp"]
    if "event_order" in source:
        tie_keys = ["case_id", "timestamp", "event_order"]
        if source["event_order"].isna().any() or source.duplicated(tie_keys).any():
            raise ValueError("event_order must uniquely resolve ties within a case.")
        order_columns.append("event_order")
    # Without an event sequence, preserve input order for equal timestamps
    # and audit tie-sensitive edges before interpreting them.
    source = source.sort_values(order_columns, kind="stable").reset_index(drop=True)
    return pm4py.format_dataframe(
        source, case_id="case_id", activity_key="activity", timestamp_key="timestamp"
    )


def normalize_event_log(formatted):
    """Map the alias and drop Open Case rows flagged as verified duplicates."""
    normalized = formatted.copy(deep=True)
    if "is_duplicate_open_case" in normalized:
        verified = normalized["is_duplicate_open_case"].astype("boolean").fillna(False)
        drop = normalized[ACTIVITY].eq("Open Case") & verified
        normalized = normalized.loc[~drop].copy()
    normalized[ACTIVITY] = normalized[ACTIVITY].replace(
        {"Eligibility Screen": "Validate Eligibility"}
    )
    return normalized


def register_month_case_ids(formatted, month):
    """Select first-Register month in UTC, keeping trace slicing separate."""
    import pm4py

    period = pd.Period(month, freq="M")
    start = period.start_time.tz_localize("UTC")
    stop = (period + 1).start_time.tz_localize("UTC")
    anchors = (
        formatted.loc[formatted[ACTIVITY].eq("Register")]
        .sort_values(TIME, kind="stable")
        .drop_duplicates(subset=CASE, keep="first")
    )
    if anchors.empty:
        return pd.Index([], dtype="string")
    # Pad the filter bounds, then enforce an exact half-open calendar month.
    candidates = pm4py.filter_time_range(
        anchors,
        (start - pd.Timedelta(days=1)).to_pydatetime(),
        (stop + pd.Timedelta(days=1)).to_pydatetime(),
        mode="events",
    )
    in_month = candidates[TIME].ge(start) & candidates[TIME].lt(stop)
    return pd.Index(candidates.loc[in_month, CASE], dtype="string")


def cohort_artifacts(cohort, include_skeleton=False):
    import pm4py

    case_count = cohort[CASE].nunique()
    if not case_count:
        return {
            "cases": 0,
            "dfg": {},
            "dfg_per_100_cases": {},
            "starts": {},
            "ends": {},
            "variants": {},
            "temporal_profile": {},
            "log_skeleton": None,
        }

    dfg, starts, ends = pm4py.discover_dfg(cohort)
    variants = pm4py.get_variants(cohort)
    variant_counts = {
        variant: int(value) if isinstance(value, Integral) else len(value)
        for variant, value in variants.items()
    }
    return {
        "cases": case_count,
        "dfg": dfg,
        "dfg_per_100_cases": {
            edge: 100 * count / case_count for edge, count in dfg.items()
        },
        "starts": starts,
        "ends": ends,
        "variants": variant_counts,
        "temporal_profile": pm4py.discover_temporal_profile(cohort),
        "log_skeleton": pm4py.discover_log_skeleton(cohort) if include_skeleton else None,
    }


def compare_monthly_views(events, months, *, eligible_case_ids=None, include_skeleton=False):
    """Return paired artifacts. Select IDs by first Register and retain follow-up."""
    raw = format_event_log(events)
    mapped = normalize_event_log(raw)
    eligible_ids = None
    if eligible_case_ids is not None:
        eligible_ids = pd.Index(list(eligible_case_ids), dtype="string")

    comparisons = {}
    for month in months:
        ids = register_month_case_ids(raw, month)
        if eligible_ids is not None:
            ids = ids.intersection(eligible_ids)
        raw_cohort = raw.loc[raw[CASE].isin(ids)].copy()
        mapped_cohort = mapped.loc[mapped[CASE].isin(ids)].copy()
        comparisons[str(month)] = {
            "raw": cohort_artifacts(raw_cohort, include_skeleton),
            "mapped": cohort_artifacts(mapped_cohort, include_skeleton),
        }
    return comparisons


if __name__ == "__main__":
    run_aggregates()
