# 1. Source-Semantics Baseline

The Python POWL object is the authoritative source. Its semantics are the visible-trace language (with the silent XOR branch hidden), read together with the partial-order reading of concurrency that the intended semantics state explicitly. Two preliminary observations shape the whole audit:

- **The source order is a covering relation, not a transitively closed one.** For example, `Register → Legal` and `Assess → Release` are implied but not stated, so `source_powl.validate_partial_orders()` raises "transitivity of the partial order is violated". POWL defines precedence by the transitive closure, so closing the relation on a *copy* preserves semantics. The code below does exactly that and records it. The source object is never mutated.
- **The order is N-shaped.** It has `Assess → Legal`, `Assess → Verification` and `Prepare → Verification`, but no edge `Prepare → Legal`. This pattern is not series-parallel, so no process tree with unique labels can express it exactly. Every block-structured intermediate therefore has to approximate.

Abbreviations used in the witnesses: R = Register Change, A = Assess Risk, P = Prepare Evidence, L = Legal Review, C = Configure Trial, I = Inspect Trial, D = Correct Defect, Rel = Release Change, Arc = Archive Change.

| Invariant ID | Invariant | Positive witness | Negative witness | Observable after hiding tau? |
|---|---|---|---|---|
| INV-01 Initiality | R occurs exactly once and before every other activity. | `R A P C I Rel Arc` | `A R P C I Rel Arc` | Yes |
| INV-02 Unordered A/P | A and P each occur exactly once after R, and both orders are allowed. | `R A P C I Rel Arc` and `R P A C I Rel Arc` | A model that admits only `R A P …`. The negative evidence is the *absence* of `R P A C I Rel Arc`. | Yes, but only by checking that both interleavings exist in the language, not from a single trace. |
| INV-03 True concurrency | At model level, A∥P, L∥P and L∥(verification loop) are genuine concurrency (they may overlap in time), not a choice between orders. | After R fires, A and P are enabled simultaneously with disjoint presets, so the step {A, P} is possible. | A net that serializes A and P through a mutex place but still allows both orders. It is trace-equivalent but has no true concurrency. | **No.** Hidden-tau trace semantics only show interleavings. Step or partial-order semantics are needed. |
| INV-04 Optional Legal | L occurs zero times or once. The zero case is the silent XOR branch. | `R A P C I Rel Arc` (skipped) and `R A P C I L Rel Arc` (taken) | `R A L P C I L Rel Arc` (twice). A model where every completed trace contains L (skip collapsed). | Partly. The skip is observable only as the *absence* of L, and the silent step itself is invisible. |
| INV-05 Legal after Assess | If L occurs, it occurs after A. | `R A L P C I Rel Arc` | `R L A P C I Rel Arc` | Yes |
| INV-06 No Legal/Prepare order (N-shape) | L and P are unordered: L may occur before or after P. | `R A L P C I Rel Arc` and `R A P L C I Rel Arc` | A model forcing P before L, so that `R A L P C I Rel Arc` is missing. | Yes, as the existence of both interleavings. |
| INV-07 No Legal/verification order | L may occur before C, between C and I, between iterations, or after the last I (always before Rel). | `R A P C L I Rel Arc` and `R A P C I D L C I Rel Arc` | A model that forces L before verification, so `R A P C L I Rel Arc` is missing. | Yes, as interleavings. The overlap in time itself is not observable (see INV-03). |
| INV-08 Verification guard | The first C occurs only after both A and P. | `R P A C I Rel Arc` | `R A C I P Rel Arc` | Yes |
| INV-09 Iteration body | Every iteration executes C and then I, exactly once each. L may interleave between them, so this is precedence, not directly-follows. | `R A P C I D C I Rel Arc` | `R A P I C Rel Arc`, `R A P C C I Rel Arc` | Yes |
| INV-10 Binary loop / redo scope | Iterations are separated by exactly one D. D occurs only after I and is always followed by another C. The loop exits only after I, never after D. | `R A P C I D C I Rel Arc` | `R A P C I D Rel Arc` (exit after redo), `R A P C D I Rel Arc`, `R A P C I D D C I Rel Arc` | Yes |
| INV-11 Minimum iterations | At least one iteration, with no upper bound. | One, two and three iterations, e.g. `R P A C I D C I D C I L Rel Arc` | `R A P Rel Arc` (zero iterations) | The lower bound is observable. Unboundedness is only observable for finitely many witnesses. |
| INV-12 Synchronization before release | Rel waits for (a) the optional-legal branch, whether L or the silent skip completed, and (b) exit of the verification loop after its last I. | `R A P C I L Rel Arc` | `R A P C I Rel L Arc`, `R A P Rel C I Arc`, `R A P C Rel I Arc` | Partly. The join on the *skip* branch is invisible. Its only visible effect is that no L appears after Rel. |
| INV-13 Finality | Arc occurs exactly once, immediately after Rel, and nothing follows it. | `… Rel Arc` | `… Arc Rel`, `… Rel Arc L`, `… Rel` (Arc missing) | Yes |
| INV-14 Proper completion | A trace counts as completed only if the reached marking *equals* the final marking (one token in the sink), with no residual tokens. The model is sound: option to complete, proper completion, no dead transitions. | Marking after Arc is exactly `[sink:1]`. | After `R A P C I Rel Arc`, a token is left in the legal branch, or Arc can fire while a loop token remains. | Only indirectly, through exact-final-marking acceptance. Trace strings alone cannot show this. |
| INV-15 Label identity | There are nine visible labels, each bound to exactly one activity. The only silent step has label `None`, and there are no blank or duplicated labels. | The visible label set equals the nine names, with no duplicates. | Two transitions labelled `Legal Review`, a silent step turned into label `""`, or a renamed label. | Partly. Duplicated labels can be trace-invisible, so a structural check is required. |

# 2. Candidate Conversion Pipelines

| Pipeline | PM4Py calls | Expected benefit | Expected risk | Failure condition |
|---|---|---|---|---|
| **P1 (primary): POWL → accepting Petri net → BPMN**, plus a round trip BPMN → Petri net | `pm4py.convert_to_petri_net(powl)`; `pm4py.convert_to_bpmn(net, im, fm)`; `pm4py.convert_to_petri_net(bpmn)` | POWL-to-net conversion is compositional for partial orders, XOR and binary loops. In PM4Py 2.7.x, direct net-to-BPMN conversion maps places to exclusive gateways, silent multi-input/output transitions to parallel gateways and visible transitions to tasks, then reduces pass-through gateways. It needs **no block structure**, so the N-shape can survive. | The resulting gateways are unbalanced and have *unspecified* direction. The drawing may be misread. `convert_to_bpmn` catches `BaseException` internally and re-raises a generic "Unsupported conversion", which hides the root cause. BPMN exclusive-gateway semantics (an immediate decision) differ from a Petri-net place (a deferred choice). | An exception, `None` or empty markings, a result that is not a WF-net, an unsound net, a round-trip net that is not visible-trace equivalent to the source, or changed labels. |
| **P1b (drift check): P1 round-trip net → BPMN → Petri net** (second generation) | `pm4py.convert_to_bpmn(net_rt, im_rt, fm_rt)`; `pm4py.convert_to_petri_net(bpmn_gen2)` | Detects non-idempotence: a stable converter pair should reach a fixpoint after one round. | Its own artifacts can trigger tool noise. In the reference run, Woflan misjudged this net (see §5). | The generation-2 language differs from generation 1 or from the source, or the checks disagree with each other. |
| **P2: POWL → accepting Petri net → process tree → BPMN** | `pm4py.convert_to_process_tree(net, im, fm)` (inside `try/except`); `pm4py.convert_to_bpmn(tree)`; `pm4py.convert_to_petri_net(bpmn)` | If it succeeded, BPMN built from a tree is block-structured, has balanced gateways and is sound by construction, which gives the most readable diagram. | The N-shaped order is not series-parallel, so any tree with unique labels must lose L∥P or add behaviour. A "successful" tree would be suspicious, not reassuring. | An exception, which is **expected and was observed**: `ValueError: Parsing of WF-net Failed`. A success that fails the equivalence checks must also be rejected. |

That tree forces P before L. | Any precision warning, or any difference in language. In the reference run it lost `R A L P C I Rel Arc` and its extensions. |

**Primary pipeline: P1.** P1b is mandatory evidence alongside it. P2 is attempted and its failure is recorded as a *correct* outcome. P3 is kept only as a negative control that shows why block-structured shortcuts are rejected.

# 3. Conversion Code

The code starts from the authoritative definition, which is reproduced verbatim so the script is self-contained. It was executed with PM4Py 2.7.23.4, Python 3.12 and Graphviz. `save_vis_powl` writes SVG because PNG output needs the optional `cairosvg` package.

```python
import os
import warnings

import pm4py
from pm4py.objects.powl.obj import (
    StrictPartialOrder,
    OperatorPOWL,
    Transition,
    SilentTransition,
)
from pm4py.objects.process_tree.obj import Operator

# ---------------------------------------------------------------------------
# Source model (verbatim from the specification; authoritative)
# ---------------------------------------------------------------------------
register = Transition(label="Register Change")
assess_risk = Transition(label="Assess Risk")
prepare_evidence = Transition(label="Prepare Evidence")

legal_review = Transition(label="Legal Review")
skip_legal = SilentTransition()
optional_legal = OperatorPOWL(operator=Operator.XOR, children=[legal_review, skip_legal])

configure_trial = Transition(label="Configure Trial")
inspect_trial = Transition(label="Inspect Trial")
trial_body = StrictPartialOrder(nodes=[configure_trial, inspect_trial])
trial_body.order.add_edge(configure_trial, inspect_trial)

correct_defect = Transition(label="Correct Defect")
verification_loop = OperatorPOWL(operator=Operator.LOOP, children=[trial_body, correct_defect])

release_change = Transition(label="Release Change")
archive_change = Transition(label="Archive Change")

source_powl = StrictPartialOrder(
    nodes=[register, assess_risk, prepare_evidence, optional_legal,
           verification_loop, release_change, archive_change]
)
source_powl.order.add_edge(register, assess_risk)
source_powl.order.add_edge(register, prepare_evidence)
source_powl.order.add_edge(assess_risk, optional_legal)
source_powl.order.add_edge(assess_risk, verification_loop)
source_powl.order.add_edge(prepare_evidence, verification_loop)
source_powl.order.add_edge(optional_legal, release_change)
source_powl.order.add_edge(verification_loop, release_change)
source_powl.order.add_edge(release_change, archive_change)

# ---------------------------------------------------------------------------
# Configuration and bookkeeping
# ---------------------------------------------------------------------------
OUT_DIR = "powl_conversion_audit"
os.makedirs(OUT_DIR, exist_ok=True)


def out(name):
    return os.path.join(OUT_DIR, name)


EXPECTED_LABELS = {
    "Register Change", "Assess Risk", "Prepare Evidence", "Legal Review",
    "Configure Trial", "Inspect Trial", "Correct Defect",
    "Release Change", "Archive Change",
}

conversion_log = []          # (step, status, detail)
accepting_nets = {}          # name -> (net, im, fm)
bpmn_models = {}             # name -> BPMN
trees = {}                   # name -> ProcessTree


def record(step, status, detail=""):
    conversion_log.append((step, status, detail))
    print(f"[{status:>10}] {step}: {detail}")


def exc_text(exc):
    return f"{type(exc).__name__}: {exc}"


# ---------------------------------------------------------------------------
# Step 0: normalise the partial order on a copy.
# POWL defines ordering by the transitive closure; the source lists only a
# covering relation (e.g. Register -> Legal is implied, not stated).
# ---------------------------------------------------------------------------
def all_partial_orders(powl):
    if isinstance(powl, StrictPartialOrder):
        yield powl
    for child in getattr(powl, "children", []) or []:
        yield from all_partial_orders(child)


powl_for_conversion = source_powl.copy()
for po in all_partial_orders(powl_for_conversion):
    if not po.order.is_transitive():
        po.order.add_transitive_edges()
try:
    powl_for_conversion.validate_partial_orders()
    record("normalise POWL", "ok", "irreflexive and transitive after closure")
except Exception as exc:
    record("normalise POWL", "REJECT", exc_text(exc))
    raise


# ---------------------------------------------------------------------------
# Marking / structure checks (never assume markings are usable)
# ---------------------------------------------------------------------------
def marking_problems(net, im, fm):
    problems = []
    if net is None:
        return ["net is None"]
    if im is None or len(im) == 0:
        problems.append("initial marking missing or empty")
    if fm is None or len(fm) == 0:
        problems.append("final marking missing or empty")
    for name, m in (("im", im), ("fm", fm)):
        if m:
            foreign = [p for p in m if p not in net.places]
            if foreign:
                problems.append(f"{name} refers to places outside the net")
            if sum(m.values()) != 1:
                problems.append(f"{name} does not hold exactly one token")
    sources = [p for p in net.places if len(p.in_arcs) == 0]
    sinks = [p for p in net.places if len(p.out_arcs) == 0]
    if im and (len(sources) != 1 or set(im) != set(sources)):
        problems.append(f"im is not the unique source place (sources={len(sources)})")
    if fm and (len(sinks) != 1 or set(fm) != set(sinks)):
        problems.append(f"fm is not the unique sink place (sinks={len(sinks)})")
    return problems


def label_problems(net):
    visible = [t.label for t in net.transitions if t.label is not None]
    problems = []
    dup = sorted({l for l in visible if visible.count(l) > 1})
    if dup:
        problems.append(f"duplicate visible labels: {dup}")
    blank = [l for l in visible if not str(l).strip()]
    if blank:
        problems.append(f"{len(blank)} transition(s) with blank but non-None label (would be visible)")
    missing = EXPECTED_LABELS - set(visible)
    extra = set(visible) - EXPECTED_LABELS
    if missing:
        problems.append(f"missing labels: {sorted(missing)}")
    if extra:
        problems.append(f"unexpected labels: {sorted(extra)}")
    return problems


def register_net(name, result):
    """Accept a (net, im, fm) triple only after explicit null checks."""
    if result is None or len(result) != 3:
        record(name, "REJECT", "converter did not return (net, im, fm)")
        return False
    net, im, fm = result
    problems = marking_problems(net, im, fm)
    if problems:
        record(name, "QUARANTINE", "; ".join(problems))
    accepting_nets[name] = (net, im, fm)
    return True


# ---------------------------------------------------------------------------
# Pipeline 1 (primary): POWL -> accepting Petri net -> BPMN -> Petri net
# ---------------------------------------------------------------------------
try:
    net_from_powl, im_from_powl, fm_from_powl = pm4py.convert_to_petri_net(powl_for_conversion)
    record("P1 POWL->Petri", "ok",
           f"{len(net_from_powl.places)} places, {len(net_from_powl.transitions)} transitions")
except Exception as exc:
    record("P1 POWL->Petri", "REJECT", exc_text(exc))
    raise  # without the reference net nothing downstream is meaningful

register_net("net_from_powl", (net_from_powl, im_from_powl, fm_from_powl))

bpmn_from_net = None
try:
    bpmn_from_net = pm4py.convert_to_bpmn(net_from_powl, im_from_powl, fm_from_powl)
    bpmn_models["bpmn_from_net"] = bpmn_from_net
    record("P1 Petri->BPMN", "ok", f"{len(bpmn_from_net.get_nodes())} BPMN nodes")
except Exception as exc:
    record("P1 Petri->BPMN", "FAILED", exc_text(exc))

if bpmn_from_net is not None:
    try:
        register_net("net_rt_p1", pm4py.convert_to_petri_net(bpmn_from_net))
        record("P1 BPMN->Petri", "ok", "round-trip net created")
    except Exception as exc:
        record("P1 BPMN->Petri", "FAILED", exc_text(exc))

# P1b: second generation (drift check): round-trip net -> BPMN -> Petri net
if "net_rt_p1" in accepting_nets and not marking_problems(*accepting_nets["net_rt_p1"]):
    try:
        bpmn_gen2 = pm4py.convert_to_bpmn(*accepting_nets["net_rt_p1"])
        bpmn_models["bpmn_gen2"] = bpmn_gen2
        register_net("net_rt_gen2", pm4py.convert_to_petri_net(bpmn_gen2))
        record("P1b gen-2 round trip", "ok", "")
    except Exception as exc:
        record("P1b gen-2 round trip", "FAILED", exc_text(exc))

# ---------------------------------------------------------------------------
# Pipeline 2: POWL -> Petri net -> process tree -> BPMN -> Petri net
# Failure is an acceptable (and here expected) outcome: the order
# Assess->Legal, Assess->Verify, Prepare->Verify without Prepare->Legal is an
# "N"-shaped partial order, which is not series-parallel.
# ---------------------------------------------------------------------------
tree_from_net = None
try:
    tree_from_net = pm4py.convert_to_process_tree(net_from_powl, im_from_powl, fm_from_powl)
    trees["tree_from_net"] = tree_from_net
    record("P2 Petri->Tree", "SUSPICIOUS",
           f"succeeded: {tree_from_net} -- must be proven equivalent before use")
except Exception as exc:
    record("P2 Petri->Tree", "FAILED",
           f"{exc_text(exc)} -- interpreted as: net is not block-structured "
           "(N-shaped order), so no label-unique tree is exact")

if tree_from_net is not None:
    try:
        bpmn_from_tree = pm4py.convert_to_bpmn(tree_from_net)
        bpmn_models["bpmn_from_tree"] = bpmn_from_tree
        register_net("net_rt_p2", pm4py.convert_to_petri_net(bpmn_from_tree))
    except Exception as exc:
        record("P2 Tree->BPMN->Petri", "FAILED", exc_text(exc))

# ---------------------------------------------------------------------------
# Pipeline 3 (control, not for production): POWL -> process tree directly.
# PM4Py only *warns* when the partial order is not exactly representable, so
# warnings are captured and turned into a quarantine decision.
# ---------------------------------------------------------------------------
with warnings.catch_warnings(record=True) as caught:
    warnings.simplefilter("always")
    try:
        tree_direct = pm4py.convert_to_process_tree(powl_for_conversion)
        trees["tree_direct"] = tree_direct
        precision_warnings = [str(w.message) for w in caught if "precise" in str(w.message).lower()]
        status = "QUARANTINE" if precision_warnings else "ok"
        record("P3 POWL->Tree (direct)", status, f"{tree_direct}; warnings={precision_warnings}")
    except Exception as exc:
        tree_direct = None
        record("P3 POWL->Tree (direct)", "FAILED", exc_text(exc))

if tree_direct is not None:
    try:
        bpmn_from_tree_direct = pm4py.convert_to_bpmn(tree_direct)
        bpmn_models["bpmn_from_tree_direct"] = bpmn_from_tree_direct
        register_net("net_rt_p3", pm4py.convert_to_petri_net(bpmn_from_tree_direct))
    except Exception as exc:
        record("P3 Tree->BPMN->Petri", "FAILED", exc_text(exc))


# ---------------------------------------------------------------------------
# Workflow-net and soundness diagnostics on every accepting net
# ---------------------------------------------------------------------------
def diagnose(name, net, im, fm):
    report = {"net": name,
              "places": len(net.places),
              "transitions": len(net.transitions),
              "silent": sum(1 for t in net.transitions if t.label is None),
              "marking_problems": marking_problems(net, im, fm),
              "label_problems": label_problems(net)}
    try:
        report["is_workflow_net"] = bool(pm4py.check_is_workflow_net(net))
    except Exception as exc:
        report["is_workflow_net"] = f"error: {exc_text(exc)}"
    if report["marking_problems"] or report["is_workflow_net"] is not True:
        report["sound"] = "not evaluated (not a WF-net with usable markings)"
        return report
    try:
        result = pm4py.check_soundness(net, im, fm, print_diagnostics=False)
        report["sound"] = bool(result[0]) if isinstance(result, tuple) else bool(result)
    except Exception as exc:
        report["sound"] = f"error: {exc_text(exc)}"
    return report


diagnostics = {name: diagnose(name, *triple) for name, triple in accepting_nets.items()}
for rep in diagnostics.values():
    print(rep)


# ---------------------------------------------------------------------------
# Visualisations (rendering failure is logged, never treated as validation)
# ---------------------------------------------------------------------------
def save(step, fn, *args):
    try:
        fn(*args)
        record(f"save {step}", "ok", args[-1])
    except Exception as exc:
        record(f"save {step}", "FAILED", exc_text(exc))


save("source POWL", pm4py.save_vis_powl, source_powl, out("00_source_powl.svg"))  # PNG needs cairosvg
vis_names = {
    "net_from_powl": "01_P1_petri_from_powl.png",
    "net_rt_p1": "03_P1_petri_roundtrip_from_bpmn.png",
    "net_rt_gen2": "05_P1b_petri_roundtrip_generation2.png",
    "net_rt_p2": "08_P2_petri_roundtrip_from_tree_bpmn.png",
    "net_rt_p3": "12_P3_petri_from_direct_tree_QUARANTINED.png",
}
for name, (net, im, fm) in accepting_nets.items():
    save(name, pm4py.save_vis_petri_net, net, im, fm, out(vis_names.get(name, f"99_{name}.png")))
bpmn_vis = {
    "bpmn_from_net": "02_P1_bpmn_from_petri.png",
    "bpmn_gen2": "04_P1b_bpmn_generation2.png",
    "bpmn_from_tree": "07_P2_bpmn_from_tree.png",
    "bpmn_from_tree_direct": "11_P3_bpmn_from_direct_tree_QUARANTINED.png",
}
for name, bpmn in bpmn_models.items():
    save(name, pm4py.save_vis_bpmn, bpmn, out(bpmn_vis.get(name, f"99_{name}.png")))
tree_vis = {"tree_from_net": "06_P2_tree_from_petri.png",
            "tree_direct": "10_P3_tree_direct_QUARANTINED.png"}
for name, tree in trees.items():
    save(name, pm4py.save_vis_process_tree, tree, out(tree_vis[name]))

# Serialised derivatives for the evidence bundle
save("PNML reference", pm4py.write_pnml, net_from_powl, im_from_powl, fm_from_powl,
     out("01_P1_petri_from_powl.pnml"))
if bpmn_from_net is not None:
    save("BPMN XML", pm4py.write_bpmn, bpmn_from_net, out("02_P1_bpmn_from_petri.bpmn"))
```

**Observed outcome of the reference run (PM4Py 2.7.23.4):**

- **P1 POWL→Petri** succeeded: a WF-net with 12 places and 11 transitions. Two transitions are silent: the XOR skip, and one AND-join `init_par` that synchronizes A and P before C. The initial marking is `[source:1]` and the final marking is `[sink:1]`.
  - The loop has **no explicit silent exit**. `Release Change` consumes the post-Inspect place directly, and `Correct Defect` competes for the same token, so the net is *not free-choice*.
- **P1 Petri→BPMN** succeeded with 19 BPMN nodes. **BPMN→Petri** gave a net with the same structure: 12 places, 11 transitions, 2 silent.
- **P2 Petri→Tree** raised `ValueError: Parsing of WF-net Failed`. I interpret this as the correct refusal: the net is not block-structured.
- **P3 direct POWL→Tree** returned an approximating tree together with a precision warning, so it was quarantined.
- Every net is a WF-net with usable markings.

# 4. Preservation and Loss Audit

"Validated" means validated in the reference run by the §5 code. Two checks were used: exact visible-trace equivalence against an independent oracle (unbounded, by subset construction) and exhaustive bounded enumeration (up to 3 iterations). These verdicts must be re-established whenever the PM4Py version or the source changes. The Petri→BPMN column rates the BPMN object itself. It was never executed directly, so control-flow rows are only `expected preserved` there, and the evidence comes from the round trip.

| Source invariant | POWL→Petri | Petri→BPMN | Petri→Tree | BPMN round trip | Evidence or uncertainty |
|---|---|---|---|---|---|
| INV-01 Initiality | validated preserved | expected preserved | conversion failed | validated preserved | Exact equivalence with the oracle. The negative witness `register_not_first` was rejected by replay and by alignment. |
| INV-02 Unordered A/P (interleavings) | validated preserved | expected preserved | conversion failed | validated preserved | Both `R A P …` and `R P A …` are in all P1 languages. The BPMN has a parallel split after R. |
| INV-03 True concurrency (step semantics) | expected preserved | expected preserved | conversion failed | expected preserved | The nets have concurrently enabled transitions with disjoint presets, and the BPMN has parallel gateways. All validation is interleaving-based, so step or partial-order equivalence is **not tested** (see §9). |
| INV-04 Optional Legal / silent skip | validated preserved | expected preserved | conversion failed | validated preserved | In the BPMN, the silent skip becomes a bare XOR→XOR sequence flow (the gateway reduction removed the silent node). The round trip reintroduces a silent transition (`sfl_*`), and the language is unchanged. `legal_twice` was rejected. The blank-label mutation test shows that the checker would catch a skip turned visible. |
| INV-05 Legal after Assess | validated preserved | expected preserved | conversion failed | validated preserved | `legal_before_assess` was rejected everywhere. |

P3 (direct tree) **lost** it: 3 of the 45 bounded traces were missing, the shortest counterexample is `R A L P C I Rel Arc`, and the footprint changed from L∥P to P→L. **Discussion of the required topics**

- **True concurrency versus arbitrary interleaving.** The source states that the optional legal branch and verification "may overlap". A Petri net expresses this through concurrently enabled transitions, and BPMN through parallel gateways. Every check in §5, however, works in interleaving semantics. A converter that replaced concurrency with a mutex place that still allowed both orders would pass every trace test. The claim of true concurrency therefore stays at `expected preserved`, based on inspecting the structure (parallel gateways, disjoint presets), not on validation.
- **No edge between Optional Legal Review and verification.** This is two invariants: L unordered with the loop (INV-07) and L unordered with P (INV-06, the N-shape). The N-shape is what makes the model non-block-structured, and it is exactly what P3 silently discarded and P2 refused to encode. A BPMN drawn left-to-right can still *suggest* an order that the model does not contain (§6).
- **Silent optional behaviour.** The silent transition has no BPMN counterpart after reduction. Optionality survives as an unlabeled XOR→XOR flow, and in the round trip it becomes a new silent transition with a different identity. The only thing to preserve is the language effect "L zero or one times". The checker hides only label `None`. A silent step that came back as label `""` would count as a visible event and be rejected, which the mutation test confirms. A permissive check that hid empty strings would mask exactly that defect.
- **Binary-loop semantics.** POWL `*(body, redo)` means body (redo body)*. The net has no explicit exit transition: exit happens when Release consumes the post-Inspect token. The trace semantics are preserved and validated. The *point at which the exit is decided* differs from a naive block reading, and in BPMN the exclusive split after Inspect looks like an immediate decision. Loop scope is validated: C and I are inside the loop and D is the redo step. Exit after D is rejected, and so is D inside an iteration.
- **The join before Release Change.** In the net, Release has two input places: one from the legal branch, where L and the skip converge, and the post-Inspect place of the loop. In the BPMN this becomes a parallel join fed by an exclusive join and by one outgoing flow of the loop's exclusive split. This pattern is valid but easy to misread (§6). Negative witnesses that release before L or before verification were rejected by every accepted net.
- **Activity-label uniqueness.** All the language checks compare *labels*. If a converter duplicated `Legal Review`, for example one copy per branch in a tree-based repair, traces could remain identical while task identity was lost. So label uniqueness and the label set are checked structurally on every net, independent of the language.
- **Initial and final markings.** Markings are never assumed. The code checks that each is non-`None` and non-empty, holds one token, and corresponds to the unique source or sink place. BPMN cannot carry markings, so the round-trip markings are *re-derived* from the start and end events. That is why the table rates Petri→BPMN as `approximated` for INV-14, while the round trip is `validated preserved`.
- **Gateway and routing-node ambiguity in BPMN.** Every place becomes an exclusive gateway before reduction, and every silent AND-split or AND-join becomes a parallel gateway. Directions are `UNSPECIFIED`, and no exclusive gateway has conditions. The same diamond symbol is used for the loop merge, the Legal decision, the Legal join and the loop exit decision. Section 6 treats this in detail.

# 5. Round-Trip Validation Code

This code continues from §3 and uses `accepting_nets`, `marking_problems`, `label_problems` and `exc_text`. It compares every accepting net with `net_from_powl` and also with an **independent oracle**: a hand-written deterministic automaton of the intended semantics from §1. Using the oracle as well means that a converter bug shared by both the forward and the backward direction cannot certify itself.

```python
# Continues from the Section 3 script (uses accepting_nets, net_from_powl, ...).
from collections import deque

import pandas as pd
import pm4py
from pm4py.objects.petri_net.obj import Marking

R, A, P, L = "Register Change", "Assess Risk", "Prepare Evidence", "Legal Review"
C, I, D = "Configure Trial", "Inspect Trial", "Correct Defect"
REL, ARC = "Release Change", "Archive Change"

MAX_ITER = 3                                   # verification iterations explored
MAX_LEN = 3 + 3 * MAX_ITER - 1 + 1 + 2 + 2     # longest legal trace + 2 slack
LABEL_CAPS = {C: MAX_ITER, I: MAX_ITER, D: MAX_ITER}   # other labels: cap 2
DEFAULT_CAP = 2                                # lets duplicated Legal/Release surface
TOKEN_BOUND = 1                                # source net is safe; >1 token = finding
MAX_STATES = 2_000_000


# ---------------------------------------------------------------------------
# Petri-net semantics helpers
# ---------------------------------------------------------------------------
def freeze(m):
    return frozenset((p, n) for p, n in m.items() if n > 0)


def fire(m, t):
    new = Marking(m)
    for arc in t.in_arcs:
        new[arc.source] -= arc.weight
        if new[arc.source] <= 0:
            del new[arc.source]
    for arc in t.out_arcs:
        new[arc.target] += arc.weight
    return new


def bounded_visible_language(net, im, fm):
    """Exhaustive DFS over (marking, visible prefix) pairs.

    - transitions with label None are hidden (label '' is NOT hidden);
    - a trace is completed only if the marking equals fm exactly;
    - silent cycles terminate because (marking, prefix) pairs are memoised;
    - visible length and per-label counts are capped.
    """
    target = freeze(fm)
    completed, seen = set(), set()
    flags = {"length_pruned": False, "token_pruned": False, "state_cap_hit": False,
             "deadlocks_off_fm": 0, "fm_with_enabled": 0}
    stack = [(Marking(im), ())]
    while stack:
        m, trace = stack.pop()
        key = (freeze(m), trace)
        if key in seen:
            continue
        seen.add(key)
        if len(seen) > MAX_STATES:
            flags["state_cap_hit"] = True
            break
        enabled = list(pm4py.get_enabled_transitions(net, m))
        if key[0] == target:
            completed.add(trace)
            if enabled:
                flags["fm_with_enabled"] += 1
        elif not enabled:
            flags["deadlocks_off_fm"] += 1
        for t in enabled:
            m2 = fire(m, t)
            if any(n > TOKEN_BOUND for n in m2.values()):
                flags["token_pruned"] = True
                continue
            if t.label is None:
                stack.append((m2, trace))
                continue
            new_trace = trace + (t.label,)
            if (len(new_trace) > MAX_LEN or
                    new_trace.count(t.label) > LABEL_CAPS.get(t.label, DEFAULT_CAP)):
                flags["length_pruned"] = True
                continue
            stack.append((m2, new_trace))
    flags["exhaustive_within_bound"] = not (flags["token_pruned"] or flags["state_cap_hit"])
    flags["explored_pairs"] = len(seen)
    return completed, flags


def accepts(net, im, fm, trace):
    """Replay a visible trace with silent closure; exact final marking required."""
    target = freeze(fm)
    frontier = deque([(Marking(im), 0)])
    seen = set()
    while frontier:
        m, i = frontier.popleft()
        key = (freeze(m), i)
        if key in seen:
            continue
        seen.add(key)
        if i == len(trace) and key[0] == target:
            return True
        for t in pm4py.get_enabled_transitions(net, m):
            m2 = fire(m, t)
            if any(n > TOKEN_BOUND for n in m2.values()):
                continue
            if t.label is None:
                frontier.append((m2, i))
            elif i < len(trace) and t.label == trace[i]:
                frontier.append((m2, i + 1))
    return False


def state_space_soundness(net, im, fm, max_markings=200_000):
    """Independent soundness check for safe nets (cross-checks Woflan)."""
    target = freeze(fm)
    succ, fired = {}, set()
    frontier, seen = deque([Marking(im)]), {freeze(im)}
    while frontier:
        m = frontier.popleft()
        k = freeze(m)
        succ[k] = []
        for t in pm4py.get_enabled_transitions(net, m):
            fired.add(t)
            m2 = fire(m, t)
            if any(n > TOKEN_BOUND for n in m2.values()):
                return {"sound": False, "reason": f"not {TOKEN_BOUND}-bounded"}
            k2 = freeze(m2)
            succ[k].append(k2)
            if k2 not in seen:
                if len(seen) >= max_markings:
                    return {"sound": None, "reason": "marking cap hit"}
                seen.add(k2)
                frontier.append(m2)
    pred = {k: [] for k in succ}
    for k, ks in succ.items():
        for k2 in ks:
            pred[k2].append(k)
    can_finish, queue = {target} & set(succ), deque([target] if target in succ else [])
    while queue:
        for k in pred[queue.popleft()]:
            if k not in can_finish:
                can_finish.add(k)
                queue.append(k)
    proper = all(not succ[k] for k in succ if k == target) and \
        not any(dict(k).keys() >= dict(target).keys() and k != target for k in succ)
    dead = [t.label or t.name for t in net.transitions if t not in fired]
    return {"sound": len(can_finish) == len(succ) and proper and not dead,
            "reachable_markings": len(succ),
            "option_to_complete": len(can_finish) == len(succ),
            "proper_completion": proper, "dead_transitions": dead}


# ---------------------------------------------------------------------------
# Independent oracle: the declared source semantics, not any converter output
# ---------------------------------------------------------------------------
ALPHABET = (R, A, P, L, C, I, D, REL, ARC)
ORACLE_START = (False, False, False, False, "idle", False, False)  # r a p legal loop rel arc


def oracle_step(state, label):
    """Deterministic automaton of the intended semantics; None = rejected."""
    r, a, p, legal, loop, rel, arc = state
    if arc:
        return None
    if label == R and not r:
        return (True, a, p, legal, loop, rel, arc)
    if not r:
        return None
    if label == A and not a:
        return (r, True, p, legal, loop, rel, arc)
    if label == P and not p:
        return (r, a, True, legal, loop, rel, arc)
    if label == L and a and not legal and not rel:
        return (r, a, p, True, loop, rel, arc)
    if label == C and a and p and loop in ("idle", "after_D"):
        return (r, a, p, legal, "after_C", rel, arc)
    if label == I and loop == "after_C":
        return (r, a, p, legal, "after_I", rel, arc)
    if label == D and loop == "after_I" and not rel:
        return (r, a, p, legal, "after_D", rel, arc)
    if label == REL and loop == "after_I" and not rel:
        return (r, a, p, legal, "done", True, arc)
    if label == ARC and rel:
        return (r, a, p, legal, loop, rel, True)
    return None


def oracle_accepting(state):
    return state is not None and state[-1]


def in_oracle(trace):
    st = ORACLE_START
    for lab in trace:
        st = oracle_step(st, lab)
        if st is None:
            return False
    return oracle_accepting(st)


def oracle_language():
    """Enumerate visible traces of the intended semantics under the same caps."""
    results, stack = set(), [((), ORACLE_START)]
    while stack:
        trace, st = stack.pop()
        if oracle_accepting(st):
            results.add(trace)
        for lab in ALPHABET:
            nxt = oracle_step(st, lab)
            new_trace = trace + (lab,)
            if nxt is None or len(new_trace) > MAX_LEN or \
                    new_trace.count(lab) > LABEL_CAPS.get(lab, DEFAULT_CAP):
                continue
            stack.append((new_trace, nxt))
    return results


def exact_equivalence_with_oracle(net, im, fm):
    """Unbounded visible-trace equivalence for safe nets.

    Subset construction over tau-closures of reachable markings (a DFA of the
    net's visible language) explored in product with the oracle automaton.
    Returns (equivalent, shortest counterexample or None).
    """
    target = freeze(fm)

    def closure(keys):
        res, stack = set(keys), list(keys)
        while stack:
            m = Marking(dict(stack.pop()))
            for t in pm4py.get_enabled_transitions(net, m):
                if t.label is None:
                    m2 = fire(m, t)
                    if any(n > TOKEN_BOUND for n in m2.values()):
                        raise ValueError("net not safe; exact check not applicable")
                    k2 = freeze(m2)
                    if k2 not in res:
                        res.add(k2)
                        stack.append(k2)
        return frozenset(res)

    def step(subset, label):
        nxt = set()
        for k in subset:
            m = Marking(dict(k))
            for t in pm4py.get_enabled_transitions(net, m):
                if t.label == label:
                    m2 = fire(m, t)
                    if any(n > TOKEN_BOUND for n in m2.values()):
                        raise ValueError("net not safe; exact check not applicable")
                    nxt.add(freeze(m2))
        return closure(nxt) if nxt else frozenset()

    labels = set(ALPHABET) | {t.label for t in net.transitions if t.label is not None}
    start = (closure({freeze(im)}), ORACLE_START)
    queue, seen = deque([(start, ())]), {start}
    while queue:
        (subset, ost), trace = queue.popleft()
        if (target in subset) != oracle_accepting(ost):
            return False, trace
        for lab in labels:
            nxt_net = step(subset, lab) if subset else frozenset()
            nxt_or = oracle_step(ost, lab) if ost is not None else None
            if not nxt_net and nxt_or is None:
                continue
            pair = (nxt_net, nxt_or)
            if pair not in seen:
                seen.add(pair)
                queue.append((pair, trace + (lab,)))
    return True, None


POSITIVE = {
    "minimal":                   (R, A, P, C, I, REL, ARC),
    "prepare_first":             (R, P, A, C, I, REL, ARC),
    "legal_before_prepare":      (R, A, L, P, C, I, REL, ARC),   # N-shape witness
    "legal_inside_iteration":    (R, A, P, C, L, I, REL, ARC),   # overlap witness
    "legal_between_iterations":  (R, A, P, C, I, D, L, C, I, REL, ARC),
    "three_iterations":          (R, P, A, C, I, D, C, I, D, C, I, L, REL, ARC),
}
NEGATIVE = {
    "zero_iterations":           (R, A, P, REL, ARC),
    "legal_before_assess":       (R, L, A, P, C, I, REL, ARC),
    "verify_before_prepare":     (R, A, C, I, P, REL, ARC),
    "inspect_before_configure":  (R, A, P, I, C, REL, ARC),
    "exit_after_correct":        (R, A, P, C, I, D, REL, ARC),
    "correct_inside_iteration":  (R, A, P, C, D, I, REL, ARC),
    "legal_twice":               (R, A, L, P, C, I, L, REL, ARC),
    "release_before_legal":      (R, A, P, C, I, REL, L, ARC),
    "release_before_verify":     (R, A, P, REL, C, I, ARC),
    "archive_before_release":    (R, A, P, C, I, ARC, REL),
    "missing_archive":           (R, A, P, C, I, REL),
    "register_not_first":        (A, R, P, C, I, REL, ARC),
    "event_after_archive":       (R, A, P, C, I, REL, ARC, L),
}


def footprint_summary(fp):
    keys = ("activities", "start_activities", "end_activities", "sequence", "parallel")
    return {k: set(fp.get(k, set())) for k in keys}


def witness_log(traces):
    rows = []
    for case_id, trace in traces.items():
        for pos, act in enumerate(trace):
            rows.append({"case:concept:name": case_id, "concept:name": act,
                         "time:timestamp": pd.Timestamp("2026-01-01") + pd.Timedelta(minutes=pos)})
    df = pm4py.format_dataframe(pd.DataFrame(rows), case_id="case:concept:name",
                                activity_key="concept:name", timestamp_key="time:timestamp")
    return pm4py.convert_to_event_log(df)   # alignment results follow this trace order


def playout_variants(net, im, fm):
    log = pm4py.play_out(net, im, fm)
    df = log if isinstance(log, pd.DataFrame) else pm4py.convert_to_dataframe(log)
    return set(df.groupby("case:concept:name", sort=False)["concept:name"].apply(tuple))

print(f"oracle: {len(ORACLE)} traces with <= {MAX_ITER} iterations")
assert all(t in ORACLE for t in POSITIVE.values()), "positive witness violates oracle"
assert not any(t in ORACLE for t in NEGATIVE.values()), "negative witness in oracle"

        rep["footprint_diff"] = {k: (sorted(ref_fp[k] - fp[k]), sorted(fp[k] - ref_fp[k]))
                                 for k in ref_fp if ref_fp[k] != fp[k]}

    lang, flags = bounded_visible_language(net, im, fm)
    rep["bounded_language_size"] = len(lang)
    rep["exploration_flags"] = flags
    rep["missing_vs_oracle"] = sorted(ORACLE - lang, key=len)[:5]

    except ValueError as exc:
        rep["exact_trace_equivalence"] = (None, str(exc))

    rep["positive_rejected"] = [k for k, t in POSITIVE.items() if not accepts(net, im, fm, t)]
    rep["negative_accepted"] = [k for k, t in NEGATIVE.items() if accepts(net, im, fm, t)]

    try:
        wlog = witness_log({**{"pos_" + k: v for k, v in POSITIVE.items()},
                            **{"neg_" + k: v for k, v in NEGATIVE.items()}})
        aligned = pm4py.conformance_diagnostics_alignments(wlog, net, im, fm)
        cases = [trace.attributes["concept:name"] for trace in wlog]
        fit = dict(zip(cases, (a["fitness"] for a in aligned)))
        rep["alignment_disagreements"] = [c for c, f in fit.items()
                                          if (c.startswith("pos_") and f < 1.0) or
                                          (c.startswith("neg_") and f >= 1.0)]
    except Exception as exc:
        rep["alignment_disagreements"] = f"not run: {exc_text(exc)}"

    try:
        played = playout_variants(net, im, fm)
        rep["playout_variants"] = len(played)
        rep["playout_outside_oracle_semantics"] = [t for t in played if not in_oracle(t)][:3]
    except Exception as exc:
        rep["playout_variants"] = f"not run: {exc_text(exc)}"

    exact = (rep["n_missing_vs_oracle"] == 0 and rep["n_extra_vs_oracle"] == 0
             and flags["exhaustive_within_bound"])
    sound = rep["state_space"].get("sound") is True
    unbounded_ok = rep["exact_trace_equivalence"][0] is True
    behaviour_ok = (exact and unbounded_ok and sound and not rep["positive_rejected"]
                    and not rep["negative_accepted"])
    if behaviour_ok and rep["woflan_sound"] is True:
        rep["verdict"] = ("ACCEPT (visible-trace equivalent to the oracle: exhaustive for "
                          f"<= {MAX_ITER} iterations by enumeration, unbounded by subset construction)")
    elif behaviour_ok:
        rep["verdict"] = "HOLD (behaviour matches, but Woflan disagrees with state-space check)"
    else:
        rep["verdict"] = "REJECT/QUARANTINE"
    validation[name] = rep

for rep in validation.values():
    print("\n==", rep["net"])
    for k, v in rep.items():
        if k != "net":
            print(f"   {k}: {v}")
```

**Is the comparison exhaustive?**

- **Bounded enumeration.** For each net, the search covers every completed visible trace with at most 16 events, at most 3 occurrences each of C, I and D, and at most 2 occurrences of every other label. It hides only label-`None` transitions, requires exact final-marking equality, and memoizes (marking, prefix) pairs so that silent cycles terminate. Every prefix of a trace within the bound is itself within the bound, so the enumeration is **exhaustive for that bounded language**, provided that `token_pruned` and `state_cap_hit` are both `False`. In the reference run both were `False`. `length_pruned` was `True`, which is expected and simply means that longer behaviour exists beyond the bound.
- **Unbounded check.** Every net here is safe, with 15 reachable markings (13 for P3). Their visible languages are therefore regular, and the subset construction in `exact_equivalence_with_oracle` is an **exhaustive visible-trace equivalence check with no iteration bound**. It raises instead of answering if it finds a non-safe marking.
- **What neither check covers.** Both are exhaustive only for *interleaving trace* semantics. Step semantics, branching time and bisimulation are not covered.

- **Why the Woflan verdict disagrees.**
  - The generation-2 net has the same structure as the generation-1 net. The state-space check shows it is sound, and it is trace-equivalent to the oracle. Woflan nevertheless reported "places not covered by an S-component".
  - A manual S-cover exists: three S-components through the Legal branch, the A→loop branch and the P→loop branch together cover all 12 places.
  - Regenerating the same pipeline 40 times gave Woflan false negatives on 6 of 40 first-generation round-trip nets. The verdict depended on the net *instance* (UUID-based names), not on its structure, and PM4Py itself warns that its scipy-based invariant computation "may be unstable".
  - Woflan alone is therefore not accepted as evidence, in either direction. A disagreement puts the artifact on HOLD until it is explained.
- **Playout.** `pm4py.play_out` produced 52–60 distinct variants per net. Every variant was accepted by the oracle automaton, including runs longer than the bound. This is extra, random-sampling evidence, not an exhaustive check.
- **Checker sanity (mutation tests on `net_from_powl`).** Adding a silent loop bypass was caught, with counterexample `R P A Rel Arc`. Swapping the C and I labels was caught. Turning silent transitions into label `""` was caught by both the language check and the label check.

# 6. Visual-Semantics Review

The PM4Py BPMN rendering of `bpmn_from_net` reads left to right:

1. A start event, then R, then a parallel split into P and A.
2. A goes into a second parallel split. One flow goes to a parallel join that is shared with P's flow; the other goes to an exclusive split that offers L or a bare bypass flow, with both joining at an exclusive join.
3. The parallel join leads to an exclusive merge, then C, then I, then an exclusive split. From there, one flow goes to D, which is drawn above and to the right with a back edge to the merge; the other goes to a parallel join.
4. That parallel join also receives the Legal exclusive join. It leads to Rel, then Arc, then the end event.

This diagram is behaviourally acceptable, because its round trip was validated. It can still be misread in several ways:

- **Parallel gateways.**
  - The split after R is **not closed by a matching join**. P's branch joins with only one of A's two branches, and A's other branch (Legal) joins much later at Release. Readers used to block-structured BPMN tend to pair splits with joins and conclude that Legal also waits for Prepare, or that verification waits for Legal. Neither is true.
  - A parallel gateway reads as "these run in parallel". The source only says "may overlap" (no order), not "must run simultaneously".
- **Exclusive gateways.**
  - The same diamond is used for three different roles: a *merge* (loop entry), a *decision* (Legal or skip, repeat or exit), and a *join* (end of the Legal option). Directions are `UNSPECIFIED`.
  - No exclusive gateway carries a condition. In BPMN an exclusive split is a data-based, immediate decision, while the source's XOR is an uninterpreted choice. Readers will invent conditions ("Legal only for high risk"), and a process engine would need conditions that the model does not contain.
  - After Inspect, the BPMN split implies that the exit decision is taken immediately. The net defers it until Release or Correct Defect fires.
- **Loop visualization.**
  - The loop is visible only as a back edge. Because D is laid out to the right of I, near Release, it can be read as "a final correction step before release" instead of a redo step that always leads back to Configure.
  - "At least one iteration" is implicit: the merge sits *before* C. It is easy to overlook, and a casual reader may think verification can be skipped.
  - The diagram does not label C and I as the loop body or D as the redo.
- **Silent routing nodes.**
  - The silent skip was reduced to an unlabeled flow between two diamonds. Some readers will not notice that Legal is optional. Others, looking at a rendering that keeps silent transitions as blank tasks, would see a nameless "activity".
  - The silent AND-join from the POWL encoding shows up as a gateway that has no business meaning.
  - In the round-trip Petri net, new silent transitions (`sfl_*`) appear whose names hint at their BPMN origin, not at the source.
- **Apparent ordering from layout.** Graphviz ranks nodes by graph distance. Horizontal position carries **no** temporal meaning. For example, L is drawn roughly level with the loop entry, which suggests that Legal comes before Configure, or finishes before verification starts. Neither is required: L may happen before P, inside an iteration, or after the last Inspect.

**Proposed annotations and documentation.** These are overlays on the generated BPMN only. They must never be hand-edits to its flows.

- Label the gateways explicitly: "merge: loop entry (≥1 iteration)", "decision: repeat verification?", "decision: legal review needed? (uninterpreted choice)", "join: legal branch complete", "sync: legal branch AND verification complete".
- Label the bypass flow "no legal review (silent skip)".
- Put a BPMN group around C, I and D titled "Verification loop: Configure→Inspect, repeat via Correct Defect, at least once".
- Add a text annotation on Legal Review: "May start any time after Assess Risk, including before Prepare Evidence and during verification; must finish before Release."
- Add a legend: "Horizontal position does not imply order; only sequence flows and gateways do. Parallel = no ordering constraint, not mandatory simultaneity."
- Add a provenance footer: source POWL hash, PM4Py version, pipeline ID (P1), validation verdict, date.
- Publish the invariant table (§1) and the witness traces next to the diagram, so that stakeholders can check their reading against concrete sequences.

# 7. Rejection Criteria

A conversion result is **rejected** (R) or **quarantined for review** (Q) if any of the following holds:

1. **(R) Conversion exception or unusable markings.** Any converter raises. A result comes back as `None`. The initial or final marking is missing, empty, holds more than one token, or does not coincide with the unique source or sink place.
2. **(R) Not a workflow net.** `check_is_workflow_net` is false or raises.
3. **(R) Unsound under the independent state-space check.** A deadlock away from the final marking, a reachable marking without option to complete, improper completion (the final marking with transitions still enabled, or a marking that strictly covers it), dead transitions, or non-safeness.
4. **(Q) Tool disagreement.** Woflan and the state-space check disagree. This was observed for `net_rt_gen2`. The artifact is held until someone explains the disagreement, for example by producing an S-cover by hand, or re-runs Woflan with a reliable LP solver.
5. **(R) Loss of a required interleaving.** Any positive witness is rejected, or any oracle trace is missing, for example `R A L P C I Rel Arc` (N-shape) or `R A P C L I Rel Arc` (Legal overlapping verification). This is the P3 failure mode.
6. **(R) Admission of forbidden behaviour.** Any negative witness is accepted or any extra trace appears. Examples: release before verification (`R A P Rel C I Arc`), release before a pending Legal Review, zero iterations, exit after Correct Defect, Legal twice, Legal before Assess, or events after Archive.
7. **(R) Collapse of optional behaviour.** Legal becomes mandatory (no completed trace without L), Legal disappears, or the silent skip becomes visible (label `""` or a named task).
8. **(R) Failed exact-final-marking test.** A trace completes only with residual tokens, or the final marking is treated as "covering" instead of "equal".
9. **(R) Label-identity violation.** Duplicated, blank, missing, renamed or extra visible labels.
10. **(Q) Silent approximation by a converter.** Any precision warning, such as "cannot be converted precisely" from POWL→tree, or a process-tree conversion that *succeeds* on this N-shaped model without passing exact equivalence.
11. **(R) Non-idempotent round trip.** The second-generation net differs in language from the first generation or from the source.
12. **(Q) Incomplete evidence.** The bounded exploration hit the token or state caps without a successful unbounded check. Or an artifact has only a visualization or a serialization, with no attached validation record, source hash and tool version.

# 8. Canonical Representation Recommendation

**Authoritative storage model: the source POWL.** Store it as version-controlled code or as a serialized POWL, together with its hand-written oracle automaton, the witness suite (§5) and the transitive-closure normalization note. Only the POWL states the partial order directly: the N-shape, the binary loop scope and the silent option. Every other format either encodes it indirectly (the Petri net) or cannot express it with unique labels (process trees).

**Semantic reference derivative: `net_from_powl`.** Store it as PNML (`01_P1_petri_from_powl.pnml`). It is the executable form used for conformance checking and validation. It is *derived*: it can be regenerated from the POWL at any time and is never edited by hand.

**Stakeholder visualization: the BPMN from P1** (`bpmn_from_net`, exported as `.bpmn` plus a rendered image), with the §6 annotation overlay. It is derivative and read-only.

**Derivative artifacts and the evidence each must carry:**

| Derivative | Required evidence |
|---|---|
| Accepting Petri net from the POWL | Source hash, PM4Py version, closure note; WF-net check; state-space soundness, plus Woflan with any disagreement explained; exact trace equivalence with the oracle; bounded enumeration flags; label and marking checks; witness replay and alignment results. |
| BPMN (P1) | Source hash; hash of the net it came from; round-trip net passing everything required of the Petri net; second-generation idempotence result; list of gateway roles used for the annotations. |
| Rendered images (PNG/SVG) | Link to the exact BPMN or net file; the legend "layout carries no order"; the validation verdict of the underlying model. An image is never evidence by itself. |
| Any process tree | Not permitted for this model (see below). If it ever exists, it must carry the precision-warning log and a *passing* exact equivalence result. |

**Process-tree intermediates.** They are not allowed for this model. P2 correctly failed. P3 "succeeded" only by dropping the N-shaped interleavings, and PM4Py reports that as a warning, not an error. As a general policy, a tree intermediate is permitted only if the conversion finishes with zero warnings (warnings treated as errors) *and* passes the exact equivalence check against the POWL oracle. The model owner could also rewrite the POWL to be block-structured, for example by adding `Prepare → Legal`, but that is a deliberate *semantic change* that needs sign-off. It is not a conversion.

**Avoiding round-trip drift in future edits:**

- Edit only the POWL. BPMN, PNML and images are regenerated, never edited. If a stakeholder marks up the BPMN, treat it as a change request, re-model it in POWL, and update the §1 invariant table and the oracle in the same change.
- Run §3 and §5 in continuous integration on every change and on every PM4Py upgrade. Pin the PM4Py version in the evidence bundle, and fail the build on any rejection criterion from §7.
- Never chain derivatives. Always generate the BPMN from the POWL-derived net, never from a previous BPMN round trip. Use the second-generation artifact only as an idempotence check.
- Keep generated IDs out of anything that is compared. Compare languages, label sets and invariants, not node or place names. This matters because both UUID naming and the Woflan instability are instance-dependent.

# 9. Residual Uncertainty

Even if every test passes, the validation cannot establish the following:

1. **True-concurrency equivalence.** All checks are interleaving-based. A derivative that replaced concurrency with a mutex place still allowing both orders would pass every test. Whether Legal Review can *actually overlap in time* with verification in every derivative is unverified.
2. **Branching-time or bisimulation equivalence.** Trace equivalence does not fix *when* choices are made. The net defers the loop exit until Release, the BPMN suggests an immediate exclusive decision, and a tau-exit reading commits earlier. Those differences matter for monitoring, prediction and execution engines, and they are not tested.
3. **That the oracle captures stakeholder intent.** The oracle was hand-written from the stated semantics. If, for example, "Legal may overlap verification" was a modelling accident, or high-risk changes actually *require* legal review (a data condition absent from the model), every test would pass against the wrong specification.
4. **Independence of the round-trip evidence.** The BPMN is validated only by translating it back with PM4Py's *own* BPMN→Petri converter, and all semantics come from the same library's `get_enabled_transitions`. Correlated errors in PM4Py, or a different BPMN engine or modelling tool interpreting the exported XML differently, are not ruled out. That includes unspecified gateway directions and exclusive gateways without conditions.
5. **Human comprehension of the diagram.** No test shows that stakeholders read the BPMN correctly. The layout-induced misreadings in §6 are mitigated by annotations, not eliminated.
6. **Behaviour outside control flow.** Time, data, resources, cancellation and fairness are outside the model. "At least one iteration, unbounded" says nothing about whether verification terminates in practice or how long it takes.
7. **Stability across versions and instances.** The results hold for PM4Py 2.7.23.4 on these generated instances. The Woflan false negatives show that verdicts can depend on incidental naming, so a future version could change the conversion output without any change to the source.
