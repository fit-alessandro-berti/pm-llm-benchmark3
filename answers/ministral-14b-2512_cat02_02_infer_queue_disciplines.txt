# 4. Counterfactual discrimination tests

### **Episode 1: QB’s B07 Appointment Violation**
- **Observation**: B07’s appointment (10:30) is ignored; starts at 10:56.
- **Hypothesis A (Priority Overrides Appointments)**:
  - Next job after B06 (10:56) would be B07 (priority 3), but B06’s completion (10:56) leaves B07 eligible.
  - **Prediction**: If appointments were enforced, B07 would start at 10:30, but priority 1/2 jobs (none pending) would delay it.
- **Hypothesis B (Appointments Are Mandatory)**:
  - B07 should start at 10:30 regardless of priority.
  - **Discriminator**: Check if any priority 1/2 jobs arrived between 10:30–10:56. If none, appointments are likely mandatory.

### **Episode 2: QD’s D08 Preemption**
- **Observation**: D08 (priority 1, mechanical) preempts D09 (priority 3, mechanical) at 11:35.
- **Hypothesis A (Preemptive Priority)**:
  - D08’s shorter `est_min` (8 vs. 20) aligns with SPT-like behavior within skill groups.
- **Hypothesis B (SPT Within Skill Groups)**:
  - If D09 had started first, D08 would preempt it due to shorter `est_min`.
  - **Discriminator**: Compare `est_min` ratios for other mechanical jobs. If shorter jobs always preempt, SPT is likely.

- **Most Identifiable Queue**: **QD** (skill-based routing is unambiguous; preemption aligns with priority).
- **Least Identifiable Queue**: **QC** (deadlines  priorities; FIFO vs. SLA-driven behavior is observationally equivalent).

- **Cross-Queue Pattern**: **Priority dominates when observable**, but **skill constraints and appointments act as tie-breakers**. The hybrid discipline is likely **priority + skill + appointment**, with SPT-like behavior only within skill groups.

**Key Insight**: The data cannot distinguish between:
- "Priority overrides appointments" and "Appointments are ignored when higher-priority jobs arrive."
- "SPT within skill groups" and "Priority 1 jobs are always shorter."
**Recommendation**: Collect dispatch-decision logs to resolve these ambiguities.
