# **Equivalence Notions**
Define the comparison boundaries explicitly:

1. **Visible Trace Equivalence (after hiding `tau`)**
   - Two traces are equivalent if they have identical sequences of visible labels (ignoring `tau` transitions), including:
     - Positional ordering of `Check Revision`, `Analyze Revision`, and `Rework Case`.
     - Exact count of `Analyze Revision` occurrences (since `Approved Revision` is optional and hidden in P2/P3).
   - Duplicate labels (e.g., two `Analyze Revision` in a row) are distinguished by their occurrence position.

2. **Bounded Visible-Language Equivalence (P3)**
   - Traces are compared only if they:
     - Have 12 visible events.
     - Have 3 `Analyze Revision` occurrences.
   - Silent transitions (`tau`) are ignored, but their effect on loop structure (e.g., enabling/disabling `Rework Case`) is preserved.

3. **Business-Relevant Equivalence (P1)**
   - Requires:
     - Every `Analyze Revision` must precede a `Check Revision` before `Rework Case` or `Close Case`.
     - `Rework Case` separates two analysis attempts.
     - Optional `Approved Revision` is preserved in its placement (e.g., Model A’s `X` is not collapsed in P1).
   - Concurrency (Model B’s `+` inside the loop) is disallowed unless explicitly required by P1’s operational compliance.

4. **Dashboard Equivalence (P2)**
   - Collapses:
     - Repeated `Check Revision` into a Boolean fact ("a check occurred").
     - Hides `Approved Revision` and silent transitions.
   - Tracks:
     - Number of `Analyze Revision` occurrences (exact count).
     - Whether `Rework Case` occurred (Boolean).
   - Traces are equivalent if their dashboard summaries match.

```python
def explore_bounded_traces(net, max_events=12, max_analyze=3):
    reachability_graph = rg_converter.convert(net)
    traces = []
    for marking in reachability_graph.get_markings():
        if len(marking) > max_events:
            continue
        if marking.count('Analyze Revision') > max_analyze:
            continue
        trace = list(marking)
        traces.append(trace)
    return traces

traces_a = explore_bounded_traces(net_a)
traces_b = explore_bounded_traces(net_b)

# Unique traces
unique_to_a = [t for t in traces_a if t not in traces_b]
unique_to_b = [t for t in traces_b if t not in traces_a]

print("Unique traces in Model A:", unique_to_a)
print("Unique traces in Model B:", unique_to_b)
```

# **Stochastic and Footprint Comparison**
- **`pm4py.discover_footprints(...)`**:
  Useful for comparing the *distribution* of event sequences, but footprints may differ even if traces are equivalent under P3 (e.g., due to `tau` interleaving). Example:
  ```python
  footprints_a = pm4py.discover_footprints(model_a)
  footprints_b = pm4py.discover_footprints(model_b)
  print(pm4py.compare_footprints(footprints_a, footprints_b))
  ```

- **`pm4py.get_stochastic_language(...)`**:
  Requires transition probabilities. If probabilities are unknown, this cannot be used to compare models.

- **`pm4py.compute_emd(...)`**:
  Earth Mover’s Distance (EMD) compares *distributions* of traces. Even if EMD is low, models may differ in loop structure (e.g., Model A’s sequential checks vs. Model B’s interleaving). EMD alone does not prove trace equivalence.
