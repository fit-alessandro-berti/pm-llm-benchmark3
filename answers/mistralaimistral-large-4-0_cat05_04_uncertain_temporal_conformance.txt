## 1. Normalization Assumptions

- **Clock-offset direction:** `clock_offset = recorded_clock - true_clock`. If offset is in `[a, b]`, then true time is `recorded - offset`, so true time lies in `[recorded - b, recorded - a]`.
- **Resolution before clock correction:** timestamp-resolution uncertainty is applied first, then the clock-offset bound is applied.
- **Rounding semantics:**
  - HUB: exact to displayed second; measurement uncertainty `±0.5 s`; combined with clock offset `[-1, +1] s` gives `±1.5 s`.
  - Floor to minute: displayed `HH:MM` means local clock in `[HH:MM:00.000, HH:MM:59.999]`.
  - Round to nearest 10 s: displayed `HH:MM:10` means recorded clock in `[HH:MM:05.000, HH:MM:15.000)` (upper exclusive).
  - Round to nearest minute: displayed `HH:MM` means local clock in `[HH:MM:00 - 30 s, HH:MM:00 + 30 s)` (upper exclusive).
- **Time zones:** IANA zones. June 2026: CEST = UTC+2, EDT = UTC4, BST = UTC+1.
- **DST folds:** 2025-10-26 02:00–02:59 in Europe/Berlin is ambiguous. `fold=0` = CEST (UTC+2), `fold=1` = CET (UTC+1). For T-405, ingestion order rules out all but Alert_Received in CEST fold, Investigation_Start and Containment_Complete in CET fold.
- **Inferred starts:** T-404 Investigation_Start = Investigation_Complete  duration, with duration in `[18, 25]` minutes; full uncertainty retained.
- **Causal constraints:** lifecycle order assumed: Alert_Received  Investigation_Start  Containment_Complete  Close_Incident. For T-407, Alert_Received is inferred from Alert_Sent + delivery latency `[0, 20]` min and constrained to be  Investigation_Start; without this constraint the interval extends to `14:20:01.5` and S1 duration includes negative values.
- **Mobile entry delay:** T-406 user may have entered displayed time up to 5 min late. I treat this as occurrence time being earlier than entry time by `[0, 5]` min, shifting the occurrence interval earlier. If treated as record-time-only uncertainty, the interval would be `[12:08:30, 12:19:30)` instead of `[12:03:30, 12:19:30)`.
- **SLA tolerance baseline:** 0 minutes. **Temporal profile default:** zeta = 2 for the main findings table; sensitivity covers zeta 1, 2, 3 and SLA tolerance 0, 2, 5 minutes.
- **Midpoints** are used only for the PM4Py lossy approximation, never for interval conclusions.

## 5. PM4Py Temporal-Conformance Code

```python
import pandas as pd
from datetime import datetime, timedelta, timezone
from zoneinfo import ZoneInfo

UTC = timezone.utc

# ---------- Interval helpers ----------
def intersect(a, b):
    low = max(a[0], b[0])
    high = min(a[1], b[1])
    if low > high:
        return None
    return (low, high)

def duration_intervals(A, B):
    """A, B are lists of (low, high) datetime intervals. Returns list of duration intervals."""
    res = []
    for a in A:
        for b in B:
            res.append((b[0] - a[1], b[1] - a[0]))
    return res

def merge_intervals(intervals):
    if not intervals:
        return []
    intervals = sorted(intervals, key=lambda x: x[0])
    merged = [intervals[0]]
    for low, high in intervals[1:]:
        last_low, last_high = merged[-1]
        if low <= last_high:
            merged[-1] = (last_low, max(last_high, high))
        else:
            merged.append((low, high))
    return merged

def classify_sla(dur, max_allowed):
    low, high = dur
    if high <= max_allowed:
        return "CERTAIN_PASS"
    elif low > max_allowed:
        return "CERTAIN_VIOLATION"
    else:
        return "POSSIBLE_VIOLATION"

def classify_profile(dur, band_low, band_high):
    low, high = dur
    if high < band_low or low > band_high:
        return "CERTAIN_VIOLATION"
    elif low >= band_low and high <= band_high:
        return "CERTAIN_PASS"
    else:
        return "POSSIBLE_VIOLATION"

# ---------- Source normalization functions ----------
def hub_interval(ts_str):
    dt = datetime.fromisoformat(ts_str).replace(tzinfo=UTC)
    return (dt - timedelta(seconds=1.5), dt + timedelta(seconds=1.5))

def ops_ber_interval(local_str, offset_low=-90, offset_high=120):
    naive = datetime.fromisoformat(local_str)
    tz = ZoneInfo("Europe/Berlin")
    low_local = naive.replace(second=0, microsecond=0)
    high_local = low_local + timedelta(minutes=1) - timedelta(milliseconds=1)
    low_utc = low_local.replace(tzinfo=tz).astimezone(UTC)
    high_utc = high_local.replace(tzinfo=tz).astimezone(UTC)
    # true = recorded - offset, offset in [offset_low, offset_high]
    return (low_utc - timedelta(seconds=offset_high), high_utc - timedelta(seconds=offset_low))

def sensor_interval(ts_str):
    dt = datetime.fromisoformat(ts_str).replace(tzinfo=UTC)
    low = dt - timedelta(seconds=5)
    high = dt + timedelta(seconds=5)  # upper exclusive
    # offset [-5, +5]
    return (low - timedelta(seconds=5), high + timedelta(seconds=5))

def vendor_ny_interval(local_str):
    naive = datetime.fromisoformat(local_str)
    tz = ZoneInfo("America/New_York")
    low_local = naive.replace(second=0, microsecond=0)
    high_local = low_local + timedelta(minutes=1) - timedelta(milliseconds=1)
    low_utc = low_local.replace(tzinfo=tz).astimezone(UTC)
    high_utc = high_local.replace(tzinfo=tz).astimezone(UTC)
    # offset [-180, +180]
    return (low_utc - timedelta(seconds=180), high_utc + timedelta(seconds=180))

def legacy_ber_interval(local_str, fold):
    naive = datetime.fromisoformat(local_str)
    tz = ZoneInfo("Europe/Berlin")
    low_local = naive.replace(second=0, microsecond=0)
    high_local = low_local + timedelta(minutes=1) - timedelta(milliseconds=1)
    low_utc = low_local.replace(tzinfo=tz, fold=fold).astimezone(UTC)
    high_utc = high_local.replace(tzinfo=tz, fold=fold).astimezone(UTC)
    # offset [-60, +60]
    return (low_utc - timedelta(seconds=60), high_utc + timedelta(seconds=60))

def legacy_ber_intervals(local_str):
    """Return both DST-fold alternatives."""
    return [legacy_ber_interval(local_str, fold=0), legacy_ber_interval(local_str, fold=1)]

def mobile_lon_interval(local_str):
    naive = datetime.fromisoformat(local_str)
    tz = ZoneInfo("Europe/London")
    low_local = naive - timedelta(seconds=30)
    high_local = naive + timedelta(seconds=30)  # upper exclusive
    low_utc = low_local.replace(tzinfo=tz).astimezone(UTC)
    high_utc = high_local.replace(tzinfo=tz).astimezone(UTC)
    # clock offset [-300, +300]
    entry_low = low_utc - timedelta(seconds=300)
    entry_high = high_utc + timedelta(seconds=300)
    # entry delay [0, 300] s earlier: occurrence = entry - delay
    occ_low = entry_low - timedelta(seconds=300)
    occ_high = entry_high - timedelta(seconds=0)
    return (occ_low, occ_high)

def infer_start_from_complete(complete_interval, duration_low, duration_high):
    c_low, c_high = complete_interval
    return (c_low - timedelta(seconds=duration_high), c_high - timedelta(seconds=duration_low))

def infer_alert_received(sent_interval, latency_low, latency_high, causal_max=None):
    s_low, s_high = sent_interval
    r_low = s_low + timedelta(seconds=latency_low)
    r_high = s_high + timedelta(seconds=latency_high)
    if causal_max is not None:
        r_high = min(r_high, causal_max)
    return (r_low, r_high)
```

## 7. Governance Recommendation

1. **UTC storage:** Store all event timestamps in UTC internally. Retain the original local timestamp and time-zone identifier as raw provenance fields.
2. **Raw timestamp retention:** Never overwrite raw displayed timestamps. Keep the original string, the source system, the rounding semantics, and the clock-offset bound alongside the normalized UTC interval.
3. **Source offset telemetry:** Continuously collect and log per-source clock-offset diagnostics (NTP/PTP). Replace weak engineering estimates with measured bounds. Alert when offset bounds exceed policy thresholds.
4. **Resolution metadata:** Record timestamp resolution (exact second, floor-to-minute, round-to-nearest-10s, etc.) as structured metadata. Apply resolution uncertainty before clock correction.
5. **Start/complete semantics:** Define and log whether an event is a start event, completion event, or user-entered event. For user-entered timestamps, record whether entry delay reflects late recording or actual occurrence time.
6. **DST fold handling:** For ambiguous local times, store the fold explicitly (e.g., `fold=0`/`fold=1`) or store UTC directly. Never rely on local time alone during DST transitions.
7. **Causal identifiers:** Use causal identifiers (trace ID, case ID, parent event ID) to enforce lifecycle order and to infer missing events defensibly. Do not silently assume `Alert_Sent` equals `Alert_Received`.
8. **Interval-overlap enforcement policy:** Adopt a written policy for whether interval overlap is sufficient for SLA enforcement. Recommended: CERTAIN_VIOLATION triggers enforcement; POSSIBLE_VIOLATION triggers review and evidence collection; CERTAIN_PASS closes the item. Do not use midpoint-only logs for enforcement.
9. **Provenance controls:** Log the evidence source, evidence strength, and inference method (direct, inferred, constrained) for every normalized interval. This enables auditability of POSSIBLE_VIOLATION and INDETERMINATE outcomes.
