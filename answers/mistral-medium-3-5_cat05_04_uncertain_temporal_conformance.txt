def normalize_to_utc(row):
    system = row['System']
    recorded = row['Recorded']
    tz = row['TimeZone']
    rounding = row['Rounding']
    offset_bounds = row['OffsetBounds']

    # Parse recorded time (naive datetime)
    if ':' in recorded:
        recorded_dt = datetime.strptime(recorded, '%Y-%m-%d %H:%M:%S')
    else:
        recorded_dt = datetime.strptime(recorded, '%Y-%m-%d %H:%M')

    # Apply rounding
    if rounding == 'floor_minute':
        start_dt = recorded_dt.replace(second=0, microsecond=0)
        end_dt = recorded_dt.replace(second=59, microsecond=999999)
    elif rounding == 'round_10s':
        # Round to nearest 10s
        second = recorded_dt.second
        rounded_second = round(second / 10) * 10
        if rounded_second == 60:
            rounded_second = 0
            recorded_dt += timedelta(minutes=1)
        start_dt = recorded_dt.replace(second=rounded_second, microsecond=0) - timedelta(seconds=5)
        end_dt = recorded_dt.replace(second=rounded_second, microsecond=0) + timedelta(seconds=5)
    elif rounding == 'round_minute':
        # Round to nearest minute
        start_dt = recorded_dt.replace(second=0, microsecond=0) - timedelta(seconds=30)
        end_dt = recorded_dt.replace(second=0, microsecond=0) + timedelta(seconds=30)
    else:  # exact
        start_dt = recorded_dt - timedelta(seconds=0.5)
        end_dt = recorded_dt + timedelta(seconds=0.5)

    # Apply time zone
    if tz != 'UTC':
        tz_info = ZoneInfo(tz)
        if tz == 'Europe/Berlin' and recorded_dt.replace(tzinfo=tz_info).astimezone(ZoneInfo('UTC')).hour == 2:
            # DST fold: create two intervals (UTC+1 and UTC+2)
            utc_start1 = (start_dt.replace(tzinfo=ZoneInfo('Europe/Berlin')) - timedelta(hours=2)).replace(tzinfo=None)
            utc_end1 = (end_dt.replace(tzinfo=ZoneInfo('Europe/Berlin')) - timedelta(hours=2)).replace(tzinfo=None)
            utc_start2 = (start_dt.replace(tzinfo=ZoneInfo('Europe/Berlin')) - timedelta(hours=1)).replace(tzinfo=None)
            utc_end2 = (end_dt.replace(tzinfo=ZoneInfo('Europe/Berlin')) - timedelta(hours=1)).replace(tzinfo=None)
            return [f"{utc_start1.isoformat()}Z/{utc_end1.isoformat()}Z",
                    f"{utc_start2.isoformat()}Z/{utc_end2.isoformat()}Z"]

            end_dt = end_dt.replace(tzinfo=tz_info).astimezone(ZoneInfo('UTC')).replace(tzinfo=None)

    offset_low, offset_high = offset_bounds
    utc_start = start_dt - timedelta(seconds=offset_high)
    utc_end = end_dt - timedelta(seconds=offset_low)

    return [f"{utc_start.isoformat()}Z/{utc_end.isoformat()}Z"]

## 7. Governance Recommendation
1. **Timestamp Standards**:
   - Store all timestamps in **UTC** with **nanosecond precision** (even if rounded for display).
   - Retain **raw timestamps** (pre-rounding, pre-offset correction) with metadata (e.g., `raw_timestamp`, `display_rounded`, `clock_offset_applied`).

2. **Clock Synchronization**:
   - Deploy **NTP with logging** (e.g., `chrony` or `ntpd`) on all systems, with offset telemetry exported to a central monitor.
   - For high-trust systems (e.g., HUB), use **hardware clocks** (e.g., PTP) with ±10ms bounds.
   - For mobile/user-entered timestamps, **log device time + server time** at submission to bound entry delay.

3. **Time Zone and DST**:
   - Explicitly log **time zone and UTC offset** at event time (e.g., `Europe/Berlin+02:00`).
   - For DST transitions, **log the fold resolution** (e.g., `is_dst=true` or `utc_offset=+02:00`).
   - Avoid local time for critical events; use UTC internally.

4. **Lifecycle Semantics**:
   - Standardize **start/complete semantics** (e.g., `Investigation_Start` = first action, `Containment_Complete` = last action).
   - Use **causal identifiers** (e.g., `Alert_Received.causal_id = Investigation_Start.alert_id`) to enforce ordering.

5. **Provenance**:
   - Attach **source system metadata** to each timestamp (e.g., `source="OPS-BER"`, `rounding="floor_minute"`).
   - For inferred events (e.g., T-404 `Investigation_Start`), log the **inference method** and **uncertainty propagation**.

6. **Enforcement Policy**:
   - **CERTAIN_VIOLATION**: Automatically flag for review.
   - **POSSIBLE_VIOLATION**: Escalate if interval overlap with SLA boundary exceeds a **risk threshold** (e.g., >50% of the interval violates).
   - **INDETERMINATE**: Require additional evidence before enforcement.
   - **Interval Overlap**: Treat as **sufficient for compliance** only if the **entire interval** satisfies the SLA (CERTAIN_PASS). For POSSIBLE_VIOLATION, require manual review.

7. **Auditability**:
   - Maintain an **immutable timestamp audit log** with all corrections and inferences.
   - Provide a **queryable interface** for interval-based conformance checks (e.g., "Show all cases where S1 duration interval overlaps the 15-minute boundary").
