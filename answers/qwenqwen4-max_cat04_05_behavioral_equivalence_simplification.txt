Hence any A-only trace needs `#C  2  k  2  ||  3k+1 = 7`: **T1 is length-minimal for A\B**. T4 has length 4 and no shorter trace can differ (all traces of length  3 are `O … Z` with a single inner event, impossible in either model since a round needs `A` and `C`).

**Infinite families (unbounded proof).**
`{ O (AC)(R AC)^{k1} Z : k  2 }  L(A)\L(B)` and `{ O A (R A)^{k1} C Z : k  2 }  {O A P C Z}  L(B)\L(A)`. Non-equivalence is therefore *not* an artefact of the P3 bound.

**Effect of optional `Approve Revision` and hidden `tau`.**
`tau` is the skip branch of `X(P,tau)`; hiding it turns approval into  and adds **no** visible event, so it can never repair the `#C` mismatch (T1/T3 survive even if approvals are deleted from both models). Approvals *do* create an extra, independent discriminator: because A places `X(P,tau)` after the parallel pair while B runs `C` concurrently with the whole loop, `P  C` becomes possible only in B (T4). This difference persists if approvals are made mandatory (`O A P C Z` is still B-only). Conversely, T6 shows that the optional-approval mechanism is *not* the source of the P1-strict ordering problem: that comes from `+(A,C)` in A and from `C  loop` in B.

# 5. Bounded Comparison Code

Exhaustive BFS over markings. Silent transitions are fired without extending the trace; states are deduplicated on `(marking, visible trace)` — sound and complete because the future depends only on the marking and on the remaining budget, which is a function of the trace. Bounds are monotone, so prefix pruning loses nothing. Acceptance requires **exact final-marking equality** (no residual tokens).

```python
# bounded_compare.py  -- EXHAUSTIVE bounded visible-language comparison (P3)

from pm4py.objects.process_tree.obj import ProcessTree, Operator

                          'Approve Revision', 'Rework Case', 'Close Case')
MAX_VIS, MAX_ANA = 12, 3          # P3 bound

A_STR = ("->('Open Case', *(->(+('Analyze Revision','Check Revision'),"
         " X('Approve Revision', tau)), 'Rework Case'), 'Close Case')")
B_STR = ("->('Open Case', +('Check Revision', *(->('Analyze Revision',"
         " X('Approve Revision', tau)), 'Rework Case')), 'Close Case')")
S_STR = ("->('Open Case', *(->('Analyze Revision','Check Revision',"
         " X('Approve Revision', tau)), 'Rework Case'), 'Close Case')")

# ---------- parsing (with quote-style and programmatic fallbacks) ----------
def _leaf(l): return ProcessTree(label=l)
def _op(o, *kids):
    n = ProcessTree(operator=o); n.children = list(kids)
    for k in kids: k.parent = n
    return n

def _manual(which):
    if which == 'A':
        rnd = _op(Operator.SEQUENCE, _op(Operator.PARALLEL, _leaf(A_), _leaf(C_)),
                  _op(Operator.XOR, _leaf(P_), _leaf(None)))
        return _op(Operator.SEQUENCE, _leaf(O_),
                   _op(Operator.LOOP, rnd, _leaf(R_)), _leaf(Z_))
    if which == 'B':
        lp = _op(Operator.LOOP, _op(Operator.SEQUENCE, _leaf(A_),
                 _op(Operator.XOR, _leaf(P_), _leaf(None))), _leaf(R_))
        return _op(Operator.SEQUENCE, _leaf(O_),
                   _op(Operator.PARALLEL, _leaf(C_), lp), _leaf(Z_))
    rnd = _op(Operator.SEQUENCE, _leaf(A_), _leaf(C_),
              _op(Operator.XOR, _leaf(P_), _leaf(None)))
    return _op(Operator.SEQUENCE, _leaf(O_),
               _op(Operator.LOOP, rnd, _leaf(R_)), _leaf(Z_))

def parse_tree(s, which):
    for cand in (s, s.replace("'", '"')):
        try:    return pm4py.parse_process_tree(cand)
        except Exception: pass
    print(f"[warn] string parsing failed for {which}; using programmatic tree")
    return _manual(which)

# ---------- net helpers ----------
def silent(t):
    l = t.label
    return l is None or str(l).strip() == '' or str(l).lower().startswith('tau')

def keyfn(net):
    idx = {p: i for i, p in enumerate(net.places)}
    return lambda m: tuple(sorted((idx[p], c) for p, c in m.items() if c > 0))

def fire(m, t):
    nm = Marking(); nm.update(m)
    for a in t.in_arcs:
        nm[a.source] -= a.weight
        if nm[a.source] <= 0: del nm[a.source]
    for a in t.out_arcs:
        nm[a.target] = nm.get(a.target, 0) + a.weight
    return nm

def enabled(net, m):
    return pm4py.get_enabled_transitions(net, m)

# ---------- EXHAUSTIVE bounded language ----------
def bounded_language(net, im, fm, max_vis=MAX_VIS, max_ana=MAX_ANA):
    key, final = keyfn(net), keyfn(net)(fm)
    seen = {(key(im), ())}
    q, complete, dead, expanded = deque([(im, ())]), set(), [], 0
    while q:
        m, tr = q.popleft(); expanded += 1
        if key(m) == final:
            complete.add(tr)                      # exact final-marking equality
        en = enabled(net, m)
        if not en and key(m) != final:
            dead.append(tr)                       # bounded deadlock witness
        for t in en:
            if silent(t):
                ntr = tr                          # tau contributes epsilon
            else:
                lbl = str(t.label)
                if len(tr) + 1 > max_vis: continue
                if lbl == A_ and tr.count(A_) + 1 > max_ana: continue
                ntr = tr + (lbl,)
            nm = fire(m, t); k = (key(nm), ntr)
            if k in seen: continue                # handles silent cycles too
            seen.add(k); q.append((nm, ntr))
    return complete, dead, expanded, len(seen)

# ---------- exact membership (for regression traces) ----------
def accepts(net, im, fm, trace):
    key, final = keyfn(net), keyfn(net)(fm)
    seen = {(key(im), 0)}; q = deque([(im, 0)])
    while q:
        m, i = q.popleft()
        if i == len(trace) and key(m) == final: return True
        for t in enabled(net, m):
            if silent(t): ni = i
            else:
                if i >= len(trace) or str(t.label) != trace[i]: continue
                ni = i + 1
            nm = fire(m, t); k = (key(nm), ni)
            if k not in seen: seen.add(k); q.append((nm, ni))
    return False

# ---------- analytic cross-check of the exhaustive counts ----------
def count_A(max_vis=MAX_VIS, max_ana=MAX_ANA):   # rounds: 2 orders, optional P
    return sum(comb(k, a) * 2**k
               for k in range(1, max_ana + 1) for a in range(k + 1)
               if 3*k + 1 + a <= max_vis)

def count_B(max_vis=MAX_VIS, max_ana=MAX_ANA):   # 1 C inserted in 2k+a slots
    return sum(comb(k, a) * (2*k + a)
               for k in range(1, max_ana + 1) for a in range(k + 1)
               if 2*k + 2 + a <= max_vis)

def count_S(max_vis=MAX_VIS, max_ana=MAX_ANA):
    return sum(comb(k, a)
               for k in range(1, max_ana + 1) for a in range(k + 1)
               if 3*k + 1 + a <= max_vis)

def dashboard(tr):                                # P2 abstraction (strong form)
    proj = tuple(x for x in tr if x in (O_, A_, R_, Z_))
    return (proj, tr.count(A_), tr.count(R_) > 0, tr.count(C_) > 0)

if __name__ == "__main__":
```

# 6. Stochastic and Footprint Comparison

**Footprints (`pm4py.discover_footprints`).** A footprint matrix records only start/end label sets and pairwise relations (``, ``, `#`, ``) derivable from the length-2 factors of the language.

*Analytically expected result for the full models:* A and B share `A  C`, `C  R`, `A  R`, identical start/end sets; they differ **only in the {`Approve Revision`, `Check Revision`} cell**: in A only `C  P` occurs (`P` is always followed by `R` or `Z`), while in B both `C  P` and `P  C` occur (T4), i.e. `P  C`. So footprints *do* flag a difference here — but only via approval placement, **not** via the decisive check-cardinality defect.

*Why equal footprints prove nothing (concrete, using these very models):* delete `Approve Revision` from both trees. Then both have directly-follows set `{OA, OC, AC, CA, AR, CR, RA, RC, AZ, CZ}`, identical start `{O}` and end `{Z}`  **identical footprints**, yet `#C = #A` in A and `#C = 1` in B, so the languages remain incomparable (T1/T3 still separate them). A second minimal example: `->(a,b,a,b)` (language `{abab}`) and `*(->(a,b), tau)` (language `(ab)^+`) have identical footprints (`a  b`, start `a`, end `b`) and different languages. Footprints are a 2-factor abstraction: they cannot express cardinality, nesting scope, or long-distance dependencies.

**Stochastic language (`pm4py.get_stochastic_language`) and EMD (`pm4py.compute_emd`).** Both models have unbounded loops  infinite languages, so *any* computation must be truncated. **Declared probability policy (not measured, not fitted):** at each reachable marking, choose uniformly among *enabled transitions* (silent ones included), truncate at the P3 bound, discard mass that exceeds the bound or deadlocks, and renormalise over complete traces. This is a marking-level scheduler, so label-level probabilities are *not* uniform and differ between A and B purely because their routing nets differ.

```python
# stochastic_footprints.py -- assumes helpers from bounded_compare.py
from bounded_compare import *   # nets/trees helpers, bounds, declared policy

def bounded_stochastic_language(net, im, fm, max_vis=MAX_VIS, max_ana=MAX_ANA,
                                step_cap=500):
    """DECLARED policy: uniform over enabled transitions; truncated at P3 bound."""
    key, final = keyfn(net), keyfn(net)(fm)
    lang, lost = {}, 0.0
    stack = [(im, (), 1.0, 0)]
    while stack:
        m, tr, p, steps = stack.pop()
        if key(m) == final:
            lang[tr] = lang.get(tr, 0.0) + p; continue
        en = enabled(net, m)
        if not en or steps > step_cap:
            lost += p; continue
        w = p / len(en)
        for t in en:
            if silent(t):
                stack.append((fire(m, t), tr, w, steps + 1)); continue
            lbl = str(t.label)
            if len(tr) + 1 > max_vis or (lbl == A_ and tr.count(A_) + 1 > max_ana):
                lost += w; continue
            stack.append((fire(m, t), tr + (lbl,), w, steps + 1))
    tot = sum(lang.values())
    return {k: v / tot for k, v in lang.items()}, lost, tot

for name, s in (('A', A_STR), ('B', B_STR)):
    t = parse_tree(s, name); net, im, fm = pm4py.convert_to_petri_net(t)
    for obj in (t, (net, im, fm)):
        try:
            fp = pm4py.discover_footprints(obj)
            print(name, "footprints:", fp); break
        except Exception as e:
            print("footprints API variant:", e)
    sl, lost, mass = bounded_stochastic_language(net, im, fm)
    print(name, "traces:", len(sl), "discarded mass:", round(lost, 4))
    globals()['sl_' + name] = sl

try:
    print("EMD(A,B) =", pm4py.compute_emd(sl_A, sl_B))
except Exception as e:
    tv = 0.5 * sum(abs(sl_A.get(k, 0) - sl_B.get(k, 0))
                   for k in set(sl_A) | set(sl_B))
    print("compute_emd unavailable", e, "-> declared fallback total variation:", tv)
```

**Why a low EMD would still not establish trace equivalence.**
(i) EMD is a *distance between probability measures*, not between supports: a single compliance-critical trace such as T3 can carry tiny mass (it needs a specific interleaving of `C` past a `R`), so EMD can be small while a P1 violation is fully admitted. (ii) EMD depends on the *declared* scheduler; changing the silent-routing structure changes probabilities without changing the language — e.g. replacing `+(A,C)` in A by `X(->(A,C), ->(C,A))` preserves `L(A)` exactly yet changes the net's silent branching and hence EMD > 0 between two **trace-equivalent** models. (iii) Truncation makes the measure a bounded object, so EMD  0 is bounded, distribution-relative evidence only. Only EMD = 0 *with identical, untruncated supports* would coincide with language equality — and that situation is unreachable here because the languages are infinite and provably incomparable.

```python
from collections import Counter

def tree_metrics(t):
    nodes = ops = leaves = vis = sil = depth = 0
    labels = Counter()
    def walk(n, d):
        nonlocal nodes, ops, leaves, vis, sil, depth
        nodes += 1; depth = max(depth, d)

    dup = sum(c for c in labels.values() if c > 1)   # leaves sharing a label
    return dict(nodes=nodes, operators=ops, leaves=leaves, visible=vis,
                silent=sil, depth_edges=depth, distinct_labels=len(labels),
                duplicate_label_leaves=dup)
```

* A and B have **identical size** (12 nodes, 5 operators, 7 leaves, 6 visible labels, 0 duplicates). Therefore *no* size-based claim "B is simpler than A" is defensible; the only structural differences are **nesting order** (loop scope) and depth (A = 4, B = 5).

Since both nets have the same visible transition set and near-identical routing skeletons (one AND-split/join, one loop, one xor-skip), the values will be close; the metric is **blind to whether the AND-split sits inside or outside the loop**, i.e. blind to the entire P1 defect. Structural simplicity must never be used as a proxy for behavioural equivalence.

# 8. Simplified Model

**Target semantics: a declared compromise "P1-strict + P2", not P3-exact.**
Rationale: P1 carries the actual compliance obligation, P2 is a strict abstraction of it, and P3 is a *testing* view whose exact preservation would require keeping A's intra-round concurrency. I therefore make the round strictly sequential (`Analyze  Check  optional Approve`), which (a) keeps every P1 invariant, (b) additionally enforces the audit-friendly `A  C` ordering that **A itself violates**, (c) preserves P2 exactly, and (d) removes one operator level. The price is stated openly: `L(S)  L(A)`.

### 8.1 Expression

```text
->(
  'Open Case',
  *(
    ->('Analyze Revision', 'Check Revision', X('Approve Revision', tau)),
    'Rework Case'
  ),
  'Close Case'
)
```

Language: `O · (A C P?) · (R · A C P?)* · Z`.

**Why no strictly smaller model can preserve all three views (sketch, block-structured/POWL constructs).** P3-exactness w.r.t. A forces the round language to be exactly `{AC, CA, ACP, CAP}` and forces rounds to be separated by `R`. In POWL that round requires either `parallel(A,C)` + `xor(P,tau)` + a sequencing operator (3 operators — A's exact structure) or an explicit `X(->(A,C), ->(C,A))` + optional approval (4). Adding the enclosing loop and the outer sequence gives 5 operators, i.e. A's operator count. Hence A is already operator-minimal for its own visible language, and every genuinely smaller model must change the language — as S does. (This is an argument over block-structured constructs, not an exhaustive proof over arbitrary nets.)

**If the target were P2 only**, a far smaller model suffices: `->('Open Case','Check Revision', *('Analyze Revision','Rework Case'), 'Close Case')` — 7 nodes, 2 operators, depth 2, 5 visible leaves, 0 `tau`. It preserves `` exactly, but **loses P1 completely** (one check for many analyses, no approvals) and must never be used operationally. It is offered only to make the abstraction/size trade-off explicit.

# 9. Final Recommendation

* **P1 (operational compliance): use Model A, not Model B.** A guarantees `#Check = #Analyze = #Rework + 1` with each round's check completed before the round boundary; B guarantees only `#Check = 1` and lets that check float anywhere (T3), which is a structural compliance failure, not a rare edge case. If the auditors read P1 strictly (`Analyze  Check`), **neither original qualifies** (T6: `O C A Z` is admitted by both) — deploy **S**.
* **P2 (executive dashboard): A and B are equivalent only under the stated abstraction**, and this is proved unboundedly by the homomorphism `h` deleting `Check`/`Approve`/`tau` (`h(L(A)) = h(L(B)) = O A (R A)* Z`, with `#Check  1` always). Either model feeds the dashboard correctly; the 7-node P2-only model of §8 is sufficient and cheapest. **Warning:** dashboard equivalence is manufactured by discarding exactly the information P1 needs; it must never be cited to justify replacing A with B in the operational system.
* **P3 (bounded testing): not equivalent, decisively and exhaustively** (76 vs 85 traces, intersection 4). Any shared regression suite must contain T1/T3/T4; a suite that only exercises single-round cases (`k = 1`, no approval-before-check) would wrongly report agreement, because the whole intersection lives at `k = 1`.
* **Simplified model S:** recommended replacement **for A** in the compliance-facing implementation, conditional on the process owner accepting the loss of the `Check`-before-`Analyze` interleavings (63 of 76 bounded traces; N3 flips from positive to negative). S is smaller than **both** originals (11 nodes / 4 operators / depth 4 vs 12 / 5 / 4 and 12 / 5 / 5), preserves every P1 invariant and P2 exactly, and additionally enforces `A  C`. If those interleavings are contractually observable (strict P3 equivalence to A required), **keep A unchanged** — §8 argues A is already operator-minimal for its language. **Do not replace A by B under any view; B should be repaired by moving `Check Revision` inside the loop.**
* **Limits of bounded comparison.** All bounded numbers here are exhaustive *within* `12` visible events and `3` analyses, and nothing more: the bound already truncates A (the 3-round/3-approval trace of length 13 is excluded), and a defect that first appears at the fourth analysis or after an approval-heavy prefix would be invisible. Bounded equality is never a proof of unbounded equality; that is why the P1/P3 verdicts rest on invariants (`#C = #A` vs `#C = 1`) and explicit witnesses, and the P2 verdict rests on a homomorphism proof rather than on the bounded set comparison. Likewise, equal footprints (which occur here once approvals are hidden) and a low Earth Mover's Distance under a *declared* uniform-enabled scheduler are weak, abstraction-relative signals — neither can establish trace equivalence, and a low EMD can coexist with a fully admitted compliance violation.
