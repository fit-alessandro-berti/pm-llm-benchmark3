# 1. Data audit and estimands

**Queueing quantities & units**
- `arrivals`: daily case intake count (cases/day). Proxy for external arrival intensity $\lambda_{ext}$.
- `completed`: daily case closures count (cases/day). Proxy for system throughput $\lambda_{thr}$.
- `median_service_min` / `p90_service_min`: active handling times excluding queue wait. Units: minutes. Heavy-tailed distribution implied by p90/median ratios (1.8–2.5).
- `mean_wip`: mean number of cases in system (queue + service) from 15-min snapshots. Units: cases. Approximates $L$ in Little's Law.
- `staff_fte`: mean concurrent full-time-equivalent capacity. Units: FTE. 1 FTE  1 server operating 12h/day.
- `complex_pct`: share of multi-step variant arrivals. Units: %. Acts as a case-mix covariate affecting service time distribution.
- `outage_min`: system downtime. Units: minutes. Only observed on 2026-04-15 (180 min).
- `peak_08_10_pct`: share of daily arrivals in the 08:00–09:59 window. Units: %. Proxy for intraday burstiness.

**Opening-hours convention**
Service window: 07:00–19:00 (12 hours = 720 minutes). No service occurs outside this window. Daily aggregates collapse intraday dynamics; hourly vectors are provided for four representative days only.

**Limitations of aggregates**
- Daily totals mask intraday queue buildup/drain cycles.
- Median/p90 service times cannot substitute for mean service time $E[S]$ in queueing formulas without distributional assumptions.
- `completed`  `arrivals` due to overnight carryover; throughput and arrival rates diverge during backlog accumulation or depletion.
- `mean_wip` is a time-average of snapshots, not a case-average; it approximates $L$ only if the system is quasi-stationary within the day.
- No case IDs or event timestamps are provided, preventing exact flow-time or variant-level analysis.

**Five threats to naive inference**
1. **Pooling weekday/weekend**: Masks a ~2.5× demand gap and a ~2.4× capacity gap, creating false impressions of stable utilization.
2. **Substituting median for mean service time**: Queueing formulas require $E[S]$. With p90/median  2, $E[S]$ is likely 30–40% higher than the median, leading to systematic understaffing if medians are used.
3. **Ignoring carryover backlog**: Treating `completed` as daily throughput ignores that completions may be older cases. This distorts $\lambda$ and $W$ in Little's Law.
4. **Assuming i.i.d. daily points**: WIP and backlog exhibit strong serial dependence; daily observations are autocorrelated, violating standard regression/ANOVA assumptions.
5. **Simpson's paradox via regime mixing**: Pooled averages (e.g., WIP  28, completion  95) appear stable, but subgroups show degradation (weekday WIP rising to 45) and recovery (intervention dropping WIP to 32). Pooling obscures directional trends.

# 2. Pooled and regime summaries
regimes = {
    "Baseline Weekday": df[(df["date"].dt.dayofweek < 5) & (df["date"] < "2026-04-15")],
    "Outage/Recovery": df[(df["date"] >= "2026-04-15") & (df["date"] <= "2026-04-17")],
    "High-Complexity Weekday": df[(df["date"].dt.dayofweek < 5) & (df["date"] >= "2026-04-20") & (df["date"] < "2026-04-29")],
    "Intervention Weekday": df[(df["date"].dt.dayofweek < 5) & (df["date"] >= "2026-04-29")],
    "Weekend": df[df["date"].dt.dayofweek >= 5]
}

summary_rows = []
for label, sub in regimes.items():
    summary_rows.append({
        "Regime": label,
        "Days": len(sub),
        "Arr_Mean": sub["arrivals"].mean(),
        "Comp_Mean": sub["completed"].mean(),
        "Med_Svc": sub["median_service_min"].median(),
        "P90_Svc": sub["p90_service_min"].median(),
        "WIP_Mean": sub["mean_wip"].mean(),
        "FTE_Mean": sub["staff_fte"].mean(),
        "Complex_Mean": sub["complex_pct"].mean()
    })
summary_df = pd.DataFrame(summary_rows)
print("=== Regime Summaries ===")
print(summary_df.to_string(index=False))

# 3. Burstiness & serial dependence
hourly_apr7 = np.array([3,5,12,20,16,10,8,7,6,5,5,4])
hourly_apr21 = np.array([2,3,8,34,8,5,24,5,3,14,5,4])
fano_7 = np.var(hourly_apr7) / np.mean(hourly_apr7)
fano_21 = np.var(hourly_apr21) / np.mean(hourly_apr21)
cov_svc = df["median_service_min"].std() / df["median_service_min"].mean()
lag1_wip = df["mean_wip"].autocorr(lag=1)

print(f"\n=== Dispersion & Dependence ===")
print(f"Fano Factor (Apr 07): {fano_7:.2f}")
print(f"Fano Factor (Apr 21): {fano_21:.2f}")
print(f"Daily Service Time CoV: {cov_svc:.2f}")
print(f"Lag-1 WIP Autocorrelation: {lag1_wip:.2f}")

# 4. Change-point heuristic (rolling mean threshold on complex_pct)
df["complex_rolling"] = df["complex_pct"].rolling(window=3, min_periods=1).mean()
df["regime_flag"] = np.where(df["complex_rolling"] > 35, "High-Mix", "Low-Mix")
print(f"\n=== Change-Point Detection (Rolling Mean > 35) ===")
print(df[["date", "day", "complex_pct", "complex_rolling", "regime_flag"]].to_string(index=False))

# 5. Little's Law implied flow time (L/lambda) for selected windows
# Using completed as throughput proxy; WIP as L; result in days, converted to hours
ll_windows = {
    "Baseline Weekday": (df[(df["date"].dt.dayofweek < 5) & (df["date"] < "2026-04-15")]),
    "High-Complexity Weekday": (df[(df["date"].dt.dayofweek < 5) & (df["date"] >= "2026-04-20") & (df["date"] < "2026-04-29")]),
    "Intervention Weekday": (df[(df["date"].dt.dayofweek < 5) & (df["date"] >= "2026-04-29")])
}
ll_results = []
for name, sub in ll_windows.items():
    L = sub["mean_wip"].mean()
    lam = sub["completed"].mean()
    W_days = L / lam
    ll_results.append({"Window": name, "L_mean": L, "lambda_comp": lam, "W_days": W_days, "W_hours": W_days*24})
ll_df = pd.DataFrame(ll_results)
print(f"\n=== Little's Law Implied Flow Time ===")
print(ll_df.to_string(index=False))
