def linear_extension_traces(labels, preds):
    n = len(labels)
    out = set()
    def rec(done, word):
        if len(done) == n:
            out.add(tuple(labels[i] for i in word))
            return
        for i in range(n):
            if i not in done and preds[i] <= done:
                rec(done | {i}, word + [i])
    rec(frozenset(), [])
    return out

def _count(marking, place):
    try:
        return marking[place]
    except Exception:
        return 0


def marking_key(marking):
    return tuple(sorted((id(place), _count(marking, place))
                        for place in list(marking) if _count(marking, place) > 0))


def same_marking(a, b):
    return marking_key(a) == marking_key(b)


def fire(marking, transition):
    result = Marking()
    for place in list(marking):
        result[place] = _count(marking, place)
    for arc in transition.in_arcs:
        left = _count(result, arc.source) - arc.weight
        if left > 0:
            result[arc.source] = left
        else:
            try:
                del result[arc.source]
            except Exception:
                pass
    for arc in transition.out_arcs:
        result[arc.target] = _count(result, arc.target) + arc.weight
    return result

| **A (primary)** `POWL  accepting Petri net  BPMN` | `pm4py.convert_to_petri_net(source_powl)`  `pm4py.convert_to_bpmn(net_from_powl, im_from_powl, fm_from_powl)`  `pm4py.convert_to_petri_net(bpmn_from_net)` | Exactly one intermediate, and it is the only representation in which ANDjoin vs XORjoin, token counts, `SilentTransition` and loop scope are explicit and machinecheckable (`check_is_workflow_net`, `check_soundness`). No structural assumption (blockstructuredness) is imposed on the source | (i) `convert_to_bpmn` is a **marked-net** call, not a POWL call; if a given pm4py build routes it internally through a process tree, A silently inherits B’s fragility. (ii) NetBPMN must classify a node with two preset transitions as ANDjoin vs XORjoin; a placebased/arcweightblind mapping silently swaps `` and ``. (iii) BPMN does not constrain split/join pairing — the crossing gateways will render as an *unstructured* diagram | any exception inside either call; `check_is_workflow_net == False`; `check_soundness == False`; `im`/`fm` `None` or empty; visible-label drift; any §7 criterion |
| **B (secondary)** `POWL  accepting Petri net  process tree  BPMN` | `pm4py.convert_to_petri_net(...)`  `pm4py.convert_to_process_tree(net_from_powl, im_from_powl, fm_from_powl)`  `pm4py.convert_to_bpmn(tree)` | If it worked, the BPMN would be blockstructured and readable (wellnested gateway pairs) and the model would have a canonical tree serialisation | **The source is not seriesparallel.** `{Prepare Evidence, Assess Risk, Verification, Optional Legal}` induces an *N* (`Prepare<Verification`, `Assess<Verification`, `Assess<Legal`, with `PrepareAssess`, `PrepareLegal`, `VerificationLegal`). Equivalently, the SESE region between `Register` and `Release` is irreducible: the ANDsplit at `Assess Risk` and the ANDjoin at `Verification` cross the other split/join pair. No process tree can preserve *both* the trace language and the true concurrency | `convert_to_process_tree` raises  `conversion failed` (**expected, and the correct outcome**). *Alternative:* it returns a tree  that tree must be treated as `approximated`/`lost` until the §5 suite passes; a returned object is **not** evidence of fidelity |
| **C (diagnostic oracle)** `POWL  Petri  reachability graph  bounded visible LTS` | `pm4py.convert_to_reachability_graph(net, im, fm)` + `pm4py.get_enabled_transitions(net, marking)` | A second, independent oracle for the bounded visible language; exposes dead transitions, nonfinal “completed” markings and enabledness at `fm` | Reachability-graph node identity is *marking* identity and is not comparable across nets; loops make RGs unbounded in general (finite here) | `convert_to_reachability_graph` raises, or the two oracles disagree on the bounded trace set |
| **D (round-trip / drift detector)** `BPMN  accepting Petri net` (per produced BPMN) | `pm4py.convert_to_petri_net(bpmn_from_net)` and, if B succeeded, `pm4py.convert_to_petri_net(bpmn_from_tree)` | Detects whether the stakeholder artefact survives reimport; the only practical check that the *visual* model is not silently lossy | Second BPMN need not be graphequal; silent routing nodes are renumbered/renamed; loop shapes may be redrawn | label set differs, bounded trace set differs, `im`/`fm` `None`, or any §7 criterion |

**Primary pipeline: A.** It is the only pipeline that does not assume blockstructuredness of the source. B is retained precisely because its failure is informative: it is the machinecheckable proof that the model’s concurrency cannot be expressed as wellnested blocks.

*Explicitly not attempted:* `pm4py.convert_to_bpmn(source_powl)`. No POWLBPMN API is given, and inventing one would hide exactly the intermediate whose semantics we must audit.

# 3. Conversion Code

Block **A** below is the conversion, diagnostic and visualisation pipeline. Block **B** (§5) continues the same module.

```python
# =============================================================================
# 0. IMPORTS AND CONFIGURATION
# =============================================================================
from __future__ import annotations

import json
import os
import traceback
from collections import Counter, deque

import pm4py
from pm4py.objects.powl.obj import (
    StrictPartialOrder,
    OperatorPOWL,
    Transition,
    SilentTransition,
)
from pm4py.objects.process_tree.obj import Operator
from pm4py.objects.petri_net.obj import Marking

OUT_DIR = "conversion_audit_artifacts"

# Declared validation bounds (see §5).  MAX_VISIBLE = 14 and MAX_ITERATIONS = 3
# jointly cover *all* traces with at most 3 verification iterations, with or
# without Legal Review (5..5 + legal + (3k-1) loop events -> 7/8, 10/11, 13/14).
MAX_VISIBLE = 14
MAX_ITERATIONS = 3
MAX_SILENT_RUN = 32        # hard stop on one uninterrupted tau-stretch
MAX_STATES = 500_000       # hard safety budget

R, A, P, L, C, I, D, REL, AR = (
    "Register Change", "Assess Risk", "Prepare Evidence", "Legal Review",
    "Configure Trial", "Inspect Trial", "Correct Defect",
    "Release Change", "Archive Change",
)
KNOWN_LABELS = {R, A, P, L, C, I, D, REL, AR}


# =============================================================================
# 1. SOURCE MODEL (authoritative - unchanged)
# =============================================================================
register = Transition(label="Register Change")
assess_risk = Transition(label="Assess Risk")
prepare_evidence = Transition(label="Prepare Evidence")

legal_review = Transition(label="Legal Review")
skip_legal = SilentTransition()
optional_legal = OperatorPOWL(
    operator=Operator.XOR,
    children=[legal_review, skip_legal],
)

configure_trial = Transition(label="Configure Trial")
inspect_trial = Transition(label="Inspect Trial")
trial_body = StrictPartialOrder(nodes=[configure_trial, inspect_trial])
trial_body.order.add_edge(configure_trial, inspect_trial)

correct_defect = Transition(label="Correct Defect")
verification_loop = OperatorPOWL(
    operator=Operator.LOOP,
    children=[trial_body, correct_defect],
)

release_change = Transition(label="Release Change")
archive_change = Transition(label="Archive Change")

source_powl = StrictPartialOrder(
    nodes=[
        register, assess_risk, prepare_evidence, optional_legal,
        verification_loop, release_change, archive_change,
    ]
)
source_powl.order.add_edge(register, assess_risk)
source_powl.order.add_edge(register, prepare_evidence)
source_powl.order.add_edge(assess_risk, optional_legal)
source_powl.order.add_edge(assess_risk, verification_loop)
source_powl.order.add_edge(prepare_evidence, verification_loop)
source_powl.order.add_edge(optional_legal, release_change)
source_powl.order.add_edge(verification_loop, release_change)
source_powl.order.add_edge(release_change, archive_change)


# =============================================================================
# 2. SMALL TECHNICAL HELPERS
# =============================================================================
def unpack_accepting(result, origin):
    """Never assume a converter returns (net, im, fm) with non-null markings."""
    if isinstance(result, tuple):
        if len(result) == 3:
            net, im, fm = result
        elif len(result) == 2:
            net, im, fm = result[0], result[1], None
        else:
            raise TypeError(f"{origin}: unexpected return arity {len(result)}")
    else:
        net, im, fm = result, None, None
    return net, im, fm


def is_accepting(net, im, fm):
    return net is not None and im is not None and fm is not None and len(im) > 0 and len(fm) > 0


def normalise_bool(value):
    if isinstance(value, tuple):
        value = value[0] if value else False
    return bool(value)


def _count(marking, place):
    try:
        return marking[place]
    except Exception:
        return 0


def marking_key(marking):
    """Canonical, net-internal identity of a marking (place ids, zero entries dropped)."""
    return tuple(sorted((id(p), _count(marking, p)) for p in list(marking) if _count(marking, p) > 0))


def same_marking(a, b):
    return marking_key(a) == marking_key(b)


def marking_str(marking):
    return "{" + ", ".join(f"{getattr(p, 'name', p)}x{_count(marking, p)}" for p in list(marking)) + "}"


def fire(marking, transition):
    result = Marking()
    for p in list(marking):
        result[p] = _count(marking, p)
    for arc in transition.in_arcs:
        left = _count(result, arc.source) - arc.weight
        if left > 0:
            result[arc.source] = left
        else:
            try:
                del result[arc.source]
            except Exception:
                pass
    for arc in transition.out_arcs:
        result[arc.target] = _count(result, arc.target) + arc.weight
    return result


def visible_labels(net):
    return sorted({t.label for t in net.transitions if getattr(t, "label", None) not in (None, "")})


def silent_labels_in_net(net):
    return sorted({repr(t.label) for t in net.transitions if getattr(t, "label", None) in (None, "")})


# =============================================================================
# 3. DIAGNOSTICS ON EVERY ACCEPTING NET
# =============================================================================
def wf_and_soundness(net, im, fm, name):
    record = {
        "name": name,
        "produced": net is not None,
        "accepting": is_accepting(net, im, fm),
        "im": marking_str(im) if im is not None else None,
        "fm": marking_str(fm) if fm is not None else None,
        "places": len(net.places) if net is not None else None,
        "transitions": len(net.transitions) if net is not None else None,
        "silent_transitions": sum(1 for t in net.transitions
                                 if getattr(t, "label", None) in (None, "")) if net is not None else None,
        "visible_labels": visible_labels(net) if net is not None else None,
        "is_workflow_net": None,
        "sound": None,
        "sound_diagnostics": None,
        "notes": [],
    }
    if net is None:
        record["notes"].append("no net was produced by the converter")
        return record
    if im is None or fm is None:
        record["notes"].append("converter returned None for initial and/or final marking")
    elif len(im) == 0 or len(fm) == 0:
        record["notes"].append("initial and/or final marking is empty -> not an accepting net")

    try:
        record["is_workflow_net"] = normalise_bool(pm4py.check_is_workflow_net(net))
    except Exception as exc:
        record["notes"].append(f"pm4py.check_is_workflow_net raised {exc!r}")

    if im is not None and fm is not None:
        try:
            res = pm4py.check_soundness(net, im, fm, print_diagnostics=True)
            if isinstance(res, tuple):
                record["sound"] = normalise_bool(res[0])
                record["sound_diagnostics"] = repr(res[1])[:2000] if len(res) > 1 else None
            else:
                record["sound"] = normalise_bool(res)
        except Exception as exc:
            record["notes"].append(f"pm4py.check_soundness raised {exc!r}")
    return record


def footprints(net, im, fm):
    try:
        fp = pm4py.discover_footprints(net, im, fm)
    except Exception as exc:
        return {"error": repr(exc)}
    return norm_fp(fp)


def norm_fp(fp):
    if not isinstance(fp, dict):
        return {"error": f"unexpected footprints type {type(fp)}"}
    out = {}
    for k, v in fp.items():
        if isinstance(v, (set, frozenset, list, tuple)):
            items = [list(e) if isinstance(e, tuple) else e for e in v]
            out[k] = sorted(items, key=lambda x: json.dumps(x, sort_keys=True, default=str))
        else:
            out[k] = v
    return out


# =============================================================================
# 4. PIPELINE A : POWL -> accepting Petri net -> BPMN
#     PIPELINE B : POWL -> accepting Petri net -> process tree -> BPMN (may fail)
#     PIPELINE D : each BPMN -> accepting Petri net (round trip)
# =============================================================================
REPORT = {"pipelines": {}, "nets": [], "errors": [], "visuals": []}


def build_and_diagnose():
    os.makedirs(OUT_DIR, exist_ok=True)

    # ---- 1. POWL -> accepting Petri net (single, uninterpreted intermediate) ----
    net_from_powl = im_from_powl = fm_from_powl = None
    try:
        net_from_powl, im_from_powl, fm_from_powl = unpack_accepting(
            pm4py.convert_to_petri_net(source_powl), "convert_to_petri_net(source_powl)")
        REPORT["pipelines"]["A.powlnet"] = "ok"
    except Exception as exc:
        REPORT["errors"].append({"where": "POWL->Petri", "error": repr(exc),
                                 "traceback": traceback.format_exc()})
        REPORT["pipelines"]["A.powlnet"] = f"failed: {exc!r}"

    if not is_accepting(net_from_powl, im_from_powl, fm_from_powl):
        REPORT["errors"].append({"where": "POWL->Petri",
                                 "error": "result is not an accepting net (im/fm None or empty)"})
    REPORT["nets"].append(wf_and_soundness(net_from_powl, im_from_powl, fm_from_powl,
                                           "net_from_powl (POWL->Petri, canonical validation reference)"))

    # ---- 2. Pipeline A : accepting Petri net -> BPMN  (required call) ----
    bpmn_from_net = None
    try:
        bpmn_from_net = pm4py.convert_to_bpmn(net_from_powl, im_from_powl, fm_from_powl)
        REPORT["pipelines"]["A.bpmn"] = "ok"
    except Exception as exc:
        # NOT substituted by a lossy alternative: a failure here is a pipeline failure.
        REPORT["pipelines"]["A.bpmn"] = f"failed: {exc!r}"
        REPORT["errors"].append({"where": "Petri->BPMN (pipeline A)",
                                 "error": repr(exc), "traceback": traceback.format_exc(),
                                 "interpretation": ("if this build routes net->BPMN through a process "
                                                    "tree internally, pipeline A inherits pipeline B's "
                                                    "block-structuredness failure")})

    # ---- 3./4. Pipeline B : accepting Petri net -> process tree -> BPMN ----
    tree_from_net = bpmn_from_tree = None
    tree_error = None
    try:
        tree_from_net = pm4py.convert_to_process_tree(net_from_powl, im_from_powl, fm_from_powl)
        REPORT["pipelines"]["B.tree"] = "ok"
    except Exception as exc:
        tree_error = {"exception_type": type(exc).__name__, "message": str(exc),
                      "repr": repr(exc), "traceback": traceback.format_exc()}
        REPORT["pipelines"]["B.tree"] = f"conversion failed: {type(exc).__name__}: {exc}"
        REPORT["errors"].append({
            "where": "Petri->Tree (pipeline B)",
            "error": repr(exc),
            "interpretation": ("EXPECTED AND CORRECT. The sub-poset {Prepare Evidence, Assess Risk, "
                               "Verification, Optional Legal} induces an N and is therefore not "
                               "series-parallel; the net has crossing AND split/join regions and no "
                               "SESE decomposition between Register and Release. No process tree can "
                               "preserve both the trace language and the true concurrency. The exception "
                               "is recorded and interpreted, never suppressed."),
        })
    if tree_from_net is not None:
        # A returned object is NOT evidence of fidelity - it is audited in §5 like any other model.
        REPORT["pipelines"]["B.tree_note"] = ("tree object returned despite the N obstruction: "
                                              "treated as approximated/lost until §5 passes")
        try:
            bpmn_from_tree = pm4py.convert_to_bpmn(tree_from_net)
            REPORT["pipelines"]["B.bpmn"] = "ok"
        except Exception as exc:
            REPORT["pipelines"]["B.bpmn"] = f"failed: {exc!r}"
            REPORT["errors"].append({"where": "Tree->BPMN (pipeline B)", "error": repr(exc),
                                     "traceback": traceback.format_exc()})
    REPORT["pipelines"]["B.tree_exception"] = tree_error

    # ---- 5. Round trip: each produced BPMN -> accepting Petri net ----
    round_trips = {}
    for tag, bpmn in (("from_net", bpmn_from_net), ("from_tree", bpmn_from_tree)):
        if bpmn is None:
            round_trips[tag] = {"status": "not produced"}
            continue
        try:
            rt_net, rt_im, rt_fm = unpack_accepting(
                pm4py.convert_to_petri_net(bpmn), f"convert_to_petri_net(bpmn_{tag})")
            round_trips[tag] = {"status": "ok", "net": rt_net, "im": rt_im, "fm": rt_fm}
            REPORT["nets"].append(wf_and_soundness(rt_net, rt_im, rt_fm,
                                                   f"round-trip net (BPMN {tag} -> Petri)"))
        except Exception as exc:
            round_trips[tag] = {"status": f"failed: {exc!r}", "traceback": traceback.format_exc()}
            REPORT["errors"].append({"where": f"BPMN {tag} -> Petri", "error": repr(exc)})

    # process-tree intermediate -> net, so that it too gets diagnostics
    if tree_from_net is not None:
        try:
            t_net, t_im, t_fm = unpack_accepting(
                pm4py.convert_to_petri_net(tree_from_net), "convert_to_petri_net(tree_from_net)")
            round_trips["from_tree_net"] = {"status": "ok", "net": t_net, "im": t_im, "fm": t_fm}
            REPORT["nets"].append(wf_and_soundness(t_net, t_im, t_fm, "net from process-tree intermediate"))
        except Exception as exc:
            round_trips["from_tree_net"] = {"status": f"failed: {exc!r}"}
            REPORT["errors"].append({"where": "Tree -> Petri", "error": repr(exc)})

    models = {
        "net_from_powl": (net_from_powl, im_from_powl, fm_from_powl),
        "bpmn_from_net": bpmn_from_net,
        "tree_from_net": tree_from_net,
        "bpmn_from_tree": bpmn_from_tree,
        "round_trips": round_trips,
    }

    # ---- 6. footprints on every accepting net (cheap structural cross-check) ----
    for name, (n, i_, f_) in [("net_from_powl", models["net_from_powl"])] + [
        (f"round_trip.{k}", (v["net"], v["im"], v["fm"]))
        for k, v in round_trips.items() if v.get("status") == "ok"
    ]:
        REPORT.setdefault("footprints", {})[name] = footprints(n, i_, f_)

    # ---- 7. visualisations (PM4Py save functions) ----
    def _vis(fn, path, *args):
        try:
            fn(*args, path)
            REPORT["visuals"].append({"file": path, "status": "ok"})
        except Exception as exc:
            REPORT["visuals"].append({"file": path, "status": f"failed: {exc!r}"})

    _vis(pm4py.save_vis_powl, f"{OUT_DIR}/00_source_powl.png", source_powl)
    _vis(pm4py.save_vis_petri_net,
         f"{OUT_DIR}/01_net_from_powl__bound_k{MAX_ITERATIONS}.png",
         net_from_powl, im_from_powl, fm_from_powl)
    if bpmn_from_net is not None:
        _vis(pm4py.save_vis_bpmn,
             f"{OUT_DIR}/02_bpmn_from_net__bound_k{MAX_ITERATIONS}.png", bpmn_from_net)
    if tree_from_net is not None:
        _vis(pm4py.save_vis_process_tree,
             f"{OUT_DIR}/03_tree_from_net__UNTRUSTED.png", tree_from_net)
    if bpmn_from_tree is not None:
        _vis(pm4py.save_vis_bpmn,
             f"{OUT_DIR}/04_bpmn_from_tree__UNTRUSTED.png", bpmn_from_tree)
    for tag, v in round_trips.items():
        if v.get("status") == "ok":
            _vis(pm4py.save_vis_petri_net,
                 f"{OUT_DIR}/05_roundtrip_{tag}__bound_k{MAX_ITERATIONS}.png",
                 v["net"], v["im"], v["fm"])

    return models
```

# 4. Preservation and Loss Audit

> **Scope of the terms.** Terms describe *behavioural* fidelity only. Rendering fidelity is assessed separately in §6 and referenced here through the `ambiguous` term where the behaviour itself cannot be pinned down without inspecting the encoding. The table is the **apriori** audit; the §5 report regenerates it mechanically and upgrades `expected preserved`  `validated preserved` **only** where the corresponding witness/trace test actually passed. `conversion failed` in the `PetriTree` column is the predicted — and semantically correct — outcome.

Uncertainty: nothing forces a converter to keep a single start/end *event*; a BPMN with several end events yields a different final marking |

| **I-18** Gateway / routing-node semantics (readability of the rendering) | not tested | ambiguous | conversion failed | not tested | Behaviourally `not tested` in the two non-rendering columns. `ambiguous` is the whole point: see §6. A BPMN can roundtrip perfectly and still be read wrongly |

**True concurrency versus arbitrary interleaving.** POWL states a *partial order*: `Assess Risk` and `Prepare Evidence` are independent (a genuine step), and `Optional Legal` is independent of the whole verification block. An accepting Petri net represents this as independent enablement in a reachable marking — preserved as *step* semantics but immediately flattened into *interleaving* semantics by any trace-based instrument. Consequently: a trace comparison **cannot** distinguish “concurrent” from “two orderings chosen nondeterministically”. The only defensible evidence is (a) both orders present in the language **and** (b) the derived `parallel` relation (from the k=1 traces, where labels are unique) and (c) the reachability graph showing both continuations enabled at one marking. Even (a)+(b)+(c) do not establish pomset equality.

**The missing edge (`Optional Legal`  `Verification`) and the induced *N*.** On `{Prepare Evidence, Assess Risk, Verification, Optional Legal}` we have `Prepare < Verification`, `Assess < Verification`, `Assess < Legal`, and `Prepare  Assess`, `Prepare  Legal`, `Verification  Legal` — an induced **N**. Therefore the behaviour is **not seriesparallel** whenever `Legal Review` is taken (when it is skipped the residual visible pomset `(Assess  Prepare) ; Verification` *is* seriesparallel). Consequences:

* no process tree can preserve **both** the trace language and the concurrency;
* a tree that preserves the trace language must XORcasesplit on the order of `Assess` and `Prepare` — this admits all interleavings but destroys the step `{Assess, Prepare}` (`approximated` at best, `lost` at worst);
* a tree that preserves the concurrency must add an order edge and therefore reject `W-P3`, `W-P4` or `W-P5` (`lost`);
* a reduction-based `convert_to_process_tree` will in all likelihood get stuck and raise — the correct outcome (`conversion failed`).

def reference_model(k_iterations, legal):
    """Concrete event list + predecessor sets for one unrolling of the source POWL."""
    labels = [R, A, P] + ([L] if legal else [])
    loop = []
    for i in range(k_iterations):
        if i:
            loop.append(D)
        loop += [C, I]
    labels += loop + [REL, AR]

    n = len(labels)
    pos = {}
    for i, lab in enumerate(labels):
        pos.setdefault(lab, []).append(i)
    r, a, p = pos[R][0], pos[A][0], pos[P][0]
    l = pos[L][0] if legal else None
    rel, ar = pos[REL][0], pos[AR][0]
    loop_idx = [i for i, lab in enumerate(labels) if lab in (C, I, D)]

    preds = {i: set() for i in range(n)}
    for i in range(n):
        if i != r:
            preds[i].add(r)                    # Register Change is the unique minimum
    preds[l].add(a) if legal else None         # I-03: Legal enabled by Assess Risk
    preds[loop_idx[0]].add(a)                  # I-05: AND-join at verification entry
    preds[loop_idx[0]].add(p)
    for x, y in zip(loop_idx, loop_idx[1:]):
        preds[y].add(x)                        # I-07/I-08/I-10: loop word is a chain
    preds[rel].add(loop_idx[-1])               # I-11: join before Release
    if legal:
        preds[rel].add(l)
    preds[ar].add(rel)                         # I-12: Archive final
    return labels, preds


def _linear_extension_traces(labels, preds):
    n = len(labels)
    out = set()
    full = (1 << n) - 1

    def rec(done, word):
        if done == full:
            out.add(tuple(labels[i] for i in word))
            return
        for i in range(n):
            if not (done >> i) & 1 and all((done >> j) & 1 for j in preds[i]):
                rec(done | (1 << i), word + [i])

    rec(0, [])
    return out


def reference_traces(max_visible=MAX_VISIBLE, max_iterations=MAX_ITERATIONS):
    result = set()
    for k in range(1, max_iterations + 1):
        for legal in (False, True):
            labels, preds = reference_model(k, legal)
            if len(labels) > max_visible:
                continue
            result |= _linear_extension_traces(labels, preds)
    return result

INVARIANT_IDS = [f"I-{i:02d}" for i in range(1, 15)]


def check_trace(trace):
    """Return {invariant_id: bool}.  Independent of any converter."""
    t = tuple(trace)
    n = len(t)
    res = {k: True for k in INVARIANT_IDS}
    cnt = Counter(t)

    def bad(*ids):
        for i in ids:
            res[i] = False

    if n == 0 or t[0] != R or cnt[R] != 1:
        bad("I-01", "I-13")
    if cnt[AR] != 1 or (n and t[-1] != AR):
        bad("I-12")
    if any(cnt[x] != 1 for x in (A, P, REL)):
        bad("I-02", "I-13")
    unknown = set(t) - KNOWN_LABELS
    if unknown:
        bad("I-13", "I-14")
    if cnt[L] > 1:
        bad("I-03")
    if cnt[C] < 1 or cnt[C] != cnt[I]:
        bad("I-09")
    if cnt[D] != max(0, cnt[C] - 1):
        bad("I-08")
    if n < 3 or t[-2] != REL:
        bad("I-11")
        return res

    if L in cnt and t.index(L) <= t.index(A):
        bad("I-03")

    middle = list(t[1:-2])
    if L in cnt and middle.count(L) != 1:
        bad("I-03")
    stripped = [x for x in middle if x != L]
    try:
        first_c = stripped.index(C)
    except ValueError:
        first_c = len(stripped)
    head, loop = stripped[:first_c], stripped[first_c:]

    if sorted(head) != sorted([A, P]):
        bad("I-02", "I-05")
    if cnt[C] >= 1 and (t.index(C) <= t.index(A) or t.index(C) <= t.index(P)):
        bad("I-05")

    for pos_, lab in enumerate(loop):
        if lab == I and (pos_ == 0 or loop[pos_ - 1] != C):
            bad("I-07")
        if lab == D and (pos_ + 2 >= len(loop) or loop[pos_ + 1] != C or loop[pos_ + 2] != I):
            bad("I-08", "I-10")

    # full loop-word parse:  (C I) (D C I)*
    i, ok, first = 0, True, True
    while i < len(loop):
        if not first:
            if loop[i] != D:
                ok = False
                break
            i += 1
        if i + 1 >= len(loop) or loop[i] != C or loop[i + 1] != I:
            ok = False
            break
        i += 2
        first = False
    if not ok or i != len(loop):
        bad("I-10")
    return res

def explore_visible_traces(net, im, fm,
                           max_visible=MAX_VISIBLE,
                           max_iterations=MAX_ITERATIONS,
                           max_silent_run=MAX_SILENT_RUN,
                           max_states=MAX_STATES):
    """Enumerate *completed* visible traces of (net, im, fm).

    Enforced rules
      * transitions with label None or '' are hidden - they never enter a trace;
      * a trace is completed only if the reached marking equals fm EXACTLY
        (marking_key equality, zero entries dropped - see `fire`);
      * silent cycling cannot diverge: states are dominated on (marking, visible
        trace).  The future visible language of a state depends only on
        (marking, trace), so re-visiting the same pair is provably redundant and
        a tau-cycle is therefore cut after one lap.  A hard `max_silent_run`
        cap is kept as a second, independent stop;
      * a visible-length bound AND an explicit loop-iteration bound are enforced.

    Exhaustiveness: `exhaustive_within_declared_bounds` is True iff no accidental
    truncation (state budget or silent cap) occurred.  The enumeration is then
    exhaustive *for the declared bounds only* - i.e. for all traces with at most
    `max_iterations` verification iterations and at most `max_visible` visible
    events - and is NOT exhaustive over unbounded loop behaviour.
    """
    fm_key = marking_key(fm)
    traces, flags = set(), {"silent_truncation": False, "state_truncation": False,
                            "bound_pruning": False, "enabled_at_final_marking": []}
    queue = deque()
    queue.append((im, tuple(), 0))
    seen = {(marking_key(im), tuple())}

    while queue:
        marking, trace, silent = queue.popleft()
        if marking_key(marking) == fm_key:
            traces.add(trace)
            still = list(pm4py.get_enabled_transitions(net, marking))
            if still:
                flags["enabled_at_final_marking"].append(
                    sorted({(getattr(t, "label", None) or "tau") for t in still}))
        for t in pm4py.get_enabled_transitions(net, marking):
            label = getattr(t, "label", None)
            hidden = label is None or str(label).strip() == ""
            if hidden:
                if silent >= max_silent_run:
                    flags["silent_truncation"] = True
                    continue
                new_trace, new_silent = trace, silent + 1
            else:
                label = str(label)
                if len(trace) >= max_visible:
                    flags["bound_pruning"] = True
                    continue
                if label == C and trace.count(C) >= max_iterations:
                    flags["bound_pruning"] = True
                    continue
                new_trace, new_silent = trace + (label,), 0
            new_marking = fire(marking, t)
            key = (marking_key(new_marking), new_trace)
            if key in seen:
                continue
            if len(seen) >= max_states:
                flags["state_truncation"] = True
                continue
            seen.add(key)
            queue.append((new_marking, new_trace, new_silent))

    return {"traces": traces, "flags": flags, "states": len(seen),
            "bounds": {"max_visible": max_visible, "max_iterations": max_iterations,
                       "max_silent_run": max_silent_run, "max_states": max_states},
            "exhaustive_within_declared_bounds":
                (not flags["silent_truncation"]) and (not flags["state_truncation"])}
