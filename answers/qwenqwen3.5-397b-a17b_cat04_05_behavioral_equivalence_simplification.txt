# 1. Equivalence Notions

To determine equivalence, we must define the observation function $\mathcal{O}$ applied to the language of traces $L(M)$ generated by a model $M$.

- **Visible Trace Equivalence:**
  Two models are equivalent if their sets of visible traces are identical after projecting out silent transitions ($\tau$).
  $$ L_A \setminus \{\tau\} = L_B \setminus \{\tau\} $$
  Duplicate visible labels are distinguished by **occurrence position** in the trace sequence.

- **Bounded Visible-Language Equivalence (P3):**
  Equivalence is restricted to traces $t$ where the number of visible events $|t|_{vis} \le 12$ and the count of `'Analyze Revision'` $\le 3$.
  $$ \{ t \in L_A \setminus \{\tau\} \mid \text{bounds}(t) \} = \{ t \in L_B \setminus \{\tau\} \mid \text{bounds}(t) \} $$
  This is a necessary but not sufficient condition for unbounded equivalence.

- **Business-Relevant Equivalence (P1 - Compliance):**
  Equivalence holds if, for every trace, the constraint "every `'Analyze Revision'` is paired with a unique `'Check Revision'` within the same loop iteration" is satisfied or violated identically.
  Observation function $\mathcal{O}_{P1}(t)$ returns **Valid** if $\text{count}(\text{'Analyze'}) = \text{count}(\text{'Check'})$ and ordering constraints hold; otherwise **Invalid**.
  Models are equivalent if $\forall t, \mathcal{O}_{P1}(t, A) \iff \mathcal{O}_{P1}(t, B)$.

- **Abstracted Dashboard Equivalence (P2):**
  Equivalence holds under the projection $\mathcal{O}_{P2}(t)$ which maps a trace to a tuple:
  $$ (\text{StartsOpen}, \text{EndsClose}, \text{Count}(\text{'Analyze'}), \text{Count}(\text{'Rework'}), \text{Exists}(\text{'Check'})) $$
  Specific interleaving and exact counts of `'Check Revision'` (beyond 0 vs >0) are ignored.

# 5. Bounded Comparison Code

This script performs an exhaustive breadth-first search on the Petri Net markings to generate all visible traces up to the P3 bounds.

```python
import pm4py
from pm4py.objects.petri_net.utils.petri_utils import add_arc_from_to
from collections import deque

def parse_and_convert(tree_str):
    try:
        tree = pm4py.parse_process_tree(tree_str)
        net, im, fm = pm4py.convert_to_petri_net(tree)
        # Check soundness to ensure valid execution
        if not pm4py.check_soundness(net, im, fm):
            raise ValueError("Model is not sound")
        return net, im, fm
    except Exception as e:
        print(f"Error parsing model: {e}")
        return None, None, None

def get_visible_traces_bounded(net, im, fm, max_visible_length=12, max_analyze=3):
    """
    Exhaustive BFS over markings to find all visible traces within bounds.
    """
    traces = set()
    # Queue stores: (current_marking, current_trace_list, visible_count, analyze_count)
    queue = deque([(im, [], 0, 0)])
    visited_states = set()
    
    # We must track (marking, visible_count, analyze_count) to avoid infinite loops 
    # while allowing different paths to same marking with different trace histories if needed.
    # For exhaustive trace generation, we prune if we exceed bounds.
    
    while queue:
        marking, trace, v_len, a_count = queue.popleft()
        
        # Create a hashable state for pruning (marking + counts)
        # Note: For exhaustive trace set, we usually don't prune on marking alone 
        # if we want all paths, but to prevent infinite loops in bounded search, 
        # we rely on the visible length bound.
        state_key = (marking, v_len, a_count)
        if state_key in visited_states:
            continue
        visited_states.add(state_key)
        
        # Check if final marking reached
        if marking == fm:
            traces.add(tuple(trace))
            # Do not stop here, as there might be other paths to final marking
            # But usually in sound nets, we stop extending from final marking.
            continue
        
        if v_len >= max_visible_length:
            continue
            
        enabled = pm4py.get_enabled_transitions(net, marking)
        
        for trans in enabled:
            label = trans.label
            new_marking = pm4py.fire_transition(net, marking, trans)
            
            new_trace = trace[:]
            new_v_len = v_len
            new_a_count = a_count
            
            if label is not None and label != 'tau':
                new_trace.append(label)
                new_v_len += 1
                if label == 'Analyze Revision':
                    new_a_count += 1
            
            # Apply P3 Bounds
            if new_v_len <= max_visible_length and new_a_count <= max_analyze:
                queue.append((new_marking, new_trace, new_v_len, new_a_count))
                
    return traces

# Model Strings

# Execution

net_a, im_a, fm_a = parse_and_convert(model_a_str)
net_b, im_b, fm_b = parse_and_convert(model_b_str)

if net_a and net_b:
    traces_a = get_visible_traces_bounded(net_a, im_a, fm_a)
    traces_b = get_visible_traces_bounded(net_b, im_b, fm_b)
    
    unique_a = traces_a - traces_b
    unique_b = traces_b - traces_a
    
    print(f"Model A traces found: {len(traces_a)}")

    print(f"Traces unique to A (Count): {len(unique_a)}")
```
