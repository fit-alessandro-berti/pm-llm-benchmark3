## 1. Materiality Framework
**Severity Framework** (1–5 scale):
- **Control Objective Violation (COV)**: Severity 5 if core policy (P1–P4) is violated (e.g., payment without approval, fraud bypass). Severity 3–4 for edge-case violations (e.g., auto-approve with bank change).
- **Amount/Exposure**: Linear scaling for amounts > EUR 50,000 (high risk) or < EUR 1,000 (low risk). High-value cases (e.g., EUR 480K) default to severity 4 unless mitigated by evidence.
- **Reversibility**: Severity 5 if irreversible (e.g., paid claim without approval). Severity 3 if reversible but requires manual intervention (e.g., missing notification).
- **Timing**: Severity 4 if timing violations (e.g., payment before approval) or delays (e.g., notification >24h).
- **Customer/Regulatory Harm**: Severity 5 for fraud risk, 4 for compliance gaps (e.g., missing notification), 2 for cosmetic issues (e.g., telemetry).
- **Recurrence**: Severity adjusted +1 if pattern repeats (e.g., retry duplicates, auto-approve violations).
- **Evidence Reliability**: Confidence 1–5 (1 = unverifiable, 5 = documented). Severity capped at 3 if evidence is unreliable (e.g., verbal fraud check).
- **Model Scope**: Severity 5 for out-of-scope cases (e.g., denied/withdrawn claims) if model assumes payable-only flow.

**Confidence  Severity**:
- Confidence reflects *evidence quality* (e.g., signed adjuster report = high confidence; verbal check = low).
- Severity reflects *risk impact* (e.g., a high-confidence fraud bypass is severity 5; a low-confidence auto-approve violation may be severity 3).
