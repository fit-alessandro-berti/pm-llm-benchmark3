```python
from pm4py.objects.petri_net.obj import PetriNet, Marking

def is_enabled(net, marking, transition):
    # Assumes arc weight 1, as in this model.
    for arc in net.arcs:
        if arc.target is transition and isinstance(arc.source, PetriNet.Place):
            if marking.get(arc.source, 0) < 1:
                return False
    return True

def fire_transition(net, marking, transition_name):
    transition = next((t for t in net.transitions if t.name == transition_name), None)
    if transition is None:
        raise ValueError(f"No transition named '{transition_name}'")
    if not is_enabled(net, marking, transition):
        enabled_names = sorted(t.name for t in pm4py.get_enabled_transitions(net, marking))
        raise ValueError(f"Transition '{transition_name}' is not enabled in {marking}. Enabled: {enabled_names}")

    new_marking = Marking()
    for place, count in marking.items():
        new_marking[place] = count

    for arc in net.arcs:
        if arc.target is transition and isinstance(arc.source, PetriNet.Place):
            src = arc.source
            new_marking[src] = new_marking.get(src, 0) - 1
            if new_marking[src] <= 0:
                del new_marking[src]
    for arc in net.arcs:
        if arc.source is transition and isinstance(arc.target, PetriNet.Place):
            tgt = arc.target
            new_marking[tgt] = new_marking.get(tgt, 0) + 1
    return new_marking
```

```python
import pm4py
from pm4py.objects.petri_net.obj import PetriNet, Marking

def is_enabled(net, marking, transition):
    for arc in net.arcs:
        if arc.target is transition and isinstance(arc.source, PetriNet.Place):
            if marking.get(arc.source, 0) < 1:
                return False
    return True

def fire_transition(net, marking, transition_name):
    transition = next((t for t in net.transitions if t.name == transition_name), None)
    if transition is None:
        raise ValueError(f"Unknown transition: {transition_name}")
    if not is_enabled(net, marking, transition):
        enabled_names = sorted(t.name for t in pm4py.get_enabled_transitions(net, marking))
        raise ValueError(f"{transition_name} not enabled in {marking}. Enabled: {enabled_names}")
    new_marking = Marking()
    for place, count in marking.items():
        new_marking[place] = count
    for arc in net.arcs:
        if arc.target is transition and isinstance(arc.source, PetriNet.Place):
            source_place = arc.source
            new_marking[source_place] = new_marking.get(source_place, 0) - 1
            if new_marking[source_place] <= 0:
                del new_marking[source_place]
    for arc in net.arcs:
        if arc.source is transition and isinstance(arc.target, PetriNet.Place):
            target_place = arc.target
            new_marking[target_place] = new_marking.get(target_place, 0) + 1
    return new_marking

def print_enabled(net, marking):
    return sorted(t.name for t in pm4py.get_enabled_transitions(net, marking))

print("=== Original net: structural check ===")
```

| 1 | `t_register` | `{p_ready:1}` | `{t_split}` | Case registered. |
| 2 | `t_split` | `{p_analysis:1, p_review:1}` | `{t_analyze, t_standard_review, t_waive_review}` | AND split creates parallel tokens. |
| 3 | `t_waive_review` | `{p_analysis:1, p_waived:1}` | `{t_analyze, t_join_waived}` | Waiver selected; `t_join_waived` is already enabled although analysis is unfinished. |
| 4 | `t_join_waived` | `{p_analysis:1, p_decision:1}` | `{t_analyze, t_authorize}` | `t_authorize` is enabled before analysis. |
| 5 | `t_authorize` | `{p_analysis:1, sink:1}` | `{t_analyze}` | A token exists in `sink`, but the exact final marking `fm={sink:1}` is not reached because `p_analysis` still has a token. |
| 6 | `t_analyze` | `{p_analysis_done:1, sink:1}` | `{}` | `p_analysis_done` cannot be consumed: `t_join_normal` needs `p_review_done`, and `t_join_waived` needs `p_waived`. Deadlock prevents reaching `fm`. |

# 4. Minimal-Repair Alternatives

Edit-cost model: each arc addition or removal costs `1`; each place addition or removal costs `1`; each transition addition or removal costs `1`. Removing a node does not implicitly remove incident arcs; those arc removals are counted separately.

| Repair | Exact edits | Edit cost | Preserved intent | Changed behavior | New risk |
|---|---|---|---|---|---|
| A: Proper waiver join with analysis | Add arc `p_analysis_done -> t_join_waived`. | 1 | Yes. Analysis remains mandatory on both review routes; `p_waived` and `p_review_done` remain distinguishable. | `t_join_waived` now waits for both `p_waived` and `p_analysis_done`; `t_authorize` cannot fire on the waiver path until analysis is complete. | Low. Two silent joins share `p_analysis_done`, but only one review output can be produced, so they are never both enabled in the current reachable model. |
| B: Unified review-completion place | Remove `t_waive_review -> p_waived`; add `t_waive_review -> p_review_done`; remove `p_waived -> t_join_waived`; remove `t_join_waived -> p_decision`; remove place `p_waived`; remove transition `t_join_waived`. | 6 | Yes. Analysis remains mandatory because `t_join_normal` still requires `p_analysis_done`; waiver and standard both complete into `p_review_done`. | The marking can no longer distinguish waiver from standard review after review completion. Distinction survives only in the transition label/name. | Reduced auditability of the waiver state; any downstream state-based check for “waiver recorded” is lost. |

Justification of minimality:

- Repair A is globally minimal. Without any edits, the net fails on the waiver path because `t_join_waived` lacks the `p_analysis_done` input. Adding that one arc is the smallest possible structural change, and it directly enforces the missing synchronization.
- Repair B is not globally cost-minimal compared with A. It is minimal within the family that removes the duplicate waiver-only join and routes both review outcomes through the existing normal synchronization. Preserving workflow-net structure requires removing `p_waived` and `t_join_waived` as well as all their incident arcs, giving cost `6`.
- There is no zero-cost repair; some structural change is necessary.

# 6. Diagnostic and Reachability Code

```python
import pm4py
from pm4py.objects.petri_net.obj import PetriNet, Marking


def is_enabled(net, marking, transition):
    """Return True iff transition is enabled in marking, assuming arc weight 1."""
    for arc in net.arcs:
        if arc.target is transition and isinstance(arc.source, PetriNet.Place):
            if marking.get(arc.source, 0) < 1:
                return False
    return True


def fire_transition(net, marking, transition_name):
    """Fire a named transition after checking enabledness; return a new Marking."""
    transition = next((t for t in net.transitions if t.name == transition_name), None)
    if transition is None:
        raise ValueError(f"Unknown transition: {transition_name}")

    if not is_enabled(net, marking, transition):
        enabled_names = sorted(t.name for t in pm4py.get_enabled_transitions(net, marking))
        raise ValueError(
            f"{transition_name} not enabled in {marking}. Enabled: {enabled_names}"
        )

    new_marking = Marking()
    for place, count in marking.items():
        new_marking[place] = count

    # Consume tokens from input places.
    for arc in net.arcs:
        if arc.target is transition and isinstance(arc.source, PetriNet.Place):
            src = arc.source
            new_marking[src] = new_marking.get(src, 0) - 1
            if new_marking[src] <= 0:
                del new_marking[src]

    # Produce tokens in output places.
    for arc in net.arcs:
        if arc.source is transition and isinstance(arc.target, PetriNet.Place):
            tgt = arc.target
            new_marking[tgt] = new_marking.get(tgt, 0) + 1

    return new_marking


def enabled_names(net, marking):
    return sorted(t.name for t in pm4py.get_enabled_transitions(net, marking))


print("=== Original net ===")
print("workflow_net:", pm4py.check_is_workflow_net(net))
print("soundness_result:", pm4py.check_soundness(net, im, fm, print_diagnostics=True))

for t_name in ["t_register", "t_split", "t_waive_review", "t_join_waived", "t_authorize", "t_analyze"]:
    m = fire_transition(net, m, t_name)
    print(f"  after {t_name}: {m}; enabled={enabled_names(net, m)}")

print("Exact final marking fm reached?", m == fm, " fm is", fm)

rg_orig = pm4py.convert_to_reachability_graph(net, im, fm)
print("Original reachability graph created:", rg_orig is not None)

    m2 = fire_transition(repaired_net, m2, t_name)
    print(f"  after {t_name}: {m2}; enabled={enabled_names(repaired_net, m2)}")
```

# 7. Repair Trade-Offs and Residual Risks

- **Waiver and standard review distinguishability:**  
  Selected Repair A keeps `p_waived` distinct from `p_review_done`, so the marking distinguishes the two review outcomes. Fallback Repair B would collapse both outcomes into `p_review_done`, preserving distinction only through transition labels.

- **Silent transitions and potential confusion:**  
  Repair A keeps two silent joins, `t_join_normal` and `t_join_waived`. Both output to `p_decision`, so the marking after the join does not say which join occurred. However, because `p_review` contains one token and is consumed by exactly one of `t_standard_review` or `t_waive_review`, no reachable marking enables both silent joins simultaneously. The risk is low, but if the model is later extended to create both review tokens, nondeterminism could appear.

- **Soundness alone does not prove alignment with the business rule:**  
  Soundness checks proper completion and absence of leftover tokens, but it does not prove that every completed case contains an analysis event. A model could be sound but still violate a business rule, for example by relabeling an activity or adding a valid skip. Soundness must be complemented with trace-level checks.

- **Positive and negative regression traces:**
  - Positive standard path:  
    `t_register, t_split, t_analyze, t_standard_review, t_join_normal, t_authorize` should reach `{sink:1}`.
  - Positive waiver path:  
    `t_register, t_split, t_waive_review, t_analyze, t_join_waived, t_authorize` should reach `{sink:1}`.
  - Negative waiver path: after `t_waive_review`, `t_join_waived` must not be enabled until `t_analyze` has fired.
  - Negative standard path: after `t_register, t_split, t_analyze` without review, `t_authorize` must not become enabled.
  - Negative completed-case invariant: no reachable marking should contain a token in `sink` plus any non-sink place.

- **Detecting an accidental bypass of mandatory analysis:**  
  Traverse the reachability graph and check that no marking contains `sink` together with any of `p_analysis` or `p_analysis_done`. Also assert that `t_authorize` is never enabled while `p_analysis` or `p_analysis_done` is marked. For each path reaching `t_authorize`, require that `t_analyze` appears earlier in the trace.

# 8. Final Recommendation

Deploy Repair A. It is the globally minimal one-arc change, preserving all existing places, transitions, labels, and the explicit `p_waived` state. It directly enforces the missing causal dependency: the waiver join now waits for both the waiver outcome and the completed analysis. This keeps the standard and waiver review paths distinguishable and does not change the business policy.

Use Repair B as a fallback only if the team prefers a structurally simpler net with one review-completion place and is willing to lose the explicit `p_waived` marking. It is sound and preserves mandatory analysis, but it reduces downstream auditability.

Do not adopt an optional-analysis waiver policy without explicit business approval, because it would change the stated “analysis is always mandatory” intent.
