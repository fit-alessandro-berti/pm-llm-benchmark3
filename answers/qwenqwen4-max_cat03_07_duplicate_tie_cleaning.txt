```python
def _call(fn, *args, **kwargs):
    """Call a pm4py API across versions: drop kwargs it does not accept."""
    name = getattr(fn, "__name__", str(fn))
    try:
        sig = inspect.signature(fn)
        if not any(p.kind == p.VAR_KEYWORD for p in sig.parameters.values()):
            kwargs = {k: v for k, v in kwargs.items() if k in sig.parameters}
    except (TypeError, ValueError):
        pass
    return fn(*args, **kwargs)
```

```python
def api(name):
    fn = getattr(pm4py, name, None)
    if fn is None: raise RuntimeError(f"pm4py.{name} unavailable in this version")
    return fn

def call(fn, *args, **kwargs):
    try:
        pars = inspect.signature(fn).parameters
        if not any(p.kind == p.VAR_KEYWORD for p in pars.values()):
            kwargs = {k:v for k,v in kwargs.items() if k in pars}
    except (TypeError, ValueError): pass
    return fn(*args, **kwargs)
```

## 1. Duplicate-handling decision tree

The tree is evaluated **per candidate group**, never log-wide. A candidate group is `(activity, timestamp)`; it is then *partitioned* by the object IDs of **cardinality-bearing types** (`Item`, `Payment`) before any duplicate rule fires. This partition is the single most important guard in the pipeline.

```
Q0  Same source AND same source_event_key AND same payload_hash AND same timestamp?
    YES -> EXACT TECHNICAL DUPLICATE -> DROP (keep deterministic first; alias recorded)
    Same payload_hash, different key, same source -> QUARANTINE (possible re-keying)
Q1  Different sources, same label + timestamp, identical object sets,
    AND independent identity evidence (reconciliation report, invoice number, scan ID)?
    YES -> SAME PHYSICAL EVENT, MULTIPLE OBSERVATIONS
           -> MERGE ATTRIBUTES AND RELATIONS (per-attribute source authority,
              canonical eid + alias list, namespaced lineage for every value)
           Attribute authority not yet agreed? -> RETAIN BOTH with coref qualifier
Q2  One event is coarser (subset of objects), emitted by a downstream system,
    derived from a message (e06->e07, e13/e14->e15)?
    YES -> SUMMARY DERIVED FROM DETAIL
           -> RETAIN BOTH with abstraction qualifiers + derived_from link.
              NEVER union the detail's relations upward into the summary.
              Optional, only with documented one-transition evidence: collapse into detail.
Q3  Harmonization map shows two semantically different source activities mapped
    to one label (e08 release vs e09 acceptance)?
    YES -> HARMONIZATION COLLISION -> RETAIN BOTH WITH REFINED LABELS/QUALIFIERS
Q4  Same label + timestamp but different identity-bearing objects (I1 vs I2, M1 vs M2)?
    YES -> CONCURRENT SAME-LABEL DISTINCT EVENTS -> RETAIN BOTH UNCHANGED,
           mark concurrency_group; order deterministically only
Q5  Evidence conflicting, missing, or precedence graph cyclic -> QUARANTINE FOR REVIEW
VETO (applies to every merge branch): would the merge delete an object's only event,
    or reduce observed cardinality (2 Payments -> 1)? -> QUARANTINE, do not merge.
```

## 3. Timestamp-tie ordering rules

Ordering is a **partial order first**, total order second, synthetic timestamps last.

* **R1 – domain/lifecycle precedence (semantic).** Per object type: order creationvalidation; pick(I)pack(I); packreleaseacceptancehandoverdelivery confirmation; invoiceauthorizecapturebalance summary.
* **R2 – documented causal derivation (semantic).** e06e07, {e13,e14}e15 (fact 8), e09e10 (fact 5), e12e13 for M1 (fact 7).
* **R3 – within-source `source_seq` (semi-semantic).** Only comparable inside one source: e13e14 (PSP 401<402); e04e05 (SCANNER 551<552) which, after merging, becomes e03e05 via the alias's scanner sequence. Cross-source seq comparison is forbidden.
* **R4 – source-authority heuristic (semi-semantic, low confidence).** Optional orientation of retained co-referent pairs (issuing system before replicating system: e16e11). Off by default because fact 6 gives no derivation direction.
* **R5 – fixed source priority list (deterministic only).** ERP, WMS, SCANNER, CARRIER, PSP, BILLING. Arbitrary but stable.
* **R6 – lexicographic canonical eid (deterministic only).**

`ingested_at` is **excluded from the ordering key** entirely; it is forensic metadata. Implementation: build a DAG from R1–R4 inside each tie group, validate that no edge runs backwards across real timestamps (violation  quarantine, not silent reordering), then Kahn topological sort with a heap keyed `(R5 rank, min source_seq, eid)`. Every adjacency gets `order_basis  {semantic, source_seq, deterministic}` plus a `concurrency_group` so analytics can refuse to interpret deterministic-only adjacencies as precedence.

**Why microseconds first is damaging:** `ocel_add_index_based_timedelta` freezes whatever row order the dataframe currently has — typically insertion/ingestion order. That converts arbitrary adjacency into apparent precedence *and* nonzero durations, manufactures DFG edges (e.g. `Capture Payment  Issue Invoice`), and permanently destroys the evidence that events were concurrent. Semantic order must be decided while ties are still visible.

**Intended orders**

* **10:00** — `e03 (merged e03+e04)  e05  e06  e07`. Admissible alternative: `e05  e03  e06  e07` (picks genuinely concurrent; R3 gives only source-level order). Inadmissible: e06 before either pick, e07 before e06. In A/E: `e03  e05  e06`.
* **10:15** — `e08  e09  e10` (R1 on D1, R2 for e09e10). Admissible alternative if acceptance is treated as independent of release: `e09  e08  e10`; e10 is always last. In A: `e08(merged)  e10`.

6. **Link, don't fabricate:** `derived_from(e07)=[e06]`, `derived_from(e15)=[e13,e14]`, `coref_group(e11,e16)=INV-V1`, `concurrency_group(e03,e05)`.
7. **Order** per §3, sort by `order_index`, then apply index-based microseconds; record `synthetic_offset` and `timestamp_is_synthetic`.
8. **Validate** referential integrity, protected eids, per-object lifecycle monotonicity, provenance completeness.

**Retained count: 16 events, 41 E2O relations** (171; 443). Nothing else is deleted; concurrency, abstraction levels, and both invoice observations survive. Variant C2 (invoice authority agreed) = 15/39.

## 5. Aggressive alternatives

**E – evidence-based semantic merging.** C plus attribute-authoritative merge of e11/e16 (identity proven by V1). **15 events, 39 relations.** Optional E additionally collapses e06/e07 under an explicit "one business transition" assumption: **14/37**. Damage: E loses the ability to audit each system's invoice attributes as *separately observed* (mitigated by namespaced lineage); E deletes an abstraction level, removes the packstatus-update latency, and makes ERP-only packing statuses invisible when no WMS detail exists. e08/e09 and e13/e14/e15 are still never merged.

**A – mechanically aggressive PM4Py merging.** Protect `{e05, e14, e15}` by removing them from the working copy, run `pm4py.ocel_merge_duplicates(..., have_common_object=True)` on the remainder, re-inject the protected rows, repair relation unions and provenance. Merges e03/e04, e06/e07, e08/e09, e11/e16  **13 events, 34 relations**. Damage: the surviving Dispatch event keeps only one label, so *carrier acceptance disappears as a milestone*; the ERP packing status and one invoice observation vanish with their attributes (the library keeps the first row's attributes); dock dwell time and duplicate-billing signals become unmeasurable.

**Unguarded counterfactual (rejected, never published):** the same call log-wide yields **10 events, 28 relations**, swallowing e05 into e03 and e14/e15 into e13.

**Why `have_common_object=True` cannot protect e13/e14:** the flag tests *existence of any shared object*, and both captures share `O1` and `V1`. Those are the *context* objects every payment of this order touches; the discriminating objects are `M1` and `M2`. Common-object overlap is therefore maximal precisely where events are most clearly distinct. Worse, e15's object set `{O1,V1}` is a *subset* of both captures, so the predicate also pulls the invoice-level summary into the payment group. Protection requires equality of the **identity-bearing object signature**, plus a veto on cardinality reduction — not intersection.

```python
# =====================================================================
# OCEL cleaning / ordering sandbox -- pm4py >= 2.7 (OCEL 2.0 API)
# Assumes ocel_raw exists; ocel_raw.events carries source, source_event_key,
# source_seq, ingested_at, payload_hash. ocel_raw is NEVER mutated.
# =====================================================================
import copy, inspect, json
from collections import defaultdict
import heapq
import pandas as pd
import pm4py
from pm4py.objects.ocel.obj import OCEL

EID, ACT, TS = "ocel:eid", "ocel:activity", "ocel:timestamp"
OID, OTYPE, QUAL = "ocel:oid", "ocel:type", "ocel:qualifier"
IDENTITY_TYPES = ("Item", "Payment")                      # cardinality-bearing
SOURCE_PRIORITY = {"ERP": 0, "WMS": 1, "SCANNER": 2, "CARRIER": 3, "PSP": 4, "BILLING": 5}
AUDIT, SCENARIOS = [], {}
RAW_SNAPSHOT = copy.deepcopy(ocel_raw)                    # immutable fallback

STAGE = {"Create Order": 0, "Validate Order": 1, "Pick Item": 2, "Pack Package": 3,
         "Pack Package (ERP status update)": 4, "Release from Warehouse": 5,
         "Carrier Acceptance": 6, "Handover to Carrier": 7, "Issue Invoice": 8,
         "Issue Invoice (ERP view)": 8, "Issue Invoice (Billing SoR)": 8,
         "Authorize Payment": 9, "Capture Payment": 10,
         "Record Payment Summary (invoice level)": 11, "Confirm Delivery": 12}
FACT_EDGES = [("e09", "e10", "fact5"), ("e12", "e13", "fact7"),
              ("e06", "e07", "derivation"), ("e13", "e15", "fact8"), ("e14", "e15", "fact8")]
REFINED_COMMON = {"e07": "Pack Package (ERP status update)", "e08": "Release from Warehouse",
                  "e09": "Carrier Acceptance", "e15": "Record Payment Summary (invoice level)"}
REFINED_C = dict(REFINED_COMMON, **{"e11": "Issue Invoice (ERP view)",
                                    "e16": "Issue Invoice (Billing SoR)"})

# ---------- version-tolerant helpers -----------------------------------
def api(name):
    fn = getattr(pm4py, name, None)
    if fn is None:
        raise RuntimeError(f"pm4py.{name} not available in this version")
    return fn

def call(fn, *a, **kw):
    try:
        pars = inspect.signature(fn).parameters
        if not any(p.kind == p.VAR_KEYWORD for p in pars.values()):
            kw = {k: v for k, v in kw.items() if k in pars}
    except (TypeError, ValueError):
        pass
    return fn(*a, **kw)

def ev_frame(o):
    e = o.events
    return (e.reset_index() if EID not in e.columns else e).copy()

def rel_frame(o):
    r = o.relations
    if EID not in r.columns or OID not in r.columns:
        r = r.reset_index()
    r = r.copy()
    if QUAL not in r.columns:
        r[QUAL] = ""
    return r[[EID, OID, QUAL]]

def objs_per_event(o):
    d = defaultdict(set)
    for e, i in rel_frame(o)[[EID, OID]].itertuples(index=False):
        d[e].add(i)
    return d

def type_of(o):
    ob = o.objects
    ob = ob.reset_index() if OID not in ob.columns else ob
    return dict(zip(ob[OID], ob[OTYPE]))

def ident_sig(eid, omap, tmap):
    return tuple(sorted(x for x in omap.get(eid, ()) if tmap.get(x) in IDENTITY_TYPES))

def sub_ocel(o, eids):
    eids = set(eids)
    e, r = ev_frame(o), rel_frame(o)
    return OCEL(events=e[e[EID].isin(eids)].set_index(EID),
                objects=o.objects.copy(), relations=r[r[EID].isin(eids)].copy())

def bootstrap(o):
    e = ev_frame(o)
    for c in ("source", "source_event_key", "source_seq", "ingested_at", "payload_hash"):
        if c not in e.columns:
            raise KeyError(f"missing metadata column {c}")
    e["original_timestamp"] = e[TS]
    e["original_activity"] = e[ACT]
    e["refined_activity"] = e[ACT]
    e["canonical_eid"] = e[EID]
    e["source_eids"] = e[EID].apply(lambda x: [x])
    e["source_seq_index"] = e.apply(lambda r: [(r["source"], int(r["source_seq"]))], axis=1)
    for c, v in [("merge_rule", "none"), ("order_basis", ""), ("concurrency_group", ""),
                 ("coref_group", ""), ("derived_from", None), ("confidence", 1.0),
                 ("review_status", "accepted"), ("timestamp_is_synthetic", False)]:
        e[c] = v
    o.events = e.set_index(EID)
    return o

# ---------- 1. pre-check (inspect BEFORE acting) ------------------------
def candidate_groups(o, guard=True):
    e, omap, tmap = ev_frame(o), objs_per_event(o), type_of(o)
    buckets = defaultdict(list)
    for r in e.itertuples(index=False):
        buckets[(getattr(r, "_2", None) or r[1], r.original_timestamp)].append(r[0])
    out = []
    for (act, ts), members in buckets.items():
        if len(members) < 2:
            continue
        parts = defaultdict(list)
        for m in members:
            parts[ident_sig(m, omap, tmap) if guard else "UNGUARDED"].append(m)
        for sig, ms in parts.items():
            if len(ms) < 2:
                continue
            sets = {frozenset(omap[m]) for m in ms}
            out.append(dict(activity=act, timestamp=str(ts), members=sorted(ms), guard_key=sig,
                            identical_object_sets=len(sets) == 1,
                            sources=sorted({e.set_index(EID).loc[m, "source"] for m in ms})))
    return out

def precheck(o, label):
    guarded, unguarded = candidate_groups(o, True), candidate_groups(o, False)
    print(f"[precheck:{label}] guarded groups:")
    for g in guarded:
        print("   ", g)
    for g in unguarded:
        sigs = {ident_sig(m, objs_per_event(o), type_of(o)) for m in g["members"]}
        if len(sigs) > 1:
            print("    !! MUST-NOT-MERGE (distinct identity objects):", g["members"], sigs)
    return guarded

def exact_duplicate_groups(o):
    e = ev_frame(o)
    g = e.groupby(["source", "source_event_key", "payload_hash", "original_timestamp"])[EID]
    return [sorted(v) for _, v in g if len(v) > 1]

def drop_exact_duplicates_scoped(o):
    """ocel_drop_duplicates ONLY inside verified exact-technical-duplicate groups."""
    groups = exact_duplicate_groups(o)
    if not groups:
        print("[drop_duplicates] no exact technical duplicates -> not applied log-wide")
        st = sub_ocel(o, ["e01"])                                  # wiring self-test
        e = ev_frame(st)
        dup = e.iloc[[0]].copy(); dup[EID] = "e01_reingest"
        st2 = OCEL(events=pd.concat([e, dup]).set_index(EID),
                   objects=o.objects.copy(), relations=rel_frame(st))
        res = call(api("ocel_drop_duplicates"), st2, keep="first")
        assert len(ev_frame(res)) == 1, "scoped dedup self-test failed"
        print("[drop_duplicates] self-test OK (injected re-ingestion removed, scope=1 group)")
        return o
    keep = set(ev_frame(o)[EID])
    for grp in groups:
        res = call(api("ocel_drop_duplicates"), sub_ocel(o, grp), keep="first")
        survivors = set(ev_frame(res)[EID])
        for lost in set(grp) - survivors:
            keep.discard(lost)
            AUDIT.append(dict(rule="exact_technical_duplicate", canonical=sorted(survivors)[0],
                              dropped=lost, original_rows=ev_frame(o).set_index(EID)
                              .loc[[lost]].to_dict("index"), confidence=1.0))
    return sub_ocel(o, keep)

# ---------- 2. verified-pair merge (custom, lossless) -------------------
def verified_pair_merge(o, keep, drop, rule_id, authority, evidence, confidence,
                        reviewer="rule-engine-v1", allow_subset=False):
    e = ev_frame(o).set_index(EID)
    omap, tmap = objs_per_event(o), type_of(o)
    if keep not in e.index or drop not in e.index:
        raise KeyError("unknown eid")
    if e.loc[keep, ACT] != e.loc[drop, ACT]:
        raise ValueError("label mismatch: harmonization collision is not a duplicate")
    if e.loc[keep, "original_timestamp"] != e.loc[drop, "original_timestamp"]:
        raise ValueError("timestamp mismatch")
    if not allow_subset and omap[keep] != omap[drop]:
        raise ValueError("object sets differ -> summary/derivation case, not a verified pair")
    if ident_sig(keep, omap, tmap) != ident_sig(drop, omap, tmap):
        raise ValueError("identity-bearing objects differ -> VETO")
    lost_events = set(rel_frame(o)[EID]) - {keep, drop}
    if any(omap[x] <= omap[drop] and not (omap[x] <= omap[keep]) for x in lost_events):
        raise ValueError("merge would orphan an object -> VETO")

    conflicts, lineage = [], {}
    for c in e.columns:
        if c in {EID, ACT, TS, "source_eids", "source_seq_index", "canonical_eid"}:
            continue
        vk, vd = e.loc[keep, c], e.loc[drop, c]
        sk, sd = e.loc[keep, "source"], e.loc[drop, "source"]
        lineage[c] = {sk: str(vk), sd: str(vd)}
        if pd.notna(vk) and pd.notna(vd) and str(vk) != str(vd):
            winner = authority.get(c, sk)
            e.loc[keep, c] = vk if winner == sk else vd
            conflicts.append(dict(attr=c, kept_from=winner, values={sk: str(vk), sd: str(vd)}))
        e.loc[keep, f"{c}__{sd}"] = vd
    e.loc[keep, "source_eids"] = list(e.loc[keep, "source_eids"]) + list(e.loc[drop, "source_eids"])
    e.loc[keep, "source_seq_index"] = (list(e.loc[keep, "source_seq_index"])
                                       + list(e.loc[drop, "source_seq_index"]))
    e.loc[keep, "merge_rule"] = rule_id
    e.loc[keep, "confidence"] = confidence

    r = rel_frame(o)
    moved = r[r[EID] == drop].copy(); moved[EID] = keep
    r = pd.concat([r[r[EID] != drop], moved], ignore_index=True)
    r = r.drop_duplicates(subset=[EID, OID, QUAL])
    AUDIT.append(dict(canonical_eid=keep, source_event_ids=[keep, drop], merge_rule=rule_id,
                      reviewer=reviewer, evidence=evidence, confidence=confidence,
                      original_activity=e.loc[keep, "original_activity"],
                      refined_activity=e.loc[keep, ACT],
                      original_timestamp=str(e.loc[keep, "original_timestamp"]),
                      attribute_lineage=lineage, discarded_conflicts=conflicts,
                      relations_from_drop=sorted(omap[drop]),
                      original_rows=e.loc[[keep, drop]].astype(str).to_dict("index")))
    o.events = e.drop(index=drop)
    o.relations = r
    return o

def refine(o, eid, label, reason):
    e = ev_frame(o).set_index(EID)
    e.loc[eid, ACT] = label; e.loc[eid, "refined_activity"] = label
    e.loc[eid, "merge_rule"] = f"label_refinement:{reason}"
    o.events = e
    AUDIT.append(dict(canonical_eid=eid, rule="label_refinement", reason=reason,
                      original_activity=e.loc[eid, "original_activity"], refined_activity=label))
    return o

def annotate(o, eids, column, value):
    e = ev_frame(o).set_index(EID)
    for x in eids:
        e.loc[x, column] = value
    o.events = e
    return o

# ---------- 3. partial order -> deterministic total order ---------------
def build_total_order(o):
    e = ev_frame(o).set_index(EID)
    omap, tmap = objs_per_event(o), type_of(o)
    edges, basis = defaultdict(set), {}
    def add(a, b, kind):
        if a in e.index and b in e.index and a != b:
            if e.loc[a, "original_timestamp"] > e.loc[b, "original_timestamp"]:
                raise ValueError(f"constraint {a}->{b} contradicts timestamps: QUARANTINE")
            edges[a].add(b); basis[(a, b)] = kind
    for a, b, k in FACT_EDGES:
        add(a, b, "semantic:" + k)
    ids = list(e.index)
    for i in ids:                                       # lifecycle on shared objects
        for j in ids:
            if i == j or e.loc[i, "original_timestamp"] != e.loc[j, "original_timestamp"]:
                continue
            if omap[i] & omap[j]:
                si, sj = STAGE.get(e.loc[i, ACT], 99), STAGE.get(e.loc[j, ACT], 99)
                if si < sj:
                    add(i, j, "semantic:lifecycle")
    for i in ids:                                       # within-source sequence only
        for j in ids:
            if i == j:
                continue
            for s, q in e.loc[i, "source_seq_index"]:
                for s2, q2 in e.loc[j, "source_seq_index"]:
                    if s == s2 and q < q2:
                        add(i, j, "source_seq")
    indeg = {i: 0 for i in ids}
    for a, bs in edges.items():
        for b in bs:
            indeg[b] += 1
    def key(i):
        seqs = e.loc[i, "source_seq_index"]
        return (SOURCE_PRIORITY.get(e.loc[i, "source"], 99),
                min([q for _, q in seqs], default=10**9), str(i))
    heap = [key(i) + (i,) for i in ids if indeg[i] == 0]
    heapq.heapify(heap); order = []
    while heap:
        _, _, i = heapq.heappop(heap); order.append(i)
        for b in sorted(edges[i]):
            indeg[b] -= 1
            if indeg[b] == 0:
                heapq.heappush(heap, key(b) + (b,))
    if len(order) != len(ids):
        raise ValueError("precedence cycle -> quarantine group, do not force an order")
    e["order_index"] = pd.Series({x: k for k, x in enumerate(order)})
    e["order_basis"] = pd.Series({b: basis.get((a, b), "deterministic")
                                  for a, b in zip(order[:-1], order[1:])})
    o.events = e
    return o

def apply_deterministic_order(o, delta_us=1):
    o = build_total_order(o)
    try:
        o = call(api("ocel_sort_by_additional_column"), o,
                 column="order_index", column_key="order_index", reverse=False)
    except Exception as ex:
        print("[sort fallback]", ex)
        o.events = ev_frame(o).sort_values("order_index").set_index(EID)
    before = ev_frame(o).set_index(EID)["original_timestamp"].copy()
    try:                                    # ONLY now: order is already semantically fixed
        o = call(api("ocel_add_index_based_timedelta"), o, delta=delta_us)
    except Exception as ex:
        print("[timedelta fallback]", ex)
        e = ev_frame(o).set_index(EID)
        rank = e.groupby("original_timestamp")["order_index"].rank(method="first") - 1
        e[TS] = e["original_timestamp"] + pd.to_timedelta(rank * delta_us, unit="us")
        o.events = e
    e = ev_frame(o).set_index(EID)
    e["original_timestamp"] = before
    off = (e[TS] - e["original_timestamp"]).dt.total_seconds() * 1e6
    e["synthetic_offset_us"] = off
    e["timestamp_is_synthetic"] = off > 0
    assert off.max() < 1000, "synthetic offset must stay sub-millisecond"
    assert (e.sort_values("order_index")["original_timestamp"].is_monotonic_increasing)
    o.events = e
    return o

# ---------- 4. validation & metrics ------------------------------------
def validate(o, label, protected=("e05", "e14")):
    e, r = ev_frame(o), rel_frame(o)
    ob = o.objects; ob = ob.reset_index() if OID not in ob.columns else ob
    ids, oids = set(e[EID]), set(ob[OID])
    assert set(r[EID]) <= ids, "dangling E2O event reference"
    assert set(r[OID]) <= oids, "dangling E2O object reference"
    for p in protected:
        assert p in ids, f"protected event {p} was removed"
    for c in ("original_timestamp", "original_activity", "source", "source_event_key"):
        assert e[c].notna().all(), f"provenance column {c} lost"
    orphan = sorted(oids - set(r[OID]))
    tmap = type_of(o); ee = e.set_index(EID)
    for oid, grp in r.groupby(OID):
        seq = ee.loc[sorted(grp[EID], key=lambda x: ee.loc[x, "order_index"]), ACT]
        ranks = [STAGE.get(a, 99) for a in seq]
        assert ranks == sorted(ranks), f"lifecycle violation on {oid} ({tmap.get(oid)})"
    print(f"[validate:{label}] events={len(e)} relations={len(r)} orphan_objects={orphan}")
    return dict(events=len(e), relations=len(r), orphans=orphan)

def metrics(o, label):
    e, r, tmap = ev_frame(o), rel_frame(o), type_of(o)
    j = r.merge(e[[EID, ACT]], on=EID); j[OTYPE] = j[OID].map(tmap)
    etot = {f"{a}|{t}": int(n) for (a, t), n in j.groupby([ACT, OTYPE]).size().items()}
    otg = set()
    for _, grp in r.groupby(EID):
        ts = sorted({tmap[x] for x in grp[OID]})
        otg |= {(a, b) for i, a in enumerate(ts) for b in ts[i:]}
    dfgs = {}
    for t in ("Order", "Item", "Payment"):
        try:
            dfg, _, _ = pm4py.discover_dfg(pm4py.ocel_flattening(o, t))
            dfgs[t] = {f"{a}->{b}": int(c) for (a, b), c in dfg.items()}
        except Exception as ex:
            dfgs[t] = f"unavailable: {ex}"
    print(json.dumps(dict(label=label, events=len(e), relations=len(r),
                          et_ot=etot, otg=sorted(otg), dfg=dfgs), default=str, indent=1))
    return dfgs

def scenario_aggressive_library():
    """WARNING: pm4py.ocel_merge_duplicates keeps ONE row's attributes and merges on
    (activity, timestamp) + have_common_object. That predicate is NOT identity proof:
    e13/e14 share O1,V1 and e15's objects are a subset. e05/e14/e15 are therefore
    quarantined out of the working copy and re-injected afterwards."""
    o = bootstrap(copy.deepcopy(ocel_raw))
    for eid, lab in REFINED_COMMON.items():
        o = refine(o, eid, lab, "source-native semantics")
    protected = {"e05", "e14", "e15"}
    before = ev_frame(o).set_index(EID)
    work_ids = [x for x in before.index if x not in protected]
    merged = call(api("ocel_merge_duplicates"), sub_ocel(o, work_ids),
                  have_common_object=True, keep="first")
    me = ev_frame(merged).set_index(EID)
    survivors = set(me.index)
    key_of = lambda row: (row[ACT], row["original_timestamp"])
    bucket = {key_of(me.loc[s]): s for s in survivors}
    rel = rel_frame(merged)
    for lost in set(work_ids) - survivors:
        host = bucket[key_of(before.loc[lost])]
        add = rel_frame(o); add = add[add[EID] == lost].copy(); add[EID] = host
        rel = pd.concat([rel, add], ignore_index=True).drop_duplicates([EID, OID, QUAL])
        me.loc[host, "source_eids"] = list(me.loc[host, "source_eids"]) + [lost]
        me.loc[host, "merge_rule"] = "pm4py.ocel_merge_duplicates(have_common_object=True)"
        me.loc[host, "confidence"] = 0.5
        AUDIT.append(dict(canonical_eid=host, source_event_ids=[host, lost],
                          merge_rule="library_merge_guarded", reviewer="WARNING-lossy",
                          discarded_attributes=before.loc[lost].astype(str).to_dict(),
                          original_rows=before.loc[[host, lost]].astype(str).to_dict("index"),
                          confidence=0.5, reason="mechanical activity+timestamp+common object"))
    fin = pd.concat([me.reset_index(), before.loc[sorted(protected)].reset_index()])
    for c in before.columns:
        if c not in fin.columns:
            fin[c] = fin[EID].map(before[c])
    o.events = fin.set_index(EID)
    o.relations = rel
    o = annotate(o, ["e03", "e05"], "concurrency_group", "PICK-10:00")
    o = apply_deterministic_order(o)
    validate(o, "aggressive"); return o                        # 13 events / 34 relations

def reconstruct_raw(clean):
    """Lossless inverse: expand every canonical event into its source observations."""
    rows, rels = [], []
    raw_e = ev_frame(RAW_SNAPSHOT).set_index(EID)
    for r in ev_frame(clean).itertuples(index=False):
        for src_eid in r.source_eids:
            rows.append(raw_e.loc[src_eid])
    got = pd.DataFrame(rows)[[EID, ACT, TS]].sort_values(EID).reset_index(drop=True)
    exp = ev_frame(RAW_SNAPSHOT)[[EID, ACT, TS]].sort_values(EID).reset_index(drop=True)
    assert got.equals(exp), "round-trip failed -> audit trail incomplete"
    return copy.deepcopy(RAW_SNAPSHOT)

SCENARIOS["raw"] = bootstrap(copy.deepcopy(ocel_raw))
SCENARIOS["conservative"] = scenario_conservative()
SCENARIOS["evidence"] = scenario_evidence_merge()
SCENARIOS["aggressive"] = scenario_aggressive_library()
for k, v in SCENARIOS.items():
    metrics(v, k)
reconstruct_raw(SCENARIOS["aggressive"])
assert not ev_frame(ocel_raw).equals(ev_frame(SCENARIOS["conservative"]))  # raw untouched
```

## 7. Sensitivity analysis

| Dataset | Events | E2O | Character |
|---|---:|---:|---|
| raw | 17 | 44 | duplicate + collision + concurrency all present |
| conservative | 16 | 41 | one verified scan merge; labels refined; concurrency kept |
| evidence merge | 15 | 39 | + invoice merge (E 14/37 if packing collapsed) |
| aggressive (guarded) | 13 | 34 | 4 mechanical merges, attribute loss |
| unguarded (rejected) | 10 | 28 | e05, e14, e15 swallowed |

**Order-flattened DFG.** Six interpretation flips: (1) `Pick Item  Pick Item` self-loop falls 21 after the scan merge — raw overstates re-picking by 200%, truth is 0 real rework; (2) `Pack Package  Pack Package` (e06e07) exists in raw/C/E but vanishes in A/E — abstraction-level status update read as repacking; (3) `Dispatch Package  Dispatch Package` (e08e09) exists in raw/C/E, disappears in A, deleting the releaseacceptance handoff; (4) `Issue Invoice  Issue Invoice` (V1) is 1 in raw/C, 0 in E/A — the duplicate-billing signal is a *co-reference artifact*, correctly removed only with identity evidence; (5) `Capture Payment  Capture Payment` occurs twice (e13e14e15) and survives all guarded scenarios but becomes 0 unguarded, erasing split settlement; (6) an ingestion-ordered variant inserts `Capture Payment  Issue Invoice` and `Issue Invoice  Capture Payment` (e16 ingested 12:00:04), fabricating post-payment re-invoicing.

**Item-flattened.** I1's trace `Pick, Pick, Pack`  `Pick, Pack`: the I1 Pick self-loop disappears and per-item pick effort drops from 2 to 1 (raw inflates picking labour 50%). I2 stays `Pick, Pack` in every guarded scenario; if a merge kept only the first row's relations, e06 would lose I2 and I2's trace would end at Pick — a false "unpacked item".

**Payment-flattened.** M1 = `Authorize  Capture`; M2 = single `Capture` (a genuine missing-authorization control gap). Unguarded merging leaves M2 with **zero events**: relations may survive the union, so the OTG still looks intact while the Payment case disappears and the control gap becomes invisible.

**OC-DFG / ET–OT / OTG.** Typed edges `Pick Item --I1--> Pack Package` and `Capture Payment --M1--> ...` are stable; `Issue Invoice --V1--> Issue Invoice` disappears in E/A while `Capture Payment --V1--> Capture Payment` persists — same shape, opposite meaning, distinguishable only by identity type. ET–OT weights: Pick–Item 32 (C onward), Issue Invoice–Invoice 21 (E/A), Dispatch–Delivery 21 (A), Capture–Payment stays 2 guarded. OTG topology is robust (Order–Item, Item–Package, Item–Item via I1+I2 in e06, Order–Invoice, Invoice–Payment all persist), but the **OrderPayment cardinality** reads 1:2 in guarded views and effectively 1:1 unguarded.

**Lifecycle/performance.** O1 case duration stays 24 h in all scenarios (first/last events untouched), which is exactly why aggregate KPIs hide the damage. Stage durations inside ties are 0 s in reality; synthetic microseconds introduce 1–3 µs steps that must be excluded via `timestamp_is_synthetic`. Ingestion-based ordering would report a 55 s "packing overhead" (e06e07) and a 19 s dock dwell (e08e09); A removes the latter milestone entirely, making dock dwell unmeasurable rather than zero.

## 8. Audit trail and reversibility

Schema `event_provenance` (one row per canonical event per rule application, append-only): `canonical_eid`, `source_event_ids[]`, `source_systems[]`, `source_event_keys[]`, `source_seq_index[]`, `merge_rule_id`, `rule_version`, `reviewer`, `decision_class` (six terminal classes from §1), `original_activity`, `refined_activity`, `harmonization_map_version`, `original_timestamp`, `ordering_timestamp`, `synthetic_offset_us`, `order_index`, `order_basis`, `concurrency_group`, `coref_group`, `derived_from[]`, `attribute_lineage` (JSON: attribute  {source  value, authority_rank, winner}), `discarded_conflicts` (JSON), `relation_delta` (added/removed triples with contributing source), `confidence`, `reason`, `evidence_ref` (reconciliation report ID, invoice number), `raw_snapshot_hash`. Companion tables: `relation_provenance`, `decision_log`, `object_alias`.

Reconstruction: every merge is a **union with namespacing**, never a destructive overwrite; every discarded value is stored. `reconstruct_raw` expands each canonical event by `source_eids`, restores per-source activity, timestamp, attributes and relation sets from the lineage/snapshot, and asserts multiset equality with the raw snapshot on `(eid, activity, timestamp)` plus per-event relation sets. Because rule application is versioned and append-only, an analyst can also replay to any intermediate scenario, or re-run with a different authority map, without re-extracting from source systems.

## 9. Failure modes and safeguards

| Failure mode | Safeguard |
|---|---|
| Collapsing distinct partial payments (e13/e14) | identity-signature partition on `Payment`; cardinality-reduction veto; assert e14 present |
| Abstraction updates read as rework (e06/e07, e15) | `derived_from` links + abstraction qualifiers; report Pack/Capture self-loops separately as "status-update edges" |
| Ordering by `ingested_at` | ingestion excluded from ordering key; regression test showing the fabricated `Capture  Issue Invoice` edge |
| Shared objects treated as duplication proof | `have_common_object` never used as evidence; only equality of identity-bearing object sets plus external identity evidence |
| Unioning incompatible E2O relations (adding M1/M2 to e15, or I1/I2 to e07) | merges allowed only for equal object sets (or documented detail-collapse); summaries never inherit detail relations |
| Durations changed by synthetic microseconds | semantic order first; `original_timestamp` + `synthetic_offset_us` + `timestamp_is_synthetic`; sub-ms assertion; exclude synthetic gaps from performance metrics |
| Losing source-authoritative attributes | per-attribute authority map, `attr__source` namespacing, `discarded_conflicts`; library merges flagged lossy and repaired from the pre-merge copy |
| Applying duplicate functions log-wide without inspection | pre-check report + scoped sub-OCEL application + protected-row quarantine and re-injection |
| Cross-source `source_seq` comparison | sequence edges only within identical `source` |
| Orphan objects / dangling relations after drops | post-change referential-integrity and orphan-object assertions; per-object lifecycle monotonicity check |
| Precedence cycles or constraints contradicting timestamps | cycle detection  quarantine, never forced ordering |
| Non-idempotent / order-dependent re-runs | deterministic keys (R5/R6), versioned rules, append-only audit, round-trip reconstruction test |

No scenario claims to recover the true physical order; each publishes its assumptions, its retained event count, and the edges whose meaning it changes.
