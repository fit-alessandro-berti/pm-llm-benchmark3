# 1. Delay-decomposition definitions

For each case `c` and branch `i  {A,B,C}`, define:

- **Upstream elapsed**: `upstream_elapsed(c) = fork_release(c) - arrival(c)`
  *Time before any branch work begins.*

- **Branch queue delay**: `queue_i(c) = max(fork_release(c), branch_start_i(c)) - fork_release(c)`
  *Time spent waiting in branch `i`'s queue after `fork_release`.*

- **Branch service time**: `service_i(c) = branch_end_i(c) - branch_start_i(c)`
  *Active processing time for branch `i`.*

- **Branch completion time**: `completion_i(c) = branch_end_i(c)`
  *When branch `i` finishes (including queue + service).*

- **Join-ready time**: `join_ready(c) = max(completion_A(c), completion_B(c), completion_C(c))`
  *Latest branch completion (synchronization point).*

- **Branch synchronization wait**: `sync_wait_i(c) = join_ready(c) - completion_i(c)`
  *Time branch `i` waits after finishing until `join_ready`.*
  *Summing all `sync_wait_i(c)` would double-count the elapsed time between the last branch completion and `join_ready` (since it is counted for all branches that finish before the last one).*

- **Downstream queueing**: `downstream_queue(c) = final_start(c) - join_ready(c)`
  *Time spent waiting in the final-station queue after `join_ready`.*

- **Final service time**: `final_service(c) = final_end(c) - final_start(c)`
  *Active processing time at the final station.*

- **Total flow time**: `total_flow_time(c) = final_end(c) - arrival(c)`
  *End-to-end time from arrival to release.*
