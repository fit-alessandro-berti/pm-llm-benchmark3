# 2. Candidate Conversion Pipelines

Because PM4Py provides `POWL  accepting Petri net` and `accepting Petri net / process tree  BPMN` (and does not provide a direct `POWL  BPMN` API), every candidate pipeline routes through an accepting Petri net first.

| :--- | :--- | :--- | :--- | :--- |

| **Pipeline B (Secondary / Audit):** `POWL  accepting Petri net  process tree  BPMN` | `pm4py.convert_to_petri_net(source_powl)`  `pm4py.convert_to_process_tree(net_from_powl, im_from_powl, fm_from_powl)`  (if successful) `pm4py.convert_to_bpmn(tree_from_net)` | If a process tree existed faithfully, `tree  BPMN` would guarantee clean, well-nested, block-structured BPMN gateways and structural soundness by construction. | **High risk of structural infeasibility or silent approximation.** A unique-label process tree (series-parallel operators only) cannot faithfully encode the N-shaped partial order in `source_powl` without duplicating activity labels or adding/removing ordering constraints. | `pm4py.convert_to_process_tree(...)` raises an exception (expected faithful refusal on a non-block-structured net), **or** succeeds only by approximating behavior / duplicating labels (detected and rejected by round-trip validation). |

**Primary pipeline selection:** **Pipeline A (`POWL  accepting Petri net  BPMN`)** is selected as the primary pipeline because `source_powl` is intentionally non-series-parallel. Pipeline B is retained strictly as a structural audit probe: its failure is informative evidence that the source model exceeds block-structured process-tree expressiveness, whereas an unexpected success would require heightened scrutiny for hidden semantic approximation.

The following self-contained Python script builds `source_powl`, executes both candidate pipelines with explicit marking checks and exception interpretation, round-trips every produced BPMN model back to an accepting Petri net, runs workflow-net and soundness diagnostics on every accepting net, and saves visual artifacts with unambiguous filenames.

```python
from __future__ import annotations

from dataclasses import dataclass, field
from pathlib import Path
from typing import Any, Dict, Optional, Tuple

import pm4py
from pm4py.objects.powl.obj import (
    OperatorPOWL,
    SilentTransition,
    StrictPartialOrder,
    Transition,
)
from pm4py.objects.process_tree.obj import Operator


# ---------------------------------------------------------------------------
# 1. Authoritative Source POWL Definition
# ---------------------------------------------------------------------------
def build_source_powl() -> StrictPartialOrder:
    register = Transition(label="Register Change")
    assess_risk = Transition(label="Assess Risk")
    prepare_evidence = Transition(label="Prepare Evidence")

    legal_review = Transition(label="Legal Review")
    skip_legal = SilentTransition()
    optional_legal = OperatorPOWL(
        operator=Operator.XOR,
        children=[legal_review, skip_legal],
    )

    configure_trial = Transition(label="Configure Trial")
    inspect_trial = Transition(label="Inspect Trial")
    trial_body = StrictPartialOrder(nodes=[configure_trial, inspect_trial])
    trial_body.order.add_edge(configure_trial, inspect_trial)

    correct_defect = Transition(label="Correct Defect")
    verification_loop = OperatorPOWL(
        operator=Operator.LOOP,
        children=[trial_body, correct_defect],
    )

    release_change = Transition(label="Release Change")
    archive_change = Transition(label="Archive Change")

    source_powl = StrictPartialOrder(
        nodes=[
            register,
            assess_risk,
            prepare_evidence,
            optional_legal,
            verification_loop,
            release_change,
            archive_change,
        ]
    )

    source_powl.order.add_edge(register, assess_risk)
    source_powl.order.add_edge(register, prepare_evidence)
    source_powl.order.add_edge(assess_risk, optional_legal)
    source_powl.order.add_edge(assess_risk, verification_loop)
    source_powl.order.add_edge(prepare_evidence, verification_loop)
    source_powl.order.add_edge(optional_legal, release_change)
    source_powl.order.add_edge(verification_loop, release_change)
    source_powl.order.add_edge(release_change, archive_change)
    return source_powl


# ---------------------------------------------------------------------------
# 2. Defensive Helpers for Markings, Diagnostics, and Visualization
# ---------------------------------------------------------------------------
def validate_accepting_net(
    name: str, net: Any, im: Any, fm: Any
) -> Tuple[bool, str]:
    if net is None:
        return False, f"{name}: Petri net object is None."
    if im is None or fm is None:
        return False, f"{name}: Initial or final marking is None (im={im}, fm={fm})."
    im_tokens = sum(c for c in im.values() if c > 0)
    fm_tokens = sum(c for c in fm.values() if c > 0)
    if im_tokens == 0 or fm_tokens == 0:
        return (
            False,
            f"{name}: Empty marking detected (im_tokens={im_tokens}, fm_tokens={fm_tokens}).",
        )
    return True, f"{name}: Non-null net with |P|={len(net.places)}, |T|={len(net.transitions)}, im_tokens={im_tokens}, fm_tokens={fm_tokens}."


def run_net_diagnostics(name: str, net: Any, im: Any, fm: Any) -> Dict[str, Any]:
    report: Dict[str, Any] = {"name": name}
    valid, msg = validate_accepting_net(name, net, im, fm)
    report["valid_markings"] = valid
    report["marking_summary"] = msg
    print(f"[MARKING CHECK] {msg}")
    if not valid:
        report["is_workflow_net"] = False
        report["is_sound"] = False
        report["soundness_diagnostics"] = None
        return report

    try:
        is_wf = bool(pm4py.check_is_workflow_net(net))
    except Exception as exc:
        is_wf = False
        report["wf_error"] = f"{type(exc).__name__}: {exc}"
    report["is_workflow_net"] = is_wf
    print(f"[WF-NET CHECK] {name}: is_workflow_net={is_wf}")

    try:
        sound_res = pm4py.check_soundness(net, im, fm, print_diagnostics=True)
        if isinstance(sound_res, tuple):
            is_sound, diagnostics = bool(sound_res[0]), sound_res[1]
        else:
            is_sound, diagnostics = bool(sound_res), None
    except Exception as exc:
        is_sound, diagnostics = False, {"error": f"{type(exc).__name__}: {exc}"}
    report["is_sound"] = is_sound
    report["soundness_diagnostics"] = diagnostics
    print(f"[SOUNDNESS CHECK] {name}: is_sound={is_sound}")
    return report


def safe_save_vis(save_fn, *args, label: str, path: Path) -> None:
    try:
        save_fn(*args, str(path))
        print(f"[VIS SAVED] {label} -> {path}")
    except Exception as exc:
        print(f"[VIS WARNING] Failed to save {label} to {path}: {type(exc).__name__}: {exc}")


@dataclass
class ConversionArtifacts:
    source_powl: StrictPartialOrder
    net_from_powl: Any = None
    im_from_powl: Any = None
    fm_from_powl: Any = None
    bpmn_from_net: Any = None
    tree_from_net: Any = None
    tree_conversion_error: Optional[str] = None
    bpmn_from_tree: Any = None
    round_trip_nets: Dict[str, Tuple[Any, Any, Any]] = field(default_factory=dict)
    diagnostics: Dict[str, Dict[str, Any]] = field(default_factory=dict)


# ---------------------------------------------------------------------------
# 3. Pipeline Execution
# ---------------------------------------------------------------------------
def run_conversion_pipelines(output_dir: str = "conversion_artifacts") -> ConversionArtifacts:
    out = Path(output_dir)
    out.mkdir(parents=True, exist_ok=True)

    source_powl = build_source_powl()
    artifacts = ConversionArtifacts(source_powl=source_powl)

    safe_save_vis(
        pm4py.save_vis_powl,
        source_powl,
        label="source_powl",
        path=out / "01_source_powl.png",
    )

    # Step 1: POWL -> accepting Petri net
    net_from_powl, im_from_powl, fm_from_powl = pm4py.convert_to_petri_net(source_powl)
    artifacts.net_from_powl = net_from_powl
    artifacts.im_from_powl = im_from_powl
    artifacts.fm_from_powl = fm_from_powl

    artifacts.diagnostics["net_from_powl"] = run_net_diagnostics(
        "net_from_powl", net_from_powl, im_from_powl, fm_from_powl
    )

    if artifacts.diagnostics["net_from_powl"]["valid_markings"]:
        safe_save_vis(
            pm4py.save_vis_petri_net,
            net_from_powl,
            im_from_powl,
            fm_from_powl,
            label="net_from_powl",
            path=out / "02_net_from_powl.png",
        )
    else:
        raise RuntimeError(
            "Baseline POWL->Petri conversion did not return valid non-null markings."
        )

    # Step 2 (Pipeline A): accepting Petri net -> BPMN
    try:
        bpmn_from_net = pm4py.convert_to_bpmn(net_from_powl, im_from_powl, fm_from_powl)
        artifacts.bpmn_from_net = bpmn_from_net
        if bpmn_from_net is None:
            print("[PIPELINE A ERROR] convert_to_bpmn returned None.")
        else:
            safe_save_vis(
                pm4py.save_vis_bpmn,
                bpmn_from_net,
                label="bpmn_from_net",
                path=out / "03_pipelineA_bpmn_from_net.png",
            )
    except Exception as exc:
        print(f"[PIPELINE A ERROR] Petri->BPMN failed: {type(exc).__name__}: {exc}")

    # Step 3 (Pipeline B): accepting Petri net -> process tree (expected to fail or need audit)
    try:
        tree_from_net = pm4py.convert_to_process_tree(
            net_from_powl, im_from_powl, fm_from_powl
        )
        artifacts.tree_from_net = tree_from_net
        if tree_from_net is None:
            artifacts.tree_conversion_error = "convert_to_process_tree returned None."
            print(f"[PIPELINE B] {artifacts.tree_conversion_error}")
        else:
            print(f"[PIPELINE B] Process tree conversion succeeded: {tree_from_net}")
            print(
                "[PIPELINE B AUDIT NOTE] Because source_powl contains a non-series-parallel "
                "N-pattern, any returned process tree must be audited for label duplication "
                "or altered concurrency during round-trip validation."
            )
            safe_save_vis(
                pm4py.save_vis_process_tree,
                tree_from_net,
                label="tree_from_net",
                path=out / "04_pipelineB_tree_from_net.png",
            )

            # Step 4: If process tree succeeded, convert tree -> BPMN
            try:
                bpmn_from_tree = pm4py.convert_to_bpmn(tree_from_net)
                artifacts.bpmn_from_tree = bpmn_from_tree
                if bpmn_from_tree is not None:
                    safe_save_vis(
                        pm4py.save_vis_bpmn,
                        bpmn_from_tree,
                        label="bpmn_from_tree",
                        path=out / "05_pipelineB_bpmn_from_tree.png",
                    )
                else:
                    print("[PIPELINE B ERROR] convert_to_bpmn(tree_from_net) returned None.")
            except Exception as bpmn_exc:
                print(
                    f"[PIPELINE B ERROR] Tree->BPMN failed: "
                    f"{type(bpmn_exc).__name__}: {bpmn_exc}"
                )
    except Exception as exc:
        artifacts.tree_conversion_error = f"{type(exc).__name__}: {exc}"
        print(
            "[PIPELINE B EXPECTED FAILURE] convert_to_process_tree raised an exception:\n"
            f"  {artifacts.tree_conversion_error}\n"
            "  Interpretation: A faithful Petri net for source_powl is non-block-structured "
            "due to the N-pattern (Assess Risk -> Optional Legal, Assess Risk -> Verification, "
            "Prepare Evidence -> Verification, with no edge Prepare Evidence -> Optional Legal). "
            "Refusing conversion is preferable to silently approximating concurrency."
        )

    # Step 5 & 6: Round-trip each produced BPMN model -> accepting Petri net + diagnostics
    produced_bpmns = [
        ("pipelineA_roundtrip_from_bpmn_net", artifacts.bpmn_from_net, "06_pipelineA_roundtrip_net.png"),
        ("pipelineB_roundtrip_from_bpmn_tree", artifacts.bpmn_from_tree, "07_pipelineB_roundtrip_net.png"),
    ]

    for rt_name, bpmn_obj, vis_filename in produced_bpmns:
        if bpmn_obj is None:
            print(f"[ROUND-TRIP SKIPPED] {rt_name}: No BPMN model produced.")
            continue
        try:
            rt_net, rt_im, rt_fm = pm4py.convert_to_petri_net(bpmn_obj)
        except Exception as exc:
            print(f"[ROUND-TRIP ERROR] {rt_name} BPMN->Petri failed: {type(exc).__name__}: {exc}")
            artifacts.diagnostics[rt_name] = {
                "name": rt_name,
                "valid_markings": False,
                "is_workflow_net": False,
                "is_sound": False,
                "conversion_error": f"{type(exc).__name__}: {exc}",
            }
            continue

        diag = run_net_diagnostics(rt_name, rt_net, rt_im, rt_fm)
        artifacts.diagnostics[rt_name] = diag
        if diag["valid_markings"]:
            artifacts.round_trip_nets[rt_name] = (rt_net, rt_im, rt_fm)
            safe_save_vis(
                pm4py.save_vis_petri_net,
                rt_net,
                rt_im,
                rt_fm,
                label=rt_name,
                path=out / vis_filename,
            )

    return artifacts


if __name__ == "__main__":
    artifacts = run_conversion_pipelines()
```

# 4. Preservation and Loss Audit

Because this audit is compiled prior to executing Sections 3 and 5 in a live PM4Py runtime, no invariant is prematurely marked `validated preserved`. Ratings use strictly the seven permitted terms: `expected preserved` reflects formal-semantics expectations prior to testing; `ambiguous` denotes structural or visual ambiguity in the target notation; `conversion failed` marks the structurally expected refusal of `PetriTree` on the non-series-parallel WF-net; and `not tested` marks runtime-dependent round-trip checks that must pass Section 5 before promotion to `validated preserved`.

| Source invariant | POWLPetri | PetriBPMN | PetriTree | BPMN round trip | Evidence or uncertainty |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **INV-01:** Unique start (`Register Change` first) | `expected preserved` | `expected preserved` | `conversion failed` | `not tested` | POWL translation connects the unique source place to `R`. BPMN start event should map directly to `R`; must be verified by exact start-activity footprints and trace prefixes in Section 5. |
| **INV-02:** Unordered `Assess Risk` and `Prepare Evidence` (interleaving & concurrency) | `expected preserved` | `expected preserved` | `conversion failed` | `not tested` | Modeled via an AND-split after `R`. True simultaneity exists in both Petri nets and BPMN parallel gateways, though trace-only validation only confirms interleaving equivalence (`A` before `P` and `P` before `A`). |
| **INV-03:** `Legal Review` after `Assess Risk`, at most once | `expected preserved` | `expected preserved` | `conversion failed` | `not tested` | Causal dependency `A  optional_legal` maps to connecting place(s) in the Petri net and sequence flow in BPMN. Must confirm round-trip does not allow `L` before `A` or repeated `L`. |
| **INV-04:** Silent optionality (`XOR(Legal Review, tau)`) | `expected preserved` | `ambiguous` | `conversion failed` | `not tested` | Petri nets represent `skip_legal` explicitly as a `None`-labeled transition. In BPMN, a silent skip becomes an unlabeled XOR bypass arc that is easily misread visually and can introduce extra routing gateways on round-trip. |
| **INV-05:** N-pattern independence (no edge `P  optional_legal`, overlap with verification) | `expected preserved` | `ambiguous` | `conversion failed` | `not tested` | **Highest-risk structural invariant.** Petri nets express the N-pattern directly, whereas a unique-label process tree cannot (`PetriTree` is expected to fail; if a converter ever returned a tree, it would be `approximated` or `lost`). In BPMN, gateway wiring preserves it only if no spurious barrier join is inserted, and layout often looks falsely ordered. |
| **INV-06:** Synchronization of `A` and `P` before `Configure Trial` | `expected preserved` | `expected preserved` | `conversion failed` | `not tested` | Represented as an AND-join feeding `verification_loop`. Must be tested via negative witnesses (`<R, A, C, P, I, Rel, Arc>` and `<R, P, C, A, I, Rel, Arc>`). |
| **INV-07:** Binary loop scope (`C  I`, redo via `D`) | `expected preserved` | `ambiguous` | `conversion failed` | `not tested` | `Operator.LOOP(do, redo)` maps cleanly to a Petri-net loop fragment with silent entry/exit transitions. In BPMN, cyclic XOR-join/XOR-split routing is structurally valid but visually ambiguous and sensitive to round-trip silent-transition proliferation. |
| **INV-08:** Minimum iteration count ($\ge 1$) | `expected preserved` | `expected preserved` | `conversion failed` | `not tested` | Binary loop semantics require executing `do` (`C  I`) before the loop-exit XOR-split. Must verify negative witness `<R, A, P, L, Rel, Arc>` is rejected after BPMN round-trip. |
| **INV-09:** Join before `Release Change` | `expected preserved` | `expected preserved` | `conversion failed` | `not tested` | Both `optional_legal` and `verification_loop` feed an AND-join preceding `Rel`. Risk in BPMN conversion is a misclassified join (XOR instead of AND), which would allow premature release or leave residual tokens. |
| **INV-10:** Finality (`Archive Change` last, exact final marking) | `expected preserved` | `expected preserved` | `conversion failed` | `not tested` | Requires clean WF-net sink place and BPMN end event. Round-trip conversion can fail if `fm` is empty/null or if unconsumed tokens remain in parallel branches upon reaching `Arc`. |

## Detailed Semantic-Risk Analysis

- **True concurrency versus arbitrary interleaving:** In `source_powl`, unordered nodes (`Assess Risk` vs. `Prepare Evidence`, and `optional_legal` vs. `verification_loop`) denote *true concurrency* (partial-order independence). An accepting Petri net and BPMN parallel gateways can both represent true concurrency structurally. However, visible-trace validation (Section 5) and reachability graphs evaluate *interleaving semantics*: they can prove that every permitted interleaving is preserved, but cannot prove that two activities execute simultaneously rather than via mutually exclusive interleaving machinery.
- **Lack of an edge between Optional Legal Review and verification:** Because `Prepare Evidence` constrains `verification_loop` but not `optional_legal`, `Legal Review` may occur *before* `Prepare Evidence`, *during* any verification iteration, or *after* verification completes. This N-pattern is the exact reason `Petri  Process Tree` cannot faithfully succeed without duplicating labels or distorting behavior (e.g., forcing `Assess Risk` and `Prepare Evidence` to synchronize before `optional_legal` can begin).
- **Silent optional behavior:** `skip_legal` is a `SilentTransition` (`label=None`). Hiding `tau` preserves whether `Legal Review` occurred, but erases *when* the skip decision occurred (branching-time choice timing). In BPMN, silent skips have no dedicated task symbol and appear as direct bypass sequence flows between XOR gateways, risking misinterpretation as missing logic or causing redundant silent transitions upon round-trip.
- **Binary-loop semantics:** PM4Py's `Operator.LOOP(children=[trial_body, correct_defect])` enforces strict binary do-redo semantics: `trial_body` executes first, then either the loop exits silently or `correct_defect` executes followed obligatorily by another `trial_body`. Converting this loop to Petri net and then BPMN introduces silent entry/exit transitions and cyclic XOR gateways; any converter defect that swaps gateway types or miswires the exit arc can either permit zero iterations or permit exiting immediately after `Correct Defect`.
- **The join before Release Change:** `Release Change` requires synchronization of a mandatory cyclic branch (`verification_loop`) and an optional branch (`optional_legal`). If `Petri  BPMN` emits an XOR-join (or an implicit unsynchronized merge) instead of an AND-join, `Release Change` could fire as soon as `skip_legal` completes—before verification finishes—or fire twice. Soundness checking and exact-final-marking validation are essential to catch this.
- **Activity-label uniqueness:** All nine visible activities in `source_powl` have distinct labels. Uniqueness is a major validation asset: footprints and visible traces unambiguously identify which transition fired. Any conversion step that duplicates an activity label (a known workaround when approximating non-block-structured models as trees) breaks structural correspondence and should be flagged immediately by checking transition-label multiplicity.
- **Initial and final markings:** A Petri net alone does not define an accepting language without `im` and `fm`. Round-tripping through BPMN can occasionally yield missing, null, or multi-token markings if start/end events are converted improperly. Validation must enforce non-null single-sink workflow-net markings and **exact** `marking == fm` equality rather than loose trace-completion heuristics.
- **Gateway or routing-node ambiguity in BPMN visualization:** `pm4py.convert_to_bpmn(net, im, fm)` derives gateways mechanically from place/transition branching degrees. Silent places and silent transitions can become unlabeled gateways, consecutive gateways of the same type, or mixed gateways (multiple incoming and outgoing flows on one diamond). Even when the underlying token semantics are sound, visual routing ambiguity can mislead reviewers about scope, optionality, and synchronization.

# 5. Round-Trip Validation Code

The code below validates every round-tripped accepting Petri net against `net_from_powl` using:

1. workflow-net and soundness checks (`pm4py.check_is_workflow_net`, `pm4py.check_soundness`);
2. behavioral footprint comparison (`pm4py.discover_footprints`);
3. reachability-graph construction and structural diagnostics (`pm4py.convert_to_reachability_graph`);
4. custom **bounded visible-trace exploration** using `pm4py.get_enabled_transitions(...)`, hiding `label is None`, enforcing exact final-marking equality, eliminating infinite silent cycles via `(marking, visible_trace)` state memoization, and bounding visible length and loop iterations;
5. targeted positive and negative witness checks (evaluated directly against the net via guided prefix BFS so witnesses of any length are checked with exact final-marking equality);
6. stochastic playout cross-checking where supported by the installed PM4Py version.

```python
from __future__ import annotations

from collections import Counter, deque
from typing import Any, Dict, Iterable, List, Optional, Set, Tuple

import pm4py
from pm4py.objects.petri_net.obj import Marking


# ---------------------------------------------------------------------------
# 1. Exact Marking Arithmetic and Firing Semantics
# ---------------------------------------------------------------------------
def normalize_marking(marking: Marking) -> Marking:
    return Marking({p: c for p, c in marking.items() if c > 0})


def marking_key(marking: Marking) -> frozenset:
    return frozenset((p, c) for p, c in marking.items() if c > 0)


def fire_transition(marking: Marking, transition: Any) -> Marking:
    next_m = Marking(marking)
    for arc in transition.in_arcs:
        next_m[arc.source] -= arc.weight
        if next_m[arc.source] <= 0:
            del next_m[arc.source]
    for arc in transition.out_arcs:
        next_m[arc.target] = next_m.get(arc.target, 0) + arc.weight
    return next_m


# ---------------------------------------------------------------------------
# 2. Bounded Visible-Trace Exploration (Hiding Tau, Exact FM, Cycle-Safe)
# ---------------------------------------------------------------------------
def explore_bounded_visible_traces(
    net: Any,
    im: Marking,
    fm: Marking,
    max_visible_len: int = 14,
    max_loop_repeats: int = 2,
    loop_marker_label: str = "Correct Defect",
    max_total_tokens: int = 30,
    max_visited_states: int = 200_000,
) -> Dict[str, Any]:
    """
    Exhaustively explores all completed visible traces within:
      - len(visible_trace) <= max_visible_len
      - visible_trace.count(loop_marker_label) <= max_loop_repeats
    provided neither max_total_tokens nor max_visited_states is exceeded.

    - Transitions with label is None (tau) are hidden.
    - Completion requires exact final-marking equality (marking == fm).
    - Infinite silent cycles are prevented by memoizing (marking_key, visible_trace).
    """
    norm_im = normalize_marking(im)
    norm_fm = normalize_marking(fm)
    fm_k = marking_key(norm_fm)

    start_state = (marking_key(norm_im), ())
    visited: Set[Tuple[frozenset, Tuple[str, ...]]] = {start_state}
    queue: deque[Tuple[Marking, Tuple[str, ...]]] = deque([(norm_im, ())])

    completed_traces: Set[Tuple[str, ...]] = set()
    deadlock_traces: Set[Tuple[str, ...]] = set()
    non_dead_final_traces: Set[Tuple[str, ...]] = set()

    exhaustive = True
    token_bound_hit = False
    state_bound_hit = False

    while queue:
        curr_m, curr_trace = queue.popleft()
        curr_k = marking_key(curr_m)
        enabled = pm4py.get_enabled_transitions(net, curr_m)

        if curr_k == fm_k:
            completed_traces.add(curr_trace)
            if enabled:
                non_dead_final_traces.add(curr_trace)
        elif not enabled:
            deadlock_traces.add(curr_trace)

        for t in enabled:
            next_m = fire_transition(curr_m, t)
            if sum(next_m.values()) > max_total_tokens:
                exhaustive = False
                token_bound_hit = True
                continue

            if t.label is None:
                next_trace = curr_trace
            else:
                if len(curr_trace) >= max_visible_len:
                    continue
                if (
                    t.label == loop_marker_label
                    and curr_trace.count(loop_marker_label) >= max_loop_repeats
                ):
                    continue
                next_trace = curr_trace + (t.label,)

            next_state = (marking_key(next_m), next_trace)
            if next_state not in visited:
                if len(visited) >= max_visited_states:
                    exhaustive = False
                    state_bound_hit = True
                    continue
                visited.add(next_state)
                queue.append((next_m, next_trace))

    return {
        "completed_traces": completed_traces,
        "deadlock_traces": deadlock_traces,
        "non_dead_final_traces": non_dead_final_traces,
        "visited_state_count": len(visited),
        "exhaustive_within_bound": exhaustive,
        "token_bound_hit": token_bound_hit,
        "state_bound_hit": state_bound_hit,
        "bound": {
            "max_visible_len": max_visible_len,
            "max_loop_repeats": max_loop_repeats,
            "loop_marker_label": loop_marker_label,
        },
    }


# ---------------------------------------------------------------------------
# 3. Exact Witness Checker (Arbitrary Length, Hiding Tau, Exact FM)
# ---------------------------------------------------------------------------
def check_trace_accepted(
    net: Any,
    im: Marking,
    fm: Marking,
    target_trace: Tuple[str, ...],
    max_total_tokens: int = 30,
    max_visited_states: int = 50_000,
) -> Tuple[bool, bool]:
    """
    Returns (accepted, search_complete).
    accepted is True iff target_trace can reach exact fm after hiding tau.
    """
    norm_im = normalize_marking(im)
    fm_k = marking_key(normalize_marking(fm))

    visited: Set[Tuple[frozenset, int]] = {(marking_key(norm_im), 0)}
    queue: deque[Tuple[Marking, int]] = deque([(norm_im, 0)])
    search_complete = True

    while queue:
        curr_m, idx = queue.popleft()
        if idx == len(target_trace) and marking_key(curr_m) == fm_k:
            return True, True

        for t in pm4py.get_enabled_transitions(net, curr_m):
            if t.label is None:
                next_idx = idx
            elif idx < len(target_trace) and t.label == target_trace[idx]:
                next_idx = idx + 1
            else:
                continue

            next_m = fire_transition(curr_m, t)
            if sum(next_m.values()) > max_total_tokens:
                search_complete = False
                continue

            state = (marking_key(next_m), next_idx)
            if state not in visited:
                if len(visited) >= max_visited_states:
                    search_complete = False
                    continue
                visited.add(state)
                queue.append((next_m, next_idx))

    return False, search_complete

# 5. Footprints, Reachability Graph, Label Multiplicity, and Optional Playout
# ---------------------------------------------------------------------------
def visible_label_counts(net: Any) -> Counter:
    return Counter(t.label for t in net.transitions if t.label is not None)


def compare_footprints(
    ref_net: Any, ref_im: Marking, ref_fm: Marking,
    cand_net: Any, cand_im: Marking, cand_fm: Marking,
) -> Dict[str, Any]:
    fp_ref = pm4py.discover_footprints(ref_net, ref_im, ref_fm)
    fp_cand = pm4py.discover_footprints(cand_net, cand_im, cand_fm)
    keys = ["activities", "start_activities", "end_activities", "sequence", "parallel"]
    diffs: Dict[str, Dict[str, Set[Any]]] = {}
    for k in keys:
        s_ref = set(fp_ref.get(k, set()) or set())
        s_cand = set(fp_cand.get(k, set()) or set())
        if s_ref != s_cand:
            diffs[k] = {"only_in_ref": s_ref - s_cand, "only_in_cand": s_cand - s_ref}
    return {"exact_match": len(diffs) == 0, "diffs": diffs}


def inspect_reachability_graph(
    name: str, net: Any, im: Marking, fm: Marking, is_sound: bool
) -> Dict[str, Any]:
    if not is_sound:
        return {
            "built": False,
            "reason": f"{name}: Skipped reachability graph because net failed soundness check (risk of unbounded state space).",
        }
    try:
        rg = pm4py.convert_to_reachability_graph(net, im, fm)
        terminal_states = [s for s in rg.states if len(s.outgoing) == 0]
        return {
            "built": True,
            "num_states": len(rg.states),
            "num_transitions": len(rg.transitions),
            "num_terminal_states": len(terminal_states),
        }
    except Exception as exc:
        return {"built": False, "error": f"{type(exc).__name__}: {exc}"}


def run_playout_crosscheck(
    ref_net: Any, ref_im: Marking, ref_fm: Marking,
    cand_net: Any, cand_im: Marking, cand_fm: Marking,
    num_traces: int = 50,
    max_trace_len: int = 20,
) -> Dict[str, Any]:
    """
    Non-exhaustive stochastic playout cross-check (only if simulator is available).
    Simulates traces from candidate net and verifies exact acceptance on ref_net, and vice versa.
    """
    try:
        from pm4py.algo.simulation.playout.petri_net import algorithm as simulator
    except Exception as exc:
        return {"supported": False, "reason": f"Simulator unavailable: {type(exc).__name__}: {exc}"}

    def sample_traces(net, im, fm) -> List[Tuple[str, ...]]:
        params = {
            simulator.Variants.BASIC_PLAYOUT.value.Parameters.NO_TRACES: num_traces,
            simulator.Variants.BASIC_PLAYOUT.value.Parameters.MAX_TRACE_LENGTH: max_trace_len,
        }
        log = simulator.apply(net, im, final_marking=fm, parameters=params)
        traces: List[Tuple[str, ...]] = []
        for trace in log:
            traces.append(tuple(ev["concept:name"] for ev in trace if "concept:name" in ev))
        return traces

    try:
        cand_samples = sample_traces(cand_net, cand_im, cand_fm)
        ref_samples = sample_traces(ref_net, ref_im, ref_fm)
    except Exception as exc:
        return {"supported": False, "reason": f"Playout failed: {type(exc).__name__}: {exc}"}

    cand_rejected_by_ref = [
        tr for tr in set(cand_samples)
        if not check_trace_accepted(ref_net, ref_im, ref_fm, tr)[0]
    ]
    ref_rejected_by_cand = [
        tr for tr in set(ref_samples)
        if not check_trace_accepted(cand_net, cand_im, cand_fm, tr)[0]
    ]
    return {
        "supported": True,
        "sampled_from_cand": len(cand_samples),
        "sampled_from_ref": len(ref_samples),
        "cand_traces_rejected_by_ref": cand_rejected_by_ref,
        "ref_traces_rejected_by_cand": ref_rejected_by_cand,
        "all_samples_accepted": (
            len(cand_rejected_by_ref) == 0 and len(ref_rejected_by_cand) == 0
        ),
    }


# ---------------------------------------------------------------------------
# 6. Master Round-Trip Comparison Runner
# ---------------------------------------------------------------------------
def validate_round_trips(
    net_from_powl: Any,
    im_from_powl: Marking,
    fm_from_powl: Marking,
    round_trip_nets: Dict[str, Tuple[Any, Marking, Marking]],
    max_visible_len: int = 14,
    max_loop_repeats: int = 2,
) -> Dict[str, Dict[str, Any]]:
    def check_sound_bool(net, im, fm) -> bool:
        res = pm4py.check_soundness(net, im, fm, print_diagnostics=False)
        return bool(res[0]) if isinstance(res, tuple) else bool(res)

    ref_wf = bool(pm4py.check_is_workflow_net(net_from_powl))
    ref_sound = check_sound_bool(net_from_powl, im_from_powl, fm_from_powl)
    ref_labels = visible_label_counts(net_from_powl)
    ref_rg = inspect_reachability_graph(
        "net_from_powl", net_from_powl, im_from_powl, fm_from_powl, ref_sound
    )
    ref_explore = explore_bounded_visible_traces(
        net_from_powl,
        im_from_powl,
        fm_from_powl,
        max_visible_len=max_visible_len,
        max_loop_repeats=max_loop_repeats,
    )

    print(
        f"[BASELINE net_from_powl] wf={ref_wf}, sound={ref_sound}, "
        f"completed_traces={len(ref_explore['completed_traces'])}, "
        f"exhaustive={ref_explore['exhaustive_within_bound']}, "
        f"deadlocks={len(ref_explore['deadlock_traces'])}, rg={ref_rg}"
    )

    results: Dict[str, Dict[str, Any]] = {}
    for rt_name, (rt_net, rt_im, rt_fm) in round_trip_nets.items():
        rt_wf = bool(pm4py.check_is_workflow_net(rt_net))
        rt_sound = check_sound_bool(rt_net, rt_im, rt_fm)
        rt_labels = visible_label_counts(rt_net)

        fp_report = compare_footprints(
            net_from_powl, im_from_powl, fm_from_powl, rt_net, rt_im, rt_fm
        )
        rt_rg = inspect_reachability_graph(rt_name, rt_net, rt_im, rt_fm, rt_sound)

        rt_explore = explore_bounded_visible_traces(
            rt_net,
            rt_im,
            rt_fm,
            max_visible_len=max_visible_len,
            max_loop_repeats=max_loop_repeats,
        )

        ref_traces = ref_explore["completed_traces"]
        rt_traces = rt_explore["completed_traces"]
        missing_traces = ref_traces - rt_traces
        extra_traces = rt_traces - ref_traces

        pos_failures = []
        for wid, trace in POSITIVE_WITNESSES.items():
            accepted, complete = check_trace_accepted(rt_net, rt_im, rt_fm, trace)
            if not (accepted and complete):
                pos_failures.append((wid, accepted, complete))

        neg_failures = []
        for wid, trace in NEGATIVE_WITNESSES.items():
            accepted, complete = check_trace_accepted(rt_net, rt_im, rt_fm, trace)
            if accepted or not complete:
                neg_failures.append((wid, accepted, complete))

        playout_report = run_playout_crosscheck(
            net_from_powl, im_from_powl, fm_from_powl, rt_net, rt_im, rt_fm
        )

        both_exhaustive = (
            ref_explore["exhaustive_within_bound"]
            and rt_explore["exhaustive_within_bound"]
        )
        bounded_equiv = (
            both_exhaustive
            and len(missing_traces) == 0
            and len(extra_traces) == 0
            and len(rt_explore["deadlock_traces"]) == 0
            and len(rt_explore["non_dead_final_traces"]) == 0
        )

        overall_pass = (
            rt_wf
            and rt_sound
            and (ref_labels == rt_labels)
            and fp_report["exact_match"]
            and bounded_equiv
            and len(pos_failures) == 0
            and len(neg_failures) == 0
            and (not playout_report["supported"] or playout_report["all_samples_accepted"])
        )

        results[rt_name] = {
            "overall_pass": overall_pass,
            "is_workflow_net": rt_wf,
            "is_sound": rt_sound,
            "label_multiplicity_match": ref_labels == rt_labels,
            "ref_labels": dict(ref_labels),
            "rt_labels": dict(rt_labels),
            "footprints": fp_report,
            "ref_reachability_graph": ref_rg,
            "rt_reachability_graph": rt_rg,
            "bounded_exploration": {
                "both_exhaustive_within_bound": both_exhaustive,
                "ref_trace_count": len(ref_traces),
                "rt_trace_count": len(rt_traces),
                "missing_traces_count": len(missing_traces),
                "extra_traces_count": len(extra_traces),
                "sample_missing": sorted(missing_traces)[:5],
                "sample_extra": sorted(extra_traces)[:5],
                "rt_deadlock_count": len(rt_explore["deadlock_traces"]),
                "rt_non_dead_final_count": len(rt_explore["non_dead_final_traces"]),
            },
            "positive_witness_failures": pos_failures,
            "negative_witness_failures": neg_failures,
            "playout_crosscheck": playout_report,
        }

        print(f"\n=== ROUND-TRIP VALIDATION SUMMARY: {rt_name} ===")
        print(f"  OVERALL PASS: {overall_pass}")
        print(f"  WF-net={rt_wf}, Sound={rt_sound}, LabelsExact={ref_labels == rt_labels}")
        print(f"  FootprintsExact={fp_report['exact_match']}")
        print(
            f"  BoundedTraces (len<={max_visible_len}, redos<={max_loop_repeats}): "
            f"ref={len(ref_traces)}, rt={len(rt_traces)}, "
            f"missing={len(missing_traces)}, extra={len(extra_traces)}, "
            f"exhaustive={both_exhaustive}"
        )
        print(
            f"  Deadlocks={len(rt_explore['deadlock_traces'])}, "
            f"NonDeadFM={len(rt_explore['non_dead_final_traces'])}"
        )
        print(f"  WitnessFailures: pos={pos_failures}, neg={neg_failures}")
        print(f"  PlayoutCrossCheck: {playout_report}")

    return results
```

### Exhaustiveness Statement

Under the default bound (`max_visible_len = 14`, `max_loop_repeats = 2` on `"Correct Defect"`), the custom exploration is **exhaustive for all completed visible traces with 0, 1, or 2 verification-loop repetitions** (which for `source_powl` spans all 45 exact visible traces up to length 14, covering every valid interleaving of `Assess Risk`, `Prepare Evidence`, optional `Legal Review`, and the verification loop), **if and only if** `both_exhaustive_within_bound == True` (neither `max_total_tokens` nor `max_visited_states` is reached). It is **not exhaustive** for traces with 3 or more `"Correct Defect"` iterations, for true-concurrency (partial-order) equivalence beyond interleaving, or for stochastic playout (which is strictly sampling-based). Note also that reachability graphs are intentionally *not* required to be isomorphic, because valid BPMN round-trips commonly alter the number of silent transitions and intermediate places while preserving the visible accepting language.

# 6. Visual-Semantics Review

Even if `bpmn_from_net` passes every automated round-trip check in Section 5, the rendered BPMN diagram can easily mislead technical and compliance stakeholders:

- **Parallel gateways (AND-split / AND-join) and the N-pattern:** Because `Assess Risk` feeds both `Optional Legal Review` and the verification AND-join while `Prepare Evidence` feeds only the verification AND-join, the diagram will contain crossing sequence flows or chained AND-gateways. Readers commonly misread this cluster as a symmetric barrier ("wait for both `Assess Risk` and `Prepare Evidence` before starting *either* `Legal Review` or `Verification`"), missing that `Legal Review` can start as soon as `Assess Risk` completes.
- **Exclusive gateways (XOR-split / XOR-join) overloaded for two roles:** BPMN uses the same `×` diamond for both *optionality* (skipping `Legal Review`) and *iteration* (loop entry before `Configure Trial` and loop exit after `Inspect Trial`). Without visual grouping or labels, reviewers often misread the `Legal Review` bypass as an error/exception path or confuse which XOR gateway closes the loop versus which opens the optional branch.
- **Loop visualization and minimum iteration count:** Mechanical `Petri  BPMN` layout often renders the backward edge through `Correct Defect` awkwardly—sometimes reversing visual flow direction or stretching edges across parallel branches. Stakeholders inspecting the diagram quickly struggle to confirm that (1) at least one `(Configure Trial  Inspect Trial)` cycle is mandatory, and (2) `Correct Defect` can never terminate the loop without another full trial.
- **Silent routing nodes:** Silent transitions (`tau`) from `skip_legal`, loop entry/exit, and partial-order synchronization frequently manifest as unlabeled gateways, empty bypass arcs, or sequences of adjacent gateways with no intervening task. Stakeholders may assume an unlabeled gateway represents an undocumented decision rule or mistakenly attempt to "clean up" the diagram by deleting a gateway—accidentally breaking soundness or concurrency.
- **Apparent ordering induced by graph layout:** Hierarchical left-to-right layout engines assign horizontal ranks to tasks. If `Legal Review` happens to be placed visually to the left of `Configure Trial` or visually to the right of `Inspect Trial`, human readers instinctively infer temporal precedence ("Legal Review happens before verification" or "after verification"), even though the graph has no directed path connecting them.

### Recommended Annotations and Documentation

1. **Visual Scope Grouping:** Enclose `Configure Trial`, `Inspect Trial`, `Correct Defect`, and their loop XOR gateways in a BPMN Group (dotted boundary, non-executable) titled: *"Verification Loop — minimum 1 iteration; repeats separated by Correct Defect."*
2. **Explicit Gateway and Flow Annotations:** Attach BPMN text annotations to each ambiguous construct without altering control-flow semantics:
   - At the `Legal Review` XOR-split: *"Optional branch (no guard modeled in source POWL): may skip; depends only on Assess Risk; runs concurrently with Prepare Evidence and Verification."*
   - At the `Verification` AND-join: *"Synchronization: requires both Assess Risk and Prepare Evidence."*
   - At the `Release Change` AND-join: *"Synchronization: waits for both Optional Legal branch (completed or skipped) and Verification Loop exit."*
   - On loop exit/redo flows (clearly labeled as *illustrative prose, not executable POWL guards*): *"Defect found  Correct Defect"* vs. *"Inspection passed  Release join."*
3. **Layout-Semantics Legend:** Include a standard disclaimer box on every published diagram: *"Horizontal position is layout-only. Execution order is defined strictly by directed sequence flows and gateway types. Unlabeled bypass arcs represent formal silent transitions (`tau`)."*

# 7. Rejection Criteria

A converted BPMN model or intermediate artifact must be **rejected or quarantined** if any of the following conditions occurs:

1. **Null artifact, conversion exception, or invalid markings:** Any conversion call raises an unexpected exception (excluding an *interpreted* refusal on the diagnostic Pipeline B), returns `None`, or produces an accepting net with `im is None`, `fm is None`, or zero tokens in `im` or `fm`.
2. **Workflow-net or soundness failure:** Either `pm4py.check_is_workflow_net(net)` or `pm4py.check_soundness(net, im, fm)` returns `False` on `net_from_powl` or on any round-tripped net (indicating dead transitions, deadlocks, livelocks, or improper completion).
3. **Exact-final-marking violation or improper termination:** Any positive witness fails to reach exact `marking == fm`, bounded exploration detects any deadlocked marking `m != fm`, or `fm` itself still has enabled transitions (`non_dead_final_traces` non-empty).
4. **Loss of a required interleaving (over-constrained concurrency):** Any valid trace of `net_from_powl` within the exploration bound is absent from the round-tripped net—specifically including loss of `<R, P, A, ...>`, `<R, A, L, P, C, I, Rel, Arc>` (N-pattern collapse), or `<R, P, A, C, L, I, Rel, Arc>` (loss of legal/verification overlap).
5. **Admission of premature release or synchronization breach:** Any extra trace is accepted by the round-tripped net—specifically any negative witness allowing `Configure Trial` before both `Assess Risk` and `Prepare Evidence`, `Legal Review` before `Assess Risk`, `Release Change` before verification or before `Legal Review` completes, or activities after `Archive Change`.
6. **Collapse of optionality or corruption of binary-loop semantics:** The round-tripped net eliminates the silent-skip path (`<R, A, P, C, I, Rel, Arc>` rejected), permits zero verification iterations (`<R, A, P, L, Rel, Arc>` accepted), allows reversed trial ordering (`I` before `C`), permits exiting directly after `Correct Defect`, or allows repeated `Legal Review`.
7. **Activity-label distortion or unintended duplication:** The multiset of visible transition labels in a round-tripped net differs from `net_from_powl` (e.g., dropped, renamed, or duplicated labels introduced by a block-structured approximation, or a silent transition accidentally receiving a visible label).
8. **Incomplete validation or structural regression:** Bounded exploration fails to achieve `both_exhaustive_within_bound == True` (hitting token or state safety caps), footprint relations (`activities`, `start_activities`, `end_activities`, `sequence`, `parallel`) diverge from `net_from_powl`, or reachability-graph construction fails due to unboundedness.

# 8. Canonical Representation Recommendation

- **Authoritative canonical model for storage:** Store the **POWL specification** (`source_powl`, serialized in version-controlled code or canonical POWL JSON/Python format) as the single source of truth. POWL natively, compactly, and unambiguously captures the strict partial order (including the non-series-parallel N-pattern), optionality, and binary loop without gateway clutter or layout artifacts.
- **Stakeholder visualization model:** Publish **annotated BPMN** generated from Pipeline A (`POWL  accepting Petri net  BPMN`) as the stakeholder-facing communication view, paired with the visual annotations and invariant summary defined in Section 6.
- **Derivative artifacts:** All generated objects—`net_from_powl`, `bpmn_from_net`, rendered PNG/SVG/BPMN XML diagrams, and `net_from_bpmn_direct`—are strictly **derivative build outputs**, never authoritative sources.
- **Mandatory validation evidence accompanying each derivative:** Every published BPMN package must bundle a machine-generated verification manifest containing:
  1. source POWL commit hash and PM4Py version;
  2. WF-net and soundness pass results for both `net_from_powl` and `net_from_bpmn_direct`;
  3. bounded visible-trace equivalence summary confirming `missing == 0`, `extra == 0`, `deadlocks == 0`, `non_dead_final == 0`, exact-final-marking enforcement, and `both_exhaustive_within_bound == True` with the stated bound (`max_visible_len`, `max_loop_repeats`);
  4. 100% pass record on the Section 5 positive and negative witness suites;
  5. exact label-multiplicity match, exact footprint match, and finite reachability-graph metrics;
  6. human visual-semantics review sign-off confirming annotations do not contradict the invariant baseline.
- **Policy on process-tree intermediates:** A process-tree intermediate **must not be allowed** in the production conversion pipeline for POWL models of this class. Because POWL strictly generalizes process trees, requiring a process tree either fails on valid partial orders (as expected here) or encourages lossy approximations. `convert_to_process_tree` may be run solely as an optional *diagnostic probe* to report whether a given model happens to lie within the block-structured fragment.
- **Preventing round-trip drift on future edits:** Enforce a strict **one-way CI/CD pipeline**: all semantic changes are authored exclusively in the canonical POWL source, peer-reviewed alongside updated semantic invariants and witness traces, converted via Pipeline A, and gated automatically by Section 5 validation before releasing updated BPMN diagrams. Manual edits to exported BPMN files are restricted to pure layout coordinates and non-executable text annotations—and any post-processed BPMN XML must pass the exact same `BPMN  Petri net` round-trip validation gate prior to publication.

# 9. Residual Uncertainty

Even if every diagnostic and validation check in Sections 3 and 5 passes cleanly, the validation **cannot** establish the following claims:

1. **Equivalence for unbounded loop iterations:** Bounded visible-trace exploration proves exact language equality only up to the chosen bound (`max_visible_len = 14`, `max_loop_repeats = 2`). Although WF-net soundness, exact footprints, and finite reachability graphs provide strong structural assurance, bounded enumeration does not constitute a formal proof of language equivalence for arbitrary iteration counts $k \ge 3$.
2. **True-concurrency and branching-time equivalence:** Visible-trace validation and reachability-graph exploration operate under *interleaving trace semantics* after hiding `tau`. Passing all checks does not prove partial-order (pomset) equivalence—distinguishing genuine simultaneous overlap from nondeterministic interleaving—nor does it prove weak/branching bisimulation equivalence regarding *when* silent choices (`skip_legal` or loop exit) are resolved.
3. **Business rules, data guards, and liveness/fairness in execution:** The source POWL models pure control flow with nondeterministic choices. Passing validation says nothing about *under what risk conditions* `Legal Review` must be triggered, what defect criteria trigger `Correct Defect`, whether the loop terminates fairly in real operations, or whether SLA/role constraints are satisfied.
4. **Third-party BPMN 2.0 engine and human interpretability:** Round-tripping through PM4Py's own `convert_to_bpmn` and `convert_to_petri_net` validates internal consistency within PM4Py's semantics. It cannot rule out symmetric encoder/decoder assumptions inside PM4Py that might diverge from strict BPMN 2.0 execution engines (e.g., Camunda or Flowable) on unlabeled/mixed gateways, nor can automated validation prove that human stakeholders will read the rendered layout without misinterpreting concurrent branches.
