# 1. Source-Semantics Baseline

Source POWL `source_powl` is authoritative. Visualization/layout is not semantics. All invariants below are defined on visible traces after hiding `tau` (`SilentTransition`, `label is None`) unless stated.

# 2. Candidate Conversion Pipelines

| Pipeline | PM4Py calls | Expected benefit | Expected risk | Failure condition |
|---|---|---|---|---|
| **Pipeline A (Primary): POWL  accepting Petri net  BPMN** | `pm4py.convert_to_petri_net(source_powl)`  `pm4py.convert_to_bpmn(net, im, fm)`  `pm4py.convert_to_petri_net(bpmn)` for round-trip | Semantics-preserving translation to Petri net is defined and supported. Direct PetriBPMN conversion avoids block-structured restriction. Retains concurrency (INV-02, INV-05) as Petri net free-choice/partial order, BPMN with Parallel Gateways. Lowest information loss for this POWL shape. | BPMNPetri round-trip and visualization can introduce silent routing transitions, gateway ambiguity, tau explosion. BPMN layout suggests order not in semantics (e.g., Legal branch drawn above loop implies sequence). Soundness must be re-checked after each step. | **Fail if:** `convert_to_petri_net` returns null markings, `check_is_workflow_net`/`check_soundness` fails, footprints lose `` relations, round-trip rejects positive witness or accepts negative witness (e.g., Release before verification). |
| **Pipeline B (Stress test): POWL  Petri net  Process Tree  BPMN** | `pm4py.convert_to_petri_net(source_powl)`  `pm4py.convert_to_process_tree(net,im,fm)` inside `try/except`  `pm4py.convert_to_bpmn(tree)`  `pm4py.convert_to_petri_net(bpmn_from_tree)` | Process Tree would give fully block-structured, sound, hierarchical model ideal for mining/analytics and guarantees soundness by construction. BPMN from Tree is often more compact. | **High risk for this POWL:** POWL partial order with two independent joins (`Assess+Prepare  Loop`, `OptionalLegal  Loop  Release`) is not block-structured. `convert_to_process_tree` is not guaranteed to succeed and is expected to raise `Exception` or produce language-approximating tree. Risk of over-sequencing (forcing Legal before Loop), loss of concurrency, approximating OPTIONAL+LOOP as XOR/LOOP with wrong scope. | **Expected failure condition:** `pm4py.convert_to_process_tree(...)` raises `Exception` (`ProcessTree conversion not possible / non-block-structured`). Correct outcome is to **catch and quarantine**, not suppress. If it succeeds, must be validated: reject if footprints collapse `` to ``, if optionality lost, or if 0-iteration loop accepted. |
| Pipeline C (Validation only): BPMN  Petri net diagnostics | `pm4py.convert_to_reachability_graph`, `pm4py.discover_footprints`, `pm4py.get_enabled_transitions` bounded exploration, `pm4py.check_soundness` | No new artifact; provides independent cross-validation of Pipeline A/B without adding conversion bias. Bounded enumeration of visible language establishes evidence. | State explosion; tau loops cause infinite unfolding; footprint/reachability may be incomplete under bound. | Fail if soundness false, reachability graph shows deadlock before `Archive`, or witness replay fails. |

**Choice:** Pipeline A is primary for preservation. Pipeline B is attempted but **failure is an acceptable correct outcome** - do not fabricate a POWLBPMN direct API.

# 3. Conversion Code

```python
import pm4py
from pm4py.objects.powl.obj import StrictPartialOrder, OperatorPOWL, Transition, SilentTransition
from pm4py.objects.process_tree.obj import Operator

# -------------------------------------------------
# 0. Source POWL is authoritative (re-stated for reproducibility)
# -------------------------------------------------
register = Transition(label="Register Change")
assess_risk = Transition(label="Assess Risk")
prepare_evidence = Transition(label="Prepare Evidence")
legal_review = Transition(label="Legal Review")
skip_legal = SilentTransition()
optional_legal = OperatorPOWL(operator=Operator.XOR, children=[legal_review, skip_legal])
configure_trial = Transition(label="Configure Trial")
inspect_trial = Transition(label="Inspect Trial")
trial_body = StrictPartialOrder(nodes=[configure_trial, inspect_trial])
trial_body.order.add_edge(configure_trial, inspect_trial)
correct_defect = Transition(label="Correct Defect")
verification_loop = OperatorPOWL(operator=Operator.LOOP, children=[trial_body, correct_defect])
release_change = Transition(label="Release Change")
archive_change = Transition(label="Archive Change")
source_powl = StrictPartialOrder(
    nodes=[register, assess_risk, prepare_evidence, optional_legal, verification_loop, release_change, archive_change]
)
source_powl.order.add_edge(register, assess_risk)
source_powl.order.add_edge(register, prepare_evidence)
source_powl.order.add_edge(assess_risk, optional_legal)
source_powl.order.add_edge(assess_risk, verification_loop)
source_powl.order.add_edge(prepare_evidence, verification_loop)
source_powl.order.add_edge(optional_legal, release_change)
source_powl.order.add_edge(verification_loop, release_change)
source_powl.order.add_edge(release_change, archive_change)

# save POWL visualization (baseline)
pm4py.save_vis_powl(source_powl, "01_source_powl.png")

# -------------------------------------------------
# 1. POWL -> accepting Petri net
# -------------------------------------------------
net_from_powl, im_from_powl, fm_from_powl = pm4py.convert_to_petri_net(source_powl)

# Do not assume markings non-null: explicit check
assert net_from_powl is not None, "POWL->Petri net conversion returned None"
assert im_from_powl is not None and fm_from_powl is not None, "Initial/final marking is None"
print("POWL->Petri:", pm4py.check_is_workflow_net(net_from_powl))
print(pm4py.check_soundness(net_from_powl, im_from_powl, fm_from_powl, print_diagnostics=True))
pm4py.save_vis_petri_net(net_from_powl, im_from_powl, fm_from_powl, "02_petri_from_powl.png")

# -------------------------------------------------
# 2. Petri net -> BPMN (Primary)
# -------------------------------------------------
bpmn_from_net = pm4py.convert_to_bpmn(net_from_powl, im_from_powl, fm_from_powl)
assert bpmn_from_net is not None
pm4py.save_vis_bpmn(bpmn_from_net, "03_bpmn_from_petri.png")

# BPMN round-trip -> Petri net where possible
net_from_bpmn = None
im_from_bpmn = fm_from_bpmn = None
try:
    net_from_bpmn, im_from_bpmn, fm_from_bpmn = pm4py.convert_to_petri_net(bpmn_from_net)
    assert im_from_bpmn is not None and fm_from_bpmn is not None
    print("BPMN round-trip WF-net:", pm4py.check_is_workflow_net(net_from_bpmn))
    print(pm4py.check_soundness(net_from_bpmn, im_from_bpmn, fm_from_bpmn, print_diagnostics=True))
    pm4py.save_vis_petri_net(net_from_bpmn, im_from_bpmn, fm_from_bpmn, "04_petri_roundtrip_via_bpmn.png")
    pm4py.save_vis_bpmn(bpmn_from_net, "03_bpmn_from_petri.png") # keep BPMN
except Exception as e:
    print(f"[WARN] BPMN->Petri round-trip failed: {e}")

# -------------------------------------------------
# 3. Attempt Process-Tree intermediate (may fail - correct to catch)
# -------------------------------------------------
tree_from_petri = None
bpmn_from_tree = None
net_from_bpmn_tree = im_from_bpmn_tree = fm_from_bpmn_tree = None

try:
    tree_from_petri = pm4py.convert_to_process_tree(net_from_powl, im_from_powl, fm_from_powl)
    print(f"Process tree conversion succeeded (unexpected for this POWL shape): {tree_from_petri}")
    pm4py.save_vis_process_tree(tree_from_petri, "05_process_tree_from_petri.png")
    # Tree -> BPMN
    bpmn_from_tree = pm4py.convert_to_bpmn(tree_from_petri)
    pm4py.save_vis_bpmn(bpmn_from_tree, "06_bpmn_from_tree.png")
    # Round-trip BPMN(from tree) -> Petri
    try:
        net_from_bpmn_tree, im_from_bpmn_tree, fm_from_bpmn_tree = pm4py.convert_to_petri_net(bpmn_from_tree)
        if im_from_bpmn_tree is not None and fm_from_bpmn_tree is not None:
            print("Tree-derived BPMN round-trip soundness:",
                  pm4py.check_soundness(net_from_bpmn_tree, im_from_bpmn_tree, fm_from_bpmn_tree, print_diagnostics=True))
            pm4py.save_vis_petri_net(net_from_bpmn_tree, im_from_bpmn_tree, fm_from_bpmn_tree, "07_petri_roundtrip_via_tree.png")
    except Exception as e2:
        print(f"[WARN] BPMN(from tree)->Petri failed: {e2}")

except Exception as e:
    print(f"[EXPECTED] Petri->ProcessTree conversion failed (non-block-structured): {e}")
    # Do NOT suppress: log and continue; Pipeline B is quarantined
    tree_from_petri = None
    bpmn_from_tree = None

# -------------------------------------------------
# 4. Diagnostics on every accepting net produced
# -------------------------------------------------
def diagnose(name, net, im, fm):
    if net is None or im is None or fm is None:
        print(f"{name}: SKIPPED (null artifact)")
        return
    print(f"\n=== {name} ===")
    print("is_workflow_net:", pm4py.check_is_workflow_net(net))
    sound = pm4py.check_soundness(net, im, fm, print_diagnostics=True)
    print("sound:", sound)

diagnose("net_from_powl", net_from_powl, im_from_powl, fm_from_powl)
diagnose("net_from_bpmn (Pipeline A round-trip)", net_from_bpmn, im_from_bpmn, fm_from_bpmn)
diagnose("net_from_bpmn_tree (Pipeline B round-trip)", net_from_bpmn_tree, im_from_bpmn_tree, fm_from_bpmn_tree)
```

**Notes:** No `pm4py.convert_to_bpmn(source_powl)` is used. No assumption that markings are non-null. All `save_vis_*` use clear filenames. Exceptions from tree conversion are caught and interpreted, not hidden.

# 5. Round-Trip Validation Code

```python
import pm4py
from collections import deque

# -------------------------------------------------
# Helpers: bounded visible-trace exploration (tau-hiding, exact FM, anti-tau-cycle)
# -------------------------------------------------
def visible_language(net, im, fm, max_visible_len=8, max_loop_iters=3, max_states=5000):
    """
    Bounded BFS over (marking, visible_trace_tuple).
    - hides transitions where label is None (tau)
    - requires exact final-marking equality for acceptance
    - avoids infinite silent cycling via visited set on (marking, trace) and
      silent-closure step limit and simple loop-iteration bound on 'Correct Defect'
    - returns set of visible traces (tuple of labels)
    Bound 8 visible steps covers 1-2 loop iterations including Legal option.
    Not exhaustive beyond bound.
    """
    from pm4py.objects.petri_net.utils import petri_utils
    # Use pm4py.get_enabled_transitions
    start = im
    # state = (marking_dict, visible_trace_list)
    # For hashability, freeze marking as frozenset of (place.name, tokens)
    def freeze(m):
        return frozenset((p.name, m.get(p,0)) for p in net.places if m.get(p,0)>0)
    visited = set()
    accepted = set()
    queue = deque()
    queue.append((im, ()))
    visited.add((freeze(im), ()))
    states = 0

    while queue and states < max_states:
        marking, trace = queue.popleft()
        states += 1
        # acceptance: exact final marking equality regardless of trace length
        if marking == fm:
            accepted.add(trace)
            # do not expand beyond FM if you want proper completion semantics,
            # but allow continuation only if loop would continue before Release?
            # Here we stop expansion at FM (process ended).
            continue
        # bound visible length
        if len(trace) > max_visible_len:
            continue
        # bound loop iterations: count 'Correct Defect' occurrences
        if trace.count("Correct Defect") > max_loop_iters:
            continue

        enabled = pm4py.get_enabled_transitions(net, marking)
        for t in enabled:
            # Fire
            new_marking = petri_utils.fire_transition(net, marking, t)
            # hide tau
            if t.label is None:
                # silent: do not extend trace, but avoid silent self-loop explosion
                # only enqueue if not visited with same trace
                key = (freeze(new_marking), trace)
                if key not in visited:
                    visited.add(key)
                    queue.append((new_marking, trace))
            else:
                new_trace = trace + (t.label,)
                key = (freeze(new_marking), new_trace)
                if key not in visited:
                    visited.add(key)
                    queue.append((new_marking, new_trace))
    return accepted

def diagnose_net(name, net, im, fm):
    print(f"\n--- DIAGNOSIS {name} ---")
    if net is None or im is None or fm is None:
        print("SKIPPED: null net/marking")
        return None
    print("is_workflow_net:", pm4py.check_is_workflow_net(net))
    sound = pm4py.check_soundness(net, im, fm, print_diagnostics=True)
    try:
        fps = pm4py.discover_footprints(net, im, fm)
        print("footprints sequence:", fps.get("sequence"))
        print("footprints parallel:", fps.get("parallel"))
    except Exception as e:
        print("footprints error:", e)
        fps=None
    try:
        rg = pm4py.convert_to_reachability_graph(net, im, fm)
        print("reachability graph: states", len(rg[0]), "edges", len(rg[1]) if len(rg)>1 else "?")
    except Exception as e:
        print("reachability error:", e)
    return fps

# -------------------------------------------------
# Run diagnostics
# -------------------------------------------------
fps_powl = diagnose_net("net_from_powl", net_from_powl, im_from_powl, fm_from_powl)
fps_bpmn = diagnose_net("net_from_bpmn (A)", net_from_bpmn, im_from_bpmn, fm_from_bpmn)
if 'net_from_bpmn_tree' in globals() and net_from_bpmn_tree is not None:
    fps_tree_bpmn = diagnose_net("net_from_bpmn_tree (B)", net_from_bpmn_tree, im_from_bpmn_tree, fm_from_bpmn_tree)

# -------------------------------------------------
# Bounded language comparison + witness replay
# -------------------------------------------------
lang_powl = visible_language(net_from_powl, im_from_powl, fm_from_powl, max_visible_len=9)
print(f"\nPOWL language (bounded, tau-hidden) size: {len(lang_powl)}")
# sample
for t in sorted(lang_powl)[:10]:
    print(t)

if net_from_bpmn is not None:
    lang_bpmn = visible_language(net_from_bpmn, im_from_bpmn, fm_from_bpmn, max_visible_len=9)
    print(f"BPMN round-trip language size: {len(lang_bpmn)}")
    print("Difference POWL\\BPMN (missing in round-trip):", lang_powl - lang_bpmn)
    print("Difference BPMN\\POWL (extra in round-trip):", lang_bpmn - lang_powl)
    # Exhaustiveness statement
    print("Bounded exhaustive? YES within max_visible_len=9 and max_loop_iters=3 and max_states; NO for longer/ deeper behavior.")

# -------------------------------------------------
# Positive and negative witness traces (exact FM test via exploration membership)
# -------------------------------------------------
```

# 6. Visual-Semantics Review

Even when `net_from_bpmn` passes all diagnostics, the BPMN diagram invites misreading because **layout  semantics**:

*   **Parallel Gateway (diamond with +):** Means `AND` (all incoming must complete, all outgoing start concurrently). In Pipeline A the correct rendering uses a Parallel Fork after `Register` to enable `Assess` **and** `Prepare`, and a second Parallel Fork to spawn `OptionalLegal` **and** `verification_loop` concurrently, with a Parallel Join before `Release`. To a business reader, two branches drawn one above the other looks like “top happens first”. They may assume `Legal Review` must complete before `Configure Trial` starts (or vice versa) because the eye follows top-to-bottom. The underlying token semantics **does not** order them; the diagram needs an explicit annotation: `` and a note *“Legal Review and Verification may overlap in any order”*.
*   **Exclusive Gateway (diamond with X):** Used for `Legal Review` optionality (XOR with empty path). The empty path is often rendered as an unlabeled flow or hidden gateway branch. Viewers may miss the skip and believe Legal is mandatory, or may assume the gateway is a decision requiring data. Silent routing nodes added by conversion (unlabeled sequence flows) amplify this: they have no visible label but affect join semantics. Recommend labeling the empty path `skip` and adding text annotation *“Optional – may be skipped”*.
*   **Loop visualization:** POWL LOOP (`do = ConfigureInspect`, `redo = Correct Defect`, 1) has no single BPMN equivalent. Converters typically render it as a cycle with an Exclusive Gateway after `Inspect` looping back via `Correct Defect`. This can be misread as *while* (0 iterations allowed) vs *do-while* (1). Without a marker, a reader may admit the zero-iteration trace `Register...ReleaseArchive`. Propose BPMN loop marker with annotation *“At least one trial required; redo separated by Correct Defect”* and avoid collapsing `Correct Defect` into a gateway label.
*   **Silent routing nodes:** `convert_to_bpmn` introduces silent transitions as sequence flows/gateways to preserve Petri routing. These are invisible after hiding but visible as small diamonds/circles. A reviewer counting nodes may think there are extra activities. They should be documented as *“ – routing only, no business activity”*.
*   **Apparent ordering of graph layout:** BPMN auto-layout places nodes left-to-right in discovery order. `Assess` left of `Prepare` does **not** mean `Assess  Prepare`; it means `Assess  Prepare` rendered sequentially for readability. Same for `Legal` vs `Loop`. Without a legend, stakeholders will infer sequence. Mitigation: **do not rely on visual inspection**. Attach alongside every BPMN image: (1) footprint table showing `Assess  Prepare`, `Legal  Loop`, (2) witness traces for both orders, (3) a textual invariant table stating synchronization before Release.

**Proposed annotations/documentation to accompany each BPMN artifact:** Title block stating *“Derived view – not authoritative”*, gateway legend, explicit `` markers on parallel gateways, `X (skip allowed)` label on optional Legal gateway, loop annotation with `1`, note *“Tau flows are routing only”*, and reference to validation report (soundness, footprints, bounded language diff =  within bound).

# 7. Rejection Criteria

Quarantine or reject a conversion result if **any** holds (technical **or** semantic):

1.  **Non-workflow net or unsound:** `pm4py.check_is_workflow_net == False` or `pm4py.check_soundness(...) == False` (diagnostics report deadlock, lack of proper completion, dead transition, or unbounded place). Unsound net must not be stored or published.
2.  **Initial/final marking null or malformed:** `im` or `fm` is `None`, `fm` not reachable, or final marking does not require exactly `Archive Change` completed (e.g., extra tokens left, termination after `Release` accepted). Exact-FM test fails.
3.  **Loss of required interleaving / over-sequencing:** Positive witness rejected or footprint relation `` collapsed to ``. Examples: `Register, Prepare, Assess, ...` rejected, or `Legal  Loop` not both orders accepted. Indicates concurrency forced into sequence.
4.  **Admission of forbidden behavior:** Any negative witness **accepted** by round-tripped net: zero-iteration loop (`Release` without `Configure/Inspect`), `Inspect` before `Configure` in same iteration, `Release` before both `OptionalLegal` and `Loop` completed, `Legal` before `Assess`, or `Archive` before `Release`. Indicates join or ordering lost.
5.  **Collapse or spurious expansion of optional behaviour:** Language with `Legal Review` present and language without it not both present (mandatory or prohibited), or duplicate `Legal` allowed twice. Demonstrates XOR+tau mis-converted (often via Exclusive vs Inclusive gateway error).
6.  **Label duplication / silent explosion:** Round-tripped net contains duplicated visible labels (two different transitions with same business label) or number of  transitions grows > 2× original and changes language (e.g., BPMNPetri synthesizes extra visible duplicate). Footprint keys no longer 1:1; validation `not tested` becomes `lost`.
7.  **Bounded language divergence:** `lang_powl - lang_bpmn  ` or `lang_bpmn - lang_powl  ` within stated bound, or `discover_footprints(powl) != discover_footprints(roundtrip)` on `parallel`/`sequence` relations. Even if diagram looks plausible, semantic drift requires quarantine.
8.  **Process-tree intermediate succeeded but introduced approximation:** If `convert_to_process_tree` returned a tree without throwing, but subsequent witness/ footprint comparison shows `approximated/lost` on INV-02/INV-05/INV-07, the tree-derived BPMN must be rejected as derivative, not promoted to canonical. Suppressed exceptions also count as rejection (hidden failure).

Any single criterion triggers *quarantine*: keep artifact for forensics with `REJECTED_` prefix, do not publish as stakeholder view, require re-conversion via Pipeline A.

# 8. Canonical Representation Recommendation

*   **Authoritative (storage, versioning, future edits):** **Source POWL (`source_powl`) and its directly derived accepting Petri net (`net_from_powl, im_from_powl, fm_from_powl`) jointly as canonical.** POWL is the human-readable *intent* (partial orders, XOR+tau, LOOP do/redo) and is unambiguous for this domain; the Petri net is the executable semantics produced by the supported, semantics-preserving `convert_to_petri_net(POWL)`. Store both with hash linkage: POWL pickle + PNML with `im`/`fm`. Never store BPMN as source of truth. Rationale: POWL/Petri retain partial order, loop scope, and join semantics without gateway ambiguity; they are the only representations with a defined formal conversion path and support exact `fm` and soundness checks.
*   **Derivative (stakeholder visualization only):** BPMN from Pipeline A (`bpmn_from_net`). Publish BPMN strictly as a **rendered view** for discussion. Mark every BPMN file as `DERIVED - DO NOT EDIT` and attach validation evidence package: `check_soundness` report, `discover_footprints` diff, bounded language diff (must be  within bound), witness replay log (all positive ACCEPT, all negative REJECT), and gateway legend annotations from Section 6. If BPMN is edited by business users, it must be treated as a *new sketch*, not a round-tripped edit, and must be re-validated via `BPMN  Petri net` comparison before acceptance.
*   **Process-tree intermediate:** **Not allowed as canonical or as intermediate for preservation.** For this POWL shape, Pipeline B is expected to `conversion failed`; if a tree is produced it is by definition an approximation (block-structured approximation of a non-block-structured language). Trees may be used **only** for analytics that explicitly require block structure (e.g., inductive mining benchmarks), and then must never overwrite the canonical POWL/Petri. Any tree-derived BPMN (`bpmn_from_tree`) is automatically `QUARANTINED` unless it passes the full invariant audit, which it is not expected to.
*   **Validation evidence that must accompany each derivative:** For every BPMN published: (1) `im`/`fm` non-null proof, (2) `is_workflow_net` + `soundness` diagnostics log, (3) footprint `parallel/sequence` equality vs canonical, (4) bounded visible-language diff report with stated bound and exhaustiveness disclaimer, (5) positive/negative witness replay table, (6) screenshot with annotations from Section 6. No BPMN without this bundle is distributable.
*   **How future edits avoid round-trip drift:** Edits must be made **on POWL**, not on BPMN or Petri net. Workflow: `edit POWL  regenerate Petri via convert_to_petri_net  regenerate BPMN via convert_to_bpmn  re-run full Round-Trip Validation Code  republish BPMN`. Prohibit `BPMN  POWL` or `BPMN  Petri  POWL` cycles (no supported API and drift is inevitable). Version control must reject commits where `net_from_bpmn` language diverges from `net_from_powl` within bound; CI pipeline runs Sections 5 and 7 checks automatically.

# 9. Residual Uncertainty

Even if every check in Sections 3-5 passes within the stated bound, the following cannot be established:

1.  **Unbounded language equivalence and true-concurrency equivalence.** Bounded visible-trace enumeration (`max_visible_len=9`, `max_loop_iters=3`) is exhaustive only inside the bound. Equivalence for arbitrary loop iterations (e.g., 10+ cycles) is not proven, and Petri net interleaving semantics cannot prove pomset/history-preserving bisimulation (true concurrency). Two nets can have identical bounded traces but differ on longer traces or on partial-order behaviour that is unobservable via sequential traces.
2.  **Silent transition identity and branching bisimilarity.** Hiding `tau` makes multiple -topologies (different numbers/placements of silent gateways introduced by BPMN conversion) observationally identical on visible traces. Passing witnesses does **not** prove that internal silent routing is correct or that there is no extra internal deadlock/livelock that hides behind bounded exploration but appears under fair scheduling or with larger silent loops.
3.  **BPMN gateway semantics fidelity beyond Petri mapping.** BPMN standard execution semantics (e.g., Inclusive Gateway, OR-join, cancellation, message flows) are not fully captured by the Petri net encoding. A BPMN diagram that round-trips correctly to a Petri net may still be interpreted differently by a BPMN engine or a human following the BPMN spec, especially for loop termination, empty-path handling of the optional Legal XOR, and Parallel Join waiting behaviour. Footprints and replay validate the *converted* net, not the independent BPMN engine's interpretation.
4.  **Future extensibility and data/resource perspective.** Validation covers control-flow ordering, optionality, loop, and synchronization. It does not establish preservation of *intended* business rules not encoded in control flow (e.g., risk assessment data guard for Legal, authorization roles, time constraints, or variant where Legal is *conditionally* mandatory based on risk level). Such rules would be lost even with perfect structural conversion.
5.  **Visual and pragmatic equivalence for stakeholders.** No automated test can prove that stakeholders will interpret the BPMN diagram as intended (e.g., they may still infer sequence from layout, or misread Exclusive vs Parallel gateways). Successful replay proves the underlying net is behaviourally acceptable, not that the rendering is unambiguous to readers; documentation and annotations remain necessary and human review is still required.
