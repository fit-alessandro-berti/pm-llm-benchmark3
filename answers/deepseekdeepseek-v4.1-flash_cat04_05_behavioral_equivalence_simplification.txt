def bounded_traces(net, im, fm, max_visible=12, max_analyze=3):
    fm_key = marking_key(fm)
    start_marking = norm_marking(im)
    start_trace = tuple()
    start = (start_marking, start_trace, 0)
    q = deque([start])
    seen = {(marking_key(start_marking), start_trace, 0)}
    complete = set()
    while q:
        marking, trace, a_count = q.popleft()
        if marking_key(marking) == fm_key:
            complete.add(trace)
            # final marking usually has no enabled; do not expand
            continue
        if a_count > max_analyze:
            continue
        for t in pm4py.get_enabled_transitions(net, marking):
            label = t.label
            silent = is_silent(label)
            if silent:
                new_trace = trace
                new_a = a_count
            else:
                if len(trace) >= max_visible:
                    continue
                label_str = str(label)
                new_trace = trace + (label_str,)
                new_a = a_count + (1 if label_str == "Analyze Revision" else 0)
                if new_a > max_analyze:
                    continue
            new_marking = fire(net, marking, t)
            if new_marking is None:
                continue
            key = (marking_key(new_marking), new_trace, new_a)
            if key not in seen:
                seen.add(key)
                q.append((new_marking, new_trace, new_a))
    return complete

def norm(m):
    return Counter({p: c for p, c in Counter(m).items() if c > 0})

def mkey(m):
    return tuple(sorted((p.name, c) for p, c in norm(m).items()))

def fire(net, marking, trans):
    m = Counter(marking)
    for arc in net.arcs:
        if arc.target == trans and arc.source in net.places:
            w = getattr(arc, "weight", 1) or 1
            m[arc.source] -= w
            if m[arc.source] < 0:
                return None
    for arc in net.arcs:
        if arc.source == trans and arc.target in net.places:
            w = getattr(arc, "weight", 1) or 1
            m[arc.target] += w
    return norm(m)

def load(s):

    ok = pm4py.check_soundness(net, im, fm, print_diagnostics=True)
    print("soundness result:", ok)
    return net, im, fm

def bounded_visible_traces(net, im, fm, max_visible=12, max_analyze=3):
    fm_key = mkey(fm)
    start = (norm(im), tuple(), 0)
    q = deque([start])
    seen = {(mkey(start[0]), start[1], start[2])}
    complete = set()
    while q:
        marking, trace, a_count = q.popleft()
        if mkey(marking) == fm_key:
            complete.add(trace)
            continue

            continue

def tree_stats(node, depth=0):
    children = getattr(node, "children", None)
    if not children:
        lab = getattr(node, "label", None)
        return {
            "nodes": 1,
            "depth": depth,
            "visible_leaves": 0 if is_silent_label(lab) else 1,
            "silent_leaves": 1 if is_silent_label(lab) else 0,
            "labels": [lab],
            "operators": []
        }
    out = {
        "nodes": 1,
        "depth": depth,
        "visible_leaves": 0,
        "silent_leaves": 0,
        "labels": [],
        "operators": [str(getattr(node, "operator", None))]
    }
    for ch in children:
        st = tree_stats(ch, depth + 1)
        out["nodes"] += st["nodes"]
        out["depth"] = max(out["depth"], st["depth"])
        out["visible_leaves"] += st["visible_leaves"]
        out["silent_leaves"] += st["silent_leaves"]
        out["labels"] += st["labels"]
        out["operators"] += st["operators"]
    return out

def dup_count(labels):
    from collections import Counter
    c = Counter(l for l in labels if not is_silent_label(l))

# 1. Equivalence Notions

**Visible trace equivalence after hiding `tau`.**  
For a model \(M\), let \(L(M)\) be the set of finite complete visible traces from the initial marking to the final marking after erasing every silent transition (`tau`, `None`, or empty label). Two models are visibly trace equivalent iff \(L(A)=L(B)\). Duplicate visible labels are distinguished by **occurrence position in the trace**, not by transition identity and not merely by label multiset. Thus `A,C,R,A,C` differs from `A,C,R,A`.

**Bounded visible-language equivalence under P3.**  
P3 compares only complete traces with:
- at most 12 visible events;
- at most 3 occurrences of `Analyze Revision`;
- silent transitions hidden.

Two models are P3-bounded equivalent iff their finite bounded visible trace sets are equal. This is **evidence**, not a proof of unbounded equivalence.

**Business-relevant equivalence under P1.**  
P1 observes visible labels `Open Case`, `Analyze Revision`, `Check Revision`, `Approve Revision`, `Rework Case`, `Close Case`, hiding `tau`. Duplicate labels are distinguished by occurrence position. P1 also enforces:
- each analysis revision has its own `Check Revision` before the next `Rework Case` or before `Close Case`;
- `Rework Case` separates attempts;
- `Approve Revision` is optional and its number and placement are visible/relevant.

Two models are P1-equivalent iff they admit the same set of P1-compliant visible traces under this observation model. If P1 is read strictly as “Check must follow the Analyze it belongs to,” Model A’s parallel `Analyze`/`Check` is too permissive.

**Abstracted dashboard equivalence under P2.**  
P2 maps each complete visible trace to the tuple:
- `Open Case` seen = true;
- `Close Case` seen = true;
- \(n_A\) = number of `Analyze Revision` occurrences;
- `hasCheck` = whether at least one `Check Revision` occurred;
- `hasRework` = whether at least one `Rework Case` occurred.

P2 hides `Approve Revision` and all silent behavior, collapses repeated `Check Revision` to a Boolean, counts `Analyze Revision`, and records `Rework Case` only as Boolean. It ignores exact interleaving of `Analyze Revision` and `Check Revision`. Duplicate `Check` labels are collapsed; duplicate `Analyze` labels are counted.

Optional approval matters because B allows `Analyze, Approve, Check` while A forces approval to occur after the parallel `Analyze`/`Check` completes. Under P2, approval is hidden, so that distinction disappears. Hidden `tau` allows A1 and B2 to omit approval entirely, and it also creates silent loop-exit and join behavior. Hiding `tau` alone does not make A and B equivalent under P1 or P3: A still forces one check per iteration, while B still has only one global check.

# 5. Bounded Comparison Code

The following code performs an **exhaustive bounded exploration** over markings. It is not random playout. It handles silent transitions, repeated markings/traces, visible-length bounds, `Analyze Revision` count bounds, and final-marking equality explicitly.

```python
from collections import deque, Counter
import pm4py

MODEL_A = "->('Open Case', *(->(+('Analyze Revision','Check Revision'), X('Approve Revision',tau)), 'Rework Case'), 'Close Case')"
MODEL_B = "->('Open Case', +('Check Revision', *(->('Analyze Revision', X('Approve Revision',tau)), 'Rework Case')), 'Close Case')"

def is_silent(label):
    return label is None or str(label).lower() in {"", "tau", ""}

def norm(m):
    return Counter({p: c for p, c in Counter(m).items() if c > 0})

def mkey(m):
    return tuple(sorted((p.name, c) for p, c in norm(m).items()))

def fire(net, marking, trans):
    m = Counter(marking)
    # consume place -> transition
    for arc in net.arcs:
        if arc.target == trans and arc.source in net.places:
            w = getattr(arc, "weight", 1) or 1
            m[arc.source] -= w
            if m[arc.source] < 0:
                return None
    # produce transition -> place
    for arc in net.arcs:
        if arc.source == trans and arc.target in net.places:
            w = getattr(arc, "weight", 1) or 1
            m[arc.target] += w
    return norm(m)

def load_model(s):
    tree = pm4py.parse_process_tree(s)
    net, im, fm = pm4py.convert_to_petri_net(tree)
    ok = pm4py.check_soundness(net, im, fm, print_diagnostics=True)
    print("soundness result:", ok)
    return net, im, fm

def bounded_visible_traces(net, im, fm, max_visible=12, max_analyze=3):
    fm_key = mkey(fm)
    start = (norm(im), tuple(), 0)
    q = deque([start])
    seen = {(mkey(start[0]), start[1], start[2])}
    complete = set()

    while q:
        marking, trace, a_count = q.popleft()

        if mkey(marking) == fm_key:
            complete.add(trace)
            # In sound nets the final marking normally has no enabled transitions.
            continue

        if a_count > max_analyze:
            continue

        for t in pm4py.get_enabled_transitions(net, marking):
            lab = t.label
            if is_silent(lab):
                new_trace = trace
                new_a = a_count
            else:
                if len(trace) >= max_visible:
                    continue
                lab = str(lab)
                new_trace = trace + (lab,)
                new_a = a_count + (1 if lab == "Analyze Revision" else 0)
                if new_a > max_analyze:
                    continue

            new_marking = fire(net, marking, t)
            if new_marking is None:
                continue

            key = (mkey(new_marking), new_trace, new_a)
            if key not in seen:
                seen.add(key)
                q.append((new_marking, new_trace, new_a))

    return complete

net_a, im_a, fm_a = load_model(MODEL_A)
net_b, im_b, fm_b = load_model(MODEL_B)

traces_a = bounded_visible_traces(net_a, im_a, fm_a, max_visible=12, max_analyze=3)
traces_b = bounded_visible_traces(net_b, im_b, fm_b, max_visible=12, max_analyze=3)

only_a = sorted(traces_a - traces_b)
only_b = sorted(traces_b - traces_a)

print("A-only bounded traces:")
for tr in only_a:
    print(tr)

print("B-only bounded traces:")
for tr in only_b:
    print(tr)

print("A size:", len(traces_a))
print("B size:", len(traces_b))
```

This is exhaustive within the stated bound. A random `pm4py.play_out(...)` would not be exhaustive and would only provide sampled evidence.

# 6. Stochastic and Footprint Comparison

Footprints and stochastic distances can add evidence, but they cannot establish trace equivalence.

```python
# Footprints from the accepting Petri nets or process trees from Section 5.
fp_a = pm4py.discover_footprints(net_a)
fp_b = pm4py.discover_footprints(net_b)
print("Footprints A:", fp_a)
print("Footprints B:", fp_b)

# Declared ad hoc stochastic semantics: uniform distribution over the bounded traces.
# This is NOT inferred from the models and is only an illustration.
def uniform_language(traces):
    n = len(traces)
    return {t: 1.0 / n for t in traces} if n else {}

lang_a = uniform_language(traces_a)
lang_b = uniform_language(traces_b)

emd = pm4py.compute_emd(lang_a, lang_b)
print("EMD under declared uniform bounded language:", emd)
```

`pm4py.get_stochastic_language(...)` would require a stochastic Petri net or declared transition probabilities. These models have no declared stochastic semantics, so I do not invent one. The uniform distribution above is explicitly declared and applies only to the bounded trace set from Section 5.

Equal footprints are only local successor/ordering evidence. They do not prove equality of loop scope, per-revision check placement, or approval placement. A low EMD under a chosen bounded stochastic language can occur even when the supports differ outside the bound, or when the distinguishing traces are rare under the chosen distribution. Therefore neither footprints nor EMD establish trace equivalence.

# 7. Complexity Comparison

Depth below uses **root depth 0**.

| Metric | Model A | Model B | Simplified model from Section 8 |
|---|---:|---:|---:|
| Process-tree node count | 12 | 12 | 11 |
| Depth | 4 | 5 | 4 |
| Visible leaves | 6 | 6 | 6 |
| Silent leaves | 1 | 1 | 1 |
| Duplicate visible leaf labels | 0 | 0 | 0 |
| Operators | 5 | 5 | 4 |

Model A and B have the same node and leaf counts, but B is deeper because `Check Revision` is outside the loop and parallel with it. The simplified model removes the parallel operator, reducing node count by one and matching Model A’s depth while remaining shallower than Model B.

```python
def is_silent_label(lab):
    return lab is None or str(lab).lower() in {"", "tau", ""}

def tree_stats(node, depth=0):
    children = getattr(node, "children", None)
    if not children:
        lab = getattr(node, "label", None)
        return {
            "nodes": 1,
            "depth": depth,
            "visible_leaves": 0 if is_silent_label(lab) else 1,
            "silent_leaves": 1 if is_silent_label(lab) else 0,
            "labels": [lab],
            "operators": []
        }

    out = {
        "nodes": 1,
        "depth": depth,
        "visible_leaves": 0,
        "silent_leaves": 0,
        "labels": [],
        "operators": [str(getattr(node, "operator", None))]
    }

    for ch in children:
        st = tree_stats(ch, depth + 1)
        out["nodes"] += st["nodes"]
        out["depth"] = max(out["depth"], st["depth"])
        out["visible_leaves"] += st["visible_leaves"]
        out["silent_leaves"] += st["silent_leaves"]
        out["labels"] += st["labels"]
        out["operators"] += st["operators"]

    return out

def duplicate_visible_leaf_labels(labels):
    from collections import Counter
    c = Counter(l for l in labels if not is_silent_label(l))
    return sum(1 for l, n in c.items() if n > 1)

for name, s in [("A", MODEL_A), ("B", MODEL_B)]:
    tree = pm4py.parse_process_tree(s)
    st = tree_stats(tree)
    net, im, fm = pm4py.convert_to_petri_net(tree)
    print(name, st)
    print(name, "duplicate visible leaf labels:", duplicate_visible_leaf_labels(st["labels"]))
    print(name, "simplicity_petri_net:", pm4py.simplicity_petri_net(net, im, fm))
```

I do not report exact `pm4py.simplicity_petri_net(...)` values here because they depend on the PM4Py conversion and should be obtained by running the code above.

# 8. Simplified Model

I choose **P1 operational compliance** as the primary business target, with **P2 dashboard preservation** as a secondary target. The simplification removes the parallel `Analyze`/`Check` operator and enforces a clear per-revision order: analyze, then check, then optionally approve, then optionally rework.

**Compact process-tree model**

```python
simplified_model = pm4py.parse_process_tree(
    "->('Open Case', *(->('Analyze Revision', 'Check Revision', X('Approve Revision',tau)), 'Rework Case'), 'Close Case')"
)
```

Self-contained PM4Py code:

```python
simplified_model = pm4py.parse_process_tree(
    "->('Open Case', *(->('Analyze Revision', 'Check Revision', X('Approve Revision',tau)), 'Rework Case'), 'Close Case')"
)

simp_net, simp_im, simp_fm = pm4py.convert_to_petri_net(simplified_model)
print(pm4py.check_soundness(simp_net, simp_im, simp_fm, print_diagnostics=True))
```

**Preservation table**

| Property | Status | Comment |
|---|---|---|
| P1: each analysis has its own check before next rework/close | exact / strengthened | It enforces `Analyze` then `Check` in each iteration. |
| P1: rework separates attempts | exact | `Rework Case` is the loop-back child. |
| P1: approval optional and visible | exact | `X(Approve Revision, tau)` after each check. |
| P1: number/placement of approvals visible | exact | One optional approval per revision, after check. |
| P2: open first, close last | exact | Sequence `Open`, loop, `Close`. |
| P2: at least one analyze and one check | exact | Loop executes first child once. |
| P2: check collapsed to Boolean | exact | Multiple checks still collapse to `hasCheck = true`. |
| P2: hides approval and silent behavior | exact | P2 projection ignores them. |
| P2: counts analyze and records any rework | exact | `Rework` occurs iff there are at least two analyses. |
| P3: exact visible traces vs Model A | weakened/lost | Loses `Check`-before-`Analyze` concurrency. |
| P3: exact visible traces vs Model B | lost | B has one global check; simplified has one check per revision. |
| Concurrency | lost | No parallel operator remains. |

The simplified model is structurally simpler than both originals: 11 process-tree nodes, depth 4, and no parallel operator. Model A has 12 nodes and parallel `Analyze`/`Check`; Model B has 12 nodes but depth 5 and global parallel check.

**Regression traces admitted by the simplified model**

| ID | Trace | Why admitted |
|---|---|---|
| R1 | O, A, C, Cl | One revision, auto-approved. |
| R2 | O, A, C, App, Cl | One revision, manually approved. |
| R3 | O, A, C, App, R, A, C, Cl | Two revisions, approval on first. |

**Negative traces not admitted by the simplified model**

| ID | Trace | Why rejected |
|---|---|---|
| N1 | O, A, C, R, A, Cl | Second analysis has no check before close. |
| N2 | O, C, A, Cl | Check before analysis. |
| N3 | O, A, App, C, Cl | Approval before check. |

# 9. Final Recommendation

- **P1 operational compliance:** Model B is not suitable. It has only one `Check Revision` for the entire revision loop, so it cannot satisfy per-revision checking when two or more analyses occur. Model A is closer, but its parallel `Analyze`/`Check` allows check-before-analysis. If P1 requires check-after-analysis, use the simplified sequential model from Section 8. If P1 only requires a check before the next rework/close, Model A is acceptable for P1 but still differs from B.
- **P2 executive dashboard:** Model A and Model B are equivalent only under the P2 abstraction: Open first, Close last, at least one Analyze, Boolean check occurred, Boolean rework, and Analyze count. The simplified model also preserves this dashboard semantics. B should not be used as the operational source because the dashboard abstraction hides the per-revision check loss.
- **P3 bounded testing:** Model A and Model B are not equivalent. Counterexamples appear within the stated bound of 12 visible events and 3 `Analyze Revision` occurrences. Bounded comparison is useful for testing and counterexample generation, but it is not a proof of unbounded equivalence.
- **Simplified model:** Use the simplified sequential per-revision model for P1-style operational compliance and P2-style dashboard reporting. It is simpler than both originals and stronger than Model A if checks must follow analyses. It should not replace Model A when exact P3 visible-trace equivalence, including parallel `Analyze`/`Check` interleavings, is required.

**Warning.** Bounded comparison up to 12 visible events and 3 analyses can only show difference or bounded agreement. It cannot prove that two unbounded loop models are equivalent. Silent `tau` transitions, loop unrolling, and concurrency can create distinguishing behavior beyond the bound.
