- Waiting time: registration wait (1.5h) and signing wait (44h) fall; queues at Classify (2h), KYC (4h), and Doc review (18h) likely grow as A1 accelerates arrivals.
- Rework: A5 cuts the Doc review  Request docs  Doc review loop (3,300/2,800); A2 cuts the 8% misroute rate.
- Handovers: fewer manual registration handoffs; reminder loops automated.
- Resource demand: back-office load drops where slack already exists; analysts and compliance face faster inflow — overload risk.
- Control violations: provisional signing (6.5%) eliminated for e-sign-adopted cases via the hard gate; otherwise neutral.

**P2 (Bottleneck/synchronization)**
- Cycle time: largest reduction for the mismatch variant (31h wait, 82% critical-path) and Equipment finance (58h valuation partially parallelized with credit analysis).
- Waiting time: down at mismatch resolution, normalization (20h), valuation (58h), and the packaging join (26h).
- Rework: mismatch recurrence (38%) and packaging rework (15%) fall once inputs are clean.
- Handovers: less KYC  specialist ping-pong (1,160 returns); standardized valuer routing.
- Resource demand: senior-specialist leverage; analysts shift to judgment/exceptions; month-end spikes ease.
- Control violations: four-eyes enforceable in A8; month-end violations (5.8%) ease as rush pressure drops — but only if A8 follows input-quality maturity.

**P3 (Compliance-first)**
- Cycle time: modest; contract remediation loops (650/510 edges) shrink; signing wait falls.
- Waiting time: contract prep (22h) and KYC hit queues improve.
- Rework: contract remediation (8.5% overall, 14% Credit-line renewal) and KYC false-positive handling fall.
- Handovers: remediation routed through a workbench instead of ad hoc legal–analyst exchanges.
- Resource demand: legal ops smoothed (month-end relief); A3 escalations add load to the 2 senior specialists — must be staffed.
- Control violations: largest improvement — provisional signing gated, terms-match enforced, remediation root-caused, full audit trail.

**P4 (Balanced, recommended)**
- Cycle time: strong improvement on the mainstream variant — document loop, mismatch wait, analyst chain, and contract loop are all attacked; the 58h valuation and 44h signing waits remain (year-2 targets).
- Waiting time: Doc review (18h) + request loop (8h), mismatch (31h), normalize (20h), contract prep (22h) all reduced.
- Rework: 52% repeat requests, 38% mismatch recurrence, and 8.5%/14% contract remediation all targeted; A6 introduces a new but managed exception stream (low-confidence extractions).
- Handovers: fewer back-office  analyst  customer loops; mismatch resolutions captured for reuse; the 380-case mismatch  contract-prep bypass is blocked.
- Resource demand: back office redeployed to exceptions/outreach; analysts shift to judgment + low-confidence review — monitored so A5's cleaner inflow doesn't overload the network-central analyst pool; compliance seniors relieved by A4.
- Control violations: A9 enforces terms-match-decision; A4 adds an audited KYC exception trail; month-end pressure (and thus four-eyes violations) eases indirectly.

## 5. Risks and compensating controls

| Risk | Where | Compensating control |
|---|---|---|
| Auditability gap | All model-based modules | Immutable log of model suggestion, human override, final decision; case-level audit trail; periodic compliance audit |
| False negatives (missed KYC hits) | A3 | Conservative thresholds; 100% human review for High-exposure SME; QA sampling; escalation SLA to senior specialists |
| False positives / alert fatigue | A3, A5 | Precision monitoring, threshold tuning, feedback loops |
| Misclassification  wrong control path | A2 | Confidence threshold + human confirmation; misroute detection report; periodic revalidation |
| Extraction errors on poor PDFs | A6 | Field-level confidence scores; human review queue; dual control for low-confidence outputs |
| Model drift | A2, A3, A6 | Monthly accuracy/override monitoring; retraining schedule; champion-challenger; drift alarms |
| Exceptions hidden by automation | All | Explicit exception queues with SLAs and aging metrics; exceptions counted and reported, not absorbed silently |
| Four-eyes violations | A8 / workflow | System-enforced segregation for High-exposure SME; month-end surveillance; violation alerts |
| Provisional signing | A10, process | Hard KYC-clearance gate; reconcile signing vs. KYC timestamps; close the mismatch  contract-prep bypass (380 cases) |
| Outdated contract rule library | A9 | Legal ownership, versioning, effective dating, formal change approval |
| Customer friction | A5, A10 | RM co-design of instructions; flexible upload channels; consent management; friction KPIs |
| Automation bias | A2, A3, A9 | Training; override-rate metrics; rotating QA review |
| Partner dependency | A7 | Valuer SLAs, multi-valuer panel, quality-dispute process |
| Downstream overload from faster inflow | A1, A5, A6 | Sequencing (A5 before/with A6), capacity monitoring, intake throttles; defer A1 |

Automation changes where humans work — from execution to exception handling, judgment, and control verification. Compliance accountability remains with the bank; no module transfers responsibility to a model.

## 6. Recommended phased rollout

**Phase 0 (months 0–1) — Foundations**
Baseline variant-level metrics (cycle time, waiting time, loop rates); implement audit-logging standard; charter the contract rule-library governance; co-design document checklists with RMs; design exception queues. *Gate: baseline signed off; audit-trail standard approved by compliance.*

**Phase 1 (months 1–4) — A5 + A4 (both light integration; zero deep slots consumed)**
Metrics: repeat-request rate (baseline 52%), customer response time, doc-review wait (18h), mismatch wait (31h), mismatch rework (38%), specialist escalation load, RM friction KPIs.
*Gates: repeat-request rate materially reduced; mismatch median wait materially reduced with zero missed true mismatches in QA sampling; friction KPIs acceptable.*

**Phase 2 (months 3–8) — A6 (deep integration #1)**
Pilot on Micro/Working-capital (simpler statements), then expand. Metrics: first-pass extraction yield, exception rate and queue age, normalize wait (20h), analyst utilization/overtime, credit-analysis queue (28h).
*Gates: extraction accuracy above threshold with a stable exception queue; analyst overtime not rising — then scale.*

**Phase 3 (months 6–12) — A9 (deep integration #2)**
Deploy after rule-library sign-off and upstream data-completeness thresholds are met; prioritize Credit-line renewal (14% remediation). Metrics: contract-prep wait (22h), remediation loop rate (8.5%/14%), terms-match violations, legal month-end load.
*Gates: rule library approved; decision/KYC data completeness threshold met; pilot shows remediation reduction — then scale.*

Deep-integration accounting: A6 + A9 consume exactly the two permitted deep integrations in the first six months; A5/A4 are light; A1 and A11 (both deep) are deliberately excluded from wave 1.

**Year-2 backlog (sequenced):** A10 (KYC-gated e-sign), A7 with early-initiation redesign, A2, A8 (with four-eyes enforcement), A3, A12, then A11 — only after control stability is demonstrated.

## 7. Final recommendation

**Adopt P4: A5 + A4 + A6 + A9.**

The trade-off argument: frequency measures how often an activity occurs, not how much it constrains the process. A1 (Register application) is an 8-minute task with a 1.5h queue in a pool that already falls below 65% utilization after 15:00. Automating it saves clerical minutes but does nothing to the mechanisms that dominate end-to-end performance: the 52% repeat document loop, the 31h entity-mismatch wait on a variant that is 82% critical-path, the 20–28h analyst chain, and the 8.5–14% contract remediation loops. Worse, A1 raises the arrival rate into precisely those constrained pools — a local optimization that can degrade end-to-end performance.

P4 instead attacks three of the four largest internal delay mechanisms plus one control loop, satisfies the compliance mandate through A9's control-rule checks and A4's audited exception handling, respects the two-deep-integration limit, and sequences upstream data quality (A5, A4, A6) before a downstream control-enforcing module (A9) — avoiding the trap of deploying a downstream bot (A11) on unreliable upstream controls. The political need for a quick win is met by A5, which is customer- and RM-visible, high-feasibility, and structural rather than cosmetic; if registration automation is politically indispensable, a "lite" duplicate-detection enhancement can be delivered without consuming a portfolio slot.

The acknowledged sacrifice: the 44h signing wait and 58h external valuation wait persist in year 1. They top the year-2 backlog (A10, A7), and part of A7's benefit — earlier, parallel valuation initiation — is achievable through process redesign without a module. This is a defensible process-level portfolio: it optimizes the constraints, not the frequencies.
