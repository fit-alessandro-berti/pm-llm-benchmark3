# 5. PM4Py role-discovery and similarity code

The following code demonstrates how to load data, discover roles, and avoid naïve clustering by incorporating complexity and substitution flags.

```python
import pandas as pd
import pm4py

# 1. Load and format the dataframe
# Assume 'log_df' is the raw event log dataframe with columns:
# case:concept:name, concept:name, time:timestamp, org:resource, 
# case_complexity, customer_segment, product_line, temporary_substitution, escalation_level

raw_df = pd.read_csv('order_to_resolution_log.csv')
event_log = pm4py.format_dataframe(raw_df, log_format='pm4py', key_columns=['case:concept:name'], 
                                   activity_column='concept:name', resource_column='org:resource')

# 2. Discover Organizational Roles (Initial Clustering)
# This function groups resources based on activity similarity.
# We pass the event_log to discover_organizational_roles.
# Note: Do not rely solely on the 'cluster_id' output.
roles_df = pm4py.discover_organizational_roles(event_log, threshold=0.7, min_cluster_size=2)

# 3. Discover Activity-based Resource Similarity
# This gives a matrix to inspect specific pairs (e.g., R06 vs R07)
similarity_df = pm4py.discover_activity_based_resource_similarity(event_log, 
                                                                 method='cosine', 
                                                                 top_k=10)

# 4. Analyze Handover Networks
# To understand cross-functional work, inspect who hands work to whom.
handover_net = pm4py.discover_handover_of_work_network(event_log, 
                                                       max_depth=2)

# 5. Analyze Working Together Networks
# To find collaboration/coordination (e.g., R13 and R08)
collab_net = pm4py.discover_working_together_network(event_log, 
                                                     top_k=20)

# 6. Filter and Join with Complexity/Substitution Evidence
# We must join the role discovery with case complexity to avoid misclassification.
# Create a resource complexity profile from the summary data
resource_complexity = pd.read_csv('resource_complexity_summary.csv') # Hypothetical summary

# Join role outputs with complexity data
merged_roles = pd.merge(roles_df, resource_complexity, 
                        left_on='resource_id', right_on='Resource', how='left')

# 7. Filter for Temporary Substitution Indicators
# Identify if a resource is acting as a substitute.
substitution_mask = merged_roles['temporary_substitution'].astype(bool)

# 8. Compute Variants to check for Process Deviations
# If a resource deviates significantly from the standard variant, it might be a shadow role.
variants = pm4py.get_variants(event_log, case_key='case:concept:name', 
                              activity_key='concept:name')

# 9. Avoid over-interpreting frequency
# Naïve approach: Sort by activity count.
# Better approach: Weight activity by complexity.
def weighted_activity_score(row):
    # Pseudo-code for weighting: High complexity activity = higher weight
    score = 0
    for activity, count in row['activity_counts'].items():
        complexity_weight = 1.0 # Default
        if activity in ['A6', 'A9', 'A3']:
            complexity_weight = 2.0 # High complexity activities
        score += count * complexity_weight
    return score

# Apply to resources to re-cluster if necessary
resource_scores = merged_roles.apply(weighted_activity_score, axis=1)

# 10. Final Inspection
# Do not assign roles based solely on `cluster_id`.
# Use `similarity_df` to check if R06 and R07 are truly similar or just overlapping.
# Check if R13 appears in 'handover_net' as a connector, not a leaf.
print("Role Clusters:", roles_df['cluster_id'].value_counts())
print("High Complexity Activities:", similarity_df[similarity_df['similarity'] > 0.8]['pair'])
```
