# 4. Risks invisible in average cycle time

1. **Tail latency blowout.** Medians can stay flat while P90/P99 degrade 30–50%: heavy-tailed queue waits only bind cases needing multiple specialist round trips — a small share of cases, invisible in the mean.
2. **High-complexity case degradation + mix shift (Simpson's paradox).** Simple cases get faster (automation, no local loop), so the *average improves* even if every complex case gets slower. Complexity-stratified medians are mandatory; overall averages are actively misleading here.
3. **Right-censoring in early post-change data.** In the first weeks, slow cases are still open and absent from the log; early "after" cycle times are biased downward. Any 4-week post-average is nearly uninterpretable.
4. **Local knowledge loss (latent).** Context loss and skill atrophy produce no time-metric signal for months; they surface later as rework on exceptions and inability to cover absences — precisely when the embedded specialists are already gone.
5. **Fairness as mean-preserving redistribution.** East improving +1.4 d while N/S each lose 0.3 d can *improve* the aggregate average while making two of three teams worse; segment-level SLA misses can double while the aggregate rate is stable. Flow-time unfairness (wait variance within comparable cases) never appears in averages.
6. **Learning/skill atrophy.** Routing all hard cases away removes the practice loop for local staff. Nothing in cycle time measures this; the observable precursors are activity-breadth narrowing and rising referral dependency — only visible if deliberately measured.
7. **Accountability diffusion in shared approval.** Approval *duration* can improve while approval *quality* falls (inconsistent standards across a rotating pool). This shows up later as QC rework and dispute loops, not in approval timestamps.
8. **Exception handling and lost slack.** Cross-team cover (6/100 cases, 18% rework) and absence cover are numerically negligible in averages but carry concentrated risk. Pooling at >90% utilization removes the variability buffer (Kingman: waits scale with /(1)) — fragility is invisible until the first stress week, when it hits all locations simultaneously.
9. **Measurement blind spots.** Pull-queue dwell (advice completed but not pulled) and prevented referrals (informal consults that never become events) are unlogged; utilization and handover counts can look *better* than reality unless explicitly instrumented.

# 6. Recommendation

**Modify and pilot first — do not proceed to full rollout as proposed.** The case for piloting is in management's own numbers:

import pm4py

# ---------- load & format ----------
def load(path, phase):

    df = pm4py.format_dataframe(df, case_id=CASE, activity_key=ACT, timestamp_key=TS)
    df[TS] = pd.to_datetime(df[TS], utc=True)
    df = df.sort_values([CASE, TS]).reset_index(drop=True)
    df['phase'] = phase
    return df

before, after = load('log_before.csv', 'before'), load('log_after.csv', 'after')

# ---------- segmentation (team / complexity / specialty / segment) ----------
def segment(df, **sel):
    for attr, vals in sel.items():
        df = pm4py.filter_event_attribute_values(df, attr, set(vals), level='case', retain=True)
    return df

SEGMENTS = {
    'all':             {},
    'north':           {'team': ['North']},
    'south':           {'team': ['South']},
    'east':            {'team': ['East']},
    'high_complexity': {'case_complexity': ['high']},
    'legal_risk':      {'required_specialty': ['legal', 'risk']},
    'accommodation':   {'customer_segment': ['language_accommodation', 'regional']},
}

# ---------- 1. handover analytics (event-level, robust to any schema) ----------
def handover_table(df):
    d = df.sort_values([CASE, TS]).copy()
    g = d.groupby(CASE, sort=False)
    d['prev_res'], d['prev_act'], d['prev_ts'] = g[RES].shift(), g[ACT].shift(), g[TS].shift()
    h = d.dropna(subset=['prev_res'])
    h = h[h[RES] != h['prev_res']]                       # resource change = handover
    h['wait_h'] = (h[TS] - h['prev_ts']).dt.total_seconds() / H
    # classify handover type from resource names (adapt to post-change names)
    def klass(r):
        if 'TSS' in r or 'Tech' in r:          return 'technical'
        if 'Specialist' in r:                  return 'legal_risk'
        if 'Supervisor' in r or 'Approval' in r: return 'approval'
        return 'other'
    h['class_from'], h['class_to'] = h['prev_res'].map(klass), h[RES].map(klass)
    # case-level rework flag (if flag is case-level, take first per case)
    h = h.merge(df.groupby(CASE)['rework_flag'].first().rename('case_rework'), on=CASE)
    return h

def handover_summary(h):
    return (h.groupby(['class_from', 'class_to'])
             .agg(freq_per_100=('wait_h', lambda s: 100 * len(s) / h[CASE].nunique()),
                  med_wait_h=('wait_h', 'median'),
                  p90_wait_h=('wait_h', lambda s: s.quantile(0.9)),
                  rework_after=('case_rework', 'mean')))

def queue_dwell(df, act='Specialist Review'):
    """Advice completed -> pulled/continued by local resource (pull-model idle time)."""
    d = df.sort_values([CASE, TS]).copy()
    d['next_ts'] = d.groupby(CASE, sort=False)[TS].shift(-1)
    sp = d[(d[ACT] == act)].dropna(subset=['next_ts'])
    return (sp['next_ts'] - sp[TS]).dt.total_seconds() / H

# ---------- 2. organizational networks ----------
def org_networks(df, label):
    ho = pm4py.discover_handover_of_work_network(df)      # DiGraph resource -> resource
    wt = pm4py.discover_working_together_network(df)      # Graph: same-case collaboration
    sc = pm4py.discover_subcontracting_network(df, n=2)   # delegated work chains
    w = lambda e: e[2].get('weight', e[2].get('freq', 1))
    out = {'label': label,
           'handover_edges': ho.number_of_edges(),
           'handover_top10': sorted(ho.edges(data=True), key=lambda e: -w(e))[:10],
           'hub_betweenness': sorted(nx.betweenness_centrality(ho, weight='weight').items(),
                                     key=lambda kv: -kv[1])[:5],
           'subcontracting_top5': sorted(sc.edges(data=True), key=lambda e: -w(e))[:5]}
    res_team = df.groupby(RES)['team'].agg(lambda s: s.mode().iat[0]).to_dict()
    tot = same = 0
    for u, v, data in wt.edges(data=True):
        x = data.get('weight', 1); tot += x
        if res_team.get(u) == res_team.get(v): same += x
    out['within_team_collab_share'] = same / tot if tot else None   # guardrail >= 0.35
    return out

# ---------- 3. roles & resource similarity (learning / role-clarity drift) ----------
def roles_similarity(df):
    roles = pm4py.discover_organizational_roles(df)                  # list of (role, resources, activities)
    _ = pm4py.discover_activity_based_resource_similarity(df)        # resource-resource similarity
    prof = pd.crosstab(df[RES], df[ACT])
    breadth = (prof > 0).sum(axis=1)                                 # activity breadth per resource
    locals_ = [r for r in breadth.index
               if str(r).startswith(('N_', 'S_', 'E_')) and 'Tech' not in str(r)]
    return {'n_roles': len(roles),
            'approval_role_resources': [r for r in prof.index
                                        if 'Approval' in str(r) or 'Supervisor' in str(r)],
            'local_caseworker_breadth': breadth[locals_].to_dict()}  # shrinks => atrophy

# ---------- 4. variants & performance DFG ----------
def flow_performance(df):
    _dfg, _sa, _ea = pm4py.discover_dfg(df)                          # topology/frequency
    _f, _s, _e, perf = pm4py.discover_performance_dfg(df)             # edge -> {'mean': seconds, ...}
    key = [('Local Technical Assessment', 'Specialist Review'),
           ('Specialist Review', 'Implementation'),
           ('Local Customer Contact', 'Supervisor Approval'),
           ('Supervisor Approval', 'Implementation'),
           ('Quality Check', 'Rework')]
    waits = {f'{a}->{b}': perf.get((a, b), {}).get('mean', float('nan')) / H for a, b in key}
    variants = pm4py.get_variants(df)                                # variant -> count
    top5_share = sum(sorted(variants.values(), reverse=True)[:5]) / sum(variants.values())
    _top5_log = pm4py.filter_variants(df, top_k_variants=5)          # inspect most common flows
    return {'variant_count': len(variants), 'top5_share': top5_share,
            'edge_wait_h': waits}

# ---------- 5. service / waiting / utilization ----------
def service_waiting(df):
    df2 = pm4py.insert_case_service_waiting_time(df)      # adds case:service, case:waiting (s)
    cw = df2.groupby(CASE)[['case:service', 'case:waiting']].first() / H
    svc_by_act = pm4py.get_service_time(df, strategy='mean')          # activity -> seconds
    # utilization proxy: attribute event->next-event time to performer (cap at 8h)
    d = df.sort_values([CASE, TS]).copy()
    d['next_ts'] = d.groupby(CASE, sort=False)[TS].shift(-1)
    d['dur_h'] = ((d['next_ts'] - d[TS]).dt.total_seconds().abs() / H).clip(upper=8)
    daily = d.groupby([RES, d[TS].dt.date])['dur_h'].sum().reset_index(name='busy')
    daily['util'] = (daily['busy'] / 8).clip(upper=1)
    return cw, svc_by_act, daily.groupby(RES)['util'].mean()

# ---------- 6. rework & SLA ----------
def quality(df, sla_days={'low': 10, 'medium': 12, 'high': 15}):
    rw = pm4py.get_rework_cases_per_activity(df)                     # activity -> #rework cases
    cases = df.groupby(CASE).agg(rework=('rework_flag', 'first'),
                                 complexity=('case_complexity', 'first'),
                                 team=('team', 'first'),
                                 segment=('customer_segment', 'first'),
                                 start=(TS, 'min'), end=(TS, 'max'))
    cases['days'] = (cases['end'] - cases['start']).dt.total_seconds() / 86400
    cases['sla_miss'] = cases.apply(
        lambda r: r['days'] > sla_days.get(r['complexity'], 12), axis=1)
    tf = pm4py.extract_temporal_features_dataframe(df)               # per-case temporal features
    return rw, cases, tf

# ---------- 7. before/after driver with guardrails ----------
GUARDRAILS = {  # metric -> (direction, threshold)
    'tss_wait_p90_h': ('<=', 6.0), 'referral_per_100': ('<=', 45.0),
    'pull_dwell_med_h': ('<=', 2.5), 'high_cx_p90_ratio': ('<=', 1.05),
    'rework_delta_pp': ('<=', 1.0), 'sla_miss_delta_pp': ('<=', 1.5),
    'within_team_collab': ('>=', 0.35), 'util_pooled': ('<=', 0.88),
}

def evaluate(before, after):
    report = {}
    for name, sel in SEGMENTS.items():
        b, a = segment(before, **sel), segment(after, **sel)
        hb, ha = handover_table(b), handover_table(a)
        _, cb, qb = quality(b)              # cases-level frame
        _, ca, qa = quality(a)
        report[name] = {
            'handovers': (handover_summary(hb), handover_summary(ha)),
            'cycle_p50_p90_days': (cb['days'].quantile([.5, .9]).tolist(),
                                   ca['days'].quantile([.5, .9]).tolist()),
            'sla_miss': (cb['sla_miss'].mean(), ca['sla_miss'].mean()),
            'rework': (cb['rework'].mean(), ca['rework'].mean()),
            'flow': (flow_performance(b), flow_performance(a)),
            'roles': (roles_similarity(b), roles_similarity(a)),
        }
    report['networks'] = (org_networks(before, 'before'), org_networks(after, 'after'))
    _, _, ub = service_waiting(before)
    _, _, ua = service_waiting(after)
    report['utilization'] = (ub, ua)        # watch TSS/legal/risk rows vs. GUARDRAILS
    return report

report = evaluate(before, after)
