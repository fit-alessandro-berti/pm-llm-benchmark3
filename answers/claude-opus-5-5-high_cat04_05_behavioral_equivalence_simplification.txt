# 1. Equivalence Notions

**Abbreviations used in traces:** O = Open Case, An = Analyze Revision, Ch = Check Revision, Ap = Approve Revision, R = Rework Case, C = Close Case, τ = `tau`. The visible alphabet is Σ = {O, An, Ch, Ap, R, C}.

**Common semantic basis.** Each tree is converted to an accepting (workflow) Petri net (N, m_i, m_f). A *complete run* is a firing sequence from m_i that ends exactly in m_f, with no leftover tokens. Let h be the erasing homomorphism that deletes silent transitions (the explicit `tau` leaf plus any routing transitions added by the converter). The *visible language* is
L(M) = { h(ρ) | ρ is a complete run of M }.
Only complete traces are compared. Prefixes, deadlocks and branching structure are not part of the observation unless stated.

Both models can be written as regular expressions over Σ:

- L(A) = O · X · (R · X)* · C, where X = (An Ch | Ch An) · (Ap | ε)
- L(B) = O · ( Ch ⧢ Y ) · C, where Y = An (Ap | ε) (R An (Ap | ε))* and ⧢ denotes shuffle (interleaving)

**(E1) Visible trace equivalence after hiding τ.** A ≡_tr B iff L(A) = L(B). τ is fully unobservable, so a trace that skipped approval via τ and a trace that simply has no Ap are the same observation. This is the weakest linear-time notion that keeps every visible label and its order. Stronger notions (branching or weak bisimulation) imply it, so if E1 fails, all stronger notions fail as well.

**(E2) Bounded visible-language equivalence (P3).** Define
L≤(M) = { σ ∈ L(M) | |σ| ≤ 12 and #An(σ) ≤ 3 }.
A ≡_P3 B iff L≤(A) = L≤(B). Asymmetry: bounded *non*-equivalence is conclusive, because a witness trace is a real trace of one model and not of the other. Bounded *equivalence* is only evidence, since traces beyond the bound are never examined.

**(E3) Business-relevant equivalence under P1.** In both models every trace has the form σ = O w₁ R w₂ … R w_k C with wᵢ ∈ {An, Ch, Ap}*, because R and O/C occur only as separators. Attempt i is the segment wᵢ.
- *P1 observation:* π₁(σ) = ⟨[w₁], …, [w_k]⟩, where [w] is w modulo swapping *adjacent An and Ch*. P1 does not care whether the check comes before or after the analysis within an attempt. Ap is **not** allowed to commute, because the number and placement of approvals remain relevant.
- *P1 compliance predicate:* Comp₁(σ) holds iff every attempt wᵢ contains exactly one An and at least one Ch. Because each segment ends at the next R or at C, "its own check before the next Rework/Close" is exactly this condition.
- A ≡_P1 B iff π₁(L(A)) = π₁(L(B)). A model is **P1-adequate** iff, in addition, Comp₁ holds for all of its traces.
- Both L(A) and L(B) are already closed under swapping adjacent An/Ch within an attempt, so here ≡_P1 coincides with ≡_tr. The P1 view adds the compliance predicate, which tells us *which* differences matter to the business.

**(E4) Abstracted dashboard equivalence under P2.** The dashboard abstraction is
α₂(σ) = ( first(σ)=O, last(σ)=C, #An(σ), [#Ch(σ) ≥ 1], [#R(σ) ≥ 1] ).
It hides Ap and τ, collapses repeated Ch occurrences to a Boolean, counts An, reduces R to a Boolean, and ignores interleaving. A ≡_P2 B iff α₂(L(A)) = α₂(L(B)), compared as sets of dashboard observations. This is non-stochastic: it compares which dashboard rows are *possible*, not how frequent they are.

**Duplicate labels / identity.** Neither tree contains duplicate leaf labels, so every visible label corresponds to exactly one leaf. Repeated occurrences of one label within a trace (e.g. An in attempts 1 and 2) carry **no identity**: there is no revision ID in the event data.
- E1 and E2 distinguish occurrences only by **position** in the label sequence.
- E3 uses **occurrence position relative to the R separators** (segment membership) to decide which check "belongs" to which revision. "Its own check" is positional, not identity-based.
- E4 uses **labels only** (counts and Booleans).

# 2. Structural Comparison

| Feature | Model A | Model B | Semantic consequence |
|---|---|---|---|
| Loop scope | Loop body `->(+(An, Ch), X(Ap, τ))`; Ch is **inside** the loop | Loop body `->(An, X(Ap, τ))`; Ch is **outside** the loop, in parallel with it | In A every repetition re-executes Ch; in B Ch never repeats |
| Min / max Check Revision | min 1, max unbounded; always #Ch = #An = #R + 1 | exactly 1 in every trace | For every case with ≥ 2 attempts, the models have **disjoint** traces (different Ch counts) |
| Analyze / Rework counts | #An = k ≥ 1, #R = k − 1 | #An = k ≥ 1, #R = k − 1 | Identical count structure for An and R, which is why P2 cannot separate the models |
| Placement of Check Revision | Within its own attempt only: before or after that attempt's An, always **before** that attempt's optional Ap and before the next R or C | Anywhere between O and C: before the first An, between An and Ap, **after** Ap, between R and An, after the last attempt | B admits unchecked attempts, a "pre-check" before any analysis, and approval before check |
| Optional approval | 0 or 1 per attempt, fires only **after both** An and Ch of that attempt (after the AND-join) | 0 or 1 per attempt, fires right after An, **independent of** Ch | Number of approvals has the same range (0..k), but placement differs. With k = 1 this is the *only* difference (`O An Ap Ch C`) |
| Concurrency | Local: An ∥ Ch inside one attempt, giving 2 interleavings per attempt | Global: Ch ∥ the whole loop, with (loop-trace length + 1) insertion points | A has 4^k traces with k attempts; B has 5k · 2^(k−1) (5, 20, 60 for k = 1, 2, 3) |
| Join before Close Case | Per-iteration AND-join (An, Ch) before the approval choice; C follows loop exit directly | A single AND-join of {Ch, loop exit} immediately before C | In B, C only guarantees that *one* check happened somewhere; in A, C guarantees that the last attempt was checked |
| Silent behaviour | One `tau` (skip approval); converter adds silent routing (3 silent transitions in the pm4py 2.7.23.4 net) | One `tau` (skip approval); 1 silent transition in the converted net | No silent cycles in either net. τ never creates a visible difference, it only makes "no approval" unobservable |
| Soundness | Sound (verified) | Sound (verified) | Both are proper workflow nets; they differ in language, not in soundness |

# 3. Verdicts

| View | Verdict | Confidence | Decisive reason | Caveat |
|---|---|---|---|---|
| E1: visible trace equivalence (unbounded) | not equivalent | Certain (proof + witnesses) | #Ch = #An in A but #Ch = 1 in B, so for k ≥ 2 the languages are disjoint. For k = 1, B additionally admits `O An Ap Ch C`. Neither inclusion holds; L(A) ∩ L(B) contains exactly 4 traces | None. Stronger notions (bisimulation) also fail |
| P1: operational compliance | not equivalent | Very high | B admits P1-violating traces such as `O An R An Ch C`, where the first revision is never checked, and it admits approval before check. A satisfies Comp₁ on **every** trace | Restricted to single-attempt cases without approval-before-check, the models coincide. If P1 were rewritten to "one check per case suffices", B would become adequate and A over-constrained |
| P2: executive dashboard | equivalent only under stated abstraction | High (formal proof below) | Both images equal {(T, T, k, T, [k ≥ 2]) : k ≥ 1}: both models have O first, C last, k An, at least one Ch, and R present iff k ≥ 2 | Breaks immediately if the dashboard counts Ch, reports approvals, orders Ap vs Ch, or needs frequencies. The dashboard is **blind** to the P1 violation, which is a governance risk rather than a reassurance |
| P3: bounded testing (≤ 12 events, ≤ 3 An) | not equivalent | Certain (exhaustive bounded enumeration, cross-checked against a hand-derived grammar) | \|L≤(A)\| = 76, \|L≤(B)\| = 85, common = 4, A-only = 72, B-only = 81. Shortest witnesses: `O An Ap Ch C` (B only, 5 events) and `O An Ch R An Ch C` (A only, 7 events) | Here the bounded result is conclusive because it is a *non*-equivalence. The bound even treats the models asymmetrically: the 8 three-attempt, three-approval traces of A have 13 events and are cut, whereas all of B's ≤ 3-attempt traces fit (max 11 events) |

**Proof for P2.** Take a trace of A with k attempts. It has k occurrences of An, k of Ch (≥ 1), and k − 1 of R, with O first and C last. So α₂ = (T, T, k, T, [k ≥ 2]). A trace of B with k attempts has k An, exactly 1 Ch, and k − 1 R, with O first and C last, so α₂ = (T, T, k, T, [k ≥ 2]). In both models k ranges over all positive integers. Hence α₂(L(A)) = α₂(L(B)). Every A-trace has a B-trace with the same dashboard row and vice versa, although these are generally different traces.

**Proof that neither inclusion holds, and exact intersection.** Common traces must have equal Ch counts, so k = k' = 1. A's single-attempt traces are `O An Ch C`, `O Ch An C`, `O An Ch Ap C` and `O Ch An Ap C`. Each is an interleaving of one Ch into `An` or `An Ap` with Ch before Ap, so all four are in B. B's single-attempt set has 5 traces, one extra: `O An Ap Ch C`. Therefore L(A) ∩ L(B) = those 4 traces, and both L(A) \ L(B) and L(B) \ L(A) are infinite.

# 4. Counterexample Traces

| Trace ID | Trace | Model A | Model B | First decisive semantic difference | Relevant view |
|---|---|---|---|---|---|
| X1 | O An Ch R An Ch C | accepts | rejects | Position 6: a **second** Ch. B's only Ch lies outside the loop and has already fired | E1, P1 (A's trace is compliant: both revisions checked), P3 (7 events, 2 An). P2-invisible: same α₂ as Y2 |
| X2 | O Ch An Ap R An Ch Ap C | accepts | rejects | Position 7: second Ch | E1, P1, P3 (9 events). P2-invisible |
| X3 | O An Ch R Ch An Ap R An Ch C | accepts | rejects | Position 5: second Ch (three checks in total) | E1, P1, P3 (11 events, 3 An: at the edge of the bound) |
| Y1 | O An Ap Ch C | rejects | accepts | Position 3: Ap before Ch. In A, the `X(Ap, τ)` choice is enabled only after the AND-join of An **and** Ch | E1, P1 (approval placement: a revision is approved before it is checked), P3. P2-invisible (same α₂ as `O An Ch Ap C`). This is the only single-attempt difference |
| Y2 | O An R An Ch C | rejects | accepts | Position 3: R while attempt 1 has no Ch. After prefix `O An`, A can only continue with Ch | E1, **P1 violation** (first revision unchecked), P3 |
| Y3 | O Ch An R An C | rejects | accepts | Position 6: C while attempt 2 has no Ch. In B the only check precedes all analysis | E1, **P1 violation**, P3 |
| Y4 | O An Ap R An Ap Ch C | rejects | accepts | Position 3: Ap before any Ch; later, one check covers two approved revisions | E1, **P1 violation** plus approval-placement difference, P3 |
| Z1 | O Ch An Ap C | accepts | accepts | none (common trace, for contrast) | shared by all views |

X1, X2, X3 and Y2 to Y4 each contain two or more analysis attempts. Every trace listed satisfies the P3 bound.

**Effect of optional approval and hidden τ.**
- τ appears only as the "skip approval" branch, and there are no silent cycles. Hiding τ therefore collapses `X(Ap, τ)` to "Ap or nothing" and cannot create or remove a visible difference between the models. Converter-generated silent routing transitions (AND-split/join, loop entry and exit) are likewise invisible and irrelevant to E1–E4.
- A consequence for P1: since auto-approval is silent, an attempt without Ap cannot be told apart from an attempt that was simply not approved before rework. Approval *absence* carries no information in either model.
- Optional Ap multiplies the trace count by up to 2^k but matters for the *verdict* only through its **placement relative to Ch**. If Ap were hidden as well, the single-attempt languages would coincide ({O An Ch C, O Ch An C} for both). The models would still differ for every k ≥ 2 because of the Ch count. So the loop-scope difference, not the approval, is the fundamental one.

# 5. Bounded Comparison Code

The script below performs an **exhaustive** breadth-first exploration over (marking, visible-prefix) states and, separately and clearly labelled, a **heuristic** random playout. It also cross-checks the BFS against hand-derived grammars for both languages.

```python
"""Exhaustive bounded comparison of Model A and Model B (P3 view)."""
import itertools
from collections import deque

import pm4py
from pm4py.objects.petri_net.obj import Marking

MODEL_A = """->( 'Open Case',
  *( ->( +('Analyze Revision', 'Check Revision'), X('Approve Revision', tau) ),
     'Rework Case' ),
  'Close Case' )"""

MODEL_B = """->( 'Open Case',
  +( 'Check Revision',
     *( ->( 'Analyze Revision', X('Approve Revision', tau) ), 'Rework Case' ) ),
  'Close Case' )"""

MAX_VISIBLE, MAX_ANALYZE = 12, 3
ANALYZE = "Analyze Revision"
ABBR = {"Open Case": "O", "Analyze Revision": "An", "Check Revision": "Ch",
        "Approve Revision": "Ap", "Rework Case": "R", "Close Case": "C"}


def one_line(s):
    return " ".join(s.split())


def show(trace):
    return " ".join(ABBR[a] for a in trace)


def within_bound(prefix):
    return len(prefix) <= MAX_VISIBLE and prefix.count(ANALYZE) <= MAX_ANALYZE


def fire(marking, t):
    new = Marking(marking)
    for arc in t.in_arcs:
        new[arc.source] -= arc.weight
        if new[arc.source] == 0:
            del new[arc.source]
    for arc in t.out_arcs:
        new[arc.target] += arc.weight
    return new


def freeze(marking):
    return frozenset((p.name, n) for p, n in marking.items() if n > 0)


def build(tree_string):
    tree = pm4py.parse_process_tree(one_line(tree_string))
    net, im, fm = pm4py.convert_to_petri_net(tree)
    res = pm4py.check_soundness(net, im, fm, print_diagnostics=False)
    sound = res[0] if isinstance(res, tuple) else bool(res)
    return tree, net, im, fm, sound


def exhaustive_bounded_language(net, im, fm):
    """EXHAUSTIVE: every complete trace within the P3 bound.

    - silent transitions (label None) change the marking but not the prefix;
    - the visited set over (marking, prefix) makes repeated markings and any
      silent cycle terminate;
    - prefixes violating the bound are pruned; this is safe because visible
      length and #Analyze never decrease along a run;
    - a trace is complete only if the marking EQUALS the final marking
      (no leftover tokens anywhere).
    """
    fm_key = freeze(fm)
    queue, seen = deque([(im, ())]), {(freeze(im), ())}
    complete, dead = set(), set()
    while queue:
        marking, prefix = queue.popleft()
        if freeze(marking) == fm_key:
            complete.add(prefix)
            continue
        enabled = pm4py.get_enabled_transitions(net, marking)
        if not enabled:
            dead.add(prefix)
            continue
        for t in enabled:
            nxt = prefix + ((t.label,) if t.label is not None else ())
            if not within_bound(nxt):
                continue
            m2 = fire(marking, t)
            key = (freeze(m2), nxt)
            if key not in seen:
                seen.add(key)
                queue.append((m2, nxt))
    return complete, dead


def sampled_language(net, im, fm, n=2000):
    """HEURISTIC: random playout. Returns a SAMPLE, never a proof of absence."""
    log = pm4py.play_out(net, im, fm, parameters={"noTraces": n})
    out = set()
    for trace in log:
        t = tuple(e["concept:name"] for e in trace)
        if within_bound(t):
            out.add(t)
    return out


def reference_language_A():
    """Grammar: O ((An Ch | Ch An) Ap?) (R (An Ch | Ch An) Ap?)* C."""
    attempts = [order + (("Approve Revision",) if ap else ())
                for order in (("Analyze Revision", "Check Revision"),
                              ("Check Revision", "Analyze Revision"))
                for ap in (False, True)]
    out = set()
    for k in range(1, MAX_ANALYZE + 1):
        for combo in itertools.product(attempts, repeat=k):
            body = []
            for i, att in enumerate(combo):
                body += (["Rework Case"] if i else []) + list(att)
            t = ("Open Case", *body, "Close Case")
            if within_bound(t):
                out.add(t)
    return out


def reference_language_B():
    """Grammar: O (Ch shuffle An Ap? (R An Ap?)*) C."""
    out = set()
    for k in range(1, MAX_ANALYZE + 1):
        for aps in itertools.product((False, True), repeat=k):
            loop = []
            for i, ap in enumerate(aps):
                loop += (["Rework Case"] if i else []) + ["Analyze Revision"]
                loop += ["Approve Revision"] if ap else []
            for pos in range(len(loop) + 1):
                t = ("Open Case", *loop[:pos], "Check Revision", *loop[pos:], "Close Case")
                if within_bound(t):
                    out.add(t)
    return out


def main():
    lang = {}
    for name, s, ref in (("A", MODEL_A, reference_language_A()),
                         ("B", MODEL_B, reference_language_B())):
        _, net, im, fm, sound = build(s)
        exact, dead = exhaustive_bounded_language(net, im, fm)
        sample = sampled_language(net, im, fm)
        print(f"Model {name}: sound={sound} | net P/T/F = {len(net.places)}/"
              f"{len(net.transitions)}/{len(net.arcs)} | silent transitions = "
              f"{sum(t.label is None for t in net.transitions)}")
        print(f"  [EXHAUSTIVE] bounded complete traces: {len(exact)}, "
              f"deadlocked prefixes: {len(dead)}, matches grammar: {exact == ref}")
        print(f"  [HEURISTIC]  distinct bounded traces seen in play_out: {len(sample)} "
              f"(subset of exhaustive: {sample <= exact}; missing: {len(exact - sample)})")
        lang[name] = exact

    a, b = lang["A"], lang["B"]
    print(f"common={len(a & b)}  A-only={len(a - b)}  B-only={len(b - a)}")
    print("P3 verdict:", "equivalent within bound (evidence only)" if a == b
          else "NOT equivalent (conclusive: witnesses are real traces)")
    for label, s in (("common", a & b), ("A-only", a - b), ("B-only", b - a)):
        print(f"--- {label} ---")
        for t in sorted(s, key=lambda x: (len(x), x)):
            print("  ", show(t))


if __name__ == "__main__":
    main()
```

**Output obtained with pm4py 2.7.23.4 (abridged):**

```text
Model A: sound=True | net P/T/F = 9/9/20 | silent transitions = 3
  [EXHAUSTIVE] bounded complete traces: 76, deadlocked prefixes: 0, matches grammar: True
  [HEURISTIC]  distinct bounded traces seen in play_out: 76 (subset of exhaustive: True; ...)
Model B: sound=True | net P/T/F = 7/7/16 | silent transitions = 1
  [EXHAUSTIVE] bounded complete traces: 85, deadlocked prefixes: 0, matches grammar: True
  [HEURISTIC]  distinct bounded traces seen in play_out: 75-76 (subset of exhaustive: True; missing: 9-10)
common=4  A-only=72  B-only=81
P3 verdict: NOT equivalent (conclusive: witnesses are real traces)
```

The counts match the closed forms:
- |L≤(A)| = 4 + 16 + (64 − 8) = 76. With k attempts and a approvals, A's traces have 3k + 1 + a events, so for k = 3 only a ≤ 2 fits.
- |L≤(B)| = Σ_k Σ_a C(k, a)(2k + a) = 5 + 20 + 60 = 85. B's traces have 2k + 2 + a ≤ 11 events.

**Why play_out is not exhaustive.** `pm4py.play_out` resolves choices randomly, so it can only *confirm* that sampled traces exist. It cannot prove that a trace is absent. With 2,000 sampled traces, it missed 9 to 10 of B's 85 bounded traces across runs, typically the low-probability long interleavings. The exact number varies from run to run, which is itself a sign of non-exhaustiveness. A random-playout comparison could therefore wrongly declare "trace T is unique to A" merely because B's version of T was never sampled. Only the BFS result supports the P3 verdict.

# 6. Stochastic and Footprint Comparison

**Footprints (`pm4py.discover_footprints`).** Footprints are built from the directly-follows relation: → (causal), ∥ (both directions), # (never adjacent). Analytically, and confirmed by pm4py for both the trees and the converted nets, the two footprints differ in **exactly one cell**:
- In A, (Ch, Ap) is a sequence relation Ch → Ap, because Ap never directly precedes Ch.
- In B, Ch ∥ Ap, because of `O An Ap Ch C`.

Everything else is identical, including An ∥ Ch, An ∥ R and Ch ∥ R in *both* models (e.g. `… Ch R Ch …` in A; `… Ch R …` and `… R Ch …` in B). So the footprint catches only the approval-placement difference and completely misses the fundamental one, the number of checks.

Equal footprints do not establish equivalence. Remove approval from both models:
- A′ = `->('Open Case', *(+('Analyze Revision','Check Revision'), 'Rework Case'), 'Close Case')`
- B′ = `->('Open Case', +('Check Revision', *('Analyze Revision','Rework Case')), 'Close Case')`

Their footprints are identical (verified: equal sequence and parallel relations and equal start/end activities, for both trees and nets). Yet `O An Ch R An Ch C` ∈ L(A′) \ L(B′). Directly-follows abstractions cannot count occurrences and cannot express "exactly once" versus "once per iteration".

**Stochastic languages (`pm4py.get_stochastic_language`) and EMD (`pm4py.compute_emd`).**
- The process trees carry **no probabilities**. Applied to an accepting net, `get_stochastic_language` in pm4py 2.7.23.4 obtains the distribution by playout. It returned about 200 variants with *sampled* frequencies (208 in one run, 201 in another), which reflect the playout engine's implicit random-choice policy and sampling noise, not business probabilities. That output must be treated as an undeclared assumption.
- I therefore construct the languages explicitly with **declared** parameters:
  - P(exit loop after an attempt) = 0.6, and P(approval in an attempt) = 0.5;
  - in A, the An/Ch order is 50/50;
  - in B, Ch's position is uniform over the (len + 1) insertion slots of the loop trace;
  - truncation at ≤ 3 attempts, then renormalisation.

```python
# Append to the Section 5 script (reuses MODEL_A, MODEL_B, build,
# exhaustive_bounded_language). All probabilities below are DECLARED ASSUMPTIONS.
import itertools
import pm4py

def footprint_diff(x, y):
    for key in ("sequence", "parallel", "start_activities", "end_activities"):
        if key in x and key in y and x[key] != y[key]:   # net footprints may lack some keys
            print(f"  {key}: only A {set(x[key]) - set(y[key])}, only B {set(y[key]) - set(x[key])}")

tA, netA, imA, fmA, _ = build(MODEL_A)
tB, netB, imB, fmB, _ = build(MODEL_B)
print("tree footprints:"); footprint_diff(pm4py.discover_footprints(tA), pm4py.discover_footprints(tB))
print("net footprints:");  footprint_diff(pm4py.discover_footprints(netA, imA, fmA),
                                          pm4py.discover_footprints(netB, imB, fmB))

def stochastic_A(p_exit, p_ap, kmax=3):
    per = [(o + (("Approve Revision",) if ap else ()), 0.5 * (p_ap if ap else 1 - p_ap))
           for o in (("Analyze Revision", "Check Revision"), ("Check Revision", "Analyze Revision"))
           for ap in (0, 1)]
    lang = {}
    for k in range(1, kmax + 1):
        pk = (1 - p_exit) ** (k - 1) * p_exit
        for combo in itertools.product(per, repeat=k):
            body, p = [], pk
            for i, (att, pa) in enumerate(combo):
                body += (["Rework Case"] if i else []) + list(att)
                p *= pa
            t = ("Open Case", *body, "Close Case")
            lang[t] = lang.get(t, 0.0) + p
    z = sum(lang.values())
    return {t: p / z for t, p in lang.items() if p > 0}

def stochastic_B(p_exit, p_ap, kmax=3):
    lang = {}
    for k in range(1, kmax + 1):
        pk = (1 - p_exit) ** (k - 1) * p_exit
        for aps in itertools.product((0, 1), repeat=k):
            loop, p = [], pk
            for i, ap in enumerate(aps):
                loop += (["Rework Case"] if i else []) + ["Analyze Revision"]
                loop += ["Approve Revision"] if ap else []
                p *= p_ap if ap else 1 - p_ap
            for pos in range(len(loop) + 1):
                t = ("Open Case", *loop[:pos], "Check Revision", *loop[pos:], "Close Case")
                lang[t] = lang.get(t, 0.0) + p / (len(loop) + 1)
    z = sum(lang.values())
    return {t: p / z for t, p in lang.items() if p > 0}

for p_exit, p_ap in ((0.6, 0.5), (1.0, 0.5), (1.0, 0.0)):
    emd = pm4py.compute_emd(stochastic_A(p_exit, p_ap), stochastic_B(p_exit, p_ap))
    print(f"declared p_exit={p_exit}, p_approve={p_ap}: EMD = {emd:.4f}")

a_set, _ = exhaustive_bounded_language(netA, imA, fmA)
b_set, _ = exhaustive_bounded_language(netB, imB, fmB)
uniform = lambda s: {t: 1 / len(s) for t in s}           # declared: uniform over L<=
print("uniform over bounded languages: EMD =", round(pm4py.compute_emd(uniform(a_set), uniform(b_set)), 4))

sampled = pm4py.get_stochastic_language(netA, imA, fmA)  # playout-based, NOT declared
print("playout-based stochastic language of A:", len(sampled), "variants (sampled frequencies)")
```

**Observed values** (pm4py 2.7.23.4, whose EMD uses a normalised-edit-distance ground cost):

| Declared distribution | EMD(A, B) |
|---|---|
| p_exit = 0.6, p_approve = 0.5, truncated at 3 attempts | 0.1066 |
| p_exit = 1.0 (single attempt only), p_approve = 0.5 | 0.0667 |
| p_exit = 1.0, p_approve = 0.0 | 0.0000 |
| uniform over L≤(A) and L≤(B) | 0.1822 |

The single-attempt value can be checked by hand:
- A puts 0.25 on each of its 4 traces.
- B puts 0.25 on each of the two approval-free traces and 1/6 on each of its three approval traces.
- Moving 1/12 from each of A's two approval traces to `O An Ap Ch C` costs 2 edits out of 5, i.e. 0.4. Total: 1/6 × 0.4 = 0.0667.

**Why a low EMD (or equal footprints) still does not establish trace equivalence.**
1. EMD compares *distributions*, not supports. Traces with zero or negligible probability contribute nothing. The degenerate but legal assignment "never rework, never approve" gives **EMD = 0**, while the languages differ in infinitely many traces.
2. The ground cost is an edit distance. The P1-critical difference, one missing Ch per extra attempt, costs only one edit, so a compliance-breaking difference looks "small".
3. Every number above depends on declared probabilities and on truncation. Change them and the EMD changes, while L(A) and L(B) do not.
4. Footprints discard counts and non-local order (shown above with A′/B′).

These techniques can add **negative evidence**: a non-zero EMD or a differing footprint cell proves the models differ. They can also help *rank* how different the models are under an assumed workload. They can never provide positive proof of equivalence.

**Interpretation.** On the tree level the models are the same size, and B is one level deeper. B's net is *smaller*: O acts directly as AND-split and C as AND-join, so only the approval skip remains silent. Yet B scores *lower* on arc-degree simplicity, because the metric measures arc density, not size or understandability. None of these metrics sees that B is semantically *weaker*: a smaller model that admits non-compliant behaviour is not a better model of P1. Similar size and identical activity sets clearly do not imply equal behaviour.

# Structural counts (reuses MODEL_A, MODEL_B, one_line, build from Section 5).
from collections import Counter
import pm4py

def tree_stats(node, depth=0):
    """Returns (nodes, max_depth, visible_leaves, silent_leaves, visible_labels)."""
    if not node.children:
        vis = node.label is not None
        return 1, depth, int(vis), int(not vis), [node.label] if vis else []
    n, d, v, s, labels = 1, depth, 0, 0, []
    for child in node.children:
        cn, cd, cv, cs, cl = tree_stats(child, depth + 1)
        n, d, v, s, labels = n + cn, max(d, cd), v + cv, s + cs, labels + cl
    return n, d, v, s, labels

for name, s in (("A", MODEL_A), ("B", MODEL_B)):
    tree, net, im, fm, _ = build(s)
    n, d, v, sil, labels = tree_stats(tree)
    dups = sum(c - 1 for c in Counter(labels).values() if c > 1)
    print(f"{name}: nodes={n} depth={d} visible={v} silent={sil} duplicate_labels={dups} | "
          f"net P/T/F={len(net.places)}/{len(net.transitions)}/{len(net.arcs)} "
          f"silent_T={sum(t.label is None for t in net.transitions)} "
          f"simplicity={pm4py.simplicity_petri_net(net, im, fm):.4f}")

# 8. Simplified Model

**Target semantics: P1**, i.e. exact visible trace equivalence with Model A. Reasons:
- P1 is the only view that encodes the business rule, one check per revision before the next rework or close.
- P2 observations can be *computed* from a P1-exact model by applying α₂, but P1 cannot be recovered from a P2 model.
- P3 is a testing regime, not a purpose.

A single simplification **cannot** preserve all three views relative to *both* originals, because A and B are themselves inequivalent under P1 and P3. The target is therefore P1-exact with respect to A, which automatically gives P2-exactness with respect to both originals and P3-exactness with respect to A.

**1. Compact expression (POWL).** Each attempt is written as one partial order instead of a nested sequence + parallel:

```text
PO{ Open Case < LOOP( PO{ Analyze Revision < X(Approve Revision, tau),
                          Check Revision   < X(Approve Revision, tau) },
                      Rework Case )
               < Close Case }
```

*Exactness proof (unbounded).* The linearisations of the strict partial order {An < X, Ch < X}, with An and Ch unordered, are exactly An·Ch·X and Ch·An·X. That is the language of `->(+(An, Ch), X)`. The outer partial order is total (O < LOOP < C), i.e. a sequence, and the loop operator and its children are unchanged. By compositional semantics, L(simplified) = L(A) for all lengths. The bounded check (76 = 76 traces, identical sets) is consistent with this.

A plain process tree cannot do better while staying exact. Every exact tree needs:
- the 6 visible leaves;
- an optional-approval construct (X plus τ);
- a loop;
- an outer sequence;
- a construct making An and Ch unordered and both preceding the approval choice.

That last requirement costs + and → in a tree (12 nodes, the size of A). Moving the approval choice into the redo part would lose the approval of the final attempt unless Ap is duplicated. Only a partial-order node merges the two operators.

**2. PM4Py code.**

```python
import pm4py
from pm4py.objects.powl.obj import StrictPartialOrder, OperatorPOWL, Transition, SilentTransition
from pm4py.objects.process_tree.obj import Operator

open_case  = Transition(label="Open Case")
analyze    = Transition(label="Analyze Revision")
check      = Transition(label="Check Revision")
approve    = Transition(label="Approve Revision")
rework     = Transition(label="Rework Case")
close_case = Transition(label="Close Case")

optional_approval = OperatorPOWL(operator=Operator.XOR, children=[approve, SilentTransition()])

attempt = StrictPartialOrder(nodes=[analyze, check, optional_approval])
attempt.order.add_edge(analyze, optional_approval)      # approval only after analysis ...
attempt.order.add_edge(check, optional_approval)        # ... and after this revision's check

revision_loop = OperatorPOWL(operator=Operator.LOOP, children=[attempt, rework])

simplified_model = StrictPartialOrder(nodes=[open_case, revision_loop, close_case])
simplified_model.order.add_edge(open_case, revision_loop)
simplified_model.order.add_edge(revision_loop, close_case)
simplified_model.order.add_edge(open_case, close_case)  # transitive closure

# Optional verification (reuses build, exhaustive_bounded_language, show, MODEL_A from Section 5)
net_s, im_s, fm_s = pm4py.convert_to_petri_net(simplified_model)
res = pm4py.check_soundness(net_s, im_s, fm_s, print_diagnostics=False)
s_lang, s_dead = exhaustive_bounded_language(net_s, im_s, fm_s)
_, net_a, im_a, fm_a, _ = build(MODEL_A)
a_lang, _ = exhaustive_bounded_language(net_a, im_a, fm_a)
print("sound:", res[0] if isinstance(res, tuple) else res,
      "| bounded traces:", len(s_lang), "| equal to Model A:", s_lang == a_lang)

T = lambda s: tuple({"O": "Open Case", "An": "Analyze Revision", "Ch": "Check Revision",
                     "Ap": "Approve Revision", "R": "Rework Case", "C": "Close Case"}[x]
                    for x in s.split())
positive = ["O An Ch C", "O Ch An Ap C", "O An Ch Ap R Ch An C",
            "O Ch An R An Ch Ap R An Ch C"]
negative = ["O An Ap Ch C", "O An R An Ch C", "O An Ch Ap Ap C", "O An Ch R C"]
assert all(T(s) in s_lang for s in positive)
assert not any(T(s) in s_lang for s in negative)   # all negatives lie within the P3 bound
print("regression suite passed")
```

# 9. Final Recommendation

- **P1 (operational compliance):** Model A is suitable; Model B is **not**. B describes a different process, one check covering all revisions, and admits violations such as `O An R An Ch C` as well as approval before check. B should be treated as incorrect for P1, not as an alternative notation.
- **P2 (executive dashboard):** Both models are acceptable, but *only* under the stated abstraction α₂. The dashboard should be computed from A (or from logs conformant to A), because P2 cannot see the P1 difference. Agreement on the dashboard therefore says nothing about compliance.
- **P3 (bounded testing):** The models are not equivalent (76 vs 85 bounded traces, only 4 shared). Model A, or the simplified model, should serve as the test oracle.
- **Simplified model:** The POWL model may replace **Model A** as its presentation form, where POWL tooling is available. It is provably trace-equivalent and one operator smaller, but the gain is modest and its converted Petri net is slightly larger. It must **not** be described as equivalent to Model B; replacing B with it is a *correction* of B's semantics. The 7-node P2 canonical model is a reporting artefact only.

**Warning on bounded comparison.** The P3 exploration is exhaustive only inside its bound (≤ 12 events, ≤ 3 analyses). Here it yields a conclusive *non*-equivalence, since every witness is a genuine trace. Had the bounded sets been equal, that would have been evidence, not proof: loops generate traces beyond any finite bound. Unbounded claims in this document, such as the exactness of the simplified model and the P2 equivalence, rest on the compositional and counting proofs given, not on the bounded run. Random playout, footprints, and EMD under declared probabilities can only corroborate differences; they cannot establish equivalence.
