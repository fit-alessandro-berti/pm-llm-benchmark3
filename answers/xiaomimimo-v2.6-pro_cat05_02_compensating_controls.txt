Section 2 details: structured test — I'll give a scored gate test:

Gate A — Objective coverage: does the package cover the specific threat vector (self-authorization, solo fraud, collusion, master-data fraud, non-receipt, out-of-scope matters)? AV-2 clean pass covers only its enumerated checks.
Gate B — Control moment (timing): relative to (i) instruction issuance, (ii) irrevocable settlement. Preventive-equivalent requires independent judgment before (i); recoverable-equivalent before (ii); otherwise detective only.
Gate C — Independence in fact: organizational (no reporting line/COI), credential (no shared accounts, no shared override credentials), physical/session (no shared workstation/session), role (L3+, not preparer/releaser), and temporal (pair rotation).
Gate D — Overrideability: can the layer be bypassed by the same actor or their confederate? If yes, it is not a compensating control against collusion or solo fraud — it only compensates honest-error risk.
Gate E — Recoverability: is the package complete before the recall window closes? Otherwise no corrective capacity.
Gate F — Evidence quality: substantive review documented (invoice, bank details, receipt), signed, timestamped, tamper-evident, with attributes reviewed; rubber-stamp weak.
Gate G — Collusion resistance: needs two mutually unaligned humans with different incentives; a single-operator release + a conflicted supervisor's late ratification has collusion resistance  0.
Gate H — Residual magnitude and severity caps: risk appetite.

Tiers:
- Fully equivalent = A covered + B preventive-equivalent + C satisfied + D not bypassable by the actor + F substantive + G maintained  OBJECTIVE_MET.
- Partially equivalent = A covered (or partially) + B recoverable-equivalent (pre-settlement) + C satisfied + E satisfied + F substantive  OBJECTIVE_PARTIALLY_MET.
- Merely mitigating = some of A/B/C fail; risk reduced but vector open  OBJECTIVE_PARTIALLY_MET (tolerable only when intrinsic severity is low) or OBJECTIVE_FAILED if the vector realizes.
- Ineffective = bypassed/out-of-scope/conflicted/post-irrevocable  OBJECTIVE_FAILED.
