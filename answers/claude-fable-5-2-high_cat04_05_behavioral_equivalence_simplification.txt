# 1. Equivalence Notions

**Verdict in one line:** Models A and B are *not* equivalent under P1 or P3 (and therefore not visible-trace equivalent at all); they are equivalent *only* under the lossy dashboard abstraction of P2.

Abbreviations used in formulas: `O` = Open Case, `An` = Analyze Revision, `Ch` = Check Revision, `Ap` = Approve Revision, `Rw` = Rework Case, `Cl` = Close Case. `k` always denotes the number of `An` occurrences in a trace (the number of analysis attempts).

**Observation boundary.** Only complete executions are observed (root of the tree finished, or the accepting Petri net in exactly its final marking). An observation is the sequence of visible labels; the `tau` leaf and every silent transition introduced by the Petri-net conversion are unobservable, and so is the moment at which a choice is made. All notions below are therefore linear-time (language) notions, not bisimulations.

**Closed forms of the two visible languages** (derived from the binary-loop semantics; `⧢` is the shuffle/interleaving operator):

- `L(A) = O · X · (Rw · X)* · Cl`, with `X = (An·Ch | Ch·An) · (Ap | ε)`
- `L(B) = O · ( Ch ⧢ ( Y · (Rw · Y)* ) ) · Cl`, with `Y = An · (Ap | ε)`

| Notion | Definition | What it ignores |
|---|---|---|
| Visible trace equivalence after hiding `tau` | `L(M)` = set of label sequences of complete runs with silent steps deleted. `M1 ≈ M2` iff `L(M1) = L(M2)` (unbounded, both inclusions). | Silent steps, branching structure, probabilities. |
| Bounded visible-language equivalence (P3) | `L≤(M) = { σ ∈ L(M) : len(σ) ≤ 12 and #An(σ) ≤ 3 }`. `M1 ≈P3 M2` iff `L≤(M1) = L≤(M2)`. | Everything outside the bound. A difference inside the bound is a real counterexample to trace equivalence; equality inside the bound would only be evidence. |
| Business-relevant equivalence (P1) | Split the part of a trace between `O` and `Cl` at every `Rw` into *attempt segments*. `π1(σ)` = (first label, list of attempt records, last label), where a record is `(#An, #Ch, placements)` and `placements` lists, for each `Ap` in the segment, the pair (number of `An` before it, number of `Ch` before it) inside that segment. **P1 rule:** every record has exactly one `An` and exactly one `Ch` (each analysis has its own check before the next `Rw` or `Cl`). `M1 ≈P1 M2` iff `π1(L(M1)) = π1(L(M2))`; a model is *P1-compliant* iff all its traces satisfy the P1 rule. | Only the relative order of `An` and `Ch` inside one attempt (P1 demands the check before the next `Rw`/`Cl`, not after the analysis). The number of attempts, checks per attempt, and the number and placement of approvals stay visible. |
| Abstracted dashboard equivalence (P2) | `π2(σ) = (O is first, Cl is last, #An, Ch occurred?, Rw occurred?)` after deleting `Ap` and silent steps. `M1 ≈P2 M2` iff `π2(L(M1)) = π2(L(M2))`; additionally every trace must satisfy `#An ≥ 1` and `Ch occurred`. | Number of checks, approvals, number of reworks, all interleavings. |

Implications: trace equivalence ⇒ P3 equivalence; trace equivalence ⇒ P1 equivalence ⇒ P2 equivalence (π2 is computable from π1). No converse holds. P3 inequality ⇒ trace inequality.

**Duplicate visible labels.** Events are distinguished by **label and position in the trace**, never by identity: neither model carries a revision ID. Neither tree has two leaves with the same label (duplicate-label count 0 in both); repeated labels arise only from loop iterations. Consequently:

- trace and P3 equivalence: label + position (two `Ch` events at different positions are different observations, and their number matters);
- P1: "its own check" is bound to an analysis *positionally*, through the attempt segment delimited by `Rw`;
- P2: `Ch` and `Rw` by label only (Boolean presence), `An` by label and multiplicity, no position except first/last for `O`/`Cl`.

# 2. Structural Comparison

| Feature | Model A | Model B | Semantic consequence |
|---|---|---|---|
| Loop scope | Loop "do" part = `->( +(An, Ch), X(Ap, tau) )`; redo = `Rw`. The check is inside the repeated part. | Loop "do" part = `->( An, X(Ap, tau) )`; redo = `Rw`. The check is outside the loop, a sibling of the whole loop. | In A every iteration re-executes the check; in B the loop repeats analysis (and approval) without ever repeating the check. |
| Minimum `Ch` occurrences | 1 (loop body runs at least once) | 1 (mandatory branch of the parallel block) | Both guarantee "at least one check" — this is all P2 looks at. |
| Maximum `Ch` occurrences | Unbounded; always `#Ch = #An = k` | 1; always `#Ch = 1` regardless of `k` | For `k ≥ 2` the multisets of labels already differ, so no trace with a rework is shared. |
| Possible placement of `Ch` | Once per attempt, before or after that attempt's `An`, always before that attempt's `Ap`, `Rw` or `Cl`. | Anywhere strictly between `O` and `Cl`: before the first analysis, inside any attempt, between an approval and a rework, after the last approval. With `k` analyses and `a` approvals there are `2k + a` slots. | A gives a per-revision guarantee; B gives only a per-case guarantee. In B, attempts can be reworked, approved and closed without a check of their own. |
| Optional approval occurrences | 0..k, at most one per attempt, enabled only after both `An` and `Ch` of the same attempt | 0..k, at most one per attempt, enabled directly after `An`, independent of `Ch` | The approval *count* range is identical; the approval *placement* differs (approval before, or entirely without, a check is possible only in B). |
| Concurrency | Local: `An ∥ Ch` inside each iteration (2 interleavings per attempt). `4^k` traces for `k` attempts. | Global: `Ch ∥` (entire loop). `5k · 2^(k-1)` traces for `k` attempts (5, 20, 60, …). | Different concurrency regions; B's region spans rework and approval decisions, A's does not. |
| Join before `Cl` | AND-join is inside the iteration (before the approval choice). `Cl` only needs the loop exit. | `Cl` itself synchronises the two branches: it needs the loop exited **and** the single check done. | A: "all revisions checked" is established before each rework and before closing. B: only "one check happened sometime" is established before closing. |
| Silent behaviour | One `tau` leaf (skip approval). pm4py net: 3 silent transitions (skip, AND-split, AND-join). | One `tau` leaf (skip approval). pm4py net: 1 silent transition (skip); `O` and `Cl` act as split/join. | Silent steps differ in number but never in visible effect; raw firing sequences must not be compared. |

**Language relation (proof).** In `L(A)`, `#Ch = #An`; in `L(B)`, `#Ch = 1`. A shared trace therefore has `k = 1`. For `k = 1`, `L(A)` contributes exactly `O An Ch Cl`, `O Ch An Cl`, `O An Ch Ap Cl`, `O Ch An Ap Cl`, all of which are in `L(B)`; `L(B)` has one more, `O An Ap Ch Cl`, which is not in `L(A)` because `Ap` is enabled in A only after the AND-join of `An` and `Ch`. Hence:

- `L(A) ∩ L(B)` = exactly these 4 traces;
- `L(A) \ L(B)` = all A-traces with at least one rework (infinitely many);
- `L(B) \ L(A)` = `O An Ap Ch Cl` plus all B-traces with at least one rework (infinitely many).

Neither inclusion holds, so the languages are incomparable.

# 4. Counterexample Traces

All traces are complete visible traces; membership of every row was replayed on the pm4py accepting nets with the exact membership test given in Section 8.

An approved but unchecked revision is closed. | P1, P3 |
| B4 | ⟨Open Case, Analyze Revision, Rework Case, Analyze Revision, Rework Case, Analyze Revision, Approve Revision, Check Revision, Close Case⟩ | rejected | accepted | Event 3; one late check "covers" three analyses and comes after the final approval. | P1, P3 |

| C2 (control) | ⟨Open Case, Analyze Revision, Close Case⟩ | rejected | rejected | Both require at least one check before closing (A: AND-join inside the body; B: `Cl` synchronises with the check branch). | all |

**Effect of the optional `Approve Revision`.** The number of approvals never separates the models: both allow 0..k approvals, at most one per attempt. The *placement* does. In A an approval certifies an analysed **and** checked revision; in B it follows the analysis only. B1 is the sole single-attempt counterexample and exists purely because of this placement; it disappears as soon as `Ap` is hidden. B3 shows the business impact: a revision that is approved without ever being checked.

**Effect of the hidden `tau`.** The `tau` leaf only encodes "no approval event" (auto-approval). Under trace semantics it is indistinguishable from never offering the approval, so it creates no counterexample on its own and both models are affected identically. Two technical consequences: (i) comparisons must use the visible projection, because the converted nets contain different numbers of silent transitions (3 in A, 1 in B) and raw firing sequences would differ spuriously; (ii) because the skip is silent, an auto-approval leaves no evidence in the trace, so "approved" cannot be checked from traces alone in either model.

**Why P2 still says "equivalent".** All three P2 abstractions are needed together. Without hiding `Ap`, B1 separates the models. Without collapsing the check count, A1 separates them. Without forgetting where the check sits, B2 separates them (in A the first check always precedes the first rework). With all three applied, A1–A3 and B2–B4 map to views that the other model also produces.

# 5. Bounded Comparison Code

The script performs an **exhaustive** breadth-first search over `(marking, visible prefix)` states. It then runs a **random playout** separately and labels it as heuristic. Tested with pm4py 2.7.23.4.

```python
from collections import deque

import pm4py
from pm4py.objects.petri_net.obj import Marking

MODEL_A = ("->( 'Open Case', *( ->( +( 'Analyze Revision', 'Check Revision' ), "
           "X( 'Approve Revision', tau ) ), 'Rework Case' ), 'Close Case' )")
MODEL_B = ("->( 'Open Case', +( 'Check Revision', *( ->( 'Analyze Revision', "
           "X( 'Approve Revision', tau ) ), 'Rework Case' ) ), 'Close Case' )")

MAX_VISIBLE = 12
MAX_ANALYZE = 3
ANALYZE = "Analyze Revision"


def freeze(marking):
    """Hashable multiset view of a marking; used for equality and the visited set."""
    return frozenset((place, n) for place, n in marking.items() if n > 0)


def fire(marking, transition):
    """Explicit token-game step (arc weights respected, empty places dropped)."""
    counts = dict(marking)
    for arc in transition.in_arcs:
        counts[arc.source] = counts.get(arc.source, 0) - arc.weight
    for arc in transition.out_arcs:
        counts[arc.target] = counts.get(arc.target, 0) + arc.weight
    result = Marking()
    for place, n in counts.items():
        if n > 0:
            result[place] = n
    return result


def bounded_visible_language(net, im, fm, max_visible=MAX_VISIBLE, max_analyze=MAX_ANALYZE):
    """EXHAUSTIVE breadth-first exploration under the P3 bound.

    State = (marking, visible prefix).
    - Silent transitions (label None) change the marking but not the prefix, so a
      silent cycle returns to an already visited state and is cut by `seen`.
    - A visible step is taken only if the extended prefix stays within the bound.
      Both bounds are monotone in the prefix, so no admissible trace is lost.
    - A prefix is reported only when the marking EQUALS the final marking.
    The state space is finite because prefixes are bounded and the nets are safe."""
    final = freeze(fm)
    seen = {(freeze(im), ())}
    queue = deque([(im, ())])
    language = set()
    while queue:
        marking, prefix = queue.popleft()
        if freeze(marking) == final:
            language.add(prefix)
        for transition in pm4py.get_enabled_transitions(net, marking):
            if transition.label is None:
                new_prefix = prefix
            else:
                new_prefix = prefix + (transition.label,)
                if len(new_prefix) > max_visible:
                    continue
                if new_prefix.count(ANALYZE) > max_analyze:
                    continue
            new_marking = fire(marking, transition)
            state = (freeze(new_marking), new_prefix)
            if state not in seen:
                seen.add(state)
                queue.append((new_marking, new_prefix))
    return language


def load(tree_string, name):
    tree = pm4py.parse_process_tree(tree_string)
    net, im, fm = pm4py.convert_to_petri_net(tree)
    result = pm4py.check_soundness(net, im, fm, print_diagnostics=False)
    is_sound = result[0] if isinstance(result, tuple) else bool(result)
    silent = sum(1 for t in net.transitions if t.label is None)
    print(f"{name}: sound={is_sound}, places={len(net.places)}, "
          f"transitions={len(net.transitions)}, silent={silent}")
    return tree, net, im, fm


def show(title, traces):
    print(f"\n{title}: {len(traces)}")
    for trace in sorted(traces, key=lambda t: (len(t), t)):
        print("   ", " | ".join(trace))


def random_sample(tree, n=2000):
    """HEURISTIC: random playout. Not exhaustive, and not a proof of anything."""
    sampled = set()
    for trace in pm4py.play_out(tree, parameters={"num_traces": n}):
        visible = tuple(event["concept:name"] for event in trace)
        if len(visible) <= MAX_VISIBLE and visible.count(ANALYZE) <= MAX_ANALYZE:
            sampled.add(visible)
    return sampled


if __name__ == "__main__":
    tree_a, net_a, im_a, fm_a = load(MODEL_A, "Model A")
    tree_b, net_b, im_b, fm_b = load(MODEL_B, "Model B")

    lang_a = bounded_visible_language(net_a, im_a, fm_a)
    lang_b = bounded_visible_language(net_b, im_b, fm_b)

    print("\n=== EXHAUSTIVE within the P3 bound (<= 12 visible events, <= 3 Analyze) ===")
    print(f"|L(A)| = {len(lang_a)}, |L(B)| = {len(lang_b)}, shared = {len(lang_a & lang_b)}")
    show("Shared traces", lang_a & lang_b)
    show("Traces unique to Model A", lang_a - lang_b)
    show("Traces unique to Model B", lang_b - lang_a)
    print("\nP3 verdict:", "EQUAL within the bound (evidence only, not a proof)"
          if lang_a == lang_b else "NOT EQUAL (each unique trace is a real counterexample)")

    print("\n=== RANDOM playout (heuristic, incomplete) ===")
    sample_a, sample_b = random_sample(tree_a), random_sample(tree_b)
    print(f"sample covers {len(sample_a)}/{len(lang_a)} bounded traces of A and "
          f"{len(sample_b)}/{len(lang_b)} of B")
    print("sampled A-traces that the exhaustive B-language rejects:", len(sample_a - lang_b))
    print("sampled B-traces that the exhaustive A-language rejects:", len(sample_b - lang_a))
```

Output on my installation (trace listings omitted):

```text
Model A: sound=True, places=9, transitions=9, silent=3
Model B: sound=True, places=7, transitions=7, silent=1
|L(A)| = 76, |L(B)| = 85, shared = 4
Traces unique to Model A: 72
Traces unique to Model B: 81
P3 verdict: NOT EQUAL (each unique trace is a real counterexample)
sample covers 74/76 bounded traces of A and 85/85 of B     (varies per run)
```

Notes:

- `pm4py.check_soundness` returns `(bool, diagnostics)` and emits a deprecation warning in recent releases; it still works in 2.7.x.
- `play_out` is not exhaustive: it draws runs at random, can miss rare variants (the run above missed 2 of A's 76 traces; another run missed 4 of B's 85), and stops loops according to its own random policy. Equality of two samples proves nothing. A sampled trace is useful only as a candidate witness that is then re-checked against the exhaustive language of the other model.
- `pm4py.convert_to_reachability_graph(net, im, fm)` is an alternative basis for the search (both nets are safe and finite), but the visible-length bound and the silent closure still have to be handled as above.

# 6. Stochastic and Footprint Comparison

**Footprints (`pm4py.discover_footprints`).** Footprints abstract the language to start/end activities, directly-follows "sequence" pairs and "parallel" pairs. They are a necessary-condition test: a footprint difference (on exactly computed model footprints) implies a language difference; equal footprints imply nothing.

Result for the two models: start activities, end activities, activity set, always-happening activities `{O, An, Ch, Cl}` and minimum trace length (4) are identical. The only difference is the relation between `Ch` and `Ap`:

- Model A: `(Check Revision, Approve Revision)` is a *sequence* pair;
- Model B: `Check Revision` and `Approve Revision` are *parallel* (both orders occur).

So the footprints detect the B1-type difference (approval before check) but are blind to the more important one, the number of checks: `#Ch = k` versus `#Ch = 1` produces the same directly-follows pairs because the loop makes `Ch`, `An` and `Rw` mutually "parallel" in both models. The code below proves the point: with the approval removed from both trees, the footprints become **identical** although A1 (`O An Ch Rw An Ch Cl`) and B2 (`O An Rw An Ch Cl`) still separate the languages.

**Stochastic language and EMD.** A process tree or plain Petri net has no probabilities. For a model, `pm4py.get_stochastic_language(net, im, fm)` runs a random playout and returns relative variant frequencies, so the probabilities are an artefact of the simulator's choice policy and of sampling noise, not a property of the process. `pm4py.compute_emd` then measures how much probability mass must be moved, weighted by normalised edit distance between traces. This adds *graded* evidence ("how far apart, if behaviour were distributed like this"), which is useful for prioritising; it cannot decide equivalence.

To avoid hidden probabilities, the code also builds two explicit stochastic languages from **declared assumptions**: rework probability `r` after each attempt, approval probability `a`, both `An`/`Ch` orders equally likely in A, the single check uniformly placed over its slots in B, truncation at three analyses with renormalisation. These numbers are illustrative assumptions, not estimates.

```python
from itertools import product

import pm4py

O, AN, CH, AP, RW, CL = ("Open Case", "Analyze Revision", "Check Revision",
                         "Approve Revision", "Rework Case", "Close Case")
MODEL_A = ("->( 'Open Case', *( ->( +( 'Analyze Revision', 'Check Revision' ), "
           "X( 'Approve Revision', tau ) ), 'Rework Case' ), 'Close Case' )")
MODEL_B = ("->( 'Open Case', +( 'Check Revision', *( ->( 'Analyze Revision', "
           "X( 'Approve Revision', tau ) ), 'Rework Case' ) ), 'Close Case' )")
A_NO_APPROVE = ("->( 'Open Case', *( +( 'Analyze Revision', 'Check Revision' ), "
                "'Rework Case' ), 'Close Case' )")
B_NO_APPROVE = ("->( 'Open Case', +( 'Check Revision', *( 'Analyze Revision', "
                "'Rework Case' ) ), 'Close Case' )")
FOOTPRINT_KEYS = ("start_activities", "end_activities", "activities",
                  "activities_always_happening", "min_trace_length",
                  "sequence", "parallel")


def compare_footprints(string_1, string_2, title):
    fp_1 = pm4py.discover_footprints(pm4py.parse_process_tree(string_1))
    fp_2 = pm4py.discover_footprints(pm4py.parse_process_tree(string_2))
    print(title)
    for key in FOOTPRINT_KEYS:
        if fp_1[key] == fp_2[key]:
            print(f"   {key}: identical")
        else:
            print(f"   {key}: only first  = {sorted(fp_1[key] - fp_2[key])}")
            print(f"   {key}: only second = {sorted(fp_2[key] - fp_1[key])}")


def declared_language_a(r, a, kmax=3):
    """DECLARED: P(rework)=r, P(approve)=a, Analyze/Check order 50/50, k <= kmax."""
    language = {}
    for k in range(1, kmax + 1):
        p_k = r ** (k - 1) * (1 - r)
        for orders in product([(AN, CH), (CH, AN)], repeat=k):
            for approved in product([True, False], repeat=k):
                p, body = p_k, []
                for i in range(k):
                    if i:
                        body.append(RW)
                    body.extend(orders[i])
                    p *= 0.5 * (a if approved[i] else 1 - a)
                    if approved[i]:
                        body.append(AP)
                trace = (O, *body, CL)
                language[trace] = language.get(trace, 0.0) + p
    total = sum(language.values())
    return {trace: p / total for trace, p in language.items()}


def declared_language_b(r, a, kmax=3):
    """DECLARED: same r and a; the single Check is uniform over its insertion slots."""
    language = {}
    for k in range(1, kmax + 1):
        p_k = r ** (k - 1) * (1 - r)
        for approved in product([True, False], repeat=k):
            p, inner = p_k, []
            for i in range(k):
                if i:
                    inner.append(RW)
                inner.append(AN)
                p *= a if approved[i] else 1 - a
                if approved[i]:
                    inner.append(AP)
            for slot in range(len(inner) + 1):
                trace = (O, *inner[:slot], CH, *inner[slot:], CL)
                language[trace] = language.get(trace, 0.0) + p / (len(inner) + 1)
    total = sum(language.values())
    return {trace: p / total for trace, p in language.items()}


if __name__ == "__main__":
    compare_footprints(MODEL_A, MODEL_B, "Footprints, Model A vs Model B")
    compare_footprints(A_NO_APPROVE, B_NO_APPROVE,
                       "Footprints with Approve removed (languages still differ)")

    print("\nEMD on DECLARED stochastic languages (assumptions, not estimates)")
    for r, a in ((0.5, 0.5), (0.2, 0.5), (0.02, 0.02)):
        lang_a, lang_b = declared_language_a(r, a), declared_language_b(r, a)
        shared = set(lang_a) & set(lang_b)
        print(f"   r={r}, a={a}: EMD={pm4py.compute_emd(lang_a, lang_b):.4f}, "
              f"shared variants={len(shared)}, "
              f"A-mass on shared={sum(lang_a[t] for t in shared):.3f}, "
              f"B-mass on shared={sum(lang_b[t] for t in shared):.3f}")

    print("\nEMD on SAMPLED stochastic languages (simulator policy, sampling noise)")
    net_a, im_a, fm_a = pm4py.convert_to_petri_net(pm4py.parse_process_tree(MODEL_A))
    net_b, im_b, fm_b = pm4py.convert_to_petri_net(pm4py.parse_process_tree(MODEL_B))
    sample_a1 = pm4py.get_stochastic_language(net_a, im_a, fm_a)
    sample_a2 = pm4py.get_stochastic_language(net_a, im_a, fm_a)
    sample_b = pm4py.get_stochastic_language(net_b, im_b, fm_b)
    print(f"   EMD(A, B)  = {pm4py.compute_emd(sample_a1, sample_b):.4f}")
    print(f"   EMD(A, A') = {pm4py.compute_emd(sample_a1, sample_a2):.4f}  (noise floor)")
```

Values obtained (declared languages are deterministic; sampled ones vary per run):

| Setting | EMD(A, B) | Remark |
|---|---|---|
| Declared, `r = 0.5`, `a = 0.5` | 0.1150 | 57% of A's mass and 48% of B's mass lie on the 4 shared variants |
| Declared, `r = 0.2`, `a = 0.5` | 0.0874 | |
| Declared, `r = 0.02`, `a = 0.02` | 0.0055 | 98% / 97% of the mass on shared variants, yet still only 4 shared variants out of 84 / 85 |
| Sampled by pm4py playout | ≈ 0.14 | Two independent samples of the *same* model A were 0.04–0.06 apart |

**Why equal footprints or a low EMD do not establish trace equivalence.**

- Footprints keep only pairwise directly-follows information. They lose occurrence counts and long-range dependencies ("one check per attempt"), so different languages can share a footprint — demonstrated above with the approval-free variants.
- EMD is a distance between *distributions*. It can be made arbitrarily small by shifting probability towards shared variants (third row) while the supports remain almost disjoint; rare behaviour is exactly what compliance cares about. It also uses edit distance, under which A1 and B2 are close although one of them contains an unchecked revision.
- EMD = 0 on sampled languages can occur by chance, and EMD > 0 can occur for identical models (the noise floor above). Only exact stochastic languages with EMD = 0 imply equal supports — and then the probabilities themselves would have to be justified.
- Both techniques are therefore screening tools: a difference is a hint to look for a concrete trace (Section 4); agreement is not a proof.

# 7. Complexity Comparison

Structural counts are derived by hand from the tree text and confirmed with the code below. Depth is counted in edges from the root (add 1 for levels). Petri-net figures are measured on pm4py 2.7.23.4 with the default tree-to-net conversion; they depend on the conversion's reduction rules.

| Metric | Model A | Model B |
|---|---|---|
| Process-tree nodes | 12 | 12 |
| Operator nodes | 5 (`->` ×2, `*`, `+`, `X`) | 5 (`->` ×2, `+`, `*`, `X`) |
| Depth (edges) | 4 (root → `*` → `->` → `+`/`X` → leaf) | 5 (root → `+` → `*` → `->` → `X` → leaf) |
| Visible leaves | 6 | 6 |
| Silent leaves | 1 | 1 |
| Duplicate-label count | 0 | 0 |
| Petri net: places / transitions / arcs | 9 / 9 / 20 | 7 / 7 / 16 |
| Petri net: silent transitions | 3 | 1 |
| `pm4py.simplicity_petri_net` (arc degree) | 0.8182 | 0.7778 |
| Traces with `k` analyses | `4^k` | `5k · 2^(k-1)` |
| Traces within the P3 bound | 76 | 85 |

The simplicity value is `1 / (1 + max(mean node degree − 2, 0))` with mean degree `2·arcs / (places + transitions)`: A gives `40/18 = 2.22`, B gives `32/14 = 2.29`.

Reading: the two trees are the same size and use the same operator multiset; only the position of `Ch` and `+` differs. B is one level deeper, and its concurrency block spans the loop. B's net is smaller, yet scores lower on arc-degree simplicity because `O` and `Cl` double as split and join. The metrics disagree with each other and none of them says anything about behaviour: equal size, opposite compliance verdicts.

```python
import pm4py

MODELS = {
    "A": ("->( 'Open Case', *( ->( +( 'Analyze Revision', 'Check Revision' ), "
          "X( 'Approve Revision', tau ) ), 'Rework Case' ), 'Close Case' )"),
    "B": ("->( 'Open Case', +( 'Check Revision', *( ->( 'Analyze Revision', "
          "X( 'Approve Revision', tau ) ), 'Rework Case' ) ), 'Close Case' )"),
}


def tree_metrics(tree):
    stats = {"nodes": 0, "operators": 0, "visible_leaves": 0,
             "silent_leaves": 0, "depth_edges": 0}
    labels, operators = [], {}

    def walk(node, depth):
        stats["nodes"] += 1
        stats["depth_edges"] = max(stats["depth_edges"], depth)
        if node.operator is None:
            if node.label is None:
                stats["silent_leaves"] += 1
            else:
                stats["visible_leaves"] += 1
                labels.append(node.label)
        else:
            stats["operators"] += 1
            operators[str(node.operator)] = operators.get(str(node.operator), 0) + 1
            for child in node.children:
                walk(child, depth + 1)

    walk(tree, 0)
    stats["operator_types"] = operators
    stats["duplicate_labels"] = len(labels) - len(set(labels))
    return stats


def net_metrics(tree):
    net, im, fm = pm4py.convert_to_petri_net(tree)
    return {
        "places": len(net.places),
        "transitions": len(net.transitions),
        "silent_transitions": sum(1 for t in net.transitions if t.label is None),
        "arcs": len(net.arcs),
        "simplicity": round(pm4py.simplicity_petri_net(net, im, fm), 4),
    }


if __name__ == "__main__":
    for name, tree_string in MODELS.items():
        tree = pm4py.parse_process_tree(tree_string)
        print(name, tree_metrics(tree))
        print(name, net_metrics(tree))
```

# 8. Simplified Model

**Target semantics: P1**, the operational compliance view, under the equivalence `≈P1` defined in Section 1. Reasons: P1 is the only view in which the difference between the models has consequences (unchecked revisions); any model that is exact for P1 is automatically exact for P2; and Model B cannot serve as a starting point because it violates the P1 rule in 80 of its 85 bounded traces.

**Declared compromise.** Model A is already minimal for its own *visible language*: each of its five operators encodes one distinct feature (case frame, loop, attempt sequence, `An ∥ Ch`, optional approval), and removing any of them changes the language. A structurally smaller model therefore has to give something up. The simplification gives up exactly the one thing `π1` does not observe: the freedom to start the check before the analysis. The check is placed after the analysis in every attempt.

1. Compact process tree:

```text
->( 'Open Case',
    *( ->( 'Analyze Revision', 'Check Revision', X( 'Approve Revision', tau ) ),
       'Rework Case' ),
    'Close Case' )
```

Visible language: `L(S) = O · Z · (Rw · Z)* · Cl` with `Z = An · Ch · (Ap | ε)`. `L(S) ⊂ L(A)` strictly (S is A with one interleaving chosen per attempt), and `π1(L(S)) = π1(L(A))`: both produce, for every `k ≥ 1`, all sequences of `k` records `(1 An, 1 Ch, no approval or one approval after both)`.

2. PM4Py code (self-contained; includes the exact membership test, the P1/P2 views and the regression suite):

```python
from collections import deque

import pm4py
from pm4py.objects.petri_net.obj import Marking

O, AN, CH, AP, RW, CL = ("Open Case", "Analyze Revision", "Check Revision",
                         "Approve Revision", "Rework Case", "Close Case")

MODEL_A = ("->( 'Open Case', *( ->( +( 'Analyze Revision', 'Check Revision' ), "
           "X( 'Approve Revision', tau ) ), 'Rework Case' ), 'Close Case' )")
MODEL_B = ("->( 'Open Case', +( 'Check Revision', *( ->( 'Analyze Revision', "
           "X( 'Approve Revision', tau ) ), 'Rework Case' ) ), 'Close Case' )")
SIMPLIFIED = ("->( 'Open Case', *( ->( 'Analyze Revision', 'Check Revision', "
              "X( 'Approve Revision', tau ) ), 'Rework Case' ), 'Close Case' )")

simplified_model = pm4py.parse_process_tree(SIMPLIFIED)


def freeze(marking):
    return frozenset((place, n) for place, n in marking.items() if n > 0)


def fire(marking, transition):
    counts = dict(marking)
    for arc in transition.in_arcs:
        counts[arc.source] = counts.get(arc.source, 0) - arc.weight
    for arc in transition.out_arcs:
        counts[arc.target] = counts.get(arc.target, 0) + arc.weight
    result = Marking()
    for place, n in counts.items():
        if n > 0:
            result[place] = n
    return result


def accepts(tree, trace):
    """Exact membership: BFS over (marking, position), silent moves allowed."""
    net, im, fm = pm4py.convert_to_petri_net(tree)
    final = freeze(fm)
    seen, queue = {(freeze(im), 0)}, deque([(im, 0)])
    while queue:
        marking, i = queue.popleft()
        if i == len(trace) and freeze(marking) == final:
            return True
        for transition in pm4py.get_enabled_transitions(net, marking):
            if transition.label is None:
                j = i
            elif i < len(trace) and transition.label == trace[i]:
                j = i + 1
            else:
                continue
            nxt = fire(marking, transition)
            if (freeze(nxt), j) not in seen:
                seen.add((freeze(nxt), j))
                queue.append((nxt, j))
    return False


def bounded_language(tree, max_visible=12, max_analyze=3):
    """Exhaustive bounded visible language (same algorithm as Section 5)."""
    net, im, fm = pm4py.convert_to_petri_net(tree)
    final = freeze(fm)
    seen, queue, language = {(freeze(im), ())}, deque([(im, ())]), set()
    while queue:
        marking, prefix = queue.popleft()
        if freeze(marking) == final:
            language.add(prefix)
        for transition in pm4py.get_enabled_transitions(net, marking):
            new_prefix = prefix if transition.label is None else prefix + (transition.label,)
            if len(new_prefix) > max_visible or new_prefix.count(AN) > max_analyze:
                continue
            nxt = fire(marking, transition)
            if (freeze(nxt), new_prefix) not in seen:
                seen.add((freeze(nxt), new_prefix))
                queue.append((nxt, new_prefix))
    return language


def p1_view(trace):
    """(first label, attempt records split at Rework, last label)."""
    records, n_an, n_ch, placements = [], 0, 0, []
    for label in trace[1:-1]:
        if label == RW:
            records.append((n_an, n_ch, tuple(placements)))
            n_an, n_ch, placements = 0, 0, []
        elif label == AN:
            n_an += 1
        elif label == CH:
            n_ch += 1
        elif label == AP:
            placements.append((n_an, n_ch))
    records.append((n_an, n_ch, tuple(placements)))
    return (trace[0], tuple(records), trace[-1])


def p1_rule(trace):
    """Every attempt has exactly one analysis and its own check."""
    first, records, last = p1_view(trace)
    return first == O and last == CL and all(r[0] == 1 and r[1] == 1 for r in records)


def p2_view(trace):
    return (trace[0] == O, trace[-1] == CL, trace.count(AN), CH in trace, RW in trace)


REGRESSION = [
    (O, AN, CH, CL),
    (O, AN, CH, AP, CL),
    (O, AN, CH, RW, AN, CH, AP, CL),
    (O, AN, CH, AP, RW, AN, CH, RW, AN, CH, AP, CL),
]
NEGATIVE = [
    (O, AN, AP, CH, CL),
    (O, AN, RW, AN, CH, CL),
    (O, CH, AN, AP, RW, AN, AP, CL),
    (O, AN, CH, RW, CL),
    (O, AN, CL),
    (O, CH, AN, CL),
]

if __name__ == "__main__":
    tree_a = pm4py.parse_process_tree(MODEL_A)
    tree_b = pm4py.parse_process_tree(MODEL_B)

    for trace in REGRESSION:
        assert accepts(simplified_model, trace) and accepts(tree_a, trace) and p1_rule(trace)
    for trace in NEGATIVE:
        assert not accepts(simplified_model, trace)
    print("regression and negative traces behave as specified")

    lang = {"A": bounded_language(tree_a), "B": bounded_language(tree_b),
            "S": bounded_language(simplified_model)}
    for name, traces in lang.items():
        print(name, "bounded traces:", len(traces),
              "| satisfying the P1 rule:", sum(map(p1_rule, traces)),
              "| distinct P1 views:", len({p1_view(t) for t in traces}),
              "| P2 views:", sorted({p2_view(t) for t in traces}))
    views = {name: {p1_view(t) for t in traces} for name, traces in lang.items()}
    print("L(S) subset of L(A):", lang["S"] <= lang["A"])
    print("P1 view S == A:", views["S"] == views["A"], "| P1 view A == B:", views["A"] == views["B"])
    print("P2 view A == B == S:",
          {p2_view(t) for t in lang["A"]} == {p2_view(t) for t in lang["B"]}
          == {p2_view(t) for t in lang["S"]})
```

Output on my installation: all assertions pass; A: 76 traces, 76 satisfy the P1 rule, 13 distinct P1 views; B: 85 traces, 5 satisfy the rule, 51 distinct P1 views; S: 13 traces, 13 satisfy the rule, 13 distinct P1 views; `L(S) ⊆ L(A)` true; P1 view `S == A` true, `A == B` false; P2 views of A, B and S identical (`k` = 1, 2, 3).

S is no larger than either original on any count and strictly smaller than both on tree nodes, operators, net places and arcs (leaves are equal; depth, transitions and silent transitions tie with one of the originals). It is free of concurrency, so its net is a state machine without AND-split/join. The gain is modest; that is the honest price of staying exact for P1.

| Property | Status in S | Comment |
|---|---|---|
| `O` first, `Cl` last | exact | Same frame as A and B. |
| One check per analysis before the next `Rw` / `Cl` (P1 rule) | exact (relative to A) | Holds in every trace, as in A; B violates it. |
| `Rw` separates analysis attempts; `k` attempts ⇒ `k − 1` reworks | exact | Same loop as A. |
| Approval optional, 0..k, at most one per attempt | exact | Same `X(Ap, tau)`. |
| Approval only after analysis **and** check of the same attempt | exact (relative to A) | B's "approval before or without a check" is deliberately excluded. |
| P1 view `π1` | exact | `π1(L(S)) = π1(L(A))`, unbounded (structural argument) and confirmed within the bound. |
| P2 view `π2` | exact, but abstracted by nature | Same view set as A and B. |
| Order of `An` and `Ch` inside an attempt | weakened (narrowed) | Only `An` before `Ch`; A's `Ch`-before-`An` interleavings are no longer admitted. |
| Visible trace language of A / P3 bounded language | lost as equality | `L(S) ⊂ L(A)`: 13 of A's 76 bounded traces. S is a refinement of A, not a trace-equivalent replacement. |
| Model B's behaviour (single case-level check, approval independent of check) | lost on purpose | Shares only 2 bounded traces with B (`O An Ch Cl`, `O An Ch Ap Cl`). |
| Silent auto-approval evidence | abstracted (as in both originals) | Skip remains invisible. |

No single simplification preserves all three views: exactness for P3 forces Model A itself, and anything smaller than A either narrows the language (S) or keeps only the dashboard view. For the dashboard alone, `->( 'Open Case', 'Check Revision', *( 'Analyze Revision', 'Rework Case' ), 'Close Case' )` (7 nodes, 2 operators, no `tau`, net simplicity 1.0) has exactly the same `π2` image as A and B, but it drops approvals and per-attempt checks and must never be used for P1 or P3.

# 9. Final Recommendation

| Business view | Model A | Model B | Simplified S |
|---|---|---|---|
| P1 — operational compliance | Suitable; it is the reference semantics (one check per revision, approval only after analysis and check). | Not suitable: admits reworked, approved and closed revisions without their own check. | Suitable if fixing "analyse, then check" is acceptable; exact on the P1 view. |
| P2 — executive dashboard | Suitable. | Suitable for the dashboard as specified, but only because the dashboard cannot see the missing checks. | Suitable (identical dashboard view). |
| P3 — bounded testing | Use as the test oracle. | Different language (only 4 of 85 bounded traces are shared with A); do not use as a stand-in for A. | A strict subset of A's bounded language: every S-trace is a valid A-trace, but tests generated from S will not cover A's `Ch`-before-`An` variants. |

- **Do not treat A and B as interchangeable.** They agree only on the dashboard. If B was intended to express "check every revision", it is wrong and should be replaced by A (or S). If B intentionally models one case-level check, rename that activity so nobody reads it as a per-revision control.
- **Replacing A with S** is justified only after the business confirms that a check never starts before the analysis, or that this order is irrelevant. If real logs contain `Check Revision` before `Analyze Revision`, conformance checking against S would flag compliant cases as deviations; in that case keep A, which is already minimal for its language.
- **S must not replace B** as a description of B's behaviour, and the 7-node dashboard tree must not replace anything outside P2.
- **Limits of bounded comparison.** The P3 exploration is exhaustive only up to 12 visible events and three analyses. Here it found differences, and each difference is a real counterexample, so the negative verdict is final. A positive result would not have been: bounded agreement is evidence, not proof, and behaviour beyond the bound (a fourth analysis, or A's 13-event traces with three approvals that the bound already cuts off) is simply untested. The unbounded claims in this answer — the P1 inequivalence, the P2 equivalence for all `k`, and `π1(L(S)) = π1(L(A))` — rest on the closed-form languages in Sections 1, 2 and 8, not on the bounded run. Random playout, footprints and EMD are weaker still and should only be used to screen for candidates.
