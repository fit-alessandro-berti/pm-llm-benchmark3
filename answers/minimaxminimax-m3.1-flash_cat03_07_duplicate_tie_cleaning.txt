## 1. Duplicate-handling decision tree

Apply the following tree in order; a candidate should not enter a later branch merely because an earlier test failed.

1. **Technical identity test**
   - Same `source` and `source_event_key`, identical payload hash/full business attributes, and identical object relations: **DROP the redundant source row**, while archiving its original row and relations in provenance.
   - Same source key but conflicting payload, attributes, or relations: treat as an **unresolved candidate**, not a duplicate.
2. **Cross-system physical-event test**
   - Authoritative reconciliation or equivalent evidence identifies one physical event observed by multiple systems: **MERGE attributes and relations** into one canonical event, retaining every source observation.
   - Similar labels, timestamps, or objects without identity evidence do not pass this test.
3. **Summary/detail or derived-event test**
   - An explicit lineage record proves that the summary is only a projection of the detailed event and has no independent business-state effect: **MERGE attributes and relations**, preserving source-scoped fields.
   - The summary represents an independently meaningful abstraction or status transition: **RETAIN BOTH with refined labels or qualifiers**.
   - The relationship is plausible but not established: **QUARANTINE the merge proposal for review**; retain both raw events meanwhile.
4. **Harmonization-collision test**
   - The source systems demonstrably mean different activities despite the same harmonized label: **RETAIN BOTH**, using source-authoritative refined labels where available.
5. **Same-label/different-object test**
   - Different object identities or explicit facts establish distinct events: **RETAIN BOTH UNCHANGED**, adding non-destructive qualifiers if useful.
   - A shared object alone is never sufficient.
6. **Residual unresolved case**
   - **QUARANTINE FOR REVIEW** the candidate relationship, not the underlying evidence. No event is deleted merely because deduplication is uncertain.

Thus, “drop” is limited to redundant technical representations; semantic observations are merged only with explicit identity evidence.

## 3. Timestamp-tie ordering rules

Construct a directed acyclic graph of **semantic precedence constraints**, then calculate a deterministic linear extension.

1. **Domain constraints — semantic**
   - Pick before pack.
   - Invoice issuance before its payment authorization.
   - Authorization before capture for the same payment.
   - Release before carrier acceptance, and acceptance before handover.
2. **Within-source sequence — source-local evidential constraints**
   - `source_seq` orders events only inside one source. Thus WMS e03e06e08, scanner e04e05, PSP e12e13e14, and carrier e09e10 are supported.
   - Never compare the numeric values of `source_seq` across sources.
3. **Lifecycle constraints — semantic only when direction is known**
   - A shared object permits a constraint such as package releaseacceptance, but does not imply that all events touching O1 are sequential.
4. **Source-specific semantics — semantic**
   - The ERP payment summary follows its payment messages.
   - The ERP packing status follows the WMS message that caused it.
5. **Timestamp bucket — business evidence, but coarse**
   - Use `timestamp` to separate different recorded times. A tie means unresolved at the available resolution, not necessarily physical concurrency.
6. **Stable fallback — merely deterministic**
   - For otherwise interchangeable nodes, use ascending canonical `eid`.
7. **Ingestion time — not business ordering evidence**
   - `ingested_at` is retained for audit only. It may help investigate anomalies, but must not determine process order.

Topologically sort with a deterministic priority of `(timestamp, canonical_eid)`, assigning `order_rank`. This produces a repeatable presentation order without claiming the linear extension is the unique physical history.

|---|---|---|
| 10:00, e03–e07 | e03 (canonical e03/e04)  e05  e06  e07 | If scanner sequence is not accepted, e03/e05 may swap. If the WMS message is not tied specifically to e06, e06/e07 may also swap. |
| 10:15, e08–e10 | e08  e09  e10 | e09e10 is strict; e08e09 follows the release/acceptance lifecycle. |

Adding microseconds before duplicate detection or ordering is unsafe: it can prevent e03/e04 or e11/e16 from merging and can manufacture a causal story—for example, turning an invoice-level summary into a capture occurring after a particular payment. Keep the original timestamp immutable and store any synthetic tie-break separately.

```python
from copy import deepcopy
from collections import defaultdict, Counter
import heapq
import json
import re

import numpy as np
import pandas as pd
import pm4py
from pm4py.objects.log.ocel import Ocel

RULE_VERSION = "conservative-merge-v1"

# ---------- Generic Ocel helpers ----------

def json_value(v):
    if isinstance(v, np.generic):
        return v.item()
    try:
        if pd.isna(v):
            return None
    except (TypeError, ValueError):
        pass
    return v if isinstance(v, (str, int, float, bool, list, dict)) else str(v)


def event_frame(ocel):
    e = ocel.events.copy()
    if "event_id" not in e.columns:
        e["event_id"] = [str(x) for x in e.index]
    else:
        e["event_id"] = e["event_id"].astype(str)
    return e


def rebuild_ocel(base, events, relation):
    events = events.copy()
    events["event_id"] = events["event_id"].astype(str)
    # Recent PM4Py expects event_id in events and the standard E2O schema.
    return Ocel(
        events.reset_index(drop=True),
        base.objects.copy(),
        relation.reset_index(drop=True)
    )


def ensure_original_metadata(ocel):
    e = event_frame(ocel)
    if "original_timestamp" not in e:
        e["original_timestamp"] = e["timestamp"]
    if "original_activity" not in e:
        e["original_activity"] = e["activity"]
    for required in ("source", "source_event_key", "payload_hash"):
        if required not in e.columns:
            raise ValueError(f"Missing required metadata column: {required}")
    return rebuild_ocel(ocel, e, ocel.object_relation.copy())


def candidate_precheck(ocel):
    """Inspection only: same activity/time is merely a candidate relation."""
    e = event_frame(ocel)
    result = []
    for (activity, timestamp), g in e.groupby(
        ["activity", "timestamp"], dropna=False, sort=True
    ):
        result.append({
            "activity": activity,
            "timestamp": timestamp,
            "event_ids": sorted(g["event_id"].tolist()),
            "n": len(g)
        })
    return result


def exact_technical_groups(ocel):
    """Require identical event payload AND identical E2O relations."""
    e = event_frame(ocel).set_index("event_id", drop=False)
    r = ocel.object_relation.copy()
    groups = defaultdict(list)

    for eid, row in e.iterrows():
        attrs = {
            c: json_value(row[c])
            for c in sorted(e.columns)
            if c != "event_id"
        }
        rel = r[r["source_event_id"].astype(str) == str(eid)]
        rel_sig = json.dumps(
            sorted(rel.astype(str).agg("|".join, axis=1).tolist()),
            sort_keys=True
        )
        payload_sig = json.dumps(attrs, sort_keys=True, default=str)
        groups[(payload_sig, rel_sig)].append(eid)

    return [
        {
            "event_ids": sorted(ids),
            "signature": sig
        }
        for sig, ids in groups.items()
        if len(ids) > 1
    ]


def safe_exact_drop(ocel, raw):
    """
    A justified PM4Py drop call.

    It uses all event columns as a fine-grained key, after verifying that
    any same-key candidate also has identical E2O relations. It is a no-op
    for the supplied data, where there are no exact technical duplicates.
    """
    for group in candidate_precheck(raw):
        ids = set(group["event_ids"])
        rel = raw.object_relation[
            raw.object_relation["source_event_id"].isin(ids)
        ]
        signatures = defaultdict(set)
        e = event_frame(raw).set_index("event_id", drop=False)
        for eid in ids:
            row = e.loc[eid]
            payload = json.dumps(
                {c: json_value(row[c]) for c in e.columns if c != "event_id"},
                sort_keys=True,
                default=str
            )
            rr = rel[rel["source_event_id"].astype(str) == str(eid)]
            rel_sig = json.dumps(
                sorted(rr.astype(str).agg("|".join, axis=1).tolist()),
                sort_keys=True
            )
            signatures[payload].add(rel_sig)

        if any(len(v) > 1 for v in signatures.values()):
            raise ValueError(
                "A duplicate-looking key has incompatible E2O relations; "
                "do not apply global duplicate removal."
            )

    keys = [c for c in ocel.events.columns if c != "event_id"]
    return pm4py.ocel_drop_duplicates(ocel, keys=keys)


# ---------- Verified semantic-pair merge ----------

def merge_verified_pairs(base, pairs):
    """
    pairs: [(canonical_eid, other_eid, rule_name), ...]

    Only call this for externally verified identities or a documented
    projection assumption. It:
      * keeps the canonical source fields unchanged;
      * stores conflicting/noncanonical attributes under source-scoped names;
      * unions E2O relations for the verified pair;
      * retains every source row in the separate audit ledger.
    """
    e = event_frame(base)
    r = base.object_relation.copy()
    cmap = {eid: eid for eid in e["event_id"]}
    rules = {}

    for canonical, other, rule in pairs:
        if canonical not in set(e["event_id"]) or other not in set(e["event_id"]):
            raise KeyError((canonical, other))

        ce = e[e["event_id"] == canonical].iloc[0].copy()
        oe = e[e["event_id"] == other].iloc[0].copy()

        for col in sorted((set(e.columns) | set(oe.index)) - {"event_id"}):
            if col not in ce.index:
                ce[col] = oe[col]
            elif col not in oe.index:
                continue
            else:
                a, b = ce[col], oe[col]
                a_blank = False
                b_blank = False
                try:
                    a_blank = bool(pd.isna(a))
                except (TypeError, ValueError):
                    pass
                try:
                    b_blank = bool(pd.isna(b))
                except (TypeError, ValueError):
                    pass

                if a_blank and not b_blank:
                    ce[col] = b
                elif not a_blank and not b_blank and str(a) != str(b):
                    tag = re.sub(r"\W+", "_", str(oe["source"]))
                    scoped = f"src__{tag}__{col}"
                    if scoped not in ce.index:
                        ce[col + "__source_copy"] = np.nan
                        ce = ce.rename(columns={col + "__source_copy": scoped})
                    ce[scoped] = b

        # Union relations only for this verified pair.
        mask = r["source_event_id"].astype(str) == str(other)
        r.loc[mask, "source_event_id"] = canonical

        e = e[e["event_id"] != other].copy()
        ce.name = canonical
        e = pd.concat([e, ce.to_frame().T], ignore_index=True)
        cmap[other] = canonical
        rules[canonical] = rule

    relation_cols = list(r.columns)
    r = r.drop_duplicates(subset=relation_cols)
    merged = rebuild_ocel(base, e, r)

    inverse = defaultdict(list)
    for source_id, canonical_id in cmap.items():
        inverse[canonical_id].append(source_id)

    me = event_frame(merged)
    for canonical_id, source_ids in inverse.items():
        me.loc[
            me["event_id"] == canonical_id,
            "merged_source_event_ids"
        ] = json.dumps(sorted(source_ids))
    merged = rebuild_ocel(base, me, merged.object_relation.copy())

    return merged, cmap, rules


# ---------- Constraint-based deterministic ordering ----------

SEMANTIC_EDGES = [
    ("e03", "e06"),             # pick before pack
    ("e05", "e06"),             # pick before pack
    ("e06", "e07"),             # WMS detail then ERP status
    ("e08", "e09"),             # release then carrier acceptance
    ("e09", "e10"),             # acceptance then handover
    ("e11", "e12"),             # invoice then authorization
    ("e12", "e13"),             # authorization then capture
    ("e13", "e14"),             # supported by PSP source sequence
    ("e13", "e15"),             # ERP summary after M1 message
    ("e14", "e15")              # ERP summary after M2 message
]


def order_ocel(ocel, raw, canonical_map, semantic_edges=SEMANTIC_EDGES):
    e = event_frame(ocel).set_index("event_id", drop=False)
    nodes = set(e.index)
    edges = set()

    # Source-local semantic/evidential constraints; never compare seq across sources.
    for source, g in raw.events.groupby("source", sort=True):
        g = g.sort_values("source_seq", kind="mergesort")
        mapped = []
        for source_eid in g["event_id"].astype(str):
            target = canonical_map[str(source_eid)]
            if target not in mapped:
                mapped.append(target)
        for a, b in zip(mapped, mapped[1:]):
            if a != b:
                edges.add((a, b))

    # Explicit domain/source-fact constraints.
    for a, b in semantic_edges:
        x, y = canonical_map[a], canonical_map[b]
        if x != y:
            edges.add((x, y))

    adjacency = defaultdict(set)
    indegree = {n: 0 for n in nodes}
    for a, b in sorted(edges):
        if b not in adjacency[a]:
            adjacency[a].add(b)
            indegree[b] += 1

    times = pd.to_datetime(e["timestamp"], utc=True)
    ready = []
    for n in nodes:
        if indegree[n] == 0:
            heapq.heappush(ready, (int(times[n].value), n))

    ordered_ids = []
    while ready:
        _, node = heapq.heappop(ready)
        ordered_ids.append(node)
        for nxt in sorted(adjacency[node]):
            indegree[nxt] -= 1
            if indegree[nxt] == 0:
                heapq.heappush(ready, (int(times[nxt].value), nxt))

    if len(ordered_ids) != len(nodes):
        raise ValueError("Cyclic or inconsistent precedence constraints")

    rank = {eid: i for i, eid in enumerate(ordered_ids)}
    oe = event_frame(ocel)
    oe["order_rank"] = oe["event_id"].map(rank).astype(int)

    ordered = pm4py.ocel_sort_by_additional_column(
        oe, "order_rank", descending=False
    )
    # This is called only after semantic ordering is established.
    # time_delta is index-derived and must not replace original timestamps.
    ordered = pm4py.ocel_add_index_based_timedelta(ordered)
    return ordered


# ---------- Provenance and validation ----------

def raw_audit(raw):
    rows = []
    e = event_frame(raw).set_index("event_id", drop=False)
    for eid, row in e.iterrows():
        rel = raw.object_relation[
            raw.object_relation["source_event_id"].astype(str) == str(eid)
        ]
        rows.append({
            "source_event_id": eid,
            "original_activity": row["activity"],
            "original_timestamp": row["timestamp"],
            "source": row["source"],
            "source_event_key": row["source_event_key"],
            "source_seq": row["source_seq"],
            "ingested_at": row["ingested_at"],
            "payload_hash": row["payload_hash"],
            "attributes_retained": json.dumps(
                {c: json_value(row[c]) for c in e.columns if c != "event_id"},
                default=str,
                sort_keys=True
            ),
            "related_objects": json.dumps(
                sorted(rel["target_object_id"].astype(str).tolist())
            )
        })
    return pd.DataFrame(rows)


def canonical_audit(raw, canonical_map, rules):
    e = event_frame(raw).set_index("event_id", drop=False)
    groups = defaultdict(list)
    for source_id in e.index:
        groups[canonical_map[str(source_id)]].append(str(source_id))

    result = []
    for canonical_id, source_ids in sorted(groups.items()):
        conflicts = []
        for col in e.columns:
            if col == "event_id":
                continue
            values = [
                json_value(e.loc[sid, col])
                for sid in source_ids
                if sid in e.index
            ]
            normalized = {
                json.dumps(v, sort_keys=True, default=str)
                for v in values
                if v is not None
            }
            if len(normalized) > 1:
                conflicts.append({"field": col, "values": values})

        result.append({
            "canonical_event_id": canonical_id,
            "source_event_ids": json.dumps(sorted(source_ids)),
            "merge_rule": rules.get(canonical_id, "RETAIN_SINGLE"),
            "rule_version": RULE_VERSION,
            "original_activities": json.dumps(
                {sid: e.loc[sid, "activity"] for sid in source_ids},
                default=str
            ),
            "refined_activity": None,
            "original_timestamps": json.dumps(
                {sid: str(e.loc[sid, "timestamp"]) for sid in source_ids},
                sort_keys=True
            ),
            "adjusted_timestamps": json.dumps(
                {sid: None for sid in source_ids}
            ),
            "attributes_retained": json.dumps(
                {sid: e.loc[sid].to_dict() for sid in source_ids},
                default=str,
                sort_keys=True
            ),
            "discarded_conflicts": json.dumps(conflicts, default=str),
            "confidence": "high" if len(source_ids) > 1 else "not_applicable",
            "reason": rules.get(canonical_id, "No verified merge")
        })
    return pd.DataFrame(result)


def validate(ocel):
    e = event_frame(ocel)
    for col in (
        "original_timestamp", "original_activity", "source",
        "source_event_key", "payload_hash", "order_rank", "time_delta"
    ):
        if col not in e.columns:
            raise ValueError(f"Output is missing {col}")

    event_ids = set(e["event_id"].astype(str))
    object_ids = set(ocel.objects["object_id"].astype(str))
    relation = ocel.object_relation

    if not set(relation["source_event_id"].astype(str)).issubset(event_ids):
        raise ValueError("Orphan E2O source event")
    if not set(relation["target_object_id"].astype(str)).issubset(object_ids):
        raise ValueError("Orphan E2O target object")
    if e[["original_timestamp", "original_activity", "source",
          "source_event_key"]].isna().any().any():
        raise ValueError("Missing provenance metadata")
```

## 8. Audit and reversibility

Each canonical event should have one provenance record containing:

- `canonical_event_id`;
- all `source_event_ids`, with original `source`, `source_event_key`, `source_seq`, `ingested_at`, and `payload_hash`;
- `merge_rule`, rule version, reviewer/approver, timestamp, and reason;
- original and refined activity labels;
- original, adjusted, and ordering timestamps—adjusted is null when no timestamp was changed;
- attributes retained from each source, stored source-scoped;
- discarded or conflicting attributes, including both values and their authority;
- E2O relations contributed by each source;
- confidence and evidence references.

To reconstruct the raw view, start from the immutable raw snapshot or expand the ledger by canonical event: restore each source row’s original identifier, label, timestamp, attributes, and hash; restore its original relation rows; and remove canonical-only qualifiers and ordering fields. Refined labels, source-scoped conflict copies, and deterministic ranks are never allowed to overwrite that source snapshot.

## 9. Failure modes and safeguards

| Failure mode | Safeguard |
|---|---|
| Collapsing distinct partial payments | Require payment identity or explicit lineage; preserve M1/M2 and never merge solely on O1/V1 |
| Converting abstraction-level updates into false rework | Retain detail and summary/status as qualified events unless pure projection is proven |
| Ordering by ingestion time | Use business constraints and timestamps; treat `ingested_at` only as audit metadata |
| Treating shared objects as proof of duplication | Require event-identity evidence and compatible business keys |
| Unioning incompatible E2O relations | Union only verified duplicates; do not union concurrent or semantically distinct observations |
| Changing durations through synthetic microseconds | Preserve `original_timestamp`; keep tie-breaks in a separate rank column |
| Losing source-authoritative attributes | Use source-scoped attributes and conflict records rather than last-write-wins |
| Applying duplicate functions to the whole OCEL | Inspect candidate groups first; apply fine-grained drops only to verified blocks |
| Treating equal timestamps as proof of concurrency | Equal timestamps indicate coarse resolution; use source and domain evidence without inventing sequence |
| Misreading a summary as a payment | Require a Payment object or transaction-level reconciliation before attaching M1/M2 |
| Non-reproducible tie resolution | Use a topological sort with stable `eid` fallback and fixed rule versions |
