## 2. Raw-versus-normalized interpretation

The raw-versus-mapped fitness gap that opens in March and never fully closes is primarily evidence of **label and provenance drift**, not proof that the business process collapsed. Raw fitness falls from ~0.93 to ~0.55 exactly when the migration renames eligibility and injects duplicate `Open Case` events; mapped fitness remains ~0.86–0.91. That pattern implies the normative model still largely fits once synonyms are unified and technical duplicates removed. It does **not** imply that waiting times, rework, or case mix were stable—those live outside the fitness statistic.

A label mapping can restore conformance because alignments and fitness score discrete activity names and structural match to a model. Renaming `Validate Eligibility` to `Eligibility Screen` breaks the model without changing who did what in business terms. Recovered fitness therefore shows **semantic reconciliation**, not invariance of queues, staffing, or document quality.

Duplicated `Open Case` events inflate early-path frequencies, distort DFGs and variant counts, and can create spurious deviations. Missing resources break resource-based handover, workload, and performance analyses more than control-flow fitness; they bias any conclusion about who is slow or overloaded. Neither artifact should be read as behavioral change without repair.

Post-May patterns cannot be dismissed as logging drift alone. After mapping, AssessRequestInfo roughly doubles, rework variants rise with Supplier Z share, cycle time worsens while Assess service time rises only modestly (4.8h5.4h), and normalized decision rates fall—signatures of real rework and queueing. Logging drift explains the March raw-fitness cliff; it does not explain the May–November performance and rework trajectory.

### 3.5 Global vs mechanism-specific change points

Data **do not** support one global change point. March is almost pure logging/semantic; May is supplier-driven rework; June is capacity; July is priority policy; October is seasonal case-mix; December mixes unload and intervention. A single CP model would smear distinct mechanisms and mis-time residual causes. Mechanism-specific CPs aligned to the known timeline are the appropriate structure; formal CP detection should be run **per artifact family** (labels, DFG rework edges, wait-time, case-mix shares).

| L4 semantic QA | raw vs mapped labels; migration cohort (start&lt;Mar vs Mar) | logging drift surveillance | all events | fitness gap, duplicate rate | Overfitting map to maximize fitness |
| L5 outcome | decision (A/R) × complexity × month | quality/fairness under drift | 40 decisions/cell | reject rates under rework/season | Selection from dropout/open cases |
| L6 seasonal | calendar month × high_complexity_pct band; YoY when available | recurrence vs novel drift | use 2+ years when exist; else mark provisional | Oct–Nov vs spring | Single-year false “new normal” |

**Primary monitoring population:** **L1 (month × Supplier Z × complexity)** on the **mapped, deduplicated** log. It is the coarsest cut that separates the three dominant real-world drivers (supplier quality, case mix, residual behavior/performance) while usually clearing support thresholds (~hundreds of cases/month split 2×2). L0 remains a dashboard rollup; L2–L3 are diagnostic layers after L1 alerts; L4 runs continuously as a data-quality track so semantic issues are not misread as process change.

2026-10,100,95,90,26,25,22,73

"""

def part_a_run() -> None:
    monthly = pd.read_csv(io.StringIO(MONTHLY_CSV))
    dfg_rates = pd.read_csv(io.StringIO(DFG_RATES_CSV))

    # ----- 1. validate -----
    assert monthly["month"].is_unique
    assert len(monthly) == 12
    numeric_cols = [c for c in monthly.columns if c != "month"]
    assert monthly[numeric_cols].notna().all().all()
    assert (monthly["raw_model_fitness"] <= monthly["mapped_model_fitness"] + 1e-9).all()
    assert (monthly["cases"] > 0).all()
    rate_cols = [c for c in dfg_rates.columns if c != "month"]
    assert dfg_rates[rate_cols].ge(0).all().all()
    print("VALIDATION: OK")
    print(f"  months={list(monthly['month'])}")
    print(f"  DFG fragment months={list(dfg_rates['month'])} (incomplete timeline)")

    # ----- 2. baseline-relative changes -----
    baseline = monthly.iloc[:2][numeric_cols].mean()
    rel = monthly[["month"]].copy()
    for c in numeric_cols:
        rel[f"d_{c}"] = monthly[c] - baseline[c]
    print("\nBASELINE (Jan-Feb mean):")
    print(baseline.to_string())
    print("\nBASELINE-RELATIVE CHANGES:")
    print(rel.to_string(index=False))

    # ----- 3. transparent DFG fragment distance (L1 on rates per 100 cases) -----
    base_dfg = dfg_rates.loc[dfg_rates["month"] == "2026-01", rate_cols].iloc[0]
    dist_rows = []
    for _, row in dfg_rates.iterrows():
        vec = row[rate_cols].astype(float)
        l1 = float(np.abs(vec - base_dfg).sum())
        l2 = float(np.sqrt(((vec - base_dfg) ** 2).sum()))
        dist_rows.append({"month": row["month"], "l1_to_jan": l1, "l2_to_jan": l2})
    dist_df = pd.DataFrame(dist_rows)
    print("\nDFG FRAGMENT DISTANCE TO 2026-01 (L1/L2 on supplied edges only):")
    print(dist_df.to_string(index=False))

    # ----- 4. raw-to-mapped fitness recovery -----
    fit = monthly[["month", "raw_model_fitness", "mapped_model_fitness"]].copy()
    fit["fitness_gap"] = fit["mapped_model_fitness"] - fit["raw_model_fitness"]
    fit["recovery_from_raw_floor"] = fit["mapped_model_fitness"] - fit["raw_model_fitness"]
    print("\nRAW vs MAPPED FITNESS:")
    print(fit.to_string(index=False))
    print(f"Mean gap post-migration (Mar-Dec): {fit.loc[fit['month']>='2026-03','fitness_gap'].mean():.3f}")

    # ----- 5. simple explainable change-point flags -----
    # Rule: |month - rolling median of prior 2 months| exceeds k * baseline MAD-like scale
    def flag_series(s: pd.Series, k: float, abs_floor: float) -> List[str]:
        flags = []
        for i in range(len(s)):
            if i < 2:
                flags.append("")
                continue
            prev = s.iloc[i - 2 : i]
            delta = abs(s.iloc[i] - prev.median())
            scale = max(abs_floor, float(prev.std(ddof=0)) if prev.std(ddof=0) > 0 else abs_floor)
            flags.append("CP?" if delta >= k * scale and delta >= abs_floor else "")
        return flags

    cp = monthly[["month"]].copy()
    cp["cp_raw_fitness"] = flag_series(monthly["raw_model_fitness"], k=3.0, abs_floor=0.1)
    cp["cp_rework"] = flag_series(monthly["rework_variant_pct"], k=2.5, abs_floor=5.0)
    cp["cp_supplier_z"] = flag_series(monthly["supplier_z_pct"], k=2.5, abs_floor=8.0)
    cp["cp_median_cycle"] = flag_series(monthly["median_cycle_h"], k=2.5, abs_floor=3.0)
    cp["cp_high_complexity"] = flag_series(monthly["high_complexity_pct"], k=2.5, abs_floor=6.0)
    cp["cp_missing_resource"] = flag_series(monthly["missing_resource_pct"], k=2.5, abs_floor=2.0)
    print("\nCANDIDATE CHANGE POINTS (simple residual rule vs prior 2 months):")
    print(cp.to_string(index=False))

def prepare_log(
    df: pd.DataFrame,
    case_col: str = "case_id",
    activity_col: str = "activity",
    timestamp_col: str = "timestamp",
    resource_col: Optional[str] = "resource",
):
    """Format a dataframe as a PM4Py event log without destroying the caller copy."""
    import pm4py

    work = df.copy()
    # Standard column mapping for pm4py.format_dataframe
    work = pm4py.format_dataframe(
        work,
        case_id=case_col,
        activity_key=activity_col,
        timestamp_key=timestamp_col,
        timest_format=None,
    )
    if resource_col and resource_col in df.columns:
        # keep resource under both original and concept:name-adjacent key if present
        if resource_col != "org:resource":
            work["org:resource"] = df.loc[work.index, resource_col] if False else work.get(resource_col, df[resource_col])
    return work


def apply_semantic_normalization(
    df: pd.DataFrame,
    activity_col: str = "concept:name",
    label_map: Optional[Dict[str, str]] = None,
    drop_duplicate_open_case: bool = True,
    open_case_label: str = "Open Case",
    case_col: str = "case:concept:name",
    timestamp_col: str = "time:timestamp",
) -> pd.DataFrame:
    """
    Return a *new* normalized dataframe. Original log untouched.
    Maps Eligibility Screen -> Validate Eligibility by default; optionally
    removes duplicated technical Open Case events (keeps first per case).
    """
    label_map = label_map or {"Eligibility Screen": "Validate Eligibility"}
    out = df.copy()
    out[activity_col] = out[activity_col].replace(label_map)
    if drop_duplicate_open_case:
        is_open = out[activity_col] == open_case_label
        # keep first Open Case per case; keep all non-Open Case rows
        open_rows = out[is_open].sort_values(timestamp_col)
        first_open_idx = open_rows.groupby(case_col, sort=False).head(1).index
        out = pd.concat(
            [out.loc[~is_open], out.loc[first_open_idx]],
            axis=0,
        ).sort_values([case_col, timestamp_col])
    return out.reset_index(drop=True)


def slice_window(log_df: pd.DataFrame, start: str, end: str):
    """Time-slice using pm4py.filter_time_range on a formatted dataframe/log."""
    import pm4py

    # pm4py accepts log or dataframe depending on version; normalize via event log
    event_log = pm4py.convert_to_event_log(log_df) if not isinstance(log_df, list) else log_df
    return pm4py.filter_time_range(event_log, start, end, mode="events")


def monthly_dfgs(log_df: pd.DataFrame, months: List[str]) -> Dict[str, Tuple[dict, dict]]:
    """Discover DFG per month. Returns month -> (dfg, sa_count)."""
    import pm4py

    out = {}
    tmp = log_df.copy()
    ts = "time:timestamp"
    tmp["_ym"] = pd.to_datetime(tmp[ts]).dt.strftime("%Y-%m")
    for m in months:
        sub = tmp[tmp["_ym"] == m]
        if sub.empty:
            continue
        elog = pm4py.convert_to_event_log(sub)
        dfg, start_act, end_act = pm4py.discover_dfg(elog)
        out[m] = (dfg, {"start": start_act, "end": end_act})
    return out

def compare_raw_vs_normalized(

def dfg_l1_distance(dfg_a: dict, dfg_b: dict, normalize_by_cases: Optional[float] = None) -> float:
    """L1 distance over union of edges; optional per-100-cases scaling."""
    keys = set(dfg_a) | set(dfg_b)
    total = 0.0
    for k in keys:
        va = float(dfg_a.get(k, 0.0))
        vb = float(dfg_b.get(k, 0.0))
        if normalize_by_cases:
            va = 100.0 * va / normalize_by_cases
            vb = 100.0 * vb / normalize_by_cases
        total += abs(va - vb)
    return total
