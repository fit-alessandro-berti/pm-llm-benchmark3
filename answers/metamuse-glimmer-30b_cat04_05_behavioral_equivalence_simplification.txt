# 1. Equivalence Notions

* **Visible trace equivalence after hiding `tau`.**  
Let `hide(, t)` delete all `tau` events from a trace `t`.  
`L_vis(M) = { hide(,t) | t is a complete firing sequence of M from im to fm }`.  
`M1 vis M2` iff `L_vis(M1)=L_vis(M2)`. Traces are sequences, therefore duplicate visible labels are distinguished by occurrence position and identity.

* **Bounded visible-language equivalence under P3.**  
`L_vis^{b}(M) = { t  L_vis(M) | |t|_vis 12  |t|_Analyze Revision 3 }`.  
`M1 b M2` iff `L_vis^{b}(M1)=L_vis^{b}(M2)`. Silent transitions are removed before counting.

* **Business-relevant equivalence under P1.**  
Let `1(t)` be true iff  
1. `Open Case` is first and `Close Case` last;  
2. every occurrence of `Analyze Revision` is followed in the same loop iteration by a `Check Revision` before the next `Rework Case` or `Close Case`;  
3. `Rework Case` only separates two `Analyze Revision` attempts;  
4. `Approve Revision` may occur 0/1 per iteration and is visible.  
`M1 P1 M2` iff `{ t | 1(t) }  L_vis(M1) = { t | 1(t) }  L_vis(M2)`.

* **Abstracted dashboard equivalence under P2.**  
`2(t) = ( nA , c , r )` with `nA = |t|_Analyze Revision`, `c = |t|_Check Revision >0`, `r = |t|_Rework Case >0`. `Approve Revision` and `tau` are hidden, interleaving of `Analyze`/`Check` is lost.  
`M1 P2 M2` iff `2(L_vis(M1)  {t| nA1  c}) = 2(L_vis(M2)  {t| nA1  c})`.

# 2. Structural Comparison

| Feature | Model A | Model B | Semantic consequence |
|---|---|---|---|
| Loop scope | `*` encloses `->(+ (Analyze,Check), X(Approve,tau))` and `Rework Case`. Check is per iteration | `*` encloses `->(Analyze, X(Approve,tau))` and `Rework Case`. Check is outside the loop | Check multiplicity differs |
| Minimum Check Revision occurrences | 1 per iteration, 1 overall | 1 overall in the parallel branch, 1 in Check-only mode | A forces at least one Check per Analyze attempt |
| Maximum Check Revision occurrences | Unbounded, one per iteration | 1 | A can produce >1 Check, B cannot |
| Possible placement of Check Revision | Parallel with Analyze inside each iteration, must finish before Rework/Close of that iteration | Parallel with whole loop, may interleave before/during/after any iteration, must finish before Close | A ties Check to each iteration, B ties it to the whole case |
| Optional approval occurrences | Per iteration, after the parallel block, `X(Approve,tau)` | Per iteration, after Analyze, `X(Approve,tau)` | Same local optionality, different scoping |
| Concurrency | `+` = AND: Analyze  Check concurrent per iteration | `+` = AND: Check Revision concurrent with the entire loop | Different granularity of parallelism |
| Join before Close | Sequence `Open -> loop -> Close` in both | Sequence `Open -> parallel -> Close` in both | Open first / Close last preserved |

# 5. Bounded Comparison Code

```python
import pm4py
from collections import deque

tree_a_str = "->('Open Case',* (->(+('Analyze Revision','Check Revision'),X('Approve Revision',tau)),'Rework Case'),'Close Case')"
tree_b_str = "->('Open Case',+( 'Check Revision',* (->('Analyze Revision',X('Approve Revision',tau)),'Rework Case')),'Close Case')"

tree_a = pm4py.parse_process_tree(tree_a_str)
tree_b = pm4py.parse_process_tree(tree_b_str)

net_a, im_a, fm_a = pm4py.convert_to_petri_net(tree_a)
net_b, im_b, fm_b = pm4py.convert_to_petri_net(tree_b)

pm4py.check_soundness(net_a, im_a, fm_a, print_diagnostics=True)
pm4py.check_soundness(net_b, im_b, fm_b, print_diagnostics=True)

def explore(net, im, fm, max_vis=12, max_ana=3):
    visited = set()
    q = deque()
    q.append((im.copy(), [], 0, 0))
    traces = set()
    while q:
        m, tr, vcnt, ancnt = q.popleft()
        key = (frozenset(m.items()), vcnt, ancnt)
        if key in visited: continue
        visited.add(key)
        enabled = pm4py.get_enabled_transitions(net, m)
        for t in enabled:
            m2 = m.copy()
            # simple firing, pm4py API provides fire
            # using internal simulation via pm4py for brevity we assume a helper
            # here pseudo:
            # pm4py.apply_transition(net, m2, t)
            label = t.name
            vcnt2 = vcnt + (0 if label in ('tau','') else 1)
            ancnt2 = ancnt + (1 if label=='Analyze Revision' else 0)
            if vcnt2>max_vis or ancnt2>max_ana: 
                continue
            tr2 = tr + [label if label not in ('tau','') else None]
            if m2 == fm:
                traces.add(tuple([x for x in tr2 if x]))
            else:
                q.append((m2, tr2, vcnt2, ancnt2))
    return traces

traces_a = explore(net_a, im_a, fm_a)
traces_b = explore(net_b, im_b, fm_b)

only_a = traces_a - traces_b
only_b = traces_b - traces_a
print("Unique to A:", only_a)
print("Unique to B:", only_b)
```

The BFS is exhaustive up to the stated visible-length and Analyze bounds, handles silent transitions by not increasing `vcnt`, and checks final marking equality. `pm4py.play_out` would only give random/heuristic samples and is not exhaustive.

Footprints capture ordering dependencies `<< , > , # , ||`. # 9. Final Recommendation

* **P1 operational compliance:** Use Model A as the closest of the originals, but replace `+` by `->` to enforce AnalyzeCheck ordering. Model B is unsuitable.
* **P2 executive dashboard:** Either original model is acceptable after abstraction `2`; Model B is simpler structurally because Check is a single Boolean. The Check-only branch must be filtered out by the dashboard requirement `nA1`.
* **P3 bounded testing:** Neither model is equivalent; bounded exploration shows divergent trace sets due to Check multiplicity.

The proposed P1 simplification replaces both originals for compliance use. It does not preserve the parallel interleaving of Analyze/Check and therefore cannot be claimed equivalent under P2 or P3 without abstraction. Bounded comparison is evidence only; unbounded equivalence requires formal language inclusion proof, not sampling.
