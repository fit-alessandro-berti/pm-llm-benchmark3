# 5. PM4Py role-discovery and similarity code

The role-output schema can vary slightly across PM4Py versions. The normalization helper below handles common list-of-role-dictionaries, activity-to-resources mappings, and dataframe outputs. The mined role labels remain candidate work profiles until joined with complexity, substitution, sequence, and authority evidence.

```python

def as_list(value):
    """Normalize scalar, set, list, tuple, Series, or ndarray to a list."""
    if value is None:
        return []
    if np.isscalar(value) and pd.isna(value):
        return []
    if isinstance(value, (str, bytes)):
        return [value]
    if isinstance(value, (set, list, tuple, pd.Series, np.ndarray)):
        return list(value)
    return [value]

def roles_to_long(roles):
    """
    Convert common PM4Py role-output shapes to:
    mined_role | resource | activities

    Candidate role IDs are deliberately not named as formal departments.
    """
    rows = []

    if isinstance(roles, pd.DataFrame):
        rdf = roles.copy()
        resource_col = next(
            (
                c for c in rdf.columns
                if "resource" in c.lower()
                or "originator" in c.lower()
                or c == RESOURCE
            ),
            None,
        )
        activity_col = next(
            (c for c in rdf.columns if "activit" in c.lower()),
            None,
        )
        role_col = next(
            (c for c in rdf.columns if c.lower() in {"role", "role_id"}),
            None,
        )

        if resource_col is None:
            raise ValueError(
                "Inspect the printed role dataframe and identify its resource column."
            )

        for i, row in rdf.iterrows():
            role_id = row[role_col] if role_col else f"role_{i}"
            resources = as_list(row[resource_col])
            activities = as_list(row[activity_col]) if activity_col else []

            for resource in dict.fromkeys(resources):
                rows.append(
                    {
                        "mined_role": str(role_id),
                        "resource": resource,
                        "activities": tuple(activities),
                    }
                )

        return pd.DataFrame(rows)

    iterable = roles.items() if isinstance(roles, dict) else enumerate(roles)

    for role_id, role in iterable:
        resources = []
        activities = []

        if isinstance(role, dict):
            if "resources" in role or "originators" in role:
                resources = as_list(
                    role.get("resources", role.get("originators"))
                )
                activities = as_list(
                    role.get("activities", role.get("activity", []))
                )
            else:
                # Common representation:
                # {activity_1: {resource_a, resource_b}, activity_2: {...}}
                for activity, performers in role.items():
                    activities.append(activity)
                    resources.extend(as_list(performers))

        elif isinstance(role, (tuple, list)) and len(role) == 2:
            # Possible fallback: (activities, resources)
            activities = as_list(role[0])
            resources = as_list(role[1])

        else:
            resources = as_list(getattr(role, "resources", []))
            activities = as_list(getattr(role, "activities", []))

        for resource in dict.fromkeys(resources):
            rows.append(
                {
                    "mined_role": f"candidate_role_{role_id}",
                    "resource": resource,
                    "activities": tuple(activities),
                }
            )

    return pd.DataFrame(rows)

def mined_roles_by_resource(raw_roles):
    role_long = roles_to_long(raw_roles)

    if role_long.empty:
        return pd.Series(dtype="object")

    return (
        role_long.groupby("resource")["mined_role"]
        .agg(lambda values: "; ".join(sorted(set(values))))
    )

def network_value(value):
    if isinstance(value, dict):
        return value.get("weight", value.get("count", 1))
    return value

def network_to_frame(network):
    """Normalize common PM4Py social-network outputs."""
    if isinstance(network, pd.DataFrame):
        return network.copy()

    rows = []

    if hasattr(network, "edges"):
        for source, target, data in network.edges(data=True):
            rows.append(
                {
                    "source": source,
                    "target": target,
                    "weight": network_value(data),
                }
            )

    elif isinstance(network, dict):
        if network and all(isinstance(key, tuple) for key in network):
            for edge, value in network.items():
                rows.append(
                    {
                        "source": edge[0],
                        "target": edge[1],
                        "weight": network_value(value),
                    }
                )
        else:
            for source, targets in network.items():
                if isinstance(targets, dict):
```

Important reading rules for the output:

- `mined_roles_all_events` contains candidate activity communities, not formal job titles.
- High cosine similarity means similar activity exposure. It does not imply equal authority, proficiency, risk, or replaceability.
- Handover-of-work edges are directional and can test paths such as Erik  Mateo  technical implementation or Fatima/Giorgio  Hana.
- Working-together edges mean resources appeared on the same cases; they do not establish sequence, supervision, or collaboration intent.
- Comparing `candidate_roles_during_substitution` with roles outside substitution helps distinguish temporary coverage from a durable hybrid role.
- Comparing all-event roles with high/critical-event roles separates routine specialization from risk exposure.
- An A9 count is only approval evidence. Final authority still requires approval status, permissions, escalation level, and recheck semantics.

**Cautions before changing staffing**

1. **Mined roles describe historical routing, not necessarily competence or capacity.** Chen’s higher complexity may reflect skill, but it may also reflect dispatcher behavior. Do not reduce Dina’s development opportunities or Chen’s workload solely from a role label.
2. **Activity frequency is not business criticality.** Erik would look underutilized if staffed by event volume, even though his work is concentrated in high/critical cases.
3. **Activity similarity is not authority or equivalence.** Hana and Mateo both touch escalations, and Chen and Dina have highly similar profiles, but their risk exposure and decision rights differ.
4. **Temporary substitution is not proof of permanent readiness.** Giorgio’s commercial coverage and Mateo’s preliminary approvals maintained continuity, but duration and recheck evidence show that controlled validation is still needed.
5. **A ten-week mining window can reflect seasonality and staffing constraints.** Pilot staffing changes and re-mine the process after the intervention, because changing assignments will itself change future role evidence.
