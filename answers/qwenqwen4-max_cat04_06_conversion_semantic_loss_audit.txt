    start = (marking_key(im), 0)
    seen = {start}

def try_call(fn, *args, **kwargs):
    try:
        return True, fn(*args, **kwargs)
    except Exception as exc:
        return False, {"error": f"{type(exc).__name__}: {exc}",
                       "traceback": traceback.format_exc()}

def marking_items(m):
    if m is None:
        return {}
    try:
        items = list(m.items())
    except AttributeError:
        items = [(p, m[p]) for p in m]
    return {p: int(c) for p, c in items if int(c) > 0}

def markings_equal(m1, m2):
    a, b = marking_items(m1), marking_items(m2)
    return a.keys() == b.keys() and all(a[p] == b[p] for p in a)

def marking_key(m):
    return tuple(sorted((id(p), c) for p, c in marking_items(m).items()))

def marking_from_dict(d):
    out = Marking()
    for p, c in d.items():
        if c > 0:
            out[p] = c
    return out

def arc_weight(arc):
    w = getattr(arc, "weight", 1)
    return int(w) if w else 1

def enabled(net, m):
    return list(pm4py.get_enabled_transitions(net, m))

def fire(t, m):
    d = marking_items(m)
    for arc in t.in_arcs:
        if d.get(arc.source, 0) < arc_weight(arc):
            return None
    for arc in t.in_arcs:
        p = arc.source
        d[p] -= arc_weight(arc)
        if d[p] == 0:
            del d[p]
    for arc in t.out_arcs:
        p = arc.target
        d[p] = d.get(p, 0) + arc_weight(arc)
    return marking_from_dict(d)

def label_multiset(net):
    return Counter(t.label for t in net.transitions if t.label is not None)

def normalize_soundness(res):
    if isinstance(res, bool):
        return {"is_sound": res, "raw": res}
    if isinstance(res, dict):
        for k in ("is_sound", "sound", "is_sound_wf_net", "soundness"):
            if k in res:
                return {"is_sound": bool(res[k]), "raw": res}
        return {"is_sound": None, "raw": res}
    if isinstance(res, (tuple, list)) and res and isinstance(res[0], bool):
        return {"is_sound": bool(res[0]), "raw": list(res)}
    return {"is_sound": None, "raw": repr(res)}

| I16 | **No spurious constraints.** The derivative must not add order that the source lacks (`A<P`, `P<L`, `L<C`, `I<L`, atomic loop body). | W02  W03  W06 jointly | any derivative whose whole language satisfies `P<L`, or which rejects R,A,P,C,L,I,X,Z | Yes, but only as a **language-level** property, never from a single trace |

# 2. Candidate Conversion Pipelines

| Pipeline | PM4Py calls | Expected benefit | Expected risk | Failure condition |
|---|---|---|---|---|
| **P1 — PRIMARY (gated)** `POWL  accepting Petri net  BPMN  (net)` | `pm4py.convert_to_petri_net(source_powl)`; `pm4py.convert_to_bpmn(net, im, fm)`; `pm4py.convert_to_petri_net(bpmn)`; `pm4py.check_is_workflow_net`, `pm4py.check_soundness` | Shortest documented path; the accepting net carries executable semantics and is the validation oracle; BPMN is produced for stakeholders only | In several PM4Py releases the PetriBPMN variant is *mediated by block-structured process-tree extraction*, so P1 can fail for the same reason as P2 (**correlated failure**). Silent 's become anonymous gateways/tasks; XOR-with- may be collapsed; the asymmetric join may be restructured; labels may be duplicated or renamed | Exception from `convert_to_bpmn`; `im`/`fm` null or empty; result not a workflow net; unsound; round-trip net rejects any positive witness or admits any negative witness |
| **P2 — probe, allowed to fail** `POWL  net  process tree  BPMN  (net)` | `pm4py.convert_to_process_tree(net, im, fm)` inside `try/except`; `pm4py.convert_to_bpmn(tree)`; `pm4py.convert_to_petri_net(bpmn_from_tree)` | If it worked, a block-structured tree gives the cleanest BPMN (nested sub-processes, canonical loop marker) | The source partial order is **not block-structured** (proof sketch in §4). Extraction is expected to raise. If it *returns* a tree, the tree is most likely a language approximation or uses duplicated labels — a returned object is not evidence of fidelity | `Exception` from `convert_to_process_tree` (expected); or a tree whose label multiset differs, or whose net rejects W02/W03/W06 or admits N03/N06 |
| **P3 — diagnostic isolation** `POWL  net  tree  net` | `pm4py.convert_to_process_tree(...)`; `pm4py.convert_to_petri_net(tree)` | Separates *tree-extraction loss* from *BPMN serialization loss*; if P3 already drifts, BPMN is not the culprit | Same block-structuredness obstruction; may silently over-approximate (e.g. allow zero iterations) | Exception, or bounded-language difference vs `net_from_powl` |
| **P4 — declared fallback, no BPMN** `POWL  net` (+ POWL visualization) | `pm4py.convert_to_petri_net(source_powl)`; `pm4py.save_vis_powl`; `pm4py.save_vis_petri_net` | Guarantees a semantically auditable stakeholder artifact even when P1/P2 fail; no fabricated routing | Less familiar notation for business readers; net visualization is itself layout-suggestive | Only fails if stage 1 fails, which aborts everything |

**Chosen primary: P1, gated.** P1's BPMN is published only if the §5 comparison returns `validated preserved` for the bounded checks *and* the §7 rejection list is empty. Otherwise P4 is the stakeholder deliverable and any P1/P2 BPMN is quarantined as *illustrative, non-normative*. P2 and P3 are run **because their failure is informative**, not to obtain a model.

# 3. Conversion Code

```python
# =====================================================================
# powl_audit_convert.py
# Stage harness: POWL -> accepting Petri net -> BPMN  (+ process-tree probe)
# Assumes the AUTHORITATIVE source snippet has already been executed and
# `source_powl` is in scope. This file never mutates source_powl.
# =====================================================================
from __future__ import annotations

import json
import os
import traceback
from collections import Counter

import pm4py
from pm4py.objects.petri_net.obj import Marking

if "source_powl" not in globals():
    raise RuntimeError("Execute the authoritative source snippet first: `source_powl` must be in scope.")

OUT_DIR = "artifacts"
os.makedirs(OUT_DIR, exist_ok=True)
PM4PY_VERSION = getattr(pm4py, "__version__", "unknown")

# ------------------------------------------------------------------ utils
def try_call(fn, *args, **kwargs):
    """Never suppress a conversion exception: keep type, message and traceback."""
    try:
        return True, fn(*args, **kwargs)
    except Exception as exc:
        return False, {"error": f"{type(exc).__name__}: {exc}",
                       "traceback": traceback.format_exc()}


def marking_items(m):
    """Multiset view of a marking; tolerates None and minimal Marking APIs."""
    if m is None:
        return {}
    try:
        items = list(m.items())
    except AttributeError:
        items = [(p, m[p]) for p in m]
    return {p: int(c) for p, c in items if int(c) > 0}


def markings_equal(m1, m2):
    """EXACT equality (no subsumption): residual tokens must fail this test."""
    a, b = marking_items(m1), marking_items(m2)
    return a.keys() == b.keys() and all(a[p] == b[p] for p in a)


def marking_key(m):
    """Identity-based canonical key; valid WITHIN one net only."""
    return tuple(sorted((id(p), c) for p, c in marking_items(m).items()))


def marking_from_dict(d):
    out = Marking()
    for p, c in d.items():
        if c > 0:
            out[p] = c
    return out


def arc_weight(arc):
    w = getattr(arc, "weight", 1)
    return int(w) if w else 1


def enabled(net, m):
    return list(pm4py.get_enabled_transitions(net, m))


def fire(t, m):
    """Token game with arc weights; check-all-then-consume handles self-loops."""
    d = marking_items(m)
    for arc in t.in_arcs:
        if d.get(arc.source, 0) < arc_weight(arc):
            return None
    for arc in t.in_arcs:
        p = arc.source
        d[p] -= arc_weight(arc)
        if d[p] == 0:
            del d[p]
    for arc in t.out_arcs:
        p = arc.target
        d[p] = d.get(p, 0) + arc_weight(arc)
    return marking_from_dict(d)


def label_multiset(net):
    return Counter(t.label for t in net.transitions if t.label is not None)


def normalize_soundness(res):
    """check_soundness return type varies across versions: bool / dict / tuple."""
    if isinstance(res, bool):
        return {"is_sound": res, "raw": res}
    if isinstance(res, dict):
        for k in ("is_sound", "sound", "is_sound_wf_net", "soundness"):
            if k in res:
                return {"is_sound": bool(res[k]), "raw": res}
        return {"is_sound": None, "raw": res}
    if isinstance(res, (tuple, list)) and res and isinstance(res[0], bool):
        return {"is_sound": bool(res[0]), "raw": list(res)}
    return {"is_sound": None, "raw": repr(res)}


# ------------------------------------------------------------ diagnostics
def diagnose_net(name, net, im, fm):
    rec = {
        "artifact": name,
        "places": len(net.places),
        "transitions": len(net.transitions),
        "arcs": len(net.arcs),
        "labels": dict(label_multiset(net)),
        "silent_transitions": sum(1 for t in net.transitions if t.label is None),
        "im": str(im) if im is not None else None,
        "fm": str(fm) if fm is not None else None,
        "im_ok": bool(marking_items(im)),
        "fm_ok": bool(marking_items(fm)),
        "problems": [],
    }
    rec["duplicate_labels"] = {l: c for l, c in rec["labels"].items() if c > 1}
    if rec["duplicate_labels"]:
        rec["problems"].append(f"duplicate activity labels {rec['duplicate_labels']}")

    ok, val = try_call(pm4py.check_is_workflow_net, net)
    rec["is_workflow_net"] = val if ok else None
    if not ok:
        rec["problems"].append(f"check_is_workflow_net raised: {val}")
    elif val is False:
        rec["problems"].append("not a workflow net (unique source/sink/path condition)")

    # NEVER assume markings are non-null.
    if rec["im_ok"] and rec["fm_ok"]:
        ok, val = try_call(pm4py.check_soundness, net, im, fm, print_diagnostics=True)
        rec["soundness"] = normalize_soundness(val) if ok else {"is_sound": None, "raw": val}
        if not ok:
            rec["problems"].append("check_soundness raised")
        elif rec["soundness"]["is_sound"] is not True:
            rec["problems"].append("soundness NOT confirmed")
        ok2, en = try_call(enabled, net, fm)
        rec["fm_is_dead"] = bool(ok2 and not en)
        if ok2 and en:
            rec["problems"].append("final marking still enables transitions (improper completion)")
    else:
        rec["soundness"] = {"is_sound": None, "raw": "skipped: null/empty im or fm"}
        rec["fm_is_dead"] = None
        rec["problems"].append("null/empty initial or final marking -> exact-final tests impossible")
    return rec


def bpmn_profile(bpmn):
    """Structural fingerprint for the visual/gateway audit (defensive getattr)."""
    nodes = list(getattr(bpmn, "nodes", []) or [])
    return {
        "node_kinds": dict(Counter(type(n).__name__ for n in nodes)),
        "gateway_types": dict(Counter(str(getattr(n, "gateway_type", "?"))
                                      for n in nodes if type(n).__name__ == "Gateway")),
        "task_labels": dict(Counter(str(getattr(n, "name", ""))
                                    for n in nodes if type(n).__name__ == "Task")),
        "n_arcs": len(list(getattr(bpmn, "arcs", []) or [])),
    }


def tree_profile(tree):
    ops, labels, depth = Counter(), Counter(), 0
    stack = [(tree, 0)]
    while stack:
        n, d = stack.pop()
        depth = max(depth, d)
        op = getattr(n, "operator", None)
        if op is not None:
            ops[str(op)] += 1
        lab = getattr(n, "label", None)
        if lab is not None:
            labels[str(lab)] += 1
        for c in (getattr(n, "children", []) or []):
            stack.append((c, d + 1))
    return {"operators": dict(ops), "labels": dict(labels), "depth": depth,
            "duplicate_labels": {l: c for l, c in labels.items() if c > 1}}


def unpack_net(res, origin):
    """Converters may return (net, im, fm) or a bare object; do not guess silently."""
    if isinstance(res, tuple) and len(res) == 3:
        return res[0], res[1], res[2], []
    return res, None, None, [f"{origin}: converter did not return (net, im, fm); markings unavailable"]


# ------------------------------------------------------------- conversion
def build_artifacts():
    ART = {"meta": {"pm4py": PM4PY_VERSION}, "nets": {}, "bpmns": {}, "trees": {},
           "failures": {}, "notes": []}

    # ---- Stage 1: POWL -> accepting Petri net (shared by P1..P4)
    ok, res = try_call(pm4py.convert_to_petri_net, source_powl)
    if not ok:
        ART["failures"]["stage1_powl_to_petri"] = res
        raise RuntimeError("POWL->Petri failed; no pipeline can proceed: " + res["error"])
    net, im, fm = unpack_net(res, "convert_to_petri_net(source_powl)")
    d = diagnose_net("net_from_powl", net, im, fm)
    ART["nets"]["net_from_powl"] = {"net": net, "im": im, "fm": fm,
                                    "pipeline": "stage1 (P1/P2/P3/P4)", "diag": d}

    # ---- P1: Petri -> BPMN  (may fail: block-structuredness is often required)
    ok, res = try_call(pm4py.convert_to_bpmn, net, im, fm)
    if ok:
        ART["bpmns"]["bpmn_from_net"] = {"bpmn": res, "pipeline": "P1",
                                         "profile": bpmn_profile(res)}
    else:
        ART["failures"]["P1_petri_to_bpmn"] = res
        ART["notes"].append("P1 failed. Do NOT hand-repair a BPMN into the canonical path; "
                            "fall back to P4 (POWL + net visualization).")

    # ---- P2: Petri -> process tree (EXPECTED to fail; must be caught & interpreted)
    ok, res = try_call(pm4py.convert_to_process_tree, net, im, fm)
    if ok:
        tree = res
        ART["trees"]["tree_from_net"] = {"tree": tree, "pipeline": "P2/P3",
                                         "profile": tree_profile(tree)}
        ART["notes"].append("Tree extraction UNEXPECTEDLY succeeded: treat as approximation "
                            "until bounded-language + witness comparison passes.")
        ok2, res2 = try_call(pm4py.convert_to_bpmn, tree)
        if ok2:
            ART["bpmns"]["bpmn_from_tree"] = {"bpmn": res2, "pipeline": "P2",
                                              "profile": bpmn_profile(res2)}
        else:
            ART["failures"]["P2_tree_to_bpmn"] = res2
        # ---- P3: tree -> net, isolates extraction loss from BPMN serialization loss
        ok3, res3 = try_call(pm4py.convert_to_petri_net, tree)
        if ok3:
            n3, i3, f3, warn = unpack_net(res3, "convert_to_petri_net(tree)")
            ART["nets"]["rt_tree_from_net"] = {"net": n3, "im": i3, "fm": f3, "pipeline": "P3",
                                               "diag": diagnose_net("rt_tree_from_net", n3, i3, f3)}
            ART["notes"].extend(warn)
        else:
            ART["failures"]["P3_tree_to_net"] = res3
    else:
        ART["failures"]["P2_petri_to_tree"] = res
        ART["notes"].append(
            "P2/P3 tree extraction raised. Interpretation: the source partial order is not "
            "block-structured (pred(L)={A} vs pred(V)={A,P}; L is unordered with P and with the "
            "loop body). This is a CORRECT failure, not a tooling defect. Record 'conversion failed'.")

    # ---- Round trip: every produced BPMN back to an accepting net, where possible
    for name, rec in list(ART["bpmns"].items()):
        ok, res = try_call(pm4py.convert_to_petri_net, rec["bpmn"])
        if not ok:
            ART["failures"][f"roundtrip_{name}"] = res
            continue
        n2, i2, f2, warn = unpack_net(res, f"convert_to_petri_net({name})")
        key = "rt_" + name
        ART["nets"][key] = {"net": n2, "im": i2, "fm": f2,
                            "pipeline": rec["pipeline"] + " round trip",
                            "diag": diagnose_net(key, n2, i2, f2)}
        ART["notes"].extend(warn)

    return ART


# ---------------------------------------------------------- visualisation
def save_visuals(ART):
    jobs = [(f"{OUT_DIR}/00_source_powl_AUTHORITATIVE.svg",
             pm4py.save_vis_powl, (source_powl,))]
    for name, rec in ART["nets"].items():
        if rec["im"] is not None and rec["fm"] is not None:
            jobs.append((f"{OUT_DIR}/net_{name}.svg", pm4py.save_vis_petri_net,
                         (rec["net"], rec["im"], rec["fm"])))
        else:
            ART["failures"][f"vis_{name}"] = {"error": "null marking; net visualization skipped"}
    for name, rec in ART["bpmns"].items():
        jobs.append((f"{OUT_DIR}/bpmn_{name}_{rec['pipeline']}_DERIVATIVE.svg",
                     pm4py.save_vis_bpmn, (rec["bpmn"],)))
    for name, rec in ART["trees"].items():
        jobs.append((f"{OUT_DIR}/tree_{name}_PROBE.svg", pm4py.save_vis_process_tree, (rec["tree"],)))

    saved = {}
    for path, fn, args in jobs:
        ok, res = try_call(fn, *args, path)
        saved[path] = "ok" if ok else res
        if not ok:
            ART["failures"]["vis_" + os.path.basename(path)] = res
    return saved


def main():
    ART = build_artifacts()
    ART["visuals"] = save_visuals(ART)
    report = {
        "meta": ART["meta"],
        "nets": {k: v["diag"] for k, v in ART["nets"].items()},
        "bpmns": {k: {"pipeline": v["pipeline"], "profile": v["profile"]} for k, v in ART["bpmns"].items()},
        "trees": {k: v["profile"] for k, v in ART["trees"].items()},
        "failures": ART["failures"],
        "notes": ART["notes"],
        "visuals": ART["visuals"],
    }
    with open(f"{OUT_DIR}/conversion_report.json", "w", encoding="utf-8") as fh:
        json.dump(report, fh, indent=2, default=str)
    print(json.dumps(report, indent=2, default=str))
    return ART


if __name__ == "__main__":
    main()
```

**Notes on the code.** `convert_to_bpmn` is wrapped because it is *not* guaranteed to accept an arbitrary marked net. `convert_to_process_tree` is wrapped because failure is the expected, correct outcome here. No POWLBPMN call is invented: BPMN is reached only through a marked net or a tree, exactly as the API allows. Null/empty markings disable marking-dependent tests instead of being fabricated.

# 4. Preservation and Loss Audit

Cells are **pre-execation expectations**. The harness overwrites them; the mapping from harness output to term is given after the table. `conversion failed` in the tree column is an *expected* outcome, to be confirmed at runtime.

**Term-assignment rule used by the harness** (this is the only route to `validated preserved`):

| Harness output | Term |
|---|---|
| Conversion raised / returned unusable object / null marking | `conversion failed` |
| Both nets sound workflow nets, identical label multisets, **exhaustive** bounded languages equal, all witness verdicts identical | `validated preserved` *(bounded, trace-level only — see §9)* |
| Bounded language of derivative  source (required trace missing) | `lost` |
| Bounded language  source, or extra/duplicated labels, or soundness weakened | `approximated` |
| Any budget exhausted, non-exhaustive exploration, inconclusive soundness | `ambiguous` |
| No test exists for the claim | `not tested` |

### Why the tree intermediate is expected to fail (proof sketch)

Assume a process tree over the eight labels, each appearing once, generating the source language.

1. A and P both occur in every completed trace, in both orders  `LCA(A,P)` is a **parallel** block (XOR would exclude one; SEQ would fix an order; LOOP would allow repetition).
2. L must follow A and be unordered with P. Therefore L is either **inside the A-branch** of that parallel block, or **outside** the block.
   * Inside the A-branch: the block must complete before C (because `P<V`), so `L<C` in every trace — contradicts R,A,P,C,I,L,X,Z (W05).
   * Outside the block: `A<L` **and** `P<L` — contradicts R,A,L,P,C,I,X,Z (W03).
3. Hence no such tree exists. Duplicating A or L could restore decomposability, but that breaks I13 (activity identity) and is not what the converter does.
4. Independent second obstruction: L may interleave *inside* a loop iteration (W06). A tree's loop body is a block; concurrency crossing the loop boundary is not expressible.

Conclusion: `conversion failed` for P2/P3 is the **semantically correct** result. Because some PM4Py releases route PetriBPMN through the same extraction, **P1 may fail for the same reason** — which is why P4 exists and why a "successful" P1 must never be assumed.

### Discussion of the mandated points

* **True concurrency vs interleaving.** The source states absence of order, not overlap. Token independence in the net preserves the *potential* for overlap; every test here is interleaving-based. A derivative that puts A and P in a sequence but generates both orders (e.g. via duplicated tasks or an XOR of two sequences) passes trace tests and still loses concurrency and identity.
* **No edge between optional legal and verification.** This is the invariant most likely to be silently *strengthened*. Any BPMN showing legal review "before" the trial block, or the trial block "before" legal, has added an edge. Detect it with W03, W05, W06 jointly, never with a single trace.
* **Silent optional behaviour.** The  branch is unobservable, so its collapse cannot be seen in a visualization; it shows up only as "L in every completed trace" (mandatory) or "L in none" (deleted), or as a deadlock on the skip path at the release join.
* **Binary loop.** `LOOP(SEQ(C,I), D)` = do-while with body `C I` and separator `D`. Confusable with: while-do (zero iterations), loop on a single task, mandatory `D`, or `D` after the last iteration. All four are separate negative witnesses (N03, N10, N04, N05).
* **Join before Release.** It synchronizes *branch resolution* (L **or** ) with *loop exit*. In BPMN this needs XOR-split  XOR-merge  AND-join. Skipping the merge is the classic deadlock; replacing the AND-join with an XOR-merge admits release before verification (N14).
* **Label uniqueness.** All eight source labels are distinct and single-instance. Duplication during conversion inflates footprints, breaks task identity in BPMN, and makes trace comparison label-multiset-invalid even if the language matches.
* **Initial/final markings.** Some conversions return `None` or an empty marking. Exact-final-marking equality is then untestable; the artifact must be quarantined rather than scored.
* **Gateway/routing ambiguity.** `gateway_types` counts are a *hint*, not a proof. A `+` gateway where the net has a non-free-choice construct, or an `O` (inclusive) gateway where XOR is required, changes semantics without changing the visible label set.

# 5. Round-Trip Validation Code

**Defensibility of each instrument.** `check_soundness` — necessary, not sufficient (variant-dependent, may be inconclusive on non-workflow or unbounded nets). `discover_footprints` — a lossy abstraction: equal footprints  equal languages, and unequal footprints may be an artifact of /duplicate labels; used as a *smell test*. `convert_to_reachability_graph` — may not terminate on unbounded nets, so guarded and used only for structural fingerprints and dead-state counting, **never** as an equivalence oracle. Bounded visible-trace exploration + witness admission — the primary evidence. Playout — sampling, useful for cross-admission, never a proof.

**Bound semantics.** Visible length  `MAX_VISIBLE=16`, loop iterations  `MAX_ITER=3` (counted on `Configure Trial`), -closure per state  `SILENT_STATES=4000` markings, global expansion budget, and a trace-set cap. Silent transitions (`label is None`) never enter a trace. A trace is *completed* only when the reached marking is **exactly equal** to `fm`. -cycles are terminated by a visited-marking set, so silent cycling cannot loop forever. **The comparison is exhaustive under the bound if and only if no truncation flag is set on either side; it is never exhaustive over the unbounded loop language.**

```python
# =====================================================================
# powl_audit_validate.py
# Bounded, witness-driven comparison of net_from_powl against every
# round-tripped net produced by powl_audit_convert.build_artifacts().
# =====================================================================
from __future__ import annotations

import json
from collections import Counter

import pm4py
from powl_audit_convert import (build_artifacts, marking_items, markings_equal, marking_key,
                                fire, enabled, label_multiset, try_call, normalize_soundness,
                                OUT_DIR)

LBL = dict(R="Register Change", A="Assess Risk", P="Prepare Evidence", L="Legal Review",
           C="Configure Trial", I="Inspect Trial", D="Correct Defect",
           X="Release Change", Z="Archive Change")
CONFIGURE = LBL["C"]

def tr(*codes):
    return tuple(LBL[c] for c in codes)

POSITIVE = {
    "W01_skip_assess_first": tr("R","A","P","C","I","X","Z"),
    "W02_prepare_first":     tr("R","P","A","C","I","X","Z"),
    "W03_legal_before_prep": tr("R","A","L","P","C","I","X","Z"),
    "W04_legal_after_prep":  tr("R","A","P","L","C","I","X","Z"),
    "W05_legal_after_loop":  tr("R","A","P","C","I","L","X","Z"),
    "W06_legal_inside_iter": tr("R","A","P","C","L","I","X","Z"),
    "W07_two_iterations":    tr("R","A","P","C","I","D","C","I","X","Z"),
    "W08_three_iter_legal":  tr("R","P","A","C","I","D","C","I","D","C","I","L","X","Z"),
    "W09_legal_before_redo": tr("R","A","P","C","I","L","D","C","I","X","Z"),
    "W10_legal_split":       tr("R","A","L","P","C","I","D","C","L","I","X","Z"),
    "W11_prep_first_legal":  tr("R","P","A","L","C","I","X","Z"),
}
NEGATIVE = {
    "N01_register_not_first": tr("A","R","P","C","I","X","Z"),
    "N02_verify_before_prep": tr("R","A","C","I","P","X","Z"),
    "N03_zero_iterations":    tr("R","A","P","X","Z"),
    "N04_trailing_defect":    tr("R","A","P","C","I","D","X","Z"),
    "N05_repeat_no_separator":tr("R","A","P","C","I","C","I","X","Z"),
    "N06_legal_after_release":tr("R","A","P","C","I","X","L","Z"),
    "N07_legal_before_assess":tr("R","L","A","P","C","I","X","Z"),
    "N08_no_archive":         tr("R","A","P","C","I","X"),
    "N09_archive_twice":      tr("R","A","P","C","I","X","Z","Z"),
    "N10_inspect_first":      tr("R","A","P","I","C","X","Z"),
    "N11_double_defect":      tr("R","A","P","C","I","D","D","C","I","X","Z"),
    "N12_legal_twice":        tr("R","A","P","L","L","C","I","X","Z"),
    "N13_defect_first":       tr("R","A","P","D","C","I","X","Z"),
    "N14_release_mid_loop":   tr("R","A","P","C","X","I","Z"),
    "N15_empty":              (),
}

MAX_VISIBLE, MAX_ITER = 16, 3
SILENT_STATES, NODE_BUDGET, TRACE_CAP, ADMIT_STATES = 4000, 200000, 200000, 60000


# ---------------------------------------------- bounded visible language
def explore_completed_language(net, im, fm):
    """Set of visible traces (tau hidden) that reach EXACTLY fm, under the bound."""
    st = {"nodes": 0, "truncated": False, "silent_cycle_seen": False,
          "deadlocks": [], "livelock_witnesses": [], "max_tokens": 0}
    if not marking_items(im) or not marking_items(fm):
        st["truncated"] = True
        st["error"] = "null/empty im or fm: exploration not possible"
        return set(), st

    closure_cache = {}

    def tau_closure(m):
        key = marking_key(m)
        if key in closure_cache:
            return closure_cache[key]
        seen, stack, edges = {key: m}, [m], {}
        completed = False
        while stack:
            cur = stack.pop()
            ck = marking_key(cur)
            st["max_tokens"] = max(st["max_tokens"], sum(marking_items(cur).values()))
            if markings_equal(cur, fm):
                completed = True
            en = enabled(net, cur)
            if not en and not markings_equal(cur, fm):
                st["deadlocks"].append(str(cur))
            edges.setdefault(ck, set())
            for t in en:
                if t.label is not None:            # hide tau ONLY here
                    continue
                nxt = fire(t, cur)
                if nxt is None:
                    continue
                nk = marking_key(nxt)
                edges[ck].add(nk)
                if nk in seen:                     # silent cycle -> stop, do not spin
                    st["silent_cycle_seen"] = True
                    continue
                if len(seen) >= SILENT_STATES:
                    st["truncated"] = True
                    continue
                seen[nk] = nxt
                stack.append(nxt)
        # tau-only trap: cannot reach fm nor any visible-enabled marking
        good = set()
        for k, mk in seen.items():
            if markings_equal(mk, fm) or any(t.label is not None for t in enabled(net, mk)):
                good.add(k)
        rev = {}
        for a, outs in edges.items():
            for b in outs:
                rev.setdefault(b, set()).add(a)
        frontier = list(good)
        while frontier:
            b = frontier.pop()
            for a in rev.get(b, ()):
                if a not in good:
                    good.add(a); frontier.append(a)
        for k in seen.keys() - good:
            st["livelock_witnesses"].append(str(seen[k]))
        closure_cache[key] = (list(seen.values()), completed)
        return closure_cache[key]

    memo = {}

    def suffixes(m, v, k):
        key = (marking_key(m), v, k)
        if key in memo:
            return memo[key]
        st["nodes"] += 1
        if st["nodes"] > NODE_BUDGET:
            st["truncated"] = True
            return set()
        closure, completed = tau_closure(m)
        out = {()} if completed else set()
        if v > 0:
            for cm in closure:
                for t in enabled(net, cm):
                    lab = t.label
                    if lab is None:
                        continue
                    if lab == CONFIGURE:
                        if k <= 0:
                            continue
                        nk = k - 1
                    else:
                        nk = k
                    nxt = fire(t, cm)
                    if nxt is None:
                        continue
                    for suf in suffixes(nxt, v - 1, nk):
                        out.add((lab,) + suf)
                        if len(out) > TRACE_CAP:
                            st["truncated"] = True
                            memo[key] = out
                            return out
        memo[key] = out
        return out

    lang = suffixes(im, MAX_VISIBLE, MAX_ITER)
    st["fm_is_dead"] = not enabled(net, fm)
    st["exhaustive_under_bound"] = not st["truncated"]
    return lang, st


# --------------------------------------------------- single-trace admission
def admits_trace(net, im, fm, labels):
    """'admitted' | 'not admitted' | 'unknown (...)'. Exact fm equality required.
    Iteration budget is a function of the matched prefix, so it need not be in the state key."""
    if not marking_items(im) or not marking_items(fm):
        return "unknown (null marking)"
    prefix_iters = [0] * (len(labels) + 1)
    for i, lab in enumerate(labels):
        prefix_iters[i + 1] = prefix_iters[i] + (1 if lab == CONFIGURE else 0)
    if prefix_iters[-1] > MAX_ITER or len(labels) > MAX_VISIBLE:
        return "unknown (witness outside bound)"
    seen = {(marking_key(im), 0)}
    stack = [(im, 0)]
    while stack:
        m, i = stack.pop()
        if i == len(labels) and markings_equal(m, fm):
            return "admitted"
        for t in enabled(net, m):
            if t.label is None:
                ni = i                                  # tau: no visible progress
            else:
                if i >= len(labels) or t.label != labels[i]:
                    continue
                ni = i + 1
                if prefix_iters[ni] > MAX_ITER:
                    continue
            nxt = fire(t, m)
            if nxt is None:
                continue
            key = (marking_key(nxt), ni)
            if key in seen:                             # kills infinite silent cycling
                continue
            if len(seen) >= ADMIT_STATES:
                return "unknown (state budget exhausted)"
            seen.add(key)
            stack.append((nxt, ni))
    return "not admitted"


# ------------------------------------------------------------- abstractions
def footprint_relations(fp):
    rel = {}
    for attr in ("sequence", "parallel", "choice", "loop"):
        val = getattr(fp, attr, None)
        rel[attr] = {tuple(x) for x in val} if val is not None else None
    for attr in ("activities", "start_activities", "end_activities"):
        val = getattr(fp, attr, None)
        rel[attr] = set(val) if val is not None else None
    return rel


def footprint_diff(fp1, fp2):
    a, b = footprint_relations(fp1), footprint_relations(fp2)
    out = {}
    for k in a:
        if a[k] is None or b[k] is None:
            out[k] = "unavailable"
        else:
            out[k] = {"only_source": sorted(map(str, a[k] - b[k])),
                      "only_derivative": sorted(map(str, b[k] - a[k]))}
    return out


def reachability_fingerprint(net, im, fm):
    ok, rg = try_call(pm4py.convert_to_reachability_graph, net, im, fm)
    if not ok:
        return {"status": "failed_or_unbounded", "detail": rg}
    states = list(getattr(rg, "states", []) or [])
    trans = list(getattr(rg, "transitions", []) or [])
    has_out = {getattr(t, "from_state", None) for t in trans}
    dead = [str(getattr(s, "name", s)) for s in states if s not in has_out]
    return {"status": "ok", "states": len(states), "transitions": len(trans),
            "visible_labels": sorted({str(getattr(t, "label", None)) for t in trans
                                      if getattr(t, "label", None) is not None}),
            "dead_states": dead,
            "caveat": "structural fingerprint only; NOT an equivalence check"}


def playout_crosscheck(source, target, n_traces=40):
    """Where supported: play out one model, require admission by the other."""
    play = getattr(pm4py, "play_out", None)
    if play is None:
        return {"status": "not supported in this pm4py version"}
    out = {}
    for direction, (gen, oracle) in {"derivative->source": (target, source),
                                     "source->derivative": (source, target)}.items():
        ok, log = try_call(play, gen["net"], gen["im"], gen["fm"])
        if not ok:
            ok, log = try_call(play, (gen["net"], gen["im"], gen["fm"]))
        if not ok:
            out[direction] = {"status": "playout failed", "detail": log}
            continue
        verdicts = Counter()
        examples = []
        try:
            for i, trace in enumerate(log):
                if i >= n_traces:
                    break
                labels = tuple(e["concept:name"] for e in trace)
                v = admits_trace(oracle["net"], oracle["im"], oracle["fm"], labels)
                verdicts[v] += 1
                if v != "admitted" and len(examples) < 5:
                    examples.append({"trace": labels, "verdict": v})
        except Exception as exc:
            out[direction] = {"status": f"log iteration failed: {exc}"}
            continue
        out[direction] = {"status": "ok", "verdicts": dict(verdicts), "rejected_examples": examples,
                          "caveat": "sampling, not a proof"}
    return out


# --------------------------------------------------------------- comparison
def assign_term(rep):
    if rep["status"] != "ok":
        return "conversion failed"
    if rep["missing_required"] or rep["witness_disagreements"]:
        return "lost"
    if not rep["exhaustive"]:
        return "ambiguous"
    if rep["extra_traces"]:
        return "approximated"
    if not rep["labels_identical"] or not rep["both_sound_wf"]:
        return "approximated"
    return "validated preserved"


def main():
    ART = build_artifacts()
    src = ART["nets"]["net_from_powl"]
    ok, fp_src = try_call(pm4py.discover_footprints, src["net"], src["im"], src["fm"])
    fp_src = fp_src if ok else None
    lang_src, st_src = explore_completed_language(src["net"], src["im"], src["fm"])
    wit_src = {n: admits_trace(src["net"], src["im"], src["fm"], t)
               for n, t in {**POSITIVE, **NEGATIVE}.items()}

    report = {"bound": {"MAX_VISIBLE": MAX_VISIBLE, "MAX_ITER": MAX_ITER,
                        "SILENT_STATES": SILENT_STATES, "ADMIT_STATES": ADMIT_STATES},
              "source": {"language_size": len(lang_src), "stats": st_src,
                         "soundness": src["diag"]["soundness"],
                         "is_workflow_net": src["diag"]["is_workflow_net"],
                         "witnesses": wit_src,
                         "reachability": reachability_fingerprint(src["net"], src["im"], src["fm"])},
              "comparisons": {}}

    # Source self-audit: the intended semantics must hold in the ORACLE itself.
    report["source"]["oracle_violations"] = {
        n: v for n, v in wit_src.items()
        if (n in POSITIVE and v != "admitted") or (n in NEGATIVE and v == "admitted")}

    for name, dst in ART["nets"].items():
        if name == "net_from_powl":
            continue
        rep = {"status": "ok", "pipeline": dst["pipeline"]}
        try:
            lang_dst, st_dst = explore_completed_language(dst["net"], dst["im"], dst["fm"])
            missing, extra = lang_src - lang_dst, lang_dst - lang_src
            rep.update({
                "derivative_language_size": len(lang_dst),
                "derivative_stats": st_dst,
                "missing_required": sorted(map(str, missing))[:50],
                "missing_count": len(missing),
                "extra_traces": sorted(map(str, extra))[:50],
                "extra_count": len(extra),
                "exhaustive": bool(st_src.get("exhaustive_under_bound")
                                   and st_dst.get("exhaustive_under_bound")),
                "labels_identical": label_multiset(src["net"]) == label_multiset(dst["net"]),
                "labels_source": dict(label_multiset(src["net"])),
                "labels_derivative": dict(label_multiset(dst["net"])),
                "soundness_source": src["diag"]["soundness"]["is_sound"],
                "soundness_derivative": dst["diag"]["soundness"]["is_sound"],
                "both_sound_wf": bool(src["diag"]["is_workflow_net"] and dst["diag"]["is_workflow_net"]
                                      and src["diag"]["soundness"]["is_sound"] is True
                                      and dst["diag"]["soundness"]["is_sound"] is True),
                "derivative_problems": dst["diag"]["problems"],
            })
            wit_dst = {n: admits_trace(dst["net"], dst["im"], dst["fm"], t)
                       for n, t in {**POSITIVE, **NEGATIVE}.items()}
            rep["witnesses_derivative"] = wit_dst
            rep["witness_disagreements"] = {n: {"source": wit_src[n], "derivative": wit_dst[n]}
                                            for n in wit_dst if wit_dst[n] != wit_src[n]}
            ok, fp_dst = try_call(pm4py.discover_footprints, dst["net"], dst["im"], dst["fm"])
            rep["footprint_diff"] = footprint_diff(fp_src, fp_dst) if (ok and fp_src) else "unavailable"
            rep["reachability_derivative"] = reachability_fingerprint(dst["net"], dst["im"], dst["fm"])
            rep["playout_crosscheck"] = playout_crosscheck(src, dst)
        except Exception as exc:
            rep = {"status": "error", "detail": f"{type(exc).__name__}: {exc}"}
        rep["term"] = assign_term(rep)
        rep["term_scope"] = ("bounded (visible<=%d, iterations<=%d), TRACE-level only; "
                             "not language equivalence, not bisimilarity" % (MAX_VISIBLE, MAX_ITER))
        report["comparisons"][name] = rep

    report["failures"] = ART["failures"]
    with open(f"{OUT_DIR}/roundtrip_validation_report.json", "w", encoding="utf-8") as fh:
        json.dump(report, fh, indent=2, default=str)

    print(f"source completed-trace count under bound: {len(lang_src)}; "
          f"exhaustive={st_src.get('exhaustive_under_bound')}")
    print("ORACLE violations of intended semantics:", report["source"]["oracle_violations"])
    for name, rep in report["comparisons"].items():
        print(f"{name:28s} -> {rep['term']}  "
              f"(missing={rep.get('missing_count')}, extra={rep.get('extra_count')}, "
              f"exhaustive={rep.get('exhaustive')})")
    return report


if __name__ == "__main__":
    main()
```

**Exhaustiveness statement.** Under `MAX_VISIBLE=16`, `MAX_ITER=3`, `SILENT_STATES=4000`, `ADMIT_STATES=60000`, the explored completed-trace sets are finite. The comparison is **exhaustive within that bound iff `exhaustive_under_bound` is `True` on both sides** (no silent-state, node, trace or admission budget was hit). It is **not** exhaustive over the source language, which is infinite because the loop is unbounded. Any budget hit forces `ambiguous`, never `validated preserved`. Note also the deliberate self-audit: if `net_from_powl` itself rejects W06/W09, the finding is a **stage-1** semantics gap (converter loop-body atomicity), not a BPMN problem — and it must be reported as such.

# 6. Visual-Semantics Review

A rendered BPMN can be behaviorally acceptable and still be systematically misread.

**Parallel gateways.** A `+` split/join pair reads as a *symmetric block*: "these two branches start together and end together". The source is asymmetric — `pred(L)={A}` but `pred(V)={A,P}`. A reader will infer either that legal review also needs Prepare Evidence, or that verification needs Legal Review. Both are false. Worse, if the renderer emits a `+` join fed directly by an XOR split for optional legal, the *skip* path deadlocks: the join waits forever for a token that the empty branch never sends. That is a real defect, not just a reading problem, and it is caught by the deadlock check plus W01.

**Exclusive gateways.** The XOR-with- is often drawn as a diamond with one labelled outgoing flow and one bare arrow. Readers see the bare arrow as an exception/error path, or overlook it and conclude Legal Review is mandatory. If the tool emits an *inclusive* (`O`) gateway instead, both branches may fire — two Legal Reviews, or a residual token. An `O` where an `×` is required is a semantic change with an identical label set.

**Loop visualization.** A BPMN loop marker on a single task cannot express a two-activity body (`Configure Trial  Inspect Trial`) with a `Correct Defect` separator. Readers may conclude that only Inspect Trial repeats, that Correct Defect is mandatory, or that zero iterations are allowed. Standard BPMN loop activity semantics is test-before-capable; the source is strictly do-while with at least one iteration. A gateway loop-back drawn as a plain arrow is equally ambiguous about the exit condition and about who decides.

**Silent routing nodes.**  transitions surface as unlabelled tasks, "none" tasks, or extra gateways. Business readers invent meaning for them ("Approval", "Wait for regulator") or delete them as noise, breaking routing. Conversely, a renderer that *drops*  nodes can silently delete the skip branch.

**Apparent ordering from layout.** Graphviz left-to-right/top-to-bottom placement is a layout artifact. Legal Review drawn above the trial block reads as "legal first"; Assess Risk drawn left of Prepare Evidence reads as a sequence; Correct Defect drawn after Inspect Trial reads as a mandatory closing step. None of these orders exists in the source.

**Ambiguity-reducing annotations to attach to every published BPMN:**

1. A legend stating: `+` = AND, `×` = XOR (exactly one), `O` = inclusive (**must not appear**), bare arrow from a `×` = silent skip (no activity, no event).
2. Text annotations carrying invariant IDs and cardinalities: `Legal Review 0..1 (I03)`, `Configure/Inspect 1..n (I07,I09)`, `Correct Defect 0..n1, only between iterations (I08)`, `Release: AND-join of legal-branch resolution and loop exit (I11)`.
3. Explicit "**no ordering constraint**" dashed associations between the legal branch and the verification block, and between Assess Risk and Prepare Evidence, labelled `I02 / I05 / I16`.
4. A loop annotation: "**do-while; body = Configure Trial  Inspect Trial; at least one iteration; repeat only via Correct Defect**".
5. Rename every silent node to ` routing (no business meaning)` and mark it non-removable.
6. A header block: "Non-normative rendering. Authoritative model: POWL `<hash>`, PM4Py `<version>`, pipeline P1, validation report `<hash>`, bound V=16/K=3, verdict `<term>`."
7. A one-page companion containing the §1 invariant table and the witness list, so reviewers can check the picture against the semantics rather than the reverse.

# 7. Rejection Criteria

Reject (or quarantine, with the reason recorded in the manifest) if **any** holds:

1. **Technical failure.** A conversion raises, returns `None`, returns an object of the wrong type, or returns a net without a usable `(im, fm)` pair.
2. **Null/empty markings.** `im` or `fm` is `None` or empty, so exact-final-marking and soundness tests cannot run. Never substitute an inferred marking silently.
3. **Not a workflow net.** `check_is_workflow_net` is `False` (multiple sources/sinks, nodes off any sourcesink path) without an explicitly approved justification.
4. **Unsoundness.** `check_soundness` reports improper completion, reachable deadlock  `fm`, livelock/-only trap, dead labelled transitions, or unboundedness; or `fm` still enables transitions.
5. **Loss of a required interleaving.** Any positive witness rejected — especially W02 (Prepare first), W03 (Legal before Prepare), W05/W06/W09 (Legal unordered with, or inside, the loop).
6. **Admission of forbidden behavior.** Any negative witness admitted — especially N02/N14 (release before verification completes), N03 (zero iterations), N06 (legal after release), N04/N05/N11 (broken loop separator/exit).
7. **Collapse of optionality.** Legal Review present in *every* completed trace (became mandatory) or in *none* (deleted), or the skip path deadlocks at the release join.
8. **Failed exact-final-marking test.** A run whose visible projection equals a source witness but ends in a marking  `fm` (residual tokens). "Looks right" is not acceptance.
9. **Label identity violation.** A duplicated or missing labelled transition, or label drift (case/whitespace/renaming). Do not normalize the mismatch away.
10. **Concurrency loss / spurious order.** The derivative's language satisfies an order the source lacks (`A<P`, `P<L`, `L<C`, atomic loop body). Footprint differences are a trigger for review, not by themselves proof.
11. **Non-exhaustive or inconclusive validation.** Any exploration budget exhausted, `check_soundness` inconclusive, or reachability-graph construction failing/aborting  `ambiguous`, quarantine rather than accept.
12. **Gateway/routing mismatch found in review.** Inclusive gateway where XOR is required; XOR-merge where AND-join is required; XOR-split feeding an AND-join without a merge; multiple start events; unreachable end event; silent routing node deleted.
13. **Tree intermediate accepted on trust.** A returned process tree with duplicated labels, or without a passing bounded-language + witness comparison, must never enter the publication path.
14. **Missing provenance.** Any derivative lacking source hash, PM4Py version, pipeline ID, bound parameters, exhaustiveness flag and validation report.
15. **Non-reproducibility.** Re-running the same pipeline under the same pinned version yields a different label multiset, witness verdict set, or bounded language.

# 8. Canonical Representation Recommendation

**Authoritative model: the source POWL (`source_powl`), stored as the versioned construction script plus a content hash.** It is the only artifact that states the absence of edges (I02, I04, I05, I16) without inventing structure. Every other artifact is regenerable from it. If the installed PM4Py exposes a POWL serializer, use it and pin the version; otherwise store the construction script and a pinned-environment lockfile — do not invent an export API.

**Semantic reference (derivative, but privileged): `net_from_powl` with its `(im, fm)`.** This is the executable oracle used by all tests. It is *regenerated, never hand-edited*, and stored with its diagnostics, hash and PM4Py version. If the oracle itself violates an intended invariant (e.g. rejects W06), that is a stage-1 finding to escalate, not a licence to edit the net.

**Stakeholder visualization: the P1 BPMN, only if gated in.** If P1 fails or the gate returns anything other than `validated preserved`, the stakeholder deliverable is the annotated POWL visualization plus the annotated Petri-net visualization (P4), and any BPMN is watermarked *illustrative, non-normative, not derived-faithful*.

**Derivative artifacts:** every BPMN, every process tree, every round-tripped net, every SVG, every reachability graph, every footprint object, every report. None may be edited into authority.

**Validation evidence that must accompany each derivative** (one manifest per artifact):

* source POWL hash + PM4Py version + pipeline ID + conversion status/traceback;
* `is_workflow_net`, normalized `check_soundness` diagnostics, `fm_is_dead`;
* label multiset and duplicate-label report; `im`/`fm` presence flags;
* bound parameters (V, K, silent/admission budgets) and the **exhaustiveness flag**;
* completed-trace counts, missing/extra trace lists, full witness verdict table (positive *and* negative);
* footprint diff (labelled as heuristic), reachability fingerprint (labelled as non-equivalence), playout cross-check (labelled as sampling);
* the assigned term **with its scope qualifier** ("bounded, trace-level");
* hash of the rendered SVG and of the annotation sheet.

**Process-tree intermediate: allowed only as a diagnostic probe.** It is expected to fail (§4 proof) and, if it ever succeeds, it may be used for visualization only after passing label-uniqueness, full witness and bounded-language checks. It must never be a mandatory hop in the canonical publication path, because block-structuredness is a property the source does not have.

**Avoiding round-trip drift on future edits:**

1. Edit **only** the POWL source. Never edit a BPMN and re-import it as the source; BPMNnettreeBPMN is a lossy loop and each pass can add structure.
2. Regenerate all derivatives in CI on every source change, under a pinned PM4Py version; compare the new witness verdict table and bounded language against the stored baseline.
3. Treat the witness set (§5) as executable regression tests. Any verdict change — including a *newly passing* test — requires human re-review, because it may signal a converter behaviour change.
4. Upgrade PM4Py only via a deliberate migration that re-runs the whole harness and re-signs the manifests.
5. Keep activity labels and invariant IDs stable; layout changes are cosmetic and must never be used to "fix" a semantic rejection.
6. Store the *reason* for every quarantine alongside the artifact so a later reader cannot mistake a rejected BPMN for an approved one.

# 9. Residual Uncertainty

Even if every test above passes, the following remain **unestablished**:

1. **Language equivalence.** Bounded trace-set equality at V=16 / K=3 says nothing about 4, 10 or 100 iterations. No induction, invariant or unbounded model checking was performed; the loop makes the language infinite.
2. **Branching-time equivalence.** Trace equivalence is strictly weaker than (weak/branching) bisimilarity. The *moment* at which the silent skip decision is taken, or at which the loop decides to exit versus redo, may differ; a derivative can be trace-equal while offering different intermediate choices and different deadlock potentials under commitment. No bisimulation checker was used.
3. **True concurrency / step semantics.** "May overlap" is not testable with interleaving traces. A derivative that sequentializes Assess Risk and Prepare Evidence, or makes the loop body atomic, can pass every witness except the specifically designed cross-boundary ones — and even those only test interleaving, not simultaneity, duration or resource contention.
4. **Faithfulness of the reference encoding.** That `convert_to_petri_net(source_powl)` implements the *intended* POWL semantics (do/redo loop, body atomicity, concurrency across the loop boundary) is an assumption about an implementation, not a proof. The §5 oracle self-audit can *detect* a mismatch but cannot decide whether the code or the prose is wrong.
5. **Self-consistency of the round trip.** BPMNnet uses PM4Py's own importer. A shared bug between exporter and importer is invisible: the round trip can be perfectly self-consistent and still not match what a real BPMN engine would execute (gateway token semantics, loop test-before/after, sub-process scoping, event handling).
6. **Soundness depth.** `check_soundness` results depend on the variant and on boundedness; a `True` may reflect a shallow or restricted analysis. Reachability-graph construction may abort or be truncated, and -divergence under fairness assumptions is not analysed.
7. **Rendering fidelity.** No automated check proves that gateway types, loop markers and silent nodes in the SVG mean what the net means. T8 is `not tested`; human misreading risk survives every passing test.
8. **Out-of-scope semantics.** Data, decision rules (when to skip legal, when to correct a defect), resources, durations, probabilities, costs and compliance constraints are absent from the source and cannot be validated by any behavioral test here.
9. **Identity under relabelling.** All comparisons assume exact label strings. A semantics-preserving rename, or a semantics-changing rename to an identical string in a different scope, is outside what these tests can distinguish.
