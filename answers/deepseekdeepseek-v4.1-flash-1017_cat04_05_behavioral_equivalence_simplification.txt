def exhaustive_bounded_visible_traces(net, im, fm, max_visible=12, max_a=3):
    start = (copy.deepcopy(im), (), 0)
    q = deque([start])
    visited = set()
    visited.add((msig(im), (), 0))
    complete = set()
    while q:
        marking, trace, a_count = q.popleft()
        if same_marking(marking, fm):
            complete.add(trace)
            # final marking is terminal in sound nets; do not expand beyond completion
            continue
        for t in pm4py.get_enabled_transitions(net, marking):
            lab = visible_label(t)

                visited.add(state)

def process_tree_stats(tree):
    labels = Counter()
    def rec(node, depth):
        nodes = 1
        max_depth = depth
        visible = silent = 0
        if getattr(node, "operator", None) is None:

# 1. Equivalence Notions

Let the visible alphabet be  
`O = Open Case`, `A = Analyze Revision`, `K = Check Revision`, `P = Approve Revision`, `R = Rework Case`, `C = Close Case`.

In exact visible traces, duplicate labels are distinguished by occurrence position in the sequence, not by a process-tree node identity. Thus `A K K A` is different from `K A K A`. Under P2, repeated `K` occurrences are deliberately collapsed.

**Visible trace equivalence after hiding `tau`.**  
For a model `M`, let `L_vis(M)` be the set of all finite visible sequences obtained by executing `M` from its initial marking to its final marking and deleting all silent `tau` transitions. Models A and B are visibly trace equivalent iff `L_vis(A) = L_vis(B)`.

**Bounded visible-language equivalence under P3.**  
With P3 bounds, compare only complete visible traces `w` such that:

- `len(w) <= 12`,
- number of `A` occurrences in `w` is at most `3`.

Define `L_P3(M) = { w in L_vis(M) | len(w) <= 12 and count_A(w) <= 3 }`.  
P3 equivalence means `L_P3(A) = L_P3(B)`. This is evidence only; it is not a proof of unbounded equivalence.

**Business-relevant equivalence under P1.**  
P1 retains the operational facts that matter for compliance: `R` separates analysis attempts; each attempt should have its own `K` before the next `R` or before `C`; optional `P` remains visible; repeated `K` occurrences are not collapsed. Under the stricter post-analysis reading of “its own Check Revision”, I interpret each attempt as requiring `A` before its associated `K`, with `P` optional after `K`. If the organization only requires “some check before the next R/Close”, then the order requirement is relaxed but the one-to-one per-attempt check requirement remains.

**Abstracted dashboard equivalence under P2.**  
For a complete trace `w`, define the P2 abstraction as:

`alpha_P2(w) = (count_A(w), any_K(w), any_R(w))`,

with `P` and `tau` hidden, `Open`/`Close` fixed as first/last, and `K` collapsed to a Boolean. P2 also requires at least one `A` and at least one `K`; both models always satisfy that on complete runs. Two models are P2-equivalent iff their sets of `alpha_P2(w)` values coincide.

# 2. Structural Comparison

| Feature | Model A | Model B | Semantic consequence |
|---|---|---|---|
| Loop scope | Loop is after `Open` and before `Close`. Each iteration contains parallel `A` and `K`, optional `P/tau`, then `R` as the loop separator. | One `K` is parallel with the entire revision loop. The loop contains `A`, optional `P/tau`, and `R` as separator. | A repeats checks with analyses; B has one global check for all analyses. |
| Minimum/maximum `Check Revision` occurrences | Minimum: `1`. Maximum: unbounded, exactly one `K` per loop iteration, hence one `K` per `A`. | Minimum: `1`. Maximum: exactly `1`, independent of the number of `A` attempts. | A can produce `n` analyses and `n` checks. B can produce `n` analyses and only one check. |
| Possible placement of `Check Revision` | Within each iteration it is concurrent with that iteration’s `A`; it may appear before or after that `A`, but before that iteration’s `P` and before the following `R` or `Close`. | Exactly once, anywhere interleaved with the whole revision loop: before first `A`, between `A` and `P`, between `P` and `R`, between iterations, or after the last `A/P`, but before `Close`. | B permits the single check after approval or after several analyses; A forces a check per analysis before approval/rework/close. |
| Optional approval occurrences | One optional `P` per iteration, after both `A` and `K` complete, before `R`/`Close`. | One optional `P` per analysis inside the loop, after `A`; because `K` is independent, `P` may occur before or after the single `K`. | Approval placement relative to `K` differs. Hidden `tau` allows no approval, but it cannot remove a check. |
| Concurrency | `A` and `K` are concurrent within each iteration. No concurrency across iterations. | `K` is concurrent with the entire revision loop. The loop itself is sequential. | A synchronizes each analysis with a check. B has one global check join before `Close`. |
| Join before `Close` | Each iteration’s parallel `A/K` must join before optional `P` and before `R`/exit. `Close` follows the final joined body. | The parallel join waits for both the single `K` and the entire loop to finish. No per-analysis join with `K` occurs. | A enforces per-analysis compliance; B only enforces that one check eventually occurs before close. |

# 5. Bounded Comparison Code

```python
import pm4py
import copy
from collections import deque

TREE_A = "->('Open Case', * (->( +('Analyze Revision', 'Check Revision'), X('Approve Revision', tau)), 'Rework Case'), 'Close Case')"
TREE_B = "->('Open Case', +('Check Revision', * (->('Analyze Revision', X('Approve Revision', tau)), 'Rework Case')), 'Close Case')"

tree_a = pm4py.parse_process_tree(TREE_A)
tree_b = pm4py.parse_process_tree(TREE_B)

net_a, im_a, fm_a = pm4py.convert_to_petri_net(tree_a)
net_b, im_b, fm_b = pm4py.convert_to_petri_net(tree_b)

print("Soundness A:", pm4py.check_soundness(net_a, im_a, fm_a, print_diagnostics=True))
print("Soundness B:", pm4py.check_soundness(net_b, im_b, fm_b, print_diagnostics=True))


def visible_label(transition):
    label = getattr(transition, "label", None)
    if label is None:
        return None
    s = str(label)
    if s == "" or s.lower() == "tau":
        return None
    return s


def fire_transition(net, marking, transition):
    # Preserve place objects; do not deepcopy keys.
    new_marking = marking.__class__(marking)
    for arc in transition.in_arcs:
        new_marking[arc.source] -= arc.weight
    for arc in transition.out_arcs:
        new_marking[arc.target] = new_marking.get(arc.target, 0) + arc.weight
    return new_marking


def marking_signature(marking):
    return tuple(sorted((id(p), int(c)) for p, c in marking.items() if c != 0))


def same_marking(m1, m2):
    return marking_signature(m1) == marking_signature(m2)


def exhaustive_bounded_visible_traces(net, im, fm, max_visible=12, max_a=3):
    """
    Exhaustive BFS over markings up to the visible-length and A-count bounds.
    Silent transitions are explored even when the visible bound has been reached.
    This is NOT random playout and NOT heuristic sampling.
    """
    q = deque()
    q.append((im, tuple(), 0))  # marking, visible trace, A-count
    visited = set()
    visited.add((marking_signature(im), tuple(), 0))
    complete = set()

    while q:
        marking, trace, a_count = q.popleft()

        if same_marking(marking, fm):
            complete.add(trace)
            # Final marking is terminal in a sound workflow net.
            continue

        for transition in pm4py.get_enabled_transitions(net, marking):
            label = visible_label(transition)
            next_trace = trace
            next_a_count = a_count

            if label is not None:
                if len(trace) + 1 > max_visible:
                    continue
                next_a_count = a_count + (1 if label == "Analyze Revision" else 0)
                if next_a_count > max_a:
                    continue
                next_trace = trace + (label,)

            next_marking = fire_transition(net, marking, transition)
            state = (marking_signature(next_marking), next_trace, next_a_count)

            if state not in visited:
                visited.add(state)
                q.append((next_marking, next_trace, next_a_count))

    return complete


traces_a = exhaustive_bounded_visible_traces(net_a, im_a, fm_a, max_visible=12, max_a=3)
traces_b = exhaustive_bounded_visible_traces(net_b, im_b, fm_b, max_visible=12, max_a=3)

unique_a = sorted(traces_a - traces_b, key=lambda t: (len(t), t))
unique_b = sorted(traces_b - traces_a, key=lambda t: (len(t), t))

print("\nExhaustive bounded BFS (not random playout).")
print("Bounded complete visible traces in A:", len(traces_a))
print("Bounded complete visible traces in B:", len(traces_b))

print("\nTraces unique to A within P3 bounds:")
for tr in unique_a:
    print("A-only:", " ".join(tr))

print("\nTraces unique to B within P3 bounds:")
for tr in unique_b:
    print("B-only:", " ".join(tr))
```

# 6. Stochastic and Footprint Comparison

`pm4py.discover_footprints(...)` can add local evidence: for example, Model B permits `P -> K` directly, as in `O A P K C`, while Model A requires `K` before the optional approval after the parallel join. Footprints can therefore expose local ordering differences. However, footprints summarize local pair relations and do not capture trace multiplicity, loop cardinality, or one-check-per-analysis obligations. Equal footprints would not establish trace equivalence.

# WARNING: This weighting is declared artificially over the exhaustively found
# bounded traces. It is NOT a probability model derived from the original trees.
def declared_bounded_language(traces, mass=lambda tr: 0.5 ** len(tr)):
    weights = {}

```python
from collections import Counter

def process_tree_stats(tree):
    labels = Counter()

    def rec(node, depth):
        nodes = 1
        max_depth = depth
        visible = 0
        silent = 0

        if getattr(node, "operator", None) is None:
            lab = getattr(node, "label", None)
            if lab is None or str(lab).lower() == "tau":
                silent = 1
            else:
                visible = 1
                labels[str(lab)] += 1
        else:
            for child in node.children:
                n2, d2, v2, s2 = rec(child, depth + 1)
                nodes += n2
                max_depth = max(max_depth, d2)
                visible += v2
                silent += s2

        return nodes, max_depth, visible, silent

    nodes, depth, visible, silent = rec(tree, 0)
    duplicate_labels = sum(1 for c in labels.values() if c > 1)
    duplicate_excess = sum(c - 1 for c in labels.values() if c > 1)

    return {
        "nodes": nodes,
        "depth_edges": depth,
        "visible_leaves": visible,
        "silent_leaves": silent,
        "duplicate_labels": duplicate_labels,
        "duplicate_excess": duplicate_excess,
        "label_counts": dict(labels),
    }

print("A stats:", process_tree_stats(tree_a))
print("B stats:", process_tree_stats(tree_b))

print("A Petri simplicity:", pm4py.simplicity_petri_net(net_a, im_a, fm_a))
print("B Petri simplicity:", pm4py.simplicity_petri_net(net_b, im_b, fm_b))
```

# 8. Simplified Model

I choose P1 as the most important operational target, because P2 hides exactly the per-analysis check multiplicity that is compliance-relevant. The simplified P1 model removes Model A’s parallel `A/K` ambiguity and enforces the stricter reading: each analysis is followed by its own check, then optional approval, with rework separating attempts.

```python
import pm4py

simplified_model = pm4py.parse_process_tree(
    "->('Open Case', * (->('Analyze Revision', 'Check Revision', X('Approve Revision', tau)), 'Rework Case'), 'Close Case')"
)

net_s, im_s, fm_s = pm4py.convert_to_petri_net(simplified_model)
print(pm4py.check_soundness(net_s, im_s, fm_s, print_diagnostics=True))
print("Simplified tree stats:", process_tree_stats(simplified_model))
print("Simplified Petri simplicity:", pm4py.simplicity_petri_net(net_s, im_s, fm_s))
```

**Structural comparison.** Model A has `12` nodes and depth `4`; Model B has `12` nodes and depth `5`; the simplified P1 model has `11` nodes and depth `4`. It removes one operator node relative to both originals, removes the global-parallel/check structure of B, and replaces A’s parallel `A/K` with the sequential sequence `A -> K -> X(P, tau)` inside each loop iteration.

| P1 property | Status in simplified model | Explanation |
|---|---|---|
| `Open` first and `Close` last | exact | Root sequence enforces this. |
| At least one attempt | exact | Loop executes its first child once, so one `A` and one `K` minimum. |
| Every `A` has its own `K` before next `R`/`C` | exact and strengthened | Body is `A, K, optional P`; `R` only occurs between bodies. |
| `Rework` separates attempts | exact | Binary loop appends `R` only before another body. |
| `P` optional and visible | exact | `X(P, tau)` after `K`; `tau` is hidden. |
| Number and placement of approvals visible | exact | One optional `P` per attempt, always after `K`. |
| Concurrency between `A` and `K` | weakened/removed | The original A allowed both orders; the simplification fixes `A` before `K`. |
| Traces with `K` before `A` | lost relative to Model A | Retained only if P1 regards them as compliant; under strict post-analysis compliance they are not needed. |
| One global check as in B | abstracted away/removed | B’s single global check is not P1-compliant for multiple analyses. |

**Regression traces for the simplified P1 model**

| Type | Trace | Expected | Reason |
|---|---|---:|---|
| Positive | `O A K C` | yes | One analysis, one check, no approval, close. |
| Positive | `O A K P C` | yes | One analysis, one check, approval, close. |
| Positive | `O A K R A K C` | yes | Two attempts, each checked before the next `R`/`C`. |
| Positive | `O A K P R A K P C` | yes | Two attempts, both checked and approved. |
| Negative | `O A R A K C` | no | First analysis is not checked before `R`. |
| Negative | `O A P K C` | no | Approval before check is impossible; check must precede approval. |
| Negative | `O K A C` | no | Check before analysis is not allowed in the simplified strict post-analysis P1 model. |

# 9. Final Recommendation

For P1, do not use Model B. It has only one `Check Revision` for the entire revision loop, so multiple analysis attempts are not individually checked. Model A is closer to P1 because it creates one `K` per loop iteration, but its parallel `A/K` placement permits `K` before `A`. If P1 means “check after each analysis,” use the simplified P1 model above instead of Model A. If concurrent pre-checking is genuinely intended, Model A may be retained, but that should be stated explicitly.

For P2, Models A and B are equivalent only after the dashboard abstraction collapses `K` occurrences and hides `P` and interleaving. For a dashboard-only implementation, an even smaller model is sufficient, e.g. `O K A (R A)* C`, which preserves the P2 facts `count_A`, `any_K`, and `any_R`. The simplified P1 model also preserves the P2 abstraction because it still has `K=true`, `count_A=n`, and `R` iff `n>1`.

For P3, compare the exact original models under the stated bound. The bounded visible languages are already different within `12` visible events and at most `3` analyses. Bounded comparison is useful as a regression test and for refutation, but it is not a proof of unbounded equivalence. Do not replace an original model with a simplified model for P3 testing unless the test target itself has intentionally been narrowed to that simplified semantics.
