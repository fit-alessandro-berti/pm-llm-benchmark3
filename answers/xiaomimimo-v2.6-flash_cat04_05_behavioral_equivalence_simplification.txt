Two visible traces are equal iff they have the same length and, at every position *i*, carry the same label. Duplicate visible labels are **distinguished by occurrence position** in the sequence, but **not by identity** (individual occurrences of the same label are interchangeable).

**Bounded visible-language equivalence (P3).** For the bound B = (max_visible_events  12, max_Analyze  3), two models are P3-equivalent iff their sets of complete visible traces satisfying both bounds are identical. Bounded non-equivalence **does** imply unbounded non-equivalence (a bounded counterexample is also an unbounded one); bounded equivalence alone, however, does **not** prove unbounded equivalence.

**Business-relevant equivalence under P1.** Two models are P1-equivalent iff, for every reachable execution state, the P1 observation is identical across both models. The P1 observation records: (a) whether every Analyze Revision is paired with its own Check Revision before the next Rework Case or before Close Case; (b) the number of Rework Cases separating analysis attempts; (c) the exact count and relative placement of visible Approve Revision occurrences. Duplicate Check Revision labels are **distinguished by their association with a specific analysis attempt** (i.e., by position relative to Analyze Revision and Rework).

**Abstracted dashboard equivalence under P2.** Two models are P2-equivalent iff their sets of P2 abstract observations are identical, where an abstract observation is the tuple (first\_event = Open Case, last\_event = Close Case, n\_Analyze  1, check\_occurred = true, any\_rework  {false, true}). Duplicate Check Revision labels are **collapsed to the Boolean `check_occurred`** and are *not* distinguished by count or position. Approve Revision and all silent behaviour are erased.

| Notion | Duplicate-label treatment |
|--------|--------------------------|
| Visible-trace (unbounded) | distinguished by position |
| P3 bounded | distinguished by position |
| P1 | distinguished by analysis-attempt association |
| P2 | collapsed to Boolean; *not* distinguished |

# 2. Structural Comparison

| Feature | Model A | Model B | Semantic consequence |
|---------|---------|---------|---------------------|
| Loop scope | `Parallel(A, C)` is the *first child* of the loop; the loop wraps both activities | `Loop` is one branch of `Parallel(C, Loop)`; C is *outside* the loop | A: every iteration contains one A **and** one C. B: C is detached from the iteration count. |
| Min Check Revision | 1 (n  1 iterations × 1 C each) | 1 (C in the parallel branch fires exactly once) | Both guarantee  1 C — satisfies P2's minimum. |
| Max Check Revision | Unbounded (grows with iterations) | **Exactly 1** (only one C activity in the parallel branch) | For n  2 iterations A produces n C's; B produces only 1. This is the decisive difference. |
| C placement (visible) | Within each iteration: C interleaves with A (AC or CA), both before Xor(App, ) | Any position interleaved with the *entire* loop (before first A, between loop activities, or after last App) | B permits C after App or between iterations; A does not. |
| Optional approval | `Xor(App, )` inside each loop first-child | `Xor(App, )` inside each loop first-child | Identical approval semantics in both models. |
| Concurrency | A and C interleave within each iteration (intra-iteration) | C and the entire loop interleave (global) | A: C is tightly coupled to A. B: C has no structural coupling to A. |
| Join before Close Case | No external parallel spans Close — Loop exits normally, then Close fires | `Parallel(C, Loop)` must **join** (both branches complete) before Close fires | In B, Close waits for C to finish; in A, Close waits only for the loop. |
| Trace language containment | Not a subset of B (A can produce n  2 C's) | Not a subset of A (B can place C after App, and for n  2 produces mismatched A/C counts) | Languages are incomparable — neither  the other. |

# 5. Bounded Comparison Code

The following is **self-contained Python** using exhaustive breadth-first exploration (not random play-out).

```python
"""
Bounded visible-language comparison under P3 bounds.
Method: exhaustive BFS over (marking, visible-trace) pairs.
This is NOT random or heuristic play-out; every reachable state
under the bounds is systematically visited.
"""
import pm4py
from collections import deque

# ------------------------------------------------------------------
# 1. Parse both process trees
# ------------------------------------------------------------------
TREE_A_STR = """
->('Open Case',
   *(
     ->(+('Analyze Revision','Check Revision'),
        X('Approve Revision', tau)),
     'Rework Case'),
   'Close Case')
"""

TREE_B_STR = """
->('Open Case',
   +('Check Revision',
     *(
       ->('Analyze Revision',
          X('Approve Revision', tau)),
       'Rework Case')),
   'Close Case')
"""

tree_a = pm4py.parse_process_tree(TREE_A_STR)
tree_b = pm4py.parse_process_tree(TREE_B_STR)

# ------------------------------------------------------------------
# 2. Convert to accepting Petri nets
# ------------------------------------------------------------------
net_a, im_a, fm_a = pm4py.convert_to_petri_net(tree_a)
net_b, im_b, fm_b = pm4py.convert_to_petri_net(tree_b)

# ------------------------------------------------------------------
# 3. Check soundness
# ------------------------------------------------------------------
print("=== Soundness ===")
print("Model A:", pm4py.check_soundness(net_a, im_a, fm_a, print_diagnostics=True))
print("Model B:", pm4py.check_soundness(net_b, im_b, fm_b, print_diagnostics=True))

# ------------------------------------------------------------------
# 4. Exhaustive bounded visible-language enumeration (BFS)
#    - silent transitions: label is None  hidden (not added to trace)
#    - repeated markings: visited set keyed on (marking_key, trace)
#    - visible-length bound: skip if len(trace) > max_visible
#    - analyze-count bound: skip if count > max_analyze
#    - final-marking equality: compare non-zero token distribution
# ------------------------------------------------------------------
def exhaustive_bounded_visible_traces(net, im, fm,
                                      max_visible=12, max_analyze=3):
    """
    Returns (set_of_traces, explored_state_count).

    EXHAUSTIVE: every reachable (marking, trace) pair under the
    bounds is visited exactly once via BFS.
    """
    # Map each place to an integer index for hashable keys
    place_idx = {p: i for i, p in enumerate(net.places)}

    def mark_key(mk):
        """Hashable key for a marking (only positive-token places)."""
        return frozenset((place_idx[p], c)
                         for p, c in mk.items() if c > 0)

    def fire(mk, trans):
        """Return new marking after firing an enabled transition."""
        result = mk.copy()
        for arc in trans.in_arcs:          # consume from pre-places
            result[arc.source] = result.get(arc.source, 0) - 1
            if result[arc.source] <= 0:
                del result[arc.source]
        for arc in trans.out_arcs:         # produce into post-places
            result[arc.target] = result.get(arc.target, 0) + 1
        return result

    fm_key = mark_key(fm)
    results = set()        # set of visible-trace tuples that reach fm
    visited = set()        # set of (marking_key, visible_trace)
    queue = deque()
    explored = 0

    init_state = (mark_key(im), ())
    queue.append((im, ()))
    visited.add(init_state)

    while queue:
        mk, trace = queue.popleft()
        explored += 1

        # Final-marking equality check
        if mark_key(mk) == fm_key:
            results.add(trace)
            continue

        # Explore all enabled transitions (visible and silent)
        for trans in pm4py.get_enabled_transitions(net, mk):
            new_mk = fire(mk, trans)

            # Silent transitions (tau / label is None) are hidden
            if trans.label is not None and trans.label != '':
                new_trace = trace + (trans.label,)
            else:
                new_trace = trace          # tau: no visible event added

            # --- Bound checks (P3) ---
            if len(new_trace) > max_visible:
                continue
            if new_trace.count('Analyze Revision') > max_analyze:
                continue

            state = (mark_key(new_mk), new_trace)
            if state not in visited:
                visited.add(state)
                queue.append((new_mk, new_trace))

    return results, explored

# ------------------------------------------------------------------
# 5. Derive bounded visible trace sets
# ------------------------------------------------------------------
P3_MAX_VIS = 12
P3_MAX_ANA = 3

print("\n=== Exhaustive BFS (not random play-out) ===")
traces_a, states_a = exhaustive_bounded_visible_traces(
    net_a, im_a, fm_a, P3_MAX_VIS, P3_MAX_ANA)
traces_b, states_b = exhaustive_bounded_visible_traces(
    net_b, im_b, fm_b, P3_MAX_VIS, P3_MAX_ANA)

# ------------------------------------------------------------------
# 6. Compare and print traces unique to each model
# ------------------------------------------------------------------
only_a = traces_a - traces_b
only_b = traces_b - traces_a
common = traces_a & traces_b

print(f"\nModel A bounded traces: {len(traces_a)}  "
      f"(states explored: {states_a})")
print(f"Model B bounded traces: {len(traces_b)}  "
      f"(states explored: {states_b})")
print(f"Common:                {len(common)}")
print(f"Only in Model A:       {len(only_a)}")
print(f"Only in Model B:       {len(only_b)}")

print("\n--- Traces only in Model A ---")
for t in sorted(only_a, key=lambda x: (len(x), x)):
    print("  " + "  ".join(t))

print("\n--- Traces only in Model B ---")
for t in sorted(only_b, key=lambda x: (len(x), x)):
    print("  " + "  ".join(t))

# ------------------------------------------------------------------
# 7. Explicit statement: this is EXHAUSTIVE, not random
# ------------------------------------------------------------------
print("\n[EXPLORATION METHOD] "
      "Breadth-first search over every reachable (marking, trace) "
      "state under P3 bounds. NOT pm4py.play_out() — play_out() "
      "generates random/heuristic traces and does NOT guarantee "
      "that all bounded traces are discovered.")
```

> **Why not `pm4py.play_out`?** `play_out` repeatedly fires random enabled transitions to generate sample traces. It does **not** enumerate the full set of traces reachable under a given bound; it may silently miss counterexamples. The BFS above guarantees every reachable state (and therefore every bounded complete trace) is visited exactly once.

# 6. Stochastic and Footprint Comparison

### Footprints

```python
fp_a = pm4py.discover_footprints(tree_a)
fp_b = pm4py.discover_footprints(tree_b)

print("=== Footprint differences ===")
for key in sorted(set(fp_a.keys()) | set(fp_b.keys())):
    fa = fp_a.get(key, frozenset())
    fb = fp_b.get(key, frozenset())
    if fa != fb:
        print(f"\n'{key}':")
        only_a = fa - fb
        only_b = fb - fa
        if only_a:
            print(f"  only in A: {only_a}")
        if only_b:
            print(f"  only in B: {only_b}")
```

Expected differences include the *succession* relation `(Approve Revision, Check Revision)` (or `(Approve Revision, Check Revision)` via hidden ): Model B admits a trace where `App` directly precedes `C` (e.g., `A, App, C`), while Model A never produces this order because `C` always fires before `App` within the same iteration.

**Why equal footprints would not establish trace equivalence.** Footprints capture only *pairwise/pattern* relations (start, end, succession, predecessor, alternate-precedence, …). Two models can have identical pairwise relations while differing in how activities combine into longer sequences. For example, if both models had the same direct-succession pairs but differed in whether three-activity subsequences can repeat, the footprints would be equal but the trace languages would differ.

### Stochastic language and EMD

```python
# PM4PY API reminder (requires explicit probability declaration):
# pm4py.get_stochastic_language(...)
# pm4py.compute_emd(lang1, lang2)

# NO probabilities are assigned here because the problem states:
# "Do not invent transition probabilities without declaring them."
#
# If business-revided probabilities were declared (e.g., uniform over
# enabled transitions), one would do:
#
# stoch_params = {"declared_probability_model": "uniform_over_enabled"}
# stoch_a = <convert net_a to stochastic net using declared probabilities>
# lang_a  = pm4py.get_stochastic_language(stoch_a)
# lang_b  = pm4py.get_stochastic_language(stoch_b)
# emd     = pm4py.compute_emd(lang_a, lang_b)
```

- **`pm4py.get_stochastic_language`** requires a *stochastic* Petri net (each transition carries a firing probability or rate). Without declared probabilities, the API is not applicable.
- **`pm4py.compute_emd`** computes the Earth Mover's Distance between two *probability distributions over traces*. A **low EMD** means the distributions are close in the underlying trace-metric space — but the supports (actual trace sets) can be **disjoint**. Two models could produce completely different trace sets whose individual traces are short edit-distance apart, yielding a low EMD while being maximally different as trace languages. Conversely, a stochastic language assigns zero probability to infinitely many traces, so equal stochastic languages under one probability assignment do not prove equality of the full trace sets.

**Structural pseudocode for counts:**

```python
def tree_metrics(tree):
    """Compute node counts, depth, leaf breakdown from a pm4py ProcessTree."""
    nodes = 0; ops = 0; vis = 0; sil = 0; max_depth = 0
    labels = []

    def walk(node, depth):
        nonlocal nodes, ops, vis, sil, max_depth
        nodes += 1
        max_depth = max(max_depth, depth)
        if node.operator is None:          # leaf
            if node.label and node.label != 'tau':
                vis += 1
                labels.append(node.label)
            else:
                sil += 1
        else:                               # operator
            ops += 1
            for child in node.children:
                walk(child, depth + 1)

    walk(tree, 0)
    dupes = len(labels) - len(set(labels))
    return {"nodes": nodes, "operators": ops,
            "visible_leaves": vis, "silent_leaves": sil,
            "depth": max_depth, "duplicate_labels": dupes}
```

# 8. Simplified Model

**Target business purpose: P1 (operational compliance).** P1 is the most safety-critical view — it enforces that every analysis attempt is independently checked. P2 can be derived from P1 by applying P2's abstractions. P3 bounded equivalence cannot be preserved by *any* simplification that reduces nondeterminism (see §9).

## 8.1 Process-tree expression

The simplification replaces `Parallel(A, C)` with `Sequence(A, C)` inside the loop, forcing a deterministic AC order while preserving the per-iteration pairing:

```text
->(
  'Open Case',
  *(
    ->(
      'Analyze Revision',
      'Check Revision',
      X('Approve Revision', tau)
    ),
    'Rework Case'
  ),
  'Close Case'
)
```

## 8.2 PM4Py code

SIMPLIFIED_STR = """

        'Check Revision',

simplified_model = pm4py.parse_process_tree(SIMPLIFIED_STR)
net_s, im_s, fm_s = pm4py.convert_to_petri_net(simplified_model)

# 9. Final Recommendation

| Business view | Recommended model | Rationale |
|---------------|-------------------|-----------|
| **P1** (operational compliance) | **Model A** (or the simplified model in §8) | Only Model A structurally guarantees a 1-to-1 A/C pairing per iteration. Model B fails P1 for any execution with  2 analysis attempts. |
| **P2** (executive dashboard) | **Either model** (or simplified model) | Under P2's abstractions (CBoolean, hide App, ignore A/C interleaving), all three models produce identical abstract observations. |
| **P3** (bounded testing) | **Neither is preferred** | Models A and B are *not* equivalent under any P3 bound — bounded counterexamples exist. Choose the model whose *unbounded* behaviour matches the real process, then test against it. |

**Should the simplified model replace either original?**
- **Yes, replace Model A for P1.** The simplified model has fewer nodes (11 vs 12), fewer operators (4 vs 5), preserves all P1 properties exactly (and strengthens the AC ordering), and preserves P2 abstract observations exactly.
- **No, do not use the simplified model as a replacement for Model B** — the simplified model does not model the global-concurrency behaviour of B (C detached from iterations), which may be the correct semantics for some deployments.
- **No, the simplified model cannot replace both under P3** — it loses the parallel-interleaving traces of Model A *and* the concurrent-C traces of Model B. **A single simplification cannot preserve all three views simultaneously.**

>  **Warning about bounded comparison.** The P3 counterexamples in §4 prove non-equivalence *within* the bound, which by contrapositive implies non-equivalence in the unbounded case as well. However, the *absence* of bounded counterexamples would **not** prove unbounded equivalence — two models can agree on all traces up to any fixed bound and diverge beyond it. Bounded exploration is therefore one-directional evidence: it can *refute* equivalence, but it cannot *confirm* it.
