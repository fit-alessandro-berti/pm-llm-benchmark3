## 1. Feasibility model
### Partial-order relations
```
{
  Register  Triage,
  Triage  (Identity Check  Document Check),
  Identity Check  (Document Check  Assessment),
  Document Check  Assessment,
  Assessment  (Compliance Review  Request More Info),
  Request More Info  (Document Check  Assessment),
  Compliance Review  Decision,
  Decision  Notify,
  (Identity Check  Document Check)  Assessment (if no originals),
  Originals Receipt  Document Check (if required),
  Compliance Review  Decision (high-risk/high-value),
  Escalation Advice  Compliance Review (if triggered)
}
```

### Constraints
**Declarative:**
1. `Register` must precede `Triage`.
2. `Identity Check` and `Document Check` must complete before `Assessment` unless `Originals Receipt` precedes `Document Check`.
3. `Compliance Review` must follow the latest `Assessment` for high-risk/high-value cases.
4. A single resource cannot perform both final `Assessment` and final `Compliance Review`.
5. `Decision` must precede `Notify`.
6. `Request More Info` triggers a new `Document Check` and `Assessment` cycle.

**Conditional:**
- If `Originals Receipt` is required, `Originals Receipt` must precede `Document Check`.
- If `Request More Info` is issued, a new `Compliance Review` is required for high-risk/high-value cases.
- `Escalation Advice` may trigger a preliminary compliance review but does not replace the final compliance review.

**Temporal:**
- Service times are probabilistic (e.g., `Identity Check` ranges 1.5–3.5 h).
- Queue estimates are forecasts; actual completion depends on external response.

**Intervention effects:**
- **K-104:** Changes routing (preliminary escalation + compliance reservation) and timing (parallel partial compliance).
- **K-219:** Changes routing (D2 instead of D1) and may alter rework probability.
- **K-337:** Changes decision policy (no second `Request More Info` loop) and timing (fewer iterations).
- **K-411:** Changes concurrency (parallel `Identity Check` and `Document Check`) and logging requirements.

### Weekly rollout analysis (100 cases)
Applying K-104, K-219, or K-411 to 100 similar cases would create systemic interference:
- **K-104:** Reserving C1 capacity for high-risk cases would delay 20–30% of urgent compliance cases, creating a bottleneck shift. Parallel partial compliance may reduce wait times but risks overloading S1 (escalation adviser) if packets are incomplete.
- **K-219:** Substituting D2 for D1 would reduce D1 queue but increase D2 queue by 30–50%. If D2 is slower, the assessment queue would grow, offsetting cycle-time gains. External supplier responses (e.g., handwritten docs) may require rework, increasing variability.
- **K-337:** Eliminating rework loops would reduce cycle time by 12–36 h but increase appeal risk and compliance exposure. High-risk cases may face stricter scrutiny, delaying decisions.
- **K-411:** Parallelizing verification would reduce cycle time by 4–12 h but risk assessment queue congestion. If D2 is faster, the benefit is realized; if not, the queue grows, negating gains.

**Key nonlinearities:**
- **Compliance capacity (C1):** A single C1 reviewer is critical. Reserving capacity for high-risk cases (K-104) would delay 20–30% of other cases, creating a cascading effect.
- **Assessment queue (A1/A2):** Parallelizing checks (K-411) may reduce wait times but if D2 is slower, the queue grows, offsetting benefits.
- **External response (K-337):** Rework loops depend on supplier responses. Eliminating them (K-337) may reduce cycle time but increase appeal risk.
- **D2 substitution (K-219):** D2 is slower and may request rework, increasing variability and assessment queue pressure.

**Weekend and external-response effects:**
- K-337’s intervention would reduce rework loops but may delay weekend supplier responses, increasing cycle time variability.
- K-219’s D2 substitution would benefit standard cases but may worsen weekend handwritten document responses, requiring rework.

**Timestamp behavior vs. true concurrency:**
- K-411’s workaround requires real-time logging. If timestamps are not accurate, false concurrency may delay cases, negating benefits.

## 8. Assumption audit

3. **Resource:** C1 is the only fully certified compliance reviewer in the window; D2 is slower than D1.

8. **Behavioral:** The four-eyes rule (same person cannot perform both final `Assessment` and `Compliance Review`).
