# 1. Assumptions and notation

### Operational notation
- Let $k \in \{\text{P01}, \dots, \text{P22}\}$ index cases and $j \in \{1, 2\}$ index stations $\text{S1}$ (Incoming Inspection) and $\text{S2}$ (Calibration).
- Observation window: $[T_0, T_{\text{end}}] = [\text{08:00}, \text{14:00}]$ on 2026-05-12, with total duration $L = 360\text{ min}$.
- For each case $k$:
  - $A_{k,1}$ = external arrival timestamp at $\text{S1}$ (`arrival_s1`).
  - $S_{k,1}, E_{k,1}$ = start and completion timestamps at $\text{S1}$, executed by resource $R_{k,1} \in \{\text{I1}, \text{I2}\}$.
  - $A_{k,2} = E_{k,1}$ = queue entry timestamp at $\text{S2}$ (per the prompt rule that a case enters the $\text{S2}$ queue upon $\text{S1}$ completion).
  - $S_{k,2}, E_{k,2}$ = start and completion timestamps at $\text{S2}$, executed by resource $R_{k,2} \in \{\text{C1}, \text{C2}\}$.

### Explicit assumptions
- **A1 (Rounding interval model):** Every reported nominal timestamp $t$ represents an underlying continuous timestamp $t^{\text{true}} \in [t - 2.5\text{ min}, t + 2.5\text{ min}]$. Consequently, the difference between two rounded timestamps $t_2 - t_1$ has a nominal value $\Delta t = t_2 - t_1$ and a continuous rounding uncertainty bound of $[\max(0, \Delta t - 5\text{ min}), \Delta t + 5\text{ min}]$.
- **A2 (Simultaneous event-order and cadence convention):** In discrete 5-minute grid evaluations (cadence $t \in \{08:00, 08:05, \dots, 14:00\}$), state transitions at timestamp $t$ follow right-continuous (`cadlag`) semantics: completions ($E_{k,j}=t$) exit service, starts ($S_{k,j}=t$) exit queue and enter service, and arrivals ($A_{k,j}=t$) enter queue *at* $t$. Notice that for $\text{P09}$ at $\text{S2}$, $E_{\text{P07},2} = 11:00$ and $S_{\text{P09},2} = 11:00$ on resource $\text{C1}$; under A1 and A2 this represents an immediate handover within the $[10:57.5, 11:02.5]$ rounding window rather than a true resource conflict.
- **A3 (Single-task resource & non-overlapping constraints for `MISSING` starts):** A resource can process at most one case at any instant. When $S_{k,j}$ is `MISSING`, its feasible nominal 5-minute grid interval $[S_{k,j}^{\min}, S_{k,j}^{\max}]$ is bounded below by $\max(A_{k,j}, E_{\text{prev}(k, R_{k,j}), j})$, where $\text{prev}(k, R_{k,j})$ is the immediately preceding case on the same resource $R_{k,j}$.
- **A4 (Domain minimum service-time bound vs. strict mathematical upper start bound):** Across all 18 fully observed $\text{S1}$ services, nominal service time is strictly $25$ or $30\text{ min}$. Across all 12 fully observed $\text{S2}$ services, nominal service time is strictly $25$ to $50\text{ min}$ ($25\text{ min}$ for $\text{P10}$, $30\text{ min}$ for $\text{P01}$, $40\text{--}50\text{ min}$ for all others). Therefore, when $S_{k,j}$ is `MISSING`, we distinguish:
  - *Strict mathematical start upper bound* ($S_{k,j}^{\text{math\_max}}$): $E_{k,j} - 5\text{ min}$ on the 5-minute grid (or $E_{k,j}$ continuously, assuming nonnegative service $V_{k,j} \ge 0$).
  - *Domain-constrained plausible start upper bound* ($S_{k,j}^{\text{plaus\_max}}$): $E_{k,j} - 25\text{ min}$, reflecting the minimum observed station service time of $25\text{ min}$.
  - *Central (midpoint/handover) imputation* ($S_{k,j}^{\text{central}}$): Since fully observed resource transitions during queued periods consistently show a $5\text{ min}$ nominal handover gap between $E_{\text{prev}}$ and $S_{\text{curr}}$ (15 out of 15 observed queued transitions at $\text{S1}$, and 9 out of 10 at $\text{S2}$), we set $S_{k,j}^{\text{central}} = \max(A_{k,j}, E_{\text{prev}(k, R_{k,j}), j}) + 5\text{ min}$.
- **A5 (Right-censoring at $T_{\text{end}} = 14:00$):** For cases in state `OPEN` (`P15`, `P17`, `P21`) or `WAITING` (`P16`, `P18`, `P19`, `P20`, `P22`) at $14:00$, we compute *elapsed* waiting or service time up to $14:00$ as a strict lower bound on their eventual completed duration, and keep them separate from completed-case service means to prevent downward right-censoring bias.
- **A6 (C2 maintenance outage semantics):** $\text{C2}$ is unavailable during $[10:55, 11:10]$ ($15\text{ min}$ nominal). We report both *scheduled utilization* (denominator = $360\text{ min}$ per resource) and *available utilization* (denominator = $360 - 15 = 345\text{ min}$ for $\text{C2}$, $705\text{ min}$ total for $\text{S2}$).

# 2. Reconstruction method and formulas

### Case-level time definitions
For each case $k$ and station $j \in \{1, 2\}$:
1. **Queue waiting time ($W_{k,j}$):**
   - If started by $14:00$: $W_{k,j} = S_{k,j} - A_{k,j}$.
   - If waiting at $14:00$ (right-censored wait): $W_{k,j}^{\text{elapsed}}(14:00) = 14:00 - A_{k,j}$, with true wait $W_{k,j} > W_{k,j}^{\text{elapsed}}(14:00)$.
2. **Active service time ($V_{k,j}$):**
   - If completed by $14:00$: $V_{k,j} = E_{k,j} - S_{k,j}$.
   - If `OPEN` at $14:00$ (right-censored service): $V_{k,j}^{\text{elapsed}}(14:00) = 14:00 - S_{k,j}$, with true service $V_{k,j} > V_{k,j}^{\text{elapsed}}(14:00)$.
3. **Station sojourn time ($Z_{k,j}$):**
   - For completed station visits: $Z_{k,j} = W_{k,j} + V_{k,j} = E_{k,j} - A_{k,j}$.
   - Crucially, $Z_{k,j}$ is **invariant to `MISSING` start timestamps** ($S_{k,j}$) whenever both $A_{k,j}$ and $E_{k,j}$ are known! Thus, $Z_{\text{P07},1}$, $Z_{\text{P15},1}$, $Z_{\text{P05},2}$, and $Z_{\text{P11},2}$ are exactly known on the nominal grid despite missing start times.
4. **Total case sojourn time ($Z_k^{\text{total}}$):**
   - For cases completing $\text{S2}$ by $14:00$ (`P01`–`P14`):
     $$Z_k^{\text{total}} = E_{k,2} - A_{k,1} = Z_{k,1} + Z_{k,2}$$
     Because $A_{k,2} = E_{k,1}$, total sojourn time is the exact sum of $\text{S1}$ and $\text{S2}$ sojourn times and is completely unaffected by the `MISSING` intermediate timestamps in `P05`, `P07`, and `P11`.

### Bounds for `MISSING` start cases (`P05`, `P07`, `P11`, `P15`)
Using A3 and A4, we derive exact nominal bounds for the four missing starts:
- **`P07` at $\text{S1}$ ($\text{I1}$, $A_{\text{P07},1}=08:45$, $E_{\text{P07},1}=10:00$):**
  - Prior case on $\text{I1}$ is $\text{P05}$ ($E_{\text{P05},1} = 09:25$). Thus $S_{\text{P07},1}^{\min} = \max(08:45, 09:25) = 09:25$.
  - Plausible upper bound (A4, $V \ge 25$): $S_{\text{P07},1}^{\text{plaus\_max}} = 10:00 - 0:25 = 09:35$. (Strict math max: $09:55$).
  - Central estimate (5-min handover): $S_{\text{P07},1}^{\text{central}} = 09:30 \implies W_{\text{P07},1}=45\text{ min}, V_{\text{P07},1}=30\text{ min}$.
- **`P15` at $\text{S1}$ ($\text{I1}$, $A_{\text{P15},1}=10:10$, $E_{\text{P15},1}=12:15$):**
  - Prior case on $\text{I1}$ is $\text{P13}$ ($E_{\text{P13},1} = 11:40$). Thus $S_{\text{P15},1}^{\min} = \max(10:10, 11:40) = 11:40$.
  - Plausible upper bound ($V \ge 25$): $S_{\text{P15},1}^{\text{plaus\_max}} = 12:15 - 0:25 = 11:50$. (Strict math max: $12:10$).
  - Central estimate: $S_{\text{P15},1}^{\text{central}} = 11:45 \implies W_{\text{P15},1}=95\text{ min}, V_{\text{P15},1}=30\text{ min}$.
- **`P05` at $\text{S2}$ ($\text{C1}$, $A_{\text{P05},2}=E_{\text{P05},1}=09:25$, $E_{\text{P05},2}=10:15$):**
  - Prior case on $\text{C1}$ is $\text{P03}$ ($E_{\text{P03},2} = 09:45$). Thus $S_{\text{P05},2}^{\min} = \max(09:25, 09:45) = 09:45$.
  - Plausible upper bound ($V \ge 25$): $S_{\text{P05},2}^{\text{plaus\_max}} = 10:15 - 0:25 = 09:50$. (Strict math max: $10:10$).
  - Central estimate: $S_{\text{P05},2}^{\text{central}} = 09:50 \implies W_{\text{P05},2}=25\text{ min}, V_{\text{P05},2}=25\text{ min}$ (or $S=09:45 \implies W=20, V=30$).
- **`P11` at $\text{S2}$ ($\text{C2}$, $A_{\text{P11},2}=E_{\text{P11},1}=11:05$, $E_{\text{P11},2}=12:25$):**
  - Prior case on $\text{C2}$ is $\text{P08}$ ($E_{\text{P08},2} = 12:00$). Notice that although $\text{P11}$ entered the $\text{S2}$ queue at $11:05$ (during the $\text{C2}$ outage $[10:55, 11:10]$), $\text{P08}$ (which arrived at $\text{S2}$ at $10:20$) took $\text{C2}$ at $11:15$ and held it until $12:00$.
  - Thus $S_{\text{P11},2}^{\min} = \max(11:05, 12:00) = 12:00$.
  - Plausible upper bound ($V \ge 25$): $S_{\text{P11},2}^{\text{plaus\_max}} = 12:25 - 0:25 = 12:00$.
  - Remarkably, the single-task constraint ($S \ge 12:00$) and the minimum observed service duration ($V \ge 25 \implies S \le 12:00$) **pinpoint $S_{\text{P11},2} = 12:00$ on the nominal grid**! Even under a 5-minute handover ($S = 12:05$), $V_{\text{P11},2} = 20\text{ min}$ (plausible given rounding). We evaluate $S_{\text{P11},2} \in [12:00, 12:05]$ for central/plausible ranges and $[12:00, 12:20]$ for strict mathematical bounds.

### Queue length, WIP, throughput, utilization, and Little's Law
- **Indicator processes at time $t \in [T_0, T_{\text{end}}]$:**
  - In-queue indicator: $I_{k,j}^Q(t) = \mathbb{I}(A_{k,j} \le t < S_{k,j})$.
  - In-service indicator: $I_{k,j}^S(t) = \mathbb{I}(S_{k,j} \le t < E_{k,j})$.
  - Queue length: $Q_j(t) = \sum_k I_{k,j}^Q(t)$; Active service count: $B_j(t) = \sum_k I_{k,j}^S(t)$; Station WIP: $\text{WIP}_j(t) = Q_j(t) + B_j(t)$.
  - Total system WIP: $\text{WIP}_{\text{tot}}(t) = \text{WIP}_1(t) + \text{WIP}_2(t)$. Notice that because $A_{k,2} = E_{k,1}$, $\text{WIP}_{\text{tot}}(t) = \sum_k \mathbb{I}(A_{k,1} \le t < E_{k,2})$ depends **only** on $A_{k,1}$ and $E_{k,2}$ and is 100% invariant to all `MISSING` timestamps! Similarly, $\text{WIP}_1(t)$ and $\text{WIP}_2(t)$ depend only on $A_{k,j}$ and $E_{k,j}$, so **station-level WIP is also 100% invariant to `MISSING` start timestamps**; missing starts only affect the internal split between $Q_j(t)$ and $B_j(t)$.
- **Time-average metrics over subperiod $[t_a, t_b]$ of length $\Delta T = t_b - t_a$:**
  - Mean queue length: $\overline{Q}_j = \frac{1}{\Delta T}\int_{t_a}^{t_b} Q_j(t)\,dt = \frac{1}{\Delta T}\sum_k \max(0, \min(S_{k,j}, t_b) - \max(A_{k,j}, t_a))$.
  - Mean active service (busy resources): $\overline{B}_j = \frac{1}{\Delta T}\int_{t_a}^{t_b} B_j(t)\,dt = \frac{1}{\Delta T}\sum_k \max(0, \min(E_{k,j}, t_b) - \max(S_{k,j}, t_a))$.
  - Resource utilization for resource $r$ with available capacity $C_r^{\text{avail}}([t_a, t_b])$:
    $$U_r = \frac{\text{BusyTime}_r([t_a, t_b])}{C_r^{\text{avail}}([t_a, t_b])}$$
    where $\text{BusyTime}_r$ includes **both completed and `OPEN` services** inside $[t_a, t_b]$.
- **Little's Law consistency check ($L = \lambda W$):**
  - Over any bounded window $[t_a, t_b]$, the exact deterministic sample-path identity (total time accumulated in state divided by window length) is $\overline{\text{WIP}}_j = \frac{\sum_k Z_{k,j}^{\text{in-window}}}{\Delta T}$.
  - Standard Little's Law $\overline{\text{WIP}}_j \approx \lambda_j \overline{Z}_j$ (or $\overline{Q}_j \approx \lambda_j \overline{W}_j$) requires an approximately stationary or clearing regime where starting WIP equals ending WIP ($\text{WIP}_j(t_a) \approx \text{WIP}_j(t_b)$) and arrival rate $\lambda_{\text{in}}$ matches departure rate $\lambda_{\text{out}}$. We restrict formal $L = \lambda W$ validation to subperiods/stations where boundary WIP distortion is small, and quantify boundary backlog divergence where it fails.

# 5. Bottleneck and temporal interpretation

### 1. Structural vs. transient bottleneck: A time-varying shift from S1 to S2
The evidence demonstrates a **time-varying bottleneck** driven by an early external arrival surge at $\text{S1}$ interacting with a **structural capacity bottleneck at $\text{S2}$**:

- **Structural service-capacity evidence (S2 is the true structural bottleneck):**
  - At $\text{S1}$, completed active service times average **$28.3\text{ min}$** (central) with a tight range of $20\text{–}30\text{ min}$. Including the consistent $5\text{ min}$ inter-case setup/handover gap during queued operation, each $\text{S1}$ resource cycles every $30\text{–}35\text{ min}$, giving a 2-resource maximum sustainable throughput of $\mu_1^{\text{eff}} \approx 3.53\text{–}4.00\text{ cases/hr}$ ($4.24\text{ cases/hr}$ excluding handovers).
  - At $\text{S2}$, completed active service times average **$38.9\text{ min}$** (central) with a range of $25\text{–}50\text{ min}$ (median $40\text{ min}$). Including the $5\text{ min}$ handover gap, each $\text{S2}$ resource cycles every $44\text{–}45\text{ min}$, giving a 2-resource maximum sustainable throughput of only $\mu_2^{\text{eff}} \approx 2.67\text{–}2.73\text{ cases/hr}$ ($3.08\text{ cases/hr}$ excluding handovers).
  - Because $\mu_2^{\text{eff}} < \mu_1^{\text{eff}}$ by nearly $1\text{ case/hr}$, **whenever $\text{S1}$ operates near capacity, it inevitably feeds work into $\text{S2}$ faster than $\text{S2}$ can clear it.**

- **Temporal wave across the morning:**
  1. **Phase 1 (`08:00–10:30` — Transient arrival bottleneck at S1):** External arrivals surge into $\text{S1}$ at **$6.50\text{ cases/hr}$** during `08:00–10:00` (13 arrivals in 2 hours: `P01`–`P13`), nearly double $\text{S1}$'s capacity ($3.50\text{ cases/hr}$). Consequently, $\text{WIP}_1$ balloons to a peak of **9 cases** (`10:25–10:35` and `11:00–11:05`, with $Q_1 = 7$ waiting and $B_1 = 2$ in service). Meanwhile, $\text{S1}$ acts as a throttle protecting $\text{S2}$, releasing cases into $\text{S2}$ at a steady $3.50\text{ cases/hr}$.
  2. **Phase 2 (`10:30–12:15` — C2 maintenance outage and bottleneck crossover):** External arrivals slow to $4.00\text{ cases/hr}$ (`10:00–12:00`) and terminate after `P22` (`12:10`). However, $\text{S1}$ continues pumping completions into $\text{S2}$ at $3.50\text{ cases/hr}$ just as $\text{C2}$ goes offline (`10:55–11:10`). Available utilization at $\text{S2}$ hits **$93.3\%$** during `10:00–12:00`.
  3. **Phase 3 (`12:15–14:00` — S1 drains while S2 saturates):** At `12:15`, $\text{WIP}_1(12:15) = 6$ and $\text{WIP}_2(12:15) = 5$. By `12:35`, **$\text{WIP}_2$ surpasses $\text{WIP}_1$** ($\text{WIP}_2 = 5$ vs. $\text{WIP}_1 = 5$, and by `12:50`, $\text{WIP}_2 = 6$ vs. $\text{WIP}_1 = 4$). From `12:00–14:00`, $\text{S2}$ runs at **$93.8\%$ utilization** (central), $\overline{\text{WIP}}_2 = 5.67$ exceeds $\overline{\text{WIP}}_1 = 4.67$, and at `14:00`, $\text{S2}$ holds **6 cases** (2 open, 4 waiting up to $>85\text{ min}$) whereas $\text{S1}$ holds only **2 cases** (`P21` finishing and `P22` waiting).

### 2. Impact of the C2 maintenance interval (`10:55–11:10`)
- **Direct observation:** $\text{C2}$ completed `P06` at `10:50`, was unavailable `10:55–11:10` ($15\text{ min}$), and started `P08` at `11:15`. Because `P08` had already been waiting in the $\text{S2}$ queue since `10:20`, the outage directly delayed `P08`'s start by $20\text{ min}$ (from a normal $5\text{ min}$ handover at `10:55` to `11:15`), inflating $W_{\text{P08},2}$ to $55\text{ min}$.
- **Cascading queue and routing effect:** While `P08` was delayed on $\text{C2}$, $\text{C1}$ finished `P07` at `11:00` and immediately started `P09` (`11:00–11:40`), causing **case overtaking** (`P09` arrived at $\text{S2}$ $15\text{ min}$ after `P08` but completed $20\text{ min}$ earlier). Furthermore, when $\text{C1}$ finished `P09` at `11:40`, $\text{C2}$ was still occupied with `P08` until `12:00`, forcing $\text{C1}$ to take `P10` (`11:45–12:10`) and leaving `P11` (which arrived at $\text{S2}$ at `11:05` during the outage) waiting $55\text{ min}$ until $\text{C2}$ freed up at `12:00`.

### 3. Operational anomalies: Evidence vs. Hypotheses
Two striking operational anomalies appear late in the window that must be separated into hard **evidence** vs. explanatory **hypotheses**:
1. **`P16` vs. `P17` FIFO violation at $\text{S2}$ (`13:55`):**
   - *Evidence:* `P16` completed $\text{S1}$ on $\text{I2}$ at `12:35` and entered the $\text{S2}$ queue. `P17` completed $\text{S1}$ on $\text{I1}$ at `12:50` ($15\text{ min}$ later). When $\text{C1}$ finished `P14` at `13:50`, $\text{C1}$ started `P17` at `13:55`, leaving `P16` waiting in queue at `14:00` ($W_{\text{P16},2} > 85\text{ min}$).
   - *Hypotheses:* (H1) Priority/expediting rule favoring `P17`; (H2) Physical buffer/lane pairing where $\text{C1}$ preferentially pulls from $\text{I1}$'s output (`P17` came from $\text{I1}$) or `P16` requires $\text{C2}$-specific tooling; or (H3) Unrecorded defect/hold on `P16`.
2. **`P22` waiting at $\text{S1}$ while $\text{I2}$ is idle (`13:45–14:00`):**
   - *Evidence:* `P22` arrived at `12:10` and remained in state `WAITING_FOR_S1` at `14:00` ($W_{\text{P22},1} > 110\text{ min}$). Resource $\text{I2}$ completed `P20` at `13:45` and recorded no activity from `13:45` to `14:00` ($15\text{ min}$ of unscheduled idle time while a case was waiting).
   - *Hypotheses:* (H1) Shift-end cutoff policy ($\text{I2}$ will not start a $25\text{–}30\text{ min}$ inspection at `13:50` if the shift or observation window ends at `14:00`); (H2) Undocumented break or secondary task by $\text{I2}$ (e.g., assisting $\text{S2}$); or (H3) `P22` requires $\text{I1}$.

### 4. Little's Law ($L = \lambda W$) consistency check
- **Why naive Little's Law fails on the full window and early subperiods:** Over `08:00–14:00`, the system starts empty ($\text{WIP}(08:00) = 0$) and ends with 8 cases in progress ($\text{WIP}_1(14:00) = 2, \text{WIP}_2(14:00) = 6$), violating conservation of flow ($\lambda_{\text{in}} > \lambda_{\text{out}}$) and right-censoring the longest-waiting cohorts.
- **Where Little's Law is defensible (`S1` during `10:00–12:00`):** During Subperiod 2 (`10:00–12:00`), $\text{S1}$ is in a quasi-stationary saturated regime: starting WIP is $\text{WIP}_1(10:00) = 6$, ending WIP is $\text{WIP}_1(12:00) = 7$, arrival rate is $\lambda_{\text{in},1} = 8 / 2\text{ hr} = 4.00\text{ cases/hr}$, completion rate is $\lambda_{\text{out},1} = 7 / 2\text{ hr} = 3.50\text{ cases/hr}$ (average throughput $\bar{\lambda}_1 = 3.75\text{ cases/hr} = 0.0625\text{ cases/min}$), and all 7 cohorts starting or completing in this window have well-determined durations:
  - Mean waiting time of cohorts entering service in `10:00–12:00` (`P09`–`P15`): $\overline{W}_1 = 77.14\text{ min}$ (central); mean service time: $\overline{V}_1 = 28.57\text{ min}$; mean station sojourn: $\overline{Z}_1 = 105.71\text{ min}$.
  - Applying Little's Law with $\bar{\lambda}_1 = 0.0625\text{ cases/min}$:
    $$\lambda_1 \overline{W}_1 = 0.0625 \times 77.14 = \mathbf{4.82}\text{ cases} \quad (\text{vs. exact } \overline{Q}_1 = \mathbf{6.33})$$
    $$\lambda_1 \overline{Z}_1 = 0.0625 \times 105.71 = \mathbf{6.61}\text{ cases} \quad (\text{vs. exact } \overline{\text{WIP}}_1 = \mathbf{8.08})$$
  - Why is $\overline{\text{WIP}}_1 = 8.08$ still $22\%$ higher than $\bar{\lambda}_1 \overline{Z}_1 = 6.61$? Because the 8 arrivals during `10:00–12:00` (`P14`–`P21`) experience *growing* sojourn times ($120\text{–}135\text{ min}$, average $128.8\text{ min}$). Using the arrival-cohort rate $\lambda_{\text{in},1} = 8/120 = 0.0667\text{ min}^{-1}$ and arrival-cohort sojourn $\overline{Z}_{1,\text{arr}} = 128.8\text{ min}$ yields $\lambda_{\text{in},1} \overline{Z}_{1,\text{arr}} = \mathbf{8.58}$, tightly bracketing the exact sample-path time average $\overline{\text{WIP}}_1 = \mathbf{8.08}$. By contrast, at $\text{S2}$, $\text{WIP}_2$ grows monotonically from $0 \to 2 \to 3 \to 6$ across the three subperiods, so steady-state Little's Law is invalid without end-of-window censoring corrections.

# 6. Missingness, censoring, and sensitivity analysis

We compare four explicit uncertainty scenarios across the full window (`08:00–14:00`):
1. **Scenario 1 — Optimistic Imputation (Earliest feasible start $S_{k,j}^{\min}$):** Sets `MISSING` starts immediately upon prior resource completion ($\text{P07}@09:25, \text{P15}@11:40, \text{P05}@09:45, \text{P11}@12:00$), minimizing queue wait and maximizing active service/utilization.
2. **Scenario 2 — Central Imputation (5-min handover $S_{k,j}^{\text{central}}$):** Applies the empirical $5\text{ min}$ handover gap ($\text{P07}@09:30, \text{P15}@11:45, \text{P05}@09:50, \text{P11}@12:00$).
3. **Scenario 3 — Pessimistic-Plausible Imputation ($S_{k,j}^{\text{plaus\_max}} = E_{k,j} - 25\text{ min}$):** Enforces the minimum observed domain service time of $25\text{ min}$ ($\text{P07}@09:35, \text{P15}@11:50, \text{P05}@09:50, \text{P11}@12:00$).
4. **Scenario 4 — Pessimistic-Mathematical Bound ($S_{k,j}^{\text{math\_max}} = E_{k,j} - 5\text{ min}$):** Allows a nominal $5\text{ min}$ service for `MISSING` starts ($\text{P07}@09:55, \text{P15}@12:10, \text{P05}@10:10, \text{P11}@12:20$), maximizing queue wait and minimizing utilization.
*(Additionally, continuous timestamp rounding of $\pm 2.5\text{ min}$ per event adds $\pm 5\text{ min}$ uncertainty to any individual duration and approximately $\pm 1.4\%$ to total station utilization if all boundary timestamps shift adversarially).*

### Which conclusions are stable vs. fragile?
- **Completely invariant / rock-solid conclusions:**
  1. **Station WIP ($\text{WIP}_1(t), \text{WIP}_2(t)$), total system WIP ($\text{WIP}_{\text{tot}}(t)$), and completed station/total sojourn times ($Z_{k,1}, Z_{k,2}, Z_k^{\text{total}}$)** are **100% invariant** to all four `MISSING` start timestamps because they depend only on arrival and completion timestamps ($A_{k,j}, E_{k,j}$).
  2. **The bottleneck shift from $\text{S1}$ to $\text{S2}$** holds under every scenario: $\text{S2}$ has a longer mean service time than $\text{S1}$ ($36.1\text{–}39.6\text{ min}$ vs. $26.0\text{–}28.8\text{ min}$ even under extreme mathematical bounds), and $\text{WIP}_2$ overtakes $\text{WIP}_1$ after `12:35` in all scenarios.
  3. **Right-censoring dominates missing-start uncertainty:** Discarding the 3 `OPEN` cases (`P15`, `P17`, `P21`) when computing resource utilization would understate $\text{S1}$ busy time by $30\text{ min}$ ($\text{I1}$ utilization drops by $8.3\%$) and $\text{S2}$ busy time by $35\text{ min}$ ($\text{C2}$ utilization drops by $8.7\%$). Similarly, ignoring the 4 cases waiting for $\text{S2}$ at `14:00` (`P16`, `P18`–`P20`, with elapsed waits up to $>85\text{ min}$) severely understates late-morning $\text{S2}$ queue delay.
- **Fragile / assumption-sensitive conclusions:**
  1. **Whether $\text{S1}$ or $\text{S2}$ had higher *full-window* average utilization (`08:00–14:00`)** is fragile: because $\text{S2}$ was starved during `08:00–08:35`, its 6-hour scheduled utilization ($79.9\%$ central) is slightly below $\text{S1}$'s ($82.6\%$ central), and their available utilizations ($81.6\%$ vs. $82.6\%$) overlap within missing-start and rounding bounds. Thus, full-window utilization alone would mask $\text{S2}$'s structural bottleneck if not decomposed by subperiod (`10:00–14:00`, where $\text{S2}$ available utilization is $93.5\%$).
  2. **Individual service vs. wait splits for `P05`, `P07`, `P11`, and `P15`** can shift by up to $25\text{–}30\text{ min}$ if the domain constraint ($V \ge 25\text{ min}$) is relaxed to allow $5\text{ min}$ services, though resource-availability constraints still bound them strictly from below.

        return pd.NaT, "OPEN"
    elif val == "" or pd.isna(val):
        return pd.NaT, "BLANK"
    else:
        return pd.Timestamp(BASE_DATE + val + ":00"), "OBSERVED"

# Compute resource-constrained bounds for MISSING starts
def add_imputation_bounds(df_in):
    d = df_in.copy()
    # Sort order on each resource follows case order
    for st, res_col, arr_col, s_col, e_col in [
        ("s1", "s1_resource", "arrival_s1_ts", "s1_start", "s1_end"),
        ("s2", "s2_resource", "arrival_s2_ts", "s2_start", "s2_end"),
    ]:
        d[f"{st}_start_opt"] = d[f"{s_col}_ts"]
        d[f"{st}_start_central"] = d[f"{s_col}_ts"]
        d[f"{st}_start_plaus_pess"] = d[f"{s_col}_ts"]
        d[f"{st}_start_math_pess"] = d[f"{s_col}_ts"]

        for res in ["I1", "I2", "C1", "C2"]:
            sub = d[d[res_col] == res]
            prev_end = T_START
            for idx, row in sub.iterrows():
                if row[f"{s_col}_status"] == "MISSING":
                    earliest = max(row[arr_col], prev_end)
                    # Central: 5-min handover after prev_end (capped at E - 25m)
                    central = min(earliest + pd.Timedelta(minutes=5), row[f"{e_col}_ts"] - pd.Timedelta(minutes=25))
                    plaus_max = max(earliest, row[f"{e_col}_ts"] - pd.Timedelta(minutes=25))
                    math_max = max(earliest, row[f"{e_col}_ts"] - pd.Timedelta(minutes=5))
                    d.loc[idx, f"{st}_start_opt"] = earliest
                    d.loc[idx, f"{st}_start_central"] = central
                    d.loc[idx, f"{st}_start_plaus_pess"] = plaus_max
                    d.loc[idx, f"{st}_start_math_pess"] = math_max
                if pd.notna(row[f"{e_col}_ts"]):
                    prev_end = row[f"{e_col}_ts"]
    return d

df = add_imputation_bounds(df)

# Helper to compute exact continuous-time overlap in minutes inside [w_start, w_end]
def overlap_mins(a, b, w_start, w_end):
    if pd.isna(a) or pd.isna(b):
        return 0.0
    s = max(a, w_start)
    e = min(b, w_end)
    return max(0.0, (e - s).total_seconds() / 60.0)

def evaluate_scenario(df_in, s1_col, s2_col, w_start, w_end):
    win_mins = (w_end - w_start).total_seconds() / 60.0
    q1_tot, b1_tot, q2_tot, b2_tot = 0.0, 0.0, 0.0, 0.0
    s1_waits, s1_servs, s2_waits, s2_servs = [], [], [], []

    for _, r in df_in.iterrows():
        # S1 intervals (effective end is T_END if OPEN or WAITING)
        a1 = r["arrival_s1_ts"]
        s1 = r[s1_col] if pd.notna(r[s1_col]) else T_END
        e1 = r["s1_end_ts"] if pd.notna(r["s1_end_ts"]) else (T_END if pd.notna(r[s1_col]) else T_END)
        q1_tot += overlap_mins(a1, s1, w_start, w_end)
        if pd.notna(r[s1_col]):
            b1_tot += overlap_mins(s1, e1, w_start, w_end)
            if w_start <= s1 < w_end:
                s1_waits.append((s1 - a1).total_seconds() / 60.0)
        if pd.notna(r["s1_end_ts"]) and (w_start <= r["s1_end_ts"] <= w_end) and r["s1_end_ts"] > w_start:
            s1_servs.append((r["s1_end_ts"] - s1).total_seconds() / 60.0)

        # S2 intervals
        a2 = r["arrival_s2_ts"]
        if pd.notna(a2):
            s2 = r[s2_col] if pd.notna(r[s2_col]) else T_END
            e2 = r["s2_end_ts"] if pd.notna(r["s2_end_ts"]) else (T_END if pd.notna(r[s2_col]) else T_END)
            q2_tot += overlap_mins(a2, s2, w_start, w_end)
            if pd.notna(r[s2_col]):
                b2_tot += overlap_mins(s2, e2, w_start, w_end)
                if w_start <= s2 < w_end:
                    s2_waits.append((s2 - a2).total_seconds() / 60.0)
            if pd.notna(r["s2_end_ts"]) and (w_start <= r["s2_end_ts"] <= w_end) and r["s2_end_ts"] > w_start:
                s2_servs.append((r["s2_end_ts"] - s2).total_seconds() / 60.0)

    # C2 outage overlap
    outage_mins = overlap_mins(
        pd.Timestamp("2026-05-12 10:55:00"),
        pd.Timestamp("2026-05-12 11:10:00"),
        w_start, w_end
    )
    s1_cap = 2.0 * win_mins
    s2_sched_cap = 2.0 * win_mins
    s2_avail_cap = s2_sched_cap - outage_mins

    return {
        "S1_Wait_Mean": np.mean(s1_waits) if s1_waits else np.nan,
        "S1_Serv_Mean": np.mean(s1_servs) if s1_servs else np.nan,
        "S1_Mean_Q": q1_tot / win_mins,
        "S1_Mean_WIP": (q1_tot + b1_tot) / win_mins,
        "S1_Busy_m": b1_tot,
        "S1_Util_%": 100.0 * b1_tot / s1_cap,
        "S2_Wait_Mean": np.mean(s2_waits) if s2_waits else np.nan,
        "S2_Serv_Mean": np.mean(s2_servs) if s2_servs else np.nan,
        "S2_Mean_Q": q2_tot / win_mins,
        "S2_Mean_WIP": (q2_tot + b2_tot) / win_mins,
        "S2_Busy_m": b2_tot,
        "S2_Sched_Util_%": 100.0 * b2_tot / s2_sched_cap,
        "S2_Avail_Util_%": 100.0 * b2_tot / s2_avail_cap,
    }
