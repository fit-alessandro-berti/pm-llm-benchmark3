# 1. Source-Semantics Baseline

In the witness column, R = Register Change, A = Assess Risk, E = Prepare Evidence, L = Legal Review, C = Configure Trial, I = Inspect Trial, D = Correct Defect, U = Release Change, and H = Archive Change. Commas denote a visible sequence; the silent skip is omitted. A “negative witness” is a forbidden trace or, for absence of order, a counterexample to a candidate model that imposes an order.

| Invariant ID | Invariant | Positive witness | Negative witness | Observable after hiding tau? |
|---|---|---|---|---|
| S1 | R occurs once and precedes all other visible work. | R,A,E,C,I,U,H | A,R,E,C,I,U,H | Yes. |
| S2 | A and E are unordered after R; either interleaving is permitted. This is a partial-order concurrency claim, not a requirement that their executions overlap in time. | Both R,A,E,C,I,U,H and R,E,A,C,I,U,H | A candidate that rejects either of those traces imposes an extra order. | Both orders are observable; true concurrency itself is not established by traces. |
| S3 | L, when chosen, follows A. | R,A,L,E,C,I,U,H | R,L,A,E,C,I,U,H | Yes. |
| S4 | Verification cannot begin before both A and E complete. | R,E,A,C,I,U,H | R,A,C,E,I,U,H | Yes. |
| S5 | The XOR permits exactly one legal branch: L once or a silent skip. L is therefore optional. | Both R,A,E,L,C,I,U,H and R,A,E,C,I,U,H | R,A,E,L,L,C,I,U,H; also a candidate that rejects the L-free trace. | Presence or absence of L is observable; the skip transition itself is hidden. |
| S6 | There is no source edge ordering the optional-legal branch against verification after their prerequisites. L may be before, during, or after the visible trial, but must finish before U. | R,A,L,E,C,I,U,H; R,A,E,C,L,I,U,H; R,A,E,C,I,L,U,H | A candidate that requires L entirely before C, or entirely after I, rejects a permitted witness. | The permitted visible interleavings are observable; physical overlap is not. |
| S7 | Each verification iteration executes C before I. | R,A,E,C,I,U,H | R,A,E,I,C,U,H | Yes. |
| S8 | A repeated iteration requires D between successive C,I pairs; D is the redo activity, not an activity inside each mandatory trial. | R,A,E,C,I,D,C,I,U,H | R,A,E,C,I,C,I,U,H or R,A,E,C,I,D,U,H | Yes. |
| S9 | At least one C,I iteration occurs. | R,A,E,C,I,U,H | R,A,E,U,H | Yes. |
| S10 | U waits for the completed verification loop and whichever legal branch was selected. | R,A,E,C,I,L,U,H | R,A,E,U,C,I,H or R,A,E,C,I,U,L,H | Yes for visible predecessors; the silent branch completion is internal. |
| S11 | H follows U and completes the case; no later visible activity belongs to that completed case. | R,A,E,C,I,U,H | R,A,E,C,I,H,U or R,A,E,C,I,U,H,C | Yes. |

A trace is a linear observation of a partial order. Witnesses test allowed and forbidden orderings, while the source POWL remains the authority for the concurrency relation.

# 2. Candidate Conversion Pipelines

| Pipeline | PM4Py calls | Expected benefit | Expected risk | Failure condition |
|---|---|---|---|---|
| **Primary:** POWL → accepting Petri net → BPMN | `convert_to_petri_net(source_powl)`; `convert_to_bpmn(net, im, fm)`; convert BPMN back to a marked net | The marked net can express the shared prerequisites, silent skip, join, and loop without first demanding a block structure. | Generated gateways and tau routing may be hard to read; conversion may alter reachable behavior or markings. | Missing marking, conversion exception, unsound net, or failed invariant/round-trip check. |
| **Conditional:** POWL → accepting Petri net → process tree → BPMN | `convert_to_process_tree(net, im, fm)` in `try/except`; if successful, `convert_to_bpmn(tree)`; convert BPMN back | A tree, when faithfully obtainable, gives a structured visualization path. | The shared dependency on A, the A+E verification prerequisite, and the unordered L/verification relationship may resist faithful block structuring; activity duplication or restricted interleavings can result. | Tree conversion raises an exception, or a successful conversion fails label, witness, soundness, or trace checks. |

A process-tree exception is evidence that this *route* is unavailable for the model or converter version. It does not invalidate the source POWL or automatically invalidate the primary route.

# 3. Conversion Code

The following code assumes the exact `source_powl` object from the question has already been constructed. It creates a local `conversion_audit` directory. Conversion and visualization errors are recorded and printed, not silently treated as successful output.

```python
from pathlib import Path
import pm4py

out_dir = Path("conversion_audit")
out_dir.mkdir(parents=True, exist_ok=True)
conversion_failures = {}
diagnostics = {}
all_nets = {}
bpmn_models = {}
round_trips = {}

def accepting(value, name):
    triple = pm4py.convert_to_petri_net(value)
    if not isinstance(triple, (tuple, list)) or len(triple) != 3:
        raise ValueError(f"{name}: converter did not return (net, im, fm)")
    net, im, fm = triple
    if net is None or im is None or fm is None:
        raise ValueError(f"{name}: accepting net or marking is None")
    return net, im, fm

def diagnose(name, triple):
    net, im, fm = triple
    result = {}
    try:
        result["workflow_net"] = pm4py.check_is_workflow_net(net)
    except Exception as exc:
        result["workflow_net"] = f"ERROR {type(exc).__name__}: {exc}"
    try:
        result["soundness"] = pm4py.check_soundness(
            net, im, fm, print_diagnostics=True
        )
    except Exception as exc:
        result["soundness"] = f"ERROR {type(exc).__name__}: {exc}"
    diagnostics[name] = result

def save_visual(name, save_call):
    try:
        save_call()
    except Exception as exc:
        conversion_failures[f"visualization:{name}"] = (
            f"{type(exc).__name__}: {exc}"
        )

save_visual(
    "powl_source.png",
    lambda: pm4py.save_vis_powl(source_powl, str(out_dir / "powl_source.png")),
)

# The primary pipeline starts here. A failure here is a primary-route failure.
net_from_powl, im_from_powl, fm_from_powl = accepting(
    source_powl, "source_powl"
)
all_nets["powl_net"] = (net_from_powl, im_from_powl, fm_from_powl)
diagnose("powl_net", all_nets["powl_net"])
save_visual(
    "petri_from_powl.png",
    lambda: pm4py.save_vis_petri_net(
        net_from_powl, im_from_powl, fm_from_powl,
        str(out_dir / "petri_from_powl.png")
    ),
)

bpmn_from_net = None
try:
    bpmn_from_net = pm4py.convert_to_bpmn(
        net_from_powl, im_from_powl, fm_from_powl
    )
    if bpmn_from_net is None:
        raise ValueError("Petri-to-BPMN converter returned None")
    bpmn_models["from_net"] = bpmn_from_net
    save_visual(
        "bpmn_from_net.png",
        lambda: pm4py.save_vis_bpmn(
            bpmn_from_net, str(out_dir / "bpmn_from_net.png")
        ),
    )
except Exception as exc:
    conversion_failures["petri_to_bpmn"] = f"{type(exc).__name__}: {exc}"

# The process-tree route is deliberately conditional.
tree_from_net = None
bpmn_from_tree = None
try:
    tree_from_net = pm4py.convert_to_process_tree(
        net_from_powl, im_from_powl, fm_from_powl
    )
    if tree_from_net is None:
        raise ValueError("Petri-to-tree converter returned None")
except Exception as exc:
    conversion_failures["petri_to_tree"] = f"{type(exc).__name__}: {exc}"
else:
    save_visual(
        "tree_from_net.png",
        lambda: pm4py.save_vis_process_tree(
            tree_from_net, str(out_dir / "tree_from_net.png")
        ),
    )
    try:
        bpmn_from_tree = pm4py.convert_to_bpmn(tree_from_net)
        if bpmn_from_tree is None:
            raise ValueError("Tree-to-BPMN converter returned None")
        bpmn_models["from_tree"] = bpmn_from_tree
        save_visual(
            "bpmn_from_tree.png",
            lambda: pm4py.save_vis_bpmn(
                bpmn_from_tree, str(out_dir / "bpmn_from_tree.png")
            ),
        )
    except Exception as exc:
        conversion_failures["tree_to_bpmn"] = f"{type(exc).__name__}: {exc}"

# Every produced BPMN is converted back where possible. Each accepting net
# receives both workflow-net and soundness diagnostics.
for route, bpmn in bpmn_models.items():
    try:
        triple = accepting(bpmn, f"BPMN round trip {route}")
    except Exception as exc:
        conversion_failures[f"bpmn_to_petri:{route}"] = (
            f"{type(exc).__name__}: {exc}"
        )
        continue
    round_trips[route] = triple
    name = f"roundtrip_{route}"
    all_nets[name] = triple
    diagnose(name, triple)
    net, im, fm = triple
    save_visual(
        f"petri_roundtrip_{route}.png",
        lambda net=net, im=im, fm=fm, route=route:
            pm4py.save_vis_petri_net(
                net, im, fm,
                str(out_dir / f"petri_roundtrip_{route}.png")
            ),
    )

print("Diagnostics:", diagnostics)
print("Conversion/visualization failures:", conversion_failures)
```

A non-null return and an image file are only conversion results. The audit below decides whether either derivative is usable.

# 4. Preservation and Loss Audit

The ratings below are **prospective**: no converter has been run in this document, so none merits “validated preserved.” “Not tested” in the last column becomes a validation outcome only after executing Section 5. If the tree converter throws, replace that route’s tree ratings with “conversion failed” and record its exception.

| Source invariant | POWL→Petri | Petri→BPMN | Petri→Tree | BPMN round trip | Evidence or uncertainty |
|---|---|---|---|---|---|
| True concurrency of A and E | expected preserved | ambiguous | ambiguous | not tested | Both visible orders are necessary but do not prove concurrency; inspect reachable independent firings and routing structure if that distinction matters. |
| No edge between optional L and verification | expected preserved | ambiguous | ambiguous | not tested | Require L-before, L-during, and L-after trial witnesses where their prerequisites permit. A neatly drawn BPMN sequence may conceal an extra order. |
| Silent optional behavior | expected preserved | ambiguous | ambiguous | not tested | Check both an L-free completed trace and a trace with one L. Tau must be hidden from visible traces, while the skip still reaches the release join. |
| Binary loop: mandatory C,I body, then D before another body | expected preserved | ambiguous | ambiguous | not tested | Require one and two iterations; reject D before the first body, repeated body without D, and D after the last body with no next body. Longer runs remain untested by a finite bound. |
| Join before U | expected preserved | ambiguous | ambiguous | not tested | U must wait for verification and the selected legal branch; the L-free route still requires the silent branch to complete. |
| Unique visible activity labels | expected preserved | ambiguous | ambiguous | not tested | The source has one transition per visible label. Count visible transition labels in each derivative; a tree converter might duplicate an activity to encode alternative interleavings. |
| Initial and final markings | expected preserved | ambiguous | ambiguous | not tested | Check non-null markings and completed traces at **exact** final-marking equality. Different nets have different places, so compare accepted behavior, not marking object identity across nets. |
| Gateway and silent-routing interpretation in the drawing | ambiguous | approximated | approximated | not tested | A BPMN picture is a layout of gateway and routing nodes; gateway appearance alone cannot certify synchronization, optionality, or loop scope. |

The marked Petri net is expected to carry the semantics of the source conversion, but that expectation must itself be checked against the source witnesses. Equal footprints or equal bounded visible traces cannot, by themselves, certify the POWL partial order or an unbounded loop.

# 5. Round-Trip Validation Code

Run this after Section 3. It compares every available BPMN round trip with the POWL-derived net and checks the source witnesses against **all** accepting nets. It enumerates completed visible traces up to 12 visible events and at most two Configure Trial executions. A state consists of its marking, visible trace, and iteration count; revisiting the same state after tau steps is skipped. A completed trace is recorded only when the current marking equals that net’s final marking exactly. If the state cap is reached, the program raises instead of reporting a complete comparison.

```python
from collections import Counter, deque
from pm4py.objects.petri_net import semantics

MAX_VISIBLE = 12
MAX_ITERATIONS = 2
MAX_STATES = 200_000

def bounded_completed_traces(net, im, fm):
    todo = deque([(im, (), 0)])
    seen = set()
    completed = set()

    while todo:
        marking, trace, iterations = todo.popleft()
        key = (
            frozenset((place, count) for place, count in marking.items()
                      if count != 0),
            trace,
            iterations,
        )
        if key in seen:
            continue
        if len(seen) >= MAX_STATES:
            raise RuntimeError("state cap reached; bounded audit incomplete")
        seen.add(key)

        if marking == fm:          # exact equality, not token-covering
            completed.add(trace)
            continue

        for transition in pm4py.get_enabled_transitions(net, marking):
            label = transition.label
            if label is None:      # hide tau
                next_trace = trace
                next_iterations = iterations
            else:
                if len(trace) >= MAX_VISIBLE:
                    continue
                next_iterations = iterations + (label == "Configure Trial")
                if next_iterations > MAX_ITERATIONS:
                    continue
                next_trace = trace + (label,)

            next_marking = semantics.execute(transition, net, marking)
            if next_marking is None:
                raise RuntimeError("enabled transition did not execute")
            todo.append((next_marking, next_trace, next_iterations))

    return completed

def T(*short):
    labels = {
        "R": "Register Change", "A": "Assess Risk",
        "E": "Prepare Evidence", "L": "Legal Review",
        "C": "Configure Trial", "I": "Inspect Trial",
        "D": "Correct Defect", "U": "Release Change",
        "H": "Archive Change",
    }
    return tuple(labels[item] for item in short)

positive = {
    T("R", "A", "E", "C", "I", "U", "H"),          # silent legal skip
    T("R", "E", "A", "C", "I", "U", "H"),          # reverse A/E
    T("R", "A", "L", "E", "C", "I", "U", "H"),     # L before verification
    T("R", "A", "E", "C", "L", "I", "U", "H"),     # L interleaved
    T("R", "A", "E", "C", "I", "L", "U", "H"),     # L after trial
    T("R", "A", "E", "C", "I", "D", "C", "I", "U", "H"),
}
negative = {
    T("A", "R", "E", "C", "I", "U", "H"),
    T("R", "L", "A", "E", "C", "I", "U", "H"),
    T("R", "A", "C", "E", "I", "U", "H"),
    T("R", "A", "E", "I", "C", "U", "H"),
    T("R", "A", "E", "U", "H"),                  # zero iterations
    T("R", "A", "E", "C", "I", "C", "I", "U", "H"),
    T("R", "A", "E", "C", "I", "D", "U", "H"),
    T("R", "A", "E", "C", "I", "U", "L", "H"),
    T("R", "A", "E", "C", "I", "H", "U"),
}

languages = {}
for name, (net, im, fm) in all_nets.items():
    labels = Counter(t.label for t in net.transitions if t.label is not None)
    duplicates = sorted(label for label, count in labels.items() if count > 1)
    try:
        languages[name] = bounded_completed_traces(net, im, fm)
    except Exception as exc:
        print(name, "TRACE AUDIT INCOMPLETE:", type(exc).__name__, str(exc))
        continue
    lang = languages[name]
    print(name, "diagnostics:", diagnostics[name])
    print(name, "duplicate visible labels:", duplicates)
    print(name, "missing positive witnesses:", positive - lang)
    print(name, "admitted negative witnesses:", negative & lang)

source_lang = languages.get("powl_net")
if source_lang is not None:
    for route in round_trips:
        name = f"roundtrip_{route}"
        if name not in languages:
            continue
        candidate = languages[name]
        print(name, "missing from source language:",
              sorted(candidate - source_lang)[:20])
        print(name, "lost from source language:",
              sorted(source_lang - candidate)[:20])
        print(name, "bounded visible-language equal:",
              candidate == source_lang)

# Footprints are corroborating evidence, not an equivalence proof.
footprints = {}
for name, (net, im, fm) in all_nets.items():
    try:
        footprints[name] = pm4py.discover_footprints(net, im, fm)
    except Exception as exc:
        print(name, "footprints unavailable:", type(exc).__name__, str(exc))

keys = ("activities", "start_activities", "end_activities",
        "sequence", "parallel", "min_trace_length")
def comparable_footprint(fp):
    if not isinstance(fp, dict):
        return None
    return {key: fp[key] for key in keys if key in fp}

if "powl_net" in footprints:
    source_fp = comparable_footprint(footprints["powl_net"])
    for route in round_trips:
        name = f"roundtrip_{route}"
        if name in footprints:
            other_fp = comparable_footprint(footprints[name])
            print(name, "comparable footprints equal:",
                  source_fp is not None and other_fp is not None
                  and source_fp == other_fp)
```

When this search terminates without hitting the state cap, its **completed visible-trace set is exhaustive within the stated visible-length and iteration bounds**, including finite tau routing to the exact final marking. It is not exhaustive for longer loops or traces. The visited-state rule prevents infinite repetition of a silent cycle that returns to the same marking and visible history; a silent path that creates endlessly distinct markings instead hits the cap and yields no completeness claim. The source net must pass its own witnesses before it is used as a reference. Soundness diagnostics and footprints add evidence, but neither substitutes for the witness and bounded-language comparisons. Reachability-graph construction and random playout may be added after separately establishing a finite state space; they are not used here because an unsound or unbounded candidate could make unrestricted exploration misleading or nonterminating.

# 6. Visual-Semantics Review

A BPMN layout can put A to the left of E, or L above the verification loop, without imposing that visible order. Parallel gateways should express the A/E split and the needed synchronization, yet this model also needs a dependency from A to optional L and a separate A+E prerequisite for verification. A tidy fork/join drawing can accidentally suggest that L must wait for E or that the whole legal branch must finish before verification begins.

An exclusive gateway represents the L-versus-skip choice; its unlabeled path is a real semantic possibility even if it looks like a connector. Loop gateways and return arrows must show that C then I happens first, that D is required before each repeat, and that exiting after one or more iterations is possible. Silent Petri transitions may become extra gateways or routing nodes with no visible activity label. Their existence or placement in a drawing is not proof of a corresponding source activity or constraint.

Publish the BPMN with a short legend: “A and E unordered”; “L optional after A and independent of verification until U”; “verification waits for A and E”; “C→I at least once, D between repeats”; and “U joins legal choice and verification.” Annotate the relevant gateways or flows with these dependencies and attach the witness/round-trip report. Judge causality from the validated model, not from the picture’s geometry.

# 7. Rejection Criteria

Reject or quarantine the affected derivative or route if any of these occurs:

1. A required conversion throws, returns no model, or returns a Petri net with a null initial or final marking; record the exception and route.
2. Any accepting net fails the workflow-net check or soundness check, or those diagnostics cannot be completed.
3. The POWL-derived net fails a source positive or negative witness; it cannot serve as the conversion reference.
4. A derivative loses either A-before-E or E-before-A, or loses a permitted L-before, L-during, or L-after verification interleaving.
5. A derivative admits verification before both A and E complete.
6. The optional branch collapses: L is required, L cannot occur, L occurs twice, or the silent skip cannot reach completion.
7. The loop admits zero trials, I before C, two trials without D, or a terminal D without a subsequent trial.
8. U can occur before verification or before the chosen legal branch finishes; H can occur before U or visible work can follow completed H.
9. An allegedly completed witness reaches only a marking that covers the final marking, not one exactly equal to it.
10. A round trip has a different bounded completed visible-trace set, introduces duplicate visible labels without a justified identity map, or hits the exploration cap. A matching bounded set is necessary evidence, not automatic acceptance.

A failed process-tree conversion rejects only the process-tree route. A failed image export calls for fixing or omitting that visualization; it does not by itself establish behavioral loss.

# 8. Canonical Representation Recommendation

Store the supplied POWL model, including its partial-order edges, silent legal alternative, and binary loop, as the **authoritative** process definition. Use a validated BPMN rendering for stakeholder visualization. The accepting Petri net, BPMN files, optional process tree, images, and round-tripped nets are generated derivatives, not new sources of truth.

Each derivative should carry its source revision and PM4Py version, conversion route and recorded exceptions, non-null marking check, workflow-net and soundness results for its accepting net, unique-label check, source witness results, bounded trace comparison with its stated bounds, and a note that visual layout is not semantic evidence. The process-tree intermediate is allowed only when conversion succeeds and its BPMN derivative passes the same checks; failure or an inability to preserve the source interleavings disqualifies that route.

Make future edits in POWL, regenerate the derivatives, and rerun the invariant and round-trip audit. An edit made for presentation in BPMN should be translated back into an explicit proposed POWL change and reviewed there before regeneration. This keeps repeated BPMN↔Petri↔tree conversions from silently becoming the process definition.

# 9. Residual Uncertainty

Even if every proposed test passes:

- Equal bounded visible traces do not prove true concurrency or preserve the original partial-order independence relation; different nets can generate the same interleavings.
- The search says nothing definitive about executions beyond 12 visible events or two trial iterations, including later loop behavior.
- Hiding tau can conceal different internal choices, divergence, or routing structure that leaves the tested completed traces unchanged.
- A BPMN tool or runtime may interpret, render, or execute generated gateways differently from the PM4Py round trip.
- Activity names and control flow do not establish data conditions, resource assignments, elapsed time, or business meaning of “risk,” “legal,” and “defect” beyond what the source model states.
