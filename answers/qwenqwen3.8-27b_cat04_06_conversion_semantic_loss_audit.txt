def explore_bounded_visible_traces(net, im, fm, max_visible=MAX_VISIBLE, max_states=MAX_STATES, max_silent_states=MAX_SILENT_STATES):

def silent_closure(net, marking, max_silent_states=MAX_SILENT_STATES):
    start = normalize_marking(marking)
    reachable = [start]
    seen = {marking_key(start)}
    stack = [start]
    truncated = False
    while stack:
        if len(reachable) >= max_silent_states:
            truncated = True
            break
        m = stack.pop()
        try:
            enabled = pm4py.get_enabled_transitions(net, m)
        except Exception as exc:
            print(f"silent get_enabled_transitions failed: {type(exc).__name__}: {exc}")
            truncated = True
            continue
        for t in enabled:
            if label_of(t) is not None:
                continue
            try:
                nm = fire_transition(net, m, t)
            except Exception as exc:
                print(f"silent fire_transition failed: {type(exc).__name__}: {exc}")
                truncated = True
                continue
            k = marking_key(nm)
            if k not in seen:
                seen.add(k)
                reachable.append(nm)
                stack.append(nm)
    return reachable, truncated

def trace_accepted(net, im, fm, trace, max_silent_states=MAX_SILENT_STATES):
    if net is None or not im or not fm:
        return False
    current = [normalize_marking(im)]
    for label in trace:
        next_marks = []
        next_keys = set()
        for m in current:
            closure, _ = silent_closure(net, m, max_silent_states)
            for cm in closure:
                try:
                    enabled = pm4py.get_enabled_transitions(net, cm)
                except Exception:
                    enabled = []
                for t in enabled:
                    if label_of(t) == label:
                        try:
                            nm = fire_transition(net, cm, t)
                        except Exception:
                            continue
                        k = marking_key(nm)
                        if k not in next_keys:
                            next_keys.add(k)
                            next_marks.append(nm)
        if not next_marks:
            return False
        current = next_marks
    fm_key = marking_key(fm)
    for m in current:
        closure, _ = silent_closure(net, m, max_silent_states)

# 4. Preservation and Loss Audit

The status terms below describe the audit design. `validated preserved` means that Section 5 contains a direct test for the invariant on the primary round trip; if that test fails, the result must be reclassified as `lost`, `ambiguous`, or `conversion failed`. The `BPMN round trip` column refers primarily to the primary `net_from_powl  BPMN  net` round trip. If the process-tree pipeline fails, tree-derived round-trip validation is not performed.

| Source invariant | POWLPetri | PetriBPMN | PetriTree | BPMN round trip | Evidence or uncertainty |
|---|---|---|---|---|---|
| I1 Register first | expected preserved | expected preserved | conversion failed | validated preserved | Positive witnesses begin with `R`; negative witness starting with `A` is rejected by playout. |
| I2 Assess/Prepare unordered | expected preserved | expected preserved | conversion failed | validated preserved | Bounded completed-trace set must contain both `R A P ...` and `R P A ...`. |
| I3 Legal Review optional | expected preserved | ambiguous | conversion failed | validated preserved | Silent skip is hidden. Positive traces with and without `L` must be accepted; `L` before `A` must be rejected. |
| I4 Verification after both prerequisites | expected preserved | expected preserved | conversion failed | validated preserved | Negative witness `R A C I P Rel Arch` must be rejected. |
| I5 Legal/verification unordered | expected preserved | expected preserved | conversion failed | validated preserved | Bounded traces must include `L` before `C` and `I` before `L`. |
| I6 Configure before Inspect | expected preserved | expected preserved | conversion failed | validated preserved | Negative witness with `I` before `C` must be rejected. |
| I7 Correct Defect separates iterations | ambiguous | ambiguous | conversion failed | validated preserved | Depends on PM4Py `Operator.LOOP` semantics. Tests accept `C I D C I` and reject `C I C I` and trailing `C I D`. |
| I8 At least one verification iteration | ambiguous | ambiguous | conversion failed | validated preserved | Negative witness with no `C`/`I` before `Rel` must be rejected. |
| I9 Release waits for both branches | expected preserved | expected preserved | conversion failed | validated preserved | Negative witnesses releasing before legal completion or verification completion must be rejected. |
| I10 Archive after Release | expected preserved | expected preserved | conversion failed | validated preserved | Negative witness `... Arch Rel` must be rejected. |
| I11 Archive final | expected preserved | expected preserved | conversion failed | validated preserved | Negative witness with visible activity after `Arch` must be rejected. |

**True concurrency versus arbitrary interleaving.**  
The POWL and the accepting Petri net express partial order, not real-time simultaneity. Independent activities may be interleaved in any order. That is behaviorally acceptable under trace semantics, but a BPMN parallel gateway can be misread as requiring true simultaneous execution or as adding timing constraints that are not present.

**Lack of an edge between Optional Legal Review and verification.**  
The source intentionally has no edge between `optional_legal` and `verification_loop`. Therefore, Legal Review may occur before, during, or after verification, as long as its own prerequisite and the release join are respected. A converter that introduces an artificial order between these branches has changed the semantics.

**Silent optional behavior.**  
The silent `skip_legal` transition makes Legal Review optional. After hiding `tau`, optionality is observable as the existence of valid traces without `L`. If the BPMN omits the silent path or renders it as an error path, the diagram may misleadingly suggest that Legal Review is mandatory or exceptional.

**Binary-loop semantics.**  
The loop is represented by `Operator.LOOP` with children `[trial_body, correct_defect]`. The intended semantics are: at least one `C I` iteration, with `D` only between repeated iterations. PM4Py’s exact `LOOP` interpretation must be validated. If `LOOP` instead means “zero or more trial bodies followed by Correct Defect,” the source code and intended semantics diverge, and no downstream conversion can repair that mismatch.

**Join before Release Change.**  
Release has two predecessors: the optional-legal branch and the verification loop. The accepting Petri net should contain a join that prevents Release until both branches complete. A round trip that loses this join would admit traces such as `R A P L Rel Arch` or `R A P C Rel Arch`.

**Activity-label uniqueness.**  
The source uses unique visible labels. A converter may introduce implicit start/end nodes, duplicate labels, or merge transitions. Label multiset comparison helps detect loss or duplication of visible activities, but it does not prove behavioral equivalence.

**Initial and final markings.**  
The POWL does not explicitly carry markings, but the accepting Petri net should have a single initial marking enabling Register and a single final marking after Archive. Missing, empty, or non-unique initial/final markings are technical rejection conditions. Exact final-marking equality is required in the custom trace playout.

**Gateway or routing-node ambiguity in BPMN visualization.**  
BPMN diagrams may introduce parallel, exclusive, or implicit routing nodes that are not present in the source POWL. A successful BPMN save does not prove that the diagram’s gateways match the Petri net’s behavior. The underlying net, not the rendered diagram, is the behavioral reference.

```python
import pm4py
from collections import Counter

# Assumes Section 3 has defined:
# net_from_powl, im_from_powl, fm_from_powl, roundtrip_nets

MAX_VISIBLE = 15
MAX_STATES = 100000
MAX_SILENT_STATES = 100000


def normalize_marking(marking):
    if marking is None:
        return {}
    out = {}
    for place, count in marking.items():
        try:
            count = int(count)
        except Exception:
            count = 0
        if count > 0:
            out[place] = count
    return out


def marking_key(marking):
    """Hashable exact key for a normalized marking."""
    m = normalize_marking(marking)
    try:
        return frozenset((p, int(c)) for p, c in m.items())
    except TypeError:
        return frozenset((str(p), int(c)) for p, c in m.items())


def marking_signature(marking):
    """Human-readable signature for reporting."""
    m = normalize_marking(marking)
    return tuple(sorted((str(p), int(c)) for p, c in m.items()))


def label_of(obj):
    """Return visible label, or None for silent/None."""
    if obj is None:
        return None
    if isinstance(obj, str):
        return obj
    lab = getattr(obj, "label", None)
    if lab is None:
        return None
    return str(lab)


def same_entity(a, b):
    if a is b:
        return True
    ida = getattr(a, "id", None)
    idb = getattr(b, "id", None)
    if ida is not None and idb is not None:
        return ida == idb
    return False


def _arc_source_target_weight(arc):
    if hasattr(arc, "source") and hasattr(arc, "target"):
        src = arc.source
        dst = arc.target
        w = getattr(arc, "weight", 1)
    elif isinstance(arc, (tuple, list)):
        if len(arc) == 3:
            src, dst, w = arc
        elif len(arc) == 2:
            src, dst, w = arc[0], arc[1], 1
        else:
            raise ValueError("Unsupported arc format")
    else:
        raise ValueError("Unsupported arc format")

    try:
        w = int(w)
    except Exception:
        w = 1
    if w <= 0:
        w = 1
    return src, dst, w


def fire_transition(net, marking, t):
    """Fire transition t in a PM4Py Petri net."""
    places = set(net.places)
    transitions = set(net.transitions)

    new_marking = {p: int(marking.get(p, 0)) for p in places}

    arcs = getattr(net, "arcs", [])
    if isinstance(arcs, dict):
        arcs = list(arcs.values())

    for arc in arcs:
        src, dst, w = _arc_source_target_weight(arc)

        if same_entity(dst, t) and src in places:
            new_marking[src] -= w
        elif same_entity(src, t) and dst in places:
            new_marking[dst] += w

    if any(c < 0 for c in new_marking.values()):
        raise ValueError("Firing produced a negative marking")

    return {p: c for p, c in new_marking.items() if c > 0}


def silent_closure(net, marking, max_silent_states=MAX_SILENT_STATES):
    """
    Compute markings reachable by silent transitions only.
    Uses visited marking keys to avoid infinite silent cycling.
    """
    start = normalize_marking(marking)
    reachable = [start]
    seen = {marking_key(start)}
    stack = [start]
    truncated = False

    while stack:
        if len(reachable) >= max_silent_states:
            truncated = True
            break

        m = stack.pop()

        try:
            enabled = pm4py.get_enabled_transitions(net, m)
        except Exception as exc:
            print(f"silent get_enabled_transitions failed: {type(exc).__name__}: {exc}")
            truncated = True
            continue

        for t in enabled:
            if label_of(t) is not None:
                continue

            try:
                nm = fire_transition(net, m, t)
            except Exception as exc:
                print(f"silent fire_transition failed: {type(exc).__name__}: {exc}")
                truncated = True
                continue

            k = marking_key(nm)
            if k not in seen:
                seen.add(k)
                reachable.append(nm)
                stack.append(nm)

    return reachable, truncated


def explore_bounded_visible_traces(
    net,
    im,
    fm,
    max_visible=MAX_VISIBLE,
    max_states=MAX_STATES,
    max_silent_states=MAX_SILENT_STATES,
):
    """
    Enumerate completed visible traces up to max_visible labels.
    A trace is completed if fm is reachable after silent moves.
    """
    if net is None or not im or not fm:
        return set(), True

    im = normalize_marking(im)
    fm = normalize_marking(fm)

    completed = set()
    truncated = False
    visited = set()
    frontier = [(im, ())]
    visited.add(((), marking_key(im)))
    processed = 0

    while frontier:
        if processed >= max_states:
            truncated = True
            break

        processed += 1
        marking, trace = frontier.pop()

        closure, closure_trunc = silent_closure(net, marking, max_silent_states)
        truncated = truncated or closure_trunc

        fm_key = marking_key(fm)
        if any(marking_key(m) == fm_key for m in closure):
            completed.add(trace)

        if len(trace) >= max_visible:
            continue

        for m in closure:
            try:
                enabled = pm4py.get_enabled_transitions(net, m)
            except Exception as exc:
                print(f"get_enabled_transitions failed: {type(exc).__name__}: {exc}")
                truncated = True
                continue

            for t in enabled:
                lab = label_of(t)
                if lab is None:
                    continue

                try:
                    nm = fire_transition(net, m, t)
                except Exception as exc:
                    print(f"fire_transition failed: {type(exc).__name__}: {exc}")
                    truncated = True
                    continue

                new_trace = trace + (lab,)
                key = (new_trace, marking_key(nm))

                if key not in visited:
                    visited.add(key)
                    frontier.append((nm, new_trace))

    return completed, truncated


def playout_visible_trace(net, im, fm, trace, max_silent_states=MAX_SILENT_STATES):
    """
    Custom model/trace playout for visible traces.
    Returns True if the visible trace can be followed to exact fm.
    """
    if net is None or not im or not fm:
        return False

    current = [normalize_marking(im)]

    for label in trace:
        next_marks = []
        next_keys = set()

        for m in current:
            closure, _ = silent_closure(net, m, max_silent_states)

            for cm in closure:
                try:
                    enabled = pm4py.get_enabled_transitions(net, cm)
                except Exception:
                    enabled = []

                for t in enabled:
                    if label_of(t) == label:
                        try:
                            nm = fire_transition(net, cm, t)
                        except Exception:
                            continue

                        k = marking_key(nm)
                        if k not in next_keys:
                            next_keys.add(k)
                            next_marks.append(nm)

        if not next_marks:
            return False

        current = next_marks

    fm_key = marking_key(fm)
    for m in current:
        closure, _ = silent_closure(net, m, max_silent_states)
        if any(marking_key(c) == fm_key for c in closure):
            return True

    return False


def soundness_result(net, im, fm):
    if net is None or not im or not fm:
        return None, "missing net/im/fm"
    try:
        return bool(pm4py.check_soundness(net, im, fm, print_diagnostics=False)), None
    except Exception as exc:
        return None, f"{type(exc).__name__}: {exc}"


def workflow_net_result(net):
    if net is None:
        return None, "missing net"
    try:
        return bool(pm4py.check_is_workflow_net(net)), None
    except Exception as exc:
        return None, f"{type(exc).__name__}: {exc}"


def footprint_signature(net, im, fm):
    if net is None or not im or not fm:
        return None, "missing net/im/fm"

    try:
        fps = pm4py.discover_footprints(net, im, fm)
    except Exception as exc:
        return None, f"discover_footprints: {type(exc).__name__}: {exc}"

    if fps is None:
        return frozenset(), None

    sig = set()
    for fp in fps:
        if fp is None:
            continue
        labels = set()
        for item in fp:
            lab = label_of(item)
            if lab is not None:
                labels.add(lab)
        sig.add(frozenset(labels))

    return frozenset(sig), None


def reachability_signature(net, im, fm):
    if net is None or not im or not fm:
        return None, "missing net/im/fm"

    try:
        rg = pm4py.convert_to_reachability_graph(net, im, fm)
    except Exception as exc:
        return None, f"convert_to_reachability_graph: {type(exc).__name__}: {exc}"

    nodes = getattr(rg, "nodes", [])
    if isinstance(nodes, dict):
        nodes = list(nodes.values())

    marks = set()
    for node in nodes:
        m = getattr(node, "marking", None)
        if m is None and isinstance(node, dict):
            m = node.get("marking")
        if m is not None:
            marks.add(marking_signature(m))

    return (len(nodes), frozenset(marks)), None


def label_multiset(net):
    if net is None:
        return None
    counts = Counter()
    for t in net.transitions:
        lab = label_of(t)
        if lab is not None:
            counts[lab] += 1
    return frozenset(counts.items())


def silent_count(net):
    if net is None:
        return None
    return sum(1 for t in net.transitions if label_of(t) is None)

def compare_roundtrip(name, rt):
    report = {"name": name}

    base_sound, base_sound_err = soundness_result(net_from_powl, im_from_powl, fm_from_powl)
    rt_sound, rt_sound_err = soundness_result(rt["net"], rt["im"], rt["fm"])
    report["base_sound"] = base_sound
    report["rt_sound"] = rt_sound
    report["sound_errors"] = [base_sound_err, rt_sound_err]

    base_wf, base_wf_err = workflow_net_result(net_from_powl)
    rt_wf, rt_wf_err = workflow_net_result(rt["net"])
    report["base_workflow_net"] = base_wf
    report["rt_workflow_net"] = rt_wf
    report["workflow_net_errors"] = [base_wf_err, rt_wf_err]

    base_fp, base_fp_err = footprint_signature(net_from_powl, im_from_powl, fm_from_powl)
    rt_fp, rt_fp_err = footprint_signature(rt["net"], rt["im"], rt["fm"])
    report["footprints_equal"] = (
        base_fp == rt_fp if base_fp is not None and rt_fp is not None else None
    )
    report["footprint_errors"] = [base_fp_err, rt_fp_err]

    base_rg, base_rg_err = reachability_signature(net_from_powl, im_from_powl, fm_from_powl)
    rt_rg, rt_rg_err = reachability_signature(rt["net"], rt["im"], rt["fm"])
    report["reachability_equal"] = (
        base_rg == rt_rg if base_rg is not None and rt_rg is not None else None
    )
    report["reachability_errors"] = [base_rg_err, rt_rg_err]

    base_labels = label_multiset(net_from_powl)
    rt_labels = label_multiset(rt["net"])
    report["label_multiset_equal"] = (
        base_labels == rt_labels
        if base_labels is not None and rt_labels is not None
        else None
    )
    report["base_silent_count"] = silent_count(net_from_powl)
    report["rt_silent_count"] = silent_count(rt["net"])

    report["base_im_signature"] = marking_signature(im_from_powl)
    report["rt_im_signature"] = marking_signature(rt["im"])
    report["base_fm_signature"] = marking_signature(fm_from_powl)
    report["rt_fm_signature"] = marking_signature(rt["fm"])

    base_completed, base_trunc = explore_bounded_visible_traces(
        net_from_powl,
        im_from_powl,
        fm_from_powl,
        MAX_VISIBLE,
        MAX_STATES,
        MAX_SILENT_STATES,
    )
    rt_completed, rt_trunc = explore_bounded_visible_traces(
        rt["net"],
        rt["im"],
        rt["fm"],
        MAX_VISIBLE,
        MAX_STATES,
        MAX_SILENT_STATES,
    )

    report["bounded_completed_equal"] = base_completed == rt_completed
    report["missing_completed"] = [
        list(t) for t in sorted(base_completed - rt_completed, key=lambda x: (len(x), x))
    ][:20]
    report["extra_completed"] = [
        list(t) for t in sorted(rt_completed - base_completed, key=lambda x: (len(x), x))
    ][:20]
    report["exploration_truncated"] = bool(base_trunc or rt_trunc)

    for idx, trace in enumerate(positive_witnesses):
        report[f"positive_{idx}_accepted"] = playout_visible_trace(
            rt["net"], rt["im"], rt["fm"], trace, MAX_SILENT_STATES
        )

    for idx, trace in enumerate(negative_witnesses):
        report[f"negative_{idx}_rejected"] = not playout_visible_trace(
            rt["net"], rt["im"], rt["fm"], trace, MAX_SILENT_STATES
        )

    return report


for rt in roundtrip_nets:
    rep = compare_roundtrip(rt["name"], rt)
```

The bounded exploration is exhaustive for completed visible traces of length at most `MAX_VISIBLE` if `exploration_truncated` is `False`. It is not exhaustive for unbounded behavior. With `MAX_VISIBLE = 15`, the bound allows at least three verification iterations in the main branch, for example `R A P C I D C I D C I Rel Arch`, and also variants including Legal Review. Silent cycling is prevented by visited marking keys in `silent_closure`.

# 6. Visual-Semantics Review

A BPMN rendering can be behaviorally acceptable while still being visually misleading.

**Parallel gateways.**  
The accepting Petri net may represent the unordered `Assess Risk` / `Prepare Evidence` branch with a parallel split. In BPMN, a parallel split can be read as “these activities run simultaneously,” whereas the source only says they are unordered and both must complete before verification. Similarly, the join before Release may be read as strict synchronization, which is correct, but the diagram may not show that Legal Review and verification may overlap before that join.

**Exclusive gateways.**  
The optional Legal Review branch is modeled as an XOR with a silent skip. In BPMN, this may appear as an exclusive gateway with one visible outgoing path to Legal Review and one invisible or implicit path. Stakeholders may misread the invisible path as an error, as a missing branch, or as evidence that Legal Review is mandatory. If the silent path is omitted entirely, the diagram may incorrectly imply that Legal Review always occurs.

**Loop visualization.**  
The verification loop may be rendered as a loop gateway, a repeated sub-process, or a Petri-net-style cycle. A loop gateway may suggest a single loop construct with an entry/exit condition, while the source semantics require at least one `Configure Trial  Inspect Trial` iteration and `Correct Defect` only between repeated iterations. A visual loop may also be misread as allowing zero iterations or as requiring `Correct Defect` after the final iteration.

**Silent routing nodes.**  
Silent transitions may become invisible connectors, implicit start/end events, or omitted routing. This can hide the optional skip and can also hide synchronization points. A diagram that looks connected may not reveal where silent routing is carrying control.

**Apparent ordering from graph layout.**  
Graph layout can imply order that does not exist. If Legal Review is drawn above or to the left of the verification loop, readers may infer that Legal Review must occur first. If verification is drawn below Legal Review, they may infer the opposite. The source explicitly allows overlap, so layout must not be treated as semantic evidence.

**Recommended annotations and documentation.**  
To reduce ambiguity, the BPMN should include:

- explicit labels on gateways: “parallel split: Assess Risk / Prepare Evidence unordered”;
- an explicit optional branch label: “Legal Review or skip”;
- a loop annotation: “at least one trial; Correct Defect separates repeated iterations”;
- a join annotation: “Release waits for Legal branch and verification loop”;
- swimlanes separating legal review from verification;
- a visible but clearly marked “skip” task if silent routing is omitted;
- a documentation note stating that the diagram is a visualization of a validated accepting Petri net, not the authoritative model;
- a validation manifest listing witness traces, soundness results, and bounded trace-equivalence results.

# 7. Rejection Criteria

A conversion result should be rejected or quarantined if any of the following occurs:

1. **Primary conversion failure.** `pm4py.convert_to_petri_net(source_powl)` fails, returns `None`, or returns an incomplete net/im/fm triple.

2. **Missing or empty markings.** The accepting Petri net has no initial marking, no final marking, or empty markings required for soundness and playout.

3. **Unsound or non-workflow net.** `pm4py.check_is_workflow_net(...)` fails or `pm4py.check_soundness(...)` returns false for the source net or any round-tripped net.

4. **Positive witness rejected.** A required valid trace is not accepted, for example a trace with Legal Review, a trace without Legal Review, a trace with `P` before `A`, or a trace with two verification iterations.

5. **Negative witness accepted.** A forbidden trace is accepted, for example Release before verification, verification before both prerequisites, Archive before Release, Legal Review before Assess Risk, Inspect before Configure, repeated verification without Correct Defect, or trailing Correct Defect with no second iteration.

6. **Loss of required interleaving.** The bounded completed-trace set no longer contains both `R A P ...` and `R P A ...`, or no longer contains both Legal-before-verification and verification-before-Legal orderings.

7. **Collapse of optional behavior.** Legal Review becomes mandatory because the skip trace is rejected, or Legal Review becomes impossible because the visible Legal trace is rejected.

8. **Wrong loop semantics.** Zero verification iterations are allowed, repeated iterations are allowed without Correct Defect, or Correct Defect is required after the final iteration.

9. **Activity-label corruption.** Visible labels are renamed, duplicated, merged, or missing. The label multiset differs from the source without a documented and validated reason.

10. **Failed exact-final-marking test.** A completed trace does not reach the exact final marking after silent moves, or the round-tripped net reaches a different final marking structure that changes workflow completion semantics.

11. **Process-tree intermediate introduces artificial order.** If a tree is produced, it forces Legal Review after Prepare Evidence, forces verification after Legal Review, forces Legal Review before verification, or otherwise changes the unordered relationship.

12. **Unexplained extra visible behavior.** The round-tripped net admits completed visible traces that are missing from the source bounded trace set and are not explained by converter-specific implicit behavior.

# 8. Canonical Representation Recommendation

**Authoritative representation.**  
The source POWL should remain the authoritative, editable specification. It is compact, expresses the intended partial order and operator structure, and avoids locking the team into a derived net or diagram.

**Executable derivative.**  
The accepting Petri net generated from the POWL should be treated as the primary executable derivative. It is the best representation for behavioral validation because it supports marking-based playout, soundness checks, reachability analysis, and bounded trace exploration.

**Stakeholder visualization.**  
The BPMN model generated from the accepting Petri net should be used for stakeholder visualization. It should be clearly marked as derivative and non-authoritative. The process-tree-derived BPMN, if produced, should be treated as an optional alternative visualization only, not as a canonical model.

**Validation evidence required for derivatives.**  
Each derivative should be accompanied by:

- conversion log showing the exact PM4Py calls used;
- initial and final marking signatures;
- workflow-net check result;
- soundness check result;
- label multiset comparison;
- positive witness acceptance results;
- negative witness rejection results;
- bounded completed-trace equivalence report;
- reachability-graph and footprint comparison summary;
- explicit statement of the bounds used and whether exploration was truncated.

**Process-tree intermediate policy.**  
For this source, a process-tree intermediate should not be allowed as canonical. It may be generated experimentally, but it should be accepted only if it passes the same invariant tests and is explicitly labeled as a non-authoritative derivative. Given the cross-branch dependency between Legal Review, Prepare Evidence, and verification, a faithful process tree is unlikely; failure of `pm4py.convert_to_process_tree(...)` should be treated as an expected and acceptable outcome.

**Avoiding round-trip drift.**  
Future edits should be made only in the POWL. The POWL should be versioned. Derivatives should be regenerated from the POWL, never edited by hand and converted back. Each regeneration should rerun the full validation suite. If a BPMN or tree artifact is modified for presentation, it should be stored as a presentation derivative with a separate hash and must not be used as the source for future behavioral conversion.

# 9. Residual Uncertainty

Even if every proposed test passes, the following claims cannot be fully established:

1. **Unbounded loop behavior.** The bounded trace exploration only covers traces up to `MAX_VISIBLE` labels. It cannot prove that all longer verification loops, all deeper interleavings, or all unbounded silent/visible combinations are preserved.

2. **True concurrency versus trace interleaving.** Passing trace-based tests shows that allowed visible sequences are preserved, but it does not prove that the model captures real-time simultaneity, causal concurrency, or the absence of hidden synchronization beyond what the partial order states.

3. **PM4Py `Operator.LOOP` formal semantics.** The validation can detect specific loop mismatches through witnesses, but it cannot prove that PM4Py’s `Operator.LOOP` matches the intended loop semantics for every possible untested loop structure or edge case.

4. **BPMN visual interpretation.** A valid BPMN save and a behaviorally acceptable underlying net do not prove that stakeholders will interpret the gateways, loop constructs, silent routing, and layout correctly.

5. **Process-tree failure as impossibility.** If `pm4py.convert_to_process_tree(...)` fails, that proves only that this PM4Py algorithm failed on this net. It does not prove that no faithful process tree exists in some other formalism or tool.
