# 5. PM4Py role-discovery and similarity code

Run this on the underlying event log. The aggregate fragments can motivate a hypothesis about a handover, but a network needs ordered case traces. The example assumes timestamps include offsets or are already in UTC, and the substitution values are Boolean-like. Unknown flag values remain visible.

```python
import pandas as pd
import pm4py

CASE = "case:concept:name"
ACTIVITY = "concept:name"
TIME = "time:timestamp"
RESOURCE = "org:resource"

raw = pd.read_csv("event_log.csv", dtype={CASE: "string", RESOURCE: "string"})
raw[TIME] = pd.to_datetime(raw[TIME], utc=True, errors="raise")
log = pm4py.format_dataframe(
    raw,
    case_id=CASE,
    activity_key=ACTIVITY,
    timestamp_key=TIME,
)
log = log.reset_index(drop=True)
log["event_id"] = log.index
log["complexity"] = log["case_complexity"].astype("string").fillna("unknown")
flag = log["temporary_substitution"].astype("string").str.strip().str.lower()
log["cover"] = flag.map({
    "true": "cover", "1": "cover", "1.0": "cover", "yes": "cover",
    "false": "regular", "0": "regular", "0.0": "regular", "no": "regular",
}).fillna("unknown")

roles = pm4py.discover_organizational_roles(log)
activity_similarity = pm4py.discover_activity_based_resource_similarity(log)
handover = pm4py.discover_handover_of_work_network(log, beta=0)
working_together = pm4py.discover_working_together_network(log)

focus = {"R05_Erik", "R06_Fatima", "R07_Giorgio", "R08_Hana", "R13_Mateo"}
for name, network in (
    ("activity similarity", activity_similarity),
    ("direct handover", handover),
    ("working together", working_together),
):
    relevant_edges = [
        (pair, weight) for pair, weight in network.connections.items()
        if focus.intersection(pair)
    ]
    print(name, sorted(relevant_edges, key=lambda edge: edge[1], reverse=True)[:15])

# Compute the stated cosine metric explicitly for comparison with the summary.
activity_counts = pd.crosstab(log[RESOURCE], log[ACTIVITY]).astype(float)
unit_profiles = activity_counts.div(activity_counts.pow(2).sum(axis=1).pow(0.5), axis=0)
cosine_similarity = unit_profiles @ unit_profiles.T

role_membership = pd.DataFrame(
    [
        (role_id, resource, activity, weight)
        for role_id, role in enumerate(roles, start=1)
        for resource, weight in role.originator_importance.items()
        if weight > 0
        for activity in role.activities
    ],
    columns=["mined_role", RESOURCE, ACTIVITY, "mined_weight"],
)
role_events = log.merge(role_membership, how="left", on=[RESOURCE, ACTIVITY])
role_context = (
    role_events.groupby(
        ["mined_role", RESOURCE, ACTIVITY, "complexity", "cover"], dropna=False
    )
    .agg(events=("event_id", "nunique"), cases=(CASE, "nunique"))
    .reset_index()
)
print(role_context)
```

- The join attaches complexity and cover to observed resource–activity pairs. An event may match multiple mined roles, and a case may occur in multiple groups. Deduplicate by event or case before computing pooled totals. If the substitution flag marks the whole case, interpret it as exposure and identify actual cover actions using the performer, activity and absence dates.
- Inspect handovers directionally for Mateo's intake and onward referrals, as well as Erik's downstream edges. Working together measures shared case participation. An edge alone cannot establish direct collaboration, supervision or delegation. Recompute networks on complete traces for comparable case cohorts by complexity, product, segment and escalation level. Compare case volumes and use dates and shift rosters to interpret changes during cover. Preserve intermediate events, including bot events, when calculating direct handovers. Use a reliable tie-breaker or case histories where equal timestamps make order uncertain.
- Check the summary inputs before setting thresholds or staffing targets. The displayed counts yield cosine values of approximately 0.998 for Chen–Dina and 0.505 for Giorgio–Fatima, compared with the supplied 0.94 and 0.71. Reconcile the event windows and any weighting or filters. Also verify the case denominators. For example, Hana's 274 case touches would require at least 274 events if the 245 activity events and case touches were complete counts for the same population and window. The role proposal rests on multiple signals, including the observed substitution episodes and trace positions. Role weights describe patterns in logged work. Confirm authorization against certification scope, delegation records and final outcomes.
