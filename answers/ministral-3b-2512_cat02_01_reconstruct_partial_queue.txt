# 1. Assumptions and notation

**Event-order convention (A1):** Events are processed in chronological order, with ties broken by case ID. For cases with overlapping start/end times, the earliest recorded timestamp is prioritized unless explicitly constrained by resource availability or queue rules.

**Rounding treatment (A2):** Reported timestamps (±2.5 min) represent actual times in [t-2.5, t+2.5]. For MISSING starts, we use:
- **Lower bound**: max(0, arrival_time + 2.5) if no prior work on the resource
- **Upper bound**: min(14:00, arrival_time + 2.5 + service_time_estimate)
For OPEN activities, elapsed time = end_time - start_time (if start is MISSING, use midpoint of bounds).

**Capacity assumptions (A3):**
- S1: Two parallel resources (I1, I2) with no capacity limits.
- S2: Two parallel resources (C1, C2) except C2 unavailable 10:55–11:10.
- Resource conflicts are resolved by enforcing single-case execution (no apparent overlaps after rounding).

**Missingness assumptions (A4):**
- MISSING start times are censored at arrival + 2.5 min (lower bound) or completion - 2.5 min (upper bound).
- OPEN status implies service duration  0 but  14:00 - start_time.
- For P05, P07, P11: Assume service time  0 and  14:00 - start_time (if start is MISSING).

# 2. Reconstruction method and formulas

**Definitions:**
- **S1_wait**: Time from arrival to S1 start (if start is MISSING, use lower/upper bounds).
- **S1_service**: S1_end - S1_start (if S1_start is MISSING, use midpoint of bounds).
- **S2_wait**: Time from S1 completion to S2 start (if S2_start is MISSING, use lower/upper bounds).
- **S2_service**: S2_end - S2_start (if S2_start is MISSING, use midpoint of bounds).
- **Total sojourn**: S1_wait + S1_service + S2_wait + S2_service.
- **WIP**: Sum of active cases in S1/S2 at any time.
- **Throughput**: Completed cases / observation window.
- **Utilization**: Busy-time / available time (e.g., S2: 8:00–14:00 minus C2 outage).

**Imputation logic:**
- For MISSING starts: Use resource availability and queue constraints to bound service time.
- For OPEN cases: Elapsed time = end_time - start_time (if start is MISSING, use midpoint of bounds).

2. **Central**: Use midpoint bounds (e.g., P07 S1_wait = 60 min).
   - S1 queue length increases by 5 min; S2 bottleneck remains.
3. **Pessimistic**: Assume MISSING starts are latest possible (e.g., P07 S1_start = 10:00).
   - S1 queue length increases by 15 min; S2 bottleneck worsens.

df = pd.DataFrame(data)

# Parse timestamps and handle MISSING/OPEN
def parse_timestamp(timestamp):
    if pd.isna(timestamp):
        return None
    if timestamp.startswith("MISSING"):
        return None
    if timestamp == "OPEN":
        return None
    return datetime.strptime(timestamp, "%H:%M")

# Convert to PM4Py-compatible format
events = []
for _, row in df.iterrows():
    case = row["case"]
    for i, col in enumerate(["s1_start", "s1_end", "s2_start", "s2_end"]):
        if pd.notna(row[col]):
            start = parse_timestamp(row[col])
            end = parse_timestamp(row[col].replace("_end", "")) if col != "s1_start" else None
            resource = row[f"{col}_resource"]
            if start:
                events.append({
                    "case": case,
                    "concept:name": f"S{i+1}",
                    "start_timestamp": start,
                    "time:timestamp": start,
                    "org:resource": resource
                })
                if end:
                    events.append({
                        "case": case,
                        "concept:name": f"S{i+1}",
                        "start_timestamp": end,
                        "time:timestamp": end,
                        "org:resource": resource
                    })

# Create PM4Py DataFrame
df_events = pd.DataFrame(events)

# Format for PM4Py
df_events = pm4py.format_dataframe(df_events, variant=pm4py.variants.XESFormatVariant())

# Calculate station-specific metrics
def calculate_metrics(df):
    # S1 metrics
    s1_arrivals = df[df["concept:name"] == "S1"]["time:timestamp"].dropna().tolist()
    s1_completions = df[df["concept:name"] == "S1"]["time:timestamp"].dropna().tolist()
    s1_wait = []
    s1_service = []
    for i, (start, end) in enumerate(zip(s1_arrivals, s1_completions)):
        wait = (start - df[df["case"] == s1_arrivals[i]]["time:timestamp"].iloc[0]).total_seconds() / 60
        service = (end - start).total_seconds() / 60
        s1_wait.append(wait)
        s1_service.append(service)

    # S2 metrics
    s2_arrivals = df[df["concept:name"] == "S2"]["time:timestamp"].dropna().tolist()
    s2_completions = df[df["concept:name"] == "S2"]["time:timestamp"].dropna().tolist()
    s2_wait = []
    s2_service = []
    for i, (start, end) in enumerate(zip(s2_arrivals, s2_completions)):
        wait = (start - df[df["case"] == s2_arrivals[i]]["time:timestamp"].iloc[0]).total_seconds() / 60
        service = (end - start).total_seconds() / 60
        s2_wait.append(wait)
        s2_service.append(service)

    return s1_wait, s1_service, s2_wait, s2_service

s1_wait, s1_service, s2_wait, s2_service = calculate_metrics(df_events)

# Print results
print("S1 Waiting Times:", s1_wait)
print("S1 Service Times:", s1_service)
print("S2 Waiting Times:", s2_wait)
print("S2 Service Times:", s2_service)
