```python
        tree_conversion_error
        + ". P2 is quarantined. This may reflect unsupported or "
          "non-block-structured routing; it does not invalidate P1.",
    )

if tree_from_net is not None:
    save_artifact(
        "save P2 process tree",
        lambda: pm4py.save_vis_process_tree(
            tree_from_net, str(OUT / "03_process_tree_from_petri.png")
        ),
    )

    # Optional but useful: isolate Petri -> tree semantic loss before BPMN.
    try:
        tree_net_result = pm4py.convert_to_petri_net(tree_from_net)
        tree_net, tree_im, tree_fm = require_accepting_net(
            tree_net_result, "process tree -> accepting Petri net"
        )
        name = "petri_tree_petri"
        accepting_nets[name] = (tree_net, tree_im, tree_fm)
        roundtrip_nets[name] = (tree_net, tree_im, tree_fm)

        save_artifact(
            "save Petri -> tree -> Petri net",
            lambda: pm4py.save_vis_petri_net(
                tree_net,
                tree_im,
                tree_fm,
                str(OUT / "04_petri_tree_petri_roundtrip.png"),
            ),
        )
    except Exception as exc:
        log_event(
            "process tree -> accepting Petri net",
            "failed",
            f"{type(exc).__name__}: {exc}",
        )

    # A BPMN model is attempted only because tree conversion succeeded.
    try:
        bpmn_from_tree = pm4py.convert_to_bpmn(tree_from_net)
        if bpmn_from_tree is None:
            raise ValueError("process-tree -> BPMN conversion returned None")

        bpmn_models["via_tree"] = bpmn_from_tree
        log_event("P2 process tree -> BPMN", "ok")

        save_artifact(
            "save P2 BPMN",
            lambda: pm4py.save_vis_bpmn(
                bpmn_from_tree, str(OUT / "05_bpmn_from_process_tree.png")
            ),
        )
    except Exception as exc:
        bpmn_from_tree = None
        log_event(
            "P2 process tree -> BPMN",
            "failed",
            f"{type(exc).__name__}: {exc}",
        )

# ---------------------------------------------------------------------
# Convert every produced BPMN model back to an accepting Petri net.
# ---------------------------------------------------------------------
for tag, bpmn in list(bpmn_models.items()):
    try:
        roundtrip_result = pm4py.convert_to_petri_net(bpmn)
        rt_net, rt_im, rt_fm = require_accepting_net(
            roundtrip_result, f"{tag} BPMN -> accepting Petri net"
        )

        name = f"{tag}_bpmn_petri_roundtrip"
        accepting_nets[name] = (rt_net, rt_im, rt_fm)
        roundtrip_nets[name] = (rt_net, rt_im, rt_fm)

        save_artifact(
            f"save {name}",
            lambda n=rt_net, i=rt_im, f=rt_fm, artifact_name=name:
                pm4py.save_vis_petri_net(
                    n, i, f, str(OUT / f"06_{artifact_name}.png")
                ),
        )
        log_event(f"{tag} BPMN round trip", "ok")
    except Exception as exc:
        log_event(
            f"{tag} BPMN -> accepting Petri net",
            "failed",
            f"{type(exc).__name__}: {exc}",
        )

# ---------------------------------------------------------------------
# Workflow-net and soundness diagnostics on every accepting net.
# Soundness is attempted even if the workflow-net test fails or errors;
# any resulting exception is recorded.
# ---------------------------------------------------------------------
for name, (net, im, fm) in accepting_nets.items():
    entry = {}

    try:
        entry["workflow_net"] = pm4py.check_is_workflow_net(net)
    except Exception as exc:
        entry["workflow_net_error"] = f"{type(exc).__name__}: {exc}"

    try:
        entry["soundness"] = pm4py.check_soundness(
            net, im, fm, print_diagnostics=True
        )
    except Exception as exc:
        entry["soundness_error"] = f"{type(exc).__name__}: {exc}"

    diagnostics[name] = entry
    log_event(f"diagnostics for {name}", "diagnostic", entry)

(OUT / "conversion_and_diagnostics.json").write_text(
    json.dumps(
        {
            "events": conversion_log,
            "diagnostics": diagnostics,
            "produced_bpmn_models": sorted(bpmn_models),
            "roundtrip_nets": sorted(roundtrip_nets),
        },
        indent=2,
        default=repr,
    ),
    encoding="utf-8",
)
```

A successful call above means only that an artifact was produced. The artifact remains provisional until the semantic audit.

# 4. Preservation and Loss Audit

This is a **pre-execution audit**. In particular, `expected preserved` describes the converter’s required behavior, not an observed result. No cell is upgraded to `validated preserved` without running the evidence-generation code and reviewing its scope.

| Source invariant | POWLPetri | PetriBPMN | PetriTree | BPMN round trip | Evidence or uncertainty |
|---|---|---|---|---|---|
| INV-01: registration and basic ordering | `expected preserved` | `expected preserved` | `ambiguous` | `not tested` | Check the reference net first. A BPMN start event or leftmost task is not itself evidence. |
| INV-02: `A` and `P` unordered | `expected preserved` | `ambiguous` | `ambiguous` | `not tested` | Both source orders must remain possible. Two orders alone still do not prove true concurrency. |
| INV-03: optional legal and silent skip | `expected preserved` | `ambiguous` | `ambiguous` | `not tested` | Test both presence and absence of `L`, `L` after `A`, and `L` before `P`. An XOR-looking picture is insufficient. |
| INV-04: verification entry joins `A` and `P` | `expected preserved` | `ambiguous` | `ambiguous` | `not tested` | The negative witness starting `C` before `P` must not be accepted. |
| INV-05: no optional-legal/verification order | `expected preserved` | `ambiguous` | `ambiguous` | `not tested` | This is a major serialization risk. A converter could produce a cleaner diagram by adding an order that the source does not contain. |
| INV-06: every body is `C` then `I` | `expected preserved` | `expected preserved` | `ambiguous` | `not tested` | Check body scope, not merely the relative order of one `C` and one `I`. |
| INV-07 and INV-08: binary LOOP and minimum one iteration | `expected preserved` | `ambiguous` | `ambiguous` | `not tested` | Required form is `C I (D C I)*`, not `(C I D)*`, `C I D*`, or an optional subprocess. |
| INV-09: release joins optional legal and verification | `expected preserved` | `ambiguous` | `ambiguous` | `not tested` | Test release before inspection and release before legal review. Silent-skip completion also needs net-level scrutiny. |
| INV-10: archive and finality | `expected preserved` | `ambiguous` | `ambiguous` | `not tested` | Acceptance without `Z`, premature acceptance, or acceptance with residual tokens must fail. |
| Source visible-label inventory | `ambiguous` | `ambiguous` | `ambiguous` | `not tested` | Conversion can add silent routing nodes or duplicate labeled implementations. Repetition of `C/I/D` is valid; unexplained duplication of other activities is not. |
| Well-defined initial/final accepting semantics | `expected preserved` | `ambiguous` | `ambiguous` | `not tested` | BPMN does not display the original Petri-net marking. Round-trip markings are newly created objects and must be checked for nullness and used in acceptance tests. |

Important interpretation points:

- **True concurrency versus arbitrary interleaving.** Observing both `A P` and `P A` does not distinguish a concurrent construction from every possible implementation choice that produces those two sequences. Conversely, a converter must not use “interleaving” as permission to admit `C` before `P` or `L` before `A`. Establishing causal independence requires inspection of reachable states or another concurrency-aware argument.
- **The missing optional-legal/verification edge is intentional.** Serializing those blocks can remove valid behavior while leaving a sound, attractive BPMN model.
- **Silent optional behavior.** A no-`L` trace does not show where the skip occurred or prove that release waited for the skip branch to complete. Making `L` mandatory removes positive traces; always skipping it removes other positive traces.
- **Binary LOOP semantics.** `correct_defect` is the redo child, not an optional final correction and not an activity that may follow the last inspection without another body.
- **Release join.** An exclusive merge, an unjoined token path, or a join attached to the wrong branches can admit early release or cause deadlock even when all task labels remain present.
- **Labels and routing nodes.** Source labels are distinct, but converted transition identity and label cardinality must be inventoried. Label-based comparisons can conflate duplicate transitions with the same label.
- **Initial and final markings.** Final-marking equality is tested **within each net**. Place-by-place equality between the reference and a round-tripped net is generally meaningless because their places differ.

# 5. Round-Trip Validation Code

The following code runs after Section 3. Its explorer fires only enabled transitions. It hides exactly transitions whose label is `None`, records a completed trace only on exact token-vector equality with that net’s final marking, prunes silent cycles that return to the same marking, and imposes additional silent-step and resource limits.

The default visible bounds are 12 visible activities and at most two `Inspect Trial` occurrences. Two iterations exercise one redo, but do not bound the source model itself.

```python
from collections import deque
import json
import pm4py
from pm4py.objects.petri_net.obj import Marking

R = "Register Change"
A = "Assess Risk"
P = "Prepare Evidence"
L = "Legal Review"
C = "Configure Trial"
I = "Inspect Trial"
D = "Correct Defect"
X = "Release Change"
Z = "Archive Change"

BOUNDS = {
    "max_visible": 12,
    "max_iterations": 2,
    "max_silent_segment": 32,
    "max_total_steps": 96,
    "max_states": 250000,
}


def bounded_visible_language(
    net,
    im,
    fm,
    max_visible=BOUNDS["max_visible"],
    max_iterations=BOUNDS["max_iterations"],
    max_silent_segment=BOUNDS["max_silent_segment"],
    max_total_steps=BOUNDS["max_total_steps"],
    max_states=BOUNDS["max_states"],
):
    if net is None or im is None or fm is None:
        raise ValueError("bounded exploration requires non-null net/im/fm")

    places = list(net.places)
    transitions = list(net.transitions)
    place_set = set(places)

    if any(p not in place_set for p in im) or any(
        p not in place_set for p in fm
    ):
        raise ValueError("a marking contains a place outside the net")

    pre = {t: [] for t in transitions}
    post = {t: [] for t in transitions}

    for arc in net.arcs:
        weight = getattr(arc, "weight", 1)
        if arc.source in pre:       # transition -> place
            pre[arc.source].append((arc.target, weight))
        if arc.target in post:      # place -> transition
            post[arc.target].append((arc.source, weight))

    def marking_key(marking):
        # Exact token count for every place, including implicit zeroes.
        return tuple(marking.get(p, 0) for p in places)

    def fire(marking, transition):
        # pm4py.get_enabled_transitions has already established enabledness.
        result = Marking(marking)

        for place, weight in pre[transition]:
            remaining = result.get(place, 0) - weight
            if remaining < 0:
                raise AssertionError("enabled transition produced negative tokens")
            if remaining:
                result[place] = remaining
            elif place in result:
                del result[place]

        for place, weight in post[transition]:
            result[place] = result.get(place, 0) + weight

        return result

    final_key = marking_key(fm)
    accepted_traces = set()
    deadlocked_nonfinal_markings = set()
    resource_limits_hit = set()

    queue = deque()
    seen_states = set()

    def push(marking, visible, silent_steps, silent_seen, total_steps):
        # visible and silent_seen are included so this deduplication does not
        # merge states with different acceptance histories or cycle information.
        state_key = (
            marking_key(marking),
            visible,
            silent_steps,
            silent_seen,
            total_steps,
        )
        if state_key not in seen_states:
            seen_states.add(state_key)
            queue.append(
                (marking, visible, silent_steps, silent_seen, total_steps)
            )

    initial_key = marking_key(im)
    push(
        Marking(im),
        tuple(),
        0,
        frozenset({initial_key}),
        0,
    )

    popped_states = 0

    while queue:
        if len(seen_states) > max_states:
            resource_limits_hit.add("state cap")
            break

        marking, visible, silent_steps, silent_seen, total_steps = queue.popleft()
        popped_states += 1
        current_key = marking_key(marking)

        # A completed trace is accepted only here. Exploration may continue
        # afterward to expose post-final behavior within the chosen bounds.
        if current_key == final_key:
            accepted_traces.add(visible)

        enabled = list(pm4py.get_enabled_transitions(net, marking))
        enabled.sort(
            key=lambda t: (
                str(getattr(t, "label", None)),
                str(getattr(t, "name", "")),
            )
        )

        if not enabled:
            if current_key != final_key:
                deadlocked_nonfinal_markings.add(current_key)
            continue

        if total_steps >= max_total_steps:
            resource_limits_hit.add("total-step budget")
            continue

        for transition in enabled:
            label = getattr(transition, "label", None)

            if label is None:
                if silent_steps >= max_silent_segment:
                    resource_limits_hit.add("silent-segment budget")
                    continue

                next_marking = fire(marking, transition)
                next_key = marking_key(next_marking)

                # Petri-net future behavior is determined by the marking.
                # Since no visible activity occurred in this segment, returning
                # to an earlier marking cannot add a new visible continuation.
                if next_key in silent_seen:
                    continue

                push(
                    next_marking,
                    visible,
                    silent_steps + 1,
                    silent_seen | {next_key},
                    total_steps + 1,
                )
            else:
                # These are intentional language bounds, not resource truncation.
                if len(visible) >= max_visible:
                    continue
                if (
                    label == I
                    and visible.count(I) >= max_iterations
                ):
                    continue

                next_marking = fire(marking, transition)
                next_visible = visible + (label,)

                # Reset silent-cycle tracking after visible progress.
                push(
                    next_marking,
                    next_visible,
                    0,
                    frozenset({marking_key(next_marking)}),
                    total_steps + 1,
                )

    return {
        "traces": accepted_traces,
        "exhaustive_under_bound": not resource_limits_hit,
        "resource_limits_hit": sorted(resource_limits_hit),
        "popped_states": popped_states,
        "seen_states": len(seen_states),
        "nonfinal_deadlock_count": len(deadlocked_nonfinal_markings),
    }


POSITIVE_WITNESSES = {
    "A before P, legal skipped": (R, A, P, C, I, X, Z),
    "P before A, legal skipped": (R, P, A, C, I, X, Z),
    "legal before verification": (R, A, P, L, C, I, X, Z),
    "legal after verification": (R, A, P, C, I, L, X, Z),
    "legal after A but before P": (R, A, L, P, C, I, X, Z),
    "two iterations with one redo": (R, A, P, C, I, D, C, I, X, Z),
}

NEGATIVE_WITNESSES = {
    "registration not first": (A, R, P, C, I, X, Z),
    "verification starts before P": (R, A, C, I, P, X, Z),
    "legal before A": (R, L, A, P, C, I, X, Z),
    "legal review twice": (R, A, P, L, L, C, I, X, Z),
    "zero verification iterations": (R, A, P, X, Z),
    "inspection before configuration": (R, A, P, I, C, X, Z),
    "repeat without Correct Defect": (R, A, P, C, I, C, I, X, Z),
    "trailing Correct Defect": (R, A, P, C, I, D, X, Z),
    "release before inspection": (R, A, P, C, X, I, Z),
    "release before legal review": (R, A, P, C, I, X, L, Z),
    "acceptance without archive": (R, A, P, C, I, X),
    "archive before release": (R, A, P, C, I, Z, X),
}


def witness_report(exploration):
    traces = exploration["traces"]
    missing_positive = {
        name: list(trace)
        for name, trace in POSITIVE_WITNESSES.items()
        if trace not in traces
    }
    admitted_negative = {
        name: list(trace)
        for name, trace in NEGATIVE_WITNESSES.items()
        if trace in traces
    }
    return {
        "missing_positive": missing_positive,
        "admitted_negative": admitted_negative,
        "all_witnesses_ok": not missing_positive and not admitted_negative,
    }


def safe_net_checks(net, im, fm):
    result = {}
    try:
        result["workflow_net"] = pm4py.check_is_workflow_net(net)
    except Exception as exc:
        result["workflow_net_error"] = f"{type(exc).__name__}: {exc}"

    try:
        result["soundness"] = pm4py.check_soundness(
            net, im, fm, print_diagnostics=False
        )
    except Exception as exc:
        result["soundness_error"] = f"{type(exc).__name__}: {exc}"
    return result


def safe_footprints(net, im, fm):
    try:
        return pm4py.discover_footprints(net, im, fm), None
    except Exception as exc:
        return None, f"{type(exc).__name__}: {exc}"


def freeze_for_comparison(value):
    """Compare normal footprint containers without relying on set ordering."""
    if isinstance(value, dict):
        return (
            "dict",
            frozenset(
                (freeze_for_comparison(k), freeze_for_comparison(v))
                for k, v in value.items()
            ),
        )
    if isinstance(value, (set, frozenset)):
        return (
            "set",
            frozenset(freeze_for_comparison(v) for v in value),
        )
    if isinstance(value, (list, tuple)):
        return (
            "sequence",
            tuple(freeze_for_comparison(v) for v in value),
        )
    try:
        hash(value)
        return ("atom", value)
    except Exception:
        return ("repr", repr(value))


def safe_reachability_summary(net, im, fm):
    # Run with an external resource timeout in production if a candidate may
    # be unbounded. Graph generation/counts are diagnostics, not isomorphism.
    try:
        graph = pm4py.convert_to_reachability_graph(net, im, fm)
        return {
            "states": len(graph.states),
            "transitions": len(graph.transitions),
        }, None
    except Exception as exc:
        return None, f"{type(exc).__name__}: {exc}"


# Reference exploration and diagnostics.
reference_exploration = bounded_visible_language(
    net_from_powl, im_from_powl, fm_from_powl
)
reference_witnesses = witness_report(reference_exploration)
reference_checks = safe_net_checks(
    net_from_powl, im_from_powl, fm_from_powl
)
reference_footprints, reference_footprints_error = safe_footprints(
    net_from_powl, im_from_powl, fm_from_powl
)
reference_rg, reference_rg_error = safe_reachability_summary(
    net_from_powl, im_from_powl, fm_from_powl
)

reference_conclusive = (
    reference_exploration["exhaustive_under_bound"]
    and reference_witnesses["all_witnesses_ok"]
)
reference_technically_ok = (
    reference_checks.get("workflow_net") is True
    and reference_checks.get("soundness") is True
)

validation_report = {
    "bounds": BOUNDS,
    "reference": {
        "checks": reference_checks,
        "accepted_trace_count": len(reference_exploration["traces"]),
        "exhaustive_under_bound":
            reference_exploration["exhaustive_under_bound"],
        "resource_limits_hit":
            reference_exploration["resource_limits_hit"],
        "nonfinal_deadlock_count":
            reference_exploration["nonfinal_deadlock_count"],
        "witnesses": reference_witnesses,
        "footprints_error": reference_footprints_error,
        "reachability_graph": reference_rg,
        "reachability_graph_error": reference_rg_error,
        # These traces were obtained by actually firing enabled transitions.
        "model_playout_samples": [
            list(trace)
            for trace in sorted(reference_exploration["traces"])[:20]
        ],
    },
    "candidates": {},
}

# Compare with every Petri/tree/BPMN round-tripped net produced in Section 3.
for name, (candidate_net, candidate_im, candidate_fm) in roundtrip_nets.items():
    candidate_exploration = bounded_visible_language(
        candidate_net, candidate_im, candidate_fm
    )
    candidate_witnesses = witness_report(candidate_exploration)
    candidate_checks = safe_net_checks(
        candidate_net, candidate_im, candidate_fm
    )

    reference_traces = reference_exploration["traces"]
    candidate_traces = candidate_exploration["traces"]

    reference_only = reference_traces - candidate_traces
    candidate_only = candidate_traces - reference_traces
    observed_sets_equal = not reference_only and not candidate_only

    both_explorations_complete = (
        reference_exploration["exhaustive_under_bound"]
        and candidate_exploration["exhaustive_under_bound"]
    )
    conclusive_bounded_equality = (
        both_explorations_complete and observed_sets_equal
    )

    candidate_footprints, candidate_footprints_error = safe_footprints(
        candidate_net, candidate_im, candidate_fm
    )
    footprints_equal = None
    if (
        reference_footprints_error is None
        and candidate_footprints_error is None
    ):
        footprints_equal = (
            freeze_for_comparison(reference_footprints)
            == freeze_for_comparison(candidate_footprints)
        )

    candidate_rg, candidate_rg_error = safe_reachability_summary(
        candidate_net, candidate_im, candidate_fm
    )

    candidate_technically_ok = (
        candidate_checks.get("workflow_net") is True
        and candidate_checks.get("soundness") is True
    )

    screen_passed = bool(
        reference_conclusive
        and reference_technically_ok
        and candidate_technically_ok
        and candidate_witnesses["all_witnesses_ok"]
        and conclusive_bounded_equality
    )

    validation_report["candidates"][name] = {
        "checks": candidate_checks,
        "accepted_trace_count": len(candidate_traces),
        "exhaustive_under_bound":
            candidate_exploration["exhaustive_under_bound"],
        "resource_limits_hit":
            candidate_exploration["resource_limits_hit"],
        "nonfinal_deadlock_count":
            candidate_exploration["nonfinal_deadlock_count"],
        "witnesses": candidate_witnesses,
        "reference_only_count": len(reference_only),
        "candidate_only_count": len(candidate_only),
        "reference_only_sample": [
            list(trace) for trace in sorted(reference_only)[:50]
        ],
        "candidate_only_sample": [
            list(trace) for trace in sorted(candidate_only)[:50]
        ],
        "observed_trace_sets_equal": observed_sets_equal,
        "conclusive_bounded_equality": conclusive_bounded_equality,
        "footprints_equal": footprints_equal,
        "footprints_error": candidate_footprints_error,
        "reachability_graph": candidate_rg,
        "reachability_graph_error": candidate_rg_error,
        # This is a screening result, never a claim of unbounded equivalence.
        "screen_passed_not_equivalence_proof": screen_passed,
    }

(OUT / "roundtrip_validation.json").write_text(
    json.dumps(validation_report, indent=2, default=repr),
    encoding="utf-8",
)

if not reference_conclusive:
    print(
        "QUARANTINE: the POWL-derived reference did not provide a conclusive "
        "source-witness baseline. Do not edit the witnesses to fit a converter."
    )

if not roundtrip_nets:
    print("No derived round-tripped accepting net was available for comparison.")
```

If both explorations avoid all resource-limit flags and their accepted trace sets are equal, the comparison is exhaustive **for the selected bounded accepting visible-trace language**, including the silent-segment and total-step limits. It is not exhaustive for arbitrary iteration counts or unbounded behavior. If either exploration reports resource truncation, equality of the observed sets is not even a complete comparison under the visible/iteration bound.

Footprints and reachability-graph summaries are secondary diagnostics. Equal footprints or equal graph counts do not prove equivalence. The witness checks are fixed-trace acceptance tests with automatic silent-path search; the playout samples are generated by model firing rather than by merely constructing strings.

# 6. Visual-Semantics Review

A BPMN rendering can be misleading even when the converted accepting net passes its behavioral tests:

- **Parallel gateways:** An AND-split can make branches look as though they must start together, whereas the source requires unordered execution, not simultaneous starts. More importantly, the verification-entry join must represent completion of both `A` and `P`, while the release join must represent completion of optional legal and verification. A visually plausible gateway attached to the wrong branches changes behavior.
- **Exclusive gateways:** The legal XOR includes a branch with no visible work. An XOR merge is not a substitute for the required synchronization before release. The source also supplies no data-based rule for choosing legal review; a diagram should not invent one.
- **Loop visualization:** A loop marker or back edge can easily be read as zero-or-more iterations, as `D` after every iteration including the last, or as a loop around only `I`. The rendering must be annotated with `C I (D C I)*`, at least one body, and no trailing `D`.
- **Silent routing nodes:** Petri-net `` transitions may become gateways, unlabeled routing elements, or collapsed flows. An empty-looking node should not automatically be interpreted as a business task. Conversely, removing it visually may hide the actual legal-skip branch or a synchronization point.
- **Layout:** Left-to-right position, vertical placement, proximity, and Graphviz ordering are not dependencies. Two vertically stacked parallel branches can look sequential, while tasks with no visible sequence flow between them can appear ordered merely because of their coordinates.
- **Start/end visuals:** A single BPMN end event does not prove exact final-marking equality or proper completion in the round-tripped net.

Useful annotations are:

1. Put the invariant IDs directly on the corresponding joins, XOR, and loop.
2. Label the legal gateway “exactly one of Legal Review or silent skip; no selection condition specified.”
3. Label the verification entry “join: Assess Risk and Prepare Evidence.”
4. Label the release entry “join: optional-legal completion and verification completion.”
5. Add an explicit note that `A/P` and optional-legal/verification are intentionally unordered, and that `L` may occur after `A` while `P` is still pending.
6. Supply a routing-node/label mapping and identify all silent nodes.
7. Attach the conversion version, witness report, exploration bounds, and a “bounded validation, not unbounded equivalence” notice to the image.

# 7. Rejection Criteria

A result should be rejected or quarantined under any of the following conditions:

1. **Technical conversion failure:** a required conversion raises an exception, returns no model, or returns a null net, initial marking, or final marking.
2. **Unresolved structural or soundness problem:** a derived net is unsound, has improper completion or reachable nonfinal deadlock, or workflow-net/soundness diagnostics cannot be completed. A non-workflow-net result may be studied, but not approved without separate justification.
3. **Reference-baseline failure:** the POWL-derived net fails source positive witnesses or accepts source negative witnesses. The source and its invariants must not be rewritten merely to agree with the converter.
4. **Lost required interleaving:** either `A/P` order disappears, legal review is forced after `P`, or optional legal and verification are serialized so that valid source traces disappear.
5. **Illegal verification or release:** verification can start before `A` and `P`, or release can occur before verification and the optional-legal node have completed. Multiple unintended releases are also grounds for rejection.
6. **Loop semantic mismatch:** zero iterations become possible, `I` can precede `C`, repetitions occur without `D`, a trailing `D` is accepted, or the loop scope otherwise differs from `C I (D C I)*`.
7. **Collapsed optional behavior:** legal review becomes mandatory, impossible, repeatable without source justification, or available before `A`; alternatively, the silent branch is removed in a way that changes release synchronization.
8. **Round-trip behavioral mismatch:** required traces are missing, forbidden traces are added, or a completed candidate trace fails exact final-marking equality. Soundness alone does not excuse a language mismatch.
9. **Unexplained label/routing corruption:** business labels are lost or ambiguously duplicated, silent routing becomes apparent business work, or no reliable source-to-derivative activity mapping can be produced.
10. **Process-tree failure or mismatch:** a Petritree exception rejects P2’s tree/BPMN artifacts, though not automatically P1. A successfully returned tree is likewise rejected if its own net round trip changes behavior.
11. **Inconclusive validation:** bounded exploration exhausts its resources, reachability analysis cannot terminate, or approval is based only on successful serialization, footprints, graph sizes, or visualization.

# 8. Canonical Representation Recommendation

- **Authoritative storage:** Keep the versioned POWL definition—preferably its executable constructor together with a serialized form where supported—and the invariant/witness specification as the single editable source of truth.
- **Analysis snapshot:** Store `net_from_powl`, `im_from_powl`, and `fm_from_powl` as an immutable, source-hash-associated analysis artifact when Petri-net tooling is needed. It is authoritative only by derivation from that exact POWL version, not as an independently editable model.
- **Stakeholder visualization:** Use an annotated BPMN model from P1 only after its round trip and semantic review pass. If it fails, quarantine it and temporarily use an annotated POWL or Petri-net view rather than selecting a prettier but unvalidated tree-based BPMN model.
- **Derivative artifacts:** Both BPMN models, the process tree, all round-tripped nets, reachability graphs, footprints, playout samples, and images are derivative. None should be edited independently.

Each derivative should be accompanied by:

1. Source version/hash and Python/PM4Py versions.
2. Conversion parameters and complete exception logs.
3. Non-null-marking checks, workflow-net diagnostics, and soundness results.
4. Positive/negative witness results and visible-trace differences.
5. Exploration bounds, resource-truncation status, and the exact scope of any exhaustiveness claim.
6. Label and silent-routing-node mappings.
7. A clear distinction between behaviorally screened artifacts and illustrative-only renderings.

A process-tree intermediate should be optional and experimental. It should never be forced by adding order, removing silent behavior, or weakening the loop merely to make conversion succeed.

Future edits should be made to the POWL source, followed by one deterministic regeneration of all derivatives. Do not repeatedly edit BPMN, convert it back to a net or tree, and then treat that result as the new source. Requested stakeholder changes should first be expressed as reviewed POWL and invariant changes; otherwise round-trip drift becomes indistinguishable from intentional semantic change.

# 9. Residual Uncertainty

Even if every implemented test passes, the validation does not establish:

1. **Unbounded behavioral equivalence.** Two iterations and 12 visible activities do not cover arbitrary redo counts, longer silent paths, or every erroneous behavior of a candidate.
2. **True concurrency, temporal overlap, or performance.** Tau-hidden visible-trace comparison does not prove simultaneity, durations, fairness, absence of starvation, or actual runtime scheduling behavior.
3. **Complete equivalence of internal silent behavior.** Different silent nondeterminism or routing can sometimes produce the same bounded visible accepting language.
4. **Equivalence from footprints or graph counts.** Footprints are abstractions, and equal reachability-graph sizes do not establish graph isomorphism or preserve state labels and causal structure.
5. **Identical behavior in every BPMN tool or engine.** The audit concerns PM4Py’s converted artifacts; external BPMN importers may interpret rendering details, unsupported constructs, or execution semantics differently.
6. **Business correctness beyond the stated model.** The tests do not establish that legal review is legally sufficient, that evidence is adequate, or that activity labels and gateway conditions capture real organizational data and compliance rules.
