# 1. Assumptions, objectives, and decision variables

**A1 – Distributional model for service times.** The table gives only ranges plus a "complex-tail" probability. Absent further evidence I model each activity's service time as a **two-component uniform mixture**: with probability `(1-p_tail)` draw Uniform(ordinary_low, ordinary_high); with probability `p_tail` draw Uniform(complex_low, complex_high). This is the simplest model consistent with the given numbers. *Caveat (flagged, not resolved):* a hard-capped uniform tail almost certainly understates real tail risk (no field process has a strict maximum); a log-normal or Pareto tail is equally defensible and would raise p90/p95 estimates further. All tail/SLA numbers below should be read as **lower bounds on tail risk**.

**A2 – Resource multipliers apply multiplicatively** to the drawn base time: `actual = base_draw × resource_multiplier`. Handover/setup/coordination minutes are **additive delays**, not multiplied by resource speed.

**A3 – ME/ES parallel-vs-sequential decision rule.** Parallel execution is chosen only when two *different* eligible resources are simultaneously idle at the moment the branch is ready to start; sequential execution is chosen only when a single cross-skilled resource (Ada: Mechanical+Electrical; Chen: Electrical+Software) is idle and would otherwise have to wait for a second resource. This is an **operational heuristic** (not a global optimum) chosen because it is auditable in real time: "use two hands if two hands are free now, otherwise let the one qualified pair-of-hands do both."
