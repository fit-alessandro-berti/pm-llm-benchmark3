## 3. Stage-by-stage decomposition

Calendar reference: Fri 18 Sep 15:30 now. Lab open Fri to 18:00 (2.5h), closed Sat-Sun, open Mon 08:00-18:00. QA open Fri to20:00, Sat09-13, Mon08-20.

**General logic: Join time T_join = max(T_chem_usable, T_micro_usable) in calendar time.** No sum. QA cannot start until both. After join, QA waiting + QA service + optional loops sequential; loops add working hours pauses.

### Scenario A - Smooth

*Chemistry waiting & service:* Two servers. Next free ~16:10 (B) / ~17:00 (A). Priority path (45%): B-417 gets slot ~17:05 Fri, works 0.9h to 18:00, pause 62h, resumes Mon08:00, needs remaining 0.6-3.6h => finishes Mon 08:36 (min) to 11:36 (max), central ~09:50-10:30. FIFO path (55%): B-417 not started Fri. Mon08:00 two servers resume partial jobs (remaining ~1.0h and ~1.9h), queue of 2 waiting ahead. B-417 starts ~11:30-12:00 Mon, service 1.5-4.5h => finishes 13:00 (min) to 17:30 (max), central ~14:00-15:00. Blend central ~10:30-14:30.

*Micro incubation & readout:* Ready Sun12:00-20:00. With authorization (35%): readout Sun13:30-00:30 Mon, central Sun18:00. Without (65%): Mon08:00 +0.5-1.5h => Mon08:30-09:30, central 09:00. So smooth micro central ~09:00 Mon if no on-call, Sun evening if on-call.

*Parallel join:* **Max**. If micro on-call Sun, T_join = T_chem (Mon09:30-15:00). If micro Mon09:00, T_join = max(chem priority ~09:50, micro09:00)= chem still, or max(chem FIFO14:00, micro09:00)= chem. So chemistry dominates smooth path. Tie only in priority+micro Mon case ~09:50.

*QA waiting & service:* Join Mon morning-afternoon when 2 reviewers active. Expected Q at join ~2-4 (from 5 -2.3 Fri -2 Sat +2.7 arrivals -2 Mon AM). Waiting ~ (Q/2)*mean ~0.75-2.5h central 1.5h; p80 queue 5 => 3-4h wait. Service median1.5h p803.5h. So QA done 2.5-6h after join central ~3.5h.

*Rework/investigation:* none.

*Final release:* +0.25-0.75h continuous => Term as in table.

### Scenario B - Chemistry rerun

*Chemistry first pass* as in A to Mon 08:36-17:30. *Borderline detection* at readout (end of service). With excursion, p~0.25 vs 0.13 otherwise. Rerun gets priority. If first pass finished Mon morning (priority path, 10:00) rerun can start ~10:30 Mon, needs 1.0-3.0h => finishes 11:30-13:30 same day, no pause. If first pass finished Mon afternoon (FIFO, 14:30) rerun starts 14:30, needs 1.93h avg => finishes 16:25 avg, max 17:30; if max 3.0h from 15:00+ => would hit 18:00 pause, spill to Tue08:00-08:30. Central rerun finish Mon16:00-Tue09:30.

*Micro* same as A (Mon09:00 or Sun). Now **Max shifts**: after rerun, micro already done, so rerun completion = T_join.

*QA* same as A but shifted +2-3h (or overnight if spill). Waiting still 1-3h Tue AM if spill. QA service 1.5-3.5h.

*Investigation probability* now 30-55% vs 7% -> further tail risk (see D). If investigation not triggered, term as B table.

### Scenario C - Delayed microbiology

*C1 - Weekend delay without contamination:* Identical to A except authorization denied is the common case (65%). T_micro=Mon09:00 not Sun. Still chemistry dominates except priority early chem tie. Adds no extra vs smooth central but explains why micro not Sun.

*C2 - Contamination:* First incubation Sun12:00-20:00 + readout (if on-call Sun or Mon09:00). Contamination signal triggers second incubation 20-30h continuous immediately. So second ready = Sun12:00+20h=Mon08:00 earliest to Sun20:00+30h=Tue02:00 latest, central Sun16:00+25h= Tue? Let's compute: Sun16:00+25h=Mon17:00. Most mass Mon08:00-Mon20:00. Readout requires microbiologist (Mon staffed 08-18, no weekend issue for second read except if ready Tue02:00 waits to Tue08:00). So usable Mon08:30-20:00 central Mon17:30, late Tue09:30.

*Chemistry* as in A finishes Mon09:30-15:00, then **waits idle** for micro: **Max = micro** now. Idle gap Mon AM to Tue AM.

*QA* join now Mon evening-Tue AM when QA capacity is Mon 08-20 (2 reviewers) or Tue. If join Mon17:30, QA wait 1-2h + service => finish Mon20:00- Tue01:00 but QA closed 20:00- next day 08:00 => pause. Working-hours conversion: service not paused if in progress? QA service paused at 20:00. So Mon evening join may not finish before 20:00, spills to Tue08:00. If join Tue09:00, QA same-day. Central QA done Tue14:00-Wed11:00.

*Chemistry idle does not add to total beyond Max.*

### Scenario D - QA query / investigation

*Pre-QA* as in A/B/C. *Join* as before. *QA first review* 1.5-3.5h. Query p0.22 adds 4-12 working-hours **before QA can resume**. Working-hours: QA open 12h M-F (8-20) +4h Sat. So 4h = same day afternoon; 12h = next day 08:00-12:00 equivalent. E.g., query raises Mon15:00, +8 working-h = Tue09:00 effective resume (Mon 5h left to20:00 +3h Tue). So adds ~0.5-1.5 calendar days.

*Doc-only investigation* (60-80% of investigations) adds 8-20 working-hours similarly = 1-2 calendar days (Mon->Tue/Wed, Tue->Wed/Thu). *Lab investigation* (20-40%) adds 3-7 calendar days continuous lab work, not gated by QA calendar except final review.

*Total* = Max(branch) + QA_wait + QA_service1 + rework + QA_service2 + release. Not sum of branch services.

## 5. Main uncertainty drivers

1. **Temperature-excursion confirmation - dependence uncertainty** - Common-cause correlation lifts p(rerun), p(contamination) and p(investigation) jointly. Creates joint-tail heaviness that cannot be added as independent events. Sensitivity: confirmed vs cleared swings tail probability ~2x.

2. **Chemistry queue discipline + Monday spillover - queue + calendar uncertainty** - FIFO vs priority decides whether B-417 starts Fri17:05 (pause-resume) vs Mon11:30. Determines chemistry finish ±4h and whether rerun spills Tue. Weekend pause makes this a calendar cliff.

3. **QA queue at future join + QA service skew - queue + service-time uncertainty** - Q at Mon/Tue join depends on arrivals/completions Fri-Sat-Mon with overdispersion (interval 1-6). Service p50 1.5h p80 3.5h adds right skew. Together they add 1-6h central but 8-12h tail via query/investigation triggers.

4. **Microbiology contamination indication (+ weekend microbiologist authorization) - path + calendar uncertainty** - Contamination 5-12% (higher if excursion) adds 20-30h continuous incubation and flips dominant branch from chemistry to microbiology. Authorization 0.25-0.45 decides Sun vs Mon read for first incubation (2-14h swing), but contamination decides Tue vs Mon dominance (~24h swing).

5. **Investigation type (doc-only vs lab) - path uncertainty (with proportion uncertainty)** - Conditional on investigation (7% normal, 42% if anomaly), doc-only 60-80% adds 8-20 working-hours (1-2d), lab 20-40% adds 3-7 calendar days. Which regime materializes moves terminal from Wed to next Mon/Tue, i.e., largest calendar magnitude.
