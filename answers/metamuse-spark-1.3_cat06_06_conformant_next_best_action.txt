## 3. Benefit and harm reasoning
No single utility function; use ranges + dominance + asymmetry + (non-)transportability.

- Stakes: deadline value €20k-€35k; false-reject/hold €15k-€80k; unlawful execution €100k-€500k+ plus non-monetary (licence, criminal referral, debarment, reputational, personal liability). The third category lexically dominates the first in compliance-aware ranking: even 0.1 probability × €100k-€500k = €10k-€50k expected, overlapping/exceeding the entire deadline benefit, before adding non-monetizable harm. With fuzzy 0.46 unresolved + score 72 (70) + border-region + stale timestamp, probability of true-hit is non-negligible and unquantified; cannot be set to zero by operational forecast.
- Predictions are observational: SLA breach 0.48-0.64 under continue normal processing; approval 0.55-0.75 after conformant review. They do not transport unchanged under intervention. Speeding via A/B breaks the control that generated the approval data, so 0.55-0.75 cannot be used as P(approve | self-certify) or P(safe | execute now). Similarly, interrupting P-901 changes P-901 breach mechanism; 0.12-0.28 increment is an estimate with wide interval.
- Dominance: Any CURRENTLY NONCONFORMANT execution (A,B) is dominated by conformant review options (C, DS4) on compliance-adjusted harm, even though it dominates on P-884 timeliness alone. Weak analysis optimizes only €20k-€35k. Correct analysis blocks the trade: regulatory/non-monetary harm is not commensurable discount for bypass.
- Among conformant options: DS4 vs C is timeliness vs spillover. C buys ~20-30m earlier review start at cost +0.12-0.28 breach to P-901 (also high-value, tighter 70m deadline). DS4 preserves P-901 + gains information for 1 API unit, at cost higher P-884 breach risk. E vs F: E preserves option value (0.55-0.75 approve chance) at cost certain deadline loss; F crystallizes false-reject risk (0.55-0.75 × €15k-€80k  €8k-€60k expected) to save time/resources. Since deadline is already at risk (0.48-0.64), sacrificing option value via premature reject is not justified without meeting rejection threshold. G as standalone gambles remaining slack (20-60m) on low-probability enablement; as parallel hedge with capped effort it has small cost, as sequential plan it dominates nothing.
- Uncertainty handling: use intervals throughout, prefer reversible/hold steps (screen, queue) over irreversible (execute, reject), refresh stale score before second review, treat screening/SAR/re-screen as uncertainty reducers, never as substitutes for mandatory review.

## 5. Resource spillovers
- S2 vs S4: S2 is immediate but costs P-901: 45m interruption, +0.12-0.28 breach prob, P-901 deadline 70m < P-884 90m, also high-value, so spillover is material and likely larger in absolute loss than P-884 gain if both values similar. S4 costs no P-901 harm but costs P-884 time: wait 35-65m overlapping with 15-30m screen, then 35-75m review. S2 minimizes P-884 breach; S4 minimizes system breach.
- API quota: 3 expedited calls left. D uses 1, leaves 2. Low system cost relative to P-901 interruption. Must not waste: use only because result can change Second Officer decision (Approve vs Reject/Hold) and documents diligence on 0.46 fuzzy; do not repeat if inconclusive unless S4 requests. Preserve 2 for P-901 or other sanction-border cases.
- Exception waiting risk: pursuing G sequentially consumes 20-60m of 90m slack with low success prob, pushing even conformant fallback past deadline. Cap G effort, run at most in parallel with DS4 (e.g., one paging attempt), never as substitute for queueing S4/S2.
- 35m vs 65m S4 sensitivity: If S4 in 35m (low end): DS4 total ~75-115m [35+35-65+5-15], lower end meets 90m, dominates C — no reason to harm P-901. Ranking 12 holds. If S4 in 65m (high end): DS4 total ~105-155m, near-certain breach; C total 40-90m becomes only conformant path to preserve deadline. Then decision is system-level: accept P-884 breach (lose €20k-€35k, hold harm) vs impose P-901 breach (+0.12-0.28). Without values for P-901, default is do not interrupt: accept P-884 breach (conformant hold) over harming another high-value case. Escalate to supervisor with both deadlines/amounts; interrupt S2 only with explicit documented acceptance of P-901 impact and time-box (e.g., proceed to S2 only if S4 delay confirmed >45m at T+20m and P-884 approval likelihood remains 0.5 after screening). Thus ranking flips conditionally: S4-early => 1>DS4, 2=C distant; S4-late => 1 and 2 near-tied, choice governed by governance, with E (accept breach) as ethically safe default over unapproved interruption.
