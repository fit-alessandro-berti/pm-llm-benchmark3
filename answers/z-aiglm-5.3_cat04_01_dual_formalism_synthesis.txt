```python
from pm4py.objects.process_tree.obj import ProcessTree, Operator

def leaf(label: str) -> ProcessTree:
    """Visible activity (operator=None, label set)."""
    return ProcessTree(operator=None, parent=None, label=label)

def silent() -> ProcessTree:
    """Silent transition (operator=None, label=None)."""
    return ProcessTree(operator=None, parent=None, label=None)

def op(operator: Operator, *children: ProcessTree) -> ProcessTree:
    """Operator node; children appended and parent pointers set explicitly."""
    node = ProcessTree(operator=operator, parent=None, label=None)
    for child in children:
        node.children.append(child)   # explicit parent/child handling
        child.parent = node
    return node

SEQ, XOR, PAR, LOOP = (Operator.SEQUENCE, Operator.XOR,
                       Operator.PARALLEL, Operator.LOOP)

# leaves
RD  = leaf("Register Deviation")
CM  = leaf("Contain Material")
ARC = leaf("Analyze Root Cause")
PV  = leaf("Plan Verification")
DCA = leaf("Design Corrective Action")
SR  = leaf("Supervisor Review")
QR  = leaf("Quality Review")
RR  = leaf("Regulatory Review")
CS  = leaf("Consult Supplier")
ET  = leaf("Execute Trial")
IT  = leaf("Inspect Trial")
AP  = leaf("Adjust Parameters")
RM  = leaf("Release Material")
AC  = leaf("Archive Case")

# stream 1: containment -> verification planning
stream_contain = op(SEQ, CM, PV)
# stream 2: root cause -> corrective-action design
stream_rootcause = op(SEQ, ARC, DCA)
# the two streams run concurrently; a barrier joins them
streams = op(PAR, stream_contain, stream_rootcause)

# approval route: exclusive choice, selected once per case
route = op(XOR, SR, op(PAR, QR, RR))

# optional supplier consultation: 0..1 times
consult = op(XOR, CS, silent())

# trial cycle: (Execute Trial -> Inspect Trial) ( Adjust Parameters ... )*
trial = op(LOOP, op(SEQ, ET, IT), AP)

# post-barrier work: route, consultation, trial mutually concurrent
post = op(PAR, route, consult, trial)

tree = op(SEQ, RD, streams, post, RM, AC)
```

# 1. Assumptions and Interpretation

Numbered list:

1. **Risk route as an exclusive choice.** The low/high risk attribute is data not visible in control flow. It is represented as an XOR between a low-risk branch (exactly `Supervisor Review`) and a high-risk branch (`Quality Review`  `Regulatory Review`, unordered). Exactly one branch executes per case; no re-routing mid-case. The model's language contains both route alternatives, and each concrete case realizes one.

2. **Optional supplier consultation as XOR with silence.** `Consult Supplier` is modeled as XOR(CS, ): zero or one occurrence per case. The silent branch encodes "not selected." The unmodeled decision data only decides *which* branch; control flow only enforces the boundaries (not before ARC completes, not after RM).

3. **Passing inspection is positional, not labeled.** The inspection result is not an event. It is abstracted structurally: the trial construct has language (ET IT)(AP ET IT)*, so the *last* `Inspect Trial` of a case is by construction the passing one, and any `Inspect Trial` that is followed by `Adjust Parameters` is a failing one. "AP must never occur after the passing inspection" therefore holds by construction (AP is always followed by a fresh ET–IT cycle).

4. **No duplicate visible labels.** Each of the 14 labels corresponds to exactly one visible node in each model. Duplication was considered as a tree-repair strategy and rejected (see §3); consequently both models are safe for alignment-based conformance, and "at most once" constraints (route, CS) are structural.

5. **Approximation policy for the tree: conservative under-approximation.** The process tree inserts one synchronization barrier after the two initial streams. The approval route and the supplier consultation cannot start before the barrier (i.e., before CM, PV, ARC, DCA have all completed), although the intended behavior lets them start right after ARC. The tree therefore *excludes* some intended traces but *admits no* disallowed trace: L(tree)  L(intended). A permissive over-approximation (putting route/CS in parallel with the streams) would admit unsafe behavior such as a review before root-cause analysis and was rejected for a compliance-critical process.

6. **"May overlap" = absence of ordering constraint (model-level concurrency).** It is interpreted as permission, not obligation: all interleavings of the concurrent parts are in the language, including fully sequentialized ones. Since the log records completion times only, a genuine interval overlap projects to one of the completion orders; the models accept every such projection. The models do not (and cannot) force simultaneous execution.

7. **Completion-time semantics.** All constraints are on the order of recorded completion events. "A may start only after B is complete" is enforced as "A is recorded after B," which is equivalent for start constraints (an activity that starts after B completes must complete after B completes). The converse (detecting an activity that started too early but completed late) is beyond any completion-based model.

8. **At least one trial per case.** Release requires a passing inspection, so every case executes at least one ET–IT cycle; zero-trial cases are not in the language.

9. **Closed world.** Only the 14 activities (plus internal silence) exist. Resources, durations, batching, and data other than what is encoded positionally are out of scope.

10. **Framing.** `Register Deviation` is strictly first and `Archive Case` strictly last; each occurs exactly once; every other activity occurs at most once except the trial-cycle activities (ET, IT repeatable; AP repeatable only between failed IT and next ET).

from pm4py.objects.process_tree.obj import ProcessTree, Operator

# ---------------------------------------------------------------- helpers
def leaf(label):
    """Visible activity: operator None, label set."""
    return ProcessTree(operator=None, parent=None, label=label)

def silent():
    """Silent transition (tau): operator None and label None."""
    return ProcessTree(operator=None, parent=None, label=None)

def op(operator, *children):
    """Operator node. PM4Py requires explicit parent/child bookkeeping:
    each child is appended to parent.children and gets .parent set."""
    node = ProcessTree(operator=operator, parent=None, label=None)
    for child in children:
        node.children.append(child)
        child.parent = node
    return node

import pm4py
from pm4py.objects.log.obj import EventLog, Trace, Event

RD, CM, ARC, PV, DCA = ("Register Deviation", "Contain Material",
                        "Analyze Root Cause", "Plan Verification",
                        "Design Corrective Action")
SR, QR, RR, CS = ("Supervisor Review", "Quality Review",
                  "Regulatory Review", "Consult Supplier")
ET, IT, AP = "Execute Trial", "Inspect Trial", "Adjust Parameters"
RM, AC = "Release Material", "Archive Case"

def respects_intent(seq):
    """Oracle for the intended language (Section 1 reading of the narrative)."""
    if len(seq) < 6 or seq[0] != RD or seq[-1] != AC or seq[-2] != RM:
        return False
    n = {l: seq.count(l) for l in set(seq)}
    for l in (RD, CM, ARC, PV, DCA, RM, AC):
        if n.get(l, 0) != 1:
            return False
    low  = n.get(SR, 0) == 1 and n.get(QR, 0) == 0 and n.get(RR, 0) == 0
    high = n.get(SR, 0) == 0 and n.get(QR, 0) == 1 and n.get(RR, 0) == 1
    if not (low or high):                      # exactly one complete route
        return False
    if n.get(CS, 0) > 1:                       # consultation at most once
        return False
    proj = [e for e in seq if e in (ET, IT, AP)]   # trial projection
    if len(proj) < 2 or proj[0] != ET or proj[1] != IT or proj[-1] != IT:
        return False
    i = 0                                       # must equal (ET IT)(AP ET IT)*
    while i < len(proj):
        if proj[i] != ET or i + 1 >= len(proj) or proj[i + 1] != IT:
            return False
        i += 2
        if i < len(proj):
            if proj[i] != AP:
                return False
            i += 1
    first, last, pos = {}, {}, {}
    for k, e in enumerate(seq):
        first.setdefault(e, k)
        last[e] = k
        pos[e] = k                              # valid for once-only activities
    if not (pos[CM] < pos[PV] and pos[ARC] < pos[DCA]):
        return False
    route_ev = [e for e in (SR, QR, RR) if e in pos]
    if any(pos[e] < pos[ARC] for e in route_ev):
        return False
    if CS in pos and not (pos[ARC] < pos[CS] < pos[RM]):
        return False
    if first[ET] < pos[PV] or first[ET] < pos[DCA]:
        return False
    if pos[RM] < max(last[e] for e in route_ev + [ET, IT]):
        return False
    if CS in pos and pos[RM] < last[CS]:
        return False
    return True
