## 3. Diagnostic tests

*Label-maturity curves and fixed-vintage backtesting.* Compute breach at 30/60/90 day vintages for each start month. Under censoring hypothesis, Oct metrics improve with longer vintage and converge to Jul-Aug levels. Under true concept drift, vintage-converged metrics stay elevated even at full maturity.

*Recomputation after activity-label normalization and duplicate cleaning.* Re-normalize `Diagnostic Assessment Completed` -> `Initial Diagnosis Completed`, drop duplicates on case_id+activity+timestamp, recompute all derived features for Apr-May. Under pipeline failure, AUROC/ECE for Apr recover to Jan-Mar baseline and mean predicted risk aligns with observed breach. Under true drift, metrics remain degraded after cleaning.

*Calibration and discrimination stratified by variant, source and month.* AUROC/Brier/ECE per V1/V2/V3 and Partner Z vs non. Under covariate drift only, within-stratum metrics stable, degradation only in pooled metrics. Under concept drift, V3 stratum AUROC/ECE degrades while V1/V2 stable.

*Comparison of process variants and DFG/performance-DFG edges.* Discover DFG and performance DFG per month. Under process drift, variant proportions and edge latencies change but conditional outcome given variant is stable. Under concept drift, conditional outcome given same variant and same latency changes.

*Test of outcome relationship conditional on same path.* Fit model on Jan-Mar, evaluate on later months with propensity-weighted reweighting to Jan-Mar variant mix. Under pure covariate drift, performance recovers after reweighting. Under concept drift, performance remains degraded after reweighting.

*Population reweighting / transport checks for Partner Z.* Reweight Sep-Oct to Jan-Mar source distribution using rural distance and device age. Under population shift only, calibrated risk aligns after reweighting. Under model misspecification, residual miscalibration persists.

*Feature missingness and lineage audits.* Audit missing queue feature, unknown activity share, feature derivation timestamps. Under pipeline failure, missingness correlates with metric degradation. Under drift, missingness is low.

## 5. Monitoring architecture

Monitors:
* Predictive: AUROC, Brier, ECE by month, variant, source.
* Calibration: reliability diagrams with alert on ECE >0.06.
* Label maturity: % mature and median label delay by start month; alert if <90%.
* Data quality: unknown activity share, missing feature rate, duplicate rate, label normalization coverage.
* Process variant: monthly variant proportions vs baseline, chi-square drift test.
* Performance-DFG: median edge latency for `Order Part -> Part Received`, `Diagnosis -> Remote Fix`. Alert on >2 change.
* Population: Partner Z share, rural distance and device age distributions.
* Intervention/deployment: model version, feature lineage hash, backfill events.

Alert dependencies: label-maturity alert suppresses retraining triggers. Data-quality alert suppresses concept-drift alerts until resolved.

```python
import pandas as pd
from pm4py import format_dataframe, filter_time_range, discover_dfg, discover_performance_dfg, get_variants
from pm4py.objects.conversion.log import converter as log_converter

def monthly_process_evidence(csv_path):
    df = pd.read_csv(csv_path, parse_dates=['timestamp','case_start'])
    df = format_dataframe(df, case_id_key='case_id', activity_key='activity', timestamp_key='timestamp')
    # normalize renamed diagnosis
    df['activity'] = df['activity'].replace({'Diagnostic Assessment Completed':'Initial Diagnosis Completed'})
    # duplicate handling
    df = df.sort_values(['case_id','timestamp']).drop_duplicates(subset=['case_id','activity','timestamp'], keep='first')
    # case start cohort
    cases = df.groupby('case_id')['case_start'].min().reset_index()
    summary = []
    for y,m in [(2026,mo) for mo in range(1,11)]:
        month_start = pd.Timestamp(year=y, month=m, day=1)
        month_end = month_start + pd.offsets.MonthBegin(2) - pd.Timedelta(days=1)
        # event-calendar cohort
        ev = filter_time_range(df, month_start, month_end)
        # case-start cohort
        cs_ids = cases[(cases['case_start']>=month_start)&(cases['case_start']<=month_end)]['case_id']
        cs = df[df['case_id'].isin(cs_ids)]
        for name, log in [('event_calendar',ev),('case_start',cs)]:
            if log.empty: continue
            dfg = discover_dfg(log)
            perf_dfg = discover_performance_dfg(log)
            variants = get_variants(log)
            # auditable summaries
            summary.append({
                'month': f'{y}-{m:02d}',
                'cohort': name,
                'cases': log['case_id'].nunique(),
                'variants': len(variants),
                'unknown_activity_share': (log['activity']=='UNKNOWN_ACTIVITY').mean(),
                'median_order_to_part': perf_dfg.get(('Order Part','Part Received'),{}).get('median',None)
            })
    return pd.DataFrame(summary)
```

## 6. Risks of acting on the wrong diagnosis

*Retraining on immature labels.* Using Oct 55% mature labels teaches the model to predict censoring, biasing risk down for long-path V3 cases. Mitigation: enforce fixed-vintage backtesting and minimum 90% maturity before inclusion.

*Calibrating around a pipeline bug.* Applying Platt scaling to April’s inflated mean risk would bake in the label-mismatch error. After the schema is fixed the calibration would be inverted. Mitigation: fix lineage first, quarantine affected months, then recalibrate.

*Ignoring genuine supplier-driven concept drift.* Treating Aug-Sep AUROC drop as only covariate drift would leave V3 under-predicted as part lead times stay high. Mitigation: monitor performance DFG edges and add lead-time features; validate conditional outcome given variant.

*Attributing Partner Z shift to unfair model behavior without stratified evidence.* Pooling metrics would suggest systematic under-prediction and trigger unnecessary fairness interventions. In reality it is population shift and missing features. Mitigation: stratify by source, audit feature coverage, reweight before concluding bias.

*Over-reacting to June mix change.* Retraining for June remote-routing policy would discard stable within-variant relationships. Mitigation: separate covariate shift detection from concept drift; use reweighting and variant-stratified monitoring.
