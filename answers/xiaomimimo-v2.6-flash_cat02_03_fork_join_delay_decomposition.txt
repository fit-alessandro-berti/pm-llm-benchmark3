def decompose(d):
    out = d.copy()
    out["upstream_elapsed"] = mins(out["fork_release"], out["arrival"])
    for b in BR:
        out[f"{b}_queue"]   = mins(out[f"{b}_start"], out["fork_release"])
        out[f"{b}_service"] = mins(out[f"{b}_end"], out[f"{b}_start"])
        out[f"{b}_span"]    = out[f"{b}_queue"] + out[f"{b}_service"]
    # join_ready is NOT logged: derived as max branch completion (fork-join rule)

# 1. Delay-decomposition definitions

**Notation.** Case index \(c \in \{1,\dots,12\}\), branch index \(i \in \{A,B,C\}\). Logged timestamps: \(t^{arr}_c\) (`arrival`), \(t^{fork}_c\) (`fork_release`), \(t^{i,start}_c, t^{i,end}_c\), \(t^{fs}_c\) (`final_start`), \(t^{fe}_c\) (`final_end`).

**Assumptions (labelled):**

- **[A1] Join rule (given):** `final_start` may not precede completion of *all* branches, so the (unlogged) join time is \(J_c := \max_i t^{i,end}_c\).
- **[A2] Fork semantics (given):** no branch may start before \(t^{fork}_c\). *Verified in data:* \(t^{A,start}_c=t^{fork}_c\) for all 12 cases, and all \(t^{i,start}_c \ge t^{fork}_c\).
- **[A3] Non-preemption / complete events (given):** intervals are contiguous and accurate to 1 minute.
- **[A4] Counterfactual direct-effect assumption:** downstream queueing is held at its observed value when a branch is accelerated (stated again in §4).
- **[A5] F01 is the first case of the day** (not stated; needed only to interpret F01's shorter upstream and downstream values).

**Components (per case, per branch):**

$$U_c = t^{fork}_c - t^{arr}_c \quad \text{(upstream elapsed)}$$

$$Q^i_c = t^{i,start}_c - t^{fork}_c \ \ (\ge 0) \quad \text{(branch queue)}$$

$$S^i_c = t^{i,end}_c - t^{i,start}_c \quad \text{(branch service)}$$

$$Span^i_c = Q^i_c + S^i_c = t^{i,end}_c - t^{fork}_c \quad \text{(forkcompletion of }i)$$

$$J_c = \max_i t^{i,end}_c = t^{fork}_c + \max_i Span^i_c \quad \text{(join\_ready, derived)}$$

$$W^i_c = J_c - t^{i,end}_c \ge 0 \quad \text{(synchronization wait after branch }i\text{)}$$

$$E_c = J_c - t^{fork}_c = \max_i Span^i_c \quad \text{(elapsed fork–join stage time)}$$

$$D_c = t^{fs}_c - J_c \ge 0 \quad \text{(downstream queue)},\qquad R_c = t^{fe}_c - t^{fs}_c \quad \text{(final service)}$$

$$T_c = t^{fe}_c - t^{arr}_c = U_c + E_c + D_c + R_c \quad \text{(total flow time — exact telescoping)}$$

**Critical branch:** \(i^\*_c = \arg\max_i Span^i_c\), deterministic label = smallest index in order \(A<B<C\) when two spans tie (verified: **no exact ties** in the 12 cases).

## Why summing branch synchronization waits double counts elapsed time

Two identities hold for every case:

1. **Per branch:** \(Span^i_c + W^i_c = E_c\) for *every* \(i\). Summing over the three branches:
$$\sum_i \left(Q^i_c + S^i_c\right) + \sum_i W^i_c = 3E_c$$
2. **Interval nesting:** each \([t^{i,end}_c,\,J_c]\subseteq[t^{fork}_c,\,J_c]\), i.e. every synchronization wait is a *sub-interval of the stage's own wall-clock time*, and the non-critical branches' waits overlap each other (e.g. F07: \(W_A=[10{:}30,10{:}55]\subset W_C=[10{:}03,10{:}55]\)).

Numerically over the whole run:

| quantity | minutes |
|---|---:|
| \(\sum_c E_c\) (true stage elapsed) | 732 |
| \(\sum_c\sum_i (Q+S)\) = \(\sum Q + \sum S = 355 + 1292\) | 1 647 |
| \(\sum_c\sum_i W\) = \(W_A{+}W_B{+}W_C = 132 + 52 + 365\) | 549 |
| \(1647 + 549\) | **2 196 = 3 × 732** |

So (mode A) adding the 549 minutes of synchronization wait to the 732 minutes of stage time re-counts 549 minutes of wall clock that lie *inside* those 732; (mode B) summing \((Q+S+W)\) across branches triple-counts the stage (2 196 vs 732, a 1 464-minute overstatement). A quick falsification test: in **F07** and **F12**, \(W_A+W_B+W_C = 77 > E_c = 75\) — a naive sum already *exceeds* the elapsed time it is supposed to describe.

**The non-double-counted decomposition has exactly two layers:**

- **Stage layer (additive, exhaustive):** \(T_c = U_c + E_c + D_c + R_c\).
- **Branch layer (diagnostic, only the critical path is additive):** \(E_c = Q^{i^\*}_c + S^{i^\*}_c\); for \(i \ne i^\*\), \(Span^i_c + W^i_c = E_c\) is an identity, not an addition to \(E_c\).
