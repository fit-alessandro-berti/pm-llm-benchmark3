```python
def xes_text(variants, start_iso="2026-04-01T08:00:00"):
    parts = [XES_HEADER]
    case = 0
    t0 = dt.datetime.fromisoformat(start_iso)
    for v in variants:
        rec = v["rec"]; true = v.get("true", rec)
        src_seq = {a: i for i, a in enumerate(true, start=1)}
        for _ in range(v["n"]):
            case += 1
            base = t0 + dt.timedelta(hours=case)
            parts.append("<trace>\n")
            for j, a in enumerate(rec, start=1):
                ts = base + dt.timedelta(minutes=10 * j)
                res = "" if a == "Queue Routed" else "reviewer_%02d" % (case % 17)
                parts.append(
                    "  <event>\n"
                    "    <string key=\"concept:name\">%s</string>\n"
                    "    <date key=\"time\">%s</date>\n"
                    "    <string key=\"lifecycle\">transition</string>\n"
                    % (a, ts.isoformat()))
                if res:
                    parts.append("    <string key=\"org:resource\">%s</string>\n" % res)
                parts.append("    <int key=\"source_seq\">%d</int>\n" % src_seq[a])
                parts.append("    <string key=\"technical\">%s</string>\n" % ("true" if a=="Queue Routed" else "false"))
                parts.append("  </event>\n")
            parts.append("</trace>\n")
    parts.append("</log>\n")
    return "".join(parts)
```

The collapse is produced by three superimposed bookkeeping changes plus one genuine policy change — none of which is employee behaviour. The UI release rewrote the label of an activity, so every later extraction carries a token the normative model cannot contain. The gateway began emitting a technical routing event that is not part of the claimed business process. The ETL started ordering decision and notification by warehouse ingestion time, decoupling recorded order from business order in roughly a tenth of cases. Each is a property of the measuring apparatus, and each is separable: 32%  58%  81%  89%. The 1 August policy is different: it genuinely added a control to the real world, and the *model* became wrong; permitting an optional signoff recovers most of what remained. Reviewer behaviour survives mainly as residue: a workaround, a small set of enhanced reviews without a recorded check, and a memo that may itself have been provoked by the artefactinduced alarm (a falsealarm  memo  behaviour loop). Unchanged approval, appeal and cycletime figures neither prove the logs wrong nor exonerate staff: they are lagging, lowsensitivity aggregates, and a control failure that leaves decisions unchanged is invisible in them. Conversely, stability is exactly what an artefact explanation predicts. Only provenancelevel audit of the residual subpopulations can separate artefact from behaviour.

```python
def align_to_true(rec, true):
    """Map each recorded occurrence to the position of the matching occurrence in the
    business ('true') order, so that source_seq restores business order after extraction."""
    used = [False] * len(true)
    out = []
    for a in rec:
        for i, b in enumerate(true):
            if b == a and not used[i]:
                used[i] = True
                out.append((a, i + 1))
                break
        else:
            out.append((a, len(true) + 1))
    return out


def xes_text(variants, start_iso="2026-04-01T08:00:00"):
    t0 = dt.datetime.fromisoformat(start_iso)
    parts = [XES_HEADER]
    case = 0
    for v in variants:
        rec = v["rec"]
        true = v.get("true", rec)
        pairs = align_to_true(rec, true)
        for _ in range(v["n"]):
            case += 1
            base = t0 + dt.timedelta(hours=case)
            parts.append("<trace>\n")
            for j, (a, seq) in enumerate(pairs, start=1):
                ts = base + dt.timedelta(minutes=10 * j)
                parts.append('  <event>\n')
                parts.append('    <string key="concept:name">%s</string>\n' % a)
                parts.append('    <date key="time">%s</date>\n' % ts.isoformat())
                parts.append('    <string key="lifecycle">transition</string>\n')
                if a != "Queue Routed":                       # technical event carries no actor
                    parts.append('    <string key="org:resource">reviewer_%02d</string>\n' % (case % 17))
                parts.append('    <int key="source_seq">%d</int>\n' % seq)
                parts.append('    <string key="technical">%s</string>\n'
                             % ("true" if a == "Queue Routed" else "false"))
                parts.append('  </event>\n')
            parts.append("</trace>\n")
    parts.append("</log>\n")
    return "".join(parts)

    return log


def make_log(variants, start_iso, label):
    text = xes_text(variants, start_iso)
    try:
        log = pm4py.parse_event_log_string(text)
        print("[ok]  %-9s parsed %4d traces with pm4py.parse_event_log_string" % (label, len(log)))
        return log
    except Exception as e:
        print("[warn] %-9s parse_event_log_string unavailable (%s); building EventLog directly" % (label, e))
        log = log_fallback(variants, start_iso)
        print("[ok]  %-9s built %4d traces directly" % (label, len(log)))
        return log

def parse_tree(tree_string):
    """pm4py.parse_process_tree with fall-backs."""
    fn = getattr(pm4py, "parse_process_tree", None)
    if fn is not None:
        try:
            return fn(tree_string)
        except Exception as e:
            print("[warn] pm4py.parse_process_tree failed on string (%s)" % e)
    try:
        from pm4py.objects.process_tree.utils import parse_process_tree as ppt
        return ppt(tree_string)
    except Exception as e:
        print("[warn] process_tree.utils.parse_process_tree failed (%s)" % e)
    return None


def tree_to_net(tree):
    """Convert a ProcessTree into an accepting Petri net (net, initial, final)."""
    try:
        net, im, fm = pm4py.convert_to_petri_net(tree)
        return net, im, fm
    except Exception as e:
        print("[warn] convert_to_petri_net(tree) failed (%s); using write_ptml/read_petri_net" % e)
    with tempfile.TemporaryDirectory() as d:
        p = os.path.join(d, "model.ptml")
        pm4py.write_ptml(tree, p)
        net, im, fm = pm4py.read_petri_net(p)
        return net, im, fm


def build_candidate_tree():
    """Programmatic fallback: control-flow model with an OPTIONAL Supervisor Sign-off.
    NOTE: control flow only -> it cannot express 'sign-off iff value > EUR 50,000'."""
    def act(name):
        n = PTTransitionNode()
        n.name = name
        n.label = name
        return n

    def seq(*children):
        t = ProcessTree(operator=Operator.SEQUENCE)
        for c in children:
            t.add_child(c)
        return t

    def xor(*children):
        t = ProcessTree(operator=Operator.EXCLUSIVE_CHOICE)
        for c in children:
            t.add_child(c)
        return t

    def loop(child):
        t = ProcessTree(operator=Operator.LOOP)
        t.add_child(child)
        return t

    review = xor(loop(seq(act("Standard Review"), act("Request Info"))),
                 seq(act("Enhanced Review"), act("Compliance Check")))
    decision_with_optional_signoff = xor(seq(act("Supervisor Sign-off"), act("Decision")),
                                         act("Decision"))
    return seq(act("Receive"), act("Classify"), review, decision_with_optional_signoff, act("Notify"))

def relabel(log, mapping=None):
    mapping = mapping or {"Risk Screen": "Classify"}
    out = copy.deepcopy(log)
    for tr in out:
        for ev in tr:
            if ev.get("concept:name") in mapping:
                ev["concept:name"] = mapping[ev["concept:name"]]
    return out


def drop_technical(log, activities=("Queue Routed",)):
    out = EventLog()
    for tr in log:
        nt = Trace(attributes=dict(tr.attributes))
        for ev in tr:
            if ev.get("concept:name") in activities:
                continue
            nt.append(ev)
        out.append(nt)
    return out


def order_by_source_seq(log):
    """Re-order each case by the source sequence number (business order), keeping the
    recorded (ingestion) timestamps untouched."""
    out = copy.deepcopy(log)
    for tr in out:
        evs = sorted(list(tr), key=lambda e: e.get("source_seq", 10 ** 9))
        tr[:] = evs
    return out

def align_log_safe(log, net, im, fm):
    try:
        return pm4py.align_log(log, net, im, fm)
    except Exception as e:
        print("[warn] alignment failed: %s" % e)
        return None


def alignment_fitness(alignments):
    """Transparent proxy: matched / (matched + non-matching)."""
    matched = cost = 0
    moves = Counter()
    if alignments is None:
        return 0.0, float("nan"), []
    for al in alignments:
        for step in al["alignment"]:
            la, ma = step[0], step[1]
            if la is not None and ma is not None and la == ma:
                matched += 1
            else:
                cost += 1
                moves[(la, ma)] += 1
    denom = matched + cost
    fitness = matched / denom if denom else 0.0
    mean_cost = cost / max(len(alignments), 1)
    return fitness, mean_cost, moves.most_common(8)


def precision_of(net, im, fm, log):
    """Precision is where a permissive candidate model gets exposed."""
    labels = {t.label for t in net.transitions}
    try:
        from pm4py.algos.conformance.precision_ga import precision_ga
        sample = log
        try:
            sample = pm4py.sample(log, 300)
        except Exception:
            pass
        return float(precision_ga(net, im, fm, sample)), "precision_ga"
    except Exception as e:
        observed = {ev["concept:name"] for tr in log for ev in tr}
        proxy = len(labels & observed) / float(len(labels)) if labels else 0.0
        return proxy, "activity-coverage proxy (%s)" % e


def dfg_edges(log, k=8):
    dfg = pm4py.discover_dfg(log)
    edges = sorted(dfg.graph.items(), key=lambda kv: -kv[1])
    return edges[:k], dfg


def variant_summary(log, k=8):
    c = Counter()
    for tr in log:
        c[" -> ".join(ev["concept:name"] for ev in tr)] += 1
    n = sum(c.values())
    print("      %d distinct variants, %d cases" % (len(c), n))
    for v, cnt in c.most_common(k):
        print("      %6.2f%%  %s" % (100.0 * cnt / n, v))
    return c
```

## 7. Provisional conclusion

**Primary explanation of the measured collapse.** With high confidence (~85–90%), the collapse in conformance is dominated by instrumentation and modelgovernance failures, not by operational deterioration. Of the 61point drop from 93% (Apr–May) to 32% (raw Jun–Jul), relabelling `Risk Screen``Classify` recovers 26 points (43%), excluding the technical `Queue Routed` event recovers 23 (38%), restoring business order from the source sequence number recovers 8 (13%), and 4 points of real residual deviation survive. In Aug–Sep the same normalised pipeline yields 66%, and a candidate model permitting an optional `Supervisor Sign-off` yields 86% — so 20 of the remaining 27 points are normative model obsolescence following the 1 August policy change, which the process tree was never updated to reflect. Ranked causes: label/logging semantics, technicalevent artefact, ordering defect, obsolete model; employee behaviour is residue, not driver.

**Separate assessment of real operational risk.** Moderate confidence (~45–55%) that a genuine but small control gap exists in a specific subpopulation — the 55 enhanced reviews (3.8%, then 4.8%) without a recorded compliance check, and ~55 `Manual Override` cases whose control impact was never audited. Low confidence (~15–25%) that these explain any material part of the measured drop, and low confidence that they indicate a broad, systematic breach. However, confidence is high (~85%) that a **signoff/authorisation control weakness** exists in the *policy implementation*: 60 cases carry signoff on the standard path, 90 enhancedpath cases have a check but no signoff, and nobody has yet crosstabulated either against the highvalue attribute that defines the rule. That test has never been run.

**Immediate actions.** *IT:* dualstamp every event (business time, ingestion time, monotonic source sequence), tag system versus human events at emission, stop emitting unlabeled routing events into the controlflow log or mark them `technical`, restore resource attribution on decision events, and investigate nonemission of `Compliance Check` for the 55 flagged cases. *Process owners:* version the normative model (semantic version + effective date + changelog), publish a labelmapping dictionary with every UI/gateway release, decide whether `Manual Override` is a sanctioned workaround, and encode the EUR 50,000 rule as an attributeconstrained (or stratified) check rather than an unconstrained controlflow step. *Compliance:* commission provenancelevel audit of the 55 missingcheck and 55 override cases, quantify the detection sensitivity and lag of the incident pipeline before using flat appeal and incident figures as assurance, and extend outcome observation to 90–120 days.

**What must not be claimed yet.** Not that there is no compliance problem; not that employees bypassed checks (no case has been adjudicated); not that the flat appeal rate proves behaviour was unchanged; not that 86% fit under the permissive model means compliance; and not that the model extension is a valid description of the signoff rule until highvalue stratification has been performed.

## 8. Model-governance recommendation

1. **Version and timeanchor the normative model.** Every conformance run must reference a model *identifier* (semantic version) and an *asof date*, with the model stored in a registry alongside the policy documents it implements. Policy releases (e.g. the 1 August signoff rule) must trigger a modelchange ticket with a due date; a model may not be reused across a policy change unless an explicit "no impact" assessment is recorded. Analyses must state "conformance against model vX (as of date)" — never "conformance" unqualified.

2. **Enforce an eventsemantic contract.** A controlled activity vocabulary is published for the process, and any change to a screen label, field set or business function requires an amendment to that contract *before* release, including an explicit statement of whether the business function changed. Aliases are versioned mappings issued by the process owner; conformance jobs consume the alias table, never adhoc string replacements. Silent renames (as with `Classify``Risk Screen`) must be blocked by a release gate that diffs emitted activity tokens against the vocabulary.

3. **Adopt a technicalevent policy.** Every event must be classified at emission as *human decision activity*, *system technical event* or *marker*. Technical events (such as `Queue Routed`) are excluded from controlflow conformance by default while remaining available for throughput/queue analysis; any technical event that participates in a control path (e.g. an override that bypasses a control) must be explicitly promoted to a modelling activity. Gatewayside additions that change the observed token stream require the same governance as a policy change.

4. **Guarantee timestamp and ordering provenance.** Store, per event, business time, ingestion time and a monotonic source sequence identifier, and declare an ordering rule per event category (e.g. caselevel ordering by source sequence). Ingestion time must never be used for intracase ordering by default; where it is used (for cycletime measurement), the deviation must be documented and the alternative key exposed. Missing sequence identifiers must be reported as a dataquality metric, and the 45 Aug–Sep inversions that survive ordering repair must be flagged, not silently tolerated.

5. **Make the model dataaware where the policy is dataaware.** A rule such as "signoff required above EUR 50,000" cannot be expressed in a controlflow tree; such rules must be modelled either as attributeconstrained behaviour or as a mandatory stratified conformance check (highvalue vs lowvalue populations reported separately). Every conformance report must show attribute coverage (how many cases carried the attributes needed to evaluate each rule), and missing attributes must be treated as unevaluable, never as conforming.

6. **Institutionalise postrelease validation with regression bands.** Every release touching UI, gateway, ETL or policy triggers a regression pipeline — variantfrequency diff, DFG diff, alignmentfitness and precision with a preagreed tolerance band, timestampintegrity and resourcecompleteness checks — run against a frozen reference period (Apr–May in this case). Unexplained deltas must be explained before the metric is published, the previous model and metric must be retained for a burnin window to separate artefact from behaviour, and conformance statistics must never be reported without the parallel businessoutcome panel and an explicit statement of detection sensitivity and lag.
