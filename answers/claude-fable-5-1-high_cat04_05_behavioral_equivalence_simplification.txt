# 1. Equivalence Notions

**Notation.** Visible labels are abbreviated in traces: `O` = Open Case, `A` = Analyze Revision, `C` = Check Revision, `P` = Approve Revision, `R` = Rework Case, `Z` = Close Case. A *complete run* of a model is a firing sequence from the initial marking to the final marking of the accepting Petri net obtained from the tree (equivalently: a full execution of the tree). `vis(σ)` deletes every `tau` from a run. `L(M) = { vis(σ) | σ complete run of M }` is the *visible language* (a set of complete traces, not prefix-closed). `#x(σ)` counts occurrences of label `x` in `σ`.

Both languages can be written in closed form (standard loop semantics: body once, then optionally `Rework` + body, repeated):

- `L(A) = O · Body_A · (R · Body_A)* · Z` with `Body_A = {AC, CA} · (P | ε)`.
  For `n ≥ 1` analysis attempts: `#A = n`, `#C = n`, `#R = n − 1`, `0 ≤ #P ≤ n`, and in each attempt `C` precedes `P` (if `P` occurs).
- `L(B) = O · shuffle(C, Body_B · (R · Body_B)*) · Z` with `Body_B = A · (P | ε)`.
  For `n ≥ 1`: `#A = n`, `#C = 1` (exactly one, at any position between `O` and `Z`), `#R = n − 1`, `0 ≤ #P ≤ n`.

**Visible trace equivalence (after hiding `tau`).** `A ≡_tr B` iff `L(A) = L(B)`. Only complete traces are compared; deadlocking or unfinished prefixes are not members. This is the strictest notion used here (it is finer than P1, P2, P3).

**Bounded visible-language equivalence (P3).** `L^{≤12,≤3}(M) = { σ ∈ L(M) : |σ| ≤ 12 ∧ #A(σ) ≤ 3 }`. `A ≡_P3 B` iff `L^{≤12,≤3}(A) = L^{≤12,≤3}(B)`. Equality is *evidence* for `≡_tr`; inequality within the bound is a *proof* of `≢_tr` (any bounded witness is also an unbounded witness).

**Business-relevant equivalence (P1, operational compliance).** Split a trace at every `R` into *attempt segments* `s_1 … s_n` (the last one ends at `Z`). P1 keeps all visible labels and the number/placement of `P`, but does not prescribe the order of `A` and `C` inside one attempt. Define `α1(σ)` = the sequence of segments where, inside each segment, the relative order of `A` and `C` is forgotten but everything else (which labels occur, how often, and the position of `P` relative to `A`/`C`) is kept. `A ≡_P1 B` iff `α1(L(A)) = α1(L(B))`. In addition P1 carries a compliance predicate `φ1(σ)`: "every segment contains exactly one `A` and at least one `C`". Two models can only be P1-equivalent if they agree on `φ1` for all traces.

**Abstracted dashboard equivalence (P2).** `α2(σ) = ( first(σ)=O ∧ last(σ)=Z , [#C(σ) ≥ 1] , #A(σ) , [#R(σ) ≥ 1] )`, defined only when `#A ≥ 1 ∧ #C ≥ 1`. `P` and `tau` are deleted; the interleaving of `A` and `C` is not part of `α2`. `A ≡_P2 B` iff `α2(L(A)) = α2(L(B))`.

**Duplicate labels.** Traces are sequences of labels; repeated occurrences of the same label (e.g. the two `C` in `O A C R A C Z`) are distinguished **only by position in the sequence**, not by identity or by which leaf produced them. Neither tree contains duplicate-labelled leaves (duplicate-label count 0 in both, Section 7), so every visible event maps to exactly one leaf; repetition arises solely from the loop operator. All four notions are therefore label-based.

# 2. Structural Comparison

| Feature | Model A | Model B | Semantic consequence |
|---|---|---|---|
| Loop scope | Loop body = `->( +(A, C), X(P, tau) )`; `C` is *inside* the redo-loop | Loop body = `->( A, X(P, tau) )`; `C` is *outside* the loop, in parallel with the whole loop | In A every attempt is re-checked; in B the check is a case-level activity independent of attempts |
| Min. `#C` | 1 (one loop body is mandatory) | 1 | Identical lower bound: the four traces with `n = 1` and `C` before `P` are the only shared traces |
| Max. `#C` | Unbounded; `#C = #A = n` | Exactly 1 | Any trace with `n ≥ 2` distinguishes the models: A needs `n` checks, B allows only one |
| Placement of `C` | Immediately before or after the `A` of the same attempt, always before that attempt's `P` and before the next `R`/`Z` | Anywhere between `O` and `Z`: before the first `A`, after `P`, between `R` and `A`, after the last `P`, … | B admits `C` after `P` (`O A P C Z`) and `C` detached from any attempt; A never does |
| Optional approval | `X(P, tau)` once per attempt, after both `A` and `C` | `X(P, tau)` once per attempt, after `A` only | `#P ∈ [0, n]` in both; but in A `P` is preceded by `C` in the same attempt, in B `P` and `C` are unordered |
| Concurrency | `+(A, C)` per attempt: 2 interleavings per attempt, local to the body | `+(C, loop)`: one `C` interleaved with an arbitrarily long sequence | A's concurrency is bounded per attempt; B's grows with trace length (`2n + #P` insertion points) |
| Join before `Z` | Loop exit → `Z` (the AND-join of `+(A,C)` is closed inside each body) | AND-join of `C` and the loop, then `Z` | Both guarantee `O` first and `Z` last; in B `Z` waits for the single `C` regardless of how many attempts ran |
| Silent behaviour | One `tau` leaf (skip approval) | One `tau` leaf (skip approval) | Same visible effect: `P` optional; the choice leaves no trace |

# 3. Verdicts

| View | Verdict | Confidence | Decisive reason | Caveat |
|---|---|---|---|---|
| Visible trace equivalence (unbounded) | not equivalent | Certain (proof) | `#C = #A` in A vs `#C = 1` in B; shortest witness `O A P C Z ∈ L(B) \ L(A)` (length 5); `L(A) ∩ L(B)` is exactly 4 traces | None: proof is by counting, independent of any bound |
| P1 – operational compliance | not equivalent | High | B admits `O A R A C Z`: attempt 1 has no `C` before `R` (violates `φ1`); B also allows `P` before `C`, changing approval placement, which P1 keeps visible | If P1 were weakened to "≥1 check per case", B would pass; that is not what P1 states |
| P2 – executive dashboard | equivalent only under stated abstraction | High (proof) | `α2(L(A)) = α2(L(B)) = { (true, true, n, [n ≥ 2]) : n ≥ 1 }`: `#A = n` and `#R = n − 1` in both, `#C ≥ 1` in both, `P`/`tau` hidden | Holds only because `#C` is collapsed to a Boolean and interleaving is ignored; any dashboard extension (count of checks, "checked after last analysis", approval rate) breaks it |
| P3 – bounded testing (≤12 events, ≤3 `A`) | not equivalent | Certain within the bound (exhaustive BFS) | 76 bounded traces in A, 85 in B, 4 common, 72 only-A, 81 only-B; neither inclusion holds | Bounded inequality proves unbounded inequality; bounded equality would not have proven equivalence |

# 4. Counterexample Traces

Both inclusion directions fail, so witnesses are given in both directions. Exact intersection: `L(A) ∩ L(B) = { O A C Z, O C A Z, O A C P Z, O C A P Z }`. Proof: for `n ≥ 2` a trace of A has `#C = n ≥ 2` (impossible in B) and a trace of B has `#C = 1 < n` (impossible in A), so the languages are disjoint for `n ≥ 2`; for `n = 1`, `L(A)` contributes `O·{AC,CA}·(P|ε)·Z` (4 traces) and `L(B)` contributes the shuffle of `C` with `A(P|ε)` (5 traces: the same 4 plus `O A P C Z`).

| Trace ID | Trace | Model A | Model B | First decisive semantic difference | Relevant view |
|---|---|---|---|---|---|
| T1 | `O A P C Z` | no | yes | Position 3: in A, `P` (`X(P,tau)`) is only enabled after both `A` and `C` of the attempt; in B `C` is concurrent with the loop and may fire after `P` | P1 (approval placement), P3 |
| T2 | `O A R A C Z` (two attempts) | no | yes | Position 3: `R` fires while attempt 1 has no `C`; in A the AND-join of `+(A,C)` must complete before `X(P,tau)` and the loop redo | P1 (`φ1` violated), P3 |
| T3 | `O A R C A Z` (two attempts) | no | yes | Position 3 (same as T2); additionally `C` appears between `R` and `A` of attempt 2, a placement A never produces | P1, P3 |
| T4 | `O A C R A C Z` (two attempts) | yes | no | Position 6: second `C`; B's single `C` transition has already fired, the AND-branch is exhausted | P1, P3 |
| T5 | `O A C R C A Z` (two attempts) | yes | no | Position 5: second `C` | P1, P3 |
| T6 | `O C A P R C A P Z` (two attempts, two approvals) | yes | no | Position 6: second `C`; shows `#C = #P = #A = 2` is legal in A and impossible in B | P1, P3 |
| T7 | `O A C P R A Z` (two attempts) | no | yes | Position 6: attempt 2 ends with `Z` without its own `C` | P1 (`φ1`), P3 |

All seven traces have ≤ 9 visible events and ≤ 2 analyses, so they lie inside the P3 bound and were confirmed by the exhaustive exploration of Section 5.

**Role of the optional `Approve Revision` and the hidden `tau`.** `tau` itself never separates the models: both hide the same `X(P, tau)` decision, and hiding it makes "no approval" a legitimate, invisible outcome in both. Its effect is indirect: because `P` may be skipped, the shortest traces (`n = 1`, no `P`) of the two models coincide (`O A C Z`, `O C A Z`), which is why a small random sample or a footprint on start/end activities can create a false impression of equivalence. Whenever `P` *does* occur, it acts as a marker of the attempt boundary: in A it certifies that the attempt's `C` has already happened (`C` precedes `P`), in B it carries no such guarantee (T1). If `P` were also hidden (as in P2), T1 would collapse to the shared trace `O A C Z`, and the remaining differences would all be about `#C`, which P2 then collapses to a Boolean; that is exactly why P2 is the only view in which the models agree.

# 5. Bounded Comparison Code

The following script was executed with pm4py 2.7.23 / Python 3.13; the numbers reported in Sections 3, 4 and 7 come from it. It performs an **exhaustive** breadth-first exploration over (marking, visible prefix) states of the converted accepting Petri nets, and only afterwards shows a random playout to make the contrast explicit.

```python
"""
Bounded visible-language comparison of two process trees (P3 view).

Exhaustive BFS over the converted accepting Petri nets, restricted to
    - at most MAX_VISIBLE visible events per complete trace, and
    - at most MAX_ANALYZE occurrences of 'Analyze Revision'.
Silent transitions (label None) are followed but never appended to the visible
trace. A trace is complete only when the reached marking equals the final marking.
"""
from collections import deque, Counter

import pm4py
from pm4py.objects.petri_net import semantics
from pm4py.objects.petri_net.obj import Marking

TREE_A = (
    "->( 'Open Case', "
    "    *( ->( +('Analyze Revision', 'Check Revision'), X('Approve Revision', tau) ), "
    "       'Rework Case' ), "
    "    'Close Case' )"
)
TREE_B = (
    "->( 'Open Case', "
    "    +( 'Check Revision', "
    "       *( ->( 'Analyze Revision', X('Approve Revision', tau) ), 'Rework Case' ) ), "
    "    'Close Case' )"
)

MAX_VISIBLE = 12          # P3: at most 12 visible events
MAX_ANALYZE = 3           # P3: at most three Analyze Revision occurrences
ANALYZE = "Analyze Revision"


def build(tree_string):
    tree = pm4py.parse_process_tree(tree_string)          # 1. parse
    net, im, fm = pm4py.convert_to_petri_net(tree)         # 2. accepting Petri net
    return tree, net, im, fm


def frozen(marking):
    """Hashable, zero-free representation of a marking."""
    return frozenset((p.name, n) for p, n in marking.items() if n > 0)


def bounded_language(net, im, fm, max_visible=MAX_VISIBLE, max_analyze=MAX_ANALYZE):
    """
    Exhaustive BFS over (marking, visible prefix). Terminates because the
    tree-derived net is safe (finitely many markings) and prefixes are bounded;
    the visited set prevents re-expansion of (marking, prefix) pairs reached
    through different silent paths (repeated markings).
    """
    start = (frozen(im), tuple())
    visited = {start}
    queue = deque([(Marking(im), tuple())])   # keep pm4py Marking (Counter) semantics
    complete = set()
    final = frozen(fm)
    expansions = 0
    while queue:
        marking, prefix = queue.popleft()
        expansions += 1
        if frozen(marking) == final:          # final-marking equality => complete trace
            complete.add(prefix)
        for t in pm4py.get_enabled_transitions(net, marking):
            new_marking = semantics.execute(t, net, marking)
            if t.label is None:               # silent: marking moves, trace does not
                new_prefix = prefix
            else:
                if len(prefix) >= max_visible:
                    continue                  # visible-length bound
                if t.label == ANALYZE and prefix.count(ANALYZE) >= max_analyze:
                    continue                  # analysis-count bound
                new_prefix = prefix + (t.label,)
            key = (frozen(new_marking), new_prefix)
            if key not in visited:
                visited.add(key)
                queue.append((new_marking, new_prefix))
    return complete, expansions


def show(traces, limit=None):
    ordered = sorted(traces, key=lambda tr: (len(tr), tr))
    for tr in ordered[:limit]:
        print("   ", " > ".join(tr))
    if limit is not None and len(ordered) > limit:
        print(f"    ... ({len(ordered) - limit} more)")


def by_analyze_count(traces):
    return dict(sorted(Counter(tr.count(ANALYZE) for tr in traces).items()))


if __name__ == "__main__":
    tree_a, net_a, im_a, fm_a = build(TREE_A)
    tree_b, net_b, im_b, fm_b = build(TREE_B)

    print("=== SOUNDNESS ===")                            # 3. soundness
    for name, (net, im, fm) in {"A": (net_a, im_a, fm_a), "B": (net_b, im_b, fm_b)}.items():
        res = pm4py.check_soundness(net, im, fm)
        is_sound = res[0] if isinstance(res, tuple) else res
        print(f"Model {name}: sound = {is_sound}; |P|={len(net.places)} |T|={len(net.transitions)} "
              f"|F|={len(net.arcs)} silent T={sum(1 for t in net.transitions if t.label is None)}")

    print("\n=== EXHAUSTIVE BOUNDED EXPLORATION (P3) ===")  # 4./5. derive + compare
    lang_a, exp_a = bounded_language(net_a, im_a, fm_a)
    lang_b, exp_b = bounded_language(net_b, im_b, fm_b)
    print(f"Model A: {len(lang_a)} complete bounded traces ({exp_a} states); by #Analyze {by_analyze_count(lang_a)}")
    print(f"Model B: {len(lang_b)} complete bounded traces ({exp_b} states); by #Analyze {by_analyze_count(lang_b)}")
    only_a, only_b, common = lang_a - lang_b, lang_b - lang_a, lang_a & lang_b
    print(f"Common: {len(common)}   only A: {len(only_a)}   only B: {len(only_b)}")
    print(f"Bounded visible-language equivalence (P3): {not only_a and not only_b}")
    print(f"A ⊆ B within bound: {not only_a};  B ⊆ A within bound: {not only_b}")
    print("\nCommon traces:");                 show(common)
    print("\nTraces unique to Model A:");      show(only_a, limit=8)   # 6. unique traces
    print("\nTraces unique to Model B:");      show(only_b, limit=8)
    print("\n#Check Revision values:  A:", sorted({t.count('Check Revision') for t in lang_a}),
          " B:", sorted({t.count('Check Revision') for t in lang_b}))

    print("\n=== RANDOM PLAYOUT (heuristic, NOT exhaustive) ===")   # 7. contrast
    # play_out draws a finite number of traces with uniform random choices; it is
    # not guaranteed to reach every bounded trace nor to respect the P3 bound.
    vis = lambda log: {tuple(e["concept:name"] for e in tr) for tr in log}
    sa = vis(pm4py.play_out(tree_a, parameters={"num_traces": 200}))
    sb = vis(pm4py.play_out(tree_b, parameters={"num_traces": 200}))
    in_bound = lambda S: {t for t in S if len(t) <= MAX_VISIBLE and t.count(ANALYZE) <= MAX_ANALYZE}
    print(f"Sampled in-bound variants: A {len(in_bound(sa))}/{len(lang_a)}  B {len(in_bound(sb))}/{len(lang_b)}"
          " -> sampling under-covers; only the BFS result is conclusive.")
```

Observed output (abridged):

```text
Model B: sound = True; |P|=7 |T|=7 |F|=16 silent T=1
```

**Hand check of the counts** (independent of the code). Trace length in A is `3n + 1 + #P`; with `n = 3` only `#P ≤ 2` fits into 12 events, so A contributes `4 + 16 + 8·7 = 76` traces (`2^n` interleavings × approval patterns). In B the loop part has length `L = 2n − 1 + #P` and `C` can be inserted at `L + 1` positions: `n=1: 2+3 = 5`, `n=2: 4+10+6 = 20`, `n=3: 6+21+24+9 = 60`, total 85, all within 12 events. Both agree with the BFS.

**Exhaustive vs. heuristic.** The BFS enumerates *every* (marking, visible prefix) pair within the bound, so its trace sets are exact for the fragment; its verdict "not equivalent" is a proof. `pm4py.play_out` (also used inside `get_stochastic_language`) draws traces at random with uniform choices; 200 traces covered only 35/76 and 45/85 in-bound variants and also produced out-of-bound traces. A sample can exhibit differences but can never certify equality.

# 6. Stochastic and Footprint Comparison

```python
import pm4py
ta, tb = pm4py.parse_process_tree(TREE_A), pm4py.parse_process_tree(TREE_B)

# --- footprints: structural 1-step relations -------------------------------
fa, fb = pm4py.discover_footprints(ta), pm4py.discover_footprints(tb)
for key in ["start_activities", "end_activities", "activities", "sequence", "parallel"]:
    va, vb = set(fa[key]), set(fb[key])
    print(key, "| only A:", sorted(va - vb), "| only B:", sorted(vb - va))

# --- stochastic language: DECLARED assumption = uniform choice at every X/loop/+
# decision, 1000 random playouts (pm4py default); this is a sampled, truncated
# estimate of an infinite language, not a probability model of the business.
la, lb = pm4py.get_stochastic_language(ta), pm4py.get_stochastic_language(tb)
print("EMD(A,B) =", pm4py.compute_emd(la, lb))
print("EMD(A,A') =", pm4py.compute_emd(la, pm4py.get_stochastic_language(ta)))  # sampling noise
```

Observed:

```text
sequence | only A: [('Check Revision', 'Approve Revision')]
parallel | only B: [('Approve Revision','Check Revision'), ('Check Revision','Approve Revision')]
start/end/activities: identical
EMD(A,B)  = 0.154
EMD(A,A') = 0.044      # two independent samples of the same model
```

- **Footprints** add cheap, decisive negative evidence here: A has `C → P` as a sequence relation, B has `C ∥ P`. This is the structural shadow of T1. But footprints are a 1-step abstraction: they cannot count occurrences, so they are blind to the `#C = n` vs `#C = 1` difference (the largest one for P1). If A were changed so that `C` could also follow `P`, the footprints would coincide while the languages would still differ in `#C`. **Equal footprints therefore never establish trace equivalence**; they only rule it out when they differ.
- **Stochastic language / EMD** turns each model into a distribution over sampled traces and compares them with a normalised-Levenshtein ground distance. Two caveats make this weak evidence: (i) the probabilities are an artefact of uniform playout, not of the business (no transition probabilities are given; I declare the uniform assumption and do not claim it is realistic); (ii) the sample is finite and truncated, so even `EMD(A, A') = 0.044 ≠ 0`. A low EMD says the *bulk of probability mass* lies on similar-looking traces; it cannot exclude a zero- or low-probability trace that belongs to one language only, and a single such trace already breaks trace equivalence. Conversely `EMD(A,B) = 0.154 ≫ 0.044` is corroborating (not conclusive) evidence of a difference. A stochastic view would become meaningful only with declared probabilities (e.g. an SLPN with the observed approval and rework rates), and then it measures distance, not equivalence.
- Both techniques are complementary to Section 5: footprints for fast structural screening, EMD for "how different in practice", the exhaustive BFS for the actual verdict.

# 7. Complexity Comparison

```python
def structural_counts(tree):
    nodes = depth = visible = silent = 0; ops = {}; labels = []
    def walk(n, d):
        nonlocal nodes, depth, visible, silent
        nodes += 1; depth = max(depth, d)
        if n.operator is None:                       # leaf
            if n.label is None: silent += 1
            else: visible += 1; labels.append(n.label)
        else:
            ops[str(n.operator)] = ops.get(str(n.operator), 0) + 1
        for c in n.children: walk(c, d + 1)
    walk(tree, 0)
    duplicates = sum(1 for l in set(labels) if labels.count(l) > 1)
    return dict(nodes=nodes, depth_edges=depth, visible_leaves=visible,
                silent_leaves=silent, operators=ops, duplicate_labels=duplicates)

for name, s in [("A", TREE_A), ("B", TREE_B)]:
    tree = pm4py.parse_process_tree(s); net, im, fm = pm4py.convert_to_petri_net(tree)
    print(name, structural_counts(tree), "simplicity:", round(pm4py.simplicity_petri_net(net, im, fm), 4))
```

# 8. Simplified Model

**Target semantics: P2 (executive dashboard).** Reasoning: P2 is the only view under which A and B agree, so it is the only view for which one simplified model can legitimately replace *both*. For P1, Model A is already the correct and essentially minimal model (its language cannot be produced with fewer operators; the only "simplification", sequentialising `+(A,C)` into `->(A,C)`, removes 63 of A's 76 bounded traces and would flag real traces where the check precedes the analysis). For P3 no abstraction is allowed at all, so no simplification is possible.

**1. Compact expression**

```text
->( 'Open Case', 'Check Revision', *( 'Analyze Revision', 'Rework Case' ), 'Close Case' )
```

Language: `O C A (R A)* Z`. It is a strict sub-language of B (the check is pinned to the first position) and not a sub-language of A (no re-check per attempt); it is chosen for the abstraction, not for trace inclusion.

**2. Self-contained PM4Py code**

```python
import pandas as pd
import pm4py
from collections import deque
from pm4py.objects.petri_net import semantics
from pm4py.objects.petri_net.obj import Marking

SIMPLIFIED = "->( 'Open Case', 'Check Revision', *( 'Analyze Revision', 'Rework Case' ), 'Close Case' )"
simplified_model = pm4py.parse_process_tree(SIMPLIFIED)
s_net, s_im, s_fm = pm4py.convert_to_petri_net(simplified_model)
print("simplified sound:", pm4py.check_soundness(s_net, s_im, s_fm)[0])

TREE_A = ("->( 'Open Case', *( ->( +('Analyze Revision', 'Check Revision'), "
          "X('Approve Revision', tau) ), 'Rework Case' ), 'Close Case' )")
TREE_B = ("->( 'Open Case', +( 'Check Revision', *( ->( 'Analyze Revision', "
          "X('Approve Revision', tau) ), 'Rework Case' ) ), 'Close Case' )")

def frozen(m):
    return frozenset((p.name, n) for p, n in m.items() if n > 0)

def bounded_language(net, im, fm, max_visible=12, max_analyze=3):   # same BFS as Section 5
    seen = {(frozen(im), tuple())}; q = deque([(Marking(im), tuple())]); out = set(); final = frozen(fm)
    while q:
        m, pre = q.popleft()
        if frozen(m) == final: out.add(pre)
        for t in pm4py.get_enabled_transitions(net, m):
            m2 = semantics.execute(t, net, m)
            if t.label is None: pre2 = pre
            else:
                if len(pre) >= max_visible: continue
                if t.label == "Analyze Revision" and pre.count("Analyze Revision") >= max_analyze: continue
                pre2 = pre + (t.label,)
            k = (frozen(m2), pre2)
            if k not in seen: seen.add(k); q.append((m2, pre2))
    return out
```

# 9. Final Recommendation

- **P1 (operational compliance): use Model A only.** It structurally enforces "one check per analysis attempt before the next rework or closing" and keeps approval placement; Model B admits non-compliant behaviour (`O A R A C Z`, `O A C P R A Z`) and an approval before the check (`O A P C Z`). The simplified model must **not** replace A here; it is non-compliant for every case with rework.
- **P2 (executive dashboard): either original is acceptable, and the simplified model can replace both.** All three have the identical dashboard image `{(check=true, #A = n, rework = [n ≥ 2]) : n ≥ 1}`; this was proven from the closed-form languages and confirmed within the P3 bound. Replace A/B with the 7-node model only in the dashboard pipeline, and re-validate the moment the dashboard starts counting checks, approval rates, or the order of check and analysis, because each of those extensions breaks the equivalence (`#C` differs, `C ∥ P` differs).
- **P3 (bounded testing): the models are not interchangeable, and no simplification is admissible.** The exhaustive exploration within 12 events / 3 analyses found 4 shared traces, 72 exclusive to A and 81 exclusive to B, with the shortest witness at length 5. Because the difference appears inside the bound, this bounded result is already a proof of unbounded non-equivalence.
- **Model B in isolation** describes a different process ("one case-level check, concurrent with any number of revisions") and should be kept only if that is the intended operational semantics; it is not a variant of A.

**Warning on bounded comparison.** Bounded exploration is asymmetric evidence: a difference found within the bound proves non-equivalence everywhere, but equality within the bound would prove nothing beyond the bound (a model that diverges only at the fourth analysis or the 13th event would pass P3 untouched). Random playout is weaker still: 200 samples reached fewer than half of the in-bound variants, and footprints and EMD are abstractions or sampled distances that can agree while languages differ. Any claim of equivalence should therefore be stated together with the observation model (P1/P2/P3), the bound, and the exploration method that produced it.
