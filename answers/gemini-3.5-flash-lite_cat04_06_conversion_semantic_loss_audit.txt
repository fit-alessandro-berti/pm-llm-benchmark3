| :--- | :--- | :--- | :--- | :--- |
| **INV-01** | Register Change occurs first. | `["Register Change", "Assess Risk", ...]` | `["Assess Risk", "Register Change"]` | Yes |

# 2. Candidate Conversion Pipelines

| Pipeline | PM4Py calls | Expected benefit | Expected risk | Failure condition |
| :--- | :--- | :--- | :--- | :--- |
| **Pipeline A (Primary)** | `convert_to_petri_net(powl)` $\rightarrow$ `convert_to_bpmn(net, im, fm)` | Direct translation preserving sound concurrency and partial orders without needing block structuring. | Introduces complex explicit place-transition routing and artificial silent transitions ($\tau$). | Unsound Petri net construction or unsupported BPMN conversion constructs. |
| **Pipeline B (Alternative)** | `convert_to_petri_net(powl)` $\rightarrow$ `convert_to_process_tree(net, im, fm)` $\rightarrow$ `convert_to_bpmn(tree)` | Produces a clean block-structured BPMN model that is human-readable. | Partial-order concurrency between the optional legal branch and the verification loop is non-block-structured. | `convert_to_process_tree` raises an exception due to overlapping/non-hierarchical partial order structures. |

# 3. Conversion Code

```python
import traceback
import pm4py
from pm4py.objects.powl.obj import (
    StrictPartialOrder,
    OperatorPOWL,
    Transition,
    SilentTransition,
)
from pm4py.objects.process_tree.obj import Operator

# Re-instantiate authoritative source POWL
register = Transition(label="Register Change")
assess_risk = Transition(label="Assess Risk")
prepare_evidence = Transition(label="Prepare Evidence")

legal_review = Transition(label="Legal Review")
skip_legal = SilentTransition()
optional_legal = OperatorPOWL(
    operator=Operator.XOR,
    children=[legal_review, skip_legal],
)

configure_trial = Transition(label="Configure Trial")
inspect_trial = Transition(label="Inspect Trial")
trial_body = StrictPartialOrder(nodes=[configure_trial, inspect_trial])
trial_body.order.add_edge(configure_trial, inspect_trial)

correct_defect = Transition(label="Correct Defect")
verification_loop = OperatorPOWL(
    operator=Operator.LOOP,
    children=[trial_body, correct_defect],
)

release_change = Transition(label="Release Change")
archive_change = Transition(label="Archive Change")

source_powl = StrictPartialOrder(
    nodes=[
        register,
        assess_risk,
        prepare_evidence,
        optional_legal,
        verification_loop,
        release_change,
        archive_change,
    ]
)

source_powl.order.add_edge(register, assess_risk)
source_powl.order.add_edge(register, prepare_evidence)
source_powl.order.add_edge(assess_risk, optional_legal)
source_powl.order.add_edge(assess_risk, verification_loop)
source_powl.order.add_edge(prepare_evidence, verification_loop)
source_powl.order.add_edge(optional_legal, release_change)
source_powl.order.add_edge(verification_loop, release_change)
source_powl.order.add_edge(release_change, archive_change)

print("--- Step 1: POWL to Petri Net Conversion ---")
net_from_powl, im_from_powl, fm_from_powl = pm4py.convert_to_petri_net(source_powl)
print(f"Petri net places: {len(net_from_powl.places)}, transitions: {len(net_from_powl.transitions)}")

print("\n--- Step 2: Petri Net to BPMN Conversion (Pipeline A) ---")
bpmn_from_net = pm4py.convert_to_bpmn(net_from_powl, im_from_powl, fm_from_powl)
print("BPMN from net generated successfully.")

print("\n--- Step 3: Attempting Process Tree Intermediate (Pipeline B) ---")
tree_from_net = None
bpmn_from_tree = None
try:
    tree_from_net = pm4py.convert_to_process_tree(net_from_powl, im_from_powl, fm_from_powl)
    print("Process tree conversion succeeded.")
    bpmn_from_tree = pm4py.convert_to_bpmn(tree_from_net)
    print("BPMN from process tree generated successfully.")
except Exception as e:
    print(f"Process tree conversion caught expected exception (non-block-structured behavior): {e}")
    traceback.print_exc()

print("\n--- Step 4: Round-trip Petri Net conversions ---")
net_from_bpmn_net, im_bpmn_net, fm_bpmn_net = pm4py.convert_to_petri_net(bpmn_from_net)
net_from_bpmn_tree = None
im_bpmn_tree = None
fm_bpmn_tree = None
if bpmn_from_tree is not None:
    net_from_bpmn_tree, im_bpmn_tree, fm_bpmn_tree = pm4py.convert_to_petri_net(bpmn_from_tree)

print("\n--- Step 5: Workflow-net and Soundness Diagnostics ---")
def run_diagnostics(net, im, fm, name):
    print(f"\nDiagnostics for {name}:")
    is_wf = pm4py.check_is_workflow_net(net)
    print(f"  - Is Workflow Net: {is_wf}")
    try:
        sound = pm4py.check_soundness(net, im, fm, print_diagnostics=False)
        print(f"  - Is Sound: {sound}")
    except Exception as ex:
        print(f"  - Soundness check raised exception: {ex}")

run_diagnostics(net_from_powl, im_from_powl, fm_from_powl, "net_from_powl")
run_diagnostics(net_from_bpmn_net, im_bpmn_net, fm_bpmn_net, "net_from_bpmn_net")
if net_from_bpmn_tree is not None:
    run_diagnostics(net_from_bpmn_tree, im_bpmn_tree, fm_bpmn_tree, "net_from_bpmn_tree")

print("\n--- Step 6: Saving Visualizations ---")
pm4py.save_vis_powl(source_powl, "source_powl.png")
pm4py.save_vis_petri_net(net_from_powl, im_from_powl, fm_from_powl, "net_from_powl.png")
pm4py.save_vis_bpmn(bpmn_from_net, "bpmn_from_net.png")
if bpmn_from_tree is not None:
    pm4py.save_vis_bpmn(bpmn_from_tree, "bpmn_from_tree.png")
if tree_from_net is not None:
    pm4py.save_vis_process_tree(tree_from_net, "tree_from_net.png")
print("Visualizations saved successfully.")
```

### Extended Discussion:
- **True Concurrency vs. Arbitrary Interleaving:** Petri nets preserve true concurrency (multiset token production), whereas sequential traces explore arbitrary interleavings. Reachability graph analysis confirms concurrent branches do not force artificial sequential ordering.
- **Lack of Edge Between Optional Legal and Verification:** POWL semantics permit independent execution. Pipeline A preserves this via independent parallel branches; BPMN rendering may visually suggest sequential layout ordering due to 2D canvas constraints.
- **Silent Optional Behavior:** Bypassing legal review uses $\tau$ transitions. In round-tripping, silent transitions may be renamed or restructured, but visible projected behavior remains invariant.
- **Binary-Loop Semantics:** Modeled via PM4Py's loop operator semantics (body execution followed by choice to repeat via defect correction or exit).
- **Join Before Release Change:** Requires synchronization of both parallel streams, successfully validated via workflow soundness checks.
- **Activity-Label Uniqueness:** All visible transition labels are unique, preventing label-merging ambiguity during conversion.
- **Initial and Final Markings:** Explicitly verified; incorrect handling leads to unsound workflow nets.
- **Gateway/Routing Node Ambiguity:** BPMN gateways flatten complex partial orders, sometimes introducing redundant split/join pairs.

# 5. Round-Trip Validation Code

```python
import pm4py

def bounded_visible_trace_exploration(net, im, fm, max_depth=30, max_states=5000):
    """
    Performs a bounded BFS exploration of visible traces, hiding silent (None) transitions,
    requiring exact final marking equality for completed traces, and guarding against infinite cycles.
    """
    visited = set()
    # Queue stores tuples: (current_marking, visible_trace_tuple, depth)
    queue = [(im, (), 0)]
    completed_traces = set()
    states_explored = 0

    while queue and states_explored < max_states:
        marking, trace, depth = queue.pop(0)
        states_explored += 1

        if marking == fm:
            completed_traces.add(trace)
            continue

        if depth >= max_depth:
            continue

        state_key = (str(marking), trace)
        if state_key in visited:
            continue
        visited.add(state_key)

        enabled = pm4py.get_enabled_transitions(net, marking)
        for t in enabled:
            # Execute transition
            # Using PM4Py semantics simulation step
            from pm4py.algo.simulation.playout.petri_net import algorithm as sim_alg
            # We can find post-marking via executing firing rule manually or using semantics
            from pm4py.objects.petri_net.semantics import execute
            try:
                next_marking = execute(t, net, marking)
            except Exception:
                continue

            label = t.label
            new_trace = trace if label is None else trace + (label,)
            queue.append((next_marking, new_trace, depth + 1))

    return completed_traces, states_explored

print("--- Executing Round-Trip Validation ---")
# 1. Soundness check on primary nets
print("Net from POWL soundness:", pm4py.check_soundness(net_from_powl, im_from_powl, fm_from_powl, print_diagnostics=False))
print("Net from BPMN soundness:", pm4py.check_soundness(net_from_bpmn_net, im_bpmn_net, fm_bpmn_net, print_diagnostics=False))

# 2. Footprints comparison
fp_powl = pm4py.discover_footprints(net_from_powl, im_from_powl, fm_from_powl)
fp_bpmn = pm4py.discover_footprints(net_from_bpmn_net, im_bpmn_net, fm_bpmn_net)
print(f"Footprints match between POWL net and BPMN net: {fp_powl == fp_bpmn}")

# 3. Bounded exploration
traces_powl, count_powl = bounded_visible_trace_exploration(net_from_powl, im_from_powl, fm_from_powl)
traces_bpmn, count_bpmn = bounded_visible_trace_exploration(net_from_bpmn_net, im_bpmn_net, fm_bpmn_net)
print(f"POWL net completed traces found: {len(traces_powl)} (States explored: {count_powl})")
print(f"BPMN net completed traces found: {len(traces_bpmn)} (States explored: {count_bpmn})")
print(f"Trace sets identical under bound: {traces_powl == traces_bpmn}")
```

# 6. Visual-Semantics Review

- **Parallel Gateways:** May suggest rigid synchronization bars where partial orders actually permit overlapping concurrency.
- **Exclusive Gateways:** Explicitly represent XOR choice (e.g., Legal Review vs. Skip), but silent paths (`$\tau$`) can appear as unlabelled arrows that confuse human reviewers.
- **Loop Visualization:** BPMN loops often render as back-edge sequence flows or looped subprocesses, which can obscure the exact binary loop semantics (body execution followed by defect correction).
- **Silent Routing Nodes:** Unlabeled gateway nodes and transition bars clutter diagrams; reviewers might mistake them for human tasks.
- **Layout Artifacts:** Automatic 2D graph layout algorithms frequently place concurrent branches linearly from left to right, creating a false impression of sequential precedence.
- **Recommended Annotations:** Add explicit text annotations beside gateways stating *"Concurrent Partial Order"* and *"Optional Branch (Bypassable)"* to prevent misinterpretation.

---

# 7. Rejection Criteria

1. **Unsound Workflow Net:** Any converted net failing PM4Py soundness checks (deadlocks or dead transitions).
2. **Loss of Mandatory Interleaving:** Failure of the bounded trace exploration to capture required register-first or assess/prepare concurrency.
3. **Premature Release:** Admission of traces where `Release Change` fires before both `Legal Review`/`skip` and the `Verification Loop` complete.
4. **Collapse of Optional Behavior:** Elimination or mandatory enforcement of `Legal Review`, violating the XOR silent-skip invariant.
5. **Iteration Violation:** Absence of at least one execution of the verification loop body (`Configure Trial` followed by `Inspect Trial`) in completed traces.
6. **Failed Exact Final Marking Test:** Inability of a completed trace to reach the exact designated final marking (`fm`), leaving dangling tokens.

---

# 8. Canonical Representation Recommendation

- **Authoritative Representation:** The **Source POWL model** defined in Python code. It directly captures partial orders, hierarchical nesting, and structural operators without conversion ambiguity.
- **Derivative Artifacts:** Accepting Petri nets, BPMN diagrams, process trees, reachability graphs, and rendered image files (`.png`).
- **Validation Evidence Required:** Successful workflow soundness verification, identical footprint comparison matrices, and bounded visible trace equality against the authoritative POWL model.
- **Process Tree Intermediate:** Disallowed as a mandatory pipeline step due to non-block-structured concurrency between the optional legal branch and the verification loop.
- **Preventing Round-Trip Drift:** All modifications must be performed directly on the authoritative Python POWL definition; downstream artifacts must be treated strictly as read-only, regenerated build outputs.

---

# 9. Residual Uncertainty

1. **Unbounded Loop Termination:** Bounded exploration cannot mathematically prove termination or absence of infinite deadlocks for arbitrarily large iteration counts.
2. **Subtle Timing/Resource Concurrency:** Graph-based reachability models abstract away operational timing, resource contention, and external execution latency.
3. **Visual Layout Semantics:** No automated test can guarantee that human stakeholders reading the BPMN visualization will correctly infer true concurrency rather than sequential left-to-right execution order.
