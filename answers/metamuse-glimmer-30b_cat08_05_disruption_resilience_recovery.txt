## 3. Resilience versus concealed noncompliance

Resilience is throughput and service protection achieved without loss of essential control. Concealed noncompliance is throughput maintained by removing or deferring controls that are later papered over.

True resilience in this case: Manual authorization check B, Temporary release control F, Defer noncritical order I, Backlog prioritization J, and the intent of Hospital-critical fast lane A when paired with minimum controls. These preserved Hospital-critical median ~8-10h and fill 91% while keeping authorization and release evidence traceable. Reconcile manual reservation K is resilience-enabling recovery work.

Risky shortcuts: Skip system authorization check C and Dispatch without scan G are clear concealed noncompliance. C created an authorization gap for ambient products with no offline verification, and G removed the scan event entirely, producing the largest traceability gap and move-on-model deviation. Phone proof of delivery H is a shortcut for controlled products.

Ambiguous depending on risk appetite: Hospital-critical fast lane A protected supply but sometimes bypassed authorization; Manual inventory snapshot check D was reasonable for first hours then became risky as inventory aged; Manual pick list E maintained flow but caused downstream reconstruction and 12.5% rework. These are resilience only if bounded by time limits, mandatory fields and explicit risk acceptance.

Conformance data supports this distinction: fitness fell to 0.71 and only 44% traces fit during manual workaround, while traceability exceptions rose 10x and cold-chain missing rose 12x. Stabilization fitness recovered to 0.90 but remained below baseline 0.96 because audit remediation is after-the-fact, not real-time compliance.

## 4. Recovery process model

Trigger conditions
* WMS unavailable >30 min or inventory sync error >10% or scanning failure >20%
* Declare Incident Level 2, activate Manual Operations Playbook.

Triage rules
Emergency Triage on Receive order:
* Risk = Customer criticality x Product risk matrix
* Hospital-critical + Controlled-substance/Cold-chain/Recall-sensitive = Tier 1 immediate
* Hospital-critical + Ambient = Tier 2
* Pharmacy-standard + Controlled/Cold-chain = Tier 3
* Others = Defer to backlog queue with SLA

Minimum controls by risk
* Tier 1: Manual authorization check using pre-approved offline matrix + phone confirmation logged; manual inventory snapshot valid <4h; dual control for controlled-substance; mandatory temperature log for cold-chain; manual release sign-off by pharmacist; manual dispatch scan sheet with courier signature; paper POD with photo for controlled.
* Tier 2: Manual authorization check sampled 100% first 24h then risk-based; snapshot valid <8h; manual release sign-off.
* Tier 3+: Defer or manual authorization check capacity permitting; no skip authorization.

Manual evidence capture
Standardised paper forms with pre-printed fields, unique manual case ID, carbon copy:
Pick list, Pack check, Release control, Dispatch scan sheet, Temperature log, POD.
Immediate entry into Spreadsheet Invoice Hold with mandatory fields enforced; daily batch import to system with validation.

Backlog prioritization
On system return: Backlog prioritization by Tier, order age, product expiry, and reconciliation effort. Explicit rules published to customers. Cancel order threshold after SLA breach.

Reconciliation and audit-remediation flow
Reconcile manual reservation -> Pick -> Pack -> Quality/release check with system. Proof-of-delivery remediation for missing scans. Invoice close -> Audit remediation only for exceptions with root cause and CAPA. Audit remediation queue size and age tracked as operational KPI, not hidden post-close.

Process notation POWL style:
Receive order -> [Emergency Triage] -> {Manual authorization check | Skip authorization [forbidden]} -> Manual inventory snapshot check [validity timer] -> Manual pick list -> Manual pack -> Temporary release control [mandatory for controlled/cold-chain] -> Dispatch with manual scan sheet -> Phone/Paper POD -> Spreadsheet invoice hold -> END
with parallel defer path: Receive order -> Defer noncritical order -> Backlog queue -> Backlog prioritization -> Resume.

## 5. Resilience indicators

Leading indicators
* Time to triage: % orders triaged within 15 min of receipt
* Manual form completeness at dispatch: % required fields filled
* Compliance capacity utilization: % of manual authorization checks completed within SLA
* Snapshot age: % picks using inventory snapshot >4h old
* Backlog age distribution: % backlog >48h by tier

Lagging indicators
* Throughput and service protection: Median and p90 cycle time by customer segment; Hospital-critical fill rate
* Traceability: Traceability exceptions %; Cold-chain temperature documentation missing %; Controlled-substance dual-control missing %
* Control completeness: Conformance fitness and % fitting traces vs normative model
* Rework and quality: Rework/correction case rate; Cancellation rate
* Fairness: Cycle time ratio Wholesale-bulk vs Hospital-critical; Pharmacy-standard fill rate
* Hidden workload: Audit remediation queue size and age; Invoice close -> Audit remediation lead time

## 6. Recommendations for future disruptions

* Pre-approved offline authorization matrix and Manual Operations Playbook kit with pre-printed forms. Effort low, Benefit high, Residual risk low if maintained.
* Standardised manual pick/pack/release/dispatch forms with unique manual IDs and daily import validation. Effort medium, Benefit high, Residual risk medium.
* Time-boxed inventory snapshots with automatic expiry and re-snapshot cadence. Effort low, Benefit medium, Residual risk low.
* Cold-chain temperature manual log and controlled-substance dual-control checklist mandatory in manual mode. Effort low, Benefit high, Residual risk low.
* Tiered triage and deferral policy with customer communication templates and SLA. Effort medium, Benefit high, Residual risk medium due to customer relations.
* Dedicated reconciliation and audit remediation team with capacity planning. Effort medium, Benefit high, Residual risk medium if backlog grows.
* Post-incident conformance review: fitness, fitting traces, move-on-log/model deviations. Effort low, Benefit high, Residual risk low.

## 7. Management trade-off statement

Management should accept temporary manual evidence capture and prioritisation of Hospital-critical orders with minimum controls retained, and should not accept skipping authorization checks or dispatch without scan for controlled-substance, cold-chain or recall-sensitive products. Throughput preservation is not resilience when traceability and authorization disappear. Evidence that would change the recommendation is real-time manual capture achieving >95% field completeness, fitness >=0.93 during manual mode, and audit remediation queue clearing within 5 business days of operational recovery.
