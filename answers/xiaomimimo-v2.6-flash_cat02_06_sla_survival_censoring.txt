Section 4: Statistical analysis plan.
- KM: for single-event estimand under hypothetical "no competing events"; not appropriate for CIF; overestimates.
- Aalen-Johansen CIF: primary for E2/E3; works with competing risks; requires non-informative censoring for open cases.
- Cause-specific hazards: for etiology/process understanding (how cohort/policy changes instantaneous resolve rate); doesn't directly give probabilities; good for stage hazards.
- Subdistribution hazards (Fine–Gray): directly models CIF; but with n=32 and 9 open + 3 transfers, unstable; interpretation is risk-set-inclusive (includes people who already had competing events) — awkward for operational decisions; fine for prediction with caution.
- Restricted mean time (RMST/RMTL): RMST to resolution restricted at =72 or 168 — interpretable "expected hours within window"; but with competing events, define RMST of "time to any disposition" or use pseudo-observations. Also "restricted mean time in the unresolved state" = area under the "no terminal disposition" curve = 0^72 S_all(t) dt — a nice workload measure (expected hours a case spends in-flight within SLA window).
- Landmarking: at t=0 (submit), t=24, t=48 predict breach using only history up to landmark  solves immortal-time/leakage; with32 cases, landmark models are descriptive only.
- Multi-state: best structural fit (states from prefixes), handles time-varying covariates, gives transition-specific hazards; but data too small  use descriptively.

```python
def km_aj(df, event_causes, horizon=HORIZON):
    """
    One pass over the risk sets.
      event_causes : set of cause codes treated as EVENTS; cause 0 and any cause not in event_causes are treated as RIGHT CENSORING (they shrink risk sets
                     but do not change the survival step).
    Returns dict with:
      'S'            : KM/AJ survival at horizon  (P(no event of type in event_causes) by horizon)
      'cif'          : {cause: Aalen-Johansen cumulative incidence at horizon}
      'n_at_risk'    : risk set at horizon
      'steps'        : (time, n_risk, S_before, S_after) for plotting/RMST
    """
    d = df.sort_values("time").reset_index(drop=True)
    n_all = len(d)
    S = 1.0
    cif = {}
    steps = []
    for i, r in d.iterrows():
        n_risk = int((d["time"] >= r["time"]).sum())
        is_event = int(r["cause"]) in event_causes
        if r["time"] > horizon:
            break # later rows only enter risk sets, never change S(horizon)
        if is_event:
            cif[int(r["cause"])] = cif.get(int(r["cause"]), 0.0) + S / n_risk
            S_after = S * (n_risk - 1) / n_risk
        else:
            S_after = S
        steps.append((r["time"], n_risk, S, S_after))
        S = S_after
    return {"S": S, "cif": cif, "n_at_risk": int((d["time"] >= horizon).sum()), "steps": steps}
```

def rmst(steps, horizon):

    t_prev, area = 0.0, 0.0
