# 1. Equivalence Notions

## Visible Trace Equivalence after Hiding 
Two models are **visible trace equivalent** if their sets of visible traces (after removing all  transitions) are identical. Duplicate visible labels are distinguished **only by label**, not by occurrence position or identity. This means that sequences like `['Check Revision', 'Analyze Revision']` and `['Analyze Revision', 'Check Revision']` are considered different traces, but repeated occurrences of the same label (e.g., two `'Check Revision'`) are not distinguished beyond their count.

## Bounded Visible-Language Equivalence under P3
Under P3, two models are **bounded visible-language equivalent** if their sets of visible traces (with  hidden) of length 12 and with 3 `'Analyze Revision'` occurrences are identical. This is a **bounded equivalence**, not a proof of unbounded equivalence. Traces are compared up to the stated bounds.

## Business-Relevant Equivalence under P1
Under P1 (operational compliance view), two models are equivalent if:
1. Every `'Analyze Revision'` is preceded by a `'Check Revision'` before the next `'Rework Case'` or `'Close Case'`.
2. `'Rework Case'` separates two `'Analyze Revision'` attempts.
3. The placement and number of `'Approve Revision'` (including silent ) are preserved.
4. The loop semantics (first child executed once, then second child, repeat) are respected.

This equivalence is **strict** and requires exact structural alignment of checks relative to analyses and reworks.

## Abstracted Dashboard Equivalence under P2
Under P2 (executive dashboard view), two models are equivalent if:
1. The collapsed traces (where repeated `'Check Revision'` are treated as a single Boolean fact) are identical.
2. The counts of `'Analyze Revision'` and whether `'Rework Case'` occurred are preserved.
3. `'Approve Revision'` and  are hidden entirely.
4. The order of `'Open Case'` and `'Close Case'` is preserved, and at least one `'Analyze Revision'` and one `'Check Revision'` occur.

This equivalence **abstracts away** silent behavior and interleaving, focusing only on counts and collapsed presence.

# 5. Bounded Comparison Code

```python
import pm4py
from collections import deque

def parse_tree(tree_str):
    return pm4py.parse_process_tree(tree_str)

def to_petri_net(tree):
    return pm4py.convert_to_petri_net(tree)

def get_visible_traces(net, im, fm, max_length=12, max_analyze=3):
    # Breadth-first exploration over markings
    visited = set()
    queue = deque([(im, [])])
    visible_traces = set()

    while queue:
        marking, trace = queue.popleft()
        if marking in visited:
            continue
        visited.add(marking)

        if marking == fm:
            if len(trace) <= max_length and trace.count('Analyze Revision') <= max_analyze:
                visible_traces.add(tuple(trace))
            continue

        enabled = pm4py.get_enabled_transitions(net, marking)
        for trans in enabled:
            if trans.label is None:  # silent transition
                new_marking = pm4py.execute(trans, net, marking)
                queue.append((new_marking, trace))
            else:  # visible transition
                new_marking = pm4py.execute(trans, net, marking)
                new_trace = trace + [trans.label]
                if len(new_trace) <= max_length and new_trace.count('Analyze Revision') <= max_analyze:
                    queue.append((new_marking, new_trace))

    return visible_traces

# Parse models
model_a_str = "->('Open Case', *('Analyze Revision', +('Check Revision', X('Approve Revision', tau))), 'Rework Case'), 'Close Case')"
model_b_str = "->('Open Case', +('Check Revision', *('Analyze Revision', X('Approve Revision', tau)), 'Rework Case')), 'Close Case')"

model_a_tree = parse_tree(model_a_str)
model_b_tree = parse_tree(model_b_str)

# Convert to Petri nets
net_a, im_a, fm_a = to_petri_net(model_a_tree)
net_b, im_b, fm_b = to_petri_net(model_b_tree)

# Check soundness
print("Model A soundness:")
pm4py.check_soundness(net_a, im_a, fm_a, print_diagnostics=True)
print("\nModel B soundness:")
pm4py.check_soundness(net_b, im_b, fm_b, print_diagnostics=True)

# Get visible traces
traces_a = get_visible_traces(net_a, im_a, fm_a)
traces_b = get_visible_traces(net_b, im_b, fm_b)

# Compare
unique_to_a = traces_a - traces_b
unique_to_b = traces_b - traces_a

print("\nTraces unique to Model A:")
for trace in sorted(unique_to_a, key=lambda x: (len(x), x)):
    print(trace)

print("\nTraces unique to Model B:")
for trace in sorted(unique_to_b, key=lambda x: (len(x), x)):
    print(trace)
```

**Notes:**
- The code uses **breadth-first exploration** over markings to ensure exhaustive bounded exploration.
- Silent transitions (`tau`) are handled by executing them without adding to the trace.
- The bounds (`max_length=12`, `max_analyze=3`) are enforced during exploration.
- This is **not a proof of unbounded equivalence**, only bounded equivalence under the given constraints.

# 6. Stochastic and Footprint Comparison

## Footprints
`pm4py.discover_footprints(...)` could reveal differences in **direct succession** and **causality**:
- In Model A, `'Check Revision'` directly follows `'Analyze Revision'` in the loop.
- In Model B, `'Check Revision'` can occur before `'Analyze Revision'` (outside the loop).

However, footprints **do not capture all interleavings** and cannot distinguish between traces like `['Check Revision', 'Analyze Revision']` and `['Analyze Revision', 'Check Revision']`.

## Stochastic Language
`pm4py.get_stochastic_language(...)` could assign probabilities to traces, but:
- Without explicit probabilities in the models, this would require assumptions.
- Even with probabilities, **low Earth Mover’s Distance (EMD)** would not establish trace equivalence, as it measures distribution similarity, not trace set equality.

## Code Example (Footprints)
```python
footprint_a = pm4py.discover_footprints(net_a, im_a, fm_a)
footprint_b = pm4py.discover_footprints(net_b, im_b, fm_b)

print("Footprint A:", footprint_a)
print("Footprint B:", footprint_b)
```

**Why equal footprints do not imply equivalence:**
Footprints abstract away **loop semantics** and **concurrency**, so two models with identical footprints may still have different trace sets (e.g., due to interleaving).

def count_nodes(tree):
    if tree is None:
        return 0
    return 1 + sum(count_nodes(child) for child in tree.children)

def count_visible_leaves(tree):
    if tree is None:
        return 0
    if tree.operator is None and tree.label is not None:  # leaf
        return 1 if tree.label not in ['tau'] else 0
    return sum(count_visible_leaves(child) for child in tree.children)

def count_silent_leaves(tree):
    if tree is None:
        return 0
    if tree.operator is None and tree.label is not None:  # leaf
        return 1 if tree.label == 'tau' else 0
    return sum(count_silent_leaves(child) for child in tree.children)

nodes_a = count_nodes(model_a_tree)
nodes_b = count_nodes(model_b_tree)
visible_a = count_visible_leaves(model_a_tree)
visible_b = count_visible_leaves(model_b_tree)
silent_a = count_silent_leaves(model_a_tree)
silent_b = count_silent_leaves(model_b_tree)
simplicity_a = pm4py.simplicity_petri_net(net_a, im_a, fm_a)
simplicity_b = pm4py.simplicity_petri_net(net_b, im_b, fm_b)

print(f"Model A: nodes={nodes_a}, visible={visible_a}, silent={silent_a}, simplicity={simplicity_a:.2f}")

# 8. Simplified Model

## Target Semantics: P1 (Operational Compliance)
We simplify Model A to enforce:
1. Every `'Analyze Revision'` must be preceded by a `'Check Revision'`.
2. `'Rework Case'` separates analyses.
3. `'Approve Revision'` is optional and silent.

**Simplified Process Tree:**
```text
->(
  'Open Case',
  *(
    ->(
      'Check Revision',
      'Analyze Revision',
      X('Approve Revision', tau)
    ),
    'Rework Case'
  ),
  'Close Case'
)
```

## PM4Py Code
```python
simplified_str = "->('Open Case', *('Check Revision', 'Analyze Revision', X('Approve Revision', tau)), 'Rework Case'), 'Close Case')"
simplified_tree = pm4py.parse_process_tree(simplified_str)
simplified_net, im_simp, fm_simp = pm4py.convert_to_petri_net(simplified_tree)
```

## Preservation Table

| Property                     | Original Model A | Simplified Model | Preservation Status       |
|------------------------------|------------------|------------------|---------------------------|
| Every `'Analyze Revision'` preceded by `'Check Revision'` | Yes              | Yes              | Exact                     |
| `'Rework Case'` separates analyses | Yes              | Yes              | Exact                     |
| Optional `'Approve Revision'` | Yes              | Yes              | Exact                     |
| Loop semantics               | Binary loop      | Binary loop      | Exact                     |
| Concurrency                  | None             | None             | Exact                     |
| Silent behavior              |  in approval    |  in approval    | Exact                     |
| `'Check Revision'` before `'Close Case'` | Yes              | Yes              | Exact                     |
| `'Check Revision'` before `'Rework Case'` | Yes              | Yes              | Exact                     |

**Regression Traces (admitted by both):**
1. `['Open Case', 'Check Revision', 'Analyze Revision', 'Close Case']`
2. `['Open Case', 'Check Revision', 'Analyze Revision', 'Rework Case', 'Check Revision', 'Analyze Revision', 'Close Case']`
3. `['Open Case', 'Check Revision', 'Analyze Revision', 'Approve Revision', 'Rework Case', 'Check Revision', 'Analyze Revision', 'Close Case']`

**Negative Traces (not admitted by simplified model):**
