## 2. Rule Interpretation

- **RR1 – Drafter/approver separation**: Ensure `Draft_Change_Request` and `Approve_Change` are performed by different people for the same case.
- **RR2 – Implementer/verifier separation**: Ensure `Implement_Change` and `Verify_Implementation` are performed by different people for the same case.
- **RR3 – High-risk approval authority**: For HIGH-risk cases, the principal approver must be a QM or valid delegate. Delegations are valid only if pre-established, inclusive of scope and absence conditions, and no prohibited subdelegation occurred.
- **RR4 – Emergency substitution**: For emergency approvals, the IC or IC delegate can implement immediate action, but a QM (or QM delegate) must perform a retrospective review within *two business days.* Business days exclude weekends and site holidays.
- **RR5 – Identity evidence**: Actions taken by aliases or service accounts must have traceable human attribution through reliable evidence such as session identification or token logs.
- **RR6 – Suspicion versus proof**: Patterns (e.g., frequent collaborations) are circumstantial unless paired with proof of collusion, credential compromise, or authority violations.

## 5. PM4Py and pandas Checking Code

```python
import pandas as pd
import io
from pm4py.objects.log.util import dataframe_utils
from pm4py.algo.enhancement.sna.transformer.versions import basic_metrics
from pm4py.algo.filtering.log.attributes import attributes_filter
from pm4py.algo.enhancement.sna.metrics import four_eyes_principle

# Load CSV event log
data = io.StringIO("""
case:concept:name,concept:name,time:timestamp,org:resource,risk,scope,emergency
CHG-501,Draft_Change_Request,2026-08-11T08:00:00Z,u_cs,HIGH,production_equipment,false
CHG-501,Approve_Change,2026-08-11T09:00:00Z,u_bk,HIGH,production_equipment,false
...
""")
df = pd.read_csv(data)
df['time:timestamp'] = pd.to_datetime(df['time:timestamp'])

df = dataframe_utils.convert_timestamp_columns_in_df(df)
df = dataframe_utils.format_dataframe(df)

# Normalize aliases
alias_map = {'u_bk': 'b.koch', 'b.koch': 'u_bk'}
df['org:resource'] = df['org:resource'].replace(alias_map)

# Filter events based on segregation rules
draft_approve_violations = four_eyes_principle.filter_cases(df, 'Draft_Change_Request', 'Approve_Change')
implement_verify_violations = four_eyes_principle.filter_cases(df, 'Implement_Change', 'Verify_Implementation')

# Analyze handover of work
handover_network = basic_metrics.apply(df).get('handover_of_work')

# Inspect working-together networks
working_together_network = basic_metrics.apply(df).get('working_together')

print(draft_approve_violations, implement_verify_violations, handover_network, working_together_network)
```

## 6. Control Improvements

1. **Delegation Creation and Recording**:
   - Make delegation explicit with immediate timestamp registration.
   - Prohibit retroactive or post-facto delegation modification.
2. **Availability Tracking**:
   - Establish real-time role absence designation in the system.
3. **Session Attribution**:
   - Enforce individual re-authentication and biometrics for service accounts.
4. **Rotation Requirements**:
   - Introduce pair rotation to prevent over-reliance on specific collaborations.
