def overlap_rate(group):
    starts = group["start_timestamp"].values
    ends = group["time:timestamp"].values
    overlaps = 0
    for i in range(len(starts)):
        for j in range(i+1, len(starts)):
            if not (ends[i] <= starts[j] or ends[j] <= starts[i]):
                overlaps += 1
    return overlaps / len(group) if len(group) > 1 else 0

# 6. Data-collection redesign

1. **Execution timestamps**: Mandate start/complete events at the moment of physical transition, not form submission or group button press.
2. **Recording timestamps**: Log database insertion time with sub-second precision and associate with user/badge identity.
3. **Source clocks**: Synchronize all sources to a common clock; log clock skew and drift.
4. **Resource/badge identity**: Capture individual badge IDs; flag shared accounts explicitly.
5. **Group/batch identifiers**: Emit explicit batch start/complete events when a group button is pressed or a fixture is loaded.
6. **Workstation capacity**: Record capacity limits and current occupancy at queue arrival and start.
7. **Pause/resume events**: Log pauses explicitly; distinguish from idle time.
8. **Timestamp precision metadata**: Store documented precision and accuracy bounds for each source.

---

# 7. Final adjudication

- **High confidence**: G1 (start batching), G4 (sequential), G8 (sequential). These preserve physical semantics and require no correction.
- **Exclude or interval-censor**: G6 (collapse to single timestamp; both waiting and service inflated), G7 (use interval censoring; timestamp coarsening inflates waiting).
- **Require operational validation**: G2, G3, G5. End batching and shared-account artifacts need confirmation from operators before performance conclusions.
