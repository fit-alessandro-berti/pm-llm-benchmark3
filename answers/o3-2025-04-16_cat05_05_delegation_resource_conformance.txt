## 2. Rule Interpretation

RR1 (Drafter/approver) and RR2 (Implementer/verifier) demand different humans after alias normalisation.

RR3 (High-risk approval)  
• Approver  {QM principal or valid QM delegate}.  
• Delegate validity = signed delegation created before use  event timestamp  effective interval  scope match  principal formally absent/unavailable  no sub-delegation.  
• If the principal acts personally, RR3 is satisfied regardless of leave status; the leave only removes the “absence” pre-condition for any active delegation.

RR4 (Emergency substitution)  
• Emergency flag = true  credible safety reason (not checked in log).  
• Approver = IC principal or delegate (same validity rules as RR3).  
• Retrospective_QM_Review by QM or delegate  2 business days after Implement_Change.  
Business-day count: local plant calendar; weekends excluded; day 0 = day of implementation; deadline = close of business on day 2 at 23:59 local.

RR5 (Identity evidence)  
• Service accounts are compliant only if session  authenticated human (badge+token/FIDO or equivalent).  
• Weak session attribution downgrades evidence strength and may hide SoD violations.

RR6 (Suspicion  Proof) guides classification language; indicators alone do not yield “UNAUTHORIZED”.

Late database entry: the signed primary document prevails; migration artefacts cannot invalidate otherwise proper delegations.

## 5. PM4Py and pandas Checking Code
```python
import io, pandas as pd, pm4py
from datetime import datetime, timedelta

# --- 1. Reconstruct CSV ---
csv = """case:concept:name,concept:name,time:timestamp,org:resource,risk,scope,emergency
CHG-501,Draft_Change_Request,2026-08-11T08:00:00Z,u_cs,HIGH,production_equipment,false
... (same content as supplied) ...
CHG-510,Retrospective_QM_Review,2026-08-12T10:00:00Z,u_bk,HIGH,cooling_system,true"""
# For brevity the ellipsis is replaced by the full text in real execution
log_df = pd.read_csv(io.StringIO(csv))

# --- 2. Parse timestamps and format for PM4Py ---
log_df['time:timestamp'] = pd.to_datetime(log_df['time:timestamp'], utc=True)
log_df = pm4py.format_dataframe(log_df,
                                case_id='case:concept:name',
                                activity_key='concept:name',
                                timestamp_key='time:timestamp')

# --- 3. Alias normalisation ---
alias_map = {'b.koch': 'u_bk'}
log_df['org:resource'] = log_df['org:resource'].replace(alias_map)

# --- 4. Four-eyes (RR1) check Draft vs Approve ---
draft_vs_approve = pm4py.filter_four_eyes_principle(
    log_df, ['Draft_Change_Request'], ['Approve_Change'],
    attr_key='org:resource')

# implement vs verify (RR2)
impl_vs_verify = pm4py.filter_four_eyes_principle(
    log_df, ['Implement_Change'], ['Verify_Implementation'],
    attr_key='org:resource')

print("RR1 violations (drafter=approver):", draft_vs_approve['case:concept:name'].unique())
print("RR2 violations (implementer=verifier):", impl_vs_verify['case:concept:name'].unique())

# --- 5. Delegation intervals (RR3 / RR4) ---
# Build delegation DataFrame
delegations = [
    ('Asha Rao','u_bk', pd.Interval(pd.Timestamp('2026-08-10', tz='UTC'),
                                    pd.Timestamp('2026-08-14 23:59', tz='UTC'), closed='both'),
     'production_equipment', 'QM'),
    ('Asha Rao','u_en', pd.Interval(pd.Timestamp('2026-08-15', tz='UTC'),
                                    pd.Timestamp('2026-08-15 23:59', tz='UTC'), closed='both'),
     'training_document', 'QM'),
    ('Diego Martins','u_fl', pd.Interval(pd.Timestamp('2026-08-11 12:00', tz='UTC'),
                                         pd.Timestamp('2026-08-11 18:00', tz='UTC'), closed='both'),
     'CI-44', 'IC')
]
del_df = pd.DataFrame(delegations, columns=['principal','delegate','interval','scope','role'])

def is_delegate(row):
    rec = del_df[del_df['delegate'] == row['org:resource']]
    if rec.empty:
        return False
    # Compare timestamp to interval
    return any(row['time:timestamp'] in iv for iv in rec['interval'])

log_df['is_delegate'] = log_df.apply(is_delegate, axis=1)

# show where high-risk approvals are NOT by QM or valid delegate
hr_approvals = log_df[(log_df['concept:name'] == 'Approve_Change') & (log_df['risk'] == 'HIGH')]
invalid_hr = hr_approvals[~(
    (hr_approvals['org:resource'].isin(['u_as'])) | (hr_approvals['is_delegate'])
)]
print("High-risk approvals lacking valid QM authority:", invalid_hr[['case:concept:name','org:resource']])

# --- 6. Handover & Working-together networks ---
hand_net = pm4py.discover_handover_of_work_network(log_df)
wt_net = pm4py.discover_working_together_network(log_df)
print("Handover network edges (weight>1):", [(e[0], e[1], d) for e,d in hand_net['matrix'].items() if d>1])

# --- 7. Optional filter for repeated approvals ---
same_resource_impl = pm4py.filter_activity_done_different_resources(
     log_df, 'Approve_Change', 'org:resource')
print("Cases with single-person multiple approvals:", same_resource_impl['case:concept:name'].unique())

# Note: svc_qms is left untouched so analysts can inspect sessions manually.
```

## 6. Control Improvements

1. Delegation creation  
   • Enforce digital-signature workflow that automatically writes the record before the start time.  
   • Block sub-delegation by system rule, not policy text.

2. Effective-time recording  
   • System clock adds delegation to access-control list only when interval actually starts.

3. Principal availability  
   • Duty-status flag integrated with HR leave calendar; delegation auto-activates only when principal status = “unavailable”.

4. Alias management  
   • Single identity store; login aliases are symbolic links, not distinct user objects.

5. Individual authentication on shared workstations  
   • Mandatory re-auth (smart-card, FIDO) for every critical transaction; service accounts may open the application, but approval button needs personal re-auth.

6. Emergency review timer  
   • Workflow engine starts countdown and escalates at 36 h; prevents 3-day lapse seen in CHG-505.

7. Pair rotation / SoD analytics  
   • Dashboard shows approver concentration by drafter to trigger preventive rotation.

8. Network & forensic logging  
   • Map workstation SID to user, capture CCTV stills, retain for 90 days.

9. Evidential retention  
   • Keep raw delegation-documents and session logs in WORM storage to survive database migrations.
