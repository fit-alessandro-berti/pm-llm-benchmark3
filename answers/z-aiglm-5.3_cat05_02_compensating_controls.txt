def case_ids(result):
    if isinstance(result, pd.DataFrame):
        key = "case:concept:name" if "case:concept:name" in result.columns else None
        if key is None:
            # pm4py may have renamed standard columns in some versions
            for cand in ("case:concept:name", "@@case_id", "case_id"):
                if cand in result.columns:
                    key = cand; break
        return set(result[key].unique()) if key else set()
    # EventLog object
    ids = set()
    for trace in result:
        ids.add(trace.attributes.get("concept:name", trace.attributes.get("case:concept:name")))
    return ids

Inputs: case fact pattern. Evaluate dimensions:
- T (timing) with levels.
- I (independence): levels: independent; conflicted (supervisor/rating); captured (shared credential/pair); system (AV-2; independence N/A but integrity assumptions).

- E (evidence quality): contemporaneous signed/ logged, reconstructable; unsigned = absent.
- CR (collusion resistance): minimum number of independent humans an adversary must subvert; pair capture reduces to 1.

Decision rule (tiers):
- Fully equivalent: For every threat in FEP-1 scope (O1, O2, O4-partial, O5), there exists a control acting at T0/T1 with independence  independent, hard enforcement or independent override, evidence adequate, and a T2 backstop. - Merely mitigating: no authorization-time assurance for the primary threat; only likelihood/loss reduction (T2/T3) — e.g., post-settlement ratification, late audit.
- Ineffective: primary preventive control absent, defeated by same actor, or fail-open; or evidence absent so no assurance can be attributed.

def case_ids_of(obj):
    """Return set of case ids whether pm4py returned a DataFrame or EventLog."""
    if isinstance(obj, pd.DataFrame):
        for key in ("case:concept:name", "@@case_id", "case_id", "case"):
            if key in obj.columns:
                return set(obj[key].astype(str).unique())
        raise KeyError("no case-id column found in pm4py result")
    out = set()
    for trace in obj:                          # EventLog / list of traces
        cid = trace.attributes.get("concept:name",
             trace.attributes.get("case:concept:name", None))
        out.add(str(cid))
    return out

## 4. Preventive–Detective–Corrective Comparison

The fix is enforcement and availability, not headcount.

**AP-201.** *Mechanism:* convenience same-user handling opens a ~2-hour window (08:06–10:00) for unilateral error or fraud inside AV-2's blind spots; nothing realized. *Chain-breaker (actual):* AV-2 for covered mechanical errors; m04's independent pre-settlement ratification for visible anomalies; audit ~23 h after settlement, just inside the recall window. *Remains exposed:* defects invisible on the document face (commercial reasonableness, receipt); the 24-minute pre-ratification window; ratification not structurally blocking settlement. *Truly independent second releaser:* eliminates the nominal violation; case-level risk delta small, portfolio-level value real — tolerated convenience erodes the norm (the same day, AP-205 shows a user attempting same-user release). **AP-206.** *Mechanism (risk story):* not loss through this payment but pathway abuse — a token created after preparation indicates ED-1's precondition can be satisfied retroactively; if tolerated, non-emergencies can be routed through the emergency path and audit attention diluted. *Chain-breaker (actual, case level):* m11's pre-release independent approval. *Chain-breaker (missing, systemic):* workflow-enforced token-before-prepare with immutable token logs. *Remains exposed:* the integrity of every ED-1 use until token forensics; if creation is routinely post hoc, emergency volume becomes a laundering channel. *Truly independent second releaser:* redundant for this payment — approval already preceded release; the binding fix is permission governance, not separation.

**AP-209.** *Mechanism:* pair capture — u12/u13 operating as one effective controller (shared workstation, 37 co-approvals in 30 days); any payment they co-process may be single-actor in substance. *Chain-breaker (missing):* pair rotation, concentration monitoring, manager sampling of pair output. *Remains exposed:* the pair's 30-day portfolio pending re-review, and future payments until rotation or a documented cell design exists. *Truly independent second releaser:* restores separation only if the partner actually rotates — a fixed partner is precisely the captured configuration. **Portfolio observation.** The two gravest packages (AP-202, AP-208) failed at the same two joints — AV-2's overrideability and its availability — both around bank-account changes, which is where diversion risk concentrates. The human checkpoints failed by timing, arriving after irrevocability. The weakest links in this architecture are enforcement design and control availability, not the presence of human activities.
