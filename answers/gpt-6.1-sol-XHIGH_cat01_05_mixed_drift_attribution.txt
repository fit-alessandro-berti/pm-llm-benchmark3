## 2. Raw-versus-normalized interpretation

The March raw fitness collapse is primarily evidence of changed representation. Against the January–February reference of 0.925, raw fitness falls to 0.55 while mapped fitness is 0.90. The 0.35 gap numerically restores about 93% of that baseline-relative loss. This is a scoring comparison, not the percentage of drift caused by migration. Fitness depends on the model, alignment procedure, aggregation, and trace completeness.

Mapping Eligibility Screen to Validate Eligibility and removing confirmed duplicate technical records restores recognizable paths. It does not establish that screening rules, decision criteria, work content, or timestamps remained equivalent. Validate the mapping against event provenance and business definitions. Frequency changes among allowed paths can constitute behavioral drift while retaining high fitness; increased use of a permitted Request Info loop is not automatically a conformance violation. Residual fitness loss requires inspection of alignment deviations and model coverage.

Duplicate Open Case records can inflate event counts, invent DFG edges, fragment variants, and distort event-based timing. Deduplication must identify technical duplicates rather than remove legitimate repeated work. Missing resource identifiers primarily damage handover networks, workload attribution, team comparisons, and service estimates; their concentration in migrated activities makes complete-resource analysis potentially selective.

After May, normalized Request Info rates rise from 12 to 24–29 per 100 cases, while cycle-time tails and reconstructed assessment queues increase. These jointly undermine a logging-only account. However, operational variant percentages were not explicitly normalized: recompute them from canonical traces, audit timestamp semantics, and standardize for supplier, complexity, region, and censoring before claiming within-population behavioral change.

def aggregate_analysis():
    monthly = pd.read_csv(StringIO(MONTHLY_CSV)).set_index("month")
    rates = pd.read_csv(StringIO(DFG_CSV)).set_index("month")
    expected = pd.period_range("2026-01", "2026-12", freq="M").astype(str)
    assert monthly.index.is_unique and list(monthly.index) == list(expected)
    assert rates.index.is_unique and rates.index.is_monotonic_increasing
    assert rates.index.isin(monthly.index).all() and rates.shape[1] == 7
    assert not monthly.isna().any().any() and not rates.isna().any().any()
    assert np.isfinite(monthly.to_numpy(dtype=float)).all()
    assert np.isfinite(rates.to_numpy(dtype=float)).all()
    assert (monthly["cases"] > 0).all()
    assert (monthly["cases"] % 1 == 0).all()
    assert (monthly["distinct_activity_labels"] % 1 == 0).all()
    pct_cols = [c for c in monthly.columns if c.endswith("_pct")]
    assert monthly[pct_cols].ge(0).all().all()
    assert monthly[pct_cols].le(100).all().all()
    fitness_cols = ["raw_model_fitness", "mapped_model_fitness"]
    assert monthly[fitness_cols].ge(0).all().all()
    assert monthly[fitness_cols].le(1).all().all()
    assert (monthly["mapped_model_fitness"] >= monthly["raw_model_fitness"]).all()
    assert (monthly["median_cycle_h"] >= 0).all()
    assert (monthly["p90_cycle_h"] >= monthly["median_cycle_h"]).all()
    assert rates.ge(0).all().all()  # Rates may exceed 100 when loops repeat.

    # Equal-month reference, not the pooled case-level median or fitness.
    baseline = monthly.loc[["2026-01", "2026-02"]].mean()
    delta = monthly.subtract(baseline, axis="columns")
    print("BASELINE: equal-month January-February means")
    print(baseline.round(3).to_string())
    print("BASELINE-RELATIVE CHANGES: percentages in pp; fitness in 0-1 units")
    print(delta.round(3).to_string())

    distance = pd.DataFrame(index=rates.index)
    distance["L1_vs_January"] = rates.sub(rates.iloc[0]).abs().sum(axis=1)
    distance["mean_abs_vs_January"] = distance["L1_vs_January"] / rates.shape[1]
    distance["L1_vs_previous_available"] = rates.diff().abs().sum(axis=1)
    distance.iloc[0, distance.columns.get_loc("L1_vs_previous_available")] = np.nan
    print("DFG DISTANCES: total occurrences per 100 cases across seven features")
    print(distance.round(3).to_string())

    recovery = pd.DataFrame(index=monthly.index)
    recovery["mapped_minus_raw"] = (
        monthly["mapped_model_fitness"] - monthly["raw_model_fitness"]
    )
    recovery["fraction_raw_penalty_removed"] = (
        recovery["mapped_minus_raw"] / (1 - monthly["raw_model_fitness"])
    )
    apparent_loss = baseline["raw_model_fitness"] - monthly["raw_model_fitness"]
    recovery["fraction_baseline_relative_loss_recovered"] = (
        recovery["mapped_minus_raw"] / apparent_loss.where(apparent_loss > 0)
    )
    print("FITNESS RECOVERY: numerical diagnostic, not a causal decomposition")
    print(recovery.round(4).to_string())

    # Transparent screening thresholds chosen for this exercise, not calibrated
    # significance tests or estimated exact change-point dates.
    step = monthly.diff()
    eps = 1e-9
    flags = pd.DataFrame(False, index=monthly.index,
                         columns=["logging", "behavioral", "performance"])
    flags["logging"] = (
        (recovery["mapped_minus_raw"].diff().abs() >= 0.03 - eps)
        | (step["missing_resource_pct"].abs() >= 0.35 - eps)
        | (step["duplicate_open_case_pct"].abs() >= 1.0 - eps)
    )
    flags["behavioral"] = step["rework_variant_pct"].abs() >= 5 - eps
    dfg_flag = distance["L1_vs_previous_available"] >= 25 - eps
    flags.loc[rates.index, "behavioral"] |= dfg_flag
    flags["performance"] = (
        (step["median_cycle_h"].abs() >= 3 - eps)
        | (step["p90_cycle_h"].abs() >= 10 - eps)
    )
    flags.iloc[0] = False
    print("CANDIDATE BOUNDARIES: direction shown separately by monthly differences")
    print(flags.to_string())
    for dimension in flags.columns:
        print(dimension, list(flags.index[flags[dimension]]))
    print("CAVEAT: omitted DFG edges are unknown, not zero; rates are not a probability distribution.")
    print("CAVEAT: DFG comparisons span unequal intervals; February/other missing fragments are not interpolated.")
    print("CAVEAT: rounded aggregates cannot identify causal shares, within-group changes, censoring, or exact dates.")
    print("CAVEAT: medians/p90s are not additive; apparent recovery fractions are not causal fractions.")
    print("CAVEAT: variant definitions outside mapped fitness have not been proven label-normalized.")
    return monthly, rates, delta, distance, recovery, flags


# PART B: reusable event-level functions; no event log is supplied or loaded.
# Requires PM4Py and pandas. Imports are lazy so Part A needs no PM4Py installation.
CASE, ACT, TIME = "case:concept:name", "concept:name", "time:timestamp"

def utc_timestamp(value):
    stamp = pd.Timestamp(value)
    return stamp.tz_localize("UTC") if stamp.tzinfo is None else stamp.tz_convert("UTC")

def format_events(frame, case_col="case_id", activity_col="activity",
                  timestamp_col="timestamp", order_col=None):
    import pm4py
    required = [case_col, activity_col, timestamp_col]
    if not set(required).issubset(frame.columns):
        raise ValueError("Missing case, activity, or timestamp column")
    out = frame.copy(deep=True)
    if out[required].isna().any().any():
        raise ValueError("Case, activity, and timestamp must be present")
    out[case_col] = out[case_col].astype(str)
    out[activity_col] = out[activity_col].astype(str)
    if out[case_col].str.strip().eq("").any() or out[activity_col].str.strip().eq("").any():
        raise ValueError("Empty case/activity identifier")
    out[timestamp_col] = pd.to_datetime(out[timestamp_col], utc=True, errors="raise")
    if out[timestamp_col].isna().any():
        raise ValueError("Invalid timestamp")
    if "_diagnostic_source_row" not in out:
        out["_diagnostic_source_row"] = np.arange(len(out))
    keys = [case_col, timestamp_col]
    if order_col is not None:
        if order_col not in out or out[order_col].isna().any():
            raise ValueError("Supplied ordering column is missing or incomplete")
        keys.append(order_col)
    elif out.duplicated([case_col, timestamp_col]).any():
        warnings.warn("Tied timestamps: source row order is provisional; verify event ordering.")
    keys.append("_diagnostic_source_row")
    out = out.sort_values(keys, kind="stable")
    # Resource NA values and all context/provenance columns are preserved.
    return pm4py.format_dataframe(out, case_id=case_col,
                                 activity_key=activity_col,
                                 timestamp_key=timestamp_col)

def event_window(formatted, start, end):
    """Half-open UTC event interval [start, end); this may truncate traces."""
    import pm4py
    lo, hi = utc_timestamp(start), utc_timestamp(end)
    if lo >= hi:
        raise ValueError("Window start must precede end")
    # PM4Py accepts these second-resolution strings. Pad outward, then enforce
    # exact bounds to handle subsecond timestamps and the API's inclusive end.
    subset = pm4py.filter_time_range(
        formatted.copy(deep=True),
        lo.floor("s").strftime("%Y-%m-%d %H:%M:%S"),
        hi.ceil("s").strftime("%Y-%m-%d %H:%M:%S"), mode="events"
    )
    return subset.loc[(subset[TIME] >= lo) & (subset[TIME] < hi)].copy()

def intake_cohort(formatted, start, end):
    """Select by first Register; retain all observed events for those cases."""
    registered = formatted.loc[formatted[ACT].eq("Register")].copy()
    registered = registered.sort_values(TIME).drop_duplicates(CASE, keep="first")
    anchors = event_window(registered, start, end)
    no_register = formatted[CASE].nunique() - registered[CASE].nunique()
    if no_register:
        warnings.warn(f"{no_register} cases have no Register; audit separately, not as cohort members.")
    return formatted.loc[formatted[CASE].isin(anchors[CASE])].copy()

def monthly_artifacts(formatted, months, as_of=None, include_constraints=False):
    """DFGs/temporal profiles use all observed intake-cohort prefixes.
    Complete variants/constraints use cases with Close; completion share is explicit.
    Do not interpret the complete subset as an unbiased performance population.
    """
    import pm4py
    snapshot = formatted.copy(deep=True)
    if as_of is not None:
        snapshot = snapshot.loc[snapshot[TIME] < utc_timestamp(as_of)].copy()
    result = {}
    for month in months:
        start = pd.Timestamp(f"{month}-01", tz="UTC")
        end = start + pd.offsets.MonthBegin(1)
        cohort = intake_cohort(snapshot, start, end)
        if cohort.empty:
            result[month] = {"cases": 0, "dfg": {}, "variants_complete": {}}
            continue
        closed_ids = cohort.loc[cohort[ACT].eq("Close"), CASE].unique()
        complete = cohort.loc[cohort[CASE].isin(closed_ids)].copy()
        dfg, starts, ends = pm4py.discover_dfg(cohort)
        n = cohort[CASE].nunique()
        item = {
            "cases": n, "closed_cases": len(closed_ids),
            "completion_share": len(closed_ids) / n,
            "dfg": dfg, "dfg_per_100_cases": {e: 100 * v / n for e, v in dfg.items()},
            "start_activities": starts, "end_activities": ends,
            "variants_complete": pm4py.get_variants(complete) if not complete.empty else {},
            "variants_observed_prefixes": pm4py.get_variants(cohort),
            # These are event-to-event elapsed times (seconds), NOT service or
            # queue durations without lifecycle/ready-for-assessment timestamps.
            "temporal_profile": pm4py.discover_temporal_profile(cohort),
        }
        if include_constraints and not complete.empty:
            item["log_skeleton"] = pm4py.discover_log_skeleton(complete)
            item["declare"] = pm4py.discover_declare(complete)
        result[month] = item
    return result

def compare_raw_normalized(frame, months, case_col="case_id", activity_col="activity",
                           timestamp_col="timestamp", duplicate_open_flag=None,
                           order_col=None, as_of=None, include_constraints=False):
    """Never modify frame. A duplicate flag must identify confirmed technical
    Open Case duplicates by provenance; repeated activity labels alone are insufficient.
    """
    raw_source = frame.copy(deep=True)
    raw_source["_diagnostic_source_row"] = np.arange(len(raw_source))
    normalized_source = raw_source.copy(deep=True)
    normalized_source["_original_activity"] = normalized_source[activity_col]
    if duplicate_open_flag is not None:
        if duplicate_open_flag not in normalized_source:
            raise ValueError("Duplicate flag column is absent")
        flags = normalized_source[duplicate_open_flag]
        if not pd.api.types.is_bool_dtype(flags) or flags.isna().any():
            raise ValueError("Duplicate flag must contain complete Boolean values")
        if (flags & normalized_source[activity_col].ne("Open Case")).any():
            raise ValueError("This normalizer removes only confirmed Open Case duplicates")
        normalized_source = normalized_source.loc[~flags].copy()
    else:
        warnings.warn("No trusted duplicate flag: only labels are mapped; Open Case events remain.")
    normalized_source[activity_col] = normalized_source[activity_col].replace(
        {"Eligibility Screen": "Validate Eligibility"}
    )
    args = dict(case_col=case_col, activity_col=activity_col,
                timestamp_col=timestamp_col, order_col=order_col)
    raw = format_events(raw_source, **args)
    normalized = format_events(normalized_source, **args)
    artifact_args = dict(months=months, as_of=as_of,
                         include_constraints=include_constraints)
    raw_monthly = monthly_artifacts(raw, **artifact_args)
    normalized_monthly = monthly_artifacts(normalized, **artifact_args)
    if set(raw[CASE]) != set(normalized[CASE]):
        warnings.warn("Canonicalization changed the case population; audit unmatched cases.")
    comparison = pd.DataFrame([
        {"month": month,
         "raw_cases": raw_monthly[month]["cases"],
         "normalized_cases": normalized_monthly[month]["cases"],
         "raw_complete_variant_count": len(raw_monthly[month]["variants_complete"]),
         "normalized_complete_variant_count": len(normalized_monthly[month]["variants_complete"])}
        for month in months
    ])
    return {
        "raw_log": raw, "normalized_log": normalized,
        "raw_activity_counts": raw[ACT].value_counts().to_dict(),
        "normalized_activity_counts": normalized[ACT].value_counts().to_dict(),
        "removed_technical_events": len(raw) - len(normalized),
        "raw_monthly": raw_monthly, "normalized_monthly": normalized_monthly,
        "comparison": comparison,
    }

if __name__ == "__main__":
    aggregate_analysis()  # Part B is defined, but never run without a supplied log.

## 9. Provisional attribution

Confidence is qualitative and applies to a particular observed change, not to an exclusive allocation of total drift.

The strongest conclusion, with high confidence, is that March's raw fitness collapse chiefly reflects migration semantics and provenance. Canonicalization restores fitness from 0.55 to 0.90, while the normalized DFG distance is only 3 and cycle times remain near baseline. Duplicate technical events and resource missingness also begin then. Small residual business or measurement changes remain possible.

With moderate-to-high confidence, supplier disruption contributes to the May–summer rework increase. The timing, normalized Request Info loops, and partial September reversal agree. However, Supplier Z's non-random customers and its sharply increased share mean aggregate changes cannot establish the size of a within-Z quality effect. Document incompleteness can mediate additional assessment visits and external waiting.

Staffing loss is a moderately strong explanation for further June–August queue growth and persistence. Recorded Assess service increases only modestly, whereas reconstructed waiting increases substantially. Supplier rework raises effective assessment demand, so departures and defective bundles interact; their effects cannot be independently read from cycle-time aggregates. Queue timestamp validity remains a condition of this attribution.

October's population shift is directly observed with high confidence. Its attribution to renewals is well supported by the supplied history, but annual recurrence is not demonstrated by this single year. Seasonal volume and complexity plausibly amplify queues under reduced capacity. The senior-route increase could combine population change, greater conditional use, and better recording; none is isolated here.

Priority-induced redistribution is plausible but unverified: high-complexity waiting may improve while standard waiting worsens. Persistent behavioral adaptation is likewise a low-confidence explanation for residual canonical differences; backlog, mix, and incomplete recovery remain sufficient alternatives. December intervention effects have low-to-moderate confidence because overtime, quality work, and seasonal relief coincide.

I would revise this account if matched supplier cohorts show no quality/rework change, credible lifecycle data contradict queue growth, fixed-mixture comparisons remove the later differences, or reviewer/source audits explain senior routing entirely. Sustained improvements in comparable new cohorts with measured intervention exposure would strengthen recovery attribution. Missingness-sensitive analyses and repeated comparable renewal seasons are needed before assigning causal shares or declaring recurrence.

## 10. Monitoring decision rules

1. IF raw fitness falls while paired canonical fitness, canonical paths, and independently validated timing remain stable, THEN audit aliases, technical duplicates, timestamp semantics, and resource capture before changing operations, BECAUSE migration can change representation without changing execution.
2. IF Request Info probability and repeat counts rise within comparable Supplier Z intake strata after May and track incomplete bundles, THEN prioritize supplier-quality remediation and measure document waits plus added assessment visits, BECAUSE defective inputs can produce rework and mediate downstream workload.
3. IF valid ready-to-Assess waits and backlog rise after staffing loss while standardized service per visit remains stable, THEN review staffed capacity against first and repeat assessment demand, BECAUSE a capacity shortfall can increase queues much more than active processing time.
4. IF post-July waiting improves for priority-eligible cases but worsens for comparable standard cases, THEN evaluate both classes against service targets and adjust the priority/capacity policy where warranted, BECAUSE queue reprioritization can redistribute delay while leaving DFG sequences unchanged.
5. IF renewal-period aggregate paths and cycle times change but conditional artifacts stay within established seasonal ranges, THEN classify the pattern as recurring population drift and plan seasonal capacity while continuing residual monitoring, BECAUSE changing mixture and load can reproduce earlier seasonal behavior.
6. IF increased senior routing is explained by stable complexity-specific rates or changed reviewer recording, THEN classify it as population or ascertainment drift and update the reference metadata, BECAUSE aggregate senior edges alone do not establish new assessment behavior.
7. IF December gains disappear after fixing case mix and follow-up, or comparable new post-recovery cohorts remain slow, THEN retain seasonal, backlog, and capacity explanations and evaluate overtime and quality-campaign exposure separately, BECAUSE coincident interventions and residual workload prevent clean recovery attribution.
