import pm4py
from collections import Counter

def validate_round_trip(original_net, orig_im, orig_fm, roundtrip_net, rt_im, rt_fm, max_loop_iter=3):
    """
    Compares original and round-tripped nets using bounded trace exploration.
    Returns True if behaviorally equivalent within bounds.
    """
    if original_net is None or roundtrip_net is None:
        return False, "One net is missing."

    # 1. Soundness Check (Pre-requisite)
    if not pm4py.check_soundness(original_net, orig_im, orig_fm):
        return False, "Original net unsound."
    if not pm4py.check_soundness(roundtrip_net, rt_im, rt_fm):
        return False, "Round-trip net unsound."

    # 2. Footprint Comparison
    # Discover footprints (direct succession)
    fp_orig = pm4py.discover_footprints(original_net, orig_im, orig_fm)
    fp_rt = pm4py.discover_footprints(roundtrip_net, rt_im, rt_fm)
    
    # Normalize footprint keys (ignore silent transitions)
    def normalize_fp(fp):
        norm = {}
        for k, v in fp.items():
            src, tgt = k
            # Filter out silent transitions (label is None)
            t_src = [t for t in original_net.transitions if t.name == src][0] if any(t.name == src for t in original_net.transitions) else None
            t_tgt = [t for t in original_net.transitions if t.name == tgt][0] if any(t.name == tgt for t in original_net.transitions) else None
            
            # Skip if either is silent (tau)
            if (hasattr(t_src, 'label') and t_src.label is None) or \
               (hasattr(t_tgt, 'label') and t_tgt.label is None):
                continue
            norm[k] = v
        return norm

    f_orig = normalize_fp(fp_orig)
    f_rt = normalize_fp(fp_rt)
    
    if f_orig != f_rt:
        return False, f"Footprints differ.\nOrig: {f_orig}\nRT: {f_rt}"

    # 3. Bounded Visible Trace Exploration
    # We explore traces up to a length limit to avoid infinite loops
    # We enforce exact final marking equality for completed traces
    def get_enabled_visible_traces(net, im, fm, max_len=20):
        traces = []
        queue = [(im, [])] # (marking, trace_labels)
        
        while queue:
            curr_marking, curr_trace = queue.pop(0)
            
            if len(curr_trace) > max_len:
                continue
                
            # Check if finished
            if curr_marking == fm:
                # Filter silent transitions from trace for comparison
                visible_trace = [t for t in curr_trace if t is not None]
                traces.append(tuple(visible_trace))
                continue
            
            enabled = pm4py.get_enabled_transitions(net, curr_marking)
            for trans in enabled:
                new_marking = pm4py.fire_transition(net, curr_marking, trans)
                # Get label, default to None for silent
                label = getattr(trans, 'label', None)
                queue.append((new_marking, curr_trace + [label]))
                
        return set(traces)

    tr_orig = get_enabled_visible_traces(original_net, orig_im, orig_fm, max_len=20)
    tr_rt = get_enabled_visible_traces(roundtrip_net, rt_im, rt_fm, max_len=20)

    if tr_orig != tr_rt:
        return False, f"Trace sets differ.\nOrig count: {len(tr_orig)}, RT count: {len(tr_rt)}"

    return True, "Validation passed within bounds."

# Execute Validation
if net_from_powl is not None and net_roundtrip_a is not None:
    is_valid, msg = validate_round_trip(net_from_powl, im_from_powl, fm_from_powl, net_roundtrip_a, im_roundtrip_a, fm_roundtrip_a)
    print(f"\nRound-Trip Validation Result: {is_valid} - {msg}")
else:

3.  **Loop Visualization:** The `verification_loop` is rendered as a loop marker or a cycle in BPMN. Without explicit annotation, the boundary of the loop (where `Correct Defect` re-enters) might be ambiguous compared to the explicit `Operator.LOOP` in the source.
4.  **Layout-Induced Ordering:** Graph layout algorithms prioritize aesthetics over causality. An edge crossing might visually imply `Assess Risk` happens after `Prepare Evidence`, violating INV-02, even though the token flow allows concurrency.
5.  **Proposed Annotations:**
    *   Add text annotations near gateways stating "Wait for All Inputs" (for AND) or "Choose One Path" (for XOR).
    *   Explicitly label the silent path as "(Optional - Skip Legal)" to prevent confusion about missing steps.
    *   Document the maximum allowed loop iterations in a property panel, as BPMN does not natively enforce iteration counts without extensions.

# 7. Rejection Criteria

A conversion result must be rejected or quarantined if any of the following conditions are met:

1.  **Unsoundness:** `pm4py.check_soundness` returns `False` (deadlock, livelock, or improper termination).
2.  **Loss of Required Interleaving:** The round-trip footprint shows a fixed order between `Assess Risk` and `Prepare Evidence` (violating INV-02).
3.  **Admission of Early Release:** Traces exist where `Release Change` fires before `Verification Loop` completes (violating INV-07).
4.  **Collapse of Optional Behavior:** The XOR with Silent transition is converted to a mandatory sequence or removed entirely (violating INV-03).
5.  **Failed Exact-Final-Marking Test:** The round-tripped net reaches a different final marking configuration than the source (tokens left in intermediate places).
6.  **Infinite Silent Cycling:** The conversion introduces a cycle of silent transitions that can fire indefinitely without producing visible output (livelock hidden in routing).

# 8. Canonical Representation Recommendation

**Authoritative Model:** **POWL (StrictPartialOrder)**.
*   **Reasoning:** The source model explicitly defines partial ordering and concurrency without forcing a block structure. It captures the "true" technical change requirements (parallelism, synchronization points) most accurately.
*   **Derivatives:**
    *   **Petri Net:** For execution semantics and formal verification (soundness).
    *   **BPMN:** For stakeholder communication and UI generation.
    *   **Process Tree:** **Do Not Store.** It is derivative and prone to failure (as seen in Pipeline B). Only generate temporarily for specific analysis tools.

**Validation Evidence:**
*   Every BPMN artifact must include a hash of the source POWL version.
*   Every BPMN artifact must pass the soundness check (`check_soundness`) before deployment.
*   Round-trip trace equivalence must be logged in the metadata of the generated BPMN file.

**Future Edits:**
*   Edits must occur in the POWL layer. Regenerate Petri Nets and BPMNs automatically.
*   Do not allow manual editing of the BPMN diagram, as this introduces "round-trip drift" where the visual representation diverges from the executable logic.

# 9. Residual Uncertainty

Even if all tests pass, the following claims cannot be established:

1.  **Business Rule Compliance:** The model ensures `Legal Review` is optional structurally, but it cannot verify that the *content* of the review meets regulatory standards (semantic meaning of the label).
2.  **Performance Constraints:** The model validates control flow but does not guarantee that `Correct Defect` loops will terminate within a time budget (timing semantics are absent).
3.  **Human Interpretation:** While `skip_legal` is technically valid, the validation cannot prove that a human auditor will not perceive the absence of a legal review step as an error or compliance risk based on organizational policy outside the model.
