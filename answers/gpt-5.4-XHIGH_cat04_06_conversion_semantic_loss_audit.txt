# 1. Source-Semantics Baseline

| Invariant ID | Invariant | Positive witness | Negative witness | Observable after hiding tau? |
| --- | --- | --- | --- | --- |
| S1 | `Register Change` is the first visible activity. | `Register Change, Assess Risk, Prepare Evidence, Configure Trial, Inspect Trial, Release Change, Archive Change` | Any completed trace beginning with `Assess Risk`, `Prepare Evidence`, or `Legal Review` | Yes |
| S2 | After registration, `Assess Risk` and `Prepare Evidence` are both required before verification and are unordered with respect to each other. | Both `Register Change, Assess Risk, Prepare Evidence, ...` and `Register Change, Prepare Evidence, Assess Risk, ...` must complete. | A converted model that forbids one of those two interleavings, or allows verification after only one of them | Yes |
| S3 | `Legal Review` is optional and can occur only after `Assess Risk`; skipping it is represented by a silent branch. | One completed trace contains `Legal Review`; another omits it entirely. | `Legal Review` before `Assess Risk`, or a target in which every completed trace must contain `Legal Review` | Partly |
| S4 | Verification cannot start until both `Assess Risk` and `Prepare Evidence` are complete. | `Register Change, Assess Risk, Prepare Evidence, Configure Trial, Inspect Trial, ...` and `Register Change, Prepare Evidence, Assess Risk, Configure Trial, Inspect Trial, ...` | `Register Change, Assess Risk, Configure Trial, ...` or `Register Change, Prepare Evidence, Configure Trial, ...` | Yes |
| S5 | The optional-legal branch and the verification branch have no precedence edge between them once enabled; if `Legal Review` is chosen, it may occur before, during, or after the visible verification steps, subject to the release join. | `..., Legal Review, Configure Trial, Inspect Trial, Release Change, ...` and `..., Configure Trial, Legal Review, Inspect Trial, Release Change, ...` | A converted model that forces all verification steps before `Legal Review`, or forces `Legal Review` before any verification step | Partly |
| S6 | In every verification iteration, `Configure Trial` precedes `Inspect Trial`. | `..., Configure Trial, Inspect Trial, ...` | `..., Inspect Trial, Configure Trial, ...` | Yes |
| S7 | The loop executes at least one verification iteration; any repeated iteration is separated by `Correct Defect`. | `..., Configure Trial, Inspect Trial, Correct Defect, Configure Trial, Inspect Trial, ...` | `..., Release Change, ...` with no `Configure Trial/Inspect Trial`, or `..., Configure Trial, Inspect Trial, Configure Trial, Inspect Trial, ...` without `Correct Defect` | Yes |
| S8 | `Release Change` waits for completion of both the optional-legal branch and the verification loop. | `..., Legal Review, Configure Trial, Inspect Trial, Release Change, ...` and `..., Configure Trial, Inspect Trial, Release Change, ...` when the skip branch is taken | `..., Assess Risk, Prepare Evidence, Release Change, ...` or `..., Configure Trial, Inspect Trial, Release Change, Legal Review, ...` | Partly |
| S9 | `Archive Change` occurs after `Release Change` and is the final visible activity. | `..., Release Change, Archive Change` | `..., Archive Change, Release Change` or any visible activity after `Archive Change` | Yes |

# 2. Candidate Conversion Pipelines

| Pipeline | PM4Py calls | Expected benefit | Expected risk | Failure condition |
| --- | --- | --- | --- | --- |
| `P1` (primary): `POWL -> accepting Petri net -> BPMN -> accepting Petri net` | `pm4py.convert_to_petri_net(source_powl)`<br>`pm4py.convert_to_bpmn(net_from_powl, im_from_powl, fm_from_powl)`<br>`pm4py.convert_to_petri_net(bpmn_from_net)` | Uses only directly supported conversions for this source; the accepting net is a precise validation anchor; BPMN can be round-tripped back into an accepting net for witness checking. | BPMN routing nodes can visually serialize or obscure concurrency; silent skip behavior becomes gateway structure rather than an explicit task. | Reject if any produced net is not a WF-net, is unsound, lacks non-null markings, or fails witness / bounded-trace comparisons. |
| `P2`: `POWL -> accepting Petri net -> process tree -> BPMN -> accepting Petri net` | `pm4py.convert_to_petri_net(source_powl)`<br>`pm4py.convert_to_process_tree(net_from_powl, im_from_powl, fm_from_powl)` inside `try/except`<br>`pm4py.convert_to_bpmn(tree_from_net)`<br>`pm4py.convert_to_petri_net(bpmn_from_tree)` | If it succeeds, the tree can produce a cleaner block-structured BPMN and makes optionality / loop scope easier to narrate to non-technical readers. | The source has partial-order behavior plus an optional branch that is unordered with a loop branch; a tree parser may reject it or over-serialize it. | Local execution on this source raised `ValueError: Parsing of WF-net Failed`; that is a valid quarantine outcome, not a recoverable success. |

Primary pipeline choice: `P1`. It is the only pipeline that both uses the guaranteed conversions and survived local validation on the provided source model.

# 3. Conversion Code

```python
import json
from pathlib import Path

import pm4py
from pm4py.objects.powl.obj import (
    StrictPartialOrder,
    OperatorPOWL,
    Transition,
    SilentTransition,
)
from pm4py.objects.process_tree.obj import Operator


# Authoritative source model
register = Transition(label="Register Change")
assess_risk = Transition(label="Assess Risk")
prepare_evidence = Transition(label="Prepare Evidence")

legal_review = Transition(label="Legal Review")
skip_legal = SilentTransition()
optional_legal = OperatorPOWL(
    operator=Operator.XOR,
    children=[legal_review, skip_legal],
)

configure_trial = Transition(label="Configure Trial")
inspect_trial = Transition(label="Inspect Trial")
trial_body = StrictPartialOrder(nodes=[configure_trial, inspect_trial])
trial_body.order.add_edge(configure_trial, inspect_trial)

correct_defect = Transition(label="Correct Defect")
verification_loop = OperatorPOWL(
    operator=Operator.LOOP,
    children=[trial_body, correct_defect],
)

release_change = Transition(label="Release Change")
archive_change = Transition(label="Archive Change")

source_powl = StrictPartialOrder(
    nodes=[
        register,
        assess_risk,
        prepare_evidence,
        optional_legal,
        verification_loop,
        release_change,
        archive_change,
    ]
)

source_powl.order.add_edge(register, assess_risk)
source_powl.order.add_edge(register, prepare_evidence)
source_powl.order.add_edge(assess_risk, optional_legal)
source_powl.order.add_edge(assess_risk, verification_loop)
source_powl.order.add_edge(prepare_evidence, verification_loop)
source_powl.order.add_edge(optional_legal, release_change)
source_powl.order.add_edge(verification_loop, release_change)
source_powl.order.add_edge(release_change, archive_change)


OUT = Path("conversion_audit_outputs")
OUT.mkdir(parents=True, exist_ok=True)


def to_jsonable(obj):
    if isinstance(obj, dict):
        return {str(k): to_jsonable(v) for k, v in obj.items()}
    if isinstance(obj, (list, tuple)):
        return [to_jsonable(v) for v in obj]
    if isinstance(obj, set):
        return [to_jsonable(v) for v in sorted(obj, key=str)]
    if isinstance(obj, (str, int, float, bool)) or obj is None:
        return obj
    return str(obj)


def require_accepting_tuple(result, context):
    if not isinstance(result, tuple) or len(result) != 3:
        raise TypeError(f"{context} did not return a (net, im, fm) tuple")
    net, im, fm = result
    if im is None or fm is None:
        raise ValueError(f"{context} returned a net without a usable initial/final marking")
    return net, im, fm


def diagnose_accepting_net(name, net, im, fm, diagnostics_store):
    wfnet = pm4py.check_is_workflow_net(net)
    sound, sound_details = pm4py.check_soundness(net, im, fm, print_diagnostics=True)
    footprints = pm4py.discover_footprints(net, im, fm)
    rg = pm4py.convert_to_reachability_graph(net, im, fm)

    pm4py.save_vis_petri_net(
        net,
        im,
        fm,
        str(OUT / f"{name}.png"),
        graph_title=name,
    )

    diagnostics_store[name] = {
        "wf_net": wfnet,
        "sound": sound,
        "soundness_details": sound_details,
        "footprints": footprints,
        "reachability_state_count": len(rg.states),
        "reachability_transition_count": len(rg.transitions),
    }


pm4py.save_vis_powl(source_powl, str(OUT / "01_source_powl.png"), graph_title="source_powl")

accepting_nets = {}
bpmn_models = {}
diagnostics = {}
process_tree_error = None

# 1. POWL -> accepting Petri net
net_from_powl, im_from_powl, fm_from_powl = require_accepting_tuple(
    pm4py.convert_to_petri_net(source_powl),
    "POWL -> accepting Petri net",
)
accepting_nets["02_net_from_powl"] = (net_from_powl, im_from_powl, fm_from_powl)
diagnose_accepting_net("02_net_from_powl", net_from_powl, im_from_powl, fm_from_powl, diagnostics)

# 2. accepting Petri net -> BPMN
bpmn_from_net = pm4py.convert_to_bpmn(net_from_powl, im_from_powl, fm_from_powl)
bpmn_models["03_bpmn_from_net"] = bpmn_from_net
pm4py.save_vis_bpmn(bpmn_from_net, str(OUT / "03_bpmn_from_net.png"), graph_title="bpmn_from_net")

# 3. Attempt a process-tree intermediate
try:
    tree_from_net = pm4py.convert_to_process_tree(net_from_powl, im_from_powl, fm_from_powl)
    pm4py.save_vis_process_tree(
        tree_from_net,
        str(OUT / "04_tree_from_net.png"),
        graph_title="tree_from_net",
    )

    # 4. If the tree exists, convert it to BPMN
    bpmn_from_tree = pm4py.convert_to_bpmn(tree_from_net)
    bpmn_models["05_bpmn_from_tree"] = bpmn_from_tree
    pm4py.save_vis_bpmn(
        bpmn_from_tree,
        str(OUT / "05_bpmn_from_tree.png"),
        graph_title="bpmn_from_tree",
    )
except Exception as exc:
    process_tree_error = f"{type(exc).__name__}: {exc}"
    diagnostics["04_tree_from_net"] = {"conversion_failed": process_tree_error}

# 5. Convert each produced BPMN model back to an accepting Petri net where possible
for bpmn_name, bpmn_model in bpmn_models.items():
    roundtrip_name = f"{bpmn_name}_roundtrip_net"
    try:
        rt_net, rt_im, rt_fm = require_accepting_tuple(
            pm4py.convert_to_petri_net(bpmn_model),
            f"{bpmn_name} -> accepting Petri net",
        )
        accepting_nets[roundtrip_name] = (rt_net, rt_im, rt_fm)
        diagnose_accepting_net(roundtrip_name, rt_net, rt_im, rt_fm, diagnostics)
    except Exception as exc:
        diagnostics[roundtrip_name] = {
            "conversion_failed": f"{type(exc).__name__}: {exc}"
        }

summary = {
    "process_tree_error": process_tree_error,
    "accepting_net_names": sorted(accepting_nets.keys()),
    "bpmn_model_names": sorted(bpmn_models.keys()),
    "diagnostics": diagnostics,
}

summary_path = OUT / "conversion_summary.json"
summary_path.write_text(json.dumps(to_jsonable(summary), indent=2), encoding="utf-8")
print(json.dumps(to_jsonable(summary), indent=2))
```

# 4. Preservation and Loss Audit

Local evidence for the table below: on this source, `POWL -> Petri -> BPMN -> Petri` produced a sound WF-net both before and after the BPMN round trip, `discover_footprints(...)` matched between the source net and the round-tripped net, both reachability graphs had `15` states and `26` transitions, and bounded visible-trace exploration found the same `11` completed visible traces under `max_visible_len=10`, `max_configure_trial_occurrences=2`, and `max_silent_state_revisits=4`. The `Petri -> process tree` step failed with `ValueError: Parsing of WF-net Failed`.

# 5. Round-Trip Validation Code

The code below assumes section 3 has already created `net_from_powl`, `im_from_powl`, `fm_from_powl`, and the `accepting_nets` dictionary. It uses only defensible PM4Py calls plus direct Petri-net semantics for bounded exploration. The comparison is exhaustive only within the stated bound; it is not a proof for arbitrarily many loop iterations.

```python
import json
from collections import deque

import pm4py
from pm4py.objects.petri_net import semantics


positive_witnesses = [
    (
        "base_without_legal",
        (
            "Register Change",
            "Assess Risk",
            "Prepare Evidence",
            "Configure Trial",
            "Inspect Trial",
            "Release Change",
            "Archive Change",
        ),
    ),
    (
        "swapped_assess_prepare_with_legal",
        (
            "Register Change",
            "Prepare Evidence",
            "Assess Risk",
            "Legal Review",
            "Configure Trial",
            "Inspect Trial",
            "Release Change",
            "Archive Change",
        ),
    ),
    (
        "legal_during_verification",
        (
            "Register Change",
            "Assess Risk",
            "Prepare Evidence",
            "Configure Trial",
            "Legal Review",
            "Inspect Trial",
            "Release Change",
            "Archive Change",
        ),
    ),
    (
        "two_iterations",
        (
            "Register Change",
            "Assess Risk",
            "Prepare Evidence",
            "Configure Trial",
            "Inspect Trial",
            "Correct Defect",
            "Configure Trial",
            "Inspect Trial",
            "Release Change",
            "Archive Change",
        ),
    ),
]

negative_witnesses = [
    (
        "verification_before_prerequisites",
        (
            "Register Change",
            "Configure Trial",
            "Inspect Trial",
            "Release Change",
            "Archive Change",
        ),
    ),
    (
        "release_before_verification",
        (
            "Register Change",
            "Assess Risk",
            "Prepare Evidence",
            "Release Change",
            "Archive Change",
        ),
    ),
    (
        "release_before_optional_legal_when_legal_chosen",
        (
            "Register Change",
            "Assess Risk",
            "Legal Review",
            "Prepare Evidence",
            "Release Change",
            "Archive Change",
        ),
    ),
    (
        "inspect_before_configure",
        (
            "Register Change",
            "Assess Risk",
            "Prepare Evidence",
            "Inspect Trial",
            "Configure Trial",
            "Release Change",
            "Archive Change",
        ),
    ),
]


def canon_marking(marking):
    return tuple(sorted((place.name, count) for place, count in marking.items() if count))


def normalize_footprints(footprints):
    keys = ["activities", "start_activities", "end_activities", "sequence", "parallel"]
    normalized = {}
    for key in keys:
        value = footprints.get(key, set())
        if isinstance(value, set):
            normalized[key] = set(value)
        else:
            normalized[key] = value
    return normalized


def bounded_visible_traces(
    net,
    im,
    fm,
    max_visible_len=10,
    max_configure_trial_occurrences=2,
    max_silent_state_revisits=4,
):
    queue = deque([(im, tuple(), {}, {})])
    completed = set()
    seen = set()

    while queue:
        marking, visible_trace, visible_counts, silent_state_revisits = queue.popleft()
        state_key = (
            canon_marking(marking),
            visible_trace,
            tuple(sorted(visible_counts.items())),
            tuple(sorted(silent_state_revisits.items())),
        )
        if state_key in seen:
            continue
        seen.add(state_key)

        if marking == fm:
            completed.add(visible_trace)

        enabled = sorted(
            pm4py.get_enabled_transitions(net, marking),
            key=lambda t: (t.label is None, t.label or "", t.name),
        )

        for transition in enabled:
            next_marking = semantics.execute(transition, net, marking)
            if next_marking is None:
                continue

            if transition.label is None:
                next_state = canon_marking(next_marking)
                revisit_count = silent_state_revisits.get(next_state, 0) + 1
                if revisit_count > max_silent_state_revisits:
                    continue
                updated_revisits = dict(silent_state_revisits)
                updated_revisits[next_state] = revisit_count
                queue.append((next_marking, visible_trace, dict(visible_counts), updated_revisits))
            else:
                next_trace = visible_trace + (transition.label,)
                if len(next_trace) > max_visible_len:
                    continue

                updated_counts = dict(visible_counts)
                updated_counts[transition.label] = updated_counts.get(transition.label, 0) + 1
                if (
                    transition.label == "Configure Trial"
                    and updated_counts[transition.label] > max_configure_trial_occurrences
                ):
                    continue

                # Visible progress resets the silent revisit counter so a later tau stretch
                # is bounded relative to the new visible prefix.
                queue.append((next_marking, next_trace, updated_counts, {}))

    return completed


def reachability_summary(net, im, fm):
    rg = pm4py.convert_to_reachability_graph(net, im, fm)
    return {
        "state_count": len(rg.states),
        "transition_count": len(rg.transitions),
    }


def compare_accepting_nets(reference_name, reference_tuple, candidate_name, candidate_tuple):
    ref_net, ref_im, ref_fm = reference_tuple
    cand_net, cand_im, cand_fm = candidate_tuple

    ref_sound, ref_sound_diag = pm4py.check_soundness(ref_net, ref_im, ref_fm, print_diagnostics=True)
    cand_sound, cand_sound_diag = pm4py.check_soundness(cand_net, cand_im, cand_fm, print_diagnostics=True)

    ref_fp = normalize_footprints(pm4py.discover_footprints(ref_net, ref_im, ref_fm))
    cand_fp = normalize_footprints(pm4py.discover_footprints(cand_net, cand_im, cand_fm))

    ref_completed = bounded_visible_traces(ref_net, ref_im, ref_fm)
    cand_completed = bounded_visible_traces(cand_net, cand_im, cand_fm)

    positive_results = []
    for witness_name, trace in positive_witnesses:
        positive_results.append(
            {
                "name": witness_name,
                "trace": list(trace),
                "reference_accepts": trace in ref_completed,
                "candidate_accepts": trace in cand_completed,
            }
        )

    negative_results = []
    for witness_name, trace in negative_witnesses:
        negative_results.append(
            {
                "name": witness_name,
                "trace": list(trace),
                "reference_accepts": trace in ref_completed,
                "candidate_accepts": trace in cand_completed,
            }
        )

    return {
        "reference": reference_name,
        "candidate": candidate_name,
        "workflow_net": {
            reference_name: pm4py.check_is_workflow_net(ref_net),
            candidate_name: pm4py.check_is_workflow_net(cand_net),
        },
        "soundness": {
            reference_name: {"sound": ref_sound, "details": ref_sound_diag},
            candidate_name: {"sound": cand_sound, "details": cand_sound_diag},
        },
        "footprints_equal": ref_fp == cand_fp,
        "reference_footprints": ref_fp,
        "candidate_footprints": cand_fp,
        "reachability": {
            reference_name: reachability_summary(ref_net, ref_im, ref_fm),
            candidate_name: reachability_summary(cand_net, cand_im, cand_fm),
        },
        "bounded_trace_comparison": {
            "max_visible_len": 10,
            "max_configure_trial_occurrences": 2,
            "max_silent_state_revisits": 4,
            "exhaustive_under_bound": True,
            "globally_exhaustive": False,
            "reference_completed_count": len(ref_completed),
            "candidate_completed_count": len(cand_completed),
            "only_in_reference": [list(t) for t in sorted(ref_completed - cand_completed)],
            "only_in_candidate": [list(t) for t in sorted(cand_completed - ref_completed)],
        },
        "positive_witnesses": positive_results,
        "negative_witnesses": negative_results,
    }


reference_name = "02_net_from_powl"
reference_tuple = accepting_nets[reference_name]
comparison_report = {}

for candidate_name, candidate_tuple in accepting_nets.items():
    if candidate_name == reference_name:
        continue
    comparison_report[candidate_name] = compare_accepting_nets(
        reference_name,
        reference_tuple,
        candidate_name,
        candidate_tuple,
    )

print(json.dumps(comparison_report, indent=2, default=str))
```

# 6. Visual-Semantics Review

A BPMN rendering can be behaviorally acceptable and still be easy to misread.

- Parallel gateways can correctly encode the fork after `Register Change` and the join before `Release Change`, but a left-to-right layout may make one branch look earlier, stronger, or mandatory when the source only states partial order.
- Exclusive gateways carry two different silent semantics here: skipping `Legal Review` and deciding whether to re-enter verification after `Correct Defect`. Unlabeled diamonds do not tell a stakeholder which one means “skip” and which one means “retry.”
- The verification loop is visually a back-edge through gateways. Many readers will interpret that as “zero or more” unless the diagram or legend explicitly says the first `Configure Trial -> Inspect Trial` pass is mandatory.
- Silent routing in the Petri net disappears into BPMN control nodes. That makes the BPMN look simpler, but it also hides that some behavior is routing-only and not a user task.
- Graph layout is not semantics. If `Legal Review` is drawn above or to the left of `Configure Trial`, that does not create a precedence edge; the source explicitly leaves those branches unordered except for the release synchronization.

Useful anti-misread annotations:

- Label the legal XOR as `Legal Review or silent skip`.
- Label the loop exit condition as `exit only after at least one Configure->Inspect pass`.
- Add a note at the release join: `wait for verification completion and legal branch completion`.
- Include a legend stating that gateway placement is visual only and that concurrency claims are validated against the accepting net, not inferred from layout.
- Put the invariant IDs (`S2`, `S5`, `S7`, `S8`) on the exported diagram or in adjacent documentation.

# 7. Rejection Criteria

- Reject any produced accepting net for which `pm4py.check_is_workflow_net(net)` is `False`.
- Reject any produced accepting net for which `pm4py.check_soundness(net, im, fm, print_diagnostics=True)` is `False` or reports dead tasks / lack of proper completion.
- Reject or quarantine any BPMN or process-tree round trip that does not return non-null initial and final markings.
- Reject any derivative that loses a required interleaving, such as forbidding `Register Change, Prepare Evidence, Assess Risk, ...` while still claiming to preserve the source.
- Reject any derivative that admits `Release Change` before completion of the verification loop.
- Reject any derivative that collapses optional legal behavior into either “always perform `Legal Review`” or “`Legal Review` can never occur.”
- Reject any derivative that allows `Inspect Trial` before `Configure Trial` or allows a second verification pass without `Correct Defect` between passes.
- Reject any derivative that permits completion at a marking different from the declared final marking under the exact-final-marking check.
- Reject any derivative that duplicates or merges visible activity labels so that witness traces become ambiguous.
- Quarantine the process-tree branch when `convert_to_process_tree(...)` raises an exception or succeeds only by serializing behavior that was unordered in the source.

# 8. Canonical Representation Recommendation

The authoritative model should be the original POWL specification. It states the intended partial order, optional silent behavior, and loop structure directly, without forcing a visualization-oriented representation to carry semantics it expresses only indirectly.

Generated accepting Petri nets and BPMN diagrams should be treated as derivative artifacts.

- The accepting Petri net is the primary validation artifact because PM4Py can check WF-net structure, soundness, footprints, reachability, and bounded witness traces against it.
- The BPMN model is the stakeholder-facing visualization artifact because it is easier to review operationally, but it should never become the semantic source of truth without a fresh round-trip audit.
- Each derivative should be accompanied by evidence: WF-net result, soundness result, footprint comparison, reachability summary, positive/negative witness results, and an explicit statement of the bounded-exploration limit.
- A process-tree intermediate should not be part of the default pipeline for this model. It may be attempted as an optional derivative path, but only in `try/except`, never treated as authoritative, and quarantined immediately on failure.
- Future edits should be made in POWL, then all derivatives should be regenerated and revalidated. Avoid manual edits to BPMN unless they are followed by conversion back to an accepting net and a full invariant audit, otherwise round-trip drift becomes likely and hard to detect.

# 9. Residual Uncertainty

- Passing the bounded visible-trace exploration does not prove equivalence for arbitrarily many loop iterations; it proves equivalence only within the stated bounds.
- Equal footprints and equal reachability-graph sizes do not prove full behavioral equivalence or bisimulation; different nets can share those summaries.
- The validation establishes PM4Py round-trip consistency, not guaranteed equivalence under every BPMN execution engine or every downstream importer.
- Hiding `tau` transitions means the audit cannot prove a one-to-one correspondence between every silent-routing choice in the source net and every silent-routing choice after conversion; it only checks visible behavior plus exact completion under the tested bound.
- Failure of `Petri -> process tree` on this run does not prove that no faithful block-structured reformulation exists; it proves only that the tested parser could not derive one automatically from this accepting net.
