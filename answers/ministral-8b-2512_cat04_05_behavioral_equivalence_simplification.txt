## 1. Equivalence Notions

### Definitions
- **Visible trace equivalence (after hiding `tau`)**:
  Two models are equivalent if they generate the same set of visible traces (ignoring silent transitions). Duplicate visible labels are distinguished by occurrence position (e.g., `Analyze Revision` at step 1 vs. step 3).

- **Bounded visible-language equivalence (P3)**:
  Models are equivalent under P3 if their visible traces (ignoring `tau`) have:
  - Length  12 visible events.
  - At most 3 `Analyze Revision` occurrences.
  - No silent transitions (`tau`) are considered.

- **Business-relevant equivalence (P1)**:
  Models are equivalent if they satisfy:
  1. Every `Analyze Revision` must be preceded by a `Check Revision` (except possibly the first).
  2. `Rework Case` separates two `Analyze Revision` attempts.
  3. Optional `Approve Revision` is allowed but must not affect the core sequence.
  4. The number and placement of `Check Revision`/`Approve Revision` are observable.

- **Abstracted dashboard equivalence (P2)**:
  Models are equivalent if they satisfy:
  1. `Open Case` is first, `Close Case` is last.
  2. At least one `Analyze Revision` and one `Check Revision` occur.
  3. Repeated `Check Revision` is abstracted to a Boolean "check occurred."
  4. `Approve Revision` and `tau` are hidden.
  5. The number of `Analyze Revision` attempts is recorded, but interleaving is ignored.

# Bounded trace exploration (exhaustive)
def get_bounded_traces(net, im, fm, max_visible_length=12, max_analyze_count=3):
    traces = []
    visited_markings = set()
    queue = [(im, [])]

    while queue:
        marking, trace = queue.pop(0)
        if marking in visited_markings:
            continue
        visited_markings.add(marking)

        if marking == fm:
            if len(trace) > 0 and trace[-1] in ['Close Case']:
                visible_trace = [event for event in trace if event not in ['tau']]
                if (len(visible_trace) <= max_visible_length and
                    visible_trace.count('Analyze Revision') <= max_analyze_count):
                    traces.append(visible_trace)
            continue

        enabled = pm4py.get_enabled_transitions(net, marking)
        for transition in enabled:
            new_marking = pm4py.apply_transition(net, marking, transition)
            new_trace = trace + [transition.label]
            queue.append((new_marking, new_trace))

    return traces

traces_a = get_bounded_traces(net_a, im_a, fm_a)
traces_b = get_bounded_traces(net_b, im_b, fm_b)

# Compare traces
unique_a = [t for t in traces_a if t not in traces_b]
unique_b = [t for t in traces_b if t not in traces_a]

print("\nTraces unique to Model A (P3):")

def count_nodes(tree):
    if isinstance(tree, str):
        return 1
    elif isinstance(tree, list):
        return sum(count_nodes(child) for child in tree)
    elif isinstance(tree, tuple):
        return 1 + sum(count_nodes(child) for child in tree[1:])
    else:
        return 0

def count_leaves(tree):
    if isinstance(tree, str):
        return 1
    elif isinstance(tree, list):
        return sum(count_leaves(child) for child in tree)
    elif isinstance(tree, tuple):

    else:
