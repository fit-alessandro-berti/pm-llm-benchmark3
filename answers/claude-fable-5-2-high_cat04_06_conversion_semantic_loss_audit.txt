# 1. Source-Semantics Baseline

The POWL object is the only authoritative statement of behaviour. Everything below is derived from it and from the stated intended semantics.

Abbreviations: `R` Register Change, `A` Assess Risk, `P` Prepare Evidence, `L` Legal Review, `C` Configure Trial, `I` Inspect Trial, `D` Correct Defect, `Rel` Release Change, `Arc` Archive Change, `τ` the silent skip.

Three things are stated by the source and are easy to overlook:

- **The order relation is an "N", not a nest.** Among the four middle nodes the order is `A < L`, `A < V`, `P < V` (V = verification loop), with `L ∥ P` and `L ∥ V`. That shape is not series-parallel, so no nesting of SEQ/XOR/AND/LOOP blocks with unique labels can express it. This decides the fate of the process-tree pipeline before any code runs.
- **Absent edges are information.** `A ∥ P`, `L ∥ P` and `L ∥ V` are requirements, not omissions.
- **The source lists covering edges only.** `register → release_change` and nine other implied pairs are not stated. The eight edges are a transitive reduction; the closure has 18 pairs.

The complete visible language can be counted by hand, which gives an oracle independent of any converter. With exactly k occurrences of `D` there are 6k + 9 complete traces: 2 without `L`, and (3k + 4) + (3k + 3) with `L`. So k = 0, 1, 2 gives 9 + 15 + 21 = 45 traces.

| Invariant ID | Invariant | Positive witness | Negative witness | Observable after hiding tau? |
|---|---|---|---|---|
| S1 | Start: `R` is the first visible activity and occurs exactly once. | `R A P C I Rel Arc` | `A R P C I Rel Arc`; `A P C I Rel Arc`; empty trace | Yes |
| S2 | Absence of order between `A` and `P`: each occurs exactly once after `R`, in either order. | Both `R A P C I Rel Arc` and `R P A C I Rel Arc` are needed; one alone proves nothing. | No trace is forbidden by an absence of order. Boundary cases: `R A A P C I Rel Arc`, `R A C I Rel Arc`. | Yes as two interleavings; not as simultaneity |
| S3 | Optionality: `L` occurs zero times or once. | `R A P C I Rel Arc` (skip) and `R A P L C I Rel Arc` | `R A L L P C I Rel Arc` | Presence or absence yes; the moment the skip is taken no |
| S4 | Ordering: `L` only after `A`. | `R A L P C I Rel Arc` | `R L A P C I Rel Arc`; `R P L A C I Rel Arc` | Yes |
| S5 | Absence of order between `L` and `P`: `L` may precede `P`. | `R A L P C I Rel Arc` together with `R A P L C I Rel Arc` | None for the absence itself; a model that rejects the first witness violates S5. | Yes |
| S6 | Ordering: the first `C` occurs only after both `A` and `P`. | `R A P C I Rel Arc`; `R P A C I Rel Arc` | `R A C P I Rel Arc`; `R P C A I Rel Arc` | Yes |
| S7 | Absence of order between `L` and the loop: `L` may occur before, inside, between or after iterations. | Before: `R A P L C I Rel Arc`. Inside: `R A P C L I Rel Arc`. Between: `R P A C I D L C I Rel Arc`. After: `R A P C I L Rel Arc`. | None for the absence itself. Boundary: `R A P C I Rel L Arc`. | Yes. Overlap with a non-atomic loop is visible, unlike overlap of two atomic activities. |
| S8 | Loop body order: in every iteration `C` precedes `I`. | `R A P C I D C I Rel Arc` | `R A P I C Rel Arc` | Yes |
| S9 | Loop scope: the loop contributes exactly `C I (D C I)*`. `D` follows an `I`, is followed by a full `C I`, and nothing else is repeated. | `R A P C I D C I Rel Arc`; `R A P C I D C I D C I Rel Arc` | `R A P C I C I Rel Arc`; `R A P C I D Rel Arc`; `R A P D C I Rel Arc`; `R A P C D I Rel Arc` | Yes |
| S10 | Minimum iteration count: at least one `C I`. | `R A P C I Rel Arc` | `R A P Rel Arc`; `R A P L Rel Arc` | Yes |
| S11 | Synchronisation: `Rel` occurs exactly once, only after the legal branch is resolved (by `L` or `τ`) and the loop has ended; no `L`, `C`, `I`, `D` afterwards. | `R A P C I Rel Arc`; `R A P C I L Rel Arc` | `R A P C Rel I Arc`; `R A P L Rel C I Arc`; `R A P C I Rel L Arc`; `R A P C I Rel D C I Arc`; `R A P C I Rel Rel Arc` | Partly. "After the last `I`" and "no `L` after `Rel`" yes. That `τ` fired before `Rel` is not visible. |
| S12 | Finality: `Arc` occurs exactly once, after `Rel`, as the last activity; the case is complete only in the exact final state with nothing left over. | `R A P C I Rel Arc` ending in the final marking | `R A P C I Rel` (incomplete); `R A P C I Arc Rel`; `R A P C I Rel Arc Arc` | Order yes. "Nothing left over" is a state property and needs an exact final-marking test. |
| S13 | Label uniqueness: nine visible labels, each on exactly one model element; no other visible label. | Structural inventory of the model | A model with two `Legal Review` elements, or a visible `start`/`end`/gateway label | Not a trace property; structural |
| S14 | Independence: unordered nodes are concurrent, not a choice between two sequential orders. | None in sequential-trace semantics | None | No |

# 2. Candidate Conversion Pipelines

No direct POWL-to-BPMN call is used, because none is provided. Every BPMN is produced through a Petri net or a process tree.

| Pipeline | PM4Py calls | Expected benefit | Expected risk | Failure condition |
|---|---|---|---|---|
| **A (primary)**: POWL → accepting Petri net → BPMN, then BPMN → accepting Petri net for checking | `pm4py.convert_to_petri_net(source_powl)`; `pm4py.convert_to_bpmn(net, im, fm)`; `pm4py.convert_to_petri_net(bpmn)` | A Petri net can express the N-shaped order exactly. It has markings, so soundness and language can be checked. The net-to-BPMN mapping is syntactic and needs no block structure. | Silent transitions turn into gateways or bare flows. Gateways are unnamed. BPMN token semantics are not PM4Py's net semantics. The round trip uses PM4Py's own inverse converter, so it is not independent evidence. If a release routes net-to-BPMN through a process tree, A degenerates into B. | Any conversion raises or returns `None`; a marking is missing, empty or foreign; the net is not a sound workflow net; the round-tripped language differs from `net_from_powl`; task inventory differs from S13. |
| **B (probe)**: POWL → accepting Petri net → process tree → BPMN | `pm4py.convert_to_petri_net(source_powl)`; `pm4py.convert_to_process_tree(net, im, fm)` in `try/except`; `pm4py.convert_to_bpmn(tree)`; `pm4py.convert_to_petri_net(tree)`; `pm4py.convert_to_petri_net(bpmn)` | If it worked, the BPMN would be block-structured with matched splits and joins, which is the easiest diagram to read. | The source is not block-structured. Success could only come from duplicated labels, extra silent structure, or a changed language. | The expected and correct outcome is an exception. A returned tree is rejected unless it has unique labels and passes exact language equality. |
| **C (negative control, never delivered)**: hand-written block-structured approximations → Petri net | `parse(...)` from `pm4py.objects.process_tree.utils.generic`; `pm4py.convert_to_petri_net(tree)` | Shows that the validator rejects the nearest lossy models, so a "pass" on A means something. | None for delivery; the models are known to be wrong. | The validator fails to reject any control. |

Pipeline A is the primary pipeline. B is run only to record its outcome. C exists to test the tests.

# 3. Conversion Code

```python
import os
import traceback
from collections import Counter, deque

import pm4py
from pm4py.objects.bpmn.obj import BPMN
from pm4py.objects.petri_net.obj import Marking
from pm4py.objects.powl.obj import (
    StrictPartialOrder,
    OperatorPOWL,
    Transition,
    SilentTransition,
)
from pm4py.objects.process_tree.obj import Operator

# ------------------------------------------------------------------ source (authoritative)
register = Transition(label="Register Change")
assess_risk = Transition(label="Assess Risk")
prepare_evidence = Transition(label="Prepare Evidence")

legal_review = Transition(label="Legal Review")
skip_legal = SilentTransition()
optional_legal = OperatorPOWL(operator=Operator.XOR, children=[legal_review, skip_legal])

configure_trial = Transition(label="Configure Trial")
inspect_trial = Transition(label="Inspect Trial")
trial_body = StrictPartialOrder(nodes=[configure_trial, inspect_trial])
trial_body.order.add_edge(configure_trial, inspect_trial)

correct_defect = Transition(label="Correct Defect")
verification_loop = OperatorPOWL(operator=Operator.LOOP, children=[trial_body, correct_defect])

release_change = Transition(label="Release Change")
archive_change = Transition(label="Archive Change")

source_powl = StrictPartialOrder(
    nodes=[register, assess_risk, prepare_evidence, optional_legal,
           verification_loop, release_change, archive_change]
)
source_powl.order.add_edge(register, assess_risk)
source_powl.order.add_edge(register, prepare_evidence)
source_powl.order.add_edge(assess_risk, optional_legal)
source_powl.order.add_edge(assess_risk, verification_loop)
source_powl.order.add_edge(prepare_evidence, verification_loop)
source_powl.order.add_edge(optional_legal, release_change)
source_powl.order.add_edge(verification_loop, release_change)
source_powl.order.add_edge(release_change, archive_change)

# ------------------------------------------------------------------ bookkeeping
OUT_DIR = "conversion_audit"
os.makedirs(OUT_DIR, exist_ok=True)

EXPECTED_LABELS = {
    "Register Change", "Assess Risk", "Prepare Evidence", "Legal Review",
    "Configure Trial", "Inspect Trial", "Correct Defect",
    "Release Change", "Archive Change",
}
STATE_CAP = 50_000          # guard against unbounded nets

audit_log = []              # (stage, status, detail): every failure is recorded, none hidden


def record(stage, status, detail=""):
    audit_log.append((stage, status, str(detail)))
    print(f"[{status:^8}] {stage}: {detail}")


def try_save(stage, fn, *args):
    """A rendering failure (e.g. Graphviz missing) is reported but is not a semantic verdict."""
    try:
        fn(*args)
        record(stage, "saved", args[-1])
    except Exception as exc:
        record(stage, "VIS-FAIL", f"{type(exc).__name__}: {exc}")


# ------------------------------------------------------------------ step 0: source pre-flight
def order_edges(spo):
    return {(a, b) for a in spo.children for b in spo.children if spo.order.is_edge(a, b)}


def normalise_orders(powl):
    """Make each order relation explicitly transitive. The source lists covering edges only
    (register -> release_change is implied, not stated). The closure denotes the same strict
    partial order, so no behaviour is added or removed; it only removes a dependency on
    whether a given PM4Py release closes the relation itself."""
    if isinstance(powl, StrictPartialOrder):
        before = order_edges(powl)
        powl.order.add_transitive_edges()
        if not powl.order.is_irreflexive():
            raise ValueError("order relation is cyclic: not a strict partial order")
        record("source order closure", "info",
               f"{len(order_edges(powl) - before)} implied edge(s) made explicit")
    for child in getattr(powl, "children", None) or []:
        normalise_orders(child)


normalise_orders(source_powl)
source_powl.validate_partial_orders()

# the closure must not order anything the source leaves unordered
for a, b in [(assess_risk, prepare_evidence), (optional_legal, verification_loop),
             (prepare_evidence, optional_legal)]:
    assert not source_powl.order.is_edge(a, b) and not source_powl.order.is_edge(b, a)

try_save("vis source POWL", pm4py.save_vis_powl, source_powl,
         os.path.join(OUT_DIR, "00_source_powl.svg"))


# ------------------------------------------------------------------ net helpers (reused in section 5)
def mkey(marking):
    return frozenset((p, c) for p, c in marking.items() if c > 0)


def fire(transition, marking):
    """Plain place/transition firing rule; caller guarantees the transition is enabled."""
    nxt = Marking(marking)
    for arc in transition.in_arcs:
        nxt[arc.source] -= arc.weight
        if nxt[arc.source] == 0:
            del nxt[arc.source]
    for arc in transition.out_arcs:
        nxt[arc.target] += arc.weight
    return nxt


def markings_usable(net, im, fm):
    issues = []
    for mname, m in (("initial", im), ("final", fm)):
        if m is None:
            issues.append(f"{mname} marking is None")
        elif len(mkey(m)) == 0:
            issues.append(f"{mname} marking is empty")
        elif any(p not in net.places for p in m):
            issues.append(f"{mname} marking references a place outside the net")
    return issues


def state_space_soundness(net, im, fm, cap=STATE_CAP):
    """Classical soundness decided on the explicit reachability set (valid for bounded nets):
    option to complete, proper completion, no dead transitions. Independent of Woflan."""
    start, final = mkey(im), mkey(fm)
    seen = {start: im}
    succ = {start: set()}
    fired = set()
    queue = deque([start])
    while queue:
        k = queue.popleft()
        for t in pm4py.get_enabled_transitions(net, seen[k]):
            fired.add(t)
            nxt = fire(t, seen[k])
            nk = mkey(nxt)
            succ[k].add(nk)
            if nk not in seen:
                if len(seen) >= cap:
                    return {"decided": False, "reason": f"more than {cap} markings (unbounded?)"}
                seen[nk] = nxt
                succ[nk] = set()
                queue.append(nk)
    pred = {k: set() for k in seen}
    for k, outs in succ.items():
        for o in outs:
            pred[o].add(k)
    can_finish = {final} if final in seen else set()
    stack = list(can_finish)
    while stack:
        for p in pred[stack.pop()]:
            if p not in can_finish:
                can_finish.add(p)
                stack.append(p)
    fm_counts = dict(final)
    improper = [k for k in seen if k != final
                and all(dict(k).get(p, 0) >= c for p, c in fm_counts.items())]
    dead = sorted(str(t.label or t.name) for t in net.transitions if t not in fired)
    return {
        "decided": True,
        "n_markings": len(seen),
        "safe": all(c <= 1 for k in seen for _, c in k),
        "option_to_complete": len(can_finish) == len(seen),
        "proper_completion": not improper,
        "final_marking_is_dead": final in seen and not succ[final],
        "dead_transitions": dead,
        "sound": len(can_finish) == len(seen) and not improper and not dead,
    }


def diagnose(name, net, im, fm):
    d = {"name": name, "usable": False, "workflow_net": None, "woflan_sound": None,
         "statespace": None, "issues": [], "review": []}
    if net is None:
        d["issues"].append("no net produced")
        record(f"diagnose {name}", "REJECT", d["issues"])
        return d

    d["issues"] += markings_usable(net, im, fm)
    d["usable"] = not d["issues"]

    visible = [t.label for t in net.transitions if t.label is not None]
    d["n_places"], d["n_transitions"] = len(net.places), len(net.transitions)
    d["n_silent"] = len(net.transitions) - len(visible)
    dup = sorted({l for l in visible if visible.count(l) > 1})
    if set(visible) != EXPECTED_LABELS:
        d["issues"].append(f"label set differs: missing={sorted(EXPECTED_LABELS - set(visible))} "
                           f"extra={sorted(set(visible) - EXPECTED_LABELS)}")
    if dup:
        d["issues"].append(f"duplicated labels: {dup}")

    try:
        d["workflow_net"] = bool(pm4py.check_is_workflow_net(net))
        if not d["workflow_net"]:
            d["issues"].append("not a workflow net")
    except Exception as exc:
        d["issues"].append(f"workflow-net check raised {type(exc).__name__}: {exc}")

    if d["usable"]:
        try:
            res = pm4py.check_soundness(net, im, fm, print_diagnostics=True)
            d["woflan_sound"] = bool(res[0]) if isinstance(res, (tuple, list)) else bool(res)
        except Exception as exc:
            d["review"].append(f"check_soundness raised {type(exc).__name__}: {exc}")
        try:
            d["statespace"] = state_space_soundness(net, im, fm)
        except Exception as exc:
            d["review"].append(f"state-space soundness raised {type(exc).__name__}: {exc}")

        ss = d["statespace"]
        if ss is None or not ss["decided"]:
            d["issues"].append(f"soundness undecided on state space: {ss}")
        elif not ss["sound"]:
            d["issues"].append(f"unsound on state space: {ss}")
        if d["woflan_sound"] is False and ss and ss.get("sound"):
            # two analyses disagree: do not pick the convenient one, escalate
            d["review"].append("Woflan reports unsound but explicit state space is sound")
        elif d["woflan_sound"] is False:
            d["issues"].append("Woflan reports unsound")
    else:
        d["issues"].append("soundness not tested: markings unusable")

    status = "REJECT" if d["issues"] else ("REVIEW" if d["review"] else "ok")
    record(f"diagnose {name}", status,
           f"WF={d['workflow_net']} woflan={d['woflan_sound']} statespace={d['statespace']} "
           f"places={d['n_places']} transitions={d['n_transitions']} silent={d['n_silent']} "
           f"issues={d['issues']} review={d['review']}")
    return d


def bpmn_profile(name, bpmn):
    """Structural inventory of a BPMN object. It has no markings and is not executed here, so
    this is the only direct evidence about the BPMN itself; behaviour is checked via round trip."""
    nodes = list(bpmn.get_nodes())
    kinds = Counter(type(n).__name__ for n in nodes)
    tasks = Counter(n.get_name() for n in nodes if isinstance(n, BPMN.Task))
    issues = []
    if set(tasks) != EXPECTED_LABELS:
        issues.append(f"task names differ: missing={sorted(EXPECTED_LABELS - set(tasks))} "
                      f"extra={sorted(set(tasks) - EXPECTED_LABELS)}")
    if any(c > 1 for c in tasks.values()):
        issues.append(f"duplicated tasks: {sorted(t for t, c in tasks.items() if c > 1)}")
    if kinds.get("InclusiveGateway"):
        issues.append("inclusive (OR) gateway introduced: join semantics not in the source")
    if sum(isinstance(n, BPMN.StartEvent) for n in nodes) != 1 \
            or sum(isinstance(n, BPMN.EndEvent) for n in nodes) != 1:
        issues.append("expected exactly one start event and one end event")
    record(f"profile {name}", "REJECT" if issues else "ok",
           f"{dict(kinds)} flows={len(bpmn.get_flows())} issues={issues}")
    return {"kinds": kinds, "tasks": tasks, "issues": issues}


accepting_nets = {}     # name -> (net, im, fm): everything section 5 compares
diagnostics = {}
bpmn_models = {}
bpmn_profiles = {}


def register_net(name, net, im, fm, filename):
    accepting_nets[name] = (net, im, fm)
    diagnostics[name] = diagnose(name, net, im, fm)
    if diagnostics[name]["usable"]:
        try_save(f"vis {name}", pm4py.save_vis_petri_net, net, im, fm,
                 os.path.join(OUT_DIR, filename))


# ------------------------------------------------------------------ pipeline A.1: POWL -> net
net_from_powl, im_from_powl, fm_from_powl = pm4py.convert_to_petri_net(source_powl)
register_net("net_from_powl", net_from_powl, im_from_powl, fm_from_powl,
             "01_net_from_powl.png")
if diagnostics["net_from_powl"]["issues"]:
    raise RuntimeError("reference net rejected; nothing downstream can be audited: "
                       f"{diagnostics['net_from_powl']['issues']}")

# ------------------------------------------------------------------ pipeline A.2: net -> BPMN
bpmn_from_net = None
try:
    bpmn_from_net = pm4py.convert_to_bpmn(net_from_powl, im_from_powl, fm_from_powl)
    if bpmn_from_net is None:
        raise ValueError("convert_to_bpmn returned None")
    bpmn_models["bpmn_from_net"] = bpmn_from_net
    record("A: net -> BPMN", "ok", "object returned; behaviour still unverified")
    bpmn_profiles["bpmn_from_net"] = bpmn_profile("bpmn_from_net", bpmn_from_net)
    try_save("vis bpmn_from_net", pm4py.save_vis_bpmn, bpmn_from_net,
             os.path.join(OUT_DIR, "02_bpmn_from_net.png"))
except Exception as exc:
    record("A: net -> BPMN", "FAILED", f"{type(exc).__name__}: {exc}")
    traceback.print_exc()

# ------------------------------------------------------------------ pipeline B: net -> tree -> BPMN
tree_from_net = None
bpmn_from_tree = None
tree_failure = None
try:
    tree_from_net = pm4py.convert_to_process_tree(net_from_powl, im_from_powl, fm_from_powl)
    if tree_from_net is None:
        raise ValueError("convert_to_process_tree returned None")
    record("B: net -> tree", "ok", f"{tree_from_net}  (success is suspicious: see section 4)")
except Exception as exc:
    tree_from_net = None
    tree_failure = f"{type(exc).__name__}: {exc}"
    record("B: net -> tree", "FAILED",
           f"{tree_failure}. Interpretation: the net cannot be reduced to nested "
           "SEQ/XOR/AND/LOOP blocks. That is the expected, correct outcome for this source: "
           "Assess Risk precedes both Legal Review and verification while Prepare Evidence "
           "precedes only verification. Pipeline B produces no artifact.")

if tree_from_net is not None:
    try_save("vis tree_from_net", pm4py.save_vis_process_tree, tree_from_net,
             os.path.join(OUT_DIR, "03_tree_from_net.png"))
    try:
        t_net, t_im, t_fm = pm4py.convert_to_petri_net(tree_from_net)
        register_net("net_from_tree", t_net, t_im, t_fm, "03_net_from_tree.png")
    except Exception as exc:
        record("B: tree -> net", "FAILED", f"{type(exc).__name__}: {exc}")
    try:
        bpmn_from_tree = pm4py.convert_to_bpmn(tree_from_net)
        if bpmn_from_tree is None:
            raise ValueError("convert_to_bpmn returned None")
        bpmn_models["bpmn_from_tree"] = bpmn_from_tree
        record("B: tree -> BPMN", "ok", "object returned; behaviour still unverified")
        bpmn_profiles["bpmn_from_tree"] = bpmn_profile("bpmn_from_tree", bpmn_from_tree)
        try_save("vis bpmn_from_tree", pm4py.save_vis_bpmn, bpmn_from_tree,
                 os.path.join(OUT_DIR, "04_bpmn_from_tree.png"))
    except Exception as exc:
        record("B: tree -> BPMN", "FAILED", f"{type(exc).__name__}: {exc}")

# ------------------------------------------------------------------ BPMN -> accepting net
for bpmn_name, bpmn in bpmn_models.items():
    rt_name = "rt_net_" + bpmn_name
    try:
        rt_net, rt_im, rt_fm = pm4py.convert_to_petri_net(bpmn)
        register_net(rt_name, rt_net, rt_im, rt_fm, f"05_{rt_name}.png")
    except Exception as exc:
        accepting_nets[rt_name] = (None, None, None)
        diagnostics[rt_name] = {"name": rt_name, "usable": False, "review": [],
                                "issues": [f"round trip raised {type(exc).__name__}: {exc}"]}
        record(f"round trip {bpmn_name}", "FAILED", f"{type(exc).__name__}: {exc}")

# ------------------------------------------------------------------ summary
print("\n=== conversion summary ===")
for name, d in diagnostics.items():
    print(f"{name:26s} usable={d.get('usable')} WF={d.get('workflow_net')} "
          f"woflan={d.get('woflan_sound')} "
          f"statespace_sound={(d.get('statespace') or {}).get('sound')} "
          f"issues={d.get('issues')} review={d.get('review')}")
print("process-tree intermediate:",
      "produced" if tree_from_net is not None else f"conversion failed ({tree_failure})")
```

Notes on the code:

- The transitive closure is added explicitly and then checked not to have ordered `A`/`P`, `L`/`V` or `P`/`L`. It adds no behaviour.
- `diagnose` checks markings before using them, runs `check_is_workflow_net` and `check_soundness`, and adds an independent state-space soundness check.
- A BPMN object has no markings and is not executed anywhere in this code. `bpmn_profile` is the only direct evidence about it; behaviour is assessed only after converting it back to a net.
- Failures are recorded and interpreted, never swallowed. A rendering failure is kept separate from a semantic verdict.

What a run showed (PM4Py 2.7.23.4, Python 3.12; these are observations from one environment and must be re-established wherever the pipeline is used):

- Without the closure, `source_powl.validate_partial_orders()` raised `The transitivity of the partial order is violated!`. The conversion itself still ran. The closure made 10 implied edges explicit.
- `net_from_powl` had 12 places and 11 transitions, 2 of them silent: the skip, and an AND-join that gathers `A` and `P` before the loop. It was a workflow net, safe, with 15 reachable markings, and sound on the explicit state space.
- `bpmn_from_net` had 9 tasks, 4 parallel gateways, 4 exclusive gateways, 1 start event, 1 end event and 22 flows.
- `convert_to_process_tree` raised `ValueError: Parsing of WF-net Failed`. No tree, and no tree-derived BPMN, was produced.
- The round-tripped net was isomorphic to `net_from_powl` (checked separately with a label-preserving graph-isomorphism test).
- `check_soundness` was not stable. In 3 of 14 runs it reported the round-tripped net as unsound ("places not covered by an s-component"), although that net is isomorphic to one it reported sound, and the explicit state space was sound every time. PM4Py printed a warning that its LP solution may be unstable without PuLP. The code therefore flags a disagreement as `REVIEW` instead of taking either answer.

# 4. Preservation and Loss Audit

The cells record what the scripts in sections 3 and 5 established in the run described above. "Validated preserved" means: exact visible-language equality on the finite state space, the bounded enumeration, all witnesses, and footprints agreed. For the POWL→Petri column the comparison is against the invariant table and the hand count of 45 traces, not against an independent POWL interpreter. The Petri→BPMN column can never be better than "expected preserved" for behaviour, because the BPMN object is not executed.

**True concurrency versus arbitrary interleaving.** The POWL states a partial order: `A` and `P` are independent. The net keeps this structurally, since the two transitions share no place. But every check available here (reachability graph, footprints, trace enumeration, playout) works on interleavings. A footprint "parallel" entry means only that both directly-follows orders occur; a choice between `A;P` and `P;A` would produce the same entry and the same language. S14 therefore never rises above "expected preserved". A BPMN parallel gateway does not promise simultaneity either.

**The lack of an edge between Optional Legal Review and verification.** This absence can be destroyed in three ways. A wrong closure could add an edge; the code asserts it does not. A block-structured rewrite must give it up. A diagram can suggest an order by position. The second is the dangerous one. Control K1 (`L` in parallel with the loop, both after an `A`/`P` block) is the closest tree. Within the bound it keeps 42 of 45 traces and adds none; what is `lost` is S5, the three traces with `L` before `P`. Its footprint differs from the reference in a single pair. Control K2 (`L` sequenced right after `A`) loses 30 of 45 traces: S7 is `lost`. Control K3 (everything parallel) adds 1,485 traces, including violations of S4 and S6. A sampled comparison could miss K1; the exhaustive ones cannot.

**Silent optional behaviour.** The source has one silent element. The net has two, the BPMN has none, and the round-tripped net has two again under new names. So the identity and count of silent elements are `approximated`; only their effect is preserved. The risk cases are a reduction that collapses `XOR(L, τ)` to `L` (caught by P01) or to `τ` (caught by the label inventory and P03).

**Binary-loop semantics.** `LOOP(do, redo)` means `do (redo do)*`. It is not a while-loop that may run zero times, and `D` is not part of the body. In the net, the place after `I` has two consumers, `D` and `Rel`, and `Rel` also needs the legal branch. The loop exit is thus fused with the release join and the choice between "rework" and "leave" stays open until `Rel` fires. This is not a free-choice structure. The BPMN shows an exclusive gateway after `Inspect Trial` with one flow to `Correct Defect` and one to the parallel join. Read with standard BPMN token semantics, that gateway commits the token immediately, after which `D` is no longer possible while the join waits for the legal branch. The set of visible traces is the same under both readings, so no test here can tell them apart. The branching behaviour differs, which matters once the exit is driven by data or by an engine.

**The join before Release Change.** In the net, `Rel` consumes one token from the legal branch and one from the loop. In the BPMN this is a converging parallel gateway. If it were an exclusive merge, `Rel` could fire twice or leave a token behind; N25 and the proper-completion test catch that. If it were an inclusive join, the semantics would no longer be those of the source; `bpmn_profile` rejects inclusive gateways.

**Activity-label uniqueness.** Duplicated labels are the usual way a converter forces non-block-structured behaviour into blocks. They break traceability to the source, and they make footprint and conformance results hard to interpret. Both nets and the BPMN are checked for the exact set of nine names, once each. Element identifiers are regenerated on every conversion, so models are compared by label and behaviour, never by identifier.

**Initial and final markings.** Markings are checked for `None`, emptiness and membership in their own net before any use. Source and sink places are new objects after the round trip, so markings are only meaningful inside their own net. A trace counts as complete only when the marking equals the final marking exactly. "The sink is marked" is not accepted, because it would hide leftover tokens. A BPMN has events, not markings; whether one start and one end event map back to one-token markings is checked, not assumed.

**Gateway or routing-node ambiguity in BPMN visualization.** All eight gateways are unnamed. The exclusive gateways were created with direction `UNSPECIFIED`, so the same symbol stands for a decision, a merge and a loop entry. The parallel split after `Assess Risk` has no matching join: one output joins `Prepare Evidence` before the loop, the other reaches the release join through the legal branch. That is correct, and it is exactly the N shape, but it looks like a modelling error to anyone who expects matched pairs.

from collections import Counter, deque

R, A, P, L = "Register Change", "Assess Risk", "Prepare Evidence", "Legal Review"
C, I, D = "Configure Trial", "Inspect Trial", "Correct Defect"
REL, ARC = "Release Change", "Archive Change"

MAX_REDO = 2                 # at most 2 x Correct Defect  => at most 3 verification iterations
MAX_VISIBLE = 14             # 3 + 1 (legal) + (3 * 2 + 2) + 2: longest source trace under MAX_REDO


# ------------------------------------------------------------------ visible-step semantics
def tau_closure(net, markings, cap=STATE_CAP):
    """All markings reachable by silent (label None) transitions only. The visited set makes a
    silent cycle terminate; the cap turns an unbounded silent blow-up into an explicit error."""
    seen = {mkey(m): m for m in markings}
    queue = deque(seen.values())
    while queue:
        m = queue.popleft()
        for t in pm4py.get_enabled_transitions(net, m):
            if t.label is None:
                nxt = fire(t, m)
                k = mkey(nxt)
                if k not in seen:
                    if len(seen) >= cap:
                        raise RuntimeError("silent closure exceeded cap (unbounded tau behaviour)")
                    seen[k] = nxt
                    queue.append(nxt)
    return seen


def visible_steps(net, closure):
    """label -> tau-closed set of markings after one visible occurrence of that label."""
    raw = {}
    for m in closure.values():
        for t in pm4py.get_enabled_transitions(net, m):
            if t.label is not None:
                raw.setdefault(t.label, []).append(fire(t, m))
    return {label: tau_closure(net, ms) for label, ms in raw.items()}


def is_final(closure, fm):
    return mkey(fm) in closure          # exact equality, not "covers" and not "sink is marked"


def bounded_language(net, im, fm, max_visible=MAX_VISIBLE, max_redo=MAX_REDO, redo_label=D):
    """All complete visible traces and all visible prefixes within the bound."""
    complete, prefixes = set(), set()
    cut_by_length = False
    stack = [((), tau_closure(net, [im]))]
    while stack:
        trace, closure = stack.pop()
        prefixes.add(trace)
        if is_final(closure, fm):
            complete.add(trace)
        for label, nxt in visible_steps(net, closure).items():
            if label == redo_label and trace.count(redo_label) >= max_redo:
                continue                               # loop-iteration bound
            if len(trace) >= max_visible:
                cut_by_length = True                   # length bound actually pruned something
                continue
            stack.append((trace + (label,), nxt))
    return complete, prefixes, cut_by_length


def accepts(net, im, fm, trace):
    closure = tau_closure(net, [im])
    for label in trace:
        closure = visible_steps(net, closure).get(label)
        if not closure:
            return False
    return is_final(closure, fm)


def language_difference(ref, cand, cap=STATE_CAP):
    """Unbounded check for bounded nets: on-the-fly determinisation of both nets (tau hidden)
    and a product walk. Returns None if the visible languages are equal, otherwise a shortest
    trace accepted by exactly one net."""
    (n1, i1, f1), (n2, i2, f2) = ref, cand
    c1, c2 = tau_closure(n1, [i1]), tau_closure(n2, [i2])
    seen = {(frozenset(c1), frozenset(c2))}
    queue = deque([((), c1, c2)])
    while queue:
        trace, c1, c2 = queue.popleft()
        if is_final(c1, f1) != is_final(c2, f2):
            return trace
        s1, s2 = visible_steps(n1, c1), visible_steps(n2, c2)
        for label in set(s1) | set(s2):
            d1, d2 = s1.get(label, {}), s2.get(label, {})      # {} is the dead state
            key = (frozenset(d1), frozenset(d2))
            if key not in seen:
                if len(seen) >= cap:
                    raise RuntimeError("product automaton exceeded cap; equivalence undecided")
                seen.add(key)
                queue.append((trace + (label,), d1, d2))
    return None

def witness_failures(net, im, fm):
    bad = [f"rejected {k}" for k, t in POSITIVE.items() if not accepts(net, im, fm, t)]
    bad += [f"accepted {k}" for k, t in NEGATIVE.items() if accepts(net, im, fm, t)]
    return bad


# ------------------------------------------------------------------ PM4Py-native abstractions
def footprints(net, im, fm):
    fp = pm4py.discover_footprints(net, im, fm)
    return {k: (set(v) if isinstance(v, (set, frozenset, list, tuple)) else v)
            for k, v in fp.items()}


def reachability_profile(net, im, fm):
    ts = pm4py.convert_to_reachability_graph(net, im, fm)
    labels = Counter()
    for tr in ts.transitions:           # arc name is repr(transition) = "(name, 'label')"
        labels[str(tr.name).rsplit(", ", 1)[-1].rstrip(")").strip("'\"")] += 1
    return {"states": len(ts.states), "arcs": len(ts.transitions), "arc_labels": labels}


def playout_variants(net, im, fm):
    """Random playout: a sample, never a proof. Returns the set of sampled visible variants."""
    log = pm4py.play_out(net, im, fm)
    return {tuple(ev["concept:name"] for ev in trace) for trace in log}

    try:
        complete, prefixes, cut = bounded_language(*cand)
        if complete != ref_complete:
            problems.append(f"bounded language differs: lost={sorted(ref_complete - complete)[:3]} "

        if prefixes != ref_prefixes:

                            f"added={sorted(prefixes - ref_prefixes)[:3]}")

            notes.append("length bound pruned candidate behaviour: bounded check not exhaustive")

        diff = language_difference(REF, cand)
        if diff is not None:
            problems.append(f"visible languages differ, shortest distinguishing trace: {diff}")

        problems += witness_failures(*cand)

        fp = footprints(*cand)
        for key in sorted(set(ref_fp) | set(fp)):
            if ref_fp.get(key) != fp.get(key):
                problems.append(f"footprint '{key}' differs")

        rg = reachability_profile(*cand)
        if rg != ref_rg:                # structural drift, not automatically behavioural
            notes.append(f"reachability graph differs: reference={ref_rg} candidate={rg}")

        foreign = [v for v in playout_variants(*cand) if not accepts(*REF, v)]
        missed = [v for v in playout_variants(*REF) if not accepts(*cand, v)]
        if foreign:
            problems.append(f"playout of candidate not in reference: {foreign[:2]}")
        if missed:
            problems.append(f"playout of reference not in candidate: {missed[:2]}")
    except Exception as exc:
        problems.append(f"validation raised {type(exc).__name__}: {exc}")

    status = "REJECT" if problems else ("REVIEW" if notes else "PASS")
    verdicts[name] = (status, problems + notes)
    record(f"compare {name}", status, problems + notes)

print("\n=== round-trip verdicts ===")
for name, (status, details) in verdicts.items():
    print(f"{name:26s} {status} {details}")
if not verdicts:

What each check establishes:

- **Bounded exploration.** It hides transitions whose label is `None`, treats a trace as complete only on exact final-marking equality, and cannot cycle silently because the silent closure keeps a visited set and has a size cap. The bound is at most 2 `Correct Defect` (3 iterations) and at most 14 visible events.
- **Exhaustiveness.** Within that bound the comparison is exhaustive: every complete trace and every prefix is enumerated, with no sampling. For the reference the length bound never prunes anything (asserted), so the 45 complete traces and 212 prefixes are all behaviour with up to 3 iterations. For a candidate, a pruned branch is reported, and the result is then exhaustive only up to 14 events. It is not exhaustive for the full language, which is infinite.
- **`language_difference`.** This closes that gap for bounded nets. Both state spaces are finite (15 markings each), so determinising both and walking the product decides equality of the complete visible languages for any number of iterations. It decides trace equivalence only.
- **`check_soundness`** is run in section 3 and cross-checked against the explicit state space.
- **Footprints and the reachability-graph profile** are abstractions. Equal footprints do not imply equal languages; a different graph size is a note, not a rejection.
- **Witnesses** tie the result back to the invariants: 10 must be accepted and 25 must be rejected by every net, including the reference.
- **Playout** is a random sample checked in both directions with the exact acceptor. It can find a difference; it cannot prove equality.
- **Negative controls** K1–K3 must be rejected, otherwise the script fails.

Observed in the run: the round-tripped net passed every check, and all three controls were caught. `fire` and `tau_closure` are shared by both sides of every comparison, so a defect in them would affect both; the hand count of 45 and PM4Py's own footprints are the independent cross-checks.

# 6. Visual-Semantics Review

The rendering of `bpmn_from_net` runs left to right: start, `Register Change`, a parallel split, `Assess Risk` drawn above `Prepare Evidence`, the legal branch on an upper line, the trial loop on a lower line, a parallel join, `Release Change`, `Archive Change`, end. The net behind it passed validation. The picture can still be misread.

- **Parallel gateways.** The "+" after `Register Change` can be read as "both at the same time" or as "both required in a fixed top-to-bottom order". It means only "both, in any order". The "+" after `Assess Risk` has no matching join, so readers may assume that Legal Review must wait for `Prepare Evidence`, or that the diagram is broken. The "+" before the loop can be mistaken for a point where the legal branch also joins.
- **Exclusive gateways.** The pair around `Legal Review` looks like a data-based decision with missing conditions. The source contains no condition, only a nondeterministic option. The bypass is a plain arrow and is easy to miss, which turns an optional activity into a mandatory one in the reader's mind. The "X" after `Inspect Trial` invites the label "defect found?", which is plausible but is not in the source.
- **Loop visualization.** The loop is an ordinary back-flow from `Correct Defect` to an "X" in front of `Configure Trial`. Nothing marks it as a loop. Readers may take `Correct Defect` for part of every iteration, may believe verification can be skipped, or may believe the process can go from `Correct Defect` straight to release. Nothing shows that at least one iteration is required or that the number of iterations is unbounded.
- **Silent routing nodes.** The two silent transitions of the net do not appear as tasks. The skip is an arrow; the join of `A` and `P` is a "+". Gateways are not activities and will never appear in an event log. Anyone comparing the diagram with a log must not expect them, and must not count them as steps.
- **Apparent ordering of graph layout.** Position comes from the layout engine. `Assess Risk` above `Prepare Evidence` suggests priority. `Legal Review` is drawn to the left of `Configure Trial`, which suggests that legal review comes first, although it may happen during or after the trials. Two horizontal lines look like lanes or departments. Only a directed path of sequence flows states an order. Two elements without such a path are unordered, wherever they are drawn.

Annotations and documentation that reduce the ambiguity:

1. Name every gateway: "AND split: risk and evidence, any order", "Legal review? (optional; no rule in the model)", "AND join: risk and evidence both done", "Rework needed? (no rule in the model)", "AND join: legal branch resolved and verification finished".
2. Put a text annotation on the bypass flow ("skip, no activity") and on the back-flow ("repeat trial after correcting the defect").
3. Draw a group around `Configure Trial`, `Inspect Trial` and `Correct Defect`: "Verification: at least one trial; Correct Defect only between trials".
4. Add a note at `Legal Review`: "may happen at any time after Assess Risk and before Release Change, including during verification and before Prepare Evidence".
5. Add a legend: "Position carries no meaning. Only arrows state order. Generated from POWL source `<hash>` with PM4Py `<version>` on `<date>`; not authoritative."
6. Ship the invariant table S1–S13 and a short "can happen / cannot happen" list taken from the witness traces with every diagram.
7. Apply annotations in a post-processing step on the exported diagram, and repeat the round-trip validation afterwards, because editing a diagram can change its flows.

# 7. Rejection Criteria

A conversion result is rejected, or quarantined until a person has reviewed it, when any of the following holds.

1. A conversion raises, returns `None`, or returns a marking that is `None`, empty, or refers to places outside its net.
2. The net is not a workflow net, or the explicit state space shows a deadlock, a marking that covers the final marking with tokens left over, a dead transition, or more markings than the cap.
3. `check_soundness` and the state-space check disagree. Quarantine; do not choose the convenient verdict.
4. An exact-final-marking test fails: a positive witness does not end in exactly the final marking, or a completed trace is recognised only by "sink marked".
5. A required interleaving is lost: any of P02, P03, P05, P06, P09, P10 is rejected, or a footprint pair that should be parallel (`A`/`P`, `L`/`P`, `L`/`C`, `L`/`I`, `L`/`D`) is not.
6. Release before verification is admitted: N11, N12, N17 or N18 is accepted, or release happens before the legal branch is resolved (N19).
7. Optional behaviour collapses: P01 is rejected (legal became mandatory), `Legal Review` disappears from the label set, or N06 is accepted.
8. Loop semantics change: zero iterations, repetition without `Correct Defect`, exit directly after `Correct Defect`, or `C`/`I` swapped (N10, N13–N16).
9. Label inventory differs: a missing, extra or duplicated visible label in a net, or a missing, extra or duplicated task in the BPMN, or a visible label on a routing element.
10. The BPMN contains an inclusive gateway, or not exactly one start and one end event.
11. `language_difference` returns a distinguishing trace, or the bounded complete-trace or prefix sets differ from the reference.
12. A playout trace of either model is not accepted by the other.
13. A process tree is returned for this source. Quarantine by default: it is acceptable only with unique labels and exact language equality, which the N-shaped order makes implausible.
14. A negative control is not caught, or the reference net itself fails a witness. Then the validation is void and nothing may be released.
15. The artifact cannot be tied to a source hash, a PM4Py version and a validation report.

A rendering failure alone is not a semantic rejection, but a diagram that could not be produced cannot be published.

# 8. Canonical Representation Recommendation

**Authoritative representation.** The POWL model is canonical: the construction script (or a serialisation of it) under version control, stored together with the invariant table S1–S14 and the witness traces as its acceptance specification. It is the only form that states the partial order, the optional choice and the loop directly, without routing artefacts. The order relation should be stored in one fixed form, covering edges as given, and closed transitively at load time by tooling.

**Derivative artifacts.** All of these are generated and never edited by hand:

- the accepting Petri net (`net_from_powl` with both markings), which is the executable reference for validation and conformance checking;
- the BPMN model, which is the stakeholder visualisation;
- image files, the round-tripped net, reachability graph and footprints.

**Evidence that must accompany each derivative.**

| Derivative | Required evidence |
|---|---|
| Petri net | Source hash and PM4Py version; markings check; workflow-net result; both soundness results; all 35 witnesses; bounded language size equal to the hand count (45 for up to two reworks); label inventory. |
| BPMN | Everything above for the net it was generated from; `bpmn_profile` result; round-trip verdict with `language_difference` empty, bounded sets equal, footprints equal; negative controls caught; an explicit statement that behaviour was validated through PM4Py's BPMN-to-net mapping and at trace level only. |
| Images | Name of the model object they were rendered from and its hash; the legend from section 6. |

**Process-tree intermediate.** It should not be allowed as a delivery path for this model. The attempt may be run as a probe, and its failure should be recorded as the expected result. If a future release returns a tree, it must be treated as an approximation until it passes exact language equality with unique labels. A tree that drops S5 or S7 to become block-structured must never be presented as the process.

**Avoiding round-trip drift.**

- Generation is one-way: POWL → net → BPMN. The BPMN-to-net conversion is used only for validation and never written back.
- A change requested on the diagram is made in the POWL source, then everything is regenerated and revalidated.
- A change to behaviour updates the invariant table and the witnesses in the same commit.
- The validation runs automatically on every change, with the PM4Py version pinned. A version upgrade is treated as a change and triggers full revalidation.
- Models are compared by label and behaviour. Identifiers, element counts and layout are expected to change between runs.

# 9. Residual Uncertainty

Even if every test passes, the validation does not establish the following.

1. **Independence (S14).** That unordered activities are truly concurrent, as opposed to a choice between sequential orders, is not shown by any interleaving-based check.
2. **Branching behaviour.** Trace equivalence does not show when choices are made. Whether the loop exit is decided at `Inspect Trial` or left open until `Release Change` is not tested, and the two readings of the BPMN differ on it.
3. **Behaviour in another BPMN tool.** The round trip uses PM4Py's own reverse mapping. It shows that PM4Py's two converters agree with each other, not that a workflow engine or modelling tool will interpret the unnamed, direction-unspecified gateways the same way. The serialised BPMN file was not validated at all, only the in-memory object.
4. **Fidelity of POWL→Petri to POWL semantics.** The reference net was checked against the invariant table and a hand count, which encode one reading of the source. No independent POWL interpreter was used. Behaviour outside the invariants I thought to write down is not covered.
5. **Termination in practice.** Soundness says the process can always complete, not that it will. The loop may repeat without limit.
6. **Human reading.** No test shows that a stakeholder will read the diagram correctly, with or without the proposed annotations.
7. **Everything the model does not contain.** Conditions for skipping legal review, who decides on rework, data, resources and time are absent from the source. Any such meaning read into the BPMN is invented.
8. **Other environments.** The observations come from one PM4Py version. The instability of `check_soundness` seen here suggests results can vary across installations; its cause was not investigated.
9. **Correctness of the intended semantics.** The validation shows agreement with the source model. Whether the source model describes the real change process is a separate question.
