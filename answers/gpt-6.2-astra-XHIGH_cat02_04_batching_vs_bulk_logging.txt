# 3. Consequences for performance analysis

For queue arrival A, local start S, local completion E and insertion R, the observed waiting time is S − A, elapsed service is E − S, and recording lag is R − E. Using these as physical durations assumes compatible clocks and the intended lifecycle meanings. Their sum identity, (S − A) + (E − S) = E − A, makes attribution important. Moving a start earlier transfers time from waiting to service even when end-to-end time is unchanged. Utilization needs busy time divided by available capacity-time over a defined window. Summing item intervals, taking their union at a station and counting human touch minutes answer different questions. The fragments give no full-shift denominator.

# 4. PM4Py and pandas analysis

The program treats displayed HH:MM values as HH:MM:00 for the exact-stamp analysis. It retains the upstream arrival, both local lifecycle fields and insertion time as distinct columns. Each activity/resource pair identifies one cluster in this extract. For each resource, the overlap rate is the fraction of unordered case pairs whose intervals intersect for a positive duration. Both cases must have known endpoints with E ≥ S. A boundary contact or a pair of point events contributes zero. S_ties and E_ties list sizes of equality groups of two or more. lag_s is the median signed insertion lag. on60 and on900 are fractions of available lifecycle endpoints on minute and quarter-hour grids. firstQ counts observed arrivals by the first recorded start, including ties. peakQ counts the largest number of observed cases in [arrival, start) at once. Both are fragment counts and depend on the validity of the starts.

    if pd.isna(value) or value in ("", "-"):
        return pd.NaT
    # UTC is a neutral common coordinate for arithmetic, not a measured zone.

def overlap_rate(group):
    intervals = list(group.loc[group.valid, ["start", "complete"]]
                     .itertuples(index=False, name=None))
    pairs = len(intervals) * (len(intervals) - 1) // 2
    hits = sum(max(s, t) < min(e, f) for (s, e), (t, f) in combinations(intervals, 2))
    return hits / pairs if pairs else float("nan")

    counts = series.value_counts()
    return ",".join(str(n) for n in counts[counts > 1]) or "-"

        return float("nan")
    return times.eq(times.dt.floor(f"{seconds}s")).mean()

# 5. Robustness and alternative explanations

**Resource assumptions.** With a trusted physical cell ID, a four-position fixture makes G1's overlap credible as occupancy. With a trusted individual ID, G2's four open inspections and G3's four open reviews can include setup, unattended time or waiting for a release. Neither implies four continuously active pairs of hands. G4 and G8 fit a single serial server under that assumption. If their IDs are shared, the recorded cases still form serial runs, but operator continuity and individual utilization no longer follow. If RBT-7 denoted several stations, even single-fixture occupancy would need a station or cycle key. For G5 there is direct evidence against treating the account as one individual. Four open cases for eight minutes exceed the three-analyst limit for exclusive attention, even if all three were present. Several workers, interleaving and paused work can coexist. Reassigning each case to a fictional analyst would conceal that ambiguity. Changing identity assumptions alone cannot recover G6's missing execution times or G7's lost resolution.

**Clock assumptions.** The exact-time reading yields four negative waits in G7 and a nominal three-minute interval between safety-check finish and triage start in G8. For a censored analysis, first map sources to a common clock with an uncertainty range. Then give each stamp a feasible interval according to its device's rounding rule. Under floor rounding at resolution p, a displayed time t represents [t, t + p). Under ceiling it represents (t − p, t]. Nearest rounding gives a half-width of p/2. If the rule is unknown, test the plausible rules separately. Documented granularity alone cannot bound clock offset, delayed entry or form defaults.

Given aligned arrivals, intersect candidate intervals with A ≤ true start ≤ true completion. For example, a feasible start window [L, U] yields a waiting range from max(0, L − A) to U − A, provided it still contains a feasible start. An empty intersection flags a data conflict. To test possible concurrency, ask whether any feasible assignment overlaps. A sufficient test for unavoidable overlap is that the later of the two upper start bounds precedes the earlier of the two lower end bounds. These tests pertain to open intervals. Inferring concurrent attention also needs the execution semantics.

- **G1, G4 and G8.** At genuine one-second resolution, uncertainty of a second per edge leaves G1's substantial shared interval intact. It can turn exact handoffs in G4 and G8 into tiny gaps or overlaps. Neither change decides whether a fixture head moves serially or a packing run was planned. An unmeasured inter-system offset in G8 can move the safety-check end to either side of restart while preserving the scanner's seven-minute durations.
- **G2, G3 and G5.** One-minute censoring can split tied boundaries, but substantial open-case overlaps survive. A common button and a real common setup fit G2 equally well at the opening instant. In G3, a bulk form and a genuine common authorization fit the same end times but imply different review-service estimates. G5's eight-minute four-way intersection is too long for minute rounding alone to explain.
- **G6.** Minute censoring could accommodate genuinely short closures within the minute. It cannot date earlier investigation or resolution. If each case became workable at arrival and its work finished by insertion, a weak bound is 0 ≤ physical wait + elapsed work interval ≤ R − A. The split is unidentified. Treating a one-minute timestamp bin as the only uncertainty would give spurious precision.
- **G7.** Under the specific floor-start/ceil-end rule and aligned arrival clocks, all five executions could fit between 14:00 and 14:15, serially or in parallel. For M05, arrival at 14:11 leaves at most four minutes to both wait and finish. A real simultaneous group could start no earlier than the last member's arrival at 14:11. Different rounding directions change these bounds and may make some rows infeasible. Use rule-specific bounds until the device rule is verified.

Two further pairs remain observationally indistinguishable even with exact reported times. G4's five contiguous services could follow either an explicit five-item release or ordinary FIFO with enough work waiting. G8's long initial gap could reflect safety work or unavailable capacity for another reason. A threshold that repeatedly triggers at five, or a station-state record linked to the safety check, would discriminate where timestamp matching cannot.
