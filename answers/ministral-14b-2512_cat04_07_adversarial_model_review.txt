## **7. Third Alternative: Hybrid Procedural + DECLARE Model**

### **1. Compact Formal Description**
- **Procedural Backbone** (POWL):
  - `Register Dossier  (Credit Check  Technical Review)  (Supplier Review?)  (Expedite Review?)  (Manager Approval  Auto Approval)  Release Order`
  - **Constraints**:
    - `Credit Check` and `Technical Review` are **mandatory** and must precede approval.
    - `Supplier Review` is **optional** but **only for external orders** (attribute-dependent).
    - `Expedite Review` is **optional** but must **follow both mandatory checks**.
    - **Exactly one** of `Manager Approval` or `Auto Approval` must occur.
    - `Correct Dossier` triggers **repetition of affected checks** (handled via **external policy check**).

- **DECLARE Constraints** (for flexibility):
  - `Response(Credit Check, Technical Review)`: Checks must precede approval.
  - `Exclusive Choice(Manager Approval, Auto Approval)`: Exactly one approval.
  - `Existence(Correct Dossier)`: Corrections are allowed but require rechecks.

```python
def is_valid_trace(trace, log_attributes):
    # Check mandatory checks
    if "Credit Check" not in trace or "Technical Review" not in trace:
        return False

    # Check approval
    approvals = [a for a in trace if a in ["Manager Approval", "Auto Approval"]]
    if len(approvals) != 1:
        return False

    # Check Supplier Review is only for external orders
    if "Supplier Review" in trace and log_attributes.get("external", False) == False:
        return False

    # Check Expedite Review follows checks
    if "Expedite Review" in trace:
        idx_expedite = trace.index("Expedite Review")
        idx_credit = trace.index("Credit Check")
        idx_tech = trace.index("Technical Review")
        if idx_expedite < min(idx_credit, idx_tech):
            return False

    # Check corrections
    if "Correct Dossier" in trace:
        idx_correct = trace.index("Correct Dossier")
        next_activity = trace[idx_correct + 1] if idx_correct + 1 < len(trace) else None
        if next_activity not in ["Credit Check", "Technical Review"]:
            return False

    return True
```
