# 4. PM4Py and Pandas Analysis

```python
import pandas as pd
import pm4py

# Construct data
data = [
    {"cluster": "G1", "case": "L01", "activity": "Apply label", "resource": "RBT-7", "queue_arrival": "08:54", "start": "09:00", "complete": "09:03", "recorded_at": "09:03:02", "source": "PLC", "precision": "1 sec", "sequence_no": 501},
    # ... (remaining rows)
]

df = pd.DataFrame(data)
df["queue_arrival"] = pd.to_datetime("2026-05-26 " + df["queue_arrival"], format="%Y-%m-%d %H:%M")
df["start"] = pd.to_datetime("2026-05-26 " + df["start"], format="%Y-%m-%d %H:%M")
df["complete"] = pd.to_datetime("2026-05-26 " + df["complete"], format="%Y-%m-%d %H:%M")
df["recorded_at"] = pd.to_datetime("2026-05-26 " + df["recorded_at"], format="%Y-%m-%d %H:%M:%S")

# PM4Py interval log
log = pm4py.format_dataframe(df, case_id="case", activity_name="activity", timestamp="complete", resource="resource")
log["start_timestamp"] = df["start"].dt.strftime("%Y-%m-%d %H:%M:%S")

# Batch discovery
batches = pm4py.discover_batches(log, merge_distance=pd.Timedelta(minutes=1), min_batch_size=2)
print("PM4Py detected batches:\n", batches)

# Independent diagnostics
overlap_rate = df.groupby("resource").apply(lambda x: (x["start"] < x["complete"].shift(-1)).mean())
start_equality = df.groupby("cluster")["start"].apply(lambda x: (x.duplicated()).sum())
recording_lag = (df["recorded_at"] - df["complete"]).dt.total_seconds().mean()
timestamp_granularity = df.groupby("source")["precision"].first()

print("\nDiagnostics:")
print("Overlap rate per resource:\n", overlap_rate)
print("Start equality groups:\n", start_equality)
print("Recording lag (seconds):\n", recording_lag)
print("Timestamp granularity:\n", timestamp_granularity)

# Compare with PM4Py
print("\nCluster-level diagnostics:")
for cluster in df["cluster"].unique():
    cluster_data = df[df["cluster"] == cluster]
    start_eq = (cluster_data["start"].duplicated()).sum()
    end_eq = (cluster_data["complete"].duplicated()).sum()
    print(f"\nCluster {cluster}:")
    print(f"  Start equality: {start_eq}, End equality: {end_eq}")
    print(f"  PM4Py batch size: {len(batches[batches['case_id'].str.contains(cluster)])}")
```

# 6. Data-Collection Redesign Recommendations

1. **Execution Timestamps**: Record **start/end** with **sub-second precision** (e.g., 100 ms).
2. **Recording Timestamps**: Separate **event time** from **database insertion time**.
3. **Source Clocks**: Synchronize clocks (e.g., NTP) or log clock offsets.
4. **Resource Identity**: Use **badge-level identity** (not shared accounts).
5. **Group/Batch IDs**: Explicitly tag **physical batches** (e.g., `batch_id`).
6. **Workstation Capacity**: Log **fixture/item counts** (e.g., RBT-7 holds 4 items).
7. **Pause/Resume Events**: Track **idle periods** (e.g., `pause_at`, `resume_at`).
8. **Timestamp Precision**: Document **true accuracy** (not just documented granularity).
