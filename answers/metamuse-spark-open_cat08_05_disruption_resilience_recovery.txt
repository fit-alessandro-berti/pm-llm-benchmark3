# 3. Resilience versus concealed noncompliance

**Definition in this case:** Resilience is an adaptation that maintains *both* the mission (patient supply continuity, especially Hospital-critical) *and* the control intent proportionate to product/customer risk, with transparent, contemporaneous evidence that enables later reconciliation. Concealed noncompliance is an adaptation that preserves *apparent* throughput, cycle time, or fill rate by silently dropping, sampling without justification, or retroactively fabricating a control, shifting risk to patients, downstream customers, or regulators while metrics look acceptable.

**True resilience (preserve flow + preserve control intent):**
*   **B. Manual authorization check:** Control performed differently (offline lists/phone) but not skipped. Cost is speed/capacity.
*   **F. Temporary release control for Controlled-substance:** 100% pharmacist check, proportionate to risk. Would be non-resilient if applied to cold-chain without temp check.
*   **I. Defer noncritical order & J. Backlog prioritization - when rules explicit:** Intentional, transparent rationing that protects critical supply at known cost to non-critical. Resilience is the *choice* and communication, not just the throughput.
*   **K. Reconcile manual reservation & L. Audit remediation - as recovery steps:** They do not replace real-time control, but their existence as *planned, staffed* recovery work is resilient. Without K/L, traceability would remain 9.5%.

**Risky shortcuts (throughput without control = concealed noncompliance):**
*   **C. Skip system authorization check:** 1,600 ambient shipments on assumed authorization. Conformance checker flagged as move-on-log deviation. If a recalled lot or lapsed pharmacy was shipped, no real-time stop. Audit remediation cannot recreate the decision point.
*   **G. Dispatch without scan for Controlled/Cold-chain:** Largest traceability gap (3,250 cases). Directly drives 9.5% traceability exceptions in T2 and 5.4% in T3. Accelerated dispatch metric hides chain-of-custody loss. For controlled substances, this is potential diversion risk.
*   **D. Manual inventory snapshot check when stale (Day 2) and H. Phone proof for controlled:** Initially reasonable, but beyond validity window they become shortcuts because the evidence no longer supports the risk.

**Ambiguous - depends on risk appetite and guardrails:**
*   **A. Hospital-critical fast lane:** Resilient if `fast` means *triage priority* with minimum controls (verbal pharmacist release + offline authorization re-check within 24h). Noncompliant if `fast` means *skip authorization entirely* for controlled/recall-sensitive. Data shows both occurred: 1,000 fast lane but only 2,500 manual authorization checks for 5,100 triaged orders. Need to disaggregate which fast-lane orders had retro-validation.
*   **E. Manual pick list & H. Phone proof for Ambient:** Acceptable trade-off if accompanied by contemporaneous manual evidence (signature, lot photo). Unacceptable if later reconstructed from memory for audit. Distinction is evidence quality at time of action, not at audit.
*   **I/J. Deferral/prioritization:** Resilient under published clinical/customer equity rules with appeal/stop-loss. Noncompliant/unfair if informal "who shouts loudest" leads to Wholesale-bulk starvation (T4 p90 120h vs 72h baseline suggests this).

**Test:** If an adaptation would be defensible to a regulator the next day with contemporaneous notes, and its cost (delay, rework) is visible in KPIs, it leans to resilience. If it makes KPIs look better while hiding rework in a later reconciliation queue, it leans to concealed noncompliance.

# 4. Recovery process model

**Design principle:** Separate *operational recovery* (get trucks moving) from *control recovery* (prove it was right). Model enforces Risk-Based Minimum Controls (RBMC) that cannot be skipped even in manual mode.

**Trigger Conditions (T0 -> T1 transition):**
*   Automatic trigger: WMS unavailable >30 min OR inventory sync error >15 min OR scanning failure >10% orders in hour.
*   Declare Incident Mode: Warehouse manager + Responsible Pharmacist + Compliance on call. Activate offline kit (printed stock snapshot, authorization whitelist, temp loggers, manual forms).
*   Freeze snapshot timestamp; start staleness clock.

**Triage Rules (Applies in T2 and T3):**
1.  **Tier 0 - Life-critical:** Hospital-critical + Cold-chain/Controlled/Recall-sensitive + ICU/OR orders -> Fast lane with *full* RBMC.
2.  **Tier 1 - Critical standard:** Hospital-critical Ambient, Pharmacy-standard Controlled/Cold-chain urgent.
3.  **Tier 2 - Standard:** Pharmacy-standard Ambient, Recall-sensitive non-urgent.
4.  **Tier 3 - Deferrable:** Wholesale-bulk Ambient non-urgent.
*   Tier 0/1 must be authorized and released before Tier 3 picking starts.

**Minimum Controls by Product/Customer Risk Matrix (RBMC) - *Never skip, only do manually*:**
*   **All orders:** Manual authorization check (B) + manual evidence capture.
*   **Cold-chain:** + continuous temp logger or manual temp log per pack + photo of ice pack/packaging. Without temp evidence, cannot Dispatch (even if G is allowed for Ambient).
*   **Controlled-substance:** + Dual-control (two sign-offs) + Temporary release control (F) 100% + Dispatch with scan-equivalent (photo of label + courier ID + signature).
*   **Recall-sensitive:** + Lot/Batch manual recording (photo) + second checker on pick.
*   **Ambient low-risk:** May use courier manifest signature as dispatch evidence.

**Process Model in BPMN-style (with POWL semantics):**

`POWL = Partially Ordered Workflow Language: SEQ = sequence, XOR = exclusive choice, AND = parallel, LOOP = repeat`

```
PROCESS Disruption-Recovery-Pharma-Wholesaler:

SEQ {
  START -> Receive order

  XOR IncidentMode? {
    NO: SEQ { Validate authorization -> Inventory reservation -> Pick -> Pack -> Quality/release check -> Dispatch -> Proof of delivery -> Invoice close -> Audit remediation check? -> END } // normative T0 path, adds light check even in baseline
    YES: SEQ {
      Emergency triage (Tier 0-3 assignment) 
      -> AND {
           Authorization branch: XOR { Manual authorization check (B) ; Skip only if Whitelist-Ambient-Preapproved AND 24h expiration } 
           Inventory branch: Manual inventory snapshot check (D) with staleness guard
         }
      -> LOOP Deferral? { Defer noncritical order (I) -> Backlog queue -> Backlog prioritization (J) } // prevents starvation
      -> Manual pick list (E) with evidence capture
      -> Manual pack
      -> RBMC Release: AND {
           Temporary release control (F) for controlled/recall,
           Temp documentation for cold-chain,
           Dual-control sign-off
         }
      -> XOR DispatchMode { Dispatch without scan-equivalent (G-manual) for Ambient ; Dispatch with scan/photo for Controlled/Cold-chain }
      -> Phone proof of delivery (H) with contemporaneous log (+ photo if Tier 0/1)
      -> Spreadsheet invoice hold
      -> Reconciliation: SEQ { Reconcile manual reservation (K) -> Compliance re-validation (authorization, temp, dual-control) }
      -> XOR Compliant? { YES -> Invoice close -> END ; NO -> Audit remediation (L) -> Risk assessment -> XOR { Release, Quarantine/Recall, Customer notification } -> END }
    }
  }
}

Explanation of notation:
- SEQ = steps in order
- XOR = choose one path based on explicit rule (e.g., product tier)
- AND = parallel checks (authorization and inventory checked together)
- LOOP = repeated monitoring (deferred orders not cancelled automatically, re-enter prioritization with aging factor)
- Audit remediation is not parallel to normal flow; it is a mandatory gateway *before* END for any case with missing RBMC evidence.
```

**Manual Evidence Capture Standard (T2/T3):**
*   Every manual step captures: Who, When (handwritten timestamp), What (order/lot/courier ID), Second checker where required, Photo on personal device uploaded to emergency share.
*   No reconstruction from memory >24h. If evidence missing, case flagged as `Compliance exception` not `Complete`.

**Backlog Prioritization (T3/T4):**
*   Scoring: `Priority = Customer Tier weight (Hospital 4 / Pharmacy 2 / Wholesale 1) * Product risk (Controlled/Cold 3 / Recall 2 / Ambient 1) + Age factor (+1 per 24h)`. 
*   Starvation cap: No Tier 3 order waits >72h without supervisor review; no Tier 2 >48h. Prevents Wholesale p90 blowout to 180h seen in T2.
*   Transparent communication: Automated SMS/email to deferred customers with reason and expected time.

**Reconciliation and Audit-Remediation Flow (T4 - formally part of T2/T3 but executed later):**
*   **K. Reconcile manual reservation:** Daily cycle counts on manually touched SKUs -> inventory adjustment -> order status re-validation -> cancel if stockout with customer callback. Staffed as separate team, measured as lagging KPI (see §5). Completion defined as inventory variance <2%.
*   **L. Audit remediation:** Every case with `Dispatch without scan`, `Phone proof`, `Skip authorization`, or missing temp/dual-control enters queue. Steps: 1) Attempt retro-evidence collection (courier GPS, customer callback, temp logger download) 2) Compliance re-validation against whitelist at shipment date 3) Risk assessment per product type 4) Disposition. Cases remain `Open - Compliance remediation` until disposition; not counted as Invoice close -> END. Regulator-ready pack.

# 5. Resilience indicators

All indicators split by **segment (Hospital-critical / Pharmacy-standard / Wholesale-bulk)** and **product type (Ambient / Cold-chain / Controlled / Recall-sensitive)**. Dashboard updates hourly in incident mode.

**Leading indicators (warn during T1/T2 that controls are drifting):**

*   **Throughput & Service Protection:**
    *   `Order intake rate vs fulfillment rate by Tier` - gap >15% triggers deferral review.
    *   `Hospital-critical fill rate (hours)` - target >90% even in manual mode; drop <85% = escalation.
    *   `% orders triaged within 1h of receipt` - measures triage capacity.

*   **Traceability & Control Completeness:**
    *   `Manual authorization check completion rate` - target 100% Tier 0-1, >95% others; <90% = red.
    *   `Controlled dual-control sign-off rate` - must stay >99%; missing 2.9% in T2 was critical breach.
    *   `Cold-chain temp documentation capture at pack` - must stay >98%; missing 4.8% in T2 flagged F gap.
    *   `Scan-equivalent capture rate at dispatch` - leading proxy for traceability exceptions; <95% predicts downstream audit queue.

*   **Backlog Age & Rework Risk:**
    *   `Backlog queue age (p50, p90) by Tier` - if Backlog p90 >24h in T2 or >48h in T3, staleness risk for D.
    *   `Manual snapshot age (hours since freeze)` - >12h amber, >24h red - forces cycle count.
    *   `First-pass rework flags` - Repack/recheck rate >5% indicates picking errors from E.

*   **Fairness:**
    *   `Deferral/cancellation rate by customer group` - Pharmacy-standard cancellation jumped to 7.8% vs Hospital protected; disparity >3x triggers fairness review.
    *   `Waiting time equity ratio (Wholesale p50 / Hospital p50)` - T2 ratio was 9.6 (96h/10h) vs baseline 4.5 (36h/8h) - signals starvation.

**Lagging indicators (reveal hidden workload after operational KPIs recover in T3/T4):**

*   **Throughput recovery illusion check:**
    *   `Median & p90 cycle time by segment` - must compare to baseline, not to T2. Persistent +20% Pharmacy, +60% Wholesale in T4 shows incomplete recovery.
    *   `Cancellation rate` - target return to <2.5% within 7 days post-recovery.

*   **Traceability & Control recovery:**
    *   `Traceability exceptions %` - baseline 0.8%, T4 2.2% reveals lingering 2.75x risk; must trend to <1.2% within 14 days.
    *   `Cold-chain/controlled missing docs %` - must return to <0.6% / <0.4% before declaring recovery complete.
    *   `Conformance fitness & % fitting traces` - recovery complete when fitness >0.93 and fitting >85%, not just throughput normal.

*   **Backlog & Reconciliation:**
    *   `Inventory reconciliation variance % SKUs` - 1,400 reconciliations in T4; track remaining open K cases.
    *   `Audit remediation queue depth & age` - 2,300 cases entered remediation; target zero >7 days old within 21 days.
    *   `Rework / correction case rate` - T4 5.8% vs 3.5% baseline indicates quality debt.
    *   `Invoice close -> Audit remediation tail (avg days)` - temporal profile deviation; should be <2 days in normal ops.

*   **Fairness final check:**
    *   `Post-recovery service level by customer group` - did Wholesale ever recover or was capacity permanently reallocated?
    *   `Customer complaints & retrospective SLA credits by segment`.

**Composite resilience scorecard:** Operational recovery = median cycle time within 15% of baseline for *all* segments + fill rate >95%. Control recovery = traceability + missing docs within 50% of baseline + fitness >0.93 + zero audit remediation >14 days old. Both must be green to close incident.

# 6. Recommendations for future disruptions

**P0 - Immediate / Low effort, high benefit (implement <30 days):**

1.  **Create offline authorization whitelist pack (B).** Weekly export of active customers + product eligibility + recall holds, stored encrypted offline + paper. Enables Manual authorization check without phoning all.
    *   *Effort:* Low (IT export + SOP). *Benefit:* Eliminates C (Skip authorization) necessity; restores 1,600 risky cases to controlled path. *Residual risk:* Human error if whitelist outdated; mitigate weekly refresh.
2.  **Define and publish triage & deferral rules (A, I, J).** Document Tier 0-3 criteria, publish customer communication template, set starvation caps.
    *   *Effort:* Low (workshop + communication). *Benefit:* Makes rationing defensible, improves fairness, prevents ad hoc bias and Pharmacy 7.8% cancellation spike. *Residual risk:* Customer dissatisfaction remains but becomes managed.
3.  **Enforce RBMC checklist and staleness guard (D, F, G).** One-page manual release form: auth check, dual-control, temp log, lot photo, dispatcher signature. Snapshot expires after 12h.
    *   *Effort:* Low (paper form + training). *Benefit:* Converts hidden risk to visible delay; prevents dispatch without scan for controlled/cold-chain; reduces 9.5% traceability. *Residual risk:* Slower throughput; need staffing.

**P1 - Short-term / Medium effort, high benefit (1-3 months):**

4.  **Deploy offline capture kit for evidence (E, G, H).** Pre-configured: battery scanners with offline mode, personal device photo upload app, prepaid phones with call logging, temp loggers with manual download. Define scan-equivalent standard.
    *   *Effort:* Medium (hardware + app config). *Benefit:* Preserves traceability without WMS; reduces move-on-model deviations; enables real evidence vs reconstruction. *Residual risk:* Data sync errors on recovery - needs K process.
5.  **Build backlog prioritization engine (J) with scoring and starvation cap.** Simple spreadsheet tool implementing formula + age factor; manager override log required.
    *   *Effort:* Medium (tool + integration to order intake). *Benefit:* Prevents Wholesale p90 180h blowout and post-recovery 58h vs 36h drag; improves fairness. *Residual risk:* Complexity in weighting disputes; needs governance.
6.  **Stand up dedicated Reconciliation & Audit Remediation cell (K, L).** Separate team, separate queue, separate KPIs; cases not counted as closed until remediation complete.
    *   *Effort:* Medium (staffing plan + queue system). *Benefit:* Makes hidden workload visible; prevents premature incident closure; reduces T4 2.2% lingering exceptions faster. *Residual risk:* Cost; requires trained auditors not just ops staff.

**P2 - Medium-term / Higher effort, structural resilience (3-6 months):**

7.  **WMS resilience upgrade: offline / degraded mode.** WMS runs read-only on local warehouse server with 24h inventory snapshot + manual decrement capability; syncs when online. Automatic incident trigger.
    *   *Effort:* High (IT architecture). *Benefit:* Removes need for printed snapshot (D staleness) and manual pick list (E) re-entry; directly improves fitness from 0.71. *Residual risk:* Cyber risk must isolate offline mode; needs pen testing.
8.  **Segmented inventory buffering for Tier 0.** Safety stock for Hospital-critical cold-chain/controlled (e.g., +15%) in separate logical location not dependent on full WMS reservation.
    *   *Effort:* High (working capital + space). *Benefit:* Protects 91% fill rate without bypassing controls; decouples critical supply from system risk. *Residual risk:* Holding cost and expiry.

# 7. Management trade-off statement

Management should accept that preserving Hospital-critical supply during a cyber outage will deliberately slow Pharmacy-standard and Wholesale-bulk service and will require expensive, slower manual controls (offline authorization checks, dual sign-offs, temp logging) — because the alternative, skipping authorization and dispatch scans to keep throughput high, creates concealed noncompliance that audit remediation cannot fully cure and that regulators will treat as a control failure, not a delay. Management should not accept dispatch without scan-equivalent evidence or assumed authorization for controlled, cold-chain, or recall-sensitive products, nor should it declare recovery complete when cycle-time metrics look recovered while traceability exceptions remain >2x baseline and a 2,000+ case remediation queue is still open. We would change this recommendation if evidence showed that retroactive validation reliably caught errors (e.g., <0.5% of skipped authorizations were later invalid) or if offline scan-equivalent capture could be made near-100% with negligible delay — but current data shows the opposite: 9.5% traceability loss and a long compliance tail prove manual shortcuts shifted risk to the future rather than eliminating it.
