## **2. Shared Assumptions**
- **Event semantics**: Activities are atomic and complete sequentially (no nested sub-processes).
- **Missing SC events**: ~5–10% of SC events may be absent due to integration issues (treated as **optional** in permissive/balanced models, but **omitted** in conservative).
- **External/stocked attribute**: Absent  assume worst case (SC is mandatory unless explicitly skipped).
- **Optionality**: Represented via XOR splits/joins (e.g., `XOR[SC, skip_SC]`).
- **Concurrency**: Assumed partial order unless S1 (CCER) is enforced (conservative) or S2 (parallel) is prioritized (balanced/permissive).

---

## **3. Conservative Candidate**
### **Inductive Bias**
Prioritizes **observed behavior** and **high-confidence rules** (D1, D2, S1, S6). Excludes unobserved variants, assumes **sequential CCER** (S1), and treats SC as **mandatory** (S3) despite missing data (S5). Uses XOR for SC to avoid overgeneralization.

### **Formal Expression (POWL)**
```python
StrictPartialOrder(
    [
        Transition("RO"),
        Transition("CC"),
        Transition("ER"),
        Transition("SC"),  # Mandatory (XOR with skip_SC)
        Transition("EX"),  # Optional (requires CC/ER)
        Transition("AC"),
        Transition("RP"),
        Transition("RC"),
    ]
)
# Constraints:
# - RO  CC  ER  SC  EX  AC  RP  RC
# - EX requires CC and ER (implicit in DFG)
# - SC is mandatory (no skip path)
```

### **PM4Py Code**
```python
from pm4py.objects.powl.obj import StrictPartialOrder, Transition

model_conservative = StrictPartialOrder()
model_conservative.order.add_edge("RO", "CC")
model_conservative.order.add_edge("CC", "ER")
model_conservative.order.add_edge("ER", "SC")
model_conservative.order.add_edge("SC", "EX")
model_conservative.order.add_edge("EX", "AC")
model_conservative.order.add_edge("AC", "RP")
model_conservative.order.add_edge("RP", "RC")
model_conservative.order.add_edge("RO", "ER")  # Allows ER before CC (but S1 violated)
```

### **Excluded Behavior**
- Any trace with **ER before CC** (violates S1).
- Traces **skipping SC** (violates S3).
- Traces with **EX before CC/ER** (violates S6).
- **Concurrent CC/ER** (violates S1).

### **Underfitting Risks**
- Overly restrictive (e.g., excludes valid parallel CC/ER cases).
- Fails to account for **stocked components** (S4).
- **Missing SC events** are treated as errors (not optionality).

## **4. Balanced Candidate**
### **Inductive Bias**
Balances **observed patterns** with **plausible generalizations** (D3–D6, S2, S4). Treats **CC/ER as concurrent** (S2), **SC as optional** (S4/S5), and **EX as optional** (D6). Uses **partial order** for CC/ER and **XOR for SC**.

### **Formal Expression (Process Tree)**
```python
Operator.XOR(
    Operator.Sequence(
        Operator.Start("RO"),
        Operator.XOR(
            Operator.Sequence("CC", "ER"),
            Operator.Sequence("ER", "CC")  # Allows concurrency
        ),
        Operator.Sequence(
            Operator.XOR("SC", SilentTransition()),  # Optional SC
            Operator.Sequence("EX", SilentTransition())  # Optional EX
        ),
        Operator.Sequence("AC", "RP", "RC")
    )
)
```

### **PM4Py Code**
```python
from pm4py.objects.process_tree.obj import Operator

model_balanced = Operator.Sequence(
    Operator.Start("RO"),
    Operator.XOR(
        Operator.Sequence("CC", "ER"),
        Operator.Sequence("ER", "CC")
    ),
    Operator.Sequence(
        Operator.XOR("SC", Operator.SilentTransition()),
        Operator.Sequence("EX", Operator.SilentTransition())
    ),
    Operator.Sequence("AC", "RP", "RC")
)
```

### **Excluded Behavior**
- **ER before CC without CC** (violates XOR).
- **SC after AC** (violates D4).
- **EX without CC/ER** (violates S6).

### **Concurrency Handling**
- **CC/ER**: Treated as **partial order** (either order allowed, but not truly concurrent due to S2).
- **SC**: Optional (XOR with skip).
- **EX**: Optional but requires CC/ER.

## **5. Permissive Candidate**
### **Inductive Bias**
Maximizes **generalization** while respecting **domain rules** (D1–D6). Treats **SC as optional** (S4/S5), **CC/ER as concurrent** (S2), and **EX as optional** (D6). Uses **concurrency** where possible (e.g., CC  ER).

### **Formal Expression (POWL)**
```python
StrictPartialOrder(
    [
        Transition("RO"),
        Transition("CC"),
        Transition("ER"),
        Transition("SC"),  # Optional (XOR with skip)
        Transition("EX"),  # Optional (requires CC/ER)
        Transition("AC"),
        Transition("RP"),
        Transition("RC"),
    ]
)
# Constraints:
# - RO  {CC, ER} (partial order)
# - {CC, ER}  SC (optional)
# - SC  AC if present
# - EX requires CC and ER
```

### **PM4Py Code**
```python
model_permissive = StrictPartialOrder()
model_permissive.order.add_edge("RO", "CC")
model_permissive.order.add_edge("RO", "ER")  # Parallel start
model_permissive.order.add_edge("CC", "SC")  # Optional SC
model_permissive.order.add_edge("ER", "SC")  # Optional SC
model_permissive.order.add_edge("SC", "EX")  # Optional EX
model_permissive.order.add_edge("EX", "AC")  # EX requires CC/ER (implicit)
model_permissive.order.add_edge("AC", "RP")
model_permissive.order.add_edge("RP", "RC")
```

### **Excluded Behavior**
- **AC before CC/ER** (violates D3).
- **EX without CC/ER** (violates S6).
- **RC before RP** (violates D2).

### **Generalization Boundary**
- **Allowed**: `RO  CC  ER  skip_SC  AC  RP  RC`.
- **Forbidden**: `RO  ER  CC  AC` (violates D3).

## **8. Validation Code**
```python
import pm4py
from pm4py.objects.petri_net.obj import PetriNet, Marking
from pm4py.objects.log.util import dataframe_utils

# Reconstruct log
log = pm4py.parse_event_log_string([
    "RO,CC,ER,SC,AC,RP,RC",
    "RO,ER,CC,SC,AC,RP,RC",
    # ... (all 30 variants)
])

# Convert models to Petri nets
def model_to_net(model, name):
    net, im, fm = pm4py.convert_to_petri_net(model)
    return net, im, fm

# Soundness checks
def check_soundness(net, im, fm):
    return pm4py.check_soundness(net, im, fm)

# Fitness/precision/generalization
def evaluate_model(log, net, im, fm):
    fitness = pm4py.fitness_alignments(log, net, im, fm)
    precision = pm4py.precision_alignments(log, net, im, fm)
    generalization = pm4py.generalization_tbr(log, net, im, fm)
    simplicity = pm4py.simplicity_petri_net(net, im, fm)
    return fitness, precision, generalization, simplicity

# Playout (sampled)
def playout_model(net, im, fm, max_traces=100):
    return pm4py.play_out(net, im, fm, max_traces=max_traces)

# Test suite
positive_traces = [
    "RO,CC,ER,SC,AC,RP,RC",  # Conservative
    "RO,ER,CC,skip_SC,AC,RP,RC",  # Balanced/Permissive
]
negative_traces = [
    "RO,ER,CC,AC,RP,RC",  # Violates D4
    "RO,CC,EX,AC,RP,RC",  # Violates S6
]

# Run evaluations
for model in [model_conservative, model_balanced, model_permissive]:
    net, im, fm = model_to_net(model, "model")
    print(f"\n{model.__class__.__name__} Results:")
    print("Soundness:", check_soundness(net, im, fm))
    fitness, precision, gen, sim = evaluate_model(log, net, im, fm)
    print("Fitness:", fitness)
    print("Precision:", precision)
    print("Generalization:", gen)
    print("Simplicity:", sim)
```

## **10. Uncertainty Statement**
- **CC/ER Ordering**: **80% confidence** in S2 (parallel) over S1 (sequential). Alternative: S1 is correct (finance constraint).
- **SC Optionality**: **70% confidence** in S4 (optional for stocked components). Alternative: SC is always required (S3).
- **Missing SC Events**: **60% confidence** in treating missing SC as optionality (not error). Alternative: Assume SC is mandatory and missing data is noise.

**Material Alternative**: If S1 is enforced, the **conservative model** becomes the only viable option, but may exclude valid parallel cases.
