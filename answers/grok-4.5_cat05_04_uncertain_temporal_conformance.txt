## 1. Normalization Assumptions

**Clock-offset direction.** Source metadata gives `clock_offset = recorded_clock - true_clock` with offset  [a, b]. Therefore  
`true_time  [t_clock_low - b, t_clock_high - a]`.

**Order of uncertainty.** (1) interpret display/rounding to a source-clock interval; (2) apply measurement uncertainty if stated; (3) apply clock-offset correction; (4) apply extra semantic uncertainty (entry delay, delivery latency, inferred duration).

**HUB.** Recorded instant is exact to the displayed second, then ±0.5 s measurement, then offset [1, +1] s  true interval **recorded ± 1.5 s**.

**OPS-BER.** Floor-to-minute: displayed `HH:MM`  source clock  [`HH:MM:00`, `HH:MM:59.999`]. June dates use CEST (UTC+2). Offset [90, +120] s unless overridden (T-409).

**SENSOR.** Recorded value is rounded to nearest 10 s  source clock  [rec  5 s, rec + 5 s]; offset [5, +5] s. Events are completion instants.

**VENDOR-NY.** Floor-to-minute; EDT (UTC4) on 2026-06-01; offset [180, +180] s.

**LEGACY-BER.** Floor-to-minute; offset [60, +60] s. On 2025-10-26 the local fold 02:00–02:59 is either CEST (UTC+2, first) or CET (UTC+1, second). Ingestion order is used only to eliminate impossible fold combinations; surviving intervals stay full width.

**MOBILE-LON.** Round-to-nearest-minute  source clock  [rec  30 s, rec + 30 s]; BST (UTC+1); offset [300, +300] s. **Entry delay (material):** treated as late recording that shifts the **occurrence** estimate earlier by an additional [0, 300] s (does not shift only the paper record). Alternative “delay is pure record lag with known occurrence” is noted in sensitivity.

**Inferred start (T-404).**  
`Investigation_Start  Investigation_Complete_true  [18 min, 25 min]`, full Minkowski difference retained.

**Missing receipt (T-407).** `Alert_Received  Alert_Sent_true + [0, 20] min`. Causal constraint `Alert_Received  Investigation_Start` is adopted as a **plausible but not logged** assumption and is labeled; without it S1 is not testable.

**Causal order.** Where ingestion or physics requires A before B, pairs with true_A > true_B are excluded; remaining set may be a truncated interval (not replaced by a midpoint).

**SLA vs profile.** SLA bounds are hard legal/operational maxima (S1: 900 s, S2: 2700 s, S3: 129600 s). Profile bands are `mean ± zeta · std`. Classifications: CERTAIN_PASS / CERTAIN_VIOLATION / POSSIBLE_VIOLATION / INDETERMINATE as defined in the prompt. Midpoints are never primary evidence.

**Duration interval.** For true times A  A, B  B with B after A enforced when required:  
`d  [max(0, B_low  A_high), B_high  A_low]` (or union fragments when folds remain). No silent midpoint substitution.

## 5. PM4Py Temporal-Conformance Code

```python
#!/usr/bin/env python3
"""
Interval-based SLA / temporal-profile analysis + lossy midpoint PM4Py comparison.
Does not read external files. PM4Py column names can vary by version; isolated below.
"""
from __future__ import annotations

import itertools
from dataclasses import dataclass
from datetime import datetime, timedelta, timezone
from typing import List, Optional, Tuple, Union
from zoneinfo import ZoneInfo

import pandas as pd

try:
    import pm4py
    HAS_PM4PY = True
except ImportError:
    HAS_PM4PY = False
    print("pm4py not installed; midpoint conformance section will be skipped.")

# ---------------------------------------------------------------------------
# Interval utilities
# ---------------------------------------------------------------------------
Interval = Tuple[datetime, datetime]
Intervals = List[Interval]


def norm_interval(a: datetime, b: datetime) -> Interval:
    return (a, b) if a <= b else (b, a)


def expand(t_low: datetime, t_high: datetime, sub_high: float, add_low: float) -> Interval:
    """true = clock - offset, offset in [a,b] => subtract [a,b] equiv. [t_low-b, t_high-a]."""
    return (t_low - timedelta(seconds=sub_high), t_high - timedelta(seconds=add_low))


def dur_range(a: Interval, b: Interval, enforce_order: bool = True) -> Optional[Interval]:
    """Feasible B-A in seconds as (dmin, dmax)."""
    a0, a1 = a
    b0, b1 = b
    if enforce_order:
        # exclude pairs with b < a
        dmax = (b1 - a0).total_seconds()
        dmin = (b0 - a1).total_seconds()
        if dmax < 0:
            return None  # impossible
        dmin = max(0.0, dmin)
        return (dmin, dmax)
    return ((b0 - a1).total_seconds(), (b1 - a0).total_seconds())


def classify_sla(d: Optional[Interval], limit: float) -> str:
    if d is None:
        return "INDETERMINATE"
    lo, hi = d
    if hi <= limit:
        return "CERTAIN_PASS"
    if lo > limit:
        return "CERTAIN_VIOLATION"
    return "POSSIBLE_VIOLATION"


def classify_profile(d: Optional[Interval], mean: float, std: float, zeta: float) -> str:
    if d is None:
        return "INDETERMINATE"
    lo, hi = d
    band_lo, band_hi = mean - zeta * std, mean + zeta * std
    if hi < band_lo or lo > band_hi:
        return "CERTAIN_VIOLATION"
    if lo >= band_lo and hi <= band_hi:
        return "CERTAIN_PASS"
    return "POSSIBLE_VIOLATION"


# ---------------------------------------------------------------------------
# Source normalizers -> UTC aware datetimes
# ---------------------------------------------------------------------------
def hub(ts: str) -> Interval:
    t = datetime.fromisoformat(ts).replace(tzinfo=timezone.utc)
    return (t - timedelta(seconds=1.5), t + timedelta(seconds=1.5))


def ops_ber_floor(ts_local: str, offset=(-(90), 120), tz="Europe/Berlin") -> Interval:
    # ts_local 'YYYY-MM-DD HH:MM'
    local = datetime.fromisoformat(ts_local).replace(tzinfo=ZoneInfo(tz))
    low_local = local
    high_local = local + timedelta(minutes=1) - timedelta(microseconds=1)
    low_utc = low_local.astimezone(timezone.utc).replace(tzinfo=timezone.utc)
    high_utc = high_local.astimezone(timezone.utc).replace(tzinfo=timezone.utc)
    a, b = offset  # offset in [a,b]
    # true = clock - offset => [low - b, high - a]
    return (low_utc - timedelta(seconds=b), high_utc - timedelta(seconds=a))


def sensor_nearest10(ts: str) -> Interval:
    t = datetime.fromisoformat(ts).replace(tzinfo=timezone.utc)
    clock_lo, clock_hi = t - timedelta(seconds=5), t + timedelta(seconds=5)
    # offset [-5,5]
    return (clock_lo - timedelta(seconds=5), clock_hi - timedelta(seconds=-5))


def vendor_ny_floor(ts_local: str) -> Interval:
    local = datetime.fromisoformat(ts_local).replace(tzinfo=ZoneInfo("America/New_York"))
    low_local = local
    high_local = local + timedelta(minutes=1) - timedelta(microseconds=1)
    low_utc = low_local.astimezone(timezone.utc).replace(tzinfo=timezone.utc)
    high_utc = high_local.astimezone(timezone.utc).replace(tzinfo=timezone.utc)
    # offset [-180,180]
    return (low_utc - timedelta(seconds=180), high_utc - timedelta(seconds=-180))


def legacy_ber_fold(ts_local: str, fold: int) -> Interval:
    """fold=0 first (CEST UTC+2), fold=1 second (CET UTC+1) via zoneinfo fold."""
    naive = datetime.fromisoformat(ts_local)
    local = naive.replace(tzinfo=ZoneInfo("Europe/Berlin"), fold=fold)
    low_local = local
    # carefully build high with same fold
    high_naive = naive + timedelta(minutes=1) - timedelta(microseconds=1)
    high_local = high_naive.replace(tzinfo=ZoneInfo("Europe/Berlin"), fold=fold)
    low_utc = low_local.astimezone(timezone.utc).replace(tzinfo=timezone.utc)
    high_utc = high_local.astimezone(timezone.utc).replace(tzinfo=timezone.utc)
    # offset [-60,60]
    return (low_utc - timedelta(seconds=60), high_utc - timedelta(seconds=-60))


def mobile_lon(ts_local: str, entry_delay_on_occurrence: bool = True) -> Interval:
    local = datetime.fromisoformat(ts_local).replace(tzinfo=ZoneInfo("Europe/London"))
    # round nearest minute: clock in [ -30s, +30s ] about displayed minute
    center = local
    clock_lo = center - timedelta(seconds=30)
    clock_hi = center + timedelta(seconds=30)
    low_utc = clock_lo.astimezone(timezone.utc).replace(tzinfo=timezone.utc)
    high_utc = clock_hi.astimezone(timezone.utc).replace(tzinfo=timezone.utc)
    # offset [-300,300]
    occ_lo = low_utc - timedelta(seconds=300)
    occ_hi = high_utc - timedelta(seconds=-300)
    if entry_delay_on_occurrence:
        # late entry up to 5 min => occurrence up to 5 min earlier
        occ_lo = occ_lo - timedelta(seconds=300)
    return (occ_lo, occ_hi)
```

## 7. Governance Recommendation

1. **UTC storage canonical.** Persist all events as UTC instants with explicit source offset and `time_zone_at_capture`. Never store only local wall time.

2. **Raw timestamp retention.** Keep (a) original display string, (b) parsed clock reading before offset correction, (c) normalization audit trail. Rounding mode (`floor_minute`, `nearest_10s`, `nearest_minute`) must be metadata on every record.

3. **Source offset telemetry.** NTP/chrony offset histograms per host-hour (HUB, OPS-BER, SENSOR mandatory; VENDOR and MOBILE best-effort). When diagnostics are missing (T-409 pattern), mark evidence **low** and block automatic CERTAIN_VIOLATION enforcement.

4. **Resolution metadata.** Record quantum and method; apply resolution **before** clock correction, as in this analysis.

5. **Lifecycle semantics.** Distinguish `Alert_Sent` vs `Alert_Received`, `Investigation_Start` vs `Investigation_Complete`, and completion vs trigger for sensors. Require causal identifiers (trace/span or `precedes` edges) so order constraints are logged, not assumed.

6. **DST fold policy.** On fold days, devices must emit `fold`/`utc_offset` or pure UTC. Legacy local-only streams are non-enforceable without independent ordering (ingestion sequence is weak).

7. **Mobile/user entry.** Separate fields: `user_displayed_time`, `client_receipt_utc`, `entry_lag_bound`. Policy default: entry lag widens occurrence uncertainty unless a trusted device clock is present.

8. **External vendors.** Contractual SLA on timestamp quality (max offset, min resolution, UTC). Absent that, vendor times support monitoring only, not CERTAIN breach findings.

9. **Enforcement rule.**  
   - **CERTAIN_VIOLATION** with high-trust clocks  enforceable.  
   - **POSSIBLE_VIOLATION**  investigate, do not auto-penalize.  
   - **INDETERMINATE**  remediate telemetry, no finding.  
   Interval overlap is **insufficient** for punitive enforcement.

10. **Dual control planes.** Maintain hard SLA limits (legal) separate from temporal-profile  bands (operations). Publish  used for alerting (recommend =2 monitor, =1 coaching, never sole legal basis).

11. **Tolerance policy.** If operational  (2–5 min) is adopted, encode it explicitly in the SLA text; do not hide it inside clock fudge factors.

12. **Provenance.** Each normalized interval should carry `evidence_strength`, `assumptions[]` (causal, fold, entry-delay), and `eliminated_alternatives[]` for audit (especially T-405/T-407/T-404).
