```python
def mkey(marking):

    new = dict(marking)
    for a in trans.in_arcs: # (weight respected)
        left = new.get(a.source, 0) - a.weight
        if left <= 0:
            new.pop(a.source, None)
        else:
            new[a.source] = left
    for a in trans.out_arcs:
```

```python
def bounded_traces(net, im, fm, max_visible=12, max_analyze=3, max_steps=64,
                   analyze_label=ANALYZE):
    """EXHAUSTIVE over all complete runs whose visible projection satisfies the
    P3 bound.  Termination is guaranteed by (max_visible, max_analyze, max_steps);
    max_steps only guards against silent cycles and is reported if it truncates."""
    start = (mkey(im), tuple(), 0, 0) # marking, visible trace, #A, #steps
    queue = deque([start])
    seen = {start}
    complete, truncated = set(), False
    while queue:
        mk, trace, n_a, steps = queue.popleft()
        if mk == mkey(fm):
            complete.add(trace)                  # complete run ends at the final marking
            continue                             # (sound nets have no run beyond it)
        if steps >= max_steps:
            truncated = True
            continue
        marking = Marking(dict(mk))
        for tr in pm4py.get_enabled_transitions(net, marking):
            if tr.label is None:                 # silent step: no visible event
                new_trace, new_a = trace, n_a
            else:
                new_trace = trace + (tr.label,)
                new_a = n_a + (tr.label == analyze_label)
            if len(new_trace) > max_visible or new_a > max_analyze:
                continue                         # outside the P3 bound -> prune
            succ = (mkey(fire(marking, tr)), new_trace, new_a, steps + 1)
            if succ not in seen:
                seen.add(succ)
                queue.append(succ)
    return complete, truncated
```

```python
def tree_stats(tree, silent_aliases=SILENT_ALIASES):
    nodes = 0; depth = 0; vis_leaves = []; sil_leaves = 0; ops = Counter()
    def rec(node, d):
        nonlocal nodes, depth, sil_leaves
        nodes += 1        depth = max(depth, d)
        if node.children:
            ops[str(node.operator)] += 1
            for c in node.children:
                rec(c, d + 1)
        else:
            if node.label is None or str(node.label).strip().lower() in silent_aliases:
                sil_leaves += 1
            else:
                vis_leaves.append(node.label)
    rec(tree, 1) # depth counted in nodes on the root-to-leaf path
    label_counts = Counter(vis_leaves)
    dup = {k: v for k, v in label_counts.items() if v > 1}
    return dict(nodes=nodes, depth=depth, operators=dict(ops),
                visible_leaves=len(vis_leaves), silent_leaves=sil_leaves,
                distinct_visible_labels=len(label_counts), duplicate_labels=dup)
```

```python
    """NON-EXHAUSTIVE: uniform random choice over the enabled transitions at every
    marking (this *is* the declared probability model -- we invent no other
```

```python
    """Declared probability model (choose ONE and say so):
       (i) empirical frequencies of a uniform-random playout, or
```

# 1. Equivalence Notions

## 1.0 Conventions (observation boundary)

* A **run** of a model `M` is a complete derivation/firing sequence from the initial marking to the final marking. Only *complete* runs are compared (partial runs are not observations in any of the three views).
* A leaf whose label is `None` (or literally `tau`) is **silent**. Hiding `` means: delete those steps from the run. Everything below compares **visible traces** `hide_(run)`.
* A **trace** is a finite sequence of visible label occurrences, e.g. `Open Case · Analyze Revision · Check Revision · Close Case`.
* The two models use no data, no case IDs, no event identities.

### Label multiplicity convention (required statement)

| View | How duplicate labels are treated |
|---|---|
| _tr , ^P3 , _P1 | **Occurrence position.** A trace is a *sequence*: `A·C·A` has **two** `Analyze` occurrences and their multiplicity is observable. There is **no identity**: two occurrences of the same label are indistinguishable except for their position, so traces are compared as label sequences (permuting two identical labels yields the same trace). |
| _P2 | **Label only, with explicit cardinality collapse.** `Check Revision` occurrences are identified by label and their multiplicity is replaced by the Boolean `check occurred`. `Analyze Revision` keeps a *count* (positions forgotten). `Approve Revision` and `` are not observed at all. |

## 1.1 Visible trace equivalence after hiding ``

Let `L(M) = { hide_() |  complete run of M }  *` with ` = {Open Case, Analyze Revision, Check Revision, Approve Revision, Rework Case, Close Case}`.

> **A _tr B    L(A) = L(B)** (equality of sets of label sequences; occurrences counted positionally).

## 1.2 Bounded visible-language equivalence under P3

> **A ^P3 B    L^12,3(A) = L^12,3(B)**, where `L^12,3(M) = { t  L(M) : |t|  12  occ(t, 'Analyze Revision')  3 }`.

The length bound applies **after** hiding ``. This notion is decidable by finite exploration. It is **evidence only in the positive direction** (agreement does not lift to unbounded agreement — the loops make both languages infinite). In the negative direction a single witness *does* settle the unbounded question (language inequality is witnessed by one trace).

## 1.3 Business-relevant equivalence under P1

P1 is both a **constraint set** and an **observation boundary**.

*Compliance language* `C_P1` (the constraints as literally worded):
* (a) in every revision block (maximal part between two `Rework Case`, or between `Open Case`/`Rework Case` and `Rework Case`/`Close Case`), each `Analyze Revision` occurrence has its own `Check Revision` occurrence **in the same block** — the deadline being "before the next `Rework Case` or before `Close Case`";
* (b) every `Rework Case` lies strictly between two `Analyze Revision` occurrences (it separates two analysis attempts);
* (c) `Approve Revision` is optional: 0 or 1 occurrence per block.

*Observation map* `_P1(t)` for `t = Open Case · m · Close Case` (else ``):
1. split `m` at every `Rework Case` into blocks `B_1 … B_n` (this keeps the number **and positions** of `Rework Case`);
2. inside each block, replace every **adjacent** pair consisting of one `Analyze Revision` and one `Check Revision` (in either order) by the token `Analyze+Check`; unpaired occurrences are kept as-is;
3. output the block sequences of tokens over `{Analyze+Check, Analyze Revision, Check Revision, Approve Revision}`.

> **A _P1 B    (i) _P1(L(A)) = _P1(L(B))  and  (ii) L(A)  C_P1 and L(B)  C_P1.**

Clause (i) is exactly the P1 abstraction: the *order of the pair* is erased (P1 never mentions it), everything else — counts, approvals and their placement, rework structure — is retained ("the number and placement of approvals remains visible and potentially relevant"). Clause (ii) makes an incompliant model non-equivalent to a compliant one regardless of observations.

**Sensitivity note (a stricter reading of (a)).** "its own Check Revision" may be read as *the check must follow the analysis it audits*, not merely occur inside the same block. Under that reading Model A's `Check · Analyze` block interleavings are themselves violations and **only the simplified model of §8 is compliant**. This reading is reported as a sensitivity analysis in §3/§8.

## 1.4 Abstracted dashboard equivalence under P2

For `t = Open Case · m · Close Case` (else ``), with `A,C,App,R` abbreviating the labels:

> `_P2(t) = ( k = occ(t, Analyze), chk = [occ(t, Check)  1], rw = [occ(t, Rework)  1] )`

(`Approve Revision` and `` deleted first; positions of `Analyze`/`Check` forgotten; `Check` multiplicity collapsed to a Boolean.)

> **A _P2 B    _P2(L(A)) = _P2(L(B))**.

| **E4** | `Open · A · R · A · C · Close` | rejected | admitted | One `Check Revision` for **two** `Analyze Revision`: the first analysis has no check before the next `Rework Case` (P1(a) violated). In A `occ_Check = occ_Analyze = 2` is forced. | P1(a), P3 |
| **E5** | `Open · A · C · R · A · Close` | rejected | admitted | Second analysis attempt with **no** check at all before `Close Case`; A pairs every analysis with a check in the same block. | P1(a), P3 |
| **F1** (shared witness) | `Open · C · A · P · Close` | admitted | admitted | none — this is one of the **exactly four** shared traces (§4.1). | P2 (same dashboard record `k=1, chk=true, rw=false`) |
| **F2** (neither) | `Open · C · Close` | rejected | rejected | both loops force  1 `Analyze Revision` before `Close Case`; `R` without a following `A` (`Open·A·C·R·Close`) is likewise rejected by both. | sanity check |

### 4.1 Formal claims (unbounded, not based on the bounded enumeration)

**Claim 1 (count invariant).** For every complete visible trace `t`: `occ_Check(t) = occ_Analyze(t) = n  1` in Model A, while `occ_Check(t) = 1` and `occ_Analyze(t) = n  1` in Model B.
*Proof.* In A the loop's *do* child contains one `Analyze` and one `Check` as a **mandatory pair** and is executed exactly once per iteration (`*` semantics: `P (R P)*`); every complete run has `n  1` iterations. In B `Check Revision` is a single leaf of the parallel operator, which executes every child exactly once, while the loop child contributes one `Analyze` per iteration. 

**Claim 2 (exact intersection).**
`L(A)  L(B) = { Open·A·C·Close, Open·C·A·Close, Open·A·C·P·Close, Open·C·A·P·Close }` — **exactly 4 traces**.
*Proof.* By Claim 1 a shared trace has `occ_Check = 1`, hence (in A) `n = 1` and the middle part is one block `x  {AC, CA, AC·P, CA·P}`. Model B with `n = 1` produces the five shuffles of one `C` with `A` or `A·P`, namely `{AC, CA, AC·P, CA·P, A·P·C}` (insert `C` at any of `|l|+1` positions of `l  {A, A·P}`). Of these five, exactly `A·P·C` fails in A (A forces the check before the approval). Hence the intersection is A's four. 

**Corollary.** `L(A)  L(B)` (E1, E2) and `L(B)  L(A)` (E3, E4, E5). **Neither inclusion direction holds** — this is why witnesses are given in both directions.

**Derived bounded counts** (used as an assertion target by the code in §5). With `n  3` analyses and `|t|  12` (the longest bounded trace has 11 visible events, so only the analysis bound bites):
* `|L^12,3(A)| = _{n=1..3} 4 = 4 + 16 + 64 = **84**` (per block: 2 interleavings × 2 approval states);
* `|L^12,3(B)| = _{n=1..3} _{k=0..n} C(n,k)·(2n+k) = 5 + 20 + 60 = **85**` (a loop trace with `k` approvals has length `2n1+k`, giving `2n+k` insertion slots for the single check);
* `|L^12,3(A)  L^12,3(B)| = **4**`, `|A\B| = **80**`, `|B\A| = **81**`.

### 4.2 Effect of optional `Approve Revision` and of hidden ``

* `X('Approve Revision', tau)` is exactly *optional approval*: after hiding the silent branch, a block contributes **0 or 1 visible** approval. The `` branch contributes **no visible event**, so hiding it changes no visible multiplicity and no visible ordering — it only makes `Approve` optional.
* The approval is not the *cause* of the difference but it **amplifies B's placement freedom**: relative to the `A … P` pair of a block, the check has 3 legal positions in B (`C·A·P`, `A·C·P`, `A·P·C`) but only 2 in A. E3 exploits exactly this.
* The number of approvals (`0…n`) is **identical** in both models and therefore never decisive — only its position relative to the check is (P1(d)).
* The auto-approved () branch is what doubles every block variant: it is responsible for the `4` (A) and `2·(2n+k)` (B) factors in the derived counts. Removing optionality would shrink both languages but would leave the `occ_Check` invariant — hence the P1/P3 verdicts — unchanged.
* `` **must** be hidden *before* the P3 bound is applied: the bound counts visible events only. If the literal token `tau` were kept visible, both languages would gain `tau`-bearing traces and the bound would truncate them, but the invariant `occ_Check = 1` vs `occ_Check = n` would still separate the models (the verdicts are robust to this choice).
* Under P2 none of E1–E5 is decisive: their dashboard records (`k=2, chk=true, rw=true` for E1/E2/E4; `k=1, chk=true, rw=false` for E3) are produced by **both** models. That is precisely the content of the P2 verdict.

# 5. Bounded Comparison Code

Self-contained. **Part 1 is exhaustive** over the P3 bound (BFS over markings). **Part 2 is sampling only** and is labelled as such.

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
P3 bounded comparison of Model A and Model B.
  Part 1 : EXHAUSTIVE bounded exploration of the reachable markings (BFS).
  Part 2 : RANDOM playout / random walk  -- NOT exhaustive, sanity check only.
"""
import random
from collections import deque, Counter

import pm4py

try:                                   # module location differs across versions
    from pm4py.objects.petri_net.obj import Marking
except ImportError:                    # pragma: no cover
    from pm4py.objects.petri_net.petri_net import Marking


# --------------------------------------------------------------- 0) the models
A_STR = ("->( 'Open Case', *( ->( +('Analyze Revision', 'Check Revision'), "
         "X('Approve Revision', tau) ), 'Rework Case' ), 'Close Case' )")

B_STR = ("->( 'Open Case', +( 'Check Revision', *( ->( 'Analyze Revision', "
         "X('Approve Revision', tau) ), 'Rework Case' ) ), 'Close Case' )")

SILENT_ALIASES = {"tau", "", "eps", "epsilon", ""}
ANALYZE = "Analyze Revision"

MAX_VISIBLE = 12      # P3: at most 12 *visible* events (after hiding tau)
MAX_ANALYZE = 3       # P3: at most 3 'Analyze Revision'
MAX_STEPS   = 128     # safety valve against silent cycles ONLY


# ------------------------------------------------- 1) parse + normalise 'tau'
def parse_model(tree_str):
    """pm4py.parse_process_tree + declared normalisation:
       a leaf labelled 'tau' becomes a genuinely silent transition (label None)."""
    tree = pm4py.parse_process_tree(tree_str)

    def norm(node):
        if node.children:
            for child in node.children:
                norm(child)
        elif node.label is not None and str(node.label).strip().lower() in SILENT_ALIASES:
            node.label = None
    norm(tree)
    return tree


# ------------------------------------------------- 2) to an accepting Petri net
def to_net(tree):
    net, im, fm = pm4py.convert_to_petri_net(tree)
    return net, im, fm


# ------------------------------------------------------------- 3) soundness
def check_sound(net, im, fm):
    out = pm4py.check_soundness(net, im, fm, print_diagnostics=True)
    return out[0] if isinstance(out, tuple) else bool(out)


# ------------------------------------------------------ marking helpers
def mkey(marking):
    return frozenset(dict(marking).items())


def fire(marking, trans):
    """Unit/weighted firing, self contained (no converter internals)."""
    new = dict(marking)
    for arc in trans.in_arcs:
        left = new.get(arc.source, 0) - arc.weight
        if left <= 0:
            new.pop(arc.source, None)
        else:
            new[arc.source] = left
    for arc in trans.out_arcs:
        new[arc.target] = new.get(arc.target, 0) + arc.weight
    return Marking(new)


# --------------------------------------------------- 4) EXHAUSTIVE derivation
def bounded_traces_exhaustive(net, im, fm,
                              max_visible=MAX_VISIBLE,
                              max_analyze=MAX_ANALYZE,
                              max_steps=MAX_STEPS):
    """
    EXHAUSTIVE (not sampled) enumeration of all complete runs whose *visible*
    projection obeys the P3 bound.

    declared handling
      * silent transitions (label None) never extend the visible trace;
      * de-duplication on (marking, visible trace): a silent cycle returning to the
        same marking with the same visible trace cannot contribute new traces, so
        skipping it loses nothing (stuttering is quotient-ed out);
      * a trace is kept only when the FINAL MARKING is reached (complete runs);
      * visible-length bound and 'Analyze Revision' bound prune the search;
      * `max_steps` guards only against unbounded silent cycles; if it truncates a
        search, `truncated` is True and the result must be read as incomplete.
    """
    start = (mkey(im), tuple(), 0, 0)          # marking, trace, #Analyze, #steps
    queue = deque([start])
    seen = {(mkey(im), tuple())}
    complete, truncated = set(), False

    while queue:
        mk, trace, n_ana, steps = queue.popleft()
        if mk == mkey(fm):                     # final marking  => complete trace
            complete.add(trace)
            continue
        if steps >= max_steps:
            truncated = True
            continue
        marking = Marking(dict(mk))
        for trans in pm4py.get_enabled_transitions(net, marking):
            if trans.label is None:                         # tau step
                new_trace, new_ana = trace, n_ana
            else:
                new_trace = trace + (trans.label,)
                new_ana = n_ana + (1 if trans.label == ANALYZE else 0)
            if len(new_trace) > max_visible or new_ana > max_analyze:
                continue                                    # outside the P3 bound
            succ_mark = mkey(fire(marking, trans))
            key = (succ_mark, new_trace)
            if key in seen:
                continue
            seen.add(key)
            queue.append((succ_mark, new_trace, new_ana, steps + 1))
    return complete, truncated


# --------------------------------------------- 5) RANDOM walk (NOT exhaustive)
def sample_traces_random_walk(net, im, fm, n_runs=2000, max_steps=200, seed=0):
    """
    NON-EXHAUSTIVE.  Declared probability model: at every marking one of the
    enabled transitions is chosen uniformly at random (we invent no other
    transition probabilities).  Returned as {trace: count} = empirical language.
    """
    rng = random.Random(seed)
    out = Counter()
    for _ in range(n_runs):
        marking, trace = im, []
        for _ in range(max_steps):
            if mkey(marking) == mkey(fm):
                break
            enabled = sorted(pm4py.get_enabled_transitions(net, marking),
                             key=lambda t: (str(t.label), id(t)))
            if not enabled:
                break
            t = rng.choice(enabled)
            if t.label is not None:
                trace.append(t.label)
            marking = fire(marking, t)
        out[tuple(trace)] += 1
    return out


def fmt(trace):
    return " -> ".join(trace) if trace else "<empty>"


# ------------------------------------------------------------------- driver
if __name__ == "__main__":
    exhaustive, nets = {}, {}

    for name, src in (("A", A_STR), ("B", B_STR)):
        tree = parse_model(src)                       # (1)
        net, im, fm = to_net(tree)                    # (2)
        nets[name] = (tree, net, im, fm)
        print(f"--- Model {name} ---")
        print("   sound:", check_sound(net, im, fm))  # (3)
        traces, trunc = bounded_traces_exhaustive(net, im, fm)   # (4) EXHAUSTIVE
        exhaustive[name] = traces
        print(f"   EXHAUSTIVE P3-bounded complete traces: {len(traces)} "
              f"(truncated={trunc})")

    A, B = exhaustive["A"], exhaustive["B"]
    only_a, only_b, both = sorted(A - B), sorted(B - A), sorted(A & B)

    print("\n=== EXHAUSTIVE bounded comparison  "
          "(<=12 visible events, <=3 'Analyze Revision') ===")
    print(f"   |L(A)| = {len(A)}    |L(B)| = {len(B)}    |L(A)^L(B)| = {len(both)}")
    print("   hand-derived expectation:  84 / 85 / 4")
    assert (len(A), len(B), len(both)) == (84, 85, 4), "unexpected bounded counts!"

    print(f"\n   traces unique to Model A : {len(only_a)}")
    for t in only_a[:10]:
        print("      A:", fmt(t))
    print(f"\n   traces unique to Model B : {len(only_b)}")
    for t in only_b[:10]:
        print("      B:", fmt(t))
    print(f"\n   shared traces ({len(both)}):")
    for t in both:
        print("      =", fmt(t))

    # ------------------------- 6) NON-EXHAUSTIVE cross-checks (sampling only) --
    print("\n=== RANDOM playout / walk  (NOT exhaustive: sampling evidence) ===")
    for name in ("A", "B"):
        tree, net, im, fm = nets[name]
        # (a) pm4py's own simulator (its internal random choices, uncontrolled)
        try:
            log = pm4py.play_out(tree, parameters={"no_traces": 1000})
        except Exception:
            log = pm4py.play_out(tree)                 # version-dependent default
        played = set()
        for case in log:
            played.add(tuple(
                e["concept:name"] for e in case
                if str(e["concept:name"]).strip().lower() not in SILENT_ALIASES))
        # (b) our declared uniform-over-enabled-transitions walk
        walk = sample_traces_random_walk(net, im, fm, n_runs=2000, seed=0)
        print(f"   Model {name}: play_out produced {len(played)} distinct visible "
              f"traces; random walk produced {len(walk)}")
        print("      sampled-but-not-exhaustive (must be 0):",
              len((played | set(walk)) - exhaustive[name]))
        print("      exhaustive traces NOT hit by sampling (expected > 0):",
              len(exhaustive[name] - (played | set(walk))))
```

**Exhaustive vs. sampled — explicit statement.** `bounded_traces_exhaustive` explores *every* reachable marking and *every* enabled transition up to the P3 bound and is therefore exhaustive for `L^12,3`; `pm4py.play_out` and `sample_traces_random_walk` follow single random executions and are **not** exhaustive: rare traces (e.g. auto-approved blocks) may never be hit, the result depends on the sample size and on the (declared or simulator-internal) branching distribution, and no finite sample can establish language equality.

# 6. Stochastic and Footprint Comparison

## 6.1 `pm4py.discover_footprints(...)`

A footprint abstracts a model to its activity set, start/end activities and the **pairwise** relations `sequence`, `parallel`, `exclusive_choice`, `loop`, `self_loop`. It adds evidence of the following kind:

* **Equal footprints prove nothing.** Footprint relations are *sets of pairs*: they forget multiplicity, loop counts and every non-pairwise constraint. Example: `X('a', ->('a','a'))` (language `{a, aa}`) and `X('a', ->('a','a','a'))` (language `{a, aaa}`) induce the same relations — `activities={a}`, `start={a}`, `end={a}`, `sequence={(a,a)}`, `exclusive_choice={(a,a)}` — although their languages differ. Exactly this loss is fatal here, since the models differ by a **count** (`occ_Check`).
* **Different footprints are evidence, not proof.** If the footprint is computed from the behaviour (log/DFG variant) it is language-derived and a mismatch implies `¬(_tr)`. If it is computed from the tree syntax (structural variant), a mismatch may reflect modelling style rather than behaviour — treat it as evidence and confirm with traces (which §4 and §5 do).

```python
def footprints(obj, fallback=None):
    for candidate in (lambda: pm4py.discover_footprints(obj),
                      lambda: pm4py.discover_footprints(fallback)):
        try:
            return candidate()
        except Exception:
            continue
    return {}

tree_a, net_a, im_a, fm_a = nets["A"]
tree_b, net_b, im_b, fm_b = nets["B"]
fp_a = footprints(tree_a, fallback=net_a)
fp_b = footprints(tree_b, fallback=net_b)

for key in sorted(set(fp_a) | set(fp_b)):
    same = fp_a.get(key) == fp_b.get(key)
    print(f"{key:22s} {'EQUAL' if same else 'DIFFERENT'}")
    if not same:
        print("    A:", fp_a.get(key))
        print("    B:", fp_b.get(key))
```

Expected (qualitative — the printed output decides): the activity sets and start/end sets agree; `parallel` must differ, because A reports the pair (`Analyze`,`Check`) as parallel inside a loop while B reports `Check` as parallel with the loop activities (`Analyze`, `Approve`, `Rework`).

## 6.2 `pm4py.get_stochastic_language(...)` and `pm4py.compute_emd(...)`

A stochastic language assigns a probability to each trace; EMD is the minimal transport cost between two such distributions under a ground metric `d`. What this adds: a *distributional* statement (e.g. "how often is a revision auto-approved", "how much probability mass sits on compliant behaviour"), which is exactly what an executive/test-prioritisation view wants. What it needs: a **probability model**, which must be declared. Two are used here and both are declared:

1. **Declared artificial:** the uniform distribution over each model's bounded trace set (the models contain no probabilities).
2. **Declared empirical:** frequencies of a random walk/playout that chooses uniformly among the enabled transitions at every marking (§5 `sample_traces_random_walk`).

```python
def stochastic_language(counter):
    total = float(sum(counter.values()))
    return {tr: c / total for tr, c in counter.items()}

def tv_distance(p, q):
    """Total variation distance == EMD for the *discrete* ground metric d(x,y)=[x!=y]."""
    keys = set(p) | set(q)
    return 0.5 * sum(abs(p.get(k, 0.0) - q.get(k, 0.0)) for k in keys)

# (1) declared uniform distribution over the bounded trace sets
p_unif_A = stochastic_language(Counter({t: 1 for t in A}))
p_unif_B = stochastic_language(Counter({t: 1 for t in B}))
print("TV / EMD(discrete metric), uniform over L^12,3 :", tv_distance(p_unif_A, p_unif_B))

# (2) declared empirical distribution of the uniform-over-enabled random walk
walk_a = sample_traces_random_walk(net_a, im_a, fm_a, n_runs=5000, seed=1)
walk_b = sample_traces_random_walk(net_b, im_b, fm_b, n_runs=5000, seed=1)
print("TV of the empirical walk languages:", tv_distance(stochastic_language(walk_a),
                                                         stochastic_language(walk_b)))

# (3) pm4py's own stochastic language + EMD (argument type is version dependent:
#     an EventLog or an accepting/stochastic net; wrapped defensively)
try:
    lang_a = pm4py.get_stochastic_language(log_a)
    lang_b = pm4py.get_stochastic_language(log_b)
    print("pm4py EMD:", pm4py.compute_emd(lang_a, lang_b))
except Exception as exc:
    print("pm4py EMD unavailable/failed ->", exc, "-> falling back to TV above")
```

**Derived value (uniform over the bounded sets).** `_t min(p_A, p_B)` is non-zero only on the 4 shared traces (Claim 2) and equals `4·(1/85) = 4/85`; hence `TV = 1  4/85 = 81/85  0.9529` (= EMD under the discrete ground metric). The distributions are almost maximally far apart.

**Why equal footprints or a low EMD still would not establish trace equivalence.**
* Footprints forget multiplicity (§6.1): `occ_Check = 1` vs `occ_Check = n` is invisible to them in general.
* EMD is computed under a **ground metric**: if `d  1` (e.g. normalised edit distance), then `EMD  TV`, because mass may be *transported between distinct but similar traces*. `EMD = 0` then only means "the mass can be matched pairwise up to `d`", not "the supports coincide". With the discrete metric, `EMD = TV`, but a low TV still only says the *declared/sampled* distributions agree — rare traces carry almost no mass (a 1-in-`N` violation can be entirely invisible in `N` play-out runs).
* Both objects are computed on a **bounded or sampled support** (here `L^12,3` or the walk output), while both languages are infinite because of the loops. A low EMD on a bounded sample is therefore strictly weaker than ^P3, which is itself strictly weaker than _tr.
* Verdict support hierarchy used in this document: count invariant / witness traces (§4) > exhaustive bounded exploration (§5) > EMD and footprints (§6).

## 7.2
