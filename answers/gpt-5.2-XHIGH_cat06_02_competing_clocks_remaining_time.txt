## 3. Stage-by-stage decomposition
Below, each scenario uses the same structural decomposition. The key parallelism rule is:
\[
t_{\text{join}}=\max(t_{\text{chem usable}},\ t_{\text{micro usable}})
\]
because chemistry and microbiology run in parallel and QA cannot start until both are usable.

### S1 Smooth path (no rerun, no contamination, no QA rework) → Electronic Release
- **Chemistry (waiting + service, with calendar pauses)**:
  - **Waiting today (Fri 15:30–18:00)**: two analysts are busy with ~0.4–0.9 h and ~1.2–2.0 h remaining, and 1 urgent + 3 ordinary are waiting ahead.
    - If **risk-priority (45%)**: B-417 is likely taken soon after the urgent is assigned, so **start Fri ~16:45–17:15** is plausible.
    - If **FIFO (55%)**: B-417 is behind 4 waiting jobs; with long service times, it **often does not start Fri**.
  - **Service time**: triangular(1.5, 2.5, 4.5) h.
  - **Pause rule**: any unfinished chemistry work pauses at **Fri 18:00** and resumes **Mon 08:00**.
  - **Usable chemistry result time (smooth)**:
    - Priority-started Fri: finish **Mon ~09:00–12:00** (some work done Fri).
    - FIFO-not-started Fri: likely starts **Mon ~11:00–14:00**, finishes **Mon ~13:00–18:00** (rarely spills to Tue if started very late and long service).
- **Microbiology (incubation + staffing wait + readout)**:
  - Incubation technical-ready time \(R\): **Sun 12:00 – Mon 20:00**.
  - If \(R\le\) Mon 08:00: readout starts Mon 08:00, completes **Mon 08:30–09:30**.
  - If Mon 08:00\(\le R\le\)Mon 18:00: completes about **\(R + 0.5\)–\(1.5\) h**, i.e., **Mon ~09:00–19:30**.
  - If \(R\ge\) Mon 18:00: readout waits, completes **Tue 08:30–09:30** (this case is handled explicitly as S3; in S1 it is a low-weight tail).
- **Parallel join (max, not sum)**:
  - Typical: microbiology provides the limiting clock unless chemistry is FIFO-delayed into late Mon.
  - **Central join**: **Mon ~14:00–18:30** (max of “chem Mon afternoon” and “micro Mon morning→evening”).
- **QA (waiting + service, calendar-aware)**:
  - QA cannot start before join; on **Mon** there are **2 reviewers (08:00–20:00)**.
  - **Waiting** (queue uncertainty at join): typical **0–6 working hours**, sometimes **8–12** if bursts.
  - **Service**: typical **1–3.5 h**.
  - If join occurs late Mon and QA cannot finish by 20:00, remaining work resumes **Tue 08:00**.
- **Final step**:
  - **Electronic Release**: **0.25–0.75 h** after QA acceptance, continuous availability.

### S2 Chemistry borderline → rerun (priority) → Release
- **Chemistry (waiting + initial service)**: same as S1 until the initial result is produced (typically Mon).
- **Rerun trigger**:
  - Borderline rerun probability **0.10–0.20** (higher if temperature excursion confirmed).
  - Rerun service triangular(1.0, 1.8, 3.0) h, **priority**.
  - **Calendar constraint**: rerun cannot continue after **18:00**; if it starts too late Mon, it pauses and resumes **Tue 08:00**.
- **Approximate chemistry usable time under rerun**:
  - If initial completes Mon mid-day: rerun finishes **Mon ~16:00–18:00** or **Tue ~09:00–11:00**.
  - If initial completes Mon late afternoon: rerun more likely finishes **Tue morning**.
- **Microbiology**: often completed by Mon (as in S1), so the **join becomes chemistry-dominated**.
- **Parallel join**:
  - \(t_{\text{join}}=\max(t_{\text{micro}}, t_{\text{chem+rerun}})\approx t_{\text{chem+rerun}}\) in this scenario.
- **QA**:
  - Join commonly occurs **Tue**; QA then runs Tue 08:00–20:00.
  - Even without extra QA rework, the later join pushes the terminal event into **Tue evening–Wed**.
- **Final step**:
  - Release as in S1 once QA accepts.

### S3 Late microbiology readout (no contamination) → Release
- **Microbiology dominates due to calendar**:
  - If technical-ready time \(R\) is **Mon 18:00–20:00**, readout waits to **Tue 08:00**, completes **Tue 08:30–09:30**.
  - Chemistry is usually already usable by Mon (or early Tue worst case), so:
    - \(t_{\text{join}} \approx t_{\text{micro}} \in\) **Tue morning**.
- **QA**:
  - Starts no earlier than Tue morning; waiting typically 0–6 working hours plus 1–3.5 h service.
  - Terminal event typically **Tue afternoon/evening**, with tail into **Wed** if QA backlog is high.
- **Final step**:
  - Release 0.25–0.75 h after acceptance.

### S4 Micro contamination indication → confirmation incubation + QA handling → likely Reject
- **Microbiology (sequential clocks, not parallel within micro)**:
  - First usable readout attempt occurs when primary incubation is ready and a microbiologist is available (often **Mon morning/afternoon**).
  - With probability **0.05–0.12** (higher if temperature excursion confirmed), a **contamination indication** occurs.
  - Confirmation requires:
    - Additional continuous incubation **20–30 h**, then
    - Another microbiologist readout **0.5–1.5 h** within staffing hours.
  - Timing implications:
    - If first readout is **Mon 08:30–12:00**, confirmation readiness is **Tue 04:30–18:00**, second readout completes **Tue 08:30–16:00**.
    - If first readout is **Mon late afternoon**, confirmation may become ready **Tue evening**, pushing the second readout to **Wed morning**.
- **Chemistry**:
  - Often completes Mon; may rerun with increased probability if temperature excursion is confirmed, but micro confirmation typically remains the slower clock.
- **Parallel join**:
  - \(t_{\text{join}}=\max(t_{\text{chem}}, t_{\text{micro-confirmed}})\approx t_{\text{micro-confirmed}}\) for most contamination cases.
- **QA (and investigation probability)**:
  - Presence of contamination indication and/or confirmed temperature excursion moves Deviation Investigation probability into **0.30–0.55**.
  - If contamination is confirmed and treated as a **confirmed critical defect**, QA can move directly toward **Batch Rejected**; otherwise, investigation adds delay:
    - **Documentation-only** (60–80% of opened): **+8–20 working hours**
    - **Laboratory** (remaining): **+3–7 calendar days**
- **Terminal event**:
  - **Rejection recording**: 0.5–1.0 h after decision on confirmed critical defect (can occur outside business hours).
  - **Release** is still possible in a minority of cases (e.g., investigation resolves the signal), but timelines then resemble S5/S6.

### S5 QA Documentation Query and/or doc-only Deviation Investigation tail → Release
- **Join**: typically Mon afternoon or Tue morning (from S1–S3).
- **QA initial review**:
  - After starting, QA may raise a **Documentation Query** with probability **0.15–0.30**, adding **4–12 working hours** before QA can resume.
- **Deviation Investigation (doc-only)**:
  - If temperature excursion is confirmed (or rerun/contamination occurred), investigation probability increases to **0.30–0.55**; even if tests are normal, a smaller **0.04–0.10** chance exists.
  - If opened and doc-only (about 60–80% of opened): **+8–20 working hours**.
- **Calendar effect**:
  - These “working hour” additions translate to **~0.5–2.5 QA working days**, depending on when the pause begins (e.g., late Mon can force carry into Wed).
- **Final step**:
  - After QA acceptance, release in 0.25–0.75 h.

### S6 QA laboratory investigation tail → Release or Reject
- **Trigger**: most likely when contamination/rerun/temperature excursion exists (higher investigation probability), or a low-probability investigation even after normal results.
- **Added duration**: **3–7 calendar days**, which dominates all queue/service effects.
- **Outcome**:
  - Either eventual **Electronic Release** after closure, or **Batch Rejected** if a critical defect is confirmed.

## 4. Forecast summary

- **Central / P50-like remaining-time range**: **~75–95 h remaining**, i.e., **Mon 21 Sep 18:00 – Tue 22 Sep 14:00** (join in Mon afternoon/evening, moderate QA waiting, no major QA rework).
- **P80-like remaining-time range**: **~95–140 h remaining**, i.e., **Tue 22 Sep 14:00 – Thu 24 Sep 12:00** (includes meaningful mass of reruns and QA queries/doc-only investigations, plus QA queue variability).
- **P90-like / severe-tail range**: **~140–260+ h remaining**, i.e., **Thu 24 Sep 12:00 – Tue 29 Sep 12:00 (or into early Oct)** (driven by laboratory investigations and the correlated “bad cluster” when the temperature excursion is confirmed).
- **Most plausible terminal event(s)**:
  - **Electronic Release** is most likely overall (smooth path + mild QA rework).
  - **Batch Rejected** is a salient minority tail, primarily when **contamination is confirmed** (and/or a temperature excursion is confirmed and the investigation finds a critical defect).

## 5. Main uncertainty drivers
1. **Microbiology technical-ready time + staffing cutoffs** (mainly **calendar uncertainty** + **service-time uncertainty**) — determines whether the join happens early Mon vs late Mon/Tue.
2. **Chemistry queue discipline (FIFO vs risk-priority) and resulting start time** (mainly **queue uncertainty**) — shifts chemistry from Mon morning to Mon late (and can flip which branch dominates the max).
3. **Temperature excursion flag resolution** (mainly **observation uncertainty** + **dependence uncertainty**) — simultaneously raises rerun, contamination, and investigation probabilities, thickening the right tail.
4. **QA rework paths (Documentation Query; Deviation Investigation type)** (mainly **path uncertainty**) — converts an otherwise same-day QA completion into multi-day outcomes.
5. **QA queue at the future join time** (mainly **queue uncertainty**, secondarily **service-time uncertainty**) — overdispersion can add hours to a day even when the join is early.

## 6. Most forecast-changing next event
**Primary update trigger**: **Resolution of the temperature-excursion flag** (confirmed vs not confirmed).
- If **confirmed**: update upward the probabilities of chemistry rerun, contamination indication, and (critically) the **0.30–0.55 investigation** regime; shift the P80/P90 ranges later and increase the rejection likelihood.
- If **not confirmed**: downshift anomaly and investigation probabilities; compress the forecast toward the S1/S3 ranges (Mon night–Tue).

**Secondary trigger**: the **first microbiology readout outcome** once incubation is ready (clear vs contamination indication), which collapses uncertainty between “fast release after join” and “+20–30 h confirmation incubation + investigation/rejection tail.”
