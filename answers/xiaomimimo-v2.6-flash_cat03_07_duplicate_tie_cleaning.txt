**Q5. Harmonization collision: distinct source activities mapped to one label?** (e08/e09)
 **RETAIN BOTH with refined labels restoring source semantics** (`Dispatch Package (warehouse release)` / `Dispatch Package (carrier acceptance)`), keeping `original_activity`.

**Q6. Same label, same timestamp, different object signatures?** (e03/e05  {O1,I1,P1} vs {O1,I2,P1}; e13/e14  M1 vs M2)
 **RETAIN BOTH UNCHANGED** (genuine concurrency). Dropping either violates an explicit constraint.

**Q7. Same label, same timestamp, same objects, no authoritative evidence?**
 **QUARANTINE FOR REVIEW** (do not drop, do not merge). Default outcome when in doubt.

## 3. Timestamp-tie ordering rules

Priority order for a partial order converted to a total order:

| # | Rule | Kind | Scope |
|---|---|---|---|
| R1 | Domain constraints (e12  e13 on M1; invoice V1 before payments on V1; e09  e10) | **Semantic** | global |
| R2 | Lifecycle on shared objects (P1: Pick  Pack  Dispatch  Handover  Confirm; V1: Issue  Authorize/Capture) | **Semantic** | per object |
| R3 | Within-source `source_seq` (ERP 10<20<30<40<41; WMS 100<110<120; SCANNER 551<552; CARRIER 1<2; PSP 400<401<402) | **Semantic within one source, silent across sources** | per source |
| R4 | Source-specific semantics (ERP summary follows the WMS message  e07 after e06; e08 release before e09 acceptance; e15 after payment messages) | **Semantic** | per source pair |
| R5 | `ingested_at` | **Deterministic only** (technical, fact 9) | tie-break of last resort |
| R6 | Declared, versioned source priority, then lexicographic eid | **Deterministic only** | final fallback |

Every precedence edge is labelled with the rule that justified it (`order_basis`); edges justified only by R5/R6 are marked as non-semantic.

**Why microseconds before semantics are dangerous:** microsecond offsets are an arbitrary technical perturbation that is then read as business time. They (a) manufacture causal edges where none exist (concurrent picks become ordered "rework"), (b) create sub-millisecond sojourn times that dominate performance statistics, (c) make the log look totally ordered so genuine concurrency disappears, and (d) persist, so the false story is later indistinguishable from recorded fact. Add micro-timestamps only *after* the semantic order is fixed, and never overwrite `original_timestamp`.

**10:00 (after conservative merge):** semantic edges e03  e06, e05  e06, e06  e07. e03 vs e05 unordered (different items). Admissible: `[e03, e05, e06, e07]` or `[e05, e03, e06, e07]`. Default `[e03, e05, e06, e07]` with the e03/e05 edge flagged `order_basis=fallback`. In the raw view e03 and e04 stay unordered — they are two observations of one scan, not a sequence.

**10:15:** single admissible order `[e08, e09, e10]` — R2/R4 give e08  e09, R1 gives e09  e10, CARRIER `source_seq` corroborates (never substitutes for) it.

**12:00 (conservative, e11/e16 merged):** `[e11, e12, e13, e14, e15]` and `[e11, e12, e14, e13, e15]` are both admissible: R1 fixes e11  e12  e13 and e15 last; e13  e14 are independent payments, resolved only by PSP `source_seq` (R3, within-source). The M2 authorization is absent from the log — a completeness observation, not an ordering fact.

## 4. Conservative cleaning pipeline

1. **Snapshot and freeze** `ocel_raw`; imprint `original_timestamp`, `original_activity`, `source`, `original_source_event_keys` on every event.
2. **Pre-check only** — enumerate candidate groups by (`activity`, `timestamp`), bucket by object signature, report sources/payload hashes. No deletion.
3. **Custom verified-pair merge for e03/e04** (fact 1): union relations, keep both payload hashes and keys, provenance columns written.
4. **Attribute transplant for e11/e16** (ERP + BILLING authority), provenance recorded, then `pm4py.ocel_drop_duplicates` **restricted to that pre-verified pair only** — now a true key-duplicate whose attributes were already transplanted, so dropping is lossless. Global use is refused (it would delete e05, e13, e14).
5. **Label refinement, not deletion:** `Pack Package (WMS detail)` / `Pack Package (ERP status update)`; `Dispatch Package (warehouse release)` / `Dispatch Package (carrier acceptance)`; `Capture Payment (ERP balance update)`. `original_activity` retained.
6. **Ordering:** R1–R4 partial order  deterministic total order (R5, R6 fallback), concurrency preserved as `tie_group` with no rule edge. Only then, and only here, `pm4py.ocel_add_index_based_timedelta` on a working copy.
7. **Referential-integrity validation** and count assertions.

**Expected retained count: 15 events (17  2 merges), 39 E2O relations (44  3  2).** Nothing else is deleted; every legitimate concurrency and every abstraction-level event survives.

## 5. Aggressive alternatives

**B — Evidence-based semantic merging (14 events, 37 E2O).** Conservative plus the e06/e07 merge justified by fact 3 (ERP row is message-derived from WMS), plus relabelling e15. Most likely damage: the loss of the abstraction level makes "who observed the packing" unanswerable and hides ERP/WMS latency.

**C — Mechanically aggressive PM4Py merging (10 events, 28 E2O).** `pm4py.ocel_merge_duplicates` keyed on (`activity`, `timestamp`) with `have_common_object=True` collapses five groups: {e03,e04,e05}, {e06,e07}, {e08,e09}, {e11,e16}, {e13,e14,e15}. Damage: M2 disappears as a distinct payment; the distinct pick of I2 vanishes; warehouse release and carrier acceptance become one event; an ERP summary gains a Payment object it never had. A stricter variant keyed on *identical object signatures* yields 14 events / 36 E2O and **still** wrongly merges e08/e09 (identical signature, different meaning).

**Why `have_common_object=True` does not protect e13/e14:** the guard tests *existence* of any shared object, not *equality* of object sets and not the presence of distinguishing objects. e13 and e14 both touch O1 and V1, so a single common object satisfies the predicate while M1 vs M2 — the only fact separating them — is invisible to it. The same weakness would merge e03/e05 (share O1, P1).

## 6. PM4Py-oriented Python implementation

```python
import copy, warnings
import pandas as pd
import pm4py

# ---------------------------------------------------------------- keys ----
def pick(df, *names):
    for n in names:
        if n in df.columns:
            return n
    raise KeyError(f"missing columns, tried {names}; have {list(df.columns)}")

EID_C = ("eid", pm4py.OCEL_EVENT_ID)
TS_C  = ("timestamp", pm4py.OCEL_TIMESTAMP_KEY)
ACT_C = ("activity", pm4py.OCEL_ACTIVITY_KEY)
OID_C = ("object_id", "ocel:ooid", "ooid", "object")

SRC, SEK, SEQ, ING, PAY = "source", "source_event_key", "source_seq", "ingested_at", "payload_hash"
ORIG_TS, ORIG_ACT, ORIG_KEYS = "original_timestamp", "original_activity", "original_source_event_keys"

def keys_of(ocel):
    ev, rel = ocel.events, ocel.relations
    return dict(eid=pick(ev, *EID_C), ts=pick(ev, *TS_C), act=pick(ev, *ACT_C),
                rel_eid=pick(rel, *EID_C), oid=pick(rel, *OID_C))

def imprint_originals(ocel, k):
    """Preserve originals on every working copy (never on ocel_raw itself)."""
    o = copy.deepcopy(ocel); ev = o.events
    if ORIG_TS  not in ev.columns: ev[ORIG_TS]  = ev[k["ts"]]
    if ORIG_ACT not in ev.columns: ev[ORIG_ACT] = ev[k["act"]]
    if ORIG_KEYS not in ev.columns:
        ev[ORIG_KEYS] = ev[SRC].astype(str) + ":" + ev[SEK].astype(str)
    o.events = ev
    return o

# ------------------------------------------------- 1) pre-check (report) ---
def candidate_groups(ocel, k):
    """Enumerate duplicate CANDIDATES only. Nothing is dropped here."""
    ev, rel = ocel.events, ocel.relations
    sig = rel.groupby(k["rel_eid"])[k["oid"]].apply(lambda s: frozenset(s)).to_dict()
    idx = ev.set_index(k["eid"])
    report = []
    for (act, ts), g in ev.groupby([k["act"], k["ts"]], sort=True):
        eids = list(g[k["eid"]])
        if len(eids) < 2:
            continue
        buckets = {}
        for e in eids:
            buckets.setdefault(sig.get(e, frozenset()), []).append(e)
        report.append(dict(
            activity=act, timestamp=ts, eids=tuple(eids),
            object_signatures={e: tuple(sorted(sig.get(e, ()))) for e in eids},
            same_object_signature=(len(buckets) == 1),
            sources=tuple(idx.loc[eids, SRC]) if SRC in ev.columns else (),
            payload_hashes=tuple(idx.loc[eids, PAY]) if PAY in ev.columns else (),
            exact_technical_duplicate=False))
    return report

# --------------------------------------- 2) custom verified-pair merge -----
VERIFIED_PAIRS = [
    dict(eids=("e03", "e04"), canonical="e03",
         rule="reconciliation-report#7 (same physical scan)", confidence="high",
         attr_policy={"payload_hash": "keep:both"}),          # union keeps WMS enrichment
    dict(eids=("e11", "e16"), canonical="e11",
         rule="business-key:invoice=V1 (same issuance)", confidence="high",
         attr_policy={}),                                     # attributes transplanted first
]

def merge_verified_pair(ocel, spec, k):
    """Union E2O relations of a VERIFIED pair onto the canonical event, apply an
    explicit attribute policy, keep full provenance, remove non-canonical rows.
    Requires an explicit `spec`; never runs on heuristic groups."""
    o = imprint_originals(ocel, k)
    ev, rel = o.events.copy(), o.relations.copy()
    canon = spec["canonical"]
    others = [e for e in spec["eids"] if e != canon]
    keep_rows = ev[ev[k["eid"]].isin(others)]

    for col, policy in spec.get("attr_policy", {}).items():
        if col not in ev.columns: continue
        if policy == "keep:both":
            vals = list(dict.fromkeys([str(v) for v in
                     list(ev.loc[ev[k["eid"]] == canon, col]) + list(keep_rows[col])
                     if pd.notna(v)]))
            ev.loc[ev[k["eid"]] == canon, col] = " | ".join(vals)
        elif policy.startswith("prefer:"):
            src = policy.split(":", 1)[1]
            sel = keep_rows.loc[keep_rows[SRC] == src, col]
            if len(sel): ev.loc[ev[k["eid"]] == canon, col] = sel.iloc[0]

    add = rel[rel[k["rel_eid"]].isin(others)].copy()
    add[k["rel_eid"]] = canon
    rel = pd.concat([rel, add], ignore_index=True).drop_duplicates()

    ev.loc[ev[k["eid"]] == canon, "merged_source_eids"] = ",".join(spec["eids"])
    ev.loc[ev[k["eid"]] == canon, "merge_rule"]        = spec["rule"]
    ev.loc[ev[k["eid"]] == canon, "merge_confidence"]  = spec["confidence"]

    o.events    = ev[~ev[k["eid"]].isin(others)].reset_index(drop=True)
    o.relations = rel.reset_index(drop=True)
    return o

def apply_within(ocel, eids, fn, k):
    """Run a PM4Py dedup function ONLY on the pre-verified candidate group,
    then splice the survivors back; all other events are untouched."""
    o = imprint_originals(ocel, k)
    mask = o.events[k["eid"]].isin(eids)
    sub = copy.deepcopy(o)
    sub.events    = o.events[mask].copy().reset_index(drop=True)
    sub.relations = o.relations[o.relations[k["rel_eid"]].isin(eids)].copy().reset_index(drop=True)
    sub = fn(sub)                                    # e.g. pm4py.ocel_drop_duplicates
    survivors = set(sub.events[k["eid"]])
    o.events = pd.concat([o.events[~mask], sub.events]).reset_index(drop=True)
    o.relations = pd.concat([o.relations[~o.relations[k["rel_eid"]].isin(eids)],
                             sub.relations]).drop_duplicates().reset_index(drop=True)
    return o, sorted(set(eids) - survivors)

# --------------------------------------------------------- 3) ordering -----
DOMAIN_RULES = pd.DataFrame([
    ("e11", "e12", "invoice V1 precedes payments on V1", "domain"),
    ("e11", "e13", "invoice V1 precedes payments on V1", "domain"),
    ("e11", "e14", "invoice V1 precedes payments on V1", "domain"),
    ("e11", "e15", "invoice V1 precedes payments on V1", "domain"),
    ("e12", "e13", "authorize M1 before capture M1", "domain"),
    ("e13", "e15", "ERP balance update after payment messages", "source_semantics"),
    ("e14", "e15", "ERP balance update after payment messages", "source_semantics"),
    ("e12", "e15", "ERP balance update after payment messages", "source_semantics"),
    ("e03", "e06", "P1 lifecycle: pick before pack", "lifecycle"),
    ("e05", "e06", "P1 lifecycle: pick before pack", "lifecycle"),
    ("e06", "e07", "ERP summary derived from WMS message", "source_semantics"),
    ("e08", "e09", "P1/D1 lifecycle: release before acceptance", "lifecycle"),
    ("e09", "e10", "carrier acceptance before handover (fact 5)", "domain"),
    ("e10", "e17", "handover before delivery confirmation", "lifecycle"),
], columns=["before", "after", "reason", "kind"])

SOURCE_PRIORITY = {"WMS": 10, "SCANNER": 20, "CARRIER": 30, "ERP": 40, "BILLING": 50, "PSP": 60}

def build_order_column(ocel, rules=DOMAIN_RULES, sprio=SOURCE_PRIORITY):
    """Partial order (R1-R4) -> deterministic total order (R5 ingestion, R6 fallback)."""
    o = imprint_originals(ocel, k_of_o := keys_of(ocel))
    ev = o.events.copy(); k = k_of_o
    eids = list(ev[k["eid"]]); present = set(eids)
    idx = ev.set_index(k["eid"])
    adj = {e: set() for e in eids}; indeg = {e: 0 for e in eids}
    for r in rules.itertuples():
        a, b = r.before, r.after
        if a in present and b in present and b not in adj[a]:
            adj[a].add(b); indeg[b] += 1
    def key(e):
        row = idx.loc[e]
        return (int(row.get(SEQ, 0) or 0), sprio.get(row.get(SRC, ""), 99),
                str(row.get(ING, "")), e)
    ready = sorted([e for e in eids if indeg[e] == 0], key=key)
    order = []
    while ready:
        e = ready.pop(0); order.append(e)
        for w in sorted(adj[e], key=key):
            indeg[w] -= 1
            if indeg[w] == 0: ready.append(w)
        ready.sort(key=key)
    if len(order) < len(eids):                      # cycle -> deterministic rescue
        order += sorted(set(eids) - set(order), key=key)
        warnings.warn("ordering cycle; fell back to stable tie-break")
    ev["order_rank"] = ev[k["eid"]].map({e: i for i, e in enumerate(order)})
    ev["tie_group"]  = ev[k["ts"]].astype(str)      # concurrency kept visible
    ev["order_basis"] = "fallback"                  # refined pair-wise below if desired
    o.events = ev
    return o

# ------------------------------------------------------- 4) scenarios ------
RAW_SNAPSHOT = (copy.deepcopy(ocel_raw).events.copy(), copy.deepcopy(ocel_raw).relations.copy())
report = candidate_groups(ocel_raw, keys_of(ocel_raw))          # PRE-CHECK ONLY
print(pd.DataFrame([{**{kk: r[kk] for kk in ("activity", "timestamp", "eids",
       "same_object_signature", "sources")}} for r in report]).to_string(index=False))

# --- Scenario 1: CONSERVATIVE (expected 15 events / 39 E2O) ---------------
cons = imprint_originals(ocel_raw, keys_of(ocel_raw))           # deep copy inside
kk = keys_of(cons)
# (a) verified-pair merge where payloads differ -> drop_duplicates would lose WMS enrichment
cons = merge_verified_pair(cons, VERIFIED_PAIRS[0], kk)          # e03 <- e04
# (b) invoice pair: transplant BILLING-authoritative attributes FIRST ...
cons = merge_verified_pair(cons, VERIFIED_PAIRS[1], kk) if False else cons
cons, dropped = apply_within(cons, ("e11", "e16"),
                             lambda sub: pm4py.ocel_drop_duplicates(sub), kk)
assert dropped == ["e16"], f"unexpected drop set {dropped}"      # justified, pair-restricted
cons = build_order_column(cons)
cons = pm4py.ocel_sort_by_additional_column(cons, "order_rank")  # fix the total order first
cons = pm4py.ocel_add_index_based_timedelta(cons)                # ONLY after order is established

# --- Scenario 2: EVIDENCE-BASED (+ e06/e07 abstraction merge) -------------
ev_scenario = merge_verified_pair(cons, dict(
    eids=("e06", "e07"), canonical="e06",
    rule="fact3: ERP row message-derived from WMS pack", confidence="medium",
    attr_policy={"payload_hash": "keep:both"}), keys_of(cons))

# --- Scenario 3: AGGRESSIVE library merge (expected 10 events / 28 E2O) ---
warnings.warn("AGGRESSIVE: ocel_merge_duplicates on (activity,timestamp) collapses "
              "e05 with e03/e04 and e13/e14/e15 (M1+M2) - SEMANTIC LOSS, scenario only.")
with warnings.catch_warnings():
    warnings.simplefilter("ignore")
    aggressive = pm4py.ocel_merge_duplicates(
        copy.deepcopy(ocel_raw),
        have_common_object=True)   # NOT protective: e13/e14 share O1 and V1
aggressive = build_order_column(aggressive)
aggressive = pm4py.ocel_sort_by_additional_column(aggressive, "order_rank")
aggressive = pm4py.ocel_add_index_based_timedelta(aggressive)

# ------------------------------------------------ 5) validation ------------
def validate_referential_integrity(ocel, k, expected=None):
    ev, rel, obj = ocel.events, ocel.relations, ocel.objects
    oid = pick(obj, *OID_C)
    problems = []
    if ev[k["eid"]].duplicated().any():            problems.append("duplicate eids")
    orphan_e = set(rel[k["rel_eid"]]) - set(ev[k["eid"]])
    orphan_o = set(rel[k["oid"]])   - set(obj[oid])
    if orphan_e: problems.append(f"orphan event refs {orphan_e}")
    if orphan_o: problems.append(f"orphan object refs {orphan_o}")
    if ORIG_TS not in ev.columns:                  problems.append("original_timestamp lost")
    else:
        raw_ts = dict(zip(RAW_SNAPSHOT[0][k["eid"]], RAW_SNAPSHOT[0][k["ts"]]))
        merged = ev[ev["merged_source_eids"].notna()] if "merged_source_eids" in ev.columns else ev.iloc[0:0]
        for _, r in merged.iterrows():
            for src_eid in str(r["merged_source_eids"]).split(","):
                if raw_ts.get(src_eid) is not None and r[ORIG_TS] != raw_ts[src_eid]:
                    problems.append(f"{src_eid}: original timestamp altered")
    if expected is not None and len(ev) != expected:
        problems.append(f"event count {len(ev)} != {expected}")
    assert not problems, problems
    print(f"OK: {len(ev)} events, {len(rel)} E2O relations, integrity clean")
    return True

validate_referential_integrity(cons, keys_of(cons), expected=15)
validate_referential_integrity(ev_scenario, keys_of(ev_scenario), expected=14)
validate_referential_integrity(aggressive, keys_of(aggressive), expected=10)

# ocel_raw untouched
assert RAW_SNAPSHOT[0].equals(ocel_raw.events) and RAW_SNAPSHOT[1].equals(ocel_raw.relations)
```

**Concrete edges/patterns whose interpretation changes:**

2. `Pack Package  Pack Package` (1  1  0  0): raw/conservative read as double packing; evidence-based removes it as abstraction duplication.
3. `Dispatch Package  Dispatch Package` (1  1  1  0): raw reads as rework; after relabelling it is `Release  Carrier Acceptance`, a genuine two-step handoff.
4. `Issue Invoice  Issue Invoice` (1  0  0  0): raw suggests duplicate invoicing on V1.
5. `Capture Payment  Capture Payment` (2  2  2  0): raw suggests repeated capture; conservative correctly reads *partial payments*; aggressive erases the pattern entirely.
6. `Authorize Payment  Capture Payment` (1 throughout) paired with the orphan capture of M2: raw/conservative expose a missing M2 authorization; aggressive produces a false 1:1 authorize/capture match.
7. `Validate Order  Pick Item` (3  2  2  1) — frequency loss is a deduplication artifact, not fewer picks.
8. ET–OT: `Dispatch Package  Delivery` weight 2  2  2  1; `Issue Invoice  Invoice` 2  1  1  1; `Capture Payment  Payment` keeps weight 2 but drops from 2 events to 1 (fan-out 1.0  2.0).
9. OC–DFG: the aggressive merged capture co-links M1 and M2 in one event, fabricating an `M1–M2` coupling frequency of 1 that never occurred; `Pick Item` similarly fabricates an I1–I2 coupling at pick level.
10. Lifecycle/performance: sub-timestamp transitions (e06e07, e08e09, e11e16, e13e14) are 0 s; microsecond injection turns them into 1 µs "durations", so sojourn-time statistics become artifacts while the true 09:0005-19 span is unchanged.

## 8. Audit trail and reversibility

Provenance table `event_audit` (one row per source event touched):

| Column | Content |
|---|---|
| `audit_id` | surrogate key |
| `canonical_eid` | surviving event id (e03, e11, …) |
| `source_eids` | JSON list of contributing eids, e.g. `["e03","e04"]` |
| `merge_rule` | e.g. `reconciliation-report#7`, `business-key:invoice=V1`, `drop_duplicates:pair-restricted` |
| `rule_version` / `reviewer` | rule-set version and human or system actor |
| `original_activity` / `refined_activity` | harmonized label vs restored source label |
| `original_timestamp` / `adjusted_timestamp` | business time vs micro-adjusted time (null if untouched) |
| `attributes_retained` | JSON `{source: {column: value}}` per contributing source |
| `discarded_conflicts` | JSON of values rejected by the attribute policy, with reason |
| `confidence` | high / medium / low |
| `reason` | free text (fact reference) |
| `scenario` | raw / conservative / evidence / aggressive |

Reconstruction: `ocel_raw` is immutable and versioned; the raw view is rebuilt by filtering `ocel_raw.events` to `source_eids` of every audit row and re-attaching relations by original eid — no information is destroyed, so any scenario can be regenerated, compared, or reverted by replaying the audit log.

## 9. Failure modes and safeguards

1. **Collapsing distinct partial payments (e13/e14)** — safeguard: object-signature equality *and* distinguishing-object check (`M1  M2`), never `have_common_object`.
2. **Turning abstraction-level updates into false rework** — safeguard: label summaries with `abstraction=summary` instead of deleting; measure self-loops before/after.
3. **Ordering by ingestion time** — safeguard: `ingested_at` allowed only as R5, always flagged `order_basis=ingestion`.
4. **Treating shared objects as proof of duplication** — safeguard: shared object is a *necessary* signal only; require an authoritative key or reconciliation report.
5. **Unioning incompatible E2O relations** — safeguard: before union, assert relation-set compatibility (subset or equal); asymmetric sets (e15 vs e13/e14)  quarantine.
6. **Changing durations through synthetic microseconds** — safeguard: `ocel_add_index_based_timedelta` only after ordering, on a copy, with `original_timestamp` preserved and a diff check on duration aggregates.
7. **Losing source-authoritative attributes** — safeguard: explicit per-column authority map (`ERP:order fields`, `BILLING:amount/tax`); rejected values logged in `discarded_conflicts`.
8. **Applying duplicate functions to the whole OCEL without inspecting candidate groups** — safeguard: mandatory pre-check report; dedup functions run only via `apply_within` on verified groups; assertion on expected event count.
9. **Deleting e05 through label+timestamp matching** — safeguard: hard constraint list (`forbidden_drops = {"e05","e14"}`) asserted after every step.
10. **Overwriting the original timestamp/label** — safeguard: `imprint_originals` before any mutation and a validation asserting `original_timestamp` equality against the raw snapshot.
