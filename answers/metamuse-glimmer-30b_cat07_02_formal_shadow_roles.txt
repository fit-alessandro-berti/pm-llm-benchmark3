# 5. PM4Py role-discovery and similarity code

```python
import pandas as pd
import pm4py

# load and format
df = pd.read_parquet('eventlog.parquet')
df = pm4py.format_dataframe(df,
    case_id='case:concept:name',
    activity_key='concept:name',
    timestamp_key='time:timestamp',
    org_resource_key='org:resource'
)

# optional enrichment
df['case_complexity'] = df['case_complexity']
df['temporary_substitution'] = df['temporary_substitution']

# organizational roles from activity profiles
roles = pm4py.discover_organizational_roles(df,
    parameters={'activities_key':'concept:name',
                'resources_key':'org:resource'}
)

# activity based resource similarity
sim = pm4py.discover_activity_based_resource_similarity(df,
    parameters={'activities_key':'concept:name',
                'resources_key':'org:resource',
                'similarity_measure':'cosine'}
)

# networks for bridging / handover
handover = pm4py.discover_handover_of_work_network(df)
working_together = pm4py.discover_working_together_network(df)
subcontracting = pm4py.discover_subcontracting_network(df)

# join with case complexity and substitution indicators
resource_stats = df.groupby('org:resource').agg(
    activity_counts=('concept:name','count'),
    median_complexity=('case_complexity','median')
).reset_index()

# avoid over-interpretation: frequency only
# normalize activity vectors before clustering and weight by complexity
from sklearn.preprocessing import normalize
activity_matrix = df.pivot_table(index='org:resource',
                                 columns='concept:name',
                                 aggfunc='size',
                                 fill_value=0)
activity_norm = normalize(activity_matrix, norm='l1')

# role discovery should be combined with complexity and formal attributes
# e.g., filter by case_complexity and temporary_substitution before labeling
permanent = df[df['temporary_substitution']==False]
```

The workflow loads the log, discovers roles and similarity, inspects handover/working-together networks for brokerage, and joins mined profiles with case_complexity and substitution flags to avoid equating frequency with authority.
