# 1. Data audit and estimands

**Queueing Quantities and Units**
*   **Arrivals ($\lambda$):** Daily count of cases entering the system during opening hours (07:00–19:00). Unit: cases/day. Effective arrival rate per hour $\approx$ Arrivals/12.
*   **Completed ($\mu$):** Daily count of cases leaving the system. Unit: cases/day.
*   **WIP ($L$):** `mean_wip` represents the average number of cases in the system (queue + service) during opening hours, derived from 15-minute snapshots. Unit: cases.
*   **Service Time ($S$):** `median_service_min` and `p90_service_min` represent active handling time only. Unit: minutes.
*   **Capacity ($C$):** `staff_fte` represents concurrent full-time-equivalent capacity. Unit: FTE (assumed 1 FTE = 1 case/hour service rate for approximation, though service time varies).
*   **Flow Time ($W$):** Time from arrival to completion. Not explicitly provided; must be derived via Little's Law ($L = \lambda_{effective} W$).

**Limitations of Aggregates**
*   **Opening Hours:** All rates apply only to 12 hours/day (07:00–19:00).
*   **Backlog:** `completed` cases may have arrived previous days. `arrivals` may not be fully processed same day. Net daily change in system inventory is $\text{Arrivals} - \text{Completed} + \text{Backlog}_{start} - \text{Backlog}_{end}$.
*   **Service Distribution:** Medians/P90s describe shape, not mean. Heavy tails (P90 > Median) suggest variability.
*   **WIP Definition:** `mean_wip` is an average over 15-minute intervals, smoothing instantaneous spikes.

**Five Threats to Naive Inference**
1.  **Non-Stationarity:** Case mix (`complex_pct`), staffing (`staff_fte`), and service times shift significantly between 04-14 and 04-29. Pooling assumes constant parameters.
2.  **Transient States:** The 04-15 outage creates a recovery spike on 04-16 (Completed 129 vs Arrivals 112). This is a transient depletion event, not steady state.
3.  **Aggregation Bias:** Daily sums hide hourly burstiness (e.g., `peak_08_10_pct` varies from 17% to 50%).
4.  **Carry-Over Backlog:** Without `backlog_start` and `backlog_end`, we cannot distinguish between new arrivals and clearing old inventory.
5.  **Simpson’s Paradox:** A pooled average of `complex_pct` (~38%) obscures that high complexity correlates with high WIP (04-20 to 04-24) and staffing intervention (04-29).

df_hourly = pd.DataFrame.from_dict(hourly_vectors, orient='index', columns=['arrivals_by_hour'])
df_hourly.index = pd.to_datetime(df_hourly.index)

# 3. Calculate Pooled and Candidate-Regime Summaries
# Pooled
pooled_arr = df['arrivals'].mean()
pooled_comp = df['completed'].mean()
pooled_wip = df['mean_wip'].mean()
pooled_fte = df['staff_fte'].mean()
pooled_complex = df['complex_pct'].mean()

# Regime: High Complexity (04-20 to 04-24)
high_comp_mask = (df['date'] >= '2026-04-20') & (df['date'] <= '2026-04-24')
high_comp_arr = df.loc[high_comp_mask, 'arrivals'].mean()
high_comp_wip = df.loc[high_comp_mask, 'mean_wip'].mean()

# Regime: Intervention (04-29 to 05-03)
int_mask = (df['date'] >= '2026-04-29') & (df['date'] <= '2026-05-03')
int_arr = df.loc[int_mask, 'arrivals'].mean()
int_wip = df.loc[int_mask, 'mean_wip'].mean()

# 4. Burstiness Indicators (Fano Factor on Hourly Vectors)
def fano_factor(arr):
    m = np.mean(arr)
    if m == 0: return 0
    return np.var(arr) / m

fano_ordinary = fano_factor(hourly_vectors['2026-04-07'])
fano_bursty = fano_factor(hourly_vectors['2026-04-21'])

# 5. Serial Dependence (Lag-1 Correlation of WIP)
wip_series = df['mean_wip'].values
if len(wip_series) > 1:
    lag_corr = np.corrcoef(wip_series[:-1], wip_series[1:])[0, 1]
else:
    lag_corr = 0

# 6. Little's Law Implied Flow Time (W = L / lambda)
# lambda = Arrivals / 1 day
# W = Mean WIP / Daily Arrivals (in days)
# Note: This is an approximation assuming steady state.
if pooled_arr > 0:
    pooled_flow_days = pooled_wip / pooled_arr
    pooled_flow_hours = pooled_flow_days * 24
else:
    pooled_flow_days = 0
    pooled_flow_hours = 0

# 7. Print Compact Tables
print("=== POOLED STATISTICS ===")
print(f"Arrivals: {pooled_arr:.1f}, Completed: {pooled_comp:.1f}, WIP: {pooled_wip:.1f}, FTE: {pooled_fte:.1f}")
print(f"Complex %: {pooled_complex:.1f}, Median Service: {df['median_service_min'].mean():.1f} min")

print("\n=== BURSTINESS INDICATORS ===")
print(f"Fano Factor (Ordinary): {fano_ordinary:.2f}")
print(f"Fano Factor (Bursty): {fano_bursty:.2f}")
print(f"WIP Lag-1 Correlation: {lag_corr:.2f}")

print("\n=== LITTLE'S LAW IMPLIES (Pooled) ===")
print(f"WIP: {pooled_wip:.1f}, Arrivals: {pooled_arr:.1f}/day")
print(f"Implied Flow Time: {pooled_flow_days:.2f} days ({pooled_flow_hours:.1f} hours)")

print(f"Intervention WIP: {int_wip:.1f}")
