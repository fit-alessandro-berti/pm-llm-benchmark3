## 1. Normalization Assumptions

For each valid interpretation of a display, convert its resolution window into UTC clock readings [rₗ, rᵤ]. If recorded clock minus true clock is in [a, b], the true-time interval is [rₗ − b, rᵤ − a]. Apply display uncertainty first. Use closed bounds, including conservative tie endpoints for nearest rounding. The minute-floor window extends from the displayed minute through second 59.999, as specified.

| Source | Resolution window relative to display | Clock correction | Zone interpretation |
|---|---|---|---|
| HUB | ±0.5 s | ±1 s | UTC |
| OPS-BER | [0, 59.999] s | [−120, +90] s under normal diagnostics | CEST, UTC+02:00 in June |
| SENSOR | ±5 s | ±5 s | UTC. The timestamp denotes completion. |
| VENDOR-NY | [0, 59.999] s | ±180 s | EDT, UTC−04:00 in June |
| LEGACY-BER | [0, 59.999] s | ±60 s | First fold CEST (UTC+02:00), second fold CET (UTC+01:00) |
| MOBILE-LON | ±30 s | ±300 s | BST, UTC+01:00 in June. Entry delay is modeled separately. |

The baseline allows each record to take any error permitted by its source bounds. A shared clock could correlate errors or cancel an offset in a duration, but the evidence gives no bound on that correlation. For independent event windows A = [aₗ, aᵤ] and B = [bₗ, bᵤ], B − A is [bₗ − aᵤ, bᵤ − aₗ]. For dependent events, project B − A from the joint constraints. Enforce the lifecycle order receipt ≤ start ≤ containment completion ≤ closure when applicable. Distinct lifecycle events may share a true-time endpoint. Eventually-following profile pairs may skip intervening events, so receipt to containment uses its endpoints directly.

- **T-404.** Interpret the signed 18–25 minutes as elapsed time between the same investigation's start and completion. Subtract [1,080, 1,500] s from the corrected completion interval, retaining the dependence on that completion and the recorded lifecycle order. If the signed interval measures effort or working time instead, it cannot bound elapsed start time by this subtraction.
- **T-405.** Enumerate folds jointly and treat the supplied ingestion order as an occurrence-order constraint for these events. The alert must use the first fold and the start the second fold. A start in the first fold cannot follow either alert candidate, and a start in the second fold cannot follow the second-fold alert. A first-fold containment cannot follow the surviving start. The surviving assignment still has resolution and clock uncertainty.
- **T-406.** The baseline treats the display as a reading taken at entry. Subtract entry delay [0, 300] s from the corrected record-time window to infer occurrence time. In the alternative where the entered value describes occurrence and only submission was late, use the corrected timestamp window directly for occurrence.
- **T-407.** The baseline is conditional on actual delivery and receipt no later than investigation start. Model receipt as send time plus latency [0, 1,200] s, with the additional constraint that receipt ≤ start. The latency estimate and that ordering premise have different evidentiary bases. Pairs involving receipt become indeterminate if actual delivery cannot be accepted.
- **T-409.** Use the weak engineering estimate of [−720, +720] s provisionally in place of the daily OPS-BER bound, and clip by lifecycle order. Treat conclusions that depend on the estimate as low-confidence screening. An alternative discards the estimate and uses order with the two HUB anchors.

## 5. PM4Py Temporal-Conformance Code

The midpoint calculation selects a feasible branch and uses the centers of its event windows as a lossy point log. The diagnostic adapter expects one list of deviations for the one trace submitted, with the activity names in the first two fields of each deviation tuple. ], columns=["case", "activity", "recorded", "source"])

# Zone, resolution-error bounds in ms, and recorded-minus-true offset bounds in ms.
sources = {
    "HUB": ("UTC", (-500, 500), (-1000, 1000)),
    "OPS-BER": ("Europe/Berlin", (0, 59999), (-90000, 120000)),
    "SENSOR": ("UTC", (-5000, 5000), (-5000, 5000)),
    "VENDOR-NY": ("America/New_York", (0, 59999), (-180000, 180000)),
    "LEGACY-BER": ("Europe/Berlin", (0, 59999), (-60000, 60000)),
    "MOBILE-LON": ("Europe/London", (-30000, 30000), (-300000, 300000)),
}
slas = {"S1": (A, I, 900), "S2": (I, C, 2700), "S3": (C, X, 129600)}
profile = {(A, I): (600, 180), (I, C): (2100, 600),
           (A, C): (2700, 720), (C, X): (86400, 21600)}

def clock_windows(row, occurrence_delay, accept_weak_offset):
    zone_name, (qlo, qhi), (olo, ohi) = sources[row.source]
    if row.case == "T-409" and row.activity == I:
        if not accept_weak_offset:
            return [(None, None)]
        olo, ohi = -720000, 720000
    naive = datetime.fromisoformat(row.recorded)
    zone = ZoneInfo(zone_name)
    delay = 300000 if row.source == "MOBILE-LON" and occurrence_delay else 0
    windows = set()
    for fold in (0, 1):
        utc = naive.replace(tzinfo=zone, fold=fold).astimezone(timezone.utc)
        if utc.astimezone(zone).replace(tzinfo=None) == naive:
            shown = pd.Timestamp(utc).value // 1_000_000
            windows.add((shown + qlo - ohi - delay, shown + qhi - olo))
    return sorted(windows)

def close_constraints(windows, constraints):
    # d[a, b] is an upper bound on t_b - t_a. None denotes the UTC epoch.
    nodes = (None, *windows)
    d = {(a, b): 0 if a == b else inf for a in nodes for b in nodes}
    for event, (lo, hi) in windows.items():
        if hi is not None:
            d[None, event] = hi
        if lo is not None:
            d[event, None] = -lo
    for a, b, lo, hi in constraints:
        d[a, b] = min(d[a, b], hi)
        d[b, a] = min(d[b, a], -lo)
    for k in nodes:
        for a in nodes:
            for b in nodes:
                d[a, b] = min(d[a, b], d[a, k] + d[k, b])
    return d if all(d[a, a] >= 0 for a in nodes) else None

def build_case(rows, occurrence_delay=True, accept_weak_offset=True, assume_delivery=True,
               accept_work_duration=True):
    case = rows["case"].iat[0]
    options = {row.activity: clock_windows(row, occurrence_delay, accept_weak_offset)
               for row in rows.itertuples(index=False)}
    constraints = []
    if case == "T-404":
        options[I] = [(None, None)]
        if accept_work_duration:
            constraints.append((I, F, 1_080_000, 1_500_000))
    if case == "T-407" and assume_delivery:
        options[A] = [(None, None)]
        constraints.append((S, A, 0, 1_200_000))
    order = [event for event in (A, I, F, C, X) if event in options]
    constraints.extend((a, b, 0, inf) for a, b in zip(order, order[1:]))

    branches = []
    for choice in product(*options.values()):
        bounds = close_constraints(dict(zip(options, choice)), constraints)
        if bounds is not None:
            branches.append(bounds)
    return branches

def projected_union(branches, a, b):
    if not branches or any((a, b) not in d for d in branches):
        return []
    ranges = sorted((-d[b, a], d[a, b]) for d in branches)
    merged = []
    for lo, hi in ranges:
        if merged and lo <= merged[-1][1]:
            merged[-1] = (merged[-1][0], max(merged[-1][1], hi))
        else:
            merged.append((lo, hi))
    return merged

def classify(ranges, lo, hi):
    if not ranges or any(not (isfinite(a) and isfinite(b)) for a, b in ranges):
        return "INDETERMINATE"
    has_pass = any(a <= hi and b >= lo for a, b in ranges)
    has_violation = any(a < lo or b > hi for a, b in ranges)
    if not has_pass:
        return "CERTAIN_VIOLATION"
    return "POSSIBLE_VIOLATION" if has_violation else "CERTAIN_PASS"

def profile_band(pair, zeta):
    mean, sd = profile[pair]
    return 1000 * (mean - zeta * sd), 1000 * (mean + zeta * sd)

def interval_report(case, branches):
    print(case, "feasible branches:", len(branches))
    if branches:
        for event in (b for a, b in branches[0] if a is None and b is not None):
            bounds = projected_union(branches, None, event)
            print(event, [tuple(pd.Timestamp(t, unit="ms", tz="UTC").isoformat()
                                if isfinite(t) else t for t in interval)
                          for interval in bounds])
    for name, (a, b, cap) in slas.items():
        durations = projected_union(branches, a, b)
        print(name, [(lo / 1000, hi / 1000) for lo, hi in durations],
              [classify(durations, 0, 1000 * (cap + extra)) for extra in (0, 120, 300)])
    for pair in profile:
        durations = projected_union(branches, *pair)
        print(pair, [(lo / 1000, hi / 1000) for lo, hi in durations],
              [classify(durations, *profile_band(pair, z)) for z in (1, 2, 3)])

def midpoint_log(models):
    # First feasible branch per case. Branch closure keeps its dependent events together.
    rows = []
    points = {}
    for case, branches in models.items():
        if not branches:
            continue
        branch = branches[0]
        points[case] = {}
        for a, event in branch:
            if a is None and event is not None:
                lo, hi = -branch[event, None], branch[None, event]
                if not (isfinite(lo) and isfinite(hi)):
                    continue
                timestamp = pd.Timestamp((lo + hi) * 500_000, unit="ns", tz="UTC")
                points[case][event] = timestamp
                # A prefix keeps date auto-detection from parsing IDs like T-401.
                rows.append(("incident_" + case, event, timestamp,
                             "lossy midpoint of one feasible branch"))
    frame = pd.DataFrame(rows, columns=["case", "activity", "timestamp", "approximation"])
    return pm4py.format_dataframe(frame, case_id="case", activity_key="activity",
                                  timestamp_key="timestamp"), points

def reported_pairs(single_trace_result):
    # Adapter for list per trace containing (activity1, activity2, duration, ...) tuples.
    if not isinstance(single_trace_result, (list, tuple)) or len(single_trace_result) != 1:
        return None
    trace_result = single_trace_result[0]
    if not isinstance(trace_result, (list, tuple)):
        return None
    if not all(isinstance(item, (list, tuple)) and len(item) >= 2
               and all(isinstance(name, str) for name in item[:2]) for item in trace_result):
        return None
    return {tuple(item[:2]) for item in trace_result}

def compare_midpoints(models):
    formatted, points = midpoint_log(models)
    for log_id, frame in formatted.groupby("case:concept:name", sort=False):
        case = log_id.removeprefix("incident_")
        one_trace_log = pm4py.convert_to_event_log(frame)
        for zeta in (1, 2, 3):
            raw = pm4py.conformance_temporal_profile(one_trace_log, profile, zeta=zeta)
            deviations = reported_pairs(raw)
            print("LOSSY MIDPOINT", case, "zeta", zeta, "raw PM4Py diagnostics:", raw)
            for a, b in profile:
                if a not in points[case] or b not in points[case]:
                    continue
                point_ns = (points[case][b] - points[case][a]).value
                lo, hi = profile_band((a, b), zeta)
                point_verdict = ("pass" if lo * 1_000_000 <= point_ns <= hi * 1_000_000
                                 else "violation")
                pm4py_verdict = ("see raw diagnostics" if deviations is None else
                                 "deviation" if (a, b) in deviations else "no deviation")
                print((a, b), point_ns / 1_000_000_000, point_verdict,
                      pm4py_verdict, classify(projected_union(models[case], a, b), lo, hi))

case_rows = dict(tuple(events.groupby("case", sort=False)))
models = {case: build_case(frame) for case, frame in case_rows.items()}

## 6. Evidential Sufficiency

A possible violation becomes certain when new evidence puts the whole feasible duration set inside the acceptance region or makes it disjoint. For an SLA cap L, a defensible upper bound ≤ L establishes a pass and a lower bound > L establishes a violation. For a profile band [l, u], establish both bounds inside the band or exclude the band altogether. A relative-time measurement can be sufficient by itself. Exact timestamps for both events may be unnecessary, and evidence that still leaves durations on both sides of a boundary will preserve the possible verdict.

## 7. Governance Recommendation

- Store event occurrence in UTC at its actual precision. Retain the raw timestamp, source clock ID, original IANA zone, explicit UTC offset and DST fold, declared resolution and rounding semantics, conversion version, and corrected uncertainty bounds. Keep occurrence, entry, and ingestion as distinct fields.
- Record time-stamped, per-source offset telemetry with its sign convention, validity window, synchronization state, drift bounds, and uncertainty. Mark outages and preserve the provenance and confidence of fallback estimates. Track when events share clock error so duration analysis can use a justified bound on differential error.
- Emit explicit receipt, investigation start and completion, containment completion, and close events. Carry case, message, and lifecycle identifiers across systems. Link send to acknowledgment and start to completion. Preserve the original evidence and record the assumptions and provenance of inferred activities.
- For enforcement, require sufficient evidence that every feasible duration violates the formal SLA. Route intervals containing both passing and violating durations to review and route untestable cases to evidence collection. Apply any tolerance through an approved SLA policy. Use temporal-profile deviations for statistical monitoring and investigation, with the profile version and ζ recorded alongside the result.
