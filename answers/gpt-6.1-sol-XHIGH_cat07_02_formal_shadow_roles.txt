# 2. Core versus peripheral activities

A core activity is central to a role's responsibility and recurs in the relevant case context. It need not have the highest process-wide count. A peripheral activity can be assistance, remediation, triage, learning, or delegated cover. Its execution does not automatically imply independent competence or authority. Assess frequency together with complexity, sequence position, persistence across weeks, substitution flags, product/segment, shift, and actual decision rights.

- **Front-office service resolution:** A1/A2/A4/A12 form the routine service bundle. # 5. PM4Py role-discovery and similarity code

The summaries support hypotheses, but exact networks and mined memberships require the underlying event-level dataframe. The following illustrative code expects the listed columns and numeric complexity scores. It preserves substitution uncertainty, counts complexity once per resource–case exposure, and keeps behavioural discovery separate from authority. It uses PM4Py's customary public functions; role objects expose `activities` and `originator_importance`, and social-network results commonly expose `connections`.

```python
import numpy as np
import pandas as pd
import pm4py

CASE = "case:concept:name"
ACT = "concept:name"
TIME = "time:timestamp"
RES = "org:resource"
SUB = "temporary_substitution"

raw = pd.read_csv("event_log.csv")
required = [CASE, ACT, TIME, RES, "case_complexity", SUB,
            "customer_segment", "product_line", "escalation_level"]
missing = set(required) - set(raw.columns)
if missing:
    raise ValueError(f"Missing columns: {sorted(missing)}")
if raw[[CASE, ACT, TIME, RES]].isna().any().any():
    raise ValueError("Resolve missing case/activity/time/resource identifiers")

raw[CASE] = raw[CASE].astype(str)
raw[RES] = raw[RES].astype(str)
raw[TIME] = pd.to_datetime(raw[TIME], utc=True, errors="raise")
raw["case_complexity"] = pd.to_numeric(
    raw["case_complexity"], errors="raise"
)
# This example assumes complexity is a stable case attribute.
if raw.groupby(CASE)["case_complexity"].nunique().gt(1).any():
    raise ValueError("Define how changing case complexity should be analysed")

# CSV booleans need explicit parsing: bool("False") would be incorrect.
sub_text = raw[SUB].astype("string").str.strip().str.lower()
raw[SUB] = sub_text.map(
    {"true": True, "false": False, "1": True, "0": False}
).astype("boolean")
if (sub_text.notna() & raw[SUB].isna()).any():
    raise ValueError("Unrecognized substitution values")
# Missing flags remain unknown, rather than becoming confirmed routine work.

df = pm4py.format_dataframe(
    raw,
    case_id=CASE,
    activity_key=ACT,
    timestamp_key=TIME,
)
# Resolve timestamp ties using authoritative event order when available.
df = df.sort_values([CASE, TIME], kind="mergesort").copy()
df["iso_week"] = df[TIME].dt.strftime("%G-W%V")

roles = pm4py.discover_organizational_roles(df)
pm_similarity = pm4py.discover_activity_based_resource_similarity(df)
handover = pm4py.discover_handover_of_work_network(df)
working_together = pm4py.discover_working_together_network(df)

# Discovery weights describe observed participation, not proficiency/authority.
member_rows = []
for role_id, role in enumerate(roles):
    for resource, weight in role.originator_importance.items():
        member_rows.append({
            "mined_role_id": role_id,
            RES: resource,
            "role_activities": tuple(sorted(role.activities)),
            "discovery_weight": float(weight),
        })
membership = pd.DataFrame(member_rows, columns=[
    "mined_role_id", RES, "role_activities", "discovery_weight"
])

# Do not weight case complexity by the number of events a person recorded.
resource_cases = df[[RES, CASE, "case_complexity"]].drop_duplicates(
    [RES, CASE]
)
case_context = resource_cases.groupby(RES).agg(
    cases_touched=(CASE, "nunique"),
    complexity_median=("case_complexity", "median"),
    complexity_p90=("case_complexity", lambda s: s.quantile(0.90)),
    complexity_coverage=("case_complexity", lambda s: s.notna().mean()),
)
event_context = df.groupby(RES).agg(
    event_count=(ACT, "size"),
    known_substitution_events=(SUB, lambda s: int(s.fillna(False).sum())),
    substitution_flag_coverage=(SUB, lambda s: s.notna().mean()),
)
resource_context = case_context.join(event_context).reset_index()
role_evidence = membership.merge(
    resource_context, on=RES, how="left", validate="many_to_one"
)
role_evidence["authority_status"] = "requires independent policy/audit evidence"

# Preserve contextual exposure: a case may appear in multiple strata.
stratum_keys = [RES, "product_line", "customer_segment",
                "escalation_level", SUB]
stratum_cases = df.drop_duplicates(stratum_keys + [CASE])
strata = stratum_cases.groupby(stratum_keys, dropna=False).agg(
    cases_touched=(CASE, "nunique"),
    complexity_median=("case_complexity", "median"),
).reset_index()
role_context = membership.merge(strata, on=RES, how="left")
activity_by_week = df.groupby(
    [RES, ACT, "iso_week", SUB], dropna=False
).size().rename("event_count").reset_index()

# Compare full-window discovery with explicitly non-substitution participation.
# This filtered view is for activity profiles, not reconstructed handovers.
routine = df.loc[df[SUB].eq(False).fillna(False)].copy()
routine_roles = (
    pm4py.discover_organizational_roles(routine) if not routine.empty else []
)
routine_similarity = (
    pm4py.discover_activity_based_resource_similarity(routine)
    if not routine.empty else None
)

# Explicit cosine reproduces the question's stated type of similarity.
# Do not assume every PM4Py version/backend uses this exact similarity metric.
counts = pd.crosstab(df[RES], df[ACT]).astype(float)
values = counts.to_numpy()
norms = np.linalg.norm(values, axis=1, keepdims=True)
normalized = np.divide(values, norms, out=np.zeros_like(values),
                       where=norms != 0)
cosine = pd.DataFrame(normalized @ normalized.T,
                      index=counts.index, columns=counts.index)

# Inspect edges with their directionality and normalization in mind.
def edge_table(network):
    edges = network.connections if hasattr(network, "connections") else network
    return pd.DataFrame(
        [(source, target, weight)
         for (source, target), weight in edges.items()],
        columns=["source", "target", "weight"],
    )

handover_edges = edge_table(handover)
together_edges = edge_table(working_together)
pm_similarity_edges = edge_table(pm_similarity)

# Contextual network: select relevant CASES, retaining their complete traces.
# Deleting intermediate events can manufacture apparent direct handovers.
enterprise_ids = df.loc[
    df["product_line"].eq("Enterprise Security"), CASE
].unique()
enterprise = df.loc[df[CASE].isin(enterprise_ids)].copy()
enterprise_handover_edges = (
    edge_table(pm4py.discover_handover_of_work_network(enterprise))
    if not enterprise.empty else pd.DataFrame()
)
enterprise_together_edges = (
    edge_table(pm4py.discover_working_together_network(enterprise))
    if not enterprise.empty else pd.DataFrame()
)

# Review role_evidence, role_context, activity_by_week, cosine, and networks
# beside supplied titles/certifications and authoritative delegation records.
# No similarity threshold or mined_role_id grants permission to approve,
# conduct independent security sign-off, or cover a critical specialist.
```

Use the outputs as follows:

- Compare candidate memberships and activity support with case complexity and weekly substitution patterns. Cross-tabulate the actor and activity within product, customer segment, and escalation strata. Do not invent score thresholds for “high” and “critical”: obtain the process owner's actual category definitions before computing those category rates.
- Inspect handovers connecting front office→technical→quality, commercial→supervision, and reopen→Mateo→specialists. Inspect working-together ties for Mateo's breadth and Giorgio's commercial relationships. Working together means shared case participation, not necessarily simultaneous collaboration; handover means observed sequence, not reporting authority.
- Use complete-case networks to examine return patterns such as coordinator→specialist→coordinator; a subcontracting network can add evidence for this hypothesis. A bot-dominated network may be inspected with bot nodes hidden after discovery, but deleting bot events first can change the meaning of adjacency.
- Compare networks and profiles across comparable time windows and case populations. Control for long cases, shared-case size, opportunity to perform an activity, shift, product, and segment. A broker's centrality may reflect assignment rules rather than greater competence.
- Treat the supplied similarities as evidence, not a clustering threshold. Establish which metric, activity mapping, normalization, and window produced each result. Repeated behaviours within matched contexts support operational roles; final signatories and policy establish authority.

For timing and outcomes, link substitutions and originating closures to subsequent rechecks/reopens at case level. If the log contains only one timestamp per activity, it cannot identify true execution duration without additional lifecycle/start-time information. Time between events can include queueing and other work. Validate the definition of the reported 38/74-minute measure and the two-day waits before using service-time or staffing calculations.

Pilot role and coverage changes with bounded scope and monitor matched-case resolution time, referral waits, first-time resolution, documentation completeness, approval rechecks, quality findings, and critical-case outcomes.
