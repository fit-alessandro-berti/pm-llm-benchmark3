# 1. Assumptions and notation

**A1 (Event-order convention):**
- When two events have the same rounded timestamp, we assume:
  - Arrivals occur before starts
  - Starts occur before ends
  - S1 ends occur before S2 starts for the same case
- This prevents artificial resource conflicts from rounding.

**A2 (Rounding treatment):**
- Each reported timestamp t represents an actual time in [t-2.5 min, t+2.5 min].
- For imputation, we use the midpoint (t) as central estimate and the interval bounds for sensitivity.

**A3 (Capacity assumptions):**
- S1 has 2 resources (I1, I2); S2 has 2 resources (C1, C2) except during C2 outage (10:55-11:10).
- No parallel work on a single resource (enforced via imputation constraints).

**A4 (Imputation assumptions for MISSING starts):**
- For S1 MISSING starts (P07, P15):
  - Lower bound: max(arrival_s1, previous end on same resource + 5 min)
  - Upper bound: min(s1_end - 5 min, next start on same resource - 5 min)
- For S2 MISSING starts (P05, P11):
  - Lower bound: s1_end + 5 min
  - Upper bound: s2_end - 5 min

**A5 (Censoring assumptions for OPEN activities):**
- OPEN activities are right-censored at 14:00.
- Elapsed service time = 14:00 - start_timestamp
- Final service time  elapsed service time

**A6 (Queue definition):**
- Queue length at time t includes all cases that have arrived but not yet started service at station X.
- WIP includes cases in queue or in service.

# 2. Reconstruction method and formulas

**Waiting time (W_q):**
- For completed cases: W_q = start_timestamp - arrival_timestamp
- For censored cases: W_q  (14:00 - arrival_timestamp) if not started

**Service time (S):**
- For completed cases: S = end_timestamp - start_timestamp
- For OPEN cases: S  (14:00 - start_timestamp)

**Sojourn time (T):**
- For completed cases: T = end_timestamp - arrival_timestamp
- For censored cases: T  (14:00 - arrival_timestamp)

**WIP calculation:**
- For each station, reconstruct timeline of:
  - Arrivals (S1: external arrival; S2: S1 completion)
  - Service starts
  - Service completions
- At each event time, WIP = previous WIP + arrivals - completions
- Handle simultaneous events via A1 convention

**Utilization:**
- Busy time = sum of service times for all resources
- Utilization = busy time / (available time × capacity)
- For S2 during outage: capacity = 1

**Little's Law check:**
- Only applied to intervals where:
  - Stationarity is plausible (arrival/service rates stable)
  - No censoring
  - No missing data
- L = W where L=mean WIP, =arrival rate, W=mean sojourn time

**Uncertainty handling:**
- For missing starts: report [lower, upper] bounds
- For censored cases: report  elapsed time
- For utilization: report range across imputation scenarios

# 4. Calculate station-level metrics with pandas
def calculate_station_metrics(station, df, event_log):
    # Filter events for this station
    station_events = event_log[event_log["concept:name"] == station]

    # Get all cases that entered the station
    if station == "S1":
        cases = df[pd.notna(df["arrival_s1"])]
    else:
        cases = df[pd.notna(df["s1_end"])]

    # Calculate arrivals and completions
    arrivals = len(cases)
    completions = len(station_events)

    # Calculate waiting times (only for completed cases)
    if station == "S1":
        completed_cases = df[pd.notna(df["s1_start"]) & pd.notna(df["s1_end"])]
        waiting_times = [(s1_start - arrival_s1).total_seconds()/60
                         for s1_start, arrival_s1 in zip(completed_cases["s1_start"], completed_cases["arrival_s1"])]
    else:
        completed_cases = df[pd.notna(df["s2_start"]) & pd.notna(df["s2_end"])]
        waiting_times = [(s2_start - s1_end).total_seconds()/60
                         for s2_start, s1_end in zip(completed_cases["s2_start"], completed_cases["s1_end"])]

    # Calculate service times
    service_times = [(end - start).total_seconds()/60
                     for start, end in zip(station_events["start_timestamp"], station_events["time:timestamp"])]

    # Calculate WIP over time (simplified approach)
    timeline = []
    if station == "S1":
        # Arrivals
        for _, row in cases.iterrows():
            timeline.append((row["arrival_s1"], "arrival"))
        # Starts
        for _, row in completed_cases.iterrows():
            timeline.append((row["s1_start"], "start"))
        # Ends
        for _, row in completed_cases.iterrows():
            timeline.append((row["s1_end"], "end"))
    else:
        # Arrivals (S1 completions)
        for _, row in df[pd.notna(df["s1_end"])].iterrows():
            timeline.append((row["s1_end"], "arrival"))
        # Starts
        for _, row in completed_cases.iterrows():
            timeline.append((row["s2_start"], "start"))
        # Ends
        for _, row in completed_cases.iterrows():
            timeline.append((row["s2_end"], "end"))

    # Sort timeline
    timeline.sort(key=lambda x: x[0])

    # Calculate WIP over time
    wip = 0
    wip_over_time = []
    for time, event in timeline:
        if event == "arrival":
            wip += 1
        elif event == "start":
            wip -= 1  # moved from queue to service
        elif event == "end":
            wip -= 1  # completed
        wip_over_time.append((time, wip))

    # Calculate busy time and utilization
    busy_time = sum(service_times)
    total_time = (datetime(2026,5,12,14,0) - datetime(2026,5,12,8,0)).total_seconds()/60
    capacity = 2 if station == "S1" else (1 if (datetime(2026,5,12,10,55) <= time <= datetime(2026,5,12,11,10)) else 2)
    utilization = busy_time / (total_time * capacity)

    return {
        "station": station,
        "arrivals": arrivals,
        "completions": completions,
        "waiting_times": waiting_times,
        "service_times": service_times,
        "wip_over_time": wip_over_time,
        "busy_time": busy_time,
        "utilization": utilization,
        "capacity": capacity
    }

s1_metrics = calculate_station_metrics("S1", df, event_log)
s2_metrics = calculate_station_metrics("S2", df, event_log)

# 6. Little's Law check for S1 (08:00-10:00)
print("\n=== Little's Law Check (S1 08:00-10:00) ===")
