# 1. Source-Semantics Baseline

**Status disclaimer.** I could not execute any code for this answer. Every statement about what PM4Py will do is an expectation or a hypothesis. The code in Sections 3 and 5 is written to test those hypotheses rather than assume them.

**Abbreviations.** R = Register Change, A = Assess Risk, P = Prepare Evidence, L = Legal Review, C = Configure Trial, I = Inspect Trial, X = Correct Defect, Rel = Release Change, Arc = Archive Change. A trace is a complete visible trace.

**What the source states.**
- Direct order edges: RA, RP, AL-block, Aloop, Ploop, L-blockRel, loopRel, RelArc.
- `optional_legal` is `XOR(L, tau)`.
- `verification_loop` is `LOOP(do = CI, redo = X)`. Its language is `C I (X C I)*`.
- There is no edge between P and the L-block, and none between the L-block and the loop.

**Structural note.** The induced sub-order on {P, A, L-block, loop} is an N-pattern: A<L, A<loop, P<loop, with PA, PL and Lloop. The order is therefore not series-parallel. This is the main reason a block-structured intermediate (a process tree) is expected to fail.

| Invariant ID | Invariant | Positive witness | Negative witness | Observable after hiding tau? |
|---|---|---|---|---|
| INV-01 | Ordering: R precedes everything (directly RA, RP; transitively all others). | R A P C I Rel Arc | A R P C I Rel Arc | Yes |
| INV-02 | A and P are unordered; both are required exactly once. | R A P C I Rel Arc **and** R P A C I Rel Arc | R A C I Rel Arc (P missing) | Yes, as the existence of both interleavings. Concurrency itself is not observable. |
| INV-03 | Optionality: L occurs 0 or 1 times (XOR with tau). | Without L: R A P C I Rel Arc. With L: R A L P C I Rel Arc | R A L L P C I Rel Arc | Partly. Presence or absence of L is observable. The tau branch and the decision point are not. |
| INV-04 | L requires only A. It is unordered with respect to P and to verification (absence of edges). | R A L P C I Rel Arc; R A P C L I Rel Arc; R A P C I X L C I Rel Arc | R P L A C I Rel Arc (L before A). Also, a candidate that rejects any positive witness is over-constrained. | Yes, as interleavings |
| INV-05 | Verification gating: C cannot start before both A and P have completed. | R P A C I Rel Arc | R A C P I Rel Arc | Yes |
| INV-06 | Loop body: every iteration runs C before I. | R A P C I X C I Rel Arc | R A P I C Rel Arc | Yes |
| INV-07 | Loop scope, binary-loop semantics: X occurs only between an I and the next C. | R A P C I X C I X C I Rel Arc | R A P C X I Rel Arc; R A P C I X Rel Arc (ends on redo); X before first C | Trace order is observable. The loop-back mechanism and the redo decision are not. |
| INV-08 | Minimum iteration count is 1. | R A P C I Rel Arc | R A P Rel Arc | Yes |
| INV-09 | Synchronization before release: Rel waits for the loop's completion and for L if L was taken. | R A P C I L Rel Arc (late L) | R A P C Rel I Arc; R A P C I Rel L Arc | Yes |
| INV-10 | Finality: Arc follows Rel, and nothing follows Arc. A trace is complete only at exactly the final marking. | R A P C I Rel Arc | R A P C I Arc Rel; R A P C I Rel (prefix, incomplete); R A P C I Rel Arc Arc | Order is observable. | INV-11 | Label uniqueness: R, A, P, Rel, Arc occur exactly once; every visible label maps to one task. | R A P C I Rel Arc | R A P C I Rel Rel Arc | Yes. The silent transitions carry no label. |
| INV-12 | Model-level overlap of L with verification. No timing is modeled. | Only indirectly: both R A P L C … and R A P C L … exist. | None exists at trace level. A trace cannot express overlap. | No. Only interleavings are observable. |

A "positive witness" must be accepted by any faithful conversion. A "negative witness" must be rejected. The trace language is necessary evidence, not sufficient evidence.

|---|---|---|---|---|

| **B: POWL  Petri net  process tree  BPMN** | `convert_to_petri_net`  `pm4py.convert_to_process_tree(net, im, fm)`  `pm4py.convert_to_bpmn(tree)`  `convert_to_petri_net(bpmn)` | A process tree yields a BPMN that is structurally well-formed by construction. | The source contains an N-pattern (A<L, A<loop, P<loop, PL). | **C (control/baseline): POWL  Petri net only, plus POWL rendering** | `convert_to_petri_net`; `save_vis_petri_net`; `save_vis_powl` | No BPMN-induced distortion. | **D (contingency, not coded): custom BPMN from the validated net** | No PM4Py call. Non-block BPMN with explicit parallel and exclusive gateways, then `convert_to_petri_net(bpmn)` for validation. | Can express the N-pattern: parallel split at R, then a second parallel split after A feeding both the L-branch and a join with P. | This is not a POWL-to-BPMN API, and hand construction can introduce errors. | Only acceptable if it passes the same round-trip validation. |

**Primary pipeline choice: A.** The brief requires it, and it is the only PM4Py route with a chance of producing BPMN for this non-series-parallel order.

If A fails, the correct outcome is "no faithful BPMN from PM4Py" plus fallback to C. A BPMN forced out of a lossy tree is not acceptable.

```python
    "N13_extra_after_arc": (R, A, P, C, I, REL, ARC, ARC),
    "N14_P_missing": (R, A, C, I, REL, ARC),
}


# ---------- marking utilities ----------
def mkey(m):
    return frozenset((p, n) for p, n in m.items() if n > 0)


def fire(t, m):
    new = Marking(m)
    for arc in t.in_arcs:
        new[arc.source] -= arc.weight
        if new[arc.source] <= 0:
            del new[arc.source]
    for arc in t.out_arcs:
        new[arc.target] += arc.weight
    return new


def tau_closure(net, start, token_bound=TOKEN_BOUND, cap=CLOSURE_CAP):
    """All markings reachable via label-None transitions only. Seen-set prevents silent cycling."""
    seen = {mkey(start): start}
    flags, queue = set(), deque([start])
    while queue:
        m = queue.popleft()
        for t in pm4py.get_enabled_transitions(net, m):
            if t.label is not None:
                continue
            m2 = fire(t, m)
            if max(m2.values(), default=0) > token_bound:
                flags.add("token_bound_exceeded")
                continue
            k = mkey(m2)
            if k in seen:
                continue
            if len(seen) >= cap:
                flags.add("closure_cap_hit")
                return seen, flags
            seen[k] = m2
            queue.append(m2)
    return seen, flags


def accepts(net, im, fm, trace):
    """Complete-trace acceptance: visible trace, tau hidden, EXACT final-marking equality."""
    fm_key = mkey(fm)
    cur, _ = tau_closure(net, Marking(im))
    for label in trace:
        nxt = {}
        for m in cur.values():
            for t in pm4py.get_enabled_transitions(net, m):
                if t.label == label:
                    closure, _ = tau_closure(net, fire(t, m))
                    nxt.update(closure)
        cur = nxt
        if not cur:
            return False
    return fm_key in cur


def explore(net, im, fm, max_visible=MAX_VISIBLE, label_caps=None):
    """Determinized (subset-construction) bounded exploration of visible behaviour."""
    label_caps = label_caps or {C: MAX_ITER}
    fm_key = mkey(fm)
    flags, cap_pruned, frontier_cut = set(), False, False
    start, f = tau_closure(net, Marking(im))
    flags |= f
    level = {(): start}
    accepted, improper = set(), set()
    for depth in range(max_visible + 1):
        nxt_level = {}
        for trace, markings in level.items():
            if fm_key in markings:
                accepted.add(trace)
            else:   # covers fm but is not exactly fm => improper completion
                for k in markings:
                    kd = dict(k)
                    if all(kd.get(p, 0) >= n for p, n in fm_key):
                        improper.add(trace)
                        break
            for m in markings.values():
                for t in pm4py.get_enabled_transitions(net, m):
                    if t.label is None:
                        continue
                    if depth == max_visible:
                        frontier_cut = True
                        continue
                    new_trace = trace + (t.label,)
                    if any(new_trace.count(lab) > cap for lab, cap in label_caps.items()):
                        cap_pruned = True
                        continue
                    m2 = fire(t, m)
                    if max(m2.values(), default=0) > TOKEN_BOUND:
                        flags.add("token_bound_exceeded")
                        continue
                    closure, f = tau_closure(net, m2)
                    flags |= f
                    nxt_level.setdefault(new_trace, {}).update(closure)
        level = nxt_level
        if len(level) > PREFIX_CAP:
            flags.add("prefix_cap_hit")
            break
    return {"accepted": accepted, "improper": improper, "flags": flags,
            "cap_pruned": cap_pruned, "frontier_cut": frontier_cut,
            "exhaustive_under_bound": not (flags & {"closure_cap_hit", "token_bound_exceeded",
                                                   "prefix_cap_hit"})}


# ---------- independent oracle computed from the POWL object, not from any converter ----------
def _children(node):
    ch = getattr(node, "children", None)
    if ch is None:
        ch = node.get_children()
    return list(ch)


def _edge(order, a, b):
    if hasattr(order, "is_edge"):
        return bool(order.is_edge(a, b))
    return (a, b) in order.edges


def _shuffle(combo, preds):
    lens = tuple(len(t) for t in combo)
    memo = {}

    def go(pos):
        if pos in memo:
            return memo[pos]
        if pos == lens:
            return {()}
        out = set()
        for i in range(len(combo)):
            if pos[i] < lens[i] and all(pos[p] == lens[p] for p in preds[i]):
                nxt = pos[:i] + (pos[i] + 1,) + pos[i + 1:]
                for s in go(nxt):
                    out.add((combo[i][pos[i]],) + s)
        memo[pos] = out
        return out

    return go(tuple(0 for _ in combo))


def powl_language(node, k):
    """Complete visible traces of a POWL node with at most k loop iterations."""
    if isinstance(node, SilentTransition):
        return {()}
    if isinstance(node, Transition):
        return {(node.label,)}
    kids = _children(node)
    if isinstance(node, OperatorPOWL):
        if node.operator == Operator.XOR:
            out = set()
            for c in kids:
                out |= powl_language(c, k)
            return out
        if node.operator == Operator.LOOP:
            do_l, redo_l = powl_language(kids[0], k), powl_language(kids[1], k)
            cur, out = set(do_l), set(do_l)
            for _ in range(k - 1):
                cur = {a + r + d for a in cur for r in redo_l for d in do_l}
                out |= cur
            return out
        raise NotImplementedError(node.operator)
    if isinstance(node, StrictPartialOrder):
        n = len(kids)
        clo = [[_edge(node.order, kids[i], kids[j]) for j in range(n)] for i in range(n)]
        for m in range(n):                       # transitive closure (Warshall)
            for i in range(n):
                if clo[i][m]:
                    for j in range(n):
                        if clo[m][j]:
                            clo[i][j] = True
        preds = [[i for i in range(n) if clo[i][j]] for j in range(n)]
        langs = [sorted(powl_language(c, k)) for c in kids]
        out = set()
        for combo in itertools.product(*langs):
            out |= _shuffle(combo, preds)
        return out
    raise NotImplementedError(type(node))


def spec_accepts(tr):
    """Hand-coded invariant checker (unbounded loops); cross-checks the oracle above."""
    if any(e not in EXPECTED_LABELS for e in tr):
        return False
    if any(tr.count(x) != 1 for x in (R, A, P, REL, ARC)) or tr.count(L) > 1:
        return False
    loop = [e for e in tr if e in (C, I, X)]
    if len(loop) % 3 != 2 or any(e != (C, I, X)[j % 3] for j, e in enumerate(loop)):
        return False
    pos = {x: tr.index(x) for x in (R, A, P, REL, ARC)}
    if not (pos[R] < pos[A] and pos[R] < pos[P]):
        return False
    gate = max(pos[A], pos[P])
    loop_pos = [j for j, e in enumerate(tr) if e in (C, I, X)]
    if any(j < gate for j in loop_pos) or pos[REL] < max(loop_pos):
        return False
    if L in tr and not (pos[A] < tr.index(L) < pos[REL]):
        return False
    return pos[ARC] > pos[REL] and pos[ARC] == len(tr) - 1


def near_miss_negatives(oracle_plus, traces, rng, sample=60, cap=2000):
    out = set()
    pool = sorted(traces)
    for tr in rng.sample(pool, min(sample, len(pool))):
        out.add(tr[:-1])
        for i in range(len(tr)):
            out.add(tr[:i] + tr[i + 1:])                         # deletion
            out.add(tr[:i] + (tr[i],) + tr[i:])                  # duplication
            if i + 1 < len(tr):
                out.add(tr[:i] + (tr[i + 1], tr[i]) + tr[i + 2:])  # adjacent swap
    return sorted(out - oracle_plus)[:cap]


# ---------- footprints, reachability graph, playout ----------
def footprints_safe(name, net, im, fm):
    try:
        return pm4py.discover_footprints(net, im, fm)
    except Exception as exc:
        record_error(f"{name}_footprints", exc)
        return None


def compare_footprints(a, b):
    if not isinstance(a, dict) or not isinstance(b, dict):
        return "not comparable"
    diff = {}
    for key in set(a) & set(b):
        if isinstance(a[key], (set, frozenset)) and isinstance(b[key], (set, frozenset)):
            d = set(a[key]) ^ set(b[key])
            if d:
                diff[key] = sorted(map(str, d))[:20]
    return diff   # {} means identical footprints: a NECESSARY check only


def reach_graph_size(name, net, im, fm):
    if diagnostics.get(name, {}).get("sound") is not True:
        return "skipped: not proven sound (reachability graph may be infinite)"
    try:
        g = pm4py.convert_to_reachability_graph(net, im, fm)
        if hasattr(g, "number_of_nodes"):
            return {"states": g.number_of_nodes(), "edges": g.number_of_edges()}
        return {"states": len(g.states), "edges": len(g.transitions)}
    except Exception as exc:
        record_error(f"{name}_reachability_graph", exc)
        return None


def playout_variants(name, net, im, fm):
    try:
        log = pm4py.play_out(net, im, fm)     # supported kwargs vary by version; defaults only
    except Exception as exc:
        record_error(f"{name}_playout", exc)
        return set()
    variants = set()
    if hasattr(log, "columns"):               # DataFrame
        for _, grp in log.groupby("case:concept:name", sort=False):
            variants.add(tuple(grp["concept:name"]))
    else:                                     # EventLog
        for tr in log:
            variants.add(tuple(ev["concept:name"] for ev in tr))
    return variants


# ---------- main comparison ----------
def main():
    rng = random.Random(0)
    report = {"bounds": {"MAX_ITER": MAX_ITER, "MAX_VISIBLE": MAX_VISIBLE,
                         "TOKEN_BOUND": TOKEN_BOUND}}

    oracle = powl_language(source_powl, MAX_ITER)
    oracle_plus = powl_language(source_powl, MAX_ITER + 1)
    report["oracle_size"] = len(oracle)
    # cross-check of the two independent oracles (detects my own misreading)
    report["oracle_vs_spec_disagreements"] = (
        [t for t in oracle if not spec_accepts(t)][:5]
        + [n for n, t in {**NEGATIVE}.items() if spec_accepts(t)]
        + [n for n, t in {**POSITIVE}.items() if not spec_accepts(t) or t not in oracle_plus])
    mutants = [t for t in near_miss_negatives(oracle_plus, oracle, rng) if not spec_accepts(t)]

    base_net, base_im, base_fm = accepting_nets["net_from_powl"]
    base = explore(base_net, base_im, base_fm)
    base_fp = footprints_safe("net_from_powl", base_net, base_im, base_fm)
    base_playout = {t for t in playout_variants("net_from_powl", base_net, base_im, base_fm)
                    if accepts(base_net, base_im, base_fm, t)}

    candidates = [n for n in accepting_nets if n != "net_from_powl"]
    if not candidates:
        print("NO round-tripped nets exist: this is NOT a pass. BPMN round trip is untested.")

    for name in ["net_from_powl"] + candidates:
        net, im, fm = accepting_nets[name]
        ex = base if name == "net_from_powl" else explore(net, im, fm)
        acc = ex["accepted"]
        labels = {t.label for t in net.transitions if t.label is not None}
        pos_fail = [k for k, t in POSITIVE.items() if not accepts(net, im, fm, t)]
        neg_fail = [k for k, t in NEGATIVE.items() if accepts(net, im, fm, t)]
        mut_fail = [m for m in mutants if accepts(net, im, fm, m)]
        own_play = playout_variants(name, net, im, fm)
        play_spec_fail = [t for t in own_play
                          if accepts(net, im, fm, t) and not spec_accepts(t)][:5]
        play_base_fail = [t for t in base_playout if not accepts(net, im, fm, t)][:5]
        fp = footprints_safe(name, net, im, fm)
        r = {
            "exhaustive_under_bound": ex["exhaustive_under_bound"],
            "flags": sorted(ex["flags"]),
            "bound_binding": {"frontier_cut": ex["frontier_cut"], "loop_cap_pruned": ex["cap_pruned"]},
            "accepted_traces": len(acc),
            "missing_vs_oracle": [list(t) for t in sorted(oracle - acc)[:5]],
            "missing_vs_oracle_count": len(oracle - acc),
            "extra_vs_oracle": [list(t) for t in sorted(acc - oracle)[:5]],
            "extra_vs_oracle_count": len(acc - oracle),
            "only_in_net_from_powl_count": len(base["accepted"] - acc),
            "only_in_candidate_count": len(acc - base["accepted"]),
            "improper_completions": len(ex["improper"]),
            "unexpected_labels": sorted(labels - EXPECTED_LABELS),
            "absent_labels": sorted(EXPECTED_LABELS - labels),
            "positive_witness_failures": pos_fail,
            "negative_witness_false_accepts": neg_fail,
            "near_miss_false_accepts": [list(m) for m in mut_fail[:5]],
            "near_miss_total": len(mutants),
            "playout_violating_spec": [list(t) for t in play_spec_fail],
            "baseline_playout_rejected_here": [list(t) for t in play_base_fail],
            "footprint_diff_vs_net_from_powl": ("identical-reference" if name == "net_from_powl"
                                                else compare_footprints(base_fp, fp)),
            "reachability_graph": reach_graph_size(name, net, im, fm),
            "soundness": diagnostics.get(name, {}).get("sound"),
            "workflow_net": diagnostics.get(name, {}).get("is_workflow_net"),
        }
        reasons = []
        if not r["exhaustive_under_bound"]: reasons.append("exploration incomplete")
        if r["missing_vs_oracle_count"]: reasons.append("lost behaviour")
        if r["extra_vs_oracle_count"]: reasons.append("added behaviour")
        if r["improper_completions"]: reasons.append("improper completion")
        if r["unexpected_labels"] or r["absent_labels"]: reasons.append("label set mismatch")
        if pos_fail or neg_fail or mut_fail: reasons.append("witness/near-miss failure")
        if play_spec_fail or play_base_fail: reasons.append("playout mismatch")
        if r["soundness"] is not True: reasons.append("soundness not established")
        r["verdict"] = ("CONSISTENT_WITH_ORACLE_UNDER_BOUND_ONLY" if not reasons
                        else "REJECT_OR_QUARANTINE: " + "; ".join(reasons))
        report[name] = r
        print(f"\n== {name}: {r['verdict']}")

    with open(f"{OUT_DIR}/round_trip_report.json", "w") as fh:
        json.dump(report, fh, indent=2, default=str)
    print("\nA 'CONSISTENT' verdict means equality of completed visible traces with at most "
          f"{MAX_ITER} loop iterations and visible length <= {MAX_VISIBLE}. Nothing more.")
    return report


report = main()
```

**Is the comparison exhaustive?**
- It is exhaustive for completed visible traces (exact final-marking equality, tau hidden) with at most `MAX_ITER` occurrences of Configure Trial and visible length at most `MAX_VISIBLE`. That holds only when `exhaustive_under_bound` is true, meaning no closure cap, prefix cap or token-bound flag fired.
- It is not exhaustive for longer loop unrollings. The `bound_binding` fields show that the bound is cutting behavior, which is expected for a loop.
- It does not establish equivalence of the unbounded language, equivalence of branching structure, or timing overlap.

**Why there are two oracles.** The comparison against `net_from_powl` alone would validate only the round trip. A shared error in POWLPetri would pass unnoticed. `powl_language` computes the language from the POWL object. `spec_accepts` is an independent hand-coded reading of the invariant table. Any disagreement between them indicates my own misreading and is reported.

# 6. Visual-Semantics Review

A converted net can be behaviorally acceptable and still be misread in BPMN for the reasons below.

- **Left-to-right layout implies sequence.**
  - Automatic layout places Legal Review on its own line, in a column or ahead of the loop. Readers infer "Legal, then verification". The source has no such order, and Legal may occur later, for example R A P C L I or R A P C I L Rel.
  - The reverse misreading is also possible: Legal drawn below the loop looks like "after verification". The model allows both.
  - Vertical or horizontal position carries no semantics.
- **Parallel gateways (+).**
  - A (+) split after Register shows A and P as unordered. It does not show that A is a predecessor of Legal but P is not.
  - In a faithful BPMN the second split belongs to A's outgoing flow. A reader who assumes a block-structured "parallel(A, P), then next" will miss this.
  - A (+) join before the loop means "both A and P". A (+) join before Release means "both Legal-branch and loop".
  - A drawing that makes Legal a subprocess of the first parallel branch hides that Legal's gate is only A.
- **Exclusive gateways (×).**
  - The optional Legal is an (×) split with an empty branch or bypass flow. It is easy to read the bypass as a "rework path".
  - Conversely, an exclusive split of the A/P branch can look like a choice.
  - Gateway symbols in some renderers are small and identical, so a wrong gateway type is easy to miss.
- **Loop visualization.**
  - PM4Py's BPMN exporter represents the redo as a back-flow through exclusive gateways.
  - Whether the merge gateway sits before C (do-while, minimum 1 iteration) or before a decision gateway (while-do, possibly 0) is a subtle visual difference. It changes INV-08.
  - X appears to loop back to "Configure Trial" only if the back-flow is drawn to the right node. A loop arrow that appears to return to Inspect Trial suggests CIXI. The model forbids that.
- **Silent routing nodes.**
  - Tau transitions become gateways, unlabeled tasks, or extra sequence flows.
  - Extra gateways increase the apparent complexity and suggest business steps that do not exist.
  - Two unlabeled diamonds do not tell the reader which is a split and which is a join.
- **Interleaving versus concurrency.**
  - Nothing in BPMN rendering tells the reader whether the model means true overlap or merely "any order". The validation in Section 5 covers only the latter.

**Annotations and documentation to reduce ambiguity**
- Put a legend on the diagram: (+) = all incoming must arrive, all outgoing are started; (×) = exactly one path.
- Label each gateway with its intent, for example "A and P both complete", "Legal Review optional (skip allowed)", "verification loop: at least once; Correct Defect only between Inspect and next Configure", and "Release waits: Legal (if taken) and verification".
- Add a note: "Legal Review may occur any time after Assess Risk, including during verification, but before Release. Position in the diagram implies nothing."
- Annotate the loop with "min 1, max unbounded".
- Ship the bounded witness traces (positive and negative from Section 1) beside the diagram as an appendix.
- Show the source POWL partial-order diagram next to the BPMN. POWL shows absence of edges directly.
- Record, next to the diagram, the pm4py version, the source hash, and the verdict JSON from Section 5.

# 7. Rejection Criteria

Reject or quarantine a conversion result if any of the following holds.

1. **Conversion exception** in a step whose output is used downstream. Record the exception, and do not retry with a modified source to force a success.
2. **Null or empty initial or final marking** from any conversion, for example `convert_to_petri_net(bpmn)`.
3. **Unsound or non-workflow net.** `check_soundness` is false, errored, or cannot run. Also `check_is_workflow_net` false for a net that should be a workflow net.
4. **Loss of a required interleaving.** Any positive witness is rejected (for example L before P, L inside the loop, L just before Release), or `missing_vs_oracle_count > 0`. This includes collapse to a block-structured order (P4/P5/P7 fail).
5. **Release before verification.** Any accepted trace in which Rel precedes the final I (N10) or in which L follows Rel (N9). This signals a wrong join or a missing synchronization.
6. **Collapse of optional behavior.** L becomes mandatory (P1 rejected), is allowed twice (N4 accepted), or the skip is lost.
7. **Loop-semantics mismatch.** Zero iterations accepted (N5), Inspect-before-Configure accepted (N6), Correct Defect inside the body accepted (N7), or ending on a redo accepted (N8).
8. **Failed exact-final-marking test.**
   - A prefix is accepted as complete (N12).
   - A trace ends with tokens elsewhere, or improper completions are found.
   - Archive is not the last activity (N11, N13).
9. **Added or unexpected labels.** Labels not in the nine-label set, such as gateway names appearing as tasks. Also absent labels, duplicated tasks, or renamed tasks (INV-11).
10. **Incomplete exploration.** Any `closure_cap_hit`, `token_bound_exceeded` or `prefix_cap_hit` flag. The comparison is then inconclusive, not a pass.
11. **Oracle disagreement.** `oracle_vs_spec_disagreements` is non-empty. Fix the validation before judging any converter.
12. **Suspicious process-tree success.** If `convert_to_process_tree` succeeds for the N-pattern source, quarantine the tree until it passes Section 5. Expect label duplication or over-approximation.
13. **Silent BPMN round-trip skip.** Accepting a BPMN without a round-trip net, or claiming a pass when no candidates were compared.

# 8. Canonical Representation Recommendation

**Authoritative representation.**
- The authoritative artifact is the **POWL source definition** (the code, version-controlled, with a content hash).
- It is the only representation that states the partial order, the absence of edges, and the XOR/loop operators directly.
- Every other model is derivative.

**Derivative artifacts**
- The **accepting Petri net** (from `convert_to_petri_net`) is the verification artifact. It may be stored as PNML (`pm4py.write_pnml`) if needed.
- The **BPMN** is the stakeholder visualization, conditional on passing the gates below. If Pipeline A fails or is rejected, the stakeholder view is the POWL rendering (`save_vis_powl`). Do not use a hand-drawn or lossy BPMN as a substitute.
- The **process tree**, if produced, is a diagnostic only.

**Validation evidence that must accompany each derivative**
- Petri net:
  - non-null markings;
  - workflow-net and soundness results;
  - the bounded comparison against the oracle (MAX_ITER, MAX_VISIBLE, flags);
  - witness results.
- BPMN:
  - the conversion log (including the exception when it fails);
  - the round-trip net with its own soundness result;
  - the Section 5 report with every verdict field and zero false accepts;
  - the pm4py version, the source hash and the visual-review checklist (Section 6).
- Any tree:
  - the same bounded comparison;
  - an explicit note that no block-structured form is expected to exist.

**Process-tree intermediate.** It may be allowed as a diagnostic, never as a storage or delivery path. The N-pattern makes a faithful tree unlikely, and a tree that "succeeds" here is evidence of loss, not of quality. If it fails, the failure is a valid finding and must be reported.

**Avoiding round-trip drift in future edits**
- Edit only the POWL source and regenerate every derivative. Never edit BPMN and re-import it as the new truth.
- There is no BPMNPOWL conversion provided, so a BPMN edit cannot be lifted back to the authoritative model. Treat such an edit as a change proposal: update the POWL, regenerate, and revalidate.
- Regression-test with the fixed witness sets and the oracle on every change. Store previous verdicts and compare them.
- Pin the pm4py version, because converters change behavior between releases.
- Do not compare by object identity or by node names across conversions. Compare by visible-label language and marking structure.

# 9. Residual Uncertainty

Even if every test passes, the validation cannot establish the following.

1. **Unbounded loop behavior.** Equality is shown only up to `MAX_ITER` = 4 loop iterations and visible length at most 17. A converter could differ only for larger unrollings. Soundness and boundedness reduce, but do not eliminate, this concern.
2. **True concurrency and timing.** The validation uses interleaving semantics only. It cannot show that Legal Review truly overlaps with verification in BPMN execution, or that the BPMN engine treats gateways the way PM4Py's BPMNPetri does.
3. **Correctness of my oracle.** The oracle and `spec_accepts` encode my reading of POWL semantics (edge means "completes before starts", loop semantics `do (redo do)*`). A shared misreading would be consistent in both. Cross-checking reduces, but does not remove, that risk.
4. **Branching and structural equivalence.** Trace-language equality does not imply bisimilarity, that is, that choices are made at the same moments. Footprints and reachability-graph sizes are necessary checks only and can coincide for different behaviors. For example, footprints cannot distinguish the C/I loop from concurrency (both give C>I and I>C).
5. **Gateway semantics in other tools.** A BPMN that round-trips correctly in PM4Py may behave differently in another BPMN engine, for example in implicit-gateway handling or token semantics.
6. **Identity of elements.** Nothing establishes that a task or gateway in one artifact corresponds to a particular source node, only that visible labels and the language match.
7. **Business meaning.** The validation cannot confirm that the source POWL matches the actual change-management policy, or that "Legal Review after Assess Risk only" is what the organization intends.
8. **Non-behavioral properties.** It does not cover resources, data, time, layout readability, or whether stakeholders read the diagram correctly.
9. **Version dependence.** The results apply only to the pm4py version and Graphviz environment actually run. The code logs the version but cannot predict other releases.
