**Declarative Constraints (PM4Py DECLARE):**
```python
from pm4py.objects.declare import Declare
from pm4py.objects.declare.model import DeclareModel
from pm4py.objects.declare.conditions import Condition
from pm4py.objects.declare.conditions.simple import SimpleCondition

# Constraints:
# 1. Credit Check and Technical Review must both occur before approval.
# 2. Expedite Review (if present) must follow both checks.
# 3. Exactly one of Manager/Auto Approval occurs.
# 4. Supplier Review only if external (attribute guard).
# 5. Correct Dossier must be followed by at least one check.

declare_model = DeclareModel()
declare_model.add_constraint(
    "MandatoryChecks",
    Condition(
        template="Precedence",
        parameters={"A": "Credit Check", "B": "Manager Approval"},
        simple_conditions=[SimpleCondition("A", "B")]
    )
)
declare_model.add_constraint(
    "ExpediteAfterChecks",
    Condition(
        template="Precedence",
        parameters={"A": "Technical Review", "B": "Expedite Review"},
        simple_conditions=[SimpleCondition("A", "B")]
    )
)
# Add more constraints for P5, P6, P7.
```

**Semantics:**
- **Mandatory Checks (P2):** Parallel `Credit Check` and `Technical Review` enforce both.
- **Supplier Review (P3):** Conditional on `external` attribute (default: silent for internal).
- **Expedite Review (P4):** Optional, but constrained to follow checks via DECLARE.
- **Approval (P5):** XOR choice between `Manager`/`Auto Approval`.
- **Corrections (P6):** Loop allows `Correct Dossier`  recheck (subset of checks).
- **Suspicious Repeats (P7):** DECLARE constraint flags `Credit Check` without prior `Correct Dossier`.

**Limitations:**
- Missing `external` attribute: Defaults to allowing Supplier Review (conservative).
- Missing `affected_check` attribute: Rechecks all mandatory checks after correction (over-approximation).

# 9. Validation Experiments

**Reproducible Setup:**
```python
import pm4py
from sklearn.model_selection import train_test_split

# Load log
log = pm4py.read_xes("dossier_log.xes")

# Stratified split by external/internal attribute (if available)
train, test = train_test_split(
    log,
    test_size=0.2,
    random_state=42,
    stratify=[trace.attributes.get("external", False) for trace in log]
)

# Preprocessing: Add missing attributes (e.g., external=False if absent)
for trace in log:
    if "external" not in trace.attributes:
        trace.attributes["external"] = False

# Model evaluation
def evaluate_model(model, log, model_name):
    net, im, fm = pm4py.convert_to_petri_net(model)
    results = {
        "fitness_train": pm4py.fitness_alignments(train, net, im, fm),
        "fitness_test": pm4py.fitness_alignments(test, net, im, fm),
        "precision_train": pm4py.precision_alignments(train, net, im, fm),
        "generalization": pm4py.generalization_tbr(test, net, im, fm),
        "simplicity": pm4py.simplicity_petri_net(net, im, fm, variant="arc_degree")
    }
    return results

# Negative trace suite
negative_traces = [
    ["Register Dossier", "Manager Approval", "Release Order"],  # B3
    ["Register Dossier", "Expedite Review", "Credit Check", "Technical Review", "Manager Approval", "Release Order"],  # B4
    ["Register Dossier", "Credit Check", "Credit Check", "Manager Approval", "Release Order"]  # B8
]

# Alignment-cost sensitivity
costs = {"default": 1, "high_penalty": 10}
for cost_model in costs.values():
    pm4py.fitness_alignments(test, net, im, fm, parameters={"cost_function": cost_model})
```

**Tests:**
1. **Attribute-Stratified Holdout:** Split by `external` to test P3.
2. **Negative Suite:** Ensure models reject B3, B4, B8.
3. **Missing-Event Perturbation:** Remove Supplier Review from external traces; check if models flag as non-compliant.
4. **Unseen Combinations:** Test `Technical Review  Credit Check  Supplier Review  Auto Approval` (absent in training).
5. **Soundness Checks:** `pm4py.check_soundness(net, im, fm)`.
6. **Stakeholder Comprehension:** Survey with standardized questions (e.g., "Does this model allow skipping Credit Check?").

**Decision Rule:**
Reject a model if:
- It fails any negative trace test.
- Holdout fitness < 80% *and* precision < 80%.
- Stakeholder comprehension score < 3/5.

# 11. Dissenting View

**Rebuttal:**
The third alternative’s attribute guards (e.g., `external`) are only as good as the data. If the `external` attribute is missing or noisy, the model may misclassify Supplier Review, leading to false compliance. Model C, despite its rigidity, at least explicitly encodes all observed variants without hidden assumptions. Moreover, the third alternative’s DECLARE constraints add complexity that may confuse stakeholders, undermining its advantage over Model S. The governance board might prefer Model C’s audit readiness, accepting its low generalization as a feature (rejecting unseen behavior by default).

**Evidence to Change Decision:**
- **For Third Alternative:** Proof that `external` and `affected_check` attributes can be reliably inferred or collected.
- **For Model C:** Demonstration that its holdout fitness improves with a larger, more diverse training set, or that its precision remains high against a curated negative suite.
- **For Model S:** Evidence that its permissiveness can be bounded with minimal DECLARE constraints without sacrificing comprehension.
