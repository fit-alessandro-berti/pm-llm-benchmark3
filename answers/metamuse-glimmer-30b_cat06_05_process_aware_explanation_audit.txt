## 2. Process-model consistency checks

* Prefix-time availability check. For each feature store the latest event timestamp used in its computation and assert `feature_timestamp  t0`. Reject features with no timestamp or with `feature_timestamp > t0`. Apply to `queue_length_at_t0`, `same_day_document_count_snapshot`, `risk_score_current`.
* Activity-order feasibility. Build a normative footprint from the process description and enforce a partial order: Registration < Coverage Check < {Damage Assessment or Documents Requested} < Damage Assessment < Settlement Decision < [Appeal] < Claim Closed. Flag any DFG edge that violates the partial order, e.g., `Claim Closed -> Damage Assessment Completed`. Use alignment checks to quantify conformance.
* Same-timestamp ambiguity resolution. When two events share a timestamp require a reliable sequence index. If missing, mark the trace as ambiguous and exclude order-dependent patterns from explanation. This resolves the `Claim Closed / Damage Assessment Completed` tie in Case Z.
* Complete-trace vs prefix test. Compute a `trace_completeness_flag` and recompute every feature on the prefix `Registration -> Coverage Check Completed`. Features whose value changes between prefix and full trace are leakage candidates, e.g., `appeal_seen_anywhere`, `num_document_requests_total`, `full_trace_variant_id`.
* Enabled / impossible / future-possible check at t0. At t0 the enabled activities are evidence cycles and Damage Assessment. Settlement Decision, Appeal, Claim Closed are future-possible but not enabled. An explanation must not reference an activity that is not enabled at t0. Repeated Settlement Decision is semantically legitimate only after an Appeal, which itself is post-t0.
* Appeal semantics check. Allow at most one `Settlement Decision Recorded` before Appeal and a second after Appeal. Validate trace with declarative constraints to separate legitimate reconsideration from duplicate logging.

Limitations: DFG frequency does not imply normative permission; footprint checks miss concurrency. Prefix-only recomputation reduces but does not guarantee causal interpretability.
