# 5. PM4Py rolediscovery and similarity code

```python
import pandas as pd
import pm4py

# 1. Load and format the event log dataframe
df = pd.read_csv('order_to_resolution_log.csv')   # assume CSV with columns as described
formatted_log = pm4py.format_dataframe(df, variant='event_log')

# 2. Discover organizational roles using a method that incorporates activity + case complexity + temp substitution
roles = pm4py.discover_organizational_roles(
    formatted_log,
    params={
        'use_case_complexity': True,
        'use_temporary_substitution': True,
        'output': 'clusters'   # clusters of resources sharing role-like behavior
    }
)

# 3. Discover activitybased resource similarity (cosine on normalized activity counts)
similarity_matrix = pm4py.discover_activity_based_resource_similarity(
    formatted_log,
    variant='cosine_normalized'
)

# 4. Compute handoverofwork and workingtogether networks
handover_net = pm4py.discover_handover_of_work_network(formatted_log)
working_together_net = pm4py.discover_working_together_network(formatted_log)

# 5. Join rolediscovery output with case complexity and temporary substitution indicators
# Assume 'roles' is a dictionary mapping each resource to a role label
for index, row in df.iterrows():
    resource = row['org:resource']
    case = row['case:concept:name']
    df.loc[index, 'role'] = roles[resource]
    # attach complexity and substitution info
    df.loc[index, 'complexity'] = row['case_complexity']
    df.loc[index, 'temp_sub'] = row.get('temporary_substitution',0)

# 6. Export or analyze the enriched dataframe
enriched_log = df   # now contains role, complexity, substitution info
pm4py.save_network(handover_net, 'handover_network.png')
pm4py.save_network(working_together_net, 'working_together_network.png')
```

**Key points in the code:**  
- `use_case_complexity=True` and `use_temporary_substitution=True` ensure that role discovery respects both routine specialization (via case complexity) and crossfunctional substitution patterns.  
- The similarity matrix helps verify intrarole similarity (e.g., Chen–Dina) and interrole differences, preventing overaggregation.  
- Handover and workingtogether networks visualize bridging (Mateo, Giorgio) and shadow (Erik) relationships, supporting the role structure identified in sections 13.
