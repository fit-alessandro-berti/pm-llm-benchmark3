## 1. Feasibility model

```text
Register < Triage
Triage < Identity Check
Triage < Document Check
Originals Receipt < Document Check                 [conditional: originals required]
Identity Check < Assessment
Document Check < Assessment
Assessment < Decision                              [if no RMI and no high-risk compliance gate]
Assessment -> Request More Info -> Document Check -> Assessment -> Decision
Assessment -> Compliance Review -> Decision        [if high-risk or high-value]
Compliance Review -> Request More Info -> Document Check -> Assessment -> Compliance Review -> Decision
Decision < Notify
Escalation Advice < Compliance Review              [optional advisory path; does not replace final review]
Preliminary Compliance Screen < Final Compliance Review
```

```text
Conditional constraints:
- If originals are required, Originals Receipt must precede Document Check; Identity Check may start earlier.
- If originals are not required, Identity Check and Document Check may run concurrently.
- If the case is high-risk or high-value, final Compliance Review must occur after the latest relevant Assessment and before Decision.
- If Request More Info is issued, a new Document Check and a new Assessment are required before Decision.
- If the case is high-risk or high-value and RMI occurs, final Compliance Review must be new or explicitly reaffirmed after the latest relevant Assessment.
- Preliminary compliance work or escalation advice may occur earlier but does not satisfy the final compliance gate.
- Four-eyes: resource(final Assessment) != resource(final Compliance Review).

Declarative constraints:
- Resources cannot have overlapping service intervals.
- Queue values are forecasts, not guarantees; start times depend on priority, arrivals, and resource availability.
- Earlier readiness is not the same as earlier final completion.
- Deleting a rework loop changes decision policy and evidence sufficiency, not only timing.
- A reserved scarce slot can create local speedup but system-wide displacement.
- Controlled concurrency is valid only if resource work intervals are real-time logged and actually overlap.
```

The interventions differ in what they change. K-104 mainly changes timing and capacity allocation: early escalation and a reserved compliance slot can shorten the final compliance review, but they do not change the mandatory order or decision policy. K-219 changes routing and timing: the same activity moves from D1 to D2, with possible rework consequences. K-337 changes the allowed decision policy: the second RMI loop is prohibited, so the case must be decided on incomplete evidence. K-411 changes timing and execution structure: it removes an artificial serial dependency by creating concurrent verification tasks, but it also changes logging behavior and may shift waiting into the assessment queue.

| K-219 D2 earlier document check | Shifts 4-8 h document work from D1 to D2; possible second document/assessment pass if rework. | D1 queue; target document wait. | D2 queue; possibly A2 queue if earlier readiness; external response queue if rework. | D2 standard cases; D1 complex cases; A2 assessment cases. | Mixed: positive if no rework, negative if D2 overload or clarification loops. | Handwriting rework probability; D1/D2 substitution is not capacity-neutral. |
| K-337 suppress second RMI | Removes RMI2, Document Check 3, and Assessment 3; may increase C1 and decision risk work. | D1 queue; A1 queue; external supplier queue. | C1 queue if reviews take longer; downstream remediation/appeal queue. | Cases needing D1/A1 later; cases affected by precedent of deciding on incomplete evidence. | Positive on cycle time, negative on compliance defensibility. | Decision quality and appeal risk can convert saved time into later loss. |
| K-411 parallelize verification | Moves I2 and D2 work earlier and concurrently; no new total work, but earlier A2 demand. | Identity/document serial wait; target assessment readiness. | A2 assessment queue; D2 queue if many concurrent starts. | Other D2 and A2 cases. | Positive if A2 slack exists; neutral or negative if A2 is bottleneck. | True concurrency versus logged concurrency; earlier readiness can just shift queue. |

If applied to 100 similar cases, single-case savings collapse into capacity constraints. K-104 reservation of C1 is the clearest displacement: each preliminary screen plus final review may consume 4-6 h from the only certified reviewer. Even if final review is 1-2 h shorter, the reserved slot can push urgent compliance cases by hours; if 50 high-risk cases reserve slots, C1 queue becomes a priority lottery and the system may create informal expediting. K-219 shifts work from D1 to D2. For 100 handwritten standard cases, D2 demand may rise by 500-800 h, while D1 frees 400-600 h. D1 relief helps complex corporate cases, but D2 queue can grow and rework probability compounds: a 20% clarification rate adds 10-30 h external delay and a second document/assessment pass, making average cycle time worse for low-value cases. K-337 suppresses second RMI. Across many high-risk cases, D1 and A1 queues shrink, but C1 may need longer reviews and legal/managerial time for conditional approvals or appeals. Weekend external responses also matter: suppressing a Friday RMI avoids a Monday supplier delay, but if many cases use it, external parties may see more conditional decisions. If the policy is used to meet SLAs, it may systematically under-collect evidence, converting queue time into downstream loss. K-411 parallelizes verification. For 100 digital low-risk cases, identity and document work can overlap, reducing serial waits, but earlier readiness moves demand into A2. If A2 queue is already 5-6 h, the case may wait in assessment instead of document; if 100 cases arrive, A2 becomes the bottleneck and other cases are displaced. Real-time timestamps are critical: batched entries can make sequential work look parallel, hiding false concurrency and preventing learning. The system-wide sign is therefore mixed: K-411 is beneficial only when assessment capacity has slack; K-219 is beneficial when D2 has slack and handwriting is legible; K-104 is beneficial only when C1 has unreserved slack; K-337 is beneficial only when the missing confirmation is immaterial.

## 7. Final synthesis

The most robust intervention is K-411, provided the controlled workaround produces true, logged concurrency and assessment capacity has slack. It removes an artificial serial dependency without changing evidence requirements, decision policy, or compliance obligations. Its downside is bounded: if A2 is congested, the case waits in assessment rather than document, so the local speedup may not become system-wide speedup. The most dangerous intervention is K-337. Suppressing the second RMI can save 1-3 days, but it changes the decision rule from “collect missing confirmation” to “decide under unresolved discrepancy”. For high-risk, high-value cases that creates legal, appeal, and loss exposure; a rejected or conditionally approved case may return through a slower remediation loop. The local counterfactual is least transportable to policy for K-104. A single reserved C1 slot may look efficient when the case is high-value, but scaling it to many cases converts a scarce reviewer into a priority queue and can delay urgent compliance work elsewhere. K-337 is also non-transportable, but its risk is primarily decision quality; K-104’s risk is hidden capacity displacement. Additional data most valuable: resource-level interval logs showing true overlap and non-overlap; queue age and priority distributions; C1 reservation utilization and downstream compliance wait times; D2 clarification/rework rates by handwriting difficulty; external response times by weekday; and post-decision reversal/appeal rates. These data would distinguish earlier readiness from earlier completion and reveal whether local savings are real or merely shifted congestion.

## 8. Assumption audit

1. `structural` — The normative partial order is complete; no hidden approvals, manager waits, or external checks are required beyond the listed activities.
2. `temporal` — Queue snapshots are forecasts, so actual starts may differ by several hours, especially on Monday and Tuesday.
3. `resource` — C1 is the only fully certified compliance reviewer in the window, so any C1 reservation is non-substitutable.
4. `behavioral` — Triage staff can prepare a preliminary escalation packet without materially delaying Register or Triage.
5. `quality` — Preliminary compliance work reduces final review time only if the sanctions issue and document scope remain stable.
6. `interference` — Other cases continue to arrive and consume D1, D2, A1, A2, and C1 capacity; single-case analysis holds them fixed only locally.
7. `temporal` — External response times for RMI are 8-36 h, and weekend delays can add 48-72 h when not suppressed.
8. `quality` — In K-337, the unresolved discrepancy is material enough that deciding without confirmation has elevated appeal, loss, or compliance-defensibility risk.
