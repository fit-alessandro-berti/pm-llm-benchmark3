## Defects that cost points

**1. “Should be expected to be sound” is answered only after the fact.**  
Section 1 states that the net *is* unsound. The required question is also whether, from structure, soundness should be *expected*. A WF-net with an AND-split and a one-input “join” on one of the two continuation routes should be expected to fail option-to-complete / proper completion *before* any firing table. That a priori step is missing.

**2. Section 2 announces a marking convention it does not use.**  
“Markings below list only places with nonzero token counts” sits in the structural table, which has no markings. Harmless, but sloppy relative to the required structure.

**3. “Behaviorally distinct” is overclaimed for A vs B.**  
A and B have the same visible complete language. The write-up later admits that and treats B as a structural variant; the table is still sold as a set of behaviorally distinct repairs. The prompt allowed structural difference, so this is a clarity failure, not a missing repair. C is the actual semantic alternative.

**4. Unsourced “local” soundness for B and C.**  
The prompt forbids invented WOFLAN numbers unless derived. Asserting that B and C “passed the local workflow-net and soundness checks” without a derivation or log is the same kind of unearned empirical claim, just qualitative. A’s token-flow sketch is enough for this net; the extra “we ran it” sentence does not help.

**5. Repair C is under-described as a Petri-net edit.**  
Adding \(p\_analysis \to t\_waive\_review\) does not only skip analysis. It turns a free-choice XOR at \(p\_review\) into a non-free-choice race, and it leaves `t_join_waived` as a dummy skip—the same one-input pattern as the original bug, now harmless only because the analysis token was already consumed. That residual dummy join is a real new risk and is not in the table.

**6. Soundness sketches are not reachability proofs.**  
For a 1-safe acyclic net this size, listing the reachable markings is feasible and would have sealed A/B/C. The prose is consistent with that set but does not exhibit it. Boundedness / 1-safeness of the original is asserted, not shown.

**7. Section 6 invokes the reachability graph and then ignores it.**  
Storing `convert_to_reachability_graph` without inspecting markings or dead states makes the call ceremonial. The qualitative table is fine; claiming that the graph was used in the diagnosis is not.

**8. Small wording leaks.**  
“Potential symptom: No defect here” is not a symptom. “Two silent steps after recording the waiver” in B reads as consecutive, but analysis can sit between `t_join_waived` and `t_join_normal`. “It can put a token in `sink`” is true of some waiver continuations, not all prefixes.
