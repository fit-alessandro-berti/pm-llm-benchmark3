### Material errors (these are why this is not an 8+)

**1. K-219 misses the intervention’s actual clock.**  
“As soon as originals arrive” is Mon 17:30. Mon 16:00 D2 queue is 5h, so remaining wait is ~3.5h → **D2 can start ~Mon 21:00** if document work continues after hours. The same snapshot world already has D1 working Mon 21:40–Tue 05:40, so overnight document work is in evidence. The answer instead uses **Tue 08:00 D2: 4h** and starts D2 **Tue 08:00–10:00**. That is the wrong forecast and the wrong day. Tue 10:00 is *later* than factual D1 start (Tue 09:30). The table then has Document complete “Tue ~12:00–18:00” **and** Assessment start “Tue ~16:00” — those cannot both be true at the late end. The specified mechanism (“D2 could start much earlier”) is exactly what was not modeled.

**2. K-219 underplays the M1-hours bound.**  
Factual Assessment ends Tue 22:30 and Decision is Wed 08:30. Unless Assessment finishes early enough to catch M1 on Tuesday, **cycle time can be ~0**. The path lists Decision “Wed ~08:30–14:00,” which includes *slower* than fact. Best-case “Tue late” is asserted more than derived from manager availability.

**3. K-104 is not minimal-change.**  
S1/C1 prep does not license cutting A1 from 4h to ~2.5h. Assessment still has to assess a high-risk, high-value, complex corporate file. That saving is invented.  
Worse, earlier **readiness** is confused with earlier **C1 start**. Factually the case is already ready Tue 21:20; C1 still starts Wed 13:10 because of the compliance queue. A Wednesday 10:00 C1 start against a Wed 08:00 forecast of **8h** is a **queue jump from the reservation**, i.e. displacement of whatever occupied those ~6h — not “the case is ready.” Preliminary C1 hours *plus* a held final slot is double demand on the only certified reviewer; that is mentioned in the scale section and under-sold in the single-case path.

**4. K-411 Identity start should barely move.**  
The legacy lock created the Identity task at Triage. I2 already ran Tue 11:30–13:20. Creating the Document task does not free I2 an hour earlier. The real CF lever is **D2 starting ~Tue 12:00** (4h queue from 08:00) in parallel, not a rewritten Identity interval. Assessment gain is then bounded by A2 — this they do say, correctly.
