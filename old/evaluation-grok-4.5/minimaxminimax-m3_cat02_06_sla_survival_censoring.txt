### Defects (why not higher)

1. **Factual error on open cases (§3)**  
   Text says “Six cases are still active” then lists **nine** IDs (S09, S10, S11, S15, S24, S25, S26, S29, S31). There are 9 opens, not 6. Later “remaining 23 closed cases” matches 329, so the section is internally inconsistent. That is a direct use-of-evidence failure.

2. **Incomplete Estimand C logic for post-72 transfer**  
   Contribution table only uses S08 (transfer at 68h). **S32 transfers at 96h**, so at t=72 it was still active and *should* count toward “no terminal disposition at 72h” even if transfer is absorbing. That case is never handled under Estimand C. Same gap for any resolve after 72h is only partially spelled out.

3. **Estimand A encoding language is muddled**  
   A is defined as \(P(T_{\mathrm{resolve}}\le 72)\), but S03 is described as “event at t=76  not counted as resolved by 72h” without cleanly separating (i) binary SLA indicator, (ii) survival process with event at 76, and (iii) CIF mass after 72. Survivable, but not precise enough for a survival-estimand section.

4. **IPCW scenario is a label, not a method**  
   Scenario 3 is acknowledged as impossible without external outcomes, then implemented identically to competing risks. Calling it a third *analysis* overstates what the sensitivity actually varies.

5. **Smaller nits**  
   - “60%+ of cases that never resolve” folds opens into “never,” which is loose.  
   - Mermaid `Submit  AutoCheck: Cohort B` overstates: several B cases never take AutoCheck-first (e.g. S20, S23, S26, S30).
