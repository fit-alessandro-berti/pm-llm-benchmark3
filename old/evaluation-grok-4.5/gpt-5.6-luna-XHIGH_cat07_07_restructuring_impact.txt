Filtering by case set must be done via dataframe case selection or trace-attribute filters. A parenthetical “adapt to version / alternatively filter the dataframe” does not fix incorrect primary code. This is a material flaw in a required deliverable.

2. **Several analysis steps are non-executable placeholders**  
   `normalize_pm4py_network_to_edges`, `compare_edges`, `build_case_activity_durations`, `make_case_metrics`, `report_adjusted_gaps`, `derive_sla_miss_from_case_deadline`, etc. are undefined.    `filter_event_attribute_values(..., level="event")`, `insert_case_service_waiting_time` / `get_service_time` usage, and `extract_temporal_features_dataframe` parameter keys are asserted without matching installed APIs.
