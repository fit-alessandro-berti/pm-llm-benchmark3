### Material analytical / technical flaws (further deductions)
1. **Best-case bound in §6 is wrong for E1.**  
   Open cases with age already \(>72\) (S09, S11, S25, S26, etc.) **cannot** be turned into “resolved within horizon.” A valid lower bound on P(not resolved by 72) must still count them as breaches. Only opens with age \(\le 72\) are free parameters for a best-case E1 bound. As written, the sensitivity overstates how low E1 can go.

2. **Tension between §2 binary coding and §8 survival coding.**  
   §2 marks `open` age \(>72\) as event=1 for E1; the code leaves them as `cause=0` and relies on \(1-\mathrm{CIF}_{\mathrm{Resolve}}(72)\). The population estimand can match, but the dual encoding is never reconciled in code (no second binary estimand path, no explicit “already breached” flag). Easy to mis-implement or mis-read.

3. **E1 formula / typesetting slips** (“1  CIFResolve”) and occasional soft wording that blurs occupancy probability vs all-cause survival identity — minor but sloppy given the quality bar.

   AJ is the right primary choice, but with ~32 cases, few transfers, and 9 opens, point estimates at 72h are extremely noisy. Variance/CI/bootstrap discipline is thinner than the Fine–Gray “underpowered” warning.

No visible IPCW or structured informative-censoring model (bounds only — acceptable if finished, not if promised analysis is half-built).
