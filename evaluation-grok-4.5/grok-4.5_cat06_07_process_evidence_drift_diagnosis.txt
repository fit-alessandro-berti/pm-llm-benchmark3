## Hypercritical deductions (why not 9.5–10)

**1. “What would falsify” is incomplete relative to the brief**  
The task explicitly asks to distinguish evidence from hypotheses and **state what would falsify each explanation**. Contradicting columns and test-wise expected results approximate this, but Section 1 rarely gives crisp falsifiers (e.g., “pipeline-Apr is falsified if canonicalized+deduped prefixes still yield AUROC ~0.67 at 100% maturity”). That is a direct checklist miss, not mere style.

**2. Code sketch: performance evidence  the audit’s median DFG story**  
The problem’s process backbone is **median** `Order Part  Part Received`. The sketch does:
```python
parts_wait_sec": pdfg.get(parts_edge)
```
In PM4Py, `discover_performance_dfg` is mean-centric edge performance, not median, and the return is not cleanly documented here as an auditable median. For a process-evidence monitor tied to the given facts, this should be an explicit median (groupby case edge timestamps or performance DFG with a clear aggregation). That is a material mismatch to the evidence standard the prose relies on.

Still acceptable as a sketch; not “nearly flawless” relative to an audit artifact.
