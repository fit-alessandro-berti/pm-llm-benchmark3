The observed drop can arise from several mechanisms acting together. The UI release changes a label that the model still calls `Classify`; the gateway adds `Queue Routed`; and the ETL switch makes ingestion time stand in for event order. Each creates log/model disagreement without requiring the underlying work to change. The successive alignment improvements after label mapping, queue removal, and source-sequence ordering support that explanation, though their exact contributions remain uncertain because the supplied variants and alignment summaries disagree.

August adds a different mechanism: the policy requires sign-off for high-value claims, but the normative tree has no such step. A compliant case can therefore look deviant. The optional-sign-off candidate is only a rough diagnostic: it does not enforce the value condition or authorization.

Residual deviations still matter. Enhanced-review traces without recorded checks, overrides, and missing high-value sign-offs may indicate noncompliance, missing capture, or both. Stable appeals, approvals, and cycle times modestly weaken claims of a broad operational breakdown, but these aggregates can hide subgroup effects, and incident detection is incomplete. They neither establish that the log is wrong nor rule out violations. Case-level provenance, policy applicability, and independent audit are needed to distinguish work performed from work recorded.

def seq(operator, *children):
    node = ProcessTree(operator=operator)
    node.children = list(children)
    for child in node.children:
        child.parent = node
    return node


def leaf(label):
    return ProcessTree(label=label)


def normative_tree():
    standard = seq(
        ProcessTree.Operator.LOOP,
        leaf("Standard Review"),
        leaf("Request Info"),
        ProcessTree(label=None),  # tau redo-exit branch for the loop
    )
    enhanced = seq(leaf("Enhanced Review"), leaf("Compliance Check"))
    choice = seq(ProcessTree.Operator.XOR, standard, enhanced)
    return seq(
        ProcessTree.Operator.SEQUENCE,
        leaf("Receive"),
        leaf("Classify"),
        choice,
        leaf("Decision"),
        leaf("Notify"),
    )


def candidate_tree():
    """Exploratory only: sign-off is optional, not conditional on claim value."""
    base = normative_tree()
    # Insert optional sign-off before Decision in a permissive candidate.
    children = list(base.children)
    children[-2] = seq(
        ProcessTree.Operator.XOR,
        leaf("Supervisor Sign-off"),
        ProcessTree(label=None),
    )
    # Preserve the required decision/notification order.
    return seq(
        ProcessTree.Operator.SEQUENCE,
        *children[:-2],
        children[-2],
        leaf("Decision"),
        leaf("Notify"),
    )


def expand_variants(period, rows):
    records = []
    for variant_number, (activities, count) in enumerate(rows):
        for case_number in range(count):
            case_id = f"{period}:{variant_number}:{case_number}"
            for position, activity in enumerate(activities):
                records.append({
                    CASE_ID: case_id,
                    ACTIVITY: activity,
                    TIMESTAMP: pd.Timestamp("2026-01-01", tz="UTC")
                                + pd.Timedelta(seconds=position),
                })
    return pm4py.format_dataframe(
        pd.DataFrame(records),
        case_id=CASE_ID,
        activity_key=ACTIVITY,
        timestamp_key=TIMESTAMP,
    )


def normalize(log, remove_queue=False, order_by_source=False):
    """Ordering uses source:sequence only if it exists and has been validated."""
    frame = pm4py.convert_to_dataframe(log).copy()
    frame[ACTIVITY] = frame[ACTIVITY].replace({"Risk Screen": "Classify"})
    if remove_queue:
        frame = frame[frame[ACTIVITY] != "Queue Routed"]
    if order_by_source:
        if "source:sequence" not in frame:
            raise ValueError("Validated source:sequence is not present")
        frame = frame.sort_values(
            [CASE_ID, "source:sequence"], kind="stable"
        )
    return pm4py.format_dataframe(
        frame, case_id=CASE_ID, activity_key=ACTIVITY,
        timestamp_key=TIMESTAMP
    )


def show_structure(title, log):
    variants = Counter(tuple(event[ACTIVITY] for event in trace) for trace in log)
    dfg, starts, ends = pm4py.discover_dfg(log)
    print(f"\nSTRUCTURE: {title}; cases={len(log)}")
    print("Variants:", dict(variants))
    print("Frequency DFG:", dict(sorted(dfg.items())))
    print("Start/end:", starts, ends)


def visible_moves(alignment):
    log_moves, model_moves = Counter(), Counter()
    for log_label, model_label in alignment:
        if model_label == ">>" and log_label not in (None, ">>"):
            log_moves[log_label] += 1
        elif log_label == ">>" and model_label not in (None, ">>"):
            model_moves[model_label] += 1
    return log_moves, model_moves


def assess(title, log, accepting_net, include_precision=False):
    net, initial, final = accepting_net
    diagnostics = pm4py.conformance_diagnostics_alignments(
        log, net, initial, final
    )
    fitness = pm4py.fitness_alignments(log, net, initial, final)
    log_moves, model_moves = Counter(), Counter()
    fitting = 0
    for trace, diagnostic in zip(log, diagnostics):
        lm, mm = visible_moves(diagnostic["alignment"])
        log_moves.update(lm)
        model_moves.update(mm)
        fitting += int(not lm and not mm)

    result = {
        "cases": len(log),
        "fitting_traces_no_visible_deviations_pct": 100 * fitting / len(log),
        "alignment_fitness": fitness,
        "mean_raw_alignment_cost": mean(d["cost"] for d in diagnostics),
        "moves_on_log": dict(log_moves),
        "visible_moves_on_model": dict(model_moves),
    }
    if include_precision:
        result["alignment_precision"] = pm4py.precision_alignments(
            log, net, initial, final
        )
    print(f"\nASSESSMENT: {title}")
    print(result)
    return result


normative = pt_converter.apply(normative_tree())
candidate = pt_converter.apply(candidate_tree())

raw_logs = {p: expand_variants(p, rows) for p, rows in VARIANTS.items()}

for period, raw_log in raw_logs.items():
    show_structure(period + " raw", raw_log)
    assess(period + " raw / normative", raw_log, normative)
    normalized = normalize(raw_log, remove_queue=True)
    show_structure(period + " normalized", normalized)
    assess(period + " normalized / normative", normalized, normative,
           include_precision=(period == "Aug-Sep"))

# Isolate label mapping from queue removal.
assess("Jun-Jul label map only / normative",
       normalize(raw_logs["Jun-Jul"]), normative)
assess("Aug-Sep normalized / optional sign-off",
       normalize(raw_logs["Aug-Sep"], remove_queue=True),
       candidate, include_precision=True)

print("\nCaveat: supplied traces have no genuine timestamps or source sequences.")
print("Caveat: candidate sign-off is optional and cannot enforce the EUR 50,000 rule.")
print("Caveat: reconcile cohort, denominator, model, and preprocessing because")
print("listed variants imply 100% Apr-May and 0% raw Jun-Jul exact fitting,")
print("not the supplied 93% and 32%.")

## 7. Provisional conclusion

The most plausible explanation for the measured conformance collapse is a combination of changed event representation, unreliable ordering, and a normative model that became obsolete in August. Label mapping, technical-event removal, and source-sequence ordering each improve the reported June–July fit. The new sign-off policy then creates legitimate deviations under the old model. Confidence that these mechanisms explain a substantial part of the measured drop is about 90/100; confidence in their individual contributions is much lower because the supplied variants and alignment summaries do not reconcile.

A real compliance concern remains. Enhanced-review traces without recorded checks, overrides, and possible missing high-value sign-offs warrant investigation. Confidence that employee noncompliance occurred is low to moderate, about 40/100, because no reliable audit establishes whether checks were performed but not captured. Stable aggregate outcomes provide limited reassurance, not proof.

Preserve the raw event stream, validate label mappings and gateway provenance, and reconstruct event order from verified source sequence data. Reconcile the reporting populations and model versions. Build an approved, effective-dated model that enforces sign-off for applicable high-value claims, and audit the 55 enhanced-review cases without recorded checks along with matched controls.

Do not claim that employees caused the conformance collapse, that every reversal is false, or that improved fitness proves policy compliance. Report historical measurement corrections separately from confirmed operational remediation.

## 8. Model-governance recommendation

1. **Version models with policy.** Record ownership, approval, effective dates, applicable populations, and rationale; retain historical versions and assess each case against its applicable model.
2. **Maintain event-semantic contracts.** Define canonical activity labels, source action identifiers, lifecycle meaning, and case linkage. Preserve original labels and document validated equivalence mappings.
3. **Define technical-event handling.** Preserve raw events and publish a versioned business-event projection. Exclude events only after provenance validation, with an auditable filter manifest.
4. **Preserve ordering provenance.** Store occurrence, completion, dispatch, and ingestion times separately, with time zone and clock semantics. Validate source sequence scope and ties.
5. **Enforce data-aware rules.** Join claim value, currency, policy date, and resource authorization. Treat unknown attributes as unresolved, not compliant.
6. **Validate releases and pipelines.** Compare reconciled cohorts before and after changes using variants, frequency DFGs, event completeness, alignment moves, fitness, precision, and stratified rule rates.
