PROCESS POLICY
A custom-order dossier uses these activities:

- Register Dossier
- Credit Check
- Technical Review
- Supplier Review
- Expedite Review
- Correct Dossier
- Manager Approval
- Auto Approval
- Release Order

Stakeholders currently agree on the following, with some unresolved detail:

P1. Register Dossier is first and Release Order is last.
P2. Credit Check and Technical Review are mandatory before approval. They may complete in either order.
P3. Supplier Review is required only for externally sourced orders. The external/internal attribute was not included in the control-flow discovery log.
P4. Expedite Review is optional, must follow both mandatory checks, and must precede approval. It may occur before or after Supplier Review.
P5. Exactly one of Manager Approval and Auto Approval occurs before release.
P6. Correct Dossier may repeat. After correction, only the checks affected by the correction should repeat, but the log does not contain an “affected check” attribute.
P7. A repeated mandatory check without a preceding Correct Dossier is considered suspicious.

The discovery team describes Model C as “audit-ready because it closely mirrors frequent variants.”

QUALITATIVE FEEDBACK

F1 — Compliance: Model S is unacceptable because it can skip Credit Check and Technical Review and can place Expedite Review before them.
F2 — Operations: Model C rejects legitimate new combinations of already known behavior and is difficult to update.
F3 — IT architecture: Model C’s duplicate labels and branch enumeration make impact analysis and ownership difficult.
F4 — Data analyst: several holdout cases combine Supplier Review, Auto Approval, and alternate check order in ways absent from training; some Supplier Review events may also be missing.
F5 — Auditor: the reported precision was computed only against observed positive traces; no curated negative behavior suite was used.
F6 — Process owner: a correction may require repeating only Credit Check, only Technical Review, or both. Neither model represents that decision transparently.
F7 — Model S advocate: low precision is acceptable because the model is intended for exploration, not enforcement.
F8 — Model C advocate: low holdout fitness is acceptable because unseen behavior should be treated as noncompliant until approved.
