CURRENT NORMATIVE POWL MODEL M0
The following PM4Py-style construction defines the intended control-flow model. Within `checks`, Sanctions_Check and Quality_Review are concurrent. The approved branch requires Manual_Procurement_Approval before Activate_Supplier. The decision is an exclusive choice between the approved branch and Reject_Supplier. Notify_Requester follows the decision, and Close_Case follows notification.

from pm4py.objects.powl.obj import StrictPartialOrder, OperatorPOWL, Transition
from pm4py.objects.process_tree.obj import Operator

register = Transition(label="Register_Supplier")
sanctions = Transition(label="Sanctions_Check")
quality = Transition(label="Quality_Review")
checks = StrictPartialOrder(nodes=[sanctions, quality])

manual_approval = Transition(label="Manual_Procurement_Approval")
activate = Transition(label="Activate_Supplier")
approved_branch = StrictPartialOrder(nodes=[manual_approval, activate])
approved_branch.order.add_edge(manual_approval, activate)

reject = Transition(label="Reject_Supplier")
decision = OperatorPOWL(operator=Operator.XOR, children=[approved_branch, reject])
notify = Transition(label="Notify_Requester")
close = Transition(label="Close_Case")

M0 = StrictPartialOrder(nodes=[register, checks, decision, notify, close])
M0.order.add_edge(register, checks)
M0.order.add_edge(checks, decision)
M0.order.add_edge(decision, notify)
M0.order.add_edge(notify, close)
