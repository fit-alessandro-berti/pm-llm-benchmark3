## Major / moderate issues (score drivers)

**1. Little’s Law identity is mis-applied in the writeup (real inconsistency)**  
Section 5 defines the area identity (should be exact with one consistent window) then computes  
\(\bar L = 1340/335 = 4.00\) but \(\bar\lambda = 20/320\), yielding \(\bar\lambda\bar W = 4.19\) and calling it “5% boundary effect.”  
That is not a boundary residual; it is inconsistent denominators. With a single \(\Delta\), area/n and n/Δ recover \(L\) exactly. The prose therefore undermines the method it claims to use (the code path is closer to correct than the narrative).

**2. Systematic +5 resource gaps treated as real changeover (A4) without a rounding-only alternative**  
Given mandatory 5-minute rounding, end\(=t\) and next start\(=t+5\) on the same resource is also the classic signature of near-zero true handoff rounded apart. The answer elevates this to a structural 5-minute changeover that enters effective capacity (\(\mu_{S1}\approx3.6/h\), \(\mu_{S2}\approx2.7/h\)) and utilization “occupied fraction ≈0.90–0.95.”  
A dual model (changeover vs pure rounding artifact) is required for competence at this level; sensitivity on service length does not fully replace it. Bottleneck *sign* likely survives, but the capacity arithmetic is over-confident.

**3. Queue-length / WIP construction undercounts starts**  
Code comment admits MISSING starts are excluded from `b1`/`b2`, so \(Q = \mathrm{arrivals}-\mathrm{starts}\) is biased high wherever an imputed start falls. Published Q1 peak ≈7 / Q2 peak ≈4 are not shown to be corrected. \(L\) from ends is safer; the wait-queue figures are softer than presented.
