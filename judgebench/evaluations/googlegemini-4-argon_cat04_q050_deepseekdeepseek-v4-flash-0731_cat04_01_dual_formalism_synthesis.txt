#### 1. Suboptimal Process-Tree Approximation (-0.7 points)
In **Section 3**, you state that the process tree is as faithful as possible under a conservative under-approximation policy, and you serialize `risk_choice`, `supplier_choice`, and `trial_loop` after the initial parallel block:
```text
-> (
  'Register Deviation',
  + ( -> ( 'Contain Material', 'Plan Verification' ), -> ( 'Analyze Root Cause', 'Design Corrective Action' ) ),
  X ( 'Supervisor Review', + ( 'Quality Review', 'Regulatory Review' ) ),
  X ( 'Consult Supplier', tau ),
  * ( -> ( 'Execute Trial', 'Inspect Trial' ), 'Adjust Parameters' ),
  'Release Material',
  'Archive Case'
)
```
**Flaw:** While a Process Tree indeed cannot capture the exact cross-branch dependency (where `Risk` and `Supplier` depend only on `Analyze Root Cause`, while `Trial` depends on both `Plan` and `Design`), **there is zero reason to serialize `Risk`, `Supplier`, and `Trial` relative to one another**. 

Once the initial parallel block `+(->(Contain, Plan), ->(Analyze, Design))` finishes, both `Analyze Root Cause` and the prerequisites for `Execute Trial` are complete. At that point, `Risk`, `Supplier`, and `Trial` are completely independent of one another until `Release Material`. You could have wrapped those three subtrees in a parallel operator `+` instead of putting them in sequence `->`:
```text
-> (
  'Register Deviation',
  + ( -> ( 'Contain Material', 'Plan Verification' ), -> ( 'Analyze Root Cause', 'Design Corrective Action' ) ),
  + (
    X ( 'Supervisor Review', + ( 'Quality Review', 'Regulatory Review' ) ),
    X ( 'Consult Supplier', tau ),
    * ( -> ( 'Execute Trial', 'Inspect Trial' ), 'Adjust Parameters' )
  ),
  'Release Material',
  'Archive Case'
)
```
By leaving them in a sequence, you unnecessarily excluded all traces where approvals, supplier consultation, and trials overlap *after* planning and design are done. Notice that in **Section 5**, your allowed witnesses **A2, A3, and A5** all complete `Plan Verification` and `Design Corrective Action` *before* starting the trials, reviews, and consultations. Had you used the `+` operator as shown above, your Process Tree would have **accepted** A2, A3, and A5! Your tree is therefore notably less faithful than it easily could have been without label duplication.
