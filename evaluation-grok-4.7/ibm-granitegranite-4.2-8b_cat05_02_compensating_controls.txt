4.5

The case labels are often in a defensible range, but the write-up is not reliable enough to use. It misstates the event log, contradicts itself on timing, and the required checker does not run.

The required headings are not exact (`ControlObjective`, `CaseLevel`, `ResidualRisk`). The equivalence test never defines collusion resistance, and its criterion table is garbled (`Fullequivalence (all )`, `(22 )`). AV-2 is still described as preventing obvious fraud, which is stronger than the checks it actually performs.

Several final case statements are factually wrong. AP-204 has no manager event and the audit is `a07` on 8 May; the findings invent a post-release manager ratification and attribute the audit to `a02`. AP-209 likewise has no manager ratification. Its audit on 5 May at 10:00 is inside the recall window after the 18:00 settlement, yet corrective capacity is called uncertain. AP-207 is internally inconsistent: m15 ratified at 14:40, after release at 14:05 and before settlement, but the finding says the manager reviewed before release and assigns high confidence. AP-202’s realized unrecovered loss is only medium-high severity, and the supervisor conflict is listed as a detective control. AP-206’s token-after-prepare ambiguity is forced to `OBJECTIVE_PARTIALLY_MET` instead of left indeterminate. AP-203, AP-205, and AP-208 are the cleanest judgments.

Section 5 often names controls that failed rather than the control that breaks the chain, and it substitutes an independent manager for an independent second releaser. Monitoring covers most requested signals and correctly separates alerts from proof, but it omits control outages.

The code is not executable. `header=None` ingests the header as an event and timestamp parsing should raise; `case_key` is not a `format_dataframe` argument; the extra imports are not valid PM4Py paths. Default `filter_four_eyes_principle` keeps different-resource cases, but the code treats the result as the violator set. Printed flags omit bank-change and repeated-pair results, mark every pair as non-repeated, treat AP-207’s manager as pre-release, and get audit timing wrong for AP-205, AP-206, and AP-209.
