6.5

The write-up covers every required section, keeps the four protected relations (Validate Order → Issue Invoice, Manual Compliance Review → Customer, Package–Delivery codeath, Reopen Order → Close Order) out of the violation bucket, and treats N3 and T6 as real forbidden hits. Those parts are not enough to offset errors in scope, norm identity, and the semantic layer.

The N4 gap is mis-scoped. The summary already states 198 of 200 externally shipped packages, so both missing Pack Package → Dispatch Package cases sit inside N4’s mandatory scope. Sections 2, 3, 4, 7, and 8 still treat those two as possibly internal and therefore possibly outside the rule. That escape is repeated in the final uncertainty statement, which says the violation depends on an external-shipment definition the observation has already applied. The same passages attach the carrier-attribute fact to this directly-follows gap. That fact belongs to a different observation: two Dispatch Package events lack a Delivery object (E6). The two gaps are not shown to be the same two packages. Section 7 then calls the packages “packed orders.”

Row 5 cites E5 for the Pack → Dispatch miss. E5 is Dispatch Package → Package, and that edge is complete at 200. The delivery-object miss is E6, which row 6 handles separately. The code block copies the same mix-up: E5’s metadata scope is `every_pack`. The classifier also inverts the mandatory cases it is meant to flag. It labels a mandatory relation conforming whenever `count != 0`, then is called with `count=2` for the N1, N4, and E6 gaps, so those gaps become `mandatory_conforming`. The E10 call uses `scope_apples`, which would not bind. The sketch therefore does not implement the semantic layer the prose describes.

Smaller problems add up. The 1450 Item versus 1448 Order Add Item weights are read as two events missing an Order, without allowing for multi-object cardinality. The OTG paragraph ties the weight-200 Package–Delivery edge to “Pack/Dispatch” events, although T2 applies to Dispatch Package. A suspected join artifact (E10, low confidence) is ranked above in-scope mandatory gaps. Relation arrows are missing across the findings, and the prose appears to run past the 2,600-word cap. Validate Order → Close Order (83) is only implied, while other benign conforming relations get their own rows.
