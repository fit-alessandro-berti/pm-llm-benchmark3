7.2

The design judgments are mostly right and the required sections are all present: the six-way decision tree has explicit terminals, e05 and e14 are kept, e08/e09 is treated as a label collision, e13/e14 is correctly protected from an existential object test, ingestion time is not the business order, and the 17/44, 15/39, 14/37, and 10/28 counts are arithmetically consistent. The sensitivity section names real interpretation changes (I1 double-pick, invoice self-loop, release vs acceptance, two partial captures, Pack echo, M2’s missing authorization).

The ordering pipeline does not implement the policy it states. The sort key omits the business timestamp and leads with a global stage rank, so it can reorder events that are not timestamp ties. After the prescribed relabel, e15’s activity is no longer in `STAGE_RANK` and falls through to 50, while e17 stays at 11 with indegree 0, so the code emits Confirm Delivery before the same-day ERP payment summary. The prose key also includes lifecycle rank and within-source sequence only; the code compares `source_seq` across sources (WMS 100 vs SCANNER 552) and never encodes several R1 edges it claims, including invoice-before-e14 and Pack-before-Release. Those edges are accidentally recovered only while stage numbers increase with time.

The pre-check groups every equal activity and timestamp together, so e03/e04/e05 become one class-E “retain both” group and the check contradicts the verified merge. `ocel_drop_duplicates` is not scoped to class A: the guard only decides whether to call it, and the call itself would drop every same-activity, same-timestamp event. `expand_to_raw_view` reads `merged_from` from the event row, but that field is written only onto relations, so the reversibility demo does not reconstruct source events. The evidence scenario is copied after `ocel_add_index_based_timedelta` has already moved timestamps, then the delta is applied again. “7 of 16 edges are self-loops” counts occurrences, not distinct DFG edges. The write-up also runs well past the 2,900-word aim.
