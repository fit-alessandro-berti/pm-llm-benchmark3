3.5

The deliverable has the right skeleton (offset direction, rounding-before-correction, SLA versus profile, fold pruning, no midpoint as the primary estimate) and a usable governance section. The actual intervals, durations, and labels are not reliable, and several required products are missing or non-executable.

The clock formula in the assumptions is right: with recorded time in \([R_{\min}, R_{\max}]\) and offset in \([a,b]\), true time is \([R_{\min}-b, R_{\max}-a]\), then convert the zone. That rule is not what the later numbers implement.

Concrete failures in the settled results:

- T-401 start in CEST is \([08:12:00, 08:16:30]\) UTC, not \([08:10:00, 08:16:30]\). Sensor \(08:51:10\) rounds and offsets to about \([08:51:00, 08:51:20]\), not \([08:51:00, 08:52:15]\).
- T-402 containment \(10:02:00\) on HUB is about a 3-second window, not \([10:01:00, 10:06:00]\). The Berlin start is about \([09:16:00, 09:18:30]\) UTC, not the \(09:11\)–\(09:17\) range.
- T-403 uses \(09:00\) instead of the stated \(04:00\) EDT. \(04:00\) EDT is \(08:00\) UTC; with a one-minute floor and \(\pm 180\) s the alert is about \([07:57:00, 08:04:00]\) UTC and start is about \(08:16\) UTC. S1 crosses 15 minutes (possible violation). “Certain pass because start is hours before the alert” is the wrong instant.
- T-404 anchors the 18–25 minute work record to containment at \(10:55\), so start lands near \(10:30\)–\(10:37\) and S1 is called a certain violation. The completion on the row is Investigation_Complete at \(10:35\). Anchoring there puts start near \(10:10\)–\(10:17\), and S1 is only a possible violation. HUB’s separate \(\pm 0.5\) s measurement uncertainty is also dropped into the \(\pm 1\) s offset.
- T-405 reverses the fold. A \(\pm 60\) s clock cannot put \(02:05\) after \(02:50\) inside one fold. Ingestion forces alert on the first fold (CEST, about \(00:49\)–\(00:52\) UTC) and start on the second (CET, about \(01:04\)–\(01:07\) UTC). That duration is about 12–18 minutes, so S1 is a possible violation, not a certain pass. The published intervals also put start before alert, which breaks the constraint used to choose them.
- T-406’s mobile window is hours wide (\([09:13, 15:14]\) UTC) because \(300\) s was handled like hours. With round-to-minute, \(\pm 300\) s, and a \(0\)–\(5\) minute late entry that shifts occurrence, start is about \([12:03:30, 12:18:30]\) UTC against a \(12:00\) alert: S1 possible, not a multi-hour span. Containment is likewise shifted by about an hour.
- Profile bands are mis-sized. Alert→containment is \(2700 \pm 720\) s, i.e. \([33, 57]\) minutes at zeta 1, not \([33, 51]\).
- T-408 is called a certain pass on every rule. Containment is 55 minutes after start, so S2 (45 minutes) is a certain violation. Close at \(2026\text{-}06\text{-}03\ 06:30\) is about 38 h 25 min after containment, so S3 (36 hours) is a certain violation. Zeta 1 and 2 on the close profile fail the same way. That is the clearest certain breach in the set.
- T-409 replaces the usual Berlin bound with \(\pm 12\) minutes, so start is about \([15:52, 16:17]\) UTC, not a ~4 minute gap after \(16:00\). S1 is possible, and start-before-alert remains feasible. “Certain pass, ~4 minutes” drops the uncertainty the case exists to test.
- Section 3 never gives one row per testable case–rule pair. S2 and S3 are largely absent; several profile pairs are absent; the same event is given incompatible intervals in the same section.
- Sensitivity recomputes itself, disagrees with its own matrix, and never covers the T-408 flips because those violations were missed. Tolerance is applied as if a minimum duration above the relaxed cap could still become a pass.
- The Python block is pseudocode. It does not build the event frame, does not emit a DST union, does not call `pm4py.format_dataframe` or `pm4py.conformance_temporal_profile`, and the imports do not match the library. The midpoint-versus-interval comparison the task requires is not produced.

Section 7 does ask for UTC storage, raw timestamps, offset telemetry, resolution, fold identity, causal ids, and an explicit rule that overlap is review evidence rather than automatic breach. That part matches the brief. It cannot carry the quantitative result: the classifications a reviewer would act on are wrong on the cases that are actually certain.
