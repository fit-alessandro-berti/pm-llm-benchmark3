The semantic core is strong: the N-shaped partial order, binary loop `C I (D C I)*`, silent XOR, release join, and concurrency-versus-interleaving distinction are right, the required sections and assessment vocabulary are present, and failure of a process-tree intermediate is treated as a real outcome rather than papered over. The acceptance search aborts the whole trace when any silent branch exceeds the cap, including before trying a visible transition enabled in that same marking. `enumerate_visible_fragment` only skips that branch. One uncertain witness then forces the whole suite to `not tested`, which hides a witness already judged `lost`. Playout uses `MAX_TRACE_LENGTH` 16 and treats every source rejection as `lost`, so a prefix cut off before the final marking false-fails a correct net, including the source self-check. `compare_concurrency` grades a missing required co-enabled pair as `lost` before the `approximated` branch, which is unreachable, contradicting sections 4 and 7. The prose says a footprint parallel mismatch is reported as `ambiguous`; no footprint diff is computed. The reachability graph is only summarized, `validate_one_derivative` is a dead stub, and `MAX_RG_SUMMARY` is unused. The I2 negative witness is illegal because of the verification join, so it does not isolate the missing A–P order.
