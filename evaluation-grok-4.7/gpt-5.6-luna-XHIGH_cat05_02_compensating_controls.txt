7.5

The control reasoning is strong and mostly non-mechanical: FEP-1 is decomposed into real threat scenarios, the sufficiency test covers timing, independence, coverage, overrideability, recoverability, evidence quality, and collusion resistance, and “same expected loss” is correctly rejected. Case judgments generally follow the evidence. AP-203 and AP-207 are treated as authorized exceptions, AP-201 as only partial, AP-205 as stopped before completion, AP-202 and AP-208 as failures, AP-204 as an objective failure despite two user IDs, and AP-206 and AP-209 as indeterminate. Post-release, pre-settlement manager action is explicitly treated as hybrid. Monitoring recommendations separate alerts from proof.

The defects are still material.

The PM4Py check does not reliably identify violating cases. `filter_four_eyes_principle` keeps cases that respect four eyes unless `positive` is false. The code never sets that direction, then labels the result as nominal violations. With the usual default, completed violations are dropped and the conforming pair AP-204/AP-209 is printed as the violation set. The fallback import `pm4py.algo.filtering.log.four_eyes` is not a real compatibility path, and the version note never mentions this polarity. There is also no independent same-resource check, despite the dataframe already containing the resources.

The case-facts frame is not a faithful transcription. AP-202’s bank change was two hours earlier, but `bank_change_days` is 2. “New vendor” is invented as 2 days, and AP-205’s “established vendor” is invented as exactly three years. The comment says missing values fail closed, while a missing bank-change value passes the ED-1 “no recent bank change” test. The 24-hour recall test is also used as the one-business-day audit test; those windows are not the same. AP-206’s unresolved token time is hardcoded as ineligible, so the flag erases the indeterminacy the narrative correctly preserves.

Section 2 is internally loose. Post-release approval is given as the example of merely partial equivalence, while AP-207’s post-release, pre-settlement ratification is then classified as the objective being met. ED-1 can support that result, but the test does not state the distinction. AP-201 is also somewhat generous: review content and any actual hold power are unknown, yet the classification confidence is medium-high. In the counterfactuals, AV-2 is described as leaving duplicates and wrong amounts open on AP-201 even though those are among the checks a full pass covers, and AP-208’s amount ceiling is treated as if it still applied after adding a genuinely independent second releaser.
