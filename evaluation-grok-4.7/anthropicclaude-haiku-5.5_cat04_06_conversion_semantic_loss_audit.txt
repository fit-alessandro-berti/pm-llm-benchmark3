The document is structurally complete and epistemically careful: POWL stays authoritative, invariants are mostly well witnessed, the process-tree path is allowed to fail, preservation is not pretended to have been executed, and layout is separated from behavior. It is still not a reliable audit, because several verdicts and claims do not match the code or the source order.

The round-trip verdict can be wrong in both directions. `concurrent_pair` stores the reference result but sets `ok` only by comparison with the hand-written pair list, so a candidate can PASS while disagreeing with `net_from_powl` on true concurrency. `play_out` is not tau-hidden: POWL-derived nets contain many `label is None` transitions, and playout keeps their names in `concept:name`, so in-bound samples miss `bounded_language` and force REJECT whenever playout works. If `play_out` is missing, the ERROR status has no `not_in_target` key and is ignored, so that check cannot fail the run. Reachability output is never compared. `check_is_workflow_net` never enters the verdict. Witnesses run only inside the candidate loop, so a lone reference net is never checked.

The harness also misses checks the prose treats as mandatory. There is no trace with activity after Archive, no negative trace for Legal before Assess, and no label-count check, while rejection criteria 8 and 13 and invariant I4 depend on them. I4 is marked `expected preserved` in the same row that says to use `not tested`. I5 cites N9, but in N9 both Assess and Prepare already precede Configure, so N9 does not witness I5. `MAX_VISIBLE = 12` makes three verification iterations unreachable: the shortest complete three-iteration trace already has length 13, so the stated “≤12 and ≤3 iterations” bound is not the bound that is actually searched. The primary `convert_to_bpmn(...)` call is outside `try/except`, so the expected BPMN failure mode aborts before `conversion_report.json` is written. The claim that a shared preset always means conflict is false once a place holds more than one token.

The N-shape argument, do-redo reading, tau closure, exact final-marking rule, and the refusal to treat BPMN as authoritative are sound. Those strengths do not offset a comparator that can both false-reject a faithful net and false-pass a concurrency mismatch.
