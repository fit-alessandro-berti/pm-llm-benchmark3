6.4

The design is structurally complete and mostly conservative, but it is not reliable enough on counts, ordering, or the PM4Py path.

The decision tree covers every required class and terminal action, and the event table hits every required pair. Keeping e05 and e14, splitting the harmonized dispatch labels, and refusing to treat O1/V1 as proof that M1 and M2 are the same capture are the right calls. The semantic-versus-deterministic ordering policy and the microsecond warning are also right. The audit fields and the eight failure modes match the request.

The quantitative and implementation claims do not hold up. Raw E2O is 44 links, not about 42. Merging e03/e04 and e11/e16 removes 5 links (3+2), so the conservative “at most one duplicate edge” claim is false, and section 7’s “about 40” does not match it. Dropping e05 does not make the package look like one item: e06 still relates to I1 and I2. A same-activity merge also cannot create one Pack event tied to M1 and M2. The “60s–12h” duration claim is incoherent.

e08 before e09 is asserted as a domain fact and even attributed to `source_seq`, which is not comparable across WMS and the carrier. Only e09 before e10 is given. The code then ranks all ties with `semantic_rank * 1000 + source_seq`, so incomparable sequence numbers decide cross-system order, including the concurrent picks.

The code mutates `ocel_raw` before copying, despite saying it must not. The verified-pair helper never writes merged attributes, uses `pass` for authority, and deletes relations under `ocel:eid` while events use `eid`. The problem’s time column is `timestamp`; the code reads `event_timestamp`. `ocel_drop_duplicates` is applied to the unsafe global collapse, not to a justified exact-duplicate case, and that path drops e05. `ocel_add_index_based_timedelta` is called with kwargs that do not match the stated operation. Evidence-based attachment of the invoice-level e15 summary onto e13 alone assigns a balance that is not known to be M1-only. “Bit-identical” reversal is stronger than the stored provenance. The prose also runs well past the 2,900-word target.
