The primary interval arithmetic, timezone conversions, DST-fold elimination, SLA limits, and ζ-bands are largely correct, and the four-way classification is applied consistently. Problems that keep this below a 9:

- T-402 S2 says violation occurs only if start is before `09:16:58.5Z` (offset more than 61.5 s fast). That timestamp is only the point at which even the earliest containment exceeds 2700 s. Violation remains possible up to start `09:17:01.5Z`. The same compression appears for T-406 S2 at `12:06:58.5Z` versus `12:07:01.5Z`. The intervals themselves are right; the predicates are not.
- Shared-offset T-405 S1 is given as `[840, 960]`. Under the answer’s own closed-band rule that interval lies inside `[240, 960]`, so A→I at ζ = 2 changes from POSSIBLE_VIOLATION to CERTAIN_PASS. The write-up records the ζ = 1 change and the +2 min SLA change, but not this one, despite requiring every classification change.
- Floor tops are defined as `.999` and then published as exact `.0`/`.5` durations (`[720.0, 1080.0]`, `[2070.0, 2360.0]`). The true extremes differ by about 0.001 s. Harmless for the headline labels, but it is exactly what makes the shared-offset upper edge 959.999 versus 960, so the rounding is not innocent.
- “`format_dataframe` coerces `T-401`” is not a reliable description of that API, and the diagnostics-dataframe branch (`iloc[0..2]`) is speculative. The version caveat limits the damage; calling the comparison “observed” on pm4py 2.7.x overstates what the code block actually establishes.
- T-409’s headline CERTAIN_PASS for S2 is only robust to dropping the offset bound because an unlogged causal order is imposed. The table shows the pieces, but “robust” is stronger than the evidence hierarchy stated in A7.

No primary certain/possible/indeterminate label was found to be flipped. The deductions are for threshold misstatements, an omitted boundary reclassification, and a few claims that are tighter than the model or the code.
