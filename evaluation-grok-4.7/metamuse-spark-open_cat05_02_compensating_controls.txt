The control judgments are strong and non-mechanical: same-user AP-203 and AP-207 are treated as met under ED-1, AP-201 and AP-206 as only partial, AP-204 as failed despite distinct users, AP-209 as indeterminate, and AP-205 as stopped before completion. The findings and code are not reliable enough for a higher score. AP-208 is described as an “800-month” vendor that “barely qualifies,” which is incoherent with the stated 8-month tenure. The code invents tenures (14 and 2000 days), records AP-208’s audit delay as 91 hours rather than about 115, and fails AP-204’s full AV-2 pass because of an exact string match. It never actually joins the facts to the log, and the set expression depends on operator precedence. It also treats a dataframe returned by `filter_four_eyes_principle` as the violating set, although the usual implementation returns cases that satisfy four-eyes; the manual fallback is correct, but the library path can invert the result.
